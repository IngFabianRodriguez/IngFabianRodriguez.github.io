Visual Question Answering - Preguntas Sobre Imagenes

14 de octubre de 2026
vqavision-languagemultimodalai

Intro

Mañana vas a analizar imágenes médicas para un proyecto de diagnóstico assistido. Necesitas hacer preguntas como "¿hay signos de neumonía en esta radiografía?" o "¿qué región muestra anomalías?". Un humano puede hacerlo, pero un modelo tradicional de visión por computador no responde preguntas en lenguaje natural sobre imágenes. Ahí es donde entra Visual Question Answering (VQA) — la habilidad de responder preguntas sobre el contenido de una imagen.

VQA es un problema multimodal fundamental que combina visión por computador y procesamiento de lenguaje natural. No es solo clasificación de imágenes — es comprensión visual profunda combinada con razonamiento lingüístico. Hoy vamos a entender cómo funciona, qué arquitecturas lo resuelven, y cómo implementar un sistema VQA básico.

Qué es Visual Question Answering

VQA es el problema de responder preguntas en lenguaje natural sobre una imagen. A diferencia de tareas tradicionales de visión donde la etiqueta es fija (gato o perro), en VQA la pregunta puede ser cualquier cosa:

  • ¿Cuántos objetos hay en la imagen? → respuesta: "3"
  • ¿El objeto rojo es un carro o un bus? → respuesta: "carro"
  • ¿Qué está haciendo la persona de la izquierda? → respuesta: "caminando"
  • ¿Hay algún peligro en esta escena? → respuesta: "sí, hay fuego"

La dificultad radica en que el modelo debe:

  • Entender la pregunta (NLP)
  • Entender el contenido visual (CV)
  • Razonar sobre la relación pregunta-imagen
  • Generar o seleccionar una respuesta válida

Arquitecturas VQA

Arquitectura temprana: CNN + LSTM

Las primeras arquitecturas VQA usaban una aproximación simple:

# Arquitectura básica CNN + LSTM para VQA
import torch
import torch.nn as nn

class VQACNNLSTM(nn.Module):
    def __init__(self, vocab_size, embed_dim=300, hidden_dim=512):
        super().__init__()
        # Encoder de imagen: CNN pretrained (ej. ResNet)
        self.image_encoder = torchvision.models.resnet50(pretrained=True)
        self.image_encoder.fc = nn.Linear(2048, hidden_dim)
        
        # Encoder de pregunta: LSTM
        self.question_encoder = nn.LSTM(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            batch_first=True
        )
        
        # Combinar características y clasificar respuesta
        self.classifier = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(hidden_dim, vocab_size)
        )
    
    def forward(self, image, question):
        # image: (batch, 3, 224, 224)
        # question: (batch, seq_len)
        
        # Extraer características de imagen
        img_features = self.image_encoder(image)  # (batch, hidden_dim)
        img_features = img_features.unsqueeze(1).expand(-1, question.size(1), -1)
        
        # Codificar pregunta
        q_output, (q_hidden, _) = self.question_encoder(question)
        q_features = q_hidden.squeeze(0)  # (batch, hidden_dim)
        q_features = q_features.unsqueeze(1).expand(-1, img_features.size(1), -1)
        
        # Combinar y clasificar
        combined = torch.cat([img_features, q_features], dim=-1)
        combined = combined.mean(dim=1)  # pooling
        output = self.classifier(combined)
        
        return output

Arquitectura con Atención

Las arquitecturas modernas usan atención visual para enfocar en las regiones relevantes de la imagen:

# Atención visual para VQA
class VisualAttention(nn.Module):
    def __init__(self, image_dim=2048, hidden_dim=512):
        super().__init__()
        self.image_attention = nn.Linear(image_dim, 1)
        self.softmax = nn.Softmax(dim=1)
    
    def forward(self, image_features, question_features):
        # image_features: (batch, num_regions, image_dim)
        # question_features: (batch, hidden_dim)
        
        # Calcular atención basada en la pregunta
        q_expanded = question_features.unsqueeze(1).expand(-1, image_features.size(1), -1)
        attention_input = image_features * q_expanded
        attention_scores = self.image_attention(attention_input).squeeze(-1)
        attention_weights = self.softmax(attention_scores)
        
        # Aplicar atención a características de imagen
        attended_features = torch.sum(image_features * attention_weights.unsqueeze(-1), dim=1)
        
        return attended_features, attention_weights


class UpDownAttentionVQA(nn.Module):
    """
    Bottom-Up Top-Down Attention - similar a la usada en BUTD (Anderson et al.)
    """
    def __init__(self, vocab_size, embed_dim=300, hidden_dim=512, num_objects=36):
        super().__init__()
        self.num_objects = num_objects
        
        # Image feature extractor (pre-trained Faster R-CNN)
        self.image_encoder = nn.Linear(2048, hidden_dim)
        
        # Question encoder
        self.word_embedding = nn.Embedding(vocab_size, embed_dim)
        self.question_encoder = nn.LSTM(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            batch_first=True,
            bidirectional=True
        )
        
        # Attention layers
        self.image_attention = nn.Linear(hidden_dim, 1)
        self.classifier = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(hidden_dim, vocab_size)
        )
    
    def forward(self, image_features, question, question_length):
        # image_features: (batch, num_objects, 2048)
        # question: (batch, max_seq_len)
        # question_length: (batch,)
        
        batch_size = image_features.size(0)
        
        # 1. Codificar pregunta
        embedded = self.word_embedding(question)
        _, (q_hidden, _) = self.question_encoder(embedded)
        q_hidden = torch.cat([q_hidden[0], q_hidden[1]], dim=1)  # bidirectional
        
        # 2. Atención visual
        image_proj = self.image_encoder(image_features)  # (batch, num_objects, hidden)
        combined = image_proj * q_hidden.unsqueeze(1).expand(-1, self.num_objects, -1)
        attention_logits = self.image_attention(combined).squeeze(-1)
        
        # Mask padding regions
        mask = torch.arange(self.num_objects, device=attention_logits.device).unsqueeze(0).expand(batch_size, -1)
        mask = mask < torch.tensor([self.num_objects] * batch_size, device=mask.device).unsqueeze(1)

        output = self.classifier(combined_features)
        
        return output

VQA con Transformers (state-of-the-art)

Los modelos modernos usan transformers multimodales que procesan imagen y texto conjuntamente:

# VQA con Multimodal Transformer (simplificado)
from transformers import BertModel, BertTokenizer, VisionEncoderDecoderModel

class TransformerVQA(nn.Module):
    def __init__(self):
        super().__init__()
        # Encoder de imagen (ViT) y decoder de texto (BERT)
        self.model = VisionEncoderDecoderModel.from_pretrained(
            "nlpconnect/vit-gpt2-image-captioning"
        )
        # Reemplazar decoder para VQA (preguntas como input, respuestas como output)
        
    def forward(self, image, question):
        # image: (batch, 3, 224, 224)
        # question: (batch, seq_len) - tokenized question
        
        # Usar pregunta como prefix para el decoder
        outputs = self.model(
            pixel_values=image,
            labels=question  # training mode
        )
        return outputs.logits


# Alternativa: usar modelo pre-entrenado de VQA
from transformers import pipeline

# Cargar pipeline VQA pre-entrenado
vqa_pipeline = pipeline("vqa", model="dandelin/vilt-b32-finetuned-vqa")

def answer_question(image_path, question):
    """
    Ejemplo de uso de pipeline VQA pre-entrenado.
    """
    from PIL import Image
    import requests
    
    image = Image.open(image_path)
    result = vqa_pipeline(image, question)

Datasets y evaluación

Los datasets principales para VQA son:

  • VQA v2.0: 1M+ preguntas sobre imágenes de COCO, con balanceo de respuestas para reducir sesgos
  • Visual Genome: 1M+ preguntas con region descriptions más detalladas
  • VQAv2.0-E: Versión equilibrada con contrafácticos

La evaluación usa VQA Accuracy:

accuracy = (1 / N) * sum(min( (# humanos que dieron respuesta r) / 3, 1 ))

Es decir, si 3 o más humanos dieron la misma respuesta, cuenta como correcta. Si 1 o 2 la dieron, cuenta parcialmente.

Aplicaciones reales

  • Médicina: Preguntas sobre radiografías, tomografías, imágenes de retina
  • Accesibilidad: Describir escenas para personas con discapacidad visual
  • Seguridad: Analizar cámaras de vigilancia con preguntas naturales
  • Educación: Sistemas interactivos que responden preguntas sobre diagramas, mapas, imágenes históricas
  • Retail: Analizar productos en estantes, responder preguntas sobre inventario

Resumen y cierre

Visual Question Answering es una tarea multimodal que combina visión por computador y NLP para responder preguntas sobre imágenes. Las arquitecturas han evolucionado desde CNN+LSTM simples hasta transformers multimodales sofisticados. El campo avanza rápidamente con modelos como CLIP, GPT-4V, y Gemini que demuestran capacidades VQA impresionantemente robustas.

La próxima vez que necesites que un modelo "mire" una imagen y responda preguntas específicas, ya sabes cómo funciona internamente. Y si necesitas implementar algo rápido, hay pipelines pre-entrenados que funcionan sorprendentemente bien out of the box.

En Bogotá decíamos: "una imagen vale más que mil palabras, pero una buena pregunta vale más que mil imágenes". Con VQA, las máquinas finalmente pueden entender esa relación.
