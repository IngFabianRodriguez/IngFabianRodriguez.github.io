🎯 Que Son Los Diffusion Models?

Diffusion models son modelos generativos que aprenden a generar datos invirtiendo un proceso de difusion (denoising). Durante el entrenamiento, aprenden a reconstruir datos de versiones ruidosas.

Fases:

  • Forward Process: Anadir ruido gradualmente hasta que sea solo ruido
  • Reverse Process: Aprender a revertir el proceso,去除 ruido
  • Sampling: Generar nuevas imagenes desde ruido puro

🚀 DDPM (Denoising Diffusion Probabilistic Models)

@torch.no_grad()
def sample_ddpm(model, shape, num_steps=1000):
    """Generate samples using DDPM"""
    x = torch.randn(shape)
    
    for t in reversed(range(num_steps)):
        # Predict noise
        noise_pred = model(x, t)
        
        # Compute mean
        alpha = alphas[t]
        alpha_bar = alphas_cumprod[t]
        
        # Slightly denoise
        if t > 0:
            noise = torch.randn_like(x)
        else:
            noise = 0
        
        x = (x - (1-alpha)/torch.sqrt(1-alpha_bar) * noise_pred) / torch.sqrt(alpha)
        x = x + torch.sqrt(1-alpha) * noise
    
    return x
