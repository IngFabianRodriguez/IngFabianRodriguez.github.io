📐 La Matemática Detrás de BatchNorm

Batch Normalization normaliza las activaciones de una capa restando la media del batch y dividiendo por la desviación estándar. Pero aquí viene el detalle que muchos ignoran: durante el entrenamiento usa estadísticas del batch actual, pero durante inference usa running statistics calculadas durante el entrenamiento.

La fórmula durante entrenamiento es:

\[ \mu_B = \frac{1}{m} \sum_{i=1}^{m} x_i \quad \sigma_B^2 = \frac{1}{m} \sum_{i=1}^{m} (x_i - \mu_B)^2 \] \[ \hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \quad y_i = \gamma \hat{x}_i + \beta \]

Donde γ y β son parámetros aprendibles (si affine=True). Los running statistics se actualizan con momentum:

\[ \mu_{\text{running}} = (1 - \text{momentum}) \cdot \mu_{\text{running}} + \text{momentum} \cdot \mu_B \] \[ \sigma^2_{\text{running}} = (1 - \text{momentum}) \cdot \sigma^2_{\text{running}} + \text{momentum} \cdot \sigma^2_B \]

El momentum por defecto es 0.1 en PyTorch. Esto significa que el 10% del batch actual entra en las estadísticas acumuladas. Un valor bajo = estadísticas más estables pero converge más lento. Un valor alto = adapta más rápido a cambios en la distribución pero puede ser ruidoso.

Affine vs Non-Affine BatchNorm

Con affine=True (default), BatchNorm aprende parámetros γ (scale) y β (shift). Esto le da a la red capacidad de desaprender la normalización si es necesario. Con affine=False, la transformación es puramente determinista — útil cuando quieres congelar la normalización o cuando ya sabes que no la necesitas.

1D, 2D y ND BatchNorm

  • BatchNorm1d: ParaMLPs — normaliza sobre las features de cada sample. Input: (N, C) o (N, C, L) donde normaliza sobre C.
  • BatchNorm2d: Para CNNs — normaliza sobre (N, C, H, W), computes stats per channel sobre N, H, W.
  • BatchNorm3d: Para 3D convs — normaliza sobre (N, C, D, H, W).

import torch
import torch.nn as nn
import torch.nn.functional as F
import math


# ==============================================================================
# 1. BatchNorm desde cero con running stats manuales
# ==============================================================================
class ManualBatchNorm1d(nn.Module):
    """
    Implementación de BatchNorm1d desde cero.
    Normaliza features sobre el eje de channels.
    """
    def __init__(self, num_features, eps=1e-5, momentum=0.1, affine=True):
        super().__init__()
        self.num_features = num_features
        self.eps = eps
        self.momentum = momentum
        self.affine = affine

        # Running stats
        self.register_buffer('running_mean', torch.zeros(num_features))
        self.register_buffer('running_var', torch.ones(num_features))

        # Parámetros aprendibles
        if affine:
            self.weight = nn.Parameter(torch.ones(num_features))
            self.bias = nn.Parameter(torch.zeros(num_features))
        else:
            self.weight = None
            self.bias = None

    def forward(self, x):
        # x shape: (N, C) o (N, C, L)
        if self.training:
            # Calcular stats sobre el batch actual
            # Para 2D: (N, C, L) -> (N*L, C) para computar stats
            if x.dim() == 3:
                N, C, L = x.shape
                x_flat = x.permute(0, 2, 1).reshape(-1, C)  # (N*L, C)
            else:
                x_flat = x

            # Media y varianza del batch
            batch_mean = x_flat.mean(dim=0)
            batch_var = x_flat.var(dim=0, unbiased=False)

            # Actualizar running stats (solo en training)
            self.running_mean = (1 - self.momentum) * self.running_mean + self.momentum * batch_mean
            self.running_var = (1 - self.momentum) * self.running_var + self.momentum * batch_var

            # Normalizar
            if x.dim() == 3:
                x_norm = (x_flat - batch_mean) / torch.sqrt(batch_var + self.eps)
                x_norm = x_norm.reshape(N, L, C).permute(0, 2, 1)
            else:
                x_norm = (x - batch_mean) / torch.sqrt(batch_var + self.eps)

            # Scale y shift
            if self.affine:
                x_norm = x_norm * self.weight + self.bias
        else:
            # Inference: usar running stats
            if x.dim() == 3:
                N, C, L = x.shape
                x_norm = (x - self.running_mean.view(1, C, 1)) / \
                         torch.sqrt(self.running_var.view(1, C, 1) + self.eps)
            else:
                x_norm = (x - self.running_mean) / torch.sqrt(self.running_var + self.eps)

            if self.affine:
                x_norm = x_norm * self.weight + self.bias

        return x_norm

    def extra_repr(self):
        return f'{self.num_features}, eps={self.eps}, momentum={self.momentum}, affine={self.affine}'

# 2. Comparación: affine=True vs affine=False
# ==============================================================================
def compare_affine():
    """Muestra cómo affine=True permite cambiar la distribución aprendida."""
    torch.manual_seed(42)

    bn_affine = nn.BatchNorm1d(64, affine=True)
    bn_no_affine = nn.BatchNorm1d(64, affine=False)

    x = torch.randn(32, 64)

    out_affine = bn_affine(x)
    out_no_affine = bn_no_affine(x)

    print("=== Affine=True vs False ===")
    print(f"Input mean: {x.mean():.4f}, std: {x.std():.4f}")
    print(f"Affine=True  -> mean: {out_affine.mean():.4f}, std: {out_affine.std():.4f}")
    print(f"Affine=False -> mean: {out_no_affine.mean():.4f}, std: {out_no_affine.std():.4f}")
    print(f"Affine params: weight={bn_affine.weight.data[:5].tolist()}")
    print()


# ==============================================================================
# 3. BatchNorm en CNNs vs LayerNorm en Transformers
# ==============================================================================
class CNNWithBatchNorm(nn.Module):
    """CNN estándar con BatchNorm — normaliza sobre (N, H, W) por canal."""
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.conv = nn.Conv2d(in_ch, out_ch, 3, padding=1)
        self.bn = nn.BatchNorm2d(out_ch)
        self.relu = nn.ReLU()

    def forward(self, x):
        return self.relu(self.bn(self.conv(x)))


class TransformerBlock(nn.Module):
    """Bloque de transformer con LayerNorm — normaliza sobre features."""
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.ln1 = nn.LayerNorm(d_model)
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.ln2 = nn.LayerNorm(d_model)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_model * 4),
            nn.GELU(),
            nn.Linear(d_model * 4, d_model)
        )

    def forward(self, x):
        # LayerNorm normaliza sobre la dimensión de features
        attn_out, _ = self.attn(self.ln1(x), self.ln1(x), self.ln1(x))
        x = x + attn_out
        x = x + self.ff(self.ln2(x))
        return x


# ==============================================================================
# 4. Gradient Flow comparison: con y sin BatchNorm
# ==============================================================================
class SimpleBlock(nn.Module):
    def __init__(self, dim, use_bn=False):
        super().__init__()
        self.lin = nn.Linear(dim, dim)
        self.bn = nn.BatchNorm1d(dim) if use_bn else nn.Identity()
        self.act = nn.ReLU()

    def forward(self, x):
        return self.act(self.bn(self.lin(x)))


def measure_gradient_flow():
    """Mide la magnitud de gradientes en capas profundas."""
    torch.manual_seed(42)

    depths = [1, 3, 5, 10, 20]
    x = torch.randn(16, 512, requires_grad=True)

    print("=== Gradient Flow: con vs sin BatchNorm ===")
    print(f"{'Depth':>6} | {'Sin BN grad_mean':>18} | {'Con BN grad_mean':>18}")
    print("-" * 50)

    for depth in depths:
        # Sin BatchNorm
        model_no_bn = nn.Sequential(*[SimpleBlock(512, False) for _ in range(depth)])
        model_no_bn(x.grad = None)
        x_init = x.clone().detach().requires_grad_(True)
        out = model_no_bn(x_init)
        out.sum().backward()
        grad_mean_no_bn = x_init.grad.abs().mean().item()

        # Con BatchNorm
        model_bn = nn.Sequential(*[SimpleBlock(512, True) for _ in range(depth)])
        model_bn(x.grad = None)
        x_init = x.clone().detach().requires_grad_(True)
        out = model_bn(x_init)
        out.sum().backward()
        grad_mean_bn = x_init.grad.abs().mean().item()

        print(f"{depth:>6} | {grad_mean_no_bn:>18.6f} | {grad_mean_bn:>18.6f}")

    print()


# ==============================================================================
# 5. Efecto de batch size pequeño
# ==============================================================================
def small_batch_effect():
    """Demuestra cómo batch sizes pequeños hacen que running stats sean ruido."""
    torch.manual_seed(42)

    bn = nn.BatchNorm1d(64, momentum=0.1)
    bn.train()

    print("=== Efecto de batch size pequeño ===")
    print(f"Running mean inicial: {bn.running_mean[:5].tolist()}")

    # Batch grande: estadísticas estables
    x_large = torch.randn(64, 64)
    bn(x_large)
    print(f"Después de batch=64: mean={bn.running_mean[:5].tolist()}")

    # Reset y batch pequeño
    bn = nn.BatchNorm1d(64, momentum=0.1)
    bn.train()

    # Batch de 1 — stats muy ruidosos
    for i in range(10):
        x_small = torch.randn(1, 64)
        bn(x_small)

    print(f"Después de 10 batches de size=1: mean={bn.running_mean[:5].tolist()}")
    print("^ ¡Este running mean es esencialmente ruido! No lo uses para inference.")
    print()

    # Batch de 2 — marginalmente mejor pero aún problemático
    bn = nn.BatchNorm1d(64, momentum=0.1)
    bn.train()
    for i in range(50):
        x_tiny = torch.randn(2, 64)
        bn(x_tiny)

    print(f"Después de 50 batches de size=2: mean={bn.running_mean[:5].tolist()}")
    print()

🚨 Los 3 Errores Más Comunes con BatchNorm

Error 1: No llamar model.eval() en inference

Este es el bug más frecuente. En training, BatchNorm usa estadísticas del batch actual. Si haces inference sin model.eval(), la red usa estadísticas del último batch — que puede ser cualquier cosa. El resultado: predicciones diferentes cada vez que corres el modelo.

# ❌ MAL: inference sin eval mode
model.train()  # Esto está mal para inference
predictions = model(data)

# ✅ BIEN: inference con eval mode
model.eval()
with torch.no_grad():
    predictions = model(data)

Error 2: Batch size de 1-2 en training

Cuando el batch size es 1, la varianza es cero (o cercana), y dividir por cero es undefined. Con batch size 2, las estadísticas son extremadamente ruidosas. Los running stats acumulados se contaminan con este ruido y nunca convergen bien.

# ❌ MAL: batch size de 1 o 2
dataloader = DataLoader(dataset, batch_size=1)  # NO HACER ESTO con BatchNorm
dataloader = DataLoader(dataset, batch_size=2)  # También problemático

# ✅ BIEN: batch size mínimo de 16-32 para BatchNorm
dataloader = DataLoader(dataset, batch_size=32)

# Alternativa si tienes GPU limitada: usa LayerNorm o GroupNorm
# que no dependen del batch size
model = nn.Sequential(
    nn.Conv2d(3, 64, 3, padding=1),
    nn.GroupNorm(8, 64),  # Divide channels en grupos, no depende del batch
    nn.ReLU()
)

Error 3: Usar BatchNorm en modelos autoregressive (RNNs, Transformers con padding variable)

En modelos autoregressive, la longitud de secuencia varía entre batches. BatchNorm asume que las estadísticas son comparables entre samples. Además, en inference con padding, el padding contribuye a las estadísticas y las corrompe.

# ❌ MAL: BatchNorm en RNNs
class BadRNNModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.rnn = nn.RNN(256, 512, batch_first=True)
        self.bn = nn.BatchNorm1d(512)  # NO: RNN produce secuencias de longitud variable

    def forward(self, x):
        out, _ = self.rnn(x)
        # out: (batch, seq, 512) — BatchNorm1d no maneja esto bien
        return self.bn(out)  # Problemas con padding y seq length variable

# ✅ BIEN: LayerNorm para secuencias
class GoodRNNModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.rnn = nn.RNN(256, 512, batch_first=True)
        self.ln = nn.LayerNorm(512)  # Normaliza sobre features, no sobre batch

    def forward(self, x):
        out, _ = self.rnn(x)
        # LayerNorm normaliza sobre (seq, features) por cada sample independently
        return self.ln(out)

📊 Cuándo Usar Qué Normalization

  • BatchNorm: CNNs, cuando tienes batch size >= 16, datasets de imágenes.
  • LayerNorm: Transformers, RNNs, cuando el batch es pequeño o variable.
  • InstanceNorm: Style transfer, generación de imágenes — normaliza cada sample/channel independently.
  • GroupNorm: Cuando tienes batch size pequeño (1-8) y necesitas algo similar a BatchNorm.
  • SyncBatchNorm: Cuando entrenas con múltiples GPUs y necesitas sincronizar stats.

✅ Resumen y Cierre

BatchNorm es poderosa pero tiene requisitos claros: batch size suficiente, training/inference bien separados, y no en cualquier arquitectura. Los tres errores de arriba cubren el 75% de los problemas que veo cuando alguien me pregunta por qué su modelo se comporta diferente en producción.

La clave: durante entrenamiento usa stats del batch actual y actualiza running stats. Durante inference SOLO usa running stats — y para eso necesitas model.eval(). Si tienes GPUs con batch size pequeño, mira GroupNorm o LayerNorm en su lugar.
