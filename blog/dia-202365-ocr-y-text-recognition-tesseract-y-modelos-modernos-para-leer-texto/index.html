Por Que OCR Es Dificil?

El reconocimiento optico de caracteres parece simple — leer texto de una imagen — pero es increiblemente dificil en la practica. La variabilidad es enorme:

  • Fuentes: Miles de fuentes diferentes, algunas ilegibles
  • Contexto: Texto en escenas naturales, documentos escaneados, fotos borrosas
  • Condiciones: Iluminacion variable, ruido, distorsion
  • Layout: Multiples columnas, tablas, texto mixto

Tesseract usa pipelines clasicos con binarizacion, deteccion de lineas, reconocimiento de caracteres. Funciona bien para documentos limpios, pero falla en escenas complejas. Los modelos modernos basados en deep learning superan esto significativamente.

La matematica de CTC (Connectionist Temporal Classification):

CTC resuelve el problema de alinear secuencias de longitud variable sin necesidad de labels alineadas a nivel de caracter:

$$\text{CTC Loss} = -\ln \prod_{t=1}^{T} \frac{\exp(y_{\pi_t}^{t})}{\sum_{\pi'} \exp(y_{\pi'}^{t})}$$

CTC introduce un token "blank" (blanco) para manejar repeticiones y permite que la red aprenda alignments automaticamente. La funcion de forward-backward de CTC:

$$\alpha_{t}(s) = \text{probabilidad de estar en estado } s \text{ al tiempo } t$$

$$\beta_{t}(s) = \text{probabilidad de completar la secuencia desde estado } s \text{ al tiempo } t$$

CRNN desde Cero con PyTorch

CRNN (Convolutional Recurrent Neural Network) combina lo mejor de CNNs y RNNs para sequence recognition:

  • CNN: Extrae features visuales de la imagen
  • Map-to-Sequence: Convierte feature maps a secuencias
  • BiLSTM: Modela contexto bidireccional
  • CTC: Decodifica sin necesidad de labels alineadas
import torch
import torch.nn as nn

class CRNN(nn.Module):
    """
    CRNN para reconocimiento de texto
    Arquitectura: CNN (ResNet) -> Map-to-Sequence -> BiLSTM -> Linear
    """
    def __init__(self, img_height=32, num_classes=37):  # 26 letras + 10 digitos + blank
        super().__init__()
        self.img_height = img_height
        
        # CNN Feature Extractor (usando ResNet18 como backbone)
        from torchvision.models import resnet18
        backbone = resnet18(weights=None)
        
        # Remover las capas fully connected y avgpool
        self.cnn = nn.Sequential(
            backbone.conv1,
            backbone.bn1,
            backbone.relu,
            backbone.maxpool,  # /4
            backbone.layer1,
            backbone.layer2,   # /8
            backbone.layer3,   # /16
        )
        
        # Output: (batch, 256, H, W) donde H = img_height/16
        
        # Map-to-Sequence: convierte feature maps a secuencia
        # Elimina la dimension espacial altura, mantiene ancho
        self.map_to_seq = nn.Sequential(
            nn.Linear(256, 256),
            nn.BatchNorm1d(256),
            nn.ReLU(inplace=True)
        )
        
        # BiLSTM para context modeling
        self.rnn1 = nn.LSTM(256, 256, bidirectional=True, batch_first=True)
        self.rnn2 = nn.LSTM(512, 256, bidirectional=True, batch_first=True)
        
        # Output: logits para CTC
        self.fc = nn.Linear(512, num_classes)
        
        self.num_classes = num_classes
    
    def forward(self, x):
        # x: (batch, channels, height, width)
        batch_size = x.size(0)
        
        # CNN feature extraction
        conv_features = self.cnn(x)  # (batch, 256, H', W')
        H = conv_features.size(2)
        W = conv_features.size(3)
        
        # Map to sequence: (batch, W, H*C) -> (batch, W, 256)
        # Tomamos cada columna de la imagen como un timestep
        features = conv_features.permute(0, 3, 1, 2)  # (batch, W, 256, H)
        features = features.reshape(batch_size, W, 256 * H)
        features = self.map_to_seq(features)  # (batch, W, 256)
        
        # BiLSTM
        lstm_out, _ = self.rnn1(features)  # (batch, W, 512)
        lstm_out, _ = self.rnn2(lstm_out)  # (batch, W, 512)
        
        # FC para cada timestep
        output = self.fc(lstm_out)  # (batch, W, num_classes)
        
        # Log softmax para CTC
        output = torch.log_softmax(output, dim=-1)
        
        return output  # Shape: (batch, W, num_classes)

# CTC Loss
ctc_loss = nn.CTCLoss(blank=0, reduction='mean', zero_infinity=True)

def decode_predictions(outputs, blank=0):
    """
    Decodificar predicciones CTC
    Greedy decode: tomar el caracter con mayor probabilidad en cada timestep
    """
    # outputs: (T, batch, num_classes)
    outputs = outputs.permute(1, 0, 2)  # (batch, T, num_classes)
    
    batch_decoded = []
    for batch_idx in range(outputs.size(0)):
        # Obtener predictions para esta muestra
        pred = outputs[batch_idx]  # (T, num_classes)
        
        # Greedy: argmax por timestep
        pred_indices = pred.argmax(dim=-1)  # (T,)
        
        # Eliminar repeticiones y blanks
        decoded = []
        prev_token = None
        for idx in pred_indices.tolist():
            if idx != blank and idx != prev_token:
                decoded.append(idx)
            prev_token = idx
        
        batch_decoded.append(decoded)
    
    return batch_decoded

Preprocesamiento para OCR

El preprocesamiento es crucial para OCR. Imagenes mal preprocessadas arruinan incluso los mejores modelos. Nunca metas una imagen cruda a OCR sin procesarla primero.

import cv2
import numpy as np
from PIL import Image

def preprocess_for_ocr(image_path, output_size=(200, 32)):
    """
    Preprocesamiento completo para OCR
    """
    # Cargar imagen
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    
    # 1. Binarizacion adaptativa
    # Otsu's thresholding automatico
    _, binary = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    
    # O binarizacion adaptativa para iluminacion variable
    binary_adaptive = cv2.adaptiveThreshold(
        img, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
        cv2.THRESH_BINARY, 11, 2
    )
    
    # 2. Deskew (corregir inclinacion)
    coords = np.column_stack(np.where(binary > 0))
    angle = cv2.minAreaRect(coords)[-1]
    
    if angle < -45:
        angle = -(90 + angle)
    else:
        angle = -angle
    
    if abs(angle) > 0.5:  # Solo corregir si esta suficientemente inclinada
        (h, w) = binary.shape[:2]
        center = (w // 2, h // 2)
        M = cv2.getRotationMatrix2D(center, angle, 1.0)
        binary = cv2.warpAffine(binary, M, (w, h), 
                                 flags=cv2.INTER_CUBIC,
                                 borderValue=255)
    
    # 3. Remover ruido
    denoised = cv2.fastNlMeansDenoising(binary, None, 10, 7, 21)
    
    # 4. Resize a tamano fijo (importante para CRNN)
    resized = cv2.resize(denoised, (output_size[0], output_size[1]), 
                         interpolation=cv2.INTER_LINEAR)
    
    # 5. Normalizar
    normalized = resized.astype('float32') / 255.0
    
    return normalized, binary

def is_image_clear(image_path, threshold=0.7):
    """
    Verificar si una imagen es lo suficientemente clara para OCR
    """
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    
    # Calcular varianza de Laplacian (medida de nitidez)
    laplacian_var = cv2.Laplacian(img, cv2.CV_64F).var()
    
    if laplacian_var < 100:
        print(f"Imagen borrosa (varianza Laplacian: {laplacian_var:.2f})")
        return False
    
    return True

# Mejorar imagenes oscuras
def improve_dark_image(image):
    # Aumentar brillo
    img_float = image.astype(np.float32)
    enhanced = np.clip(img_float * 1.5, 0, 255).astype(np.uint8)
    
    # Ecualizacion de histograma CLAHE
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    enhanced = clahe.apply(enhanced)
    
    return enhanced

Entrenar OCR para Dominio Especifico

Para texto especializado (recibo, matricula, documento), necesitas entrenar tu propio modelo. Esto requiere datos y paciencia, pero los resultados valen la pena.

import torch
from torch.utils.data import Dataset, DataLoader
import os
from PIL import Image
import numpy as np

class OCRDataset(Dataset):
    """Dataset para OCR con imagenes y labels de texto"""
    def __init__(self, root_dir, chars='abcdefghijklmnopqrstuvwxyz0123456789'):
        self.root_dir = root_dir
        self.chars = chars
        self.char_to_idx = {c: i+1 for i, c in enumerate(chars)}
        self.char_to_idx[''] = 0
        self.idx_to_char = {v: k for k, v in self.char_to_idx.items()}
        self.num_classes = len(self.char_to_idx)
        
        # Asumiendo estructura: root_dir/{image_name}.jpg, labels.txt
        with open(os.path.join(root_dir, 'labels.txt'), 'r') as f:
            self.samples = [line.strip().split(',') for line in f.readlines()]
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        img_name, label = self.samples[idx]
        img_path = os.path.join(self.root_dir, img_name)
        
        # Cargar y preprocess imagen
        img = Image.open(img_path).convert('L')  # Escala de grises
        img = img.resize((128, 32))  # Ancho fijo, alto fijo
        img = np.array(img, dtype=np.float32) / 255.0
        
        # Convertir a tensor (1, H, W)
        img = torch.from_numpy(img).unsqueeze(0)
        
        # Convertir label a indices
        target = torch.tensor([self.char_to_idx.get(c, 0) for c in label.lower()])
        
        return img, target

def collate_fn(batch):
    """Custom collate para manejar secuencias de longitud variable"""
    images, targets = zip(*batch)
    
    # Stack images
    images = torch.stack(images)  # (batch, 1, H, W)
    
    # Concatenar targets y calcular longitudes
    target_lengths = torch.tensor([len(t) for t in targets])
    targets_concat = torch.cat(targets)
    
    return images, targets_concat, target_lengths

Errores Comunes en OCR

Error 1: Usar Tesseract para Todo

El problema: Tesseract funciona bien para documentos limpios y escaneados, pero falla miserablemente en escenas naturales, fotos borrosas, y texto con fuentes unusual. Si usas Tesseract para todo, vas a obtener resultados malos en casos que no son documentos ideales.

La solucion: Evalua tu caso de uso. Para documentos limpios, Tesseract esta bien. Para escenas complejas, usa easyOCR, paddleOCR, o tu propio CRNN entrenado.

# MAL: usar Tesseract para todo
import pytesseract
text = pytesseract.image_to_string(image)  # Falla en escenas complejas

# BIEN: elegir segun el caso de uso
if is_document_clean(image):
    text = pytesseract.image_to_string(image)
else:
    reader = easyocr.Reader(['es', 'en'])
    results = reader.readtext(image)
    text = ' '.join([r[1] for r in results])

La solucion: Preprocesa siempre. Binarizacion, deskew, denoising son fundamentales.

Error 3: OCR Sin Post-Processing

El problema: Asumir que la salida de OCR es correcta. Errores comunes: caracteres mal reconocidos, "l" vs "1", "O" vs "0", faltantes por margenes de confianza.

La solucion: Post-processing sistematico. Diccionario, validacion de formato, correccion basada en contexto.

import re

def post_process_ocr(text, expected_format=None):
    """
    Post-processing para corregir errores comunes de OCR
    """
    # Limpiar espacios excesivos
    text = ' '.join(text.split())
    
    # Correcciones comunes de OCR
    replacements = {
        'l': 'I',  # veces 'rn' -> 'm'
        'rn': 'm',
        'vv': 'w',
        '|': 'I',
        '0': 'O',  # en contexto de letras
    }
    
    # Si sabemos el formato esperado, validar
    if expected_format == 'date':
        # Buscar fechas dd/mm/yyyy o similar
        match = re.search(r'\d{1,2}[/\-]\d{1,2}[/\-]\d{2,4}', text)
        if match:
            return match.group()
    
    elif expected_format == 'phone':
        # Solo digitos y algunos caracteres
        digits = re.sub(r'[^\d\+]', '', text)
        if len(digits) >= 7:
            return digits

        if match:
            return match.group()

Resumen y Cierre

Hoy cubrimos los fundamentos de OCR y Text Recognition:

  • CTC Loss permite entrenar modelos de secuencia sin alignment manual
  • CRNN combina CNN + BiLSTM para reconocimiento robusto
  • easyOCR es rapido para prototipos y casos generales
  • Preprocesamiento (binarizacion, deskew, denoising) es critico para buena accuracy
  • Post-processing corrige errores comunes y valida formatos

Desde los dias de Tesseract como el unico motor de OCR disponible hasta los modelos modernos como CRNN con CTC que aprenden de datos, el campo ha avanzado enormemente. Hoy podes entrenar un modelo que supera a Tesseract en tu dominio especifico con relativamente pocos datos. La clave esta en preprocesar bien las imagenes y hacer post-processing riguroso.
