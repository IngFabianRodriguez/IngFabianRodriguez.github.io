Por Que Deep Learning para Vision?

Las redes neuronales convolucionales (CNN) revolucionaron la vision por computador. A diferencia de los metodos tradicionales donde uno disenaba features a mano (SIFT, HOG), las CNNs aprenden features automaticamente de los datos. Esto significa que con suficiente datos y computo, podes superar cualquier sistema clasico.

La matematica detras es elegante. Una convolucion 2D aplica un kernel (filtro) sobre la imagen:

$$(I * K)_{i,j} = \sum_{m}\sum_{n} I_{i+m,j+n} \cdot K_{m,n}$$

donde $I$ es la imagen y $K$ es el kernel. Durante el entrenamiento, estos kernels aprenden a detectar bordes, texturas, y eventualmente objetos completos.

Arquitecturas clave:

  • Classification: ResNet, VGG, EfficientNet
  • Detection: YOLO, Faster R-CNN, SSD
  • Segmentation: U-Net, Mask R-CNN, DeepLabV3

CNN para Clasificacion con PyTorch

Empecemos con algo clasico: una CNN para clasificacion de imagenes. Vamos a construir una red desde cero y despues usar transfer learning.

import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    """CNN basica para clasificacion de imagenes"""
    def __init__(self, num_classes=10):
        super().__init__()
        # Capas convolucionales
        self.conv1 = nn.Conv2d(3, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        
        # Pooling y batch norm
        self.pool = nn.MaxPool2d(2, 2)
        self.bn1 = nn.BatchNorm2d(32)
        self.bn2 = nn.BatchNorm2d(64)
        self.bn3 = nn.BatchNorm2d(128)
        
        # Capas fully connected
        self.fc1 = nn.Linear(128 * 4 * 4, 256)
        self.fc2 = nn.Linear(256, num_classes)
        
        self.dropout = nn.Dropout(0.5)
    
    def forward(self, x):
        # Conv block 1: 3x32x32 -> 32x16x16
        x = self.pool(F.relu(self.bn1(self.conv1(x))))
        # Conv block 2: 32x16x16 -> 64x8x8
        x = self.pool(F.relu(self.bn2(self.conv2(x))))
        # Conv block 3: 64x8x8 -> 128x4x4
        x = self.pool(F.relu(self.bn3(self.conv3(x))))
        
        x = x.view(x.size(0), -1)
        x = self.dropout(F.relu(self.fc1(x)))
        x = self.fc2(x)
        return x

# Uso:
model = SimpleCNN(num_classes=10)
x = torch.randn(1, 3, 32, 32)
print(model(x).shape)  # torch.Size([1, 10])

La matematica del batch normalization:

$$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}$$

$$y = \gamma \hat{x} + \beta$$

donde $\mu$ y $\sigma$ son la media y desviacion estandar del batch, y $\gamma, \beta$ son parametros aprendibles.

U-Net para Segmentacion

La segmentacion semantica divide la imagen en regiones por clase. U-Net es la arquitectura dominante para esto, especialmente en imagenes medicas.

class UNet(nn.Module):
    """U-Net para segmentacion semantica"""
    def __init__(self, in_channels=3, out_channels=1):
        super().__init__()
        
        # Encoder (downsampling)
        self.enc1 = self._block(in_channels, 64)
        self.enc2 = self._block(64, 128)
        self.enc3 = self._block(128, 256)
        self.enc4 = self._block(256, 512)
        
        self.pool = nn.MaxPool2d(2)
        
        # Bottleneck
        self.bottleneck = self._block(512, 1024)
        
        # Decoder (upsampling)
        self.up4 = nn.ConvTranspose2d(1024, 512, 2, stride=2)
        self.dec4 = self._block(1024, 512)
        self.up3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = self._block(512, 256)
        self.up2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = self._block(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = self._block(128, 64)
        
        # Output
        self.out = nn.Conv2d(64, out_channels, 1)
    
    def _block(self, in_ch, out_ch):
        return nn.Sequential(
            nn.Conv2d(in_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, 3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True)
        )
    
    def forward(self, x):
        # Encoder
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))
        
        # Bottleneck
        b = self.bottleneck(self.pool(e4))
        
        # Decoder con skip connections
        d4 = self.up4(b)
        d4 = torch.cat([d4, e4], dim=1)
        d4 = self.dec4(d4)
        
        d3 = self.up3(d4)
        d3 = torch.cat([d3, e3], dim=1)
        d3 = self.dec3(d3)
        
        d2 = self.up2(d3)
        d2 = torch.cat([d2, e2], dim=1)
        d2 = self.dec2(d2)
        
        d1 = self.up1(d2)
        d1 = torch.cat([d1, e1], dim=1)
        d1 = self.dec1(d1)
        
        return torch.sigmoid(self.out(d1))

# Perdida Dice para segmentacion
class DiceLoss(nn.Module):
    def __init__(self, smooth=1e-6):
        super().__init__()
        self.smooth = smooth
    
    def forward(self, pred, target):
        pred = torch.sigmoid(pred)
        pred = pred.view(-1)
        target = target.view(-1)
        
        intersection = (pred * target).sum()
        dice = (2. * intersection + self.smooth) / (
            pred.sum() + target.sum() + self.smooth
        )
        return 1 - dice

# Uso:
model = UNet(in_channels=3, out_channels=1)
x = torch.randn(1, 3, 256, 256)
mask = torch.randn(1, 1, 256, 256)
output = model(x)
print(f"Output shape: {output.shape}")  # torch.Size([1, 1, 256, 256])

La skip connection en U-Net concatena features del encoder al decoder, preservando informacion espacial que se perderia con solo upsampling.

Deteccion de Objetos con torchvision

Para deteccion de objetos, torchvision tiene modelos pre-entrenados increibles. No reinventes la rueda — usa transfer learning.

import torchvision
from torchvision.models.detection import fasterrcnn_resnet50_fpn, FasterRCNN_ResNet50_FPN_Weights
from torchvision.models.detection import yolov5s, YOLOv5s_Weights
import torch

# Faster R-CNN con backbone ResNet50-FPN
model = fasterrcnn_resnet50_fpn(weights=FasterRCNN_ResNet50_FPN_Weights.DEFAULT)

# Preparar imagen para el modelo
from torchvision.transforms import functional as F

def detect_objects(image_path, confidence_threshold=0.5):
    """Deteccion de objetos con Faster R-CNN"""
    # Cargar y preprocesar imagen
    img = Image.open(image_path).convert("RGB")
    img_tensor = F.to_tensor(img)
    
    # Normalizar con media y std de ImageNet
    img_normalized = F.normalize(img_tensor, 
                                 mean=[0.485, 0.456, 0.406],
                                 std=[0.229, 0.224, 0.225])
    
    # Inference
    model.eval()
    with torch.no_grad():
        predictions = model([img_normalized])
    
    # Filtrar por confianza
    pred = predictions[0]
    keep = pred['scores'] > confidence_threshold
    
    return {
        'boxes': pred['boxes'][keep],
        'labels': pred['labels'][keep],
        'scores': pred['scores'][keep]
    }

# YOLO con torchvision (disponible desde torchvision 0.15)
# Descargar y usar modelo pre-entrenado
model_yolo = yolov5s(weights=YOLOv5s_Weights.DEFAULT)
model_yolo.eval()

# Inference
results = model_yolo(img_tensor.unsqueeze(0))
# results.pred contiene las detecciones
print(results.pandas().xyxy[0])  # DataFrame con bounding boxes

Non-Maximum Suppression (NMS) es crucial para filtrar detecciones redundantes:

$$b_{i} \text{ eliminada si } \exists b_{j} : \text{IoU}(b_{i}, b_{j}) > t \text{ y } \text{conf}(b_{i}) < \text{conf}(b_{j})$$

donde IoU (Intersection over Union) mide la superposicion entre bounding boxes.

Transfer Learning: El Atajo al Exito

No empezas de cero. Los modelos pre-entrenados en ImageNet (1.2M imagenes, 1000 clases) capturan features visuales generales. Fine-tunear estos modelos es mas rapido y requiere menos datos.

import torchvision.models as models

# Cargar modelo pre-entrenado
model = models.resnet50(weights=models.ResNet50_Weights.DEFAULT)

# Congelar capas (opcional - primero entrenar solo la cabeza)
for param in model.parameters():
    param.requires_grad = False

# Reemplazar la capa final
num_features = model.fc.in_features
model.fc = nn.Linear(num_features, 10)  # 10 clases propias

# Descongelar gradualmente si es necesario
# O usar discriminative learning rates
optimizer = torch.optim.Adam([
    {'params': model.conv1.parameters(), 'lr': 1e-5},
    {'params': model.fc.parameters(), 'lr': 1e-3}
], lr=1e-4)

Errores Comunes en Computer Vision

Error 1: No Usar Transfer Learning

El problema: Entrenar una CNN desde cero requiere millones de imagenes etiquetadas y dias de computo. En la mayoria de casos, no tenes esos recursos.

La solucion: Usa modelos pre-entrenados y hace fine-tuning. Solo descongela las ultimas capas primero, entrena, y si es necesario descongela mas capas gradualmente.

# Mal: entrenar desde cero
model = SimpleCNN(num_classes=100)  # Requiere MUCHOS datos

# Bien: transfer learning
model = models.resnet50(weights=models.ResNet50_Weights.DEFAULT)
model.fc = nn.Linear(model.fc.in_features, 100)
# Fine-tune solo la ultima capa primero

Error 2: Data Augmentation Inapropiada

El problema: Aplicar augmentation que cambia las labels. Por ejemplo, voltear horizontalmente un "6" y un "9" si tu modelo distingue digitos.

La solucion: Entede tu dataset y que augmentations son seguras.

# MAL: augmentation que cambia labels
transform = T.Compose([
    T.RandomHorizontalFlip(p=0.5),  # Puede cambiar "b" por "d", "6" por "9"
    T.RandomRotation(30),  # Puede confundir digitos
])

# BIEN: augmentation que preserva labels
transform = T.Compose([
    T.RandomHorizontalFlip(p=0.0),  # No voltear si hay texto/digitos
    T.ColorJitter(brightness=0.2, contrast=0.2),  # Seguro
    T.RandomAffine(degrees=5, translate=(0.1, 0.1)),  # Transformacion suave
    T.GaussianBlur(kernel_size=3, sigma=(0.1, 2.0)),  # Seguro
])

# Para segmentacion: solo aplicar misma transformacion a imagen y mascara
class SegmentationTransform:
    def __call__(self, img, mask):
        # Misma transformacion para ambos
        if torch.rand(1) > 0.5:
            img = T.functional.hflip(img)
            mask = T.functional.hflip(mask)
        return img, mask

Error 3: No Normalizar con Stats de ImageNet

El problema: Cada modelo pre-entrenado fue entrenado con datos normalizados de cierta manera. Si no usas los mismos stats, las activaciones seran incorrectas y el modelo no funcionara bien.

La solucion: Siempre normaliza con media y std de ImageNet para modelos pre-entrenados.

# Stats de ImageNet (los que usa torchvision por defecto)
IMAGENET_MEAN = [0.485, 0.456, 0.406]
IMAGENET_STD = [0.229, 0.224, 0.225]

# MAL: no normalizar o usar valores random
transform = T.Compose([
    T.ToTensor(),
    # Olvidaste normalizar
])

# MAL: normalizar con valores incorrectos
transform = T.Compose([
    T.ToTensor(),
    T.Normalize(mean=[0.5, 0.5, 0.5], std=[0.5, 0.5, 0.5]),  # Wrong!
])

# BIEN: normalizar con stats de ImageNet
transform = T.Compose([
    T.ToTensor(),
    T.Normalize(mean=IMAGENET_MEAN, std=IMAGENET_STD),
])

# Si entrenas desde cero y no usas pre-entrenados, calcula tus propios stats:
def compute_dataset_stats(dataset):
    loader = DataLoader(dataset, batch_size=32, num_workers=4)
    mean = torch.zeros(3)
    std = torch.zeros(3)
    for images, _ in loader:
        mean += images.mean([0, 2, 3])
        std += images.std([0, 2, 3])
    mean /= len(loader)
    std /= len(loader)
    return mean, std

Resumen y Cierre

Hoy cubrimos los fundamentos de Computer Vision con Deep Learning:

  • CNNs extraccionan features jerarquicos de imagenes
  • U-Net es ideal para segmentacion semantica con sus skip connections
  • Faster R-CNN y YOLO dominan la deteccion de objetos
  • Transfer learning es esencial: nunca empeces de cero si puedes evitarlo
  • Data augmentation debe preservar labels para ser util
  • Normalizacion con stats de ImageNet es critica para modelos pre-entrenados

Desde los filtros convolucionales basicos hasta arquitecturas complejas como Mask R-CNN que combinan clasificacion, deteccion y segmentacion en una sola pasada, el campo ha avanzado enormemente. La proxima vez que veas un carro autonomo detectando peatones o un sistema de diagnostico medico identificando tumores en imagenes, sabes que todo eso se construye sobre los cimientos que cubrimos hoy.
