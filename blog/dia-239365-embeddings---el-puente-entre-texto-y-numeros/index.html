Embeddings - El Puente Entre Texto y Numeros

Hagale pues, parcero. Dia 239 y hoy hablamos de embeddings, el puente entre texto y numeros que hace posible la busqueda semantica. Cafe.

Embeddings

Los embeddings son representaciones vectoriales de texto que capturan significado semantico. Palabras o frases similares tendran vectores similares en el espacio vectorial.

Propiedades:

  • Dimensionalidad: 384 a 3072 dimensiones tipicamente
  • Similitud: Vectores cercanos = significado similar
  • Direccion: La direccion importa para relaciones semanticas

Crear Embeddings

from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

# Crear embedding para un texto
vector = model.encode("Que es machine learning?")
print(f"Dimensiones: {vector.shape}")  # (384,)

# Similitud entre textos
query = model.encode("Inteligencia artificial")
doc1 = model.encode("AI y sus aplicaciones")
doc2 = model.encode("Cocina italiana")

from sklearn.metrics.pairwise import cosine_similarity
print(cosine_similarity([query], [doc1])[0][0])  # Alto
print(cosine_similarity([query], [doc2])[0][0])  # Bajo

Errores Comunes

Error 1: Usar Embeddings Para Todo

El problema: Algunos tareas no necesitan embeddings.

La solucion: Usa BM25 o keyword search para busqueda lexica.
