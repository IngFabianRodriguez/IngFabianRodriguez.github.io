SAEs - Sparse Autoencoders Para Features

Hagale pues, parcero. Hoy es el Dia 332 y hablamos de SAEs, Sparse Autoencoders para features. Cafe.

🎯 Sparse Autoencoders

SAEs aprenden a descomponer activaciones de LLM en features interpretables. El decoder define que es cada feature.

Arquitectura:

  • Encoder: Linear + ReLU, mapea a feature space
  • Feature space: Miles de features, mayor que d_model
  • Decoder: Linear, reconstruye activacion original
  • Sparsity: Pocas features activas por input

📐 SAE Training

class SAE(nn.Module):
    def __init__(self, d_model, n_features=4096):
        super().__init__()
        self.encode = nn.Linear(d_model, n_features, bias=True)
        self.decode = nn.Linear(n_features, d_model, bias=False)
    
    def forward(self, x):
        h = F.relu(self.encode(x))  # Sparse activations
        recon = self.decode(h)
        
        # L1 para sparsity
        l1 = h.abs().sum() / h.shape[0]
        loss = F.mse_loss(recon, x) + l1 * 0.001
        
        return loss, recon, h
