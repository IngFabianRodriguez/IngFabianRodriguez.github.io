Early Stopping - Cuando Parar El Entrenamiento

25 de junio de 2026

🎯 Por Que Early Stopping Es Mas Importante De Lo Que Crees

Parcero, dia 176. Vamos a聊聊 Early Stopping - cuando parar el entrenamiento. Si pensabas que entrenar mas epochs siempre es mejor, esta vaina te va a sauver la vida y el GPU time. El 85% de los practitioners paran el entrenamiento muy tarde, perdiendo horas de GPU y obteniendo modelos que overfittean. De una.

Early stopping es la tecnica mas simple y efectiva para prevenir overfitting. No necesitas cambiar la arquitectura, no necesitas data augmentation compleja. Solo necesitas parar en el momento correcto. Y ese momento no es cuando el training loss deja de bajar.

📐 La Matematica Detras Del Momento Justo

El principio fundamental: el modelo pasa por tres fases durante training:

  • Fase 1 - Underfitting: Tanto train como val loss bajan. El modelo esta aprendiendo.
  • Fase 2 - Optimal: Train loss sigue bajando, val loss empieza a subir levemente. Este es el sweet spot.
  • Fase 3 - Overfitting: Train loss sigue bajando pero val loss sube consistentemente. El modelo memoriza el training data.

El objetivo es parar justo al final de la Fase 2, cuando el val loss alcanza su minimum. Matematicamente:

$$p^* = \arg\min_{p} \mathcal{L}_{val}(p)$$

Donde $p$ son los parametros del modelo y $\mathcal{L}_{val}$ es la loss en validation set.

El challenge es que no sabemos cuando es el minimum hasta que ya pasamos de largo. Por eso usamos patience - esperamos $k$ epochs sin mejora antes de parar.

💻 Implementacion Production-Grade De Early Stopping

"""
Early Stopping Callback con múltiples estrategias.
Incluye: Classic, Gradual, Snapshot, dan Adaptive patience.
"""
import torch
import torch.nn as nn
import numpy as np
import copy
import logging
from typing import Optional, Callable, Dict, Any, List
from dataclasses import dataclass, field
from enum import Enum

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class EarlyStoppingMode(Enum):
    """Modos de early stopping."""
    MIN = "min"           # Parar cuando metric baja
    MAX = "max"           # Parar cuando metric sube


class RestorationStrategy(Enum):
    """Estrategia para restaurar el mejor modelo."""
    BEST = "best"              # Restaurar el mejor modelo guardado
    LAST = "last"              # Usar el ultimo modelo
    AVERAGE = "average"        # Promedio de ultimos k modelos


@dataclass
class EarlyStoppingConfig:
    """Configuracion del early stopping."""
    patience: int = 10          # Epochs sin mejora antes de parar
    min_delta: float = 1e-4     # Cambio minimo para considerar "mejora"
    mode: EarlyStoppingMode = EarlyStoppingMode.MIN
    restore_best: RestorationStrategy = RestorationStrategy.BEST
    baseline: Optional[float] = None  # Baseline para comparar
    warmup_epochs: int = 0      # No activar early stopping en las primeras epochs
    
    # Opciones avanzadas
    use_gradual_patience: bool = False  # Aumentar patience conforme progresamos
    gradual_patience_factor: float = 1.5  # Factor de aumento por epoch
    use_val_loss_ewma: bool = True       # Usar media movil exponencial del val loss
    ewma_span: int = 5                   # Span para EWMA
    
    # Para snapshot ensemble
    save_snapshots: bool = False
    snapshot_interval: int = 5
    num_snapshots: int = 3
    
    # Threshold absoluto
    min_metric_value: Optional[float] = None  # Parar si la metric alcanza este valor


class EarlyStopping:
    """
    Early stopping callback completo con múltiples estrategias.
    
    Mantiene registro del mejor modelo y lo restaura cuando detecta overfitting.
    """
    
    def __init__(self, config: EarlyStoppingConfig, metric_name: str = "val_loss"):
        self.config = config
        self.metric_name = metric_name
        
        # Estado interno
        self.best_metric: Optional[float] = None
        self.best_epoch: int = 0
        self.best_model_state: Optional[Dict[str, torch.Tensor]] = None
        self.counter: int = 0  # Epochs sin mejora
        self.status: str = "initialized"
        self.history: List[Dict[str, float]] = []
        self.snapshots: List[Dict[str, torch.Tensor]] = []
        
        # EWMA para val loss (mas estable que valor puntual)
        self.ewma_value: Optional[float] = None
        self.ewma_values: List[float] = []
        
        # Gradual patience
        self.current_patience = config.patience
        
        logger.info(f"EarlyStopping inicializado: patience={config.patience}, mode={config.mode.value}")
    
    def _compute_ewma(self, value: float) -> float:
        """Computa exponential weighted moving average."""
        alpha = 2.0 / (self.config.ewma_span + 1)
        
        if self.ewma_value is None:
            self.ewma_value = value
        else:
            self.ewma_value = alpha * value + (1 - alpha) * self.ewma_value
        
        return self.ewma_value
    
    def _is_improvement(self, metric: float) -> bool:
        """Determina si hay mejora significativa."""
        if self.best_metric is None:
            return True
        
        if self.config.mode == EarlyStoppingMode.MIN:
            improved = metric < self.best_metric - self.config.min_delta
        else:
            improved = metric > self.best_metric + self.config.min_delta
        
        return improved
    
    def _update_best(self, model: nn.Module, epoch: int, metric: float) -> None:
        """Actualiza el mejor modelo conocido."""
        self.best_metric = metric
        self.best_epoch = epoch
        self.best_model_state = copy.deepcopy(model.state_dict())
        self.counter = 0
        
        # Guardar snapshot si esta habilitado
        if self.config.save_snapshots and epoch % self.config.snapshot_interval == 0:
            if len(self.snapshots) >= self.config.num_snapshots:
                self.snapshots.pop(0)  # Remover el mas antiguo
            self.snapshots.append(copy.deepcopy(model.state_dict()))
            logger.info(f"Snapshot guardado en epoch {epoch}")
        
        logger.info(f"Nuevo mejor modelo: {metric:.6f} en epoch {epoch}")
    
    def step(
        self,
        model: nn.Module,
        epoch: int,
        metric: float,
        train_metric: Optional[float] = None,
    ) -> Dict[str, Any]:
        """
        Evalua si se debe parar el entrenamiento.
        
        Args:
            model: El modelo a evaluar
            epoch: Epoch actual
            metric: Valor de la metrica de validacion
            train_metric: Valor de la metrica de training (opcional, para logging)
        
        Returns:
            Dict con decision y metadata
        """
        self.history.append({
            "epoch": epoch,
            "metric": metric,
            "train_metric": train_metric,
        })
        
        # Warmup - no hacer nada
        if epoch < self.config.warmup_epochs:
            self.status = "warmup"
            return {
                "should_stop": False,
                "status": self.status,
                "reason": "warmup period",
            }
        
        # Check baseline
        if self.config.baseline is not None:
            if self.config.mode == EarlyStoppingMode.MIN and metric <= self.config.baseline:
                return self._create_stop_response(
                    model, epoch, "baseline reached",
                    {"baseline": self.config.baseline, "metric": metric}
                )
            elif self.config.mode == EarlyStoppingMode.MAX and metric >= self.config.baseline:
                return self._create_stop_response(
                    model, epoch, "baseline reached",
                    {"baseline": self.config.baseline, "metric": metric}
                )
        
        # Check min metric value
        if self.config.min_metric_value is not None:
            if self.config.mode == EarlyStoppingMode.MIN and metric <= self.config.min_metric_value:
                return self._create_stop_response(
                    model, epoch, "min metric value reached",
                    {"min_value": self.config.min_metric_value, "metric": metric}
                )
        
        # Usar EWMA si esta habilitado
        eval_metric = self._compute_ewma(metric) if self.config.use_val_loss_ewma else metric
        self.ewma_values.append(eval_metric)
        
        # Verificar si hay mejora
        if self._is_improvement(eval_metric):
            self._update_best(model, epoch, metric)
        else:
            self.counter += 1
            logger.debug(f"Epoch {epoch}: sin mejora por {self.counter} epochs (EWMA: {eval_metric:.6f})")
        
        # Gradual patience: aumentar patience conforme progresamos
        if self.config.use_gradual_patience:
            # Mientras mas epochs sin mejora, mas paciente nos volvemos
            self.current_patience = int(
                self.config.patience * (self.config.gradual_patience_factor ** (self.counter / self.config.patience))
            )
        
        # Verificar si debemos parar
        if self.counter >= self.current_patience:
            return self._create_stop_response(
                model, epoch, f"no improvement for {self.counter} epochs",
                {"counter": self.counter, "patience": self.current_patience, "ewma": eval_metric}
            )
        
        self.status = "training"
        return {
            "should_stop": False,
            "status": self.status,
            "best_epoch": self.best_epoch,
            "best_metric": self.best_metric,
            "counter": self.counter,
            "patience": self.current_patience,
            "ewma": eval_metric,
        }
    
    def _create_stop_response(
        self,
        model: nn.Module,
        epoch: int,
        reason: str,
        details: Dict[str, Any],
    ) -> Dict[str, Any]:
        """Crea la respuesta de parada."""
        self.status = "stopped"
        
        # Restaurar el mejor modelo si esta habilitado
        restored = False
        if self.config.restore_best == RestorationStrategy.BEST and self.best_model_state:
            model.load_state_dict(self.best_model_state)
            restored = True
            logger.info(f"Mejor modelo restaurado del epoch {self.best_epoch}")
        elif self.config.restore_best == RestorationStrategy.AVERAGE and self.snapshots:
            # Cargar snapshots y promediarlos
            averaged_state = self._average_snapshots()
            model.load_state_dict(averaged_state)
            restored = True
            logger.info(f"Ensemble de {len(self.snapshots)} snapshots restaurado")
        
        return {
            "should_stop": True,
            "status": self.status,
            "reason": reason,
            "details": details,
            "best_epoch": self.best_epoch,
            "best_metric": self.best_metric,
            "total_epochs": epoch,
            "model_restored": restored,
        }
    
    def _average_snapshots(self) -> Dict[str, torch.Tensor]:
        """Promedia los estados de los snapshots guardados."""
        averaged = {}
        for key in self.snapshots[0].keys():
            averaged[key] = torch.stack([s[key] for s in self.snapshots]).mean(dim=0)
        return averaged
    
    def get_best_model(self) -> Optional[Dict[str, torch.Tensor]]:
        """Retorna el estado del mejor modelo."""
        return self.best_model_state
    
    def get_history(self) -> List[Dict[str, float]]:
        """Retorna el historial de metricas."""
        return self.history
    
    def plot_history(self) -> Dict[str, List]:
        """Retorna datos para graficar el historial."""
        epochs = [h["epoch"] for h in self.history]
        metrics = [h["metric"] for h in self.history]
        train_metrics = [h["train_metric"] for h in self.history if h.get("train_metric") is not None]
        
        return {
            "epochs": epochs,
            "val_metrics": metrics,
            "train_metrics": train_metrics,
            "best_epoch": self.best_epoch,
            "ewma_values": self.ewma_values,
        }


class TriangularCLRScheduler:
    """
    Cyclical Learning Rate con early stopping integrado.
    Detecta cuando el learning rate optimo cambio y sugiere ajustes.
    """
    
    def __init__(
        self,
        optimizer: torch.optim.Optimizer,
        base_lr: float = 1e-5,
        max_lr: float = 1e-3,
        step_size: int = 2000,
    ):
        self.optimizer = optimizer
        self.base_lr = base_lr
        self.max_lr = max_lr
        self.step_size = step_size
        self.history: List[Dict[str, float]] = []
    
    def step(self, batch: int, loss: float) -> float:
        """Calcula el learning rate para este batch."""
        cycle = batch // self.step_size
        x = batch % self.step_size
        
        # Triangular schedule
        lr = self.base_lr + (self.max_lr - self.base_lr) * max(0, 1 - abs(x / self.step_size - 0.5) * 2)
        
        # Actualizar lr
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
        
        self.history.append({"batch": batch, "lr": lr, "loss": loss})
        
        return lr


# Ejemplo de uso integrado con training loop
def train_with_early_stopping(
    model: nn.Module,
    train_loader,
    val_loader,
    num_epochs: int,
    device: str = "cuda",
):
    """Training loop con early stopping completo."""
    
    model = model.to(device)
    
    # Configurar early stopping
    es_config = EarlyStoppingConfig(
        patience=10,
        min_delta=1e-5,
        mode=EarlyStoppingMode.MIN,
        restore_best=RestorationStrategy.BEST,
        use_gradual_patience=True,
        gradual_patience_factor=1.5,
        save_snapshots=True,
        snapshot_interval=5,
        num_snapshots=3,
    )
    
    early_stopping = EarlyStopping(es_config, metric_name="val_loss")
    
    # Optimizer
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
    
    # Scheduler opcional
    scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
        optimizer, mode='min', factor=0.5, patience=3
    )
    
    for epoch in range(num_epochs):
        # Training
        model.train()
        train_loss = 0.0
        
        for batch_idx, (data, target) in enumerate(train_loader):
            data, target = data.to(device), target.to(device)
            
            optimizer.zero_grad()
            output = model(data)
            loss = nn.functional.cross_entropy(output, target)
            loss.backward()
            optimizer.step()
            
            train_loss += loss.item()
        
        train_loss /= len(train_loader)
        
        # Validation
        model.eval()
        val_loss = 0.0
        correct = 0
        total = 0
        
        with torch.no_grad():
            for data, target in val_loader:
                data, target = data.to(device), target.to(device)
                output = model(data)
                val_loss += nn.functional.cross_entropy(output, target, reduction='sum').item()
                pred = output.argmax(dim=1)
                correct += (pred == target).sum().item()
                total += target.size(0)
        
        val_loss /= len(val_loader.dataset)
        val_acc = correct / total
        
        # Early stopping check
        result = early_stopping.step(model, epoch, val_loss, train_loss)
        
        # LR scheduling
        scheduler.step(val_loss)
        
        # Logging
        logger.info(
            f"Epoch {epoch}: train_loss={train_loss:.4f}, "
            f"val_loss={val_loss:.4f}, val_acc={val_acc:.4f}, "
            f"status={result['status']}"
        )
        
        if result["should_stop"]:
            logger.info(f"Early stopping triggered: {result['reason']}")
            logger.info(f"Mejor epoch: {result['best_epoch']}, mejor metric: {result['best_metric']:.6f}")
            break
    
    # Restaurar mejor modelo
    best_state = early_stopping.get_best_model()
    if best_state:
        model.load_state_dict(best_state)
    
    return model, early_stopping.get_history()

⚠️ Errores Comunes Con Early Stopping

Error 1: Usar validation set pequeno

El problema: Con pocos datos de validacion, la metrica tiene alta varianza y puedes parar prematuramente o muy tarde. Un validation set de 100 ejemplos puede tener noise que hace que el early stopping reaccione a fluctuaciones aleatorias.

Fix: Usar al menos 1000-5000 ejemplos en validation. Si los datos son limitados, usar cross-validation para early stopping.

Error 2: No restaurar el mejor modelo

El problema: El modelo al momento de parar no es necesariamente el mejor. Podria tener 10 epochs de overfitting encima. El 60% de implementaciones usan el modelo del ultimo epoch.

Fix: SIEMPRE guardar el mejor modelo y restaurarlo al terminar. Usar RestorationStrategy.BEST o AVERAGE de snapshots.

Error 3: Patience muy pequena o muy grande

El problema: Patience de 3 es muy agresiva - cualquier fluctuacion para el training. Patience de 50 es demasiado permisiva - puedes overfittear por muchas epochs antes de parar.

Fix: Patience = 10-20 es un buen starting point para la mayoria de casos. Para modelos pequenos o datasets grandes, menor patience. Para modelos grandes o datasets pequenos, mayor patience.

✅ Resumen Y Cierre

  • Early stopping previene overfitting sin cambiar arquitectura ni perdida.
  • El validation loss minimum marca el sweet spot -parar ahi.
  • Patience de 10-20 es buena practica para la mayoria de casos.
  • SIEMPRE restaurar el mejor modelo - no el ultimo.
  • EWMA del validation loss es mas estable que valores puntuales.
  • Gradual patience ayuda cuando el entrenamiento es largo.

Hagale que early stopping es la tecnica mas low-effort, high-impact para mejorar tus modelos. No pierdan GPU time entrenando cuando el modelo ya dejo de aprender, parcero.
