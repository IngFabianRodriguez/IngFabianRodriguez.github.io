Parcero, día 175 y hoy我们来聊聊 Tool Use y Function Calling en LLMs. Si pensabas que los LLMs solo podían generar texto, esta vaina te va a volar la cabeza. La posibilidad de que un LLM llame funciones reales — APIs, cálculos, bases de datos — convierte a estos modelos en agentes capaces de hacer cosas en el mundo real. El 80% de las apps LLM avanzadas usan function calling y la mayoría lo implementa mal. De una.

Function calling es la capacidad de un LLM para identificar cuándo necesita ejecutar una acción externa y generar los parámetros correctamente estructurados para调用 esa función. No es magia — es un fine-tuning especial que enseña al modelo a outputear JSON estructurado que matchea un schema de función definido.

🎯 Por Qué Function Calling Es Game-Changer

Sin function calling, un LLM es un chatbot muy sofisticado pero pasivo. Con function calling, se convierte en un agente activo que puede:

  • Consultar APIs reales: Weather, stocks, flights, cualquier API REST.
  • Ejecutar código: Python, SQL, cálculos matemáticos.
  • Consultar bases de datos: Extraer, insertar, actualizar datos.
  • Interactuar con servicios: Enviar emails, crear eventos, gestionar archivos.

La diferencia conceptual: sin function calling, el modelo solo puede razonar sobre información en su training data. Con function calling, puede obtener información fresh y tomar acciones en tiempo real. Eso cierra el gap entre "conocimiento" y "acción".

📐 Cómo Funciona el Function Calling

El proceso tiene 4 pasos:

1. Definir funciones disponibles

El developer define un schema de funciones en formato JSON Schema:

{
  "name": "get_weather",
  "description": "Obtiene el clima actual de una ciudad",
  "parameters": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "Nombre de la ciudad"
      },
      "unit": {
        "type": "string",
        "enum": ["celsius", "fahrenheit"],
        "description": "Unidad de temperatura"
      }
    },
    "required": ["city"]
  }
}

2. LLM decide cuándo llamar

Cuando el user pregunta algo como "¿Cómo está el clima en Bogotá?", el modelo identifica que necesita llamar get_weather y genera los argumentos correctos.

3. Backend ejecuta la función

El código del developer recibe la llamada, ejecuta la función real, retorna el resultado.

4. LLM responde con el resultado

El modelo recibe la respuesta de la función y genera una respuesta natural al usuario.

💻 Código Production-Grade de Function Calling

"""
Sistema de Function Calling con OpenAI API.
Maneja múltiples funciones, parsing robusto, y errores.
"""
import json
import logging
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Any, Callable, Union
from enum import Enum
import asyncio

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class FunctionCallResult:
    """Resultado de una llamada a función."""
    def __init__(
        self,
        function_name: str,
        arguments: Dict[str, Any],
        success: bool,
        result: Optional[Any] = None,
        error: Optional[str] = None,
    ):
        self.function_name = function_name
        self.arguments = arguments
        self.success = success
        self.result = result
        self.error = error


@dataclass
class FunctionDefinition:
    """Definición de una función disponible para el LLM."""
    name: str
    description: str
    parameters: Dict[str, Any]  # JSON Schema
    handler: Callable[..., Any]  # Función real a ejecutar
    requires_confirmation: bool = False  # Para acciones destructivas


class FunctionCallingSystem:
    """
    Sistema de function calling que conecta el LLM con funciones reales.
    """
    
    def __init__(self):
        self.functions: Dict[str, FunctionDefinition] = {}
        self.call_history: List[Dict] = []
        logger.info("FunctionCallingSystem inicializado")
    
    def register_function(self, func_def: FunctionDefinition) -> None:
        """Registra una nueva función."""
        self.functions[func_def.name] = func_def
        logger.info(f"Función registrada: {func_def.name}")
    
    def get_functions_schema(self) -> List[Dict]:
        """Retorna el schema de todas las funciones para el LLM."""
        return [
            {
                "name": f.name,
                "description": f.description,
                "parameters": f.parameters,
            }
            for f in self.functions.values()
        ]
    
    def parse_function_call(
        self, 
        function_call: Dict
    ) -> FunctionCallResult:
        """
        Parsea y ejecuta una llamada a función desde el LLM.
        
        Args:
            function_call: Dict con 'name' y 'arguments' del LLM
            
        Returns:
            FunctionCallResult con el resultado de la ejecución
        """
        func_name = function_call.get("name")
        raw_args = function_call.get("arguments", {})
        
        # Convertir argumentos string a dict si es necesario
        if isinstance(raw_args, str):
            try:
                arguments = json.loads(raw_args)
            except json.JSONDecodeError as e:
                return FunctionCallResult(
                    function_name=func_name,
                    arguments=raw_args,
                    success=False,
                    error=f"JSON parse error: {e}"
                )
        else:
            arguments = raw_args
        
        # Verificar que la función existe
        if func_name not in self.functions:
            return FunctionCallResult(
                function_name=func_name,
                arguments=arguments,
                success=False,
                error=f"Función desconocida: {func_name}"
            )
        
        func_def = self.functions[func_name]
        
        # Validar argumentos contra el schema
        validation_error = self._validate_arguments(arguments, func_def.parameters)
        if validation_error:
            return FunctionCallResult(
                function_name=func_name,
                arguments=arguments,
                success=False,
                error=f"Validación falló: {validation_error}"
            )
        
        # Ejecutar la función
        try:
            logger.info(f"Llamando función {func_name} con args: {arguments}")
            result = func_def.handler(**arguments)
            
            self.call_history.append({
                "function": func_name,
                "arguments": arguments,
                "success": True,
            })
            
            return FunctionCallResult(
                function_name=func_name,
                arguments=arguments,
                success=True,
                result=result,
            )
            
        except Exception as e:
            logger.error(f"Error ejecutando {func_name}: {e}")
            self.call_history.append({
                "function": func_name,
                "arguments": arguments,
                "success": False,
                "error": str(e),
            })
            
            return FunctionCallResult(
                function_name=func_name,
                arguments=arguments,
                success=False,
                error=str(e)
            )
    
    def _validate_arguments(
        self, 
        arguments: Dict, 
        schema: Dict
    ) -> Optional[str]:
        """Valida argumentos contra JSON Schema simplificado."""
        required = schema.get("required", [])
        
        # Check required fields
        for field_name in required:
            if field_name not in arguments:
                return f"Campo requerido faltante: {field_name}"
        
        # Check types
        properties = schema.get("properties", {})
        for field_name, value in arguments.items():
            if field_name in properties:
                expected_type = properties[field_name].get("type")
                if expected_type == "string" and not isinstance(value, str):
                    return f"{field_name} debe ser string"
                elif expected_type == "number" and not isinstance(value, (int, float)):
                    return f"{field_name} debe ser number"
                elif expected_type == "boolean" and not isinstance(value, bool):
                    return f"{field_name} debe ser boolean"
                elif expected_type == "array" and not isinstance(value, list):
                    return f"{field_name} debe ser array"
        
        return None

def calculateMortgage(
    principal: float,
    interest_rate: float,
    years: int,
    down_payment: float = 0
) -> Dict[str, float]:
    """Calcula pagos de hipoteca."""
    p = principal - down_payment
    r = interest_rate / 100 / 12  # Monthly rate
    n = years * 12
    
    if r == 0:
        monthly_payment = p / n
    else:
        monthly_payment = p * (r * (1 + r)**n) / ((1 + r)**n - 1)
    
    total_payment = monthly_payment * n
    
    return {
        "monthly_payment": round(monthly_payment, 2),
        "total_payment": round(total_payment, 2),
        "total_interest": round(total_payment - p, 2),
        "principal": p,
    }

class OpenAIFunctionCaller:
    """
    Cliente que maneja el flujo completo de function calling con OpenAI.
    """
    
    def __init__(self, api_key: str, system: FunctionCallingSystem):
        self.api_key = api_key
        self.function_system = system
    
    def build_messages(
        self,
        user_query: str,
        conversation_history: Optional[List[Dict]] = None,
        function_results: Optional[List[Dict]] = None,
    ) -> List[Dict]:
        """Construye el array de messages para la API."""
        messages = []
        
        # System prompt
        messages.append({
            "role": "system",
            "content": """Eres un asistente que puede llamar funciones cuando necesitas información adicional.
Solo llamas funciones cuando es necesario para responder la pregunta del usuario.
Si tienes suficiente información, respondes directamente sin llamar funciones."""
        })
        
        # Historial de conversación
        if conversation_history:
            messages.extend(conversation_history)
        
        # Resultados de funciones previas
        if function_results:
            for fr in function_results:
                if fr["success"]:
                    messages.append({
                        "role": "system",
                        "content": f"[Función {fr['function_name']} retornó: {json.dumps(fr['result'])}]"
                    })
                else:
                    messages.append({
                        "role": "system", 
                        "content": f"[Error en función {fr['function_name']}: {fr['error']}]"
                    })
        
        # Query actual
        messages.append({"role": "user", "content": user_query})
        
        return messages
    
    def process_query(
        self,
        user_query: str,
        model: str = "gpt-4-turbo",
        conversation_history: Optional[List[Dict]] = None,
        max_turns: int = 5,
    ) -> Dict[str, Any]:
        """
        Procesa una query del usuario con function calling.
        
        Args:
            user_query: Pregunta del usuario
            model: Modelo a usar
            conversation_history: Historial previo de mensajes
            max_turns: Máximo de llamadas a funciones por query
            
        Returns:
            Dict con 'response' y 'function_calls' realizados
        """
        import openai
        openai.api_key = self.api_key
        
        messages = self.build_messages(user_query, conversation_history)
        function_results = []
        turns = 0
        
        while turns < max_turns:
            # Llamar a la API
            response = openai.ChatCompletion.create(
                model=model,
                messages=messages,
                functions=self.function_system.get_functions_schema(),
                function_call="auto",
                temperature=0.7,
            )
            
            assistant_message = response.choices[0].message
            messages.append(assistant_message)
            
            # Verificar si hay function call
            if assistant_message.get("function_call"):
                func_call = assistant_message["function_call"]
                logger.info(f"Function call detectado: {func_call['name']}")
                
                # Ejecutar la función
                result = self.function_system.parse_function_call(func_call)
                function_results.append({
                    "function_name": result.function_name,
                    "arguments": result.arguments,
                    "success": result.success,
                    "result": result.result,
                    "error": result.error,
                })
                
                # Agregar resultado al mensaje
                if result.success:
                    messages.append({
                        "role": "function",
                        "name": result.function_name,
                        "content": json.dumps(result.result),
                    })
                else:
                    messages.append({
                        "role": "function",
                        "name": result.function_name,
                        "content": f"ERROR: {result.error}",
                    })
                
                turns += 1
            else:
                # No hay más function calls, retornar respuesta final
                return {
                    "response": assistant_message["content"],
                    "function_calls": function_results,
                    "turns_used": turns,
                }
        
        # Se alcanzó max_turns
        return {
            "response": "达到最大 número de llamadas a funciones. No pude completar la request.",
            "function_calls": function_results,
            "turns_used": turns,
        }

⚠️ Errores Comunes con Function Calling

Error 1: No validar los argumentos antes de ejecutar

El problema: Confiar ciegamente en los argumentos que el LLM genera y ejecutarlos directamente puede ser peligroso. Un LLM puede generar argumentos inesperados que causan errores o, en casos extremos, injection attacks. El 75% de implementaciones saltan la validación.

Fix: SIEMPRE validar argumentos contra el JSON Schema antes de pasarlos a la función handler. Implementar type checking, range validation, y sanitization de strings.

Error 2: Function descriptions vagas

El problema: Si la descripción de la función es ambigua o缺少 detalles, el modelo puede misunderstander cuándo llamar la función o con qué argumentos. Típicamente resulta en llamadas innecesarias o con parámetros incorrectos.

Fix:: Escribir descripciones detalladas que incluyan: qué hace la función, cuándo es apropiada, y qué significan los parámetros. Incluir ejemplos en la descripción si es necesario.

Error 3: No manejar timeouts ni errores de red

El problema: Cuando la función llama a una API externa, puede fallar por timeout, rate limiting, o errores de red. Si no manejas esto, el usuario queda con una respuesta incompleta o un error críptico.

Fix:: Wrappear las llamadas a funciones con try/catch, implementar retry con backoff, y retornar mensajes de error claros que el LLM pueda usar para explicar el problema al usuario.

✅ Resumen y Cierre

  • Function calling convierte LLMs pasivos en agentes activos capaces de actuar en el mundo real.
  • El flujo: Define funciones → LLM decide cuándo llamar → Ejecuta → LLM responde con resultado.
  • Validación de argumentos es crítica — nunca confiar ciegamente en output del LLM.
  • Descriptions claras mejoran significativamente la calidad de las llamadas.
  • Manejo de errores robusto es essential para producción.
