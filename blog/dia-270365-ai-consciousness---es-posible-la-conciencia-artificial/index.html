🎯 Introduction

Hagale pues, parcero. Aquí en Bogotá, Cali, Cartagena, donde sea que esté leyendo esto, el 85% de los equipos que despliegan aplicaciones LLM están exponiendo datos sensibles sin siquiera saberlo. Envían emails de clientes, números de cédula, direcciones, historiales médicos al LLM como si fuera un servidor seguro. No lo es. Y hoy le voy a mostrar por qué, con código de verdad, para que no sea uno de esos equipos.

LLM Security y Privacy no es opcional. Es obligación legal bajo GDPR, SOC2, y cualquier marco de compliance serio. Y más allá de compliance, es sentido común: sus usuarios confían que sus datos están seguros. Vamos paso a paso, desde la matemática hasta la implementación.

📐 The Math: Information Leakage and Risk Modeling

Para entender el riesgo de leakage, necesitamos medirlo. La mutual information entre input sensitive y output del modelo:

$$I(S; O) = \sum_{s \in S} \sum_{o \in O} p(s, o) \log \frac{p(s, o)}{p(s) \cdot p(o)}$$

Donde $S$ son los datos sensibles y $O$ es el output del modelo. Si $I(S; O) > 0$, hay alguna correlación entre lo que el usuario envía y lo que el modelo puede revelar.

El segundo concepto es privacy risk en términos de re-identification. even si removemos el nombre, un modelo puede inferir identidad via:

$$P(\text{identity} | \text{features}) = \frac{P(\text{features} | \text{identity}) \cdot P(\text{identity})}{P(\text{features})}$$

Esto se conoce como linkage attack. Por eso la anonymization pura no funciona — hay que hacer redaction completa.

🔍 PII Detection: Regex y NER

El primer paso es detectar PII en el input. Usamos un combination de regex patterns y NER (Named Entity Recognition):

import re
from dataclasses import dataclass
from typing import Iterator
from enum import Enum

class PIIType(Enum):
    EMAIL = "email"
    PHONE_CO = "phone_co"
    PHONE_INT = "phone_int"
    CEDULA = "cedula"
    NIT = "nit"
    IP_ADDRESS = "ip"
    CREDIT_CARD = "credit_card"
    SSN = "ssn"
    NAME = "name"
    ADDRESS = "address"
    DATE_OF_BIRTH = "dob"
    MEDICAL_TERM = "medical"
    BANK_ACCOUNT = "bank_account"

@dataclass
class PIISpan:
    pii_type: PIIType
    value: str
    start: int
    end: int
    confidence: float

class PIIRegexDetector:
    """Detector de PII via regex patterns."""
    
    PATTERNS = {
        PIIType.EMAIL: re.compile(
            r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b'
        ),
        PIIType.PHONE_CO: re.compile(
            r'\b(?:\+57\s?)?(?:\d{3}[-.\s]?\d{3}[-.\s]?\d{4})\b'
        ),
        PIIType.PHONE_INT: re.compile(
            r'\b\+\d{1,3}[-.\s]?\d{1,14}\b'
        ),
        PIIType.CEDULA: re.compile(
            r'\b\d{6,10}\b'  # Colombian ID (6-10 digits)
        ),
        PIIType.NIT: re.compile(
            r'\b\d{9}-\d\b'  # Colombian NIT format
        ),
        PIIType.IP_ADDRESS: re.compile(
            r'\b(?:\d{1,3}\.){3}\d{1,3}\b'
        ),
        PIIType.CREDIT_CARD: re.compile(
            r'\b(?:\d{4}[-\s]?){3}\d{4}\b'
        ),
        PIIType.SSN: re.compile(
            r'\b\d{3}-\d{2}-\d{4}\b'
        ),
    }
    
    def detect(self, text: str) -> list[PIISpan]:
        """Detecta PII en texto usando regex."""
        spans = []
        
        for pii_type, pattern in self.PATTERNS.items():
            for match in pattern.finditer(text):
                spans.append(PIISpan(
                    pii_type=pii_type,
                    value=match.group(),
                    start=match.start(),
                    end=match.end(),
                    confidence=1.0  # Regex gives 100% confidence
                ))
        
        return spans

class NERDetector:
    """Detector de PII usando NER (spaCy)."""
    
    def __init__(self, model_name: str = "es_core_news_lg"):
        import spacy
        self.nlp = spacy.load(model_name)
    
    def detect(self, text: str) -> list[PIISpan]:
        """Detecta entidades nombradas que pueden ser PII."""
        doc = self.nlp(text)
        spans = []
        
        for ent in doc.ents:
            pii_type = None
            confidence = ent.kb_id_ if hasattr(ent, 'kb_id_') else 0.9
            
            # Map spaCy entity types to PII types
            if ent.label_ == "PER":
                pii_type = PIIType.NAME
            elif ent.label_ == "LOC":
                pii_type = PIIType.ADDRESS
            elif ent.label_ == "ORG":
                pii_type = PIIType.BANK_ACCOUNT
            # Add more mappings as needed
            
            if pii_type:
                spans.append(PIISpan(
                    pii_type=pii_type,
                    value=ent.text,
                    start=ent.start_char,
                    end=ent.end_char,
                    confidence=float(confidence)
                ))
        
        return spans

class PIIDetector:
    """Pipeline completo: regex + NER."""
    
    def __init__(self, use_ner: bool = True):
        self.regex_detector = PIIRegexDetector()
        self.ner_detector = NERDetector() if use_ner else None
    
    def detect_all(self, text: str) -> list[PIISpan]:
        """Combina detección via regex y NER."""
        spans = self.regex_detector.detect(text)
        
        if self.ner_detector:
            ner_spans = self.ner_detector.detect(text)
            # Merge overlapping spans
            spans.extend(ner_spans)
        
        # Sort by position and remove duplicates
        spans.sort(key=lambda s: (s.start, -s.confidence))
        return self._remove_overlaps(spans)
    
    def _remove_overlaps(self, spans: list[PIISpan]) -> list[PIISpan]:
        """Remove overlapping spans, keeping highest confidence."""
        if not spans:
            return []
        
        result = [spans[0]]
        for span in spans[1:]:
            if span.start >= result[-1].end:
                result.append(span)
            elif span.confidence > result[-1].confidence:
                result[-1] = span
        return result

🛡️ Secure Context Management y Redaction

Una vez detectado, hay que redacted antes de enviar al LLM:

from typing import Protocol
import hashlib

class PIIRedactor(Protocol):
    """Interface para strategies de redaction."""
    def redact(self, text: str, spans: list[PIISpan]) -> tuple[str, dict]:
        """
        Redacts PII from text.
        Returns: (redacted_text, metadata_for_reinsertion)
        """
        ...

class MaskRedactor:
    """Replaces PII with [TYPE] markers."""
    
    MASK_CHAR = "█"  # Full block character
    
    def redact(self, text: str, spans: list[PIISpan]) -> tuple[str, dict]:
        if not spans:
            return text, {}
        
        # Spans are sorted by start position
        # Process in reverse to maintain indices
        redacted = text
        metadata = {"originals": {}}
        
        for span in reversed(spans):
            mask = f"[{span.pii_type.value.upper()}]"
            # For high-sensitivity items, use full masking
            if span.pii_type in [PIIType.CREDIT_CARD, PIIType.SSN, PIIType.BANK_ACCOUNT]:
                mask_length = min(len(span.value), 12)
                mask = self.MASK_CHAR * mask_length
            
            redacted = (
                redacted[:span.start]
                + mask
                + redacted[span.end:]
            )
            
            # Store for audit/reinsertion
            metadata["originals"][span.value] = {
                "type": span.pii_type.value,
                "replacement": mask
            }
        
        metadata["count"] = len(spans)
        return redacted, metadata

class SecureContextManager:
    """
    Maneja contexto seguro para LLMs.
    Detecta PII, redacta, y mantiene audit trail.
    """
    
    def __init__(
        self,
        detector: PIIDetector,
        redactor: PIIRedactor,
        audit_logger = None
    ):
        self.detector = detector
        self.redactor = redactor
        self.audit_logger = audit_logger
    
    def process_for_llm(
        self,
        user_input: str,
        conversation_history: list[dict] | None = None,
        include_audit: bool = True
    ) -> dict:
        """
        Procesa input del usuario para envío seguro al LLM.
        
        Returns:
            {
                "safe_prompt": str,  # Para enviar al LLM
                "has_pii": bool,
                "audit_id": str,    # Para trazabilidad
                "metadata": dict    # Info sobre redactions
            }
        """
        audit_id = hashlib.sha256(
            f"{user_input}{__import__('time').time()}".encode()
        ).hexdigest()[:16]
        
        # Combine with history if provided
        full_text = user_input
        if conversation_history:
            for msg in conversation_history:
                if msg.get("role") == "user":
                    full_text += "\n" + msg["content"]
        
        # Detect PII
        spans = self.detector.detect_all(full_text)
        
        if not spans:
            return {
                "safe_prompt": user_input,
                "has_pii": False,
                "audit_id": audit_id,
                "metadata": {}
            }
        
        # Redact
        redacted_text, metadata = self.redactor.redact(full_text, spans)
        
        # Log for audit
        if self.audit_logger:
            self.audit_logger.info({
                "event": "pii_redaction",
                "audit_id": audit_id,
                "original_length": len(full_text),
                "redacted_length": len(redacted_text),
                "pii_count": len(spans),
                "pii_types": [s.pii_type.value for s in spans],
                "timestamp": __import__('time').time()
            })
        
        return {
            "safe_prompt": redacted_text,
            "has_pii": True,
            "audit_id": audit_id,
            "metadata": {
                **metadata,
                "pii_count": len(spans),
                "pii_types": list(set(s.pii_type.value for s in spans))
            }
        }

# Ejemplo de uso
def example_usage():
    detector = PIIDetector(use_ner=True)
    redactor = MaskRedactor()
    manager = SecureContextManager(detector, redactor)
    
    user_input = """
    necesito ayuda con mi reclamo
    mi numero de cedula es 12345678
    mi email es usuario@gmail.com
    mi telefono es +57 300 123 4567
    """
    
    result = manager.process_for_llm(user_input)
    
    print("Safe prompt for LLM:")
    print(result["safe_prompt"])
    print(f"\nHad PII: {result['has_pii']}")
    print(f"Audit ID: {result['audit_id']}")

📋 GDPR Compliance y Audit Trails

Para compliance, necesitamos saber exactamente qué se envió al LLM y cuándo:

from datetime import datetime
from typing import Optional
import json

class LLMAuditLogger:
    """
    Audit logger para compliance.
    Mantiene registro de todos los prompts enviados a LLMs.
    """
    
    def __init__(self, storage_path: str = "/var/log/llm-audit"):
        self.storage_path = storage_path
        self._ensure_storage()
    
    def _ensure_storage(self):
        import os
        os.makedirs(self.storage_path, exist_ok=True)
    
    def log_prompt(
        self,
        audit_id: str,
        original_prompt: str,
        safe_prompt: str,
        has_pii: bool,
        metadata: dict,
        user_id: Optional[str] = None,
        session_id: Optional[str] = None
    ):
        """Registra un prompt para audit trail."""
        entry = {
            "audit_id": audit_id,
            "timestamp": datetime.utcnow().isoformat(),
            "user_id": user_id,
            "session_id": session_id,
            "has_pii": has_pii,
            "metadata": metadata,
            # NOTE: We store ORIGINAL, not safe prompt
            # encrypted at rest in production
            "original_prompt_hash": hashlib.sha256(
                original_prompt.encode()
            ).hexdigest(),
        }
        
        if not has_pii:
            entry["prompt_preview"] = original_prompt[:200]
        else:
            entry["prompt_preview"] = safe_prompt[:200]  # Store SAFE version
        
        filepath = f"{self.storage_path}/{audit_id}.json"
        with open(filepath, 'w') as f:
            json.dump(entry, f, indent=2)
    
    def get_audit_entry(self, audit_id: str) -> Optional[dict]:
        """Recupera un entry de audit."""
        filepath = f"{self.storage_path}/{audit_id}.json"
        try:
            with open(filepath, 'r') as f:
                return json.load(f)
        except FileNotFoundError:
            return None
    
    def export_for_gdpr_request(self, user_id: str, start_date: str, end_date: str) -> list:
        """Exporta todos los datos de un usuario para request GDPR."""
        import os
        exports = []
        
        for filename in os.listdir(self.storage_path):
            if not filename.endswith('.json'):
                continue
            
            with open(os.path.join(self.storage_path, filename)) as f:
                entry = json.load(f)
            
            if (entry.get("user_id") == user_id and
                start_date <= entry["timestamp"][:10] <= end_date):
                exports.append(entry)
        
        return exports

class GDPRComplianceChecker:
    """Verifica compliance de prompts contra políticas GDPR."""
    
    FORBIDDEN_PATTERNS = [
        # Medical conditions
        re.compile(r'diagn[oó]stico', re.IGNORECASE),
        re.compile(r'enfermedad', re.IGNORECASE),
        re.compile(r'paciente', re.IGNORECASE),
        # Financial
        re.compile(r'salario', re.IGNORECASE),
        re.compile(r'cuenta\s*bancaria', re.IGNORECASE),
        # Children
        re.compile(r'menor\s*de\s*edad', re.IGNORECASE),
    ]
    
    def check(self, text: str) -> dict:
        """Check text for GDPR-sensitive content."""
        violations = []
        
        for pattern in self.FORBIDDEN_PATTERNS:
            matches = pattern.findall(text)
            if matches:
                violations.append({
                    "pattern": pattern.pattern,
                    "matches": len(matches),
                    "action": "REVIEW"  # Could be "BLOCK" in strict mode
                })
        
        return {
            "compliant": len(violations) == 0,
            "violations": violations,
            "requires_review": any(v["action"] == "REVIEW" for v in violations)
        }

⚠️ Los 3 Errores Más Comunes

Error 1: Enviar Datos Sensibles a LLMs Sin Sanitización

El problema: El usuario escribe "mi email es juan@email.com" y usted manda eso directo al LLM. Ahora ese email está en los logs del proveedor, en el historial de conversation, potencialmente en training data. Eso es una violación de GDPR si no hay consent.

La solución: SIEMPRE pasar el input por un pipeline de sanitización antes de enviar al LLM. Esto no es opcional, es mandatory. Configure su SecureContextManager como middleware.

# ❌ MAL: Sin sanitización
async def chat(user_input: str):
    response = await llm.generate(user_input)  # PII va directa!
    return response

# ✅ BIEN: Con sanitización obligatoria
async def chat(user_input: str, ctx_manager: SecureContextManager):
    result = ctx_manager.process_for_llm(user_input)
    audit_logger.log_prompt(
        audit_id=result["audit_id"],
        original_prompt=user_input,
        safe_prompt=result["safe_prompt"],
        has_pii=result["has_pii"],
        metadata=result["metadata"]
    )
    response = await llm.generate(result["safe_prompt"])
    return response

Error 2: No Tener PII Detection y Accidentalmente Exponer Información Personal

El problema: Regex patterns simples no capturan todo. Un NIT colombiano, una placa de vehículo, un número de historia clínica — todos son PII pero muchos sistemas no los detectan. La regla es: si no lo detecta, no lo protege.

La solución: Implemente un pipeline de detección en capas: regex básico + NER con modelos entrenados para el dominio. Para aplicaciones en Colombia o Latinoamérica, asegúrese de incluir patrones locales (cédulas, NITs, teléfonos con prefijos regionales).

Error 3: No Entender Que los Prompts Son Logged y Pueden Contener Datos Sensibles

El problema: Los proveedores de LLM (OpenAI, Anthropic, etc.) logan prompts para debugging, mejora de modelos, y compliance. Si usted envía "el paciente Juan Pérez, cédula 123456, fue diagnosticado con..." eso va a logs de terceros. Usted no controla esos logs.

La solución: Asuma que TODO lo que envía al LLM será logged por el proveedor. Diseñe su arquitectura para que ningún PII llegue nunca al LLM. Use redaction de lado del cliente ANTES de enviar. Configure retención mínima de logs. Para datos verdaderamente sensibles, considere LLMs on-premise o federados.

📊 Resumen y Cierre

Pues ahí lo tiene, parcero. LLM Security y Privacy no es un feature, es una necesidad. El 85% de los equipos lo ignora hasta que tienen una brecha. El 15% que lo hace bien implementa las tres cosas que le mostré: detección de PII multicapa (regex + NER), sanitización obligatoria antes de enviar al LLM, y audit trails que les permiten responder preg ones como "¿qué datos de este usuario se enviaron a un LLM?"

La próxima vez que reciba un input de usuario, piense en esto: ¿este texto va a parar a los logs de un tercero? Si la respuesta es sí o "no sé", tiene un problema. Arrégielo antes del primer usuario en producción.

El que protege los datos de sus usuarios, protege su empresa de demandas y su reputación de la prensa. Eso es LLM Security de verdad — no después, sino antes.
