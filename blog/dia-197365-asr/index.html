Que Es ASR?

Hagale pues, parcero. Dia 197 y hoy vamos a meternos en el mundo de ASR - Automatic Speech Recognition. Esto es la tecnologia que permite a las maquinas entender el habla humana y convertirla en texto. Desde Siri hasta los subtitulos automaticos de YouTube, todo pasa por un sistema ASR. Vamos a ver como funciona internamente, porque el 80% de la gente lo implementa mal, y vamos a hacerlo bien con codigo PyTorch real. Sirvete un tintico y vamos pa'lla.

La Pipeline de ASR

Un sistema ASR tipico tiene varios componentes:

  • Preprocesamiento de audio: Convertir audio crudo a features acusticas
  • Modelo acustico: Mapear features a fonemas o caracteres
  • Modelo de lenguaje: Mejorar las predicciones con contexto linguistico
  • Decoder: Convertir secuencias de tokens a texto final

La clave esta en como manejas el audio: no puedes meter audio crudo en un transformer. Necesitas convertirlo a algo que el modelo pueda procesar - típicamente espectrogramas Mel o MFCCs.

CTC - Connectionist Temporal Classification

El Problema de Alignment

En speech recognition, el audio y el texto no tienen la misma longitud. 1 segundo de audio puede tener 100 frames, pero solo 5 caracteres de texto. CTC resuelve esto con un token especial llamado "blank" que permite que el modelo emitia predictions repetidas o vacias y luego las colapsa.

La funcion de perdida CTC es:

$$P_{CTC}(l|x) = \sum_{\pi \in B^{-1}(l)} \prod_{t=1}^{T} y_{\pi_t}^t$$

Donde $l$ es la etiqueta, $\pi$ es una ruta de predicciones, y $B$ es el operador de colapso que remueve blanks y repetidos.

Decoding con CTC

Hay dos estrategias principales:

  • Greedy decoding: Tomar el token con mayor probabilidad en cada paso
  • Beam search con lenguaje model: Explorar multiples rutas y usar un LM para reranquear
def greedy_decode(logits):
    """
    Greedy decoding para CTC.
    logits: (T, vocab_size) - probabilities de cada timestep
    """
    # Tomar el indice con mayor probabilidad en cada timestep
    predictions = torch.argmax(logits, dim=-1)  # (T,)
    
    # Colapsar repeticiones y remover blanks
    collapsed = []
    prev_token = None
    for token in predictions:
        if token != prev_token and token != blank_id:
            collapsed.append(token.item())
        prev_token = token
    
    return collapsed


def beam_search_ctc(logits, beam_width=10, lm=None, lm_weight=0.5):
    """
    Beam search con language model para mejor decoding.
    """
    T, vocab_size = logits.shape
    beams = [{'chars': [], 'score': 0.0, 'last_char': None}]
    
    for t in range(T):
        new_beams = []
        probs = torch.softmax(logits[t], dim=-1)
        
        for beam in beams:
            for c in range(vocab_size):
                prob = probs[c].item()
                new_chars = beam['chars'].copy()
                new_score = beam['score'] + math.log(prob + 1e-8)
                
                # Reglas de transicion CTC
                if c != blank_id:
                    if c != beam['last_char'] or beam['last_char'] is None:
                        new_chars.append(c)
                
                new_beams.append({
                    'chars': new_chars,
                    'score': new_score,
                    'last_char': c if c != blank_id else beam['last_char']
                })
        
        # Mantener solo los mejores beams
        new_beams.sort(key=lambda x: x['score'], reverse=True)
        beams = new_beams[:beam_width]
    
    # Devolver el mejor beam
    return beams[0]['chars']

End-to-End ASR con Transformers

Los modelos modernos como Whisper no usan CTC puro. Usan una arquitectura seq2seq con attention que aprende jointly el modelo acustico y de lenguaje.

Arquitectura Encoder-Decoder

import torch
import torch.nn as nn
import torch.nn.functional as F

class SpeechEncoder(nn.Module):
    """
    Encoder que convierte espectrogramas a features de alta dimensi\u00f3n.
    Usa capas convolucionales seguido de transformers.
    """
    def __init__(self, n_mels=80, d_model=512, n_conv_layers=3):
        super().__init__()
        
        # CNN feature extractor
        self.conv_layers = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv2d(32, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.Conv2d(64, d_model, kernel_size=3, padding=1),
            nn.ReLU(),
        )
        
        # Proyecci\u00f3n para匹配 Transformer dimension
        self.proj = nn.Linear(d_model * n_mels // 8, d_model)
        
        # Positional encoding para el audio
        self.pos编码 = PositionalEncoding(d_model)
        
        # Transformer encoder layers
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, 
            nhead=8, 
            dim_feedforward=2048,
            batch_first=True
        )
        self.transformer_encoder = nn.TransformerEncoder(
            encoder_layer, 
            num_layers=6
        )
    
    def forward(self, mel_spectrograms):
        # mel_spectrograms: (batch, 1, n_mels, T)
        x = self.conv_layers(mel_spectrograms)
        x = x.permute(0, 3, 1, 2)  # (batch, T, channels, n_mels)
        x = x.reshape(x.size(0), x.size(1), -1)  # (batch, T, d_model * n_mels // 8)
        x = self.proj(x)
        x = self.pos编码(x)
        x = self.transformer_encoder(x)
        return x


class ASRDecoder(nn.Module):
    """
    Decoder autoregresivo que genera texto token por token.
    """
    def __init__(self, vocab_size, d_model=512, n_layers=6):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model)
        
        decoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=8,
            dim_feedforward=2048,
            batch_first=True
        )
        self.transformer_decoder = nn.TransformerEncoder(
            decoder_layer,
            num_layers=n_layers
        )
        
        self.output_proj = nn.Linear(d_model, vocab_size)
    
    def forward(self, encoder_output, target_tokens):
        # target_tokens: (batch, tgt_len) - texto de entrada sin el ultimo token
        x = self.embedding(target_tokens)
        x = self.pos_encoding(x)
        
        # Cross-attention con el encoder
        # Usamos el encoder output como keys y values
        x = self.transformer_decoder(x)
        logits = self.output_proj(x)
        return logits


class EndToEndASR(nn.Module):
    """
    Modelo completo ASR: Encoder + Decoder con cross-attention.
    """
    def __init__(self, vocab_size, d_model=512):
        super().__init__()
        self.encoder = SpeechEncoder(d_model=d_model)
        self.decoder = ASRDecoder(vocab_size, d_model)
        self.vocab_size = vocab_size
    
    def forward(self, mel_spectrograms, target_tokens):
        encoder_output = self.encoder(mel_spectrograms)
        logits = self.decoder(encoder_output, target_tokens)
        return logits
    
    def generate(self, mel_spectrograms, max_len=200, sos_token=1, eos_token=2):
        """
        Generacion autoregresiva con beam search.
        """
        encoder_output = self.encoder(mel_spectrograms)
        batch_size = encoder_output.size(0)
        
        # Iniciar con token SOS
        generated = torch.full((batch_size, 1), sos_token, dtype=torch.long, device=encoder_output.device)
        
        for _ in range(max_len):
            logits = self.decoder(encoder_output, generated)
            next_token = logits[:, -1, :].argmax(dim=-1, keepdim=True)
            generated = torch.cat([generated, next_token], dim=1)
            
            # Terminar si todos han generado EOS
            if (next_token == eos_token).all():
                break
        
        return generated

Preprocesamiento de Audio

Mel Spectrograms

El primer paso es convertir audio crudo a Mel spectrograms. Esto reduce la dimensionalidad y captura las caracteristicas foneticas importantes.

import torchaudio
import torchaudio.transforms as T

class AudioPreprocessor:
    """
    Preprocesador de audio para ASR.
    Convierte audio crudo a Mel spectrograms normalizados.
    """
    def __init__(self, sample_rate=16000, n_mels=80, n_fft=400, hop_length=160):
        self.sample_rate = sample_rate
        self.n_mels = n_mels
        self.n_fft = n_fft
        self.hop_length = hop_length
        
        # Mel spectrogram transform
        self.mel_transform = T.MelSpectrogram(
            sample_rate=sample_rate,
            n_fft=n_fft,
            hop_length=hop_length,
            n_mels=n_mels,
            f_min=0,
            f_max=8000,
        )
        
        # Normalizacion
        self.normalize = T.FrequencyMasking(freq_mask_param=15)
        self.normalize2 = T.TimeMasking(time_mask_param=35)
    
    def __call__(self, waveform):
        """
        Convert waveform to mel spectrogram.
        
        Args:
            waveform: Tensor de forma (T,) o (batch, T)
        Returns:
            mel_spec: Tensor de forma (batch, 1, n_mels, T')
        """
        # Asegurar que tiene batch dimension
        if waveform.dim() == 1:
            waveform = waveform.unsqueeze(0)
        
        # Compute mel spectrogram
        mel_spec = self.mel_transform(waveform)
        
        # Log scale
        mel_spec = torch.log(mel_spec + 1e-9)
        
        # Normalize
        mean = mel_spec.mean()
        std = mel_spec.std()
        mel_spec = (mel_spec - mean) / (std + 1e-8)
        
        # Data augmentation (solo en entrenamiento)
        if self.training:
            mel_spec = self.normalize(mel_spec)
            mel_spec = self.normalize2(mel_spec)
        
        return mel_spec


# Ejemplo de uso
preprocessor = AudioPreprocessor()

Entrenamiento de un Modelo ASR

def train_asr(model, train_loader, val_loader, optimizer, scheduler, epochs=20, device='cuda'):
    """
    Entrenamiento completo de un modelo ASR.
    """
    model = model.to(device)
    criterion = nn.CrossEntropyLoss(ignore_index=pad_token, label_smoothing=0.1)
    
    for epoch in range(epochs):
        model.train()
        total_loss = 0
        
        for batch in train_loader:
            mel_specs = batch['mel'].to(device)
            input_tokens = batch['input'].to(device)
            target_tokens = batch['target'].to(device)
            
            # Forward pass
            logits = model(mel_specs, input_tokens)
            
            # Loss (ignorar padding)
            loss = criterion(logits.view(-1, model.vocab_size), target_tokens.view(-1))
            
            # Backward pass
            optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0)
            optimizer.step()
            
            total_loss += loss.item()
        
        scheduler.step()
        
        # Validacion
        val_wer = evaluate_wer(model, val_loader, device)
        print(f"Epoch {epoch+1}/{epochs}, Loss: {total_loss/len(train_loader):.4f}, WER: {val_wer:.4f}")


def evaluate_wer(model, dataloader, device):
    """
    Evalua el modelo usando Word Error Rate (WER).
    WER = (S + D + I) / N
    S = substitutions, D = deletions, I = insertions, N = total words
    """
    model.eval()
    total_words = 0
    total_wer = 0
    
    with torch.no_grad():
        for batch in dataloader:
            mel_specs = batch['mel'].to(device)
            targets = batch['target_text']
            
            # Generar predicciones
            predictions = model.generate(mel_specs)
            
            # Convertir a texto y calcular WER
            for pred, target in zip(predictions, targets):
                pred_text = decode_tokens(pred)
                wer = compute_wer(pred_text, target)
                total_wer += wer
                total_words += len(target.split())
    
    return total_wer / total_words if total_words > 0 else 0

Errores Comunes en ASR

Error 1: No Usar Spec Augmentation

El problema: En entrenamiento, el modelo memoriza el audio especifico en lugar de aprender features generalizables. En inference, cualquier variacion de velocidad o tono causa degradacion.

Error 2: Ignorar el Language Model

Resumen y Cierre

Hoy cubrimos ASR - Automatic Speech Recognition:

  • Pipeline: Audio -> Mel Spectrogram -> Encoder -> Decoder -> Texto
  • CTC: Maneja el problema de alineacion de longitud variable
  • End-to-end: Modelos modernos como Whisper aprenden todo junto
  • Spec augmentation: Critical para generalizacion
  • Language models: Mejoran significativamente la calidad

El futuro de ASR es completamente end-to-end y multilingual. Modelos como Whisper ya demuestran que se puede entrenar en multiples idiomas sin perdida significativa de calidad.
