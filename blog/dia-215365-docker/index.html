Knowledge Distillation - Aprendiendo De Modelos Grandes

Hagale pues, parcero. Llegamos al Dia 215 y hoy hablamos de Knowledge Distillation, el arte de transferir conocimiento de un modelo grande a uno pequeno. Dejala el cafe, que esto esta interesante.

🎯 Que Es La Knowledge Distillation?

Knowledge distillation es el proceso de entrenar un modelo pequeno (student) para que复刻 el comportamiento de uno grande (teacher). El modelo pequeno aprende de los "soft targets" del modelo grande, no solo de las etiquetas duras.

Conceptos clave:

  • Teacher Model: Modelo grande pre-entrenado con todo su conocimiento
  • Student Model: Modelo pequeno que aprende del teacher
  • Soft Targets: Probabilidades de salida del teacher
  • Temperature: Parametro que controla la "suavidad" de las predicciones

📐 La Matematica De La Distilacion

La loss combina dos componentes: la loss硬的 (cross-entropy con labels) y la loss软的 (KL divergence con soft targets):

import torch
import torch.nn.functional as F

def distillation_loss(student_logits, teacher_logits, labels, T=2.0, alpha=0.5):
    # Soft loss: KL divergence entre distributions
    soft_loss = F.kl_div(
        F.log_softmax(student_logits / T, dim=-1),
        F.softmax(teacher_logits / T, dim=-1),
        reduction='batchmean'
    ) * (T * T)
    
    # Hard loss: cross-entropy normal
    hard_loss = F.cross_entropy(student_logits, labels)
    
    # Combinacion
    return alpha * soft_loss + (1 - alpha) * hard_loss

🚀 Ejemplo Practico

def train_student(teacher, student, dataloader, optimizer, T=2.0, alpha=0.7):
    for batch in dataloader:
        inputs, labels = batch
        
        # Teacher predictions (no gradients)
        with torch.no_grad():
            teacher_logits = teacher(inputs)
        
        # Student predictions
        student_logits = student(inputs)
        
        # Distillation loss
        loss = distillation_loss(student_logits, teacher_logits, labels, T, alpha)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

⚠️ Errores Comunes

Error 1: Temperature Muy Alta

El problema: Predicciones muy suaves pierden informacion util.

La solucion: Empieza con T=2.0 a 4.0 y ajusta segun resultados.
