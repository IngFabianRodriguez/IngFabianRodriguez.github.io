🎯 Toy Models De Superposition

Toy models son redes pequenas que demuestran como superposition emerge. Permiten study formal del fenomeno.

Setup tipico:

  • Input: Sparse binary features
  • Hidden: Menos neurons que features
  • Output: Reconstruir features originales

📐 Analisis de Interference

import numpy as np

def measure_superposition(model, features):
    """Cuanto interfere cada feature con otras?"""
    # Get activations
    with torch.no_grad():
        hidden = model.encoder(features)
    
    # Calcular correlations
    correlations = torch.corrcoef(hidden.T)
    
    # Feature i interfere con j si tienen alta correlation
    interference = (correlations.abs() - torch.eye(len(features))).abs()
    return interference.mean(dim=-1)

🚀 Resultados

Toy models muestran que superposition es mas probable para features menos usadas. Rara combinacion = superposition.

⚠️ Generalizacion

Resultados de toy models pueden no transferirse exactamente a LLMs reales.
