Que Es Style Transfer?

El Style Transfer es una tecnica que permite separar el contenido de una imagen de su estilo artistico, y luego aplicar ese estilo a otra imagen. Imagina tomar una foto tuya y convertirla en una obra de Van Gogh, Picasso o cualquier artista que quieras.

La magia detras de esto son las Convolutional Neural Networks (CNNs). Específicamente, se usa una red pre-entrenada (como VGG19) para extraer caracteristicas de contenido y estilo de diferentes capas.

La Matematica Del Style Transfer

El objective function combina dos perdidas:

L_total = alpha * L_content + beta * L_style

Donde:

  • L_content: Preserva el contenido de la imagen original
  • L_style: Aplica el estilo artistico
  • alpha / beta: pesos que controlan el balance

Content Loss

La perdida de contenido mide la diferencia entre los features de la imagen generada y la imagen de contenido:

L_content = (1/2) * sum(||F^l - P^l||^2)

Donde F^l son los features de la imagen generada y P^l los de la imagen de contenido en la capa l.

Style Loss (Gram Matrix)

Para el estilo, se usa la Gram Matrix que captura correlaciones entre canales de features:

G^l_ij = sum_k F^l_ik * F^l_jk

La perdida de estilo es entonces:

L_style = sum_l (1/(2*N_l*M_l)^2) * sum_ij (G^l_ij - A^l_ij)^2

Donde N_l es el numero de canales y M_l es el tamano de los features.

import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import transforms, models

class VGGFeatureExtractor(nn.Module):
    """Extrae features de diferentes capas de VGG19."""
    
    def __init__(self):
        super().__init__()
        vgg = models.vgg19(pretrained=True).features
        self.slice1 = nn.Sequential(*list(vgg.children()[:2]))   # relu1_1
        self.slice2 = nn.Sequential(*list(vgg.children()[2:7]))   # relu2_1
        self.slice3 = nn.Sequential(*list(vgg.children()[7:12]))  # relu3_1
        self.slice4 = nn.Sequential(*list(vgg.children()[12:21])) # relu4_1
        
        for param in self.parameters():
            param.requires_grad = False
    
    def forward(self, x):
        h1 = self.slice1(x)
        h2 = self.slice2(h1)
        h3 = self.slice3(h2)
        h4 = self.slice4(h3)
        return h1, h2, h3, h4

def gram_matrix(features):
    """Calcula la Gram Matrix de los features."""
    batch_size, channels, height, width = features.size()
    features = features.view(batch_size, channels, height * width)
    gram = torch.bmm(features, features.transpose(1, 2))
    return gram / (channels * height * width)

class StyleTransferModel(nn.Module):
    """Modelo de Style Transfer."""
    
    def __init__(self):
        super().__init__()
        # Imagen generada inicial (se aprende)
        self.generated = None
        
    def set_content(self, content_image):
        self.generated = content_image.clone().requires_grad_(True)
        
    def forward(self, content_features, style_features, extractor, content_img):
        # Extraer features de la imagen generada
        gen_features = extractor(self.generated)
        
        # Content loss
        content_loss = 0
        for gen_f, cont_f in zip(gen_features, content_features):
            content_loss += torch.mean((gen_f - cont_f) ** 2)
        
        # Style loss
        style_loss = 0
        for gen_f, style_f in zip(gen_features, style_features):
            gen_gram = gram_matrix(gen_f)
            style_gram = gram_matrix(style_f)
            style_loss += torch.mean((gen_gram - style_gram) ** 2)
        
        return content_loss, style_loss

def run_style_transfer(
    content_img,
    style_img,
    num_steps=300,
    style_weight=1e6,
    content_weight=1.0
):
    """Ejecuta el algoritmo de Style Transfer."""
    
    extractor = VGGFeatureExtractor().to(content_img.device)
    model = StyleTransferModel()
    optimizer = optim.Adam([model.generated], lr=0.01)
    
    # Extraer features iniciales
    with torch.no_grad():
        content_features = extractor(content_img)
        style_features = extractor(style_img)
    
    for step in range(num_steps):
        optimizer.zero_grad()
        
        content_loss, style_loss = model(
            content_features, style_features, extractor, content_img
        )
        
        total_loss = content_weight * content_loss + style_weight * style_loss
        total_loss.backward()
        optimizer.step()
        
        if step % 50 == 0:
            print(f"Step {step}: content_loss={content_loss.item():.4f}, "
                  f"style_loss={style_loss.item():.4f}")
    
    return model.generated

Neural Style Transfer (Gatys et al.)

El paper original de Gatys et al. (2015) propuso este enfoque:

  1. Inicializa la imagen generada como ruido blanco o como la imagen de contenido
  2. Calcula las perdidas de contenido y estilo usando features de VGG
  3. Usa backpropagation para actualizar la imagen generada
  4. Repite hasta convergencia

Problema: Es Lento

El metodo original necesita数百 iteraciones para cada imagen, lo que lo hace impráctico para uso en tiempo real.

Fast Style Transfer (Johnson et al.)

Johnson et al. propusieron una red feed-forward que aprende a transformar cualquier imagen en un solo paso forward:

class TransformationNetwork(nn.Module):
    """Red de transformacion para Style Transfer rapido."""
    
    def __init__(self):
        super().__init__()
        
        # Encoder
        self.conv1 = nn.Conv2d(3, 32, 9, padding=4)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.conv3 = nn.Conv2d(64, 128, 3, padding=1)
        
        # Residual blocks
        self.res1 = ResidualBlock(128)
        self.res2 = ResidualBlock(128)
        self.res3 = ResidualBlock(128)
        self.res4 = ResidualBlock(128)
        
        # Decoder
        self.deconv1 = nn.ConvTranspose2d(128, 64, 3, padding=1)
        self.deconv2 = nn.ConvTranspose2d(64, 32, 3, padding=1)
        self.deconv3 = nn.ConvTranspose2d(32, 3, 9, padding=4)
        
        self.relu = nn.ReLU()
        
    def forward(self, x):
        # Encoder
        x = self.relu(self.conv1(x))
        x = self.relu(self.conv2(x))
        x = self.relu(self.conv3(x))
        
        # Residual
        x = self.res1(x)
        x = self.res2(x)
        x = self.res3(x)
        x = self.res4(x)
        
        # Decoder
        x = self.relu(self.deconv1(x))
        x = self.relu(self.deconv2(x))
        x = self.deconv3(x)  # No activacion final (tanh se aplica despues)
        
        return torch.sigmoid(x)

class ResidualBlock(nn.Module):
    """Bloque residual para preservar contenido."""
    
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.norm1 = nn.InstanceNorm2d(channels)
        self.norm2 = nn.InstanceNorm2d(channels)
        
    def forward(self, x):
        residual = x
        x = self.relu(self.norm1(self.conv1(x)))
        x = self.norm2(self.conv2(x))
        return x + residual

def train_style_transfer_network(
    content_images,
    style_image,
    num_epochs=2,
    batch_size=4
):
    """Entrena la red de transformacion."""
    
    transform_net = TransformationNetwork().to(device)
    extractor = VGGFeatureExtractor().to(device)
    
    optimizer = optim.Adam(transform_net.parameters(), lr=1e-3)
    mse_loss = nn.MSELoss()
    
    # Features del estilo (precalculados)
    with torch.no_grad():
        style_features = extractor(style_image)
        style_grams = [gram_matrix(f) for f in style_features]
    
    for epoch in range(num_epochs):
        total_content_loss = 0
        total_style_loss = 0
        
        for i, content in enumerate(content_images):
            # Forward pass
            generated = transform_net(content)
            gen_features = extractor(generated)
            
            # Content loss
            content_loss = mse_loss(gen_features[-1], gen_features[-1].detach())
            
            # Style loss
            style_loss = 0
            for gen_f, style_gram in zip(gen_features, style_grams):
                gen_gram = gram_matrix(gen_f)
                style_loss += mse_loss(gen_gram, style_gram)
            
            # Total loss
            loss = content_loss + style_weight * style_loss
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_content_loss += content_loss.item()
            total_style_loss += style_loss.item()
        
        print(f"Epoch {epoch}: content_loss={total_content_loss/len(content_images):.4f}, "
              f"style_loss={total_style_loss/len(content_images):.4f}")
    
    return transform_net

Arbitrary Style Transfer con AdaIN

Una limitacion del metodo anterior es que solo puede aplicar un estilo a la vez. Adaptive Instance Normalization (AdaIN) permite transferir estilos arbitrarios en tiempo real.

Adaptive Instance Normalization

La idea es simple: normalizar los features de contenido con las estadisticas (mean, std) del estilo deseado:

AdaIN(c, s) = sigma_s * (c - mu_c) / sigma_c + mu_s

class AdaIN(nn.Module):
    """Adaptive Instance Normalization."""
    
    def forward(self, content_features, style_features):
        # Calcular estadisticas del estilo
        style_mean = style_features.mean(dim=[2, 3], keepdim=True)
        style_std = style_features.std(dim=[2, 3], keepdim=True) + 1e-6
        
        # Normalizar contenido con estadisticas del estilo
        content_mean = content_features.mean(dim=[2, 3], keepdim=True)
        content_std = content_features.std(dim=[2, 3], keepdim=True) + 1e-6
        
        normalized = (content_features - content_mean) / content_std
        return normalized * style_std + style_mean

class ArbitraryStyleTransferNet(nn.Module):
    """Red para arbitrary style transfer con AdaIN."""
    
    def __init__(self):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(3, 64, 7, padding=3),
            nn.InstanceNorm2d(64),
            nn.ReLU(),
            nn.Conv2d(64, 128, 3, padding=1),
            nn.InstanceNorm2d(128),
            nn.ReLU(),
            nn.Conv2d(128, 256, 3, padding=1),
            nn.InstanceNorm2d(256),
            nn.ReLU(),
        )
        
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(256, 128, 3, padding=1),
            nn.InstanceNorm2d(128),
            nn.ReLU(),
            nn.ConvTranspose2d(128, 64, 3, padding=1),
            nn.InstanceNorm2d(64),
            nn.ReLU(),
            nn.ConvTranspose2d(64, 3, 7, padding=3),
            nn.Sigmoid()
        )
        
        self.adain = AdaIN()
        
    def encode(self, x):
        return self.encoder(x)
    
    def decode(self, x):
        return self.decoder(x)
    
    def forward(self, content, style):
        content_features = self.encode(content)
        styled_features = self.adain(content_features, style)
        return self.decode(styled_features)

WAH 3D-GANs y Style Transfer

Las GANs han revolucionado el style transfer, especialmente para videos y 3D:

class StyleGANGenerator(nn.Module):
    """Generator estilo StyleGAN para transfer de estilo."""
    
    def __init__(self, latent_dim=512, style_dim=512):
        super().__init__()
        self.latent_dim = latent_dim
        self.style_dim = style_dim
        
        # Mapping network
        self.mapping = nn.Sequential(
            nn.Linear(latent_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, style_dim * 2)  # mean y std por capa
        )
        
        # Synthesis network con adaptive style injection
        self.synthesis = SynthesisNetwork(style_dim)
        
    def forward(self, z, styles=None):
        # Mapear z a estilos
        w = self.mapping(z)
        
        if styles is None:
            # Usar w como estilos inyectados
            styles = w.chunk(2, dim=1)
        
        return self.synthesis(styles)
    
class SynthesisBlock(nn.Module):
    """Bloque de sintesis con injection de estilo."""
    
    def __init__(self, in_channels, out_channels, style_dim):
        super().__init__()
        self.conv = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.noise = NoiseInjection()
        self.activation = nn.LeakyReLU(0.2)
        self.style_scale = nn.Linear(style_dim, out_channels)
        self.style_bias = nn.Linear(style_dim, out_channels)
        
    def forward(self, x, style):
        x = self.conv(x)
        x = self.noise(x)
        
        # Aplicar estilo como escala y bias
        scale = self.style_scale(style).unsqueeze(-1).unsqueeze(-1)
        bias = self.style_bias(style).unsqueeze(-1).unsqueeze(-1)
        
        return self.activation(x * scale + bias)

Applications

  • Arte generativo: Crear obras unicas combinando estilos
  • Photo enhancement: Aplicar estilos artisticos a fotos
  • Video stylization: Aplicar estilos consistentes a videos cuadro por cuadro
  • 3D texturing: Aplicar estilos a geometrias 3D
  • Fashion: Diseño de ropa con estilos artisticos

Resumen

El Style Transfer es una de las aplicaciones mas fascinantes del deep learning para arte. Desde el metodo original de Gatys hasta los avances con AdaIN y StyleGANs, la tecnologia ha evolucionado para ser mas rapida y flexible.

La clave matematica esta en separar contenido y estilo usando features de CNNs, y luego recombinar usando perdidas específicas basadas en Gram Matrices o normalizacion adaptativa.
