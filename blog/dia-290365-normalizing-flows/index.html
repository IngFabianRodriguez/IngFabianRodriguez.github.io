3D Reconstruction — De 2D a 3D con AI

17 de octubre de 2026

Intro

Tienes una foto de un objeto. Necesitas un modelo 3D. Hace 5 años, esto requería escaneo con lidars costosos o software de modelado manual que tomaba horas. Hoy, con neural radiance fields (NeRF) y gaussian splatting, puedes generar mallas 3D de calidad desde docenas de fotos en minutos.

Hoy te explico cómo funcionan estas técnicas, qué herramientas puedes usar hoy, y cómo integrar 3D reconstruction en tu workflow de computer vision.

El problema: de píxeles a geometría

Una imagen 2D pierde información. Es una proyección 2D de un mundo 3D. Para reconstruir la geometría original necesitas resolver:

  • Profundidad: qué tan lejos está cada punto
  • Forma: la superficie real del objeto
  • Textura: colores y patrones de la superficie
  • Oclusión: partes ocultas en algunas vistas pero visibles en otras

Los métodos tradicionales usaban múltiples vistas y triangulación (como nuestros ojos). Los métodos modernos con NeRF y gaussian splatting aprenden una representación continua del espacio 3D directamente de las imágenes.

Neural Radiance Fields (NeRF)

NeRF, introducido en 2020, fue un breakthrough. La idea central:

  • Representar una escena como una función continua 5D: posición (x,y,z) + dirección (θ,φ)
  • La red neural aprende a predecir color y densidad para cada punto en el espacio
  • Para renderizar, se hace ray marching a través del volumen
import torch
import torch.nn as nn

class NeRFModel(nn.Module):
    """
    NeRF: Neural Radiance Field model.
    
    Input: 5D coordinate (x, y, z, θ, φ)
    Output: RGB color + density (σ)
    """
    
    def __init__(self, hidden_dim=256):
        super().__init__()
        
        # Input encoding (positional encoding)
        self.L = 10  # Frequencies for positional encoding
        
        # MLP network
        self.network = nn.Sequential(
            nn.Linear(3 + 3 * 2 * self.L, hidden_dim),  # xyz + encoded directions
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim + 1),  # output: density + features
        )
        
    def positional_encoding(self, x, L):
        """Apply positional encoding to input."""
        encoded = [x]
        for l in range(L):
            encoded.append(torch.sin((2 ** l) * x))
            encoded.append(torch.cos((2 ** l) * x))
        return torch.cat(encoded, dim=-1)
    
    def forward(self, x, d):
        """
        Args:
            x: (N, 3) positions in 3D space
            d: (N, 3) ray directions (viewing angles)
        Returns:
            rgb: (N, 3) color values
            sigma: (N, 1) density values
        """
        # Encode inputs
        x_encoded = self.positional_encoding(x, self.L)
        d_encoded = self.positional_encoding(d, 4)  # Fewer frequencies for direction
        
        # Concatenate and pass through network
        h = self.network(torch.cat([x_encoded, d_encoded], dim=-1))
        
        sigma = h[:, 0:1]  # Density
        rgb = h[:, 1:]     # Color
        
        return rgb, sigma


def render_rays(model, rays_o, rays_d, near=0., far=1., num_samples=64):
    """
    Volumetric rendering along rays.
    
    Args:
        model: NeRF model
        rays_o: (N, 3) ray origins (camera positions)
        rays_d: (N, 3) ray directions
        near, far: bounds for sampling
        num_samples: number of points to sample along each ray
    """
    device = rays_o.device
    
    # Generate sample points along each ray
    t = torch.linspace(near, far, num_samples, device=device)
    t = t.expand(len(rays_o), num_samples)  # (N, num_samples)
    
    # Add noise for stochastic sampling
    t = t + torch.rand_like(t) * (far - near) / num_samples
    
    # Compute 3D positions
    points = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t.unsqueeze(-1)
    # points: (N, num_samples, 3)
    
    # Flatten for batch processing
    points_flat = points.reshape(-1, 3)
    dirs_flat = rays_d.unsqueeze(1).expand(-1, num_samples, -1).reshape(-1, 3)
    
    # Query NeRF
    rgb_flat, sigma_flat = model(points_flat, dirs_flat)
    rgb_flat = rgb_flat.reshape(-1, num_samples, 3)
    sigma_flat = sigma_flat.reshape(-1, num_samples)
    
    # Volumetric rendering
    delta = t[:, 1:] - t[:, :-1]
    delta = torch.cat([delta, torch.ones_like(delta[:, :1]) * 1e10], dim=-1)
    
    density = 1. - torch.exp(-sigma_flat * delta)
    
    # Compute weights for each sample
    weights = density * torch.cumprod(
        torch.cat([torch.ones_like(density[:, :1]), 1. - density[:, :-1]], dim=-1),
        dim=-1
    )
    
    # Render RGB and depth
    rgb = (weights.unsqueeze(-1) * rgb_flat).sum(dim=1)
    depth = (weights * t).sum(dim=1)
    
    return rgb, depth

Gaussian Splatting

NeRF tiene un problema: es lento. Renderizar una imagen requiere hundreds of neural network evaluations por píxel. Gaussian Splatting resuelve esto con un enfoque diferente:

  • La escena se representa como un conjunto de 3D Gaussians (elipsoides)
  • Cada Gaussian tiene: posición, covarianza, color, opacidad
  • El rendering es diferenciable y extremadamente rápido (rasterization)
import torch
import torch.nn as nn
from typing import List, Tuple

class Gaussian3D:
    """
    A 3D Gaussian primitive for gaussian splatting.
    
    Attributes:
        mean: (3,) center position
        cov: (3, 3) covariance matrix (symmetric positive definite)
        color: (3,) RGB color
        opacity: (1,) alpha value
    """
    
    def __init__(self, mean: torch.Tensor, cov: torch.Tensor, 
                 color: torch.Tensor, opacity: float):
        self.mean = mean  # (3,)
        self.cov = cov    # (3, 3)
        self.color = color  # (3,)
        self.opacity = opacity  # scalar
        
    @property
    def inv_cov(self):
        """Inverse covariance for faster computation."""
        return torch.inverse(self.cov)


class GaussianSplattingRenderer:
    """
    Differentiable Gaussian Splatting renderer.
    """
    
    def __init__(self, image_height: int, image_width: int, focal: float):
        self.H = image_height
        self.W = image_width
        self.focal = focal
    
    def project_gaussian(self, gaussian: Gaussian3D, 
                        camera_matrix: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor, float]:
        """
        Project 3D Gaussian to 2D image plane.
        
        Args:
            gaussian: 3D Gaussian to project
            camera_matrix: (3, 4) camera extrinsic matrix [R|t]
            
        Returns:
            center_2d: (2,) 2D center in image coordinates
            cov_2d: (2, 2) 2D covariance
            depth: float depth value
        """
        # Transform center to camera coordinates
        center_cam = camera_matrix @ torch.cat([gaussian.mean, torch.ones(1)])
        depth = center_cam[2].item()
        
        # Project to 2D image plane
        center_2d = center_cam[:2] / center_cam[2] * self.focal
        center_2d[1] = self.H - center_2d[1]  # Flip y for image coordinates
        
        # Transform covariance to camera frame then to 2D
        R = camera_matrix[:3, :3]
        cov_cam = R @ gaussian.cov @ R.T
        
        # Jacobian of perspective projection
        J = torch.tensor([
            [self.focal / depth, 0],
            [0, -self.focal / depth]
        ], device=cov_cam.device)
        
        # 2D covariance
        cov_2d = J @ cov_cam[:2, :2] @ J.T
        
        return center_2d, cov_2d, depth
    
    def compute_alpha(self, gaussian: Gaussian3D, point_2d: torch.Tensor,
                      cov_2d: torch.Tensor) -> float:
        """
        Compute alpha value for a 2D point under this Gaussian.
        
        Uses the Mahalanobis distance: exp(-0.5 * d^T * Σ^-1 * d)
        """
        diff = point_2d - gaussian.mean[:2]
        inv_cov_2d = torch.inverse(cov_2d)
        mahal_sq = diff @ inv_cov_2d @ diff
        
        alpha = gaussian.opacity * torch.exp(-0.5 * mahal_sq)
        return alpha.item()
    
    def rasterize(self, gaussians: List[Gaussian3D], 
                  camera_matrix: torch.Tensor) -> torch.Tensor:
        """
        Rasterize all Gaussians to an image.
        
        Args:
            gaussians: List of 3D Gaussians
            camera_matrix: (3, 4) camera extrinsic
            
        Returns:
            image: (3, H, W) rendered RGB image
        """
        image = torch.zeros(3, self.H, self.W, device=camera_matrix.device)
        depth_buffer = torch.full((self.H, self.W), float('inf'), device=camera_matrix.device)
        
        for gaussian in gaussians:
            center_2d, cov_2d, depth = self.project_gaussian(gaussian, camera_matrix)
            
            if depth < 0 or depth > depth_buffer[0, 0]:  # Behind camera or occluded
                continue
            
            # Compute bounding box in 2D (3 sigma rule)
            sigma_max = max(torch.linalg.eigvalsh(cov_2d)) ** 0.5
            bbox_size = int(3 * sigma_max) + 1
            
            x_min = max(0, int(center_2d[0]) - bbox_size)
            x_max = min(self.W, int(center_2d[0]) + bbox_size + 1)
            y_min = max(0, int(center_2d[1]) - bbox_size)
            y_max = min(self.H, int(center_2d[1]) + bbox_size + 1)
            
            for y in range(y_min, y_max):
                for x in range(x_min, x_max):
                    point = torch.tensor([x, y], dtype=torch.float32)
                    alpha = self.compute_alpha(gaussian, point, cov_2d)
                    
                    if alpha > 0.01 and depth < depth_buffer[y, x]:
                        depth_buffer[y, x] = depth
                        image[:, y, x] = (1 - alpha) * image[:, y, x] + alpha * gaussian.color
        
        return image

Herramientas disponibles en 2026

COLMAP + OpenCV

El pipeline clásico. COLMAP hace Structure from Motion (SfM) para estimar poses de cámara y reconstruir puntos 3D dispersos. Luego puedes usarMulti-View Stereo (MVS) para generar mallas densas.

# Pipeline típico con COLMAP
import subprocess
import os

def reconstruct_3d_from_images(image_dir, output_dir):
    """
    Reconstruct 3D model from a collection of images.
    
    Pipeline:
    1. Feature extraction
    2. Feature matching
    3. Sparse reconstruction (SfM)
    4. Dense reconstruction (MVS)
    """
    
    # 1. Feature extraction
    subprocess.run([
        'colmap', 'feature_extractor',
        '--database_path', f'{output_dir}/database.db',
        '--image_path', image_dir,
        '--SiftExtraction.use_gpu', '1'
    ])
    
    # 2. Feature matching
    subprocess.run([
        'colmap', 'exhaustive_matcher',
        '--database_path', f'{output_dir}/database.db',
        '--SiftMatching.use_gpu', '1'
    ])
    
    # Create sparse reconstruction directory
    sparse_dir = f'{output_dir}/sparse'
    os.makedirs(sparse_dir, exist_ok=True)
    
    # 3. Sparse reconstruction
    subprocess.run([
        'colmap', 'mapper',
        '--database_path', f'{output_dir}/database.db',
        '--image_path', image_dir,
        '--output_path', sparse_dir
    ])
    
    # 4. Dense reconstruction
    dense_dir = f'{output_dir}/dense'
    os.makedirs(dense_dir, exist_ok=True)
    
    subprocess.run([
        'colmap', 'image_undistorter',
        '--image_path', image_dir,
        '--input_path', f'{sparse_dir}/0',
        '--output_path', dense_dir
    ])
    
    subprocess.run([
        'colmap', 'patch_match_stereo',
        '--workspace_path', dense_dir,
        '--workspace_format', 'COLMAP',
        '--PatchMatchStereo.geom_consistency', 'true'
    ])
    
    subprocess.run([
        'colmap', 'stereo_fusion',
        '--workspace_path', dense_dir,
        '--workspace_format', 'COLMAP',
        '--output_path', f'{dense_dir}/fused.ply'
    ])
    
    return f'{dense_dir}/fused.ply'

Limitaciones y cómo manejarlas

  • Reflections y specular surfaces: NeRF asume que los materiales son Lambertian (difusos). Superficies especulares causan artifacts. Fix: usar más vistas y técnicas de去除 specularity.
  • Lighting: Las sombras y reflections capturadas son parte de la representación. Cambiar el lighting después requiere técnicas adicionales como Scene relighting.
  • Oclusiones: Partes ocultas no pueden reconstruirse. Fix: tomar fotos desde múltiples ángulos, asegurando que cada parte visible en al menos 5-10 imágenes.
  • Textures repetitivas: Patrones como ladrillos o hierba pueden causar drifts. Fix: usar priors geométricos o限制了 el tipo de superficies.
