Vision Transformers - Transformers Para Imagenes

Hagale pues, parcero. Hoy es el Dia 228 y hablamos de Vision Transformers (ViT), aplicando la revolucion de transformers a imagenes. Dejala el cafe.

🎯 Que Es ViT?

Vision Transformer (ViT) aplica la arquitectura transformer a imagenes, tratando cada imagen como una secuencia de patches. Reemplaza las capas convolucionales tradicionales con attention.

Conceptos clave:

  • Patch Embedding: Dividir imagen en patches y linearizarlos
  • Position Embedding: Anadir informacion espacial
  • [CLS] Token: Token especial para clasificacion

📐 Implementacion De ViT

import torch
import torch.nn as nn
from einops import rearrange

class PatchEmbed(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_chans=3, embed_dim=768):
        super().__init__()
        self.img_size = img_size
        self.patch_size = patch_size
        self.num_patches = (img_size // patch_size) ** 2
        
        self.proj = nn.Conv2d(in_chans, embed_dim, 
                             kernel_size=patch_size, 
                             stride=patch_size)
    
    def forward(self, x):
        # x: [B, C, H, W] -> [B, num_patches, embed_dim]
        x = self.proj(x)  # [B, embed_dim, H/P, W/P]
        x = rearrange(x, 'b e h w -> b (h w) e')
        return x

🚀 ViT vs CNNs

# Ventajas de ViT:
# - Mejor transfer learning (pre-training con JFT-300M)
# - Mejor para tareas globais (detectar relaciones entre objetos)
# - Mas interpretable attention maps

# Desventajas:
# - Requiere mas datos para training from scratch
# - Mas costoso computacionalmente
# - Menor eficiencia en imagenes pequenas

⚠️ Errores Comunes

Error 1: Patch Size Muy Grande

El problema: Pierdes detalles locales importantes.

La solucion: 16x16 es standard, pero para imagenes pequenas usa 8x8.
