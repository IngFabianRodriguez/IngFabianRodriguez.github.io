La Visión que No Es Como la Nuestra

Cuando vemos una foto, nuestro cerebro procesa patrones de luz y sombra, reconoce objetos, faces, contextos — todo en milisegundos sin esfuerzo consciente. Las máquinas no tienen esa ventaja evolutiva de millones de años, así que tenemos que enseñarle a partir de matemáticas puras. Computer Vision es exactamente eso: enseñar a los computadores a interpretar imágenes usando álgebra lineal, cálculo y estadística. Y lo más verraco es que lo logran sin "ver" nada — solo procesando números.

Cómo Ve Un Computador Una Imagen?

Una imagen no es más que una matriz de números. Para una imagen a color de 224x224 píxeles, tenemos una matriz de shape (224, 224, 3) — 224 filas, 224 columnas, y 3 canales (Rojo, Verde, Azul). Cada valor va de 0 a 255.

Entonces cuando procesamos una imagen de un gato, el computador no ve un gato — ve algo como esto:

import numpy as np
from PIL import Image

# Cargamos una imagen
img = Image.open('gato.jpg')
img_array = np.array(img)

print(f"Shape: {img_array.shape}")  # (224, 224, 3)
print(f"Tipo de dato: {img_array.dtype}")  # uint8
print(f"Rango de valores: [{img_array.min()}, {img_array.max()}]")

# Normalizamos para deep learning (0 a 1)
img_normalized = img_array / 255.0
print(f"Valores normalizados: [{img_normalized.min():.3f}, {img_normalized.max():.3f}]")

# Accedemos a un pixel específico (fila 100, columna 100)
pixel = img_array[100, 100]
print(f"Pixel [100,100] - R:{pixel[0]}, G:{pixel[1]}, B:{pixel[2]}")

El Corazón de Vision: La Convolución

Si hay una operación que define Computer Vision moderna, es la convolución. Una convolución es básicamente un filtro que se desliza sobre la imagen extrayendo características.

Matemáticamente, para una imagen $I$ y un kernel $K$:

$$ (I * K)_{ij} = \sum_m \sum_n I_{i+m, j+n} \cdot K_{m,n} $$

El kernel es una matriz pequeña (típicamente 3x3 o 5x5) con valores aprendibles. En las primeras capas, estos kernels aprenden a detectar edges, líneas, texturas. En capas más profundas, detectan formas más complejas.

Filtros Clásicos (Sin Aprender)

Antes del deep learning, los filtros se diseñaban a mano. Algunos ejemplos clásicos:

def convolve2d(image, kernel):
    """Convolución 2D manual."""
    h, w = image.shape
    k_h, k_w = kernel.shape
    pad_h, pad_w = k_h // 2, k_w // 2
    
    # Padding
    padded = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='edge')
    result = np.zeros_like(image)
    
    for i in range(h):
        for j in range(w):
            result[i, j] = np.sum(padded[i:i+k_h, j:j+k_w] * kernel)
    
    return result

# Aplicar a una imagen

edges_y = convolve2d(image_gray, sobel_y)

Arquitecturas Que Definieron la Era

LeNet-5 (1998): Todo Empezó Aquí

Yann LeCun desarrolló LeNet-5 para reconocimiento de dígitos manuscritos para el postal service de USA. Esta arquitectura tenía 7 capas y usaba avg pooling — parecería primitiva hoy, pero fue revolutionary para su época.

import torch
import torch.nn as nn

class LeNet5(nn.Module):
    """LeNet-5: La primera CNN exitosa."""
    def __init__(self, num_classes=10):
        super().__init__()
        # Conv layers
        self.conv1 = nn.Conv2d(1, 6, kernel_size=5, padding=2)
        self.conv2 = nn.Conv2d(6, 16, kernel_size=5)
        # Fully connected
        self.fc1 = nn.Linear(16 * 5 * 5, 120)
        self.fc2 = nn.Linear(120, 84)
        self.fc3 = nn.Linear(84, num_classes)
        self.pool = nn.AvgPool2d(2)
        self.relu = nn.ReLU()
    
    def forward(self, x):
        # Conv -> Pool -> ReLU
        x = self.pool(self.relu(self.conv1(x)))  # 32x32 -> 14x14
        x = self.pool(self.relu(self.conv2(x)))  # 14x14 -> 5x5
        x = x.view(-1, 16 * 5 * 5)
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.fc3(x)
        return x

AlexNet (2012): La Revolución que Cambió Todo

AlexNet ganó ImageNet con una accuracy del 84.6% — 10 puntos porcentuales mejor que el segundo lugar. Usó ReLU, Dropout, y GPU training. Esta arquitectura demostró que deep learning funcionaba para visión.

class AlexNet(nn.Module):
    """AlexNet: 8 layers, ReLU, Dropout, GPU training."""
    def __init__(self, num_classes=1000):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=11, stride=4, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
            
            nn.Conv2d(64, 192, kernel_size=5, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
            
            nn.Conv2d(192, 384, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            
            nn.Conv2d(384, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            
            nn.Conv2d(256, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2),
        )
        self.avgpool = nn.AdaptiveAvgPool2d((6, 6))
        self.classifier = nn.Sequential(
            nn.Dropout(p=0.5),
            nn.Linear(256 * 6 * 6, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True),
            nn.Linear(4096, num_classes),
        )
    
    def forward(self, x):
        x = self.features(x)
        x = self.avgpool(x)
        x = x.view(x.size(0), -1)
        x = self.classifier(x)
        return x

VGG (2014): Simplicidad Profunda

VGG demostró que redes más profundas con kernels pequeños (3x3) funcionaban mejor. Su insight: dos capas de 3x3 tienen el mismo receptive field que una de 5x5 pero con menos parámetros.

class VGG16(nn.Module):
    """VGG16: Convoluciones 3x3 apiladas."""
    def __init__(self, num_classes=1000):
        super().__init__()
        self.features = nn.Sequential(
            # Block 1: 224 -> 112
            nn.Conv2d(3, 64, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(64, 64, 3, padding=1), nn.ReLU(inplace=True),
            nn.MaxPool2d(2, stride=2),
            
            # Block 2: 112 -> 56
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(128, 128, 3, padding=1), nn.ReLU(inplace=True),
            nn.MaxPool2d(2, stride=2),
            
            # Block 3: 56 -> 28
            nn.Conv2d(128, 256, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, 3, padding=1), nn.ReLU(inplace=True),
            nn.MaxPool2d(2, stride=2),
            
            # Block 4 & 5...
        )
        self.avgpool = nn.AdaptiveAvgPool2d((7, 7))
        self.classifier = nn.Sequential(
            nn.Linear(512 * 7 * 7, 4096), nn.ReLU(inplace=True), nn.Dropout(),
            nn.Linear(4096, 4096), nn.ReLU(inplace=True), nn.Dropout(),
            nn.Linear(4096, num_classes),
        )

# 138M parámetros vs AlexNet's 60M — más profundo pero más simple

ResNet (2015): El Skip Connection Que Hizo Possible 1000 Capas

El problema de redes profundas es que se vuelven difíciles de entrenar por el vanishing gradient. ResNet resolvió esto con skip connections (residual connections):

$$ y = F(x) + x $$

En lugar de aprender $H(x)$ directamente, aprendemos $F(x) = H(x) - x$ (el residual). Esto hace que el gradient fluya directamente sin pasar por todas las capas.

class ResidualBlock(nn.Module):
    """Bloque residual básico."""
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        # Skip connection
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )
    
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # Skip connection!
        out = torch.relu(out)
        return out

Tareas Comunes en Computer Vision

  • Classification: Qué objeto hay en la imagen? (La más básica)
  • Object Detection: Dónde están los objetos y qué son? (YOLO, Faster R-CNN)
  • Semantic Segmentation: Clasificar cada píxel (Fully Convolutional Networks)
  • Instance Segmentation: Diferenciar instancias del mismo objeto (Mask R-CNN)
  • Pose Estimation: Detectar keypoints del cuerpo humano
  • Image Generation: Crear imágenes (GANs, Diffusion Models)

El Error Que El 80% Commete

Usar una arquitectura genérica sin considerar el trade-off accuracy vs speed. No necesitas un ResNet-152 para detectar si hay un gato en una imagen. Un MobileNet puede ser 10x más rápido con 95% de la accuracy. Siempre pregúntate: dónde va a correr mi modelo? Si es en edge devices, la eficiencia importa más que la última точность.
