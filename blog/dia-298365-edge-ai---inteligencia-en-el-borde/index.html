La Matemática del Análisis de Datos que Todos Ignoran

Mientras el mundo hablaba de chatbots y generación de imágenes, en Bogotá una analista de datos llamada Carolina gastaba 6 horas diarias haciendo lo mismo: copiar datos de Excel a Python, correr scripts de pandas, graficar en matplotlib, copiar resultados a PowerPoint. 6 horas. De lunes a viernes. 30 horas semanales de trabajo que un LLM bien configurado hace en 40 minutos.

El 80% de los profesionales de datos no usa LLMs para analytics. El 20% restante está 10x más productivo. Hoy te muestro cómo joining that 20% — sin perder tu empleo, sin simplificar demasiado, y con la seriedad que merecen tus datos.

La fórmula del análisis de datos asistido por LLM es:
Insight_Value = Σ(Data_Quality × LLM_Context × Verification_Depth)

Data_Quality es qué tan limpios están tus datos (0-1). LLM_Context es qué tanto contexto le das al modelo (0-1). Verification_Depth es cuánto verificas los resultados (0-1). El resultado máximo es 3.0. Si sacas menos de 1.5, estás trabajando con insights que probablemente son ruido.

¿Por Qué el 80% No Usa LLMs para Analytics?

Porque les da miedo. Miedo de que el LLM alucine números. Miedo de que genere insights falsos. Miedo de que alguien descubra que están usando IA y piense que están jugando.bekommt Esos miedos son válidos — pero la solución no es no usar IA. La solución es usar IA con verificación.

Hay tres problemas reales:

  1. Los LLMs no calculan bien números crudos — Pueden describir tendencias, pero si le pides que sume 2.5 millones de filas, va a fallar.
  2. Pueden alucinar correlaciones — "Los días que llueve hay más ventas de paraguas" es obvio. Pero "los días que llueve hay más ventas de cerveza" podría ser una correlación espuria.
  3. No saben de tu dominio — Si no les dices que en tu empresa "rechazo" significa otra cosa, van a asumir lo genérico.

La solución no es远离 (alejarse) de los LLMs. Es usarlos como asistente de pensamiento, no como calculadora.

Framework de Análisis de Datos con LLMs

Este framework usa LLMs para las partes que hacen sentido: exploración, generación de hypotheses, escritura de código, y comunicación de resultados. Los cálculos pesados se hacen con Python/Pandas real.

"""
DataMind: Framework de análisis de datos asistido por LLM
Usa Claude para exploración, hipótesis y comunicación.
Python/Pandas para cálculos reales.
"""

import anthropic
import pandas as pd
import numpy as np
import re
import json
from typing import Dict, List, Optional, Tuple, Any
from dataclasses import dataclass, field
from enum import Enum
import sqlite3

client = anthropic.Anthropic()

class InsightType(Enum):
    CORRELATION = "correlation"
    TREND = "trend"
    OUTLIER = "outlier"
    DISTRIBUTION = "distribution"
    COMPARISON = "comparison"
    ANOMALY = "anomaly"

@dataclass
class DataInsight:
    insight_type: InsightType
    description: str
    evidence: Dict[str, Any]
    confidence: float  # 0-1
    verified: bool
    requires_attention: bool
    business_impact: str

@dataclass
class AnalysisResult:
    dataset_name: str
    row_count: int
    column_count: int
    summary: str
    insights: List[DataInsight]
    visualizations_suggested: List[str]
    next_steps: List[str]
    llm_model: str
    verification_log: List[str]

class EDAReport:
    """Genera un reporte de Análisis Exploratorio de Datos (EDA) con LLM."""

    def __init__(self, model: str = "claude-sonnet-4-20250514"):
        self.client = anthropic.Anthropic()
        self.model = model

    def generate_eda(
        self,
        df: pd.DataFrame,
        dataset_name: str = "dataset",
        target_column: Optional[str] = None,
        business_context: Optional[str] = None
    ) -> AnalysisResult:
        """
        Genera un reporte EDA completo asistido por LLM.

        Args:
            df: DataFrame de pandas con los datos
            dataset_name: Nombre del dataset para el reporte
            target_column: Columna objetivo (si existe)
            business_context: Contexto del negocio para mejor interpretación
        """

        # 1. Análisis estadístico básico con Python real
        basic_stats = self._compute_basic_stats(df)
        missing_data = self._analyze_missing(df)
        correlations = self._compute_correlations(df, target_column)
        distributions = self._analyze_distributions(df)

        # 2. Generar descripciones con LLM
        column_descriptions = self._describe_columns(df, business_context)

        # 3. Generar insights con LLM
        insights = self._generate_insights(
            df, basic_stats, missing_data, correlations,
            distributions, column_descriptions, target_column, business_context
        )

        # 4. Verificar insights con cálculos reales
        verified_insights = self._verify_insights(df, insights)

        # 5. Generar visualizaciones sugeridas
        visualizations = self._suggest_visualizations(
            insights, df, target_column
        )

        # 6. Generar summary con LLM
        summary = self._generate_summary(
            df, basic_stats, verified_insights, business_context
        )

        return AnalysisResult(
            dataset_name=dataset_name,
            row_count=len(df),
            column_count=len(df.columns),
            summary=summary,
            insights=verified_insights,
            visualizations_suggested=visualizations,
            next_steps=self._suggest_next_steps(verified_insights),
            llm_model=self.model,
            verification_log=[f"Insight {i+1}: {'Verificado' if v.verified else 'No verificado - requiere revisión'}"
                              for i, v in enumerate(verified_insights)]
        )

    def _compute_basic_stats(self, df: pd.DataFrame) -> Dict[str, Any]:
        """Computa estadísticas básicas con pandas real."""

        stats = {}
        numeric_cols = df.select_dtypes(include=[np.number]).columns

        stats['row_count'] = len(df)
        stats['column_count'] = len(df.columns)
        stats['numeric_columns'] = list(numeric_cols)
        stats['categorical_columns'] = list(df.select_dtypes(include=['object', 'category']).columns)

        stats['numeric_summary'] = {}
        for col in numeric_cols:
            stats['numeric_summary'][col] = {
                'mean': float(df[col].mean()),
                'median': float(df[col].median()),
                'std': float(df[col].std()),
                'min': float(df[col].min()),
                'max': float(df[col].max()),
                'q25': float(df[col].quantile(0.25)),
                'q75': float(df[col].quantile(0.75))
            }

        return stats

    def _analyze_missing(self, df: pd.DataFrame) -> Dict[str, Any]:
        """Analiza datos faltantes."""

        missing = {}
        for col in df.columns:
            null_count = df[col].isnull().sum()
            if null_count > 0:
                missing[col] = {
                    'count': int(null_count),
                    'percentage': float(null_count / len(df) * 100)
                }

        return missing

    def _compute_correlations(
        self,
        df: pd.DataFrame,
        target_column: Optional[str] = None
    ) -> Dict[str, Any]:
        """Computa correlaciones con pandas real."""

        numeric_df = df.select_dtypes(include=[np.number])

        if numeric_df.empty:
            return {}

        corr_matrix = numeric_df.corr()

        # Solo devolver correlaciones fuertes
        strong_correlations = []
        for i in range(len(corr_matrix.columns)):
            for j in range(i+1, len(corr_matrix.columns)):
                corr_value = corr_matrix.iloc[i, j]
                if abs(corr_value) >= 0.5:
                    strong_correlations.append({
                        'var1': corr_matrix.columns[i],
                        'var2': corr_matrix.columns[j],
                        'correlation': float(corr_value)
                    })

        return {
            'strong_correlations': strong_correlations,
            'full_matrix': corr_matrix.to_dict()
        }

    def _analyze_distributions(self, df: pd.DataFrame) -> Dict[str, Any]:
        """Analiza distribuciones de columnas."""

        distributions = {}
        numeric_cols = df.select_dtypes(include=[np.number]).columns

        for col in numeric_cols:
            data = df[col].dropna()
            if len(data) < 3:
                continue

            # Calcular asimetría y curtosis
            from scipy import stats as scipy_stats
            skewness = float(scipy_stats.skew(data))
            kurtosis = float(scipy_stats.kurtosis(data))

            distributions[col] = {
                'skewness': skewness,
                'kurtosis': kurtosis,
                'likely_normal': abs(skewness) < 2 and abs(kurtosis) < 7
            }

        return distributions

    def _describe_columns(
        self,
        df: pd.DataFrame,
        business_context: Optional[str] = None
    ) -> Dict[str, str]:
        """Usa LLM para describir columnas en lenguaje natural."""

        descriptions = {}

        # Procesar en batches de 10 columnas
        columns = list(df.columns)
        for i in range(0, len(columns), 10):
            batch = columns[i:i+10]

            prompt = f"""Dataset tiene las siguientes columnas:\n"""
            for col in batch:
                dtype = str(df[col].dtype)
                unique = df[col].nunique()
                sample = df[col].dropna().head(3).tolist()
                prompt += f"- {col}: tipo={dtype}, únicos={unique}, ejemplos={sample}\n"

            if business_context:
                prompt += f"\nContexto del negocio: {business_context}\n"

            prompt += """\nPara cada columna, escribe una descripción breve (1-2 líneas) de qué representa.
Sé específico. Si es una fecha, di qué rango. Si es numérica, di qué unidad o escala.
Si es categórica, lista las categorías principales."""

            response = self.client.messages.create(
                model=self.model,
                max_tokens=1024,
                system="Eres un data analyst experto. Describe columnas de datos de forma clara y precisa.",
                messages=[{"role": "user", "content": prompt}]
            )

            # Parsear la respuesta
            lines = response.content[0].text.split('\n')
            for line in lines:
                for col in batch:
                    if col.lower() in line.lower() or line.startswith('-'):
                        descriptions[col] = line

        return descriptions

    def _generate_insights(
        self,
        df: pd.DataFrame,
        basic_stats: Dict,
        missing_data: Dict,
        correlations: Dict,
        distributions: Dict,
        column_descriptions: Dict,
        target_column: Optional[str],
        business_context: Optional[str]
    ) -> List[DataInsight]:
        """Genera insights usando LLM basado en el análisis estadístico."""

        # Preparar contexto para el LLM
        context = f"""Análisis estadístico de dataset '{basic_stats['row_count']}' filas x '{basic_stats['column_count']}' columnas.

Estadísticas numéricas:
{json.dumps(basic_stats['numeric_summary'], indent=2)}

Datos faltantes:
{json.dumps(missing_data, indent=2)}

Correlaciones fuertes (|r| >= 0.5):
{json.dumps(correlations.get('strong_correlations', []), indent=2)}

Distribuciones:
{json.dumps(distributions, indent=2)}

"""

        if business_context:
            context += f"Contexto del negocio: {business_context}\n"

        if target_column:
            context += f"Columna objetivo para análisis: {target_column}\n"

        context += """Basado en el análisis estadístico, identifica los 5 insights más importantes.
Para cada insight indica:
1. Tipo (correlation, trend, outlier, distribution, comparison, anomaly)
2. Descripción clara
3. Evidencia numérica específica
4. Nivel de confianza (0-1)
5. Impacto de negocio potencial

Formatea como JSON array."""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=2048,
            system="""Eres un data analyst senior con 15 años de experiencia.
Generas insights accionables basados en análisis estadístico.
Siempre verificas que los insights tengan sentido numérico.
Nunca alucinas números.""",
            messages=[{"role": "user", "content": context}]
        )

        # Parsear insights del JSON
        insights = []
        try:
            # Intentar extraer JSON de la respuesta
            text = response.content[0].text
            json_match = re.search(r'\[.*\]', text, re.DOTALL)
            if json_match:
                insights_data = json.loads(json_match.group())
                for item in insights_data:
                    insights.append(DataInsight(
                        insight_type=InsightType(item.get('tipo', 'trend')),
                        description=item.get('descripcion', ''),
                        evidence=item.get('evidencia', {}),
                        confidence=item.get('confianza', 0.5),
                        verified=False,
                        requires_attention=item.get('confianza', 0.5) < 0.7,
                        business_impact=item.get('impacto_negocio', '')
                    ))
        except json.JSONDecodeError:
            # Si falla el parsing, crear un insight genérico
            insights.append(DataInsight(
                insight_type=InsightType.TREND,
                description="Revisar insights manualmente - error en parsing",
                evidence={},
                confidence=0.0,
                verified=False,
                requires_attention=True,
                business_impact=""
            ))

        return insights

    def _verify_insights(
        self,
        df: pd.DataFrame,
        insights: List[DataInsight]
    ) -> List[DataInsight]:
        """Verifica cada insight con cálculos reales."""

        verified = []

        for insight in insights:
            try:
                # Verificar con pandas real
                if insight.insight_type == InsightType.CORRELATION:
                    # Recalcular correlación mentioned
                    if 'var1' in insight.evidence and 'var2' in insight.evidence:
                        var1, var2 = insight.evidence['var1'], insight.evidence['var2']
                        if var1 in df.columns and var2 in df.columns:
                            actual_corr = float(df[var1].corr(df[var2]))
                            insight.evidence['verified_correlation'] = actual_corr
                            insight.verified = abs(actual_corr) >= 0.3

                elif insight.insight_type == InsightType.OUTLIER:
                    # Verificar outliers mencionados
                    if 'column' in insight.evidence and 'threshold' in insight.evidence:
                        col = insight.evidence['column']
                        threshold = insight.evidence['threshold']
                        if col in df.columns:
                            outlier_count = int((df[col] > threshold).sum())
                            insight.evidence['verified_outlier_count'] = outlier_count
                            insight.verified = outlier_count > 0

                # Si no se puede verificar, marcar como no verificado
                if not insight.verified and insight.confidence >= 0.7:
                    insight.requires_attention = True

            except Exception as e:
                insight.evidence['verification_error'] = str(e)

            verified.append(insight)

        return verified

    def _suggest_visualizations(
        self,
        insights: List[DataInsight],
        df: pd.DataFrame,
        target_column: Optional[str]
    ) -> List[str]:
        """Sugiere visualizaciones basadas en los insights."""

        suggestions = []

        for insight in insights:
            if insight.insight_type == InsightType.CORRELATION:
                if 'var1' in insight.evidence and 'var2' in insight.evidence:
                    suggestions.append(
                        f"Scatter plot: {insight.evidence['var1']} vs {insight.evidence['var2']}"
                    )

            elif insight.insight_type == InsightType.TREND:
                if target_column:
                    suggestions.append(f"Line chart: {target_column} over time")

            elif insight.insight_type == InsightType.DISTRIBUTION:
                for col in df.select_dtypes(include=[np.number]).columns:
                    suggestions.append(f"Histogram: {col}")

            elif insight.insight_type == InsightType.OUTLIER:
                if 'column' in insight.evidence:
                    suggestions.append(f"Box plot: {insight.evidence['column']}")

        # Deduplicar
        return list(set(suggestions))[:6]

    def _generate_summary(
        self,
        df: pd.DataFrame,
        basic_stats: Dict,
        insights: List[DataInsight],
        business_context: Optional[str]
    ) -> str:
        """Genera un resumen ejecutivo con LLM."""

        top_insights = sorted(insights, key=lambda x: x.confidence, reverse=True)[:3]

        prompt = f"""Genera un resumen ejecutivo de 3-4 párrafos para un análisis de datos.

Dataset: {basic_stats['row_count']} filas, {basic_stats['column_count']} columnas.
Columnas numéricas: {', '.join(basic_stats['numeric_columns'][:5])}
Columnas categóricas: {', '.join(basic_stats['categorical_columns'][:5])}

Top 3 insights:
{chr(10).join([f"- {i.description} (confianza: {i.confidence:.0%})" for i in top_insights])}

"""

        if business_context:
            prompt += f"Contexto: {business_context}\n"

        prompt += """El resumen debe:
- Ser accesible para un ejecutivo no técnico
- Destacar los 2-3 hallazgos más importantes
- Mencionar el impacto de negocio potencial
- Sugerir acciones concretas

No menciones métodos estadísticos. Habla en lenguaje de negocio."""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=1024,
            system="Eres un data analyst que traduce análisis técnico en insights de negocio.",
            messages=[{"role": "user", "content": prompt}]
        )

        return response.content[0].text

    def _suggest_next_steps(self, insights: List[DataInsight]) -> List[str]:
        """Sugiere próximos pasos basado en insights."""

        suggestions = []

        for insight in insights:
            if insight.requires_attention:
                suggestions.append(f"Investigar a fondo: {insight.description}")

        if len(insights) < 3:
            suggestions.append("Recolectar más datos para análisis más profundo")

        verified_count = sum(1 for i in insights if i.verified)
        if verified_count > 0:
            suggestions.append(f"Compartir insights verificados ({verified_count}) con stakeholders")

        return suggestions[:5]


def natural_language_query(
    df: pd.DataFrame,
    question: str,
    model: str = "claude-sonnet-4-20250514"
) -> str:
    """
    Responde preguntas sobre el dataset en lenguaje natural.
    """

    # Generar descripción del dataset
    stats = {
        'rows': len(df),
        'columns': list(df.columns),
        'dtypes': {col: str(dtype) for col, dtype in df.dtypes.items()},
        'numeric_summary': {}
    }

    for col in df.select_dtypes(include=[np.number]).columns:
        stats['numeric_summary'][col] = {
            'mean': float(df[col].mean()),
            'min': float(df[col].min()),
            'max': float(df[col].max())
        }

    prompt = f"""Dataset tiene {stats['rows']} filas.
Columnas: {', '.join(stats['columns'])}

Estadísticas clave:
{json.dumps(stats, indent=2)}

Pregunta: {question}

Responde la pregunta usando los datos. Si necesitas calcular algo específico,
indica qué cálculo harías pero no lo hagas tú.
Sé preciso con los números."""

    response = client.messages.create(
        model=model,
        max_tokens=1024,
        system="Eres un data analyst respondiendo preguntas sobre un dataset.",
        messages=[{"role": "user", "content": prompt}]
    )

    return response.content[0].text

Los 3 Errores Críticos al Usar LLMs para Analytics



Error 1: No Usar LLMs para Analytics Cuando Deberías



El primer error es no usar LLMs cuando podrían multiplicar tu productividad. Si estás copiando datos de Excel a Python manualmente, si estás escribiendo el mismo script de pandas por decimoquinta vez, si estás pasando horas escribiendo reportes que siguen el mismo formato — estás desperdiciando tiempo que un LLM maneja en segundos.



Las tareas donde LLMs brillan en analytics:



    

  • EDA automático — ¿Cuántas columnas tiene? ¿Cuáles son numéricas? ¿Hay missing data? Un LLM con acceso a un DataFrame te responde en 10 segundos.
    • 

  • Generación de código Pandas — "Filtra las ventas del Q3 donde el cliente es tipo A y el descuento fue mayor al 15%" → código en 5 segundos.
    • 

  • Interpretación de resultados — Tienes un p-value de 0.03, ¿eso qué significa para mi negocio?
    • 

  • Comunicación de insights — Convertir "r=-0.65 entre descuento y margen" en "a mayor descuento, menor ganancia".
    • 




Fix: Identifica las tareas repetitivas en tu workflow de datos. Cada vez que copies algo que hiciste antes, pregúntate: ¿esto lo puede hacer un LLM? La respuesta probablemente es sí.



Error 2: Confiar en Insights de LLMs Sin Verificación



El segundo error — el más peligroso — es creer ciegamente lo que el LLM te dice sobre tus datos. Los LLMs alucinan. Pueden decirte que hay una correlación fuerte entre dos variables cuando en realidad no existe. Pueden malinterpretar un código categórico. Pueden inventarse un número.



La verificación no es opcional. Es obligatoria. Siempre.



Mi workflow de verificación:



    

  1. Todo cálculo numérico se hace con Python/Pandas real — El LLM sugiere, Python verifica.
    2. 

  2. Todo insight va acompañado de evidencia — "Hay correlación" no basta. ¿Cuál es el valor de r? ¿Cuántas observaciones?
    3. 

  3. Los outliers se recalculan — Si el LLM dice que hay outliers, corro un describe() y verifico.
    4. 

  4. Los insights de negocio se contextúan — "Este mes bajó 20%" necesita contexto: ¿estacionalidad? ¿campaña? ¿error de datos?
    5. 




Fix: Antes de presentar cualquier insight generado por LLM, haz al menos una verificación rápida en Python. Si el número no cuadra, el insight no vale.



Error 3: No Saber Cómo Hacer Prompts Efectivos para Analytics



El tercer error es pedirle al LLM "analiza estos datos" y esperar magia. No funciona así. La calidad del output depende de la calidad del input. Un buen prompt para analytics incluye:



    

  • Contexto del negocio — ¿Qué representa cada columna? ¿Cuál es el objetivo del análisis?
    • 

  • Restricciones — ¿Hay alguna variable que no debe considerarse? ¿Algún threshold específico?
    • 

  • Formato esperado — ¿Quieres código? ¿Un resumen? ¿Un JSON con insights?
    • 

  • Verificación — "Primero calcula X, luego verifica con Y, luego genera Z"
    • 




La fórmula de un buen prompt de analytics:



Prompt_Bueno = Contexto + Datos_Clave + Pregunta_Específica + Formato_Solicitado + Verificación_Solicitada



Fix: Practica escribir prompts estructurados. No pidas "analiza". Pide "Dado [contexto], usando [datos], calcula [métrica], verifica [contra], y presenta [formato]". La diferencia en resultados es de 10x.



Resumen: Cómo Hacerlo Bien



El análisis de datos con LLMs no es "pregúntale a ChatGPT". Es un workflow estructurado:



    

  1. Prepara — Limpia tus datos. El LLM no arregla garbage in.
    2. 

  2. Contextualiza — Dale al LLM el contexto del negocio, no solo los números.
    3. 

  3. Genera — Pide código, insights, visualizaciones, resúmenes.
    4. 

  4. Verifica — Todo número se recalcula. Todo insight se comprueba.
    5. 

  5. Comunica — Usa el LLM para traducir técnica a negocio.
    6. 




El 20% que lo hace bien sigue estos pasos. El 80% le pregunta a ChatGPT cosas vagasy luego se sorprende cuando los insights no cuadran. No seas del 80%.






Cierre Colombiano



Y bueno, hermano, hasta aquí llegamos hoy. Aprendimos que los LLMs para datos son como el agua tibia: si los usas bien, son mortales (en el buen sentido). Si los usas mal, te quemas. La clave está en no pretender que son oracle infinitos — son asistentes. Asisten. Tú decides.



Así como en la vida: no todo se resolve sozinho. A veces necesitas ayuda, pero al final quien responde por el resultado eres tú. Lo mismo con los LLMs — pídele la opinión, pero verifica los números con tu propia cabeza y con Python.
