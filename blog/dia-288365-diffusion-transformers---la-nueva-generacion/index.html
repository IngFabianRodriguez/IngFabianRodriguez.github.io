Diffusion Transformers - La Nueva Generacion

15 de octubre de 2026
ditdiffusiontransformersgenerative

Intro

Stable Diffusion cambió todo cuando llegó en 2022 — generación de imágenes por diffusión accesible para todos. Pero había un problema: la arquitectura U-Net que usaba era un cuello de botella. Funcionaba, pero los modelos basados en U-Net tenían dificultades con detalles finos, composición, y coherencia global. Entraban en conflicto la eficiencia computacional y la calidad.

En 2023, Stability AI publicó DiT (Diffusion Transformer) — una arquitectura que reemplaza la U-Net tradicional con un transformer. El paper "Scalable Diffusion Models with Transformers" demostró que los transformers no solo igualaban a las U-Nets, sino que las superaban significativamente en calidad de imagen cuando se escalaban. Y lo más importante: escalaban mejor. Más parámetros = mejor calidad de manera más predecible que con U-Nets.

Hoy vamos a entender cómo funcionan los Diffusion Transformers (DiT), por qué superan a las U-Nets, y cómo implementarlos.

De U-Net a Transformer: por qué el cambio

La diffusión tradicional usa una U-Net para predecir el ruido en cada paso denoising. La U-Net tiene una estructura de encoder-decoder con skip connections que funciona bien para muchas tareas, pero tiene limitaciones:

  • No escala tan bien: añadir más parámetros no mejora la calidad proporcionalmente
  • Difícil capturar dependencias globales: las skip connections priorizan información local
  • Menos eficiente en hardware moderno: las operaciones convolucionales no se aprovechan tan bien de TPUs y GPUs modernas

Los transformers, por otro lado, escalan excepcionalmente bien — eso lo demostró GPT, eso lo demostró ViT. Si funciona para texto e imágenes, ¿por qué no para difusión?

Arquitectura DiT

Componentes principales

DiT reemplaza la U-Net con un Vision Transformer (ViT) modificado. Los componentes clave:

import torch
import torch.nn as nn
from einops import rearrange

class DiTBlock(nn.Module):
    """
    Transformer block para DiT. Incluye:
    - Self-attention sobre la imagen tokenizada
    - Cross-attention sobre el conditioning (ej. timestep embedding)
    - Feedforward MLP
    """
    def __init__(self, hidden_size, num_heads=16, mlp_ratio=4.0):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_size)
        self.norm2 = nn.LayerNorm(hidden_size)
        self.norm3 = nn.LayerNorm(hidden_size)
        
        self.attn = nn.MultiheadAttention(hidden_size, num_heads, batch_first=True)
        self.cross_attn = nn.MultiheadAttention(hidden_size, num_heads, batch_first=True)
        
        mlp_hidden = int(hidden_size * mlp_ratio)
        self.mlp = nn.Sequential(
            nn.Linear(hidden_size, mlp_hidden),
            nn.GELU(),
            nn.Linear(mlp_hidden, hidden_size)
        )
    
    def forward(self, x, condition):
        # Self-attention con norm
        x = x + self.attn(self.norm1(x), self.norm1(x), self.norm1(x))[0]
        
        # Cross-attention con conditioning (timestep, class, etc.)
        x = x + self.cross_attn(self.norm2(x), condition, condition)[0]
        
        # MLP con norm
        x = x + self.mlp(self.norm3(x))
        
        return x


class DiT(nn.Module):
    """
    Diffusion Transformer completo.
    """
    def __init__(
        self,
        input_size=32,  # Tamaño de la imagen latente
        patch_size=2,
        hidden_size=1152,
        depth=28,
        num_heads=16,
        in_channels=4,  # Canales del espacio latente ( VAE )
        class_dropout_prob=0.1,
        num_classes=1000,
    ):
        super().__init__()
        self.input_size = input_size
        self.patch_size = patch_size
        self.hidden_size = hidden_size
        self.in_channels = in_channels
        self.out_channels = in_channels
        
        # 1. Patch embedding ( convolutional )
        self.patch_embed = nn.Conv2d(
            in_channels, hidden_size, kernel_size=patch_size, stride=patch_size
        )
        
        # 2. Positional embedding ( learnable )
        num_patches = (input_size // patch_size) ** 2
        self.pos_embed = nn.Parameter(torch.zeros(1, num_patches, hidden_size))
        
        # 3. Timestep embedding ( sinusoidal + MLP )
        self.timestep_embed = TimestepEmbedding(hidden_size)
        
        # 4. Class embedding ( para class-conditional )
        self.class_embed = nn.Sequential(
            nn.Linear(num_classes, hidden_size),
            nn.SiLU(),
            nn.Linear(hidden_size, hidden_size)
        )
        self.class_dropout_prob = class_dropout_prob
        self.use_cfg = True
        
        # 5. Transformer blocks
        self.blocks = nn.ModuleList([
            DiTBlock(hidden_size, num_heads) for _ in range(depth)
        ])
        
        # 6. Output projection
        self.norm_final = nn.LayerNorm(hidden_size)
        self.proj_out = nn.Linear(hidden_size, patch_size * patch_size * in_channels)
        
        # Inicialización
        self.initialize_weights()
    
    def initialize_weights(self):
        # Inicialización de pesos estándar para transformers
        def _basic_init(module):
            if isinstance(module, nn.Linear):
                torch.nn.init.xavier_uniform_(module.weight)
                if module.bias is not None:
                    nn.init.constant_(module.bias, 0)
        
        self.apply(_basic_init)
        
        # Inicializar patch embedding como identidad
        nn.init.constant_(self.patch_embed.bias, 0)
        nn.init.constant_(self.proj_out.bias, 0)
    
    def forward(self, x, timestep, class_labels=None):
        """
        x: (B, C, H, W) imagen latente con ruido
        timestep: (B,) timestep de difusión
        class_labels: (B,) etiquetas de clase para class-conditional
        """
        B, C, H, W = x.shape
        
        # Patch embedding
        x = self.patch_embed(x)  # (B, hidden_size, H/patch, W/patch)
        x = rearrange(x, 'b c h w -> b (h w) c')  # (B, num_patches, hidden_size)
        
        # Add positional embedding
        x = x + self.pos_embed
        
        # Timestep embedding
        t_emb = self.timestep_embed(timestep)  # (B, hidden_size)
        
        # Conditioning
        if self.use_cfg and class_labels is not None:
            # Classifier-free guidance: usar embeddings de clase y null
            if self.training or torch.rand(1) < self.class_dropout_prob:
                null_class = torch.zeros_like(class_labels)
            else:
                null_class = class_labels
            
            c = self.class_embed(null_class) + t_emb
        else:
            c = t_emb
        
        # Expandir conditioning para todos los patches
        c = c.unsqueeze(1)  # (B, 1, hidden_size)
        
        # Transformer blocks
        for block in self.blocks:
            x = block(x, c)
        
        # Output
        x = self.norm_final(x)
        x = self.proj_out(x)  # (B, num_patches, patch_size*patch_size*in_channels)
        
        # Reshape a imagen
        num_patches_h = H // self.patch_size
        num_patches_w = W // self.patch_size
        x = rearrange(
            x,
            'b (h w) (p1 p2 c) -> b c (h p1) (w p2)',
            h=num_patches_h,
            w=num_patches_w,
            p1=self.patch_size,
            p2=self.patch_size,
            c=self.in_channels
        )
        
        return x

Timestep Embedding

El timestep embedding es crucial para que el modelo sepa en qué paso de denoising está:

import math

class TimestepEmbedding(nn.Module):
    """
    Sinusoidal timestep embedding + MLP.
    """
    def __init__(self, hidden_size, max_period=10000):
        super().__init__()
        self.hidden_size = hidden_size
        self.max_period = max_period
        
        self.mlp = nn.Sequential(
            nn.Linear(hidden_size, hidden_size * 4),
            nn.SiLU(),
            nn.Linear(hidden_size * 4, hidden_size)
        )
    
    def forward(self, timestep):
        """
        timestep: (B,) valores de timestep
        """
        half = self.hidden_size // 2
        
        # Crear frecuencias logarítmicas
        freqs = torch.exp(
            -math.log(self.max_period) * torch.arange(0, half, dtype=torch.float32, device=timestep.device) / half
        )
        
        # Crear embedding sinusoidal
        args = timestep[:, None].float() * freqs[None]  # (B, half)
        embedding = torch.cat([torch.cos(args), torch.sin(args)], dim=-1)  # (B, hidden_size)
        
        # MLP
        embedding = self.mlp(embedding)
        
        return embedding

Training y Sampling

Training Loop

El training de DiT es similar a cualquier modelo de difusión:

def train_step(model, batch, optimizer, scheduler, device):
    """
    Un paso de entrenamiento para DiT.
    """
    model.train()
    images, classes = batch
    images = images.to(device)
    classes = classes.to(device)
    
    B = images.size(0)
    
    # Sample timestep aleatorio
    t = torch.randint(0, num_timesteps, (B,), device=device)
    
    # Sample ruido
    noise = torch.randn_like(images)
    
    # Añadir ruido a imagen limpia ( forward diffusion )
    alpha_cumprod = get_alpha_cumprod(t)  # schedule de ruido
    sqrt_alpha = torch.sqrt(alpha_cumprod)
    sqrt_one_minus_alpha = torch.sqrt(1 - alpha_cumprod)
    
    noisy_images = sqrt_alpha.view(B, 1, 1, 1) * images + \
                    sqrt_one_minus_alpha.view(B, 1, 1, 1) * noise
    
    # Predecir ruido ( DiT predice el ruido, no la imagen )
    predicted_noise = model(noisy_images, t, classes)
    
    # Loss: MSE entre ruido predicho y ruido real
    loss = nn.functional.mse_loss(predicted_noise, noise)
    
    # Backprop
    optimizer.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
    scheduler.step()
    
    return loss.item()


def get_alpha_cumprod(timesteps, beta_start=0.0001, beta_end=0.02, num_timesteps=1000):
    """
    Crear schedule de betas y calcular alpha_cumprod.
    """
    betas = torch.linspace(beta_start, beta_end, num_timesteps)
    alphas = 1.0 - betas
    alphas_cumprod = torch.cumprod(alphas, dim=0)
    
    return alphas_cumprod[timesteps]

DDPM Sampling

Para generar imágenes, usamos el proceso de denoising iterativo:

@torch.no_grad()
def ddpm_sample(model, shape, num_timesteps=1000, device='cuda'):
    """
    Generar imágenes usando DDPM sampling completo.
    """
    model.eval()
    
    # Empezar con ruido puro
    x = torch.randn(shape, device=device)
    
    # Denoising iterativo ( backwards )
    for t in reversed(range(num_timesteps)):
        t_batch = torch.full((shape[0],), t, device=device, dtype=torch.long)
        
        # Predecir ruido
        predicted_noise = model(x, t_batch)
        
        # Obtener parámetros del schedule
        alpha_t = alphas[t]
        alpha_cumprod_t = alphas_cumprod[t]
        beta_t = betas[t]
        
        # Calcular media de la imagen limpia
        if t > 0:
            noise = torch.randn_like(x)
        else:
            noise = 0
        
        # Sampling step
        x = (1 / math.sqrt(alpha_t)) * (x - (beta_t / math.sqrt(1 - alpha_cumprod_t)) * predicted_noise) + \
            math.sqrt(beta_t) * noise
    
    return x


@torch.no_grad()
def ddim_sample(model, shape, num_timesteps=50, eta=0.0, device='cuda'):
    """
    Generar imágenes usando DDIM sampling ( más rápido ).
    eta=0 significa sampling determinístico.
    """
    model.eval()
    
    # Saltar algunos timesteps para acelerar
    step_size = num_timesteps // 50
    timesteps = list(range(0, num_timesteps, step_size))
    
    x = torch.randn(shape, device=device)
    
    for i, t in enumerate(tqdm(timesteps[:-1])):
        t_batch = torch.full((shape[0],), t, device=device, dtype=torch.long)
        next_t = timesteps[i + 1]
        next_t_batch = torch.full((shape[0],), next_t, device=device, dtype=torch.long)
        
        # Predecir ruido
        predicted_noise = model(x, t_batch)
        
        # DDIM step
        alpha_cumprod_t = alphas_cumprod[t]
        alpha_cumprod_next = alphas_cumprod[next_t]
        
        pred_x0 = (x - math.sqrt(1 - alpha_cumprod_t) * predicted_noise) / math.sqrt(alpha_cumprod_t)
        
        direction = math.sqrt(1 - alpha_cumprod_next) * predicted_noise
        
        if eta > 0:
            noise = torch.randn_like(x)
        else:
            noise = 0
        
        x = math.sqrt(alpha_cumprod_next) * pred_x0 + direction + eta * noise
    
    return x

Classifier-Free Guidance

DiT usa classifier-free guidance (CFG) para mejorar la calidad del conditioning. En vez de un classifier separado, se entrena el modelo jointly con y sin labels:

def cfg_forward(model, x, t, class_labels=None, cfg_scale=7.5):
    """
    Forward pass con Classifier-Free Guidance.
    cfg_scale > 1 усиливает conditioning, < 1 lo debilita.
    """
    # Predicción condicional ( con clase )
    pred_cond = model(x, t, class_labels)
    
    # Predicción inconditional ( sin clase = null embedding )
    pred_uncond = model(x, t, None)
    
    # Interpolar
    predicted_noise = pred_uncond + cfg_scale * (pred_cond - pred_uncond)
    
    return predicted_noise

Por qué DiT supera a U-Net

Los experimentos en el paper de DiT muestran varias ventajas:

  • Mejor scaling: DiT-L/2 supera a U-Net-L en FID (calidad de imagen) con menos parámetros
  • Mejor uso de compute: los transformers se benefician más de más FLOPs que las U-Nets
  • Menos artifacts: las dependencias de atención global reducen artifacts locales
  • Másstable training: menos sensible a hyperparameters

Los modelos DiT más conocidos:

  • Stable Diffusion 3: usa DiT-MMDiT (multi-modal DiT) con flujos de texto e imagen separados
  • DiT-XL/2: el modelo del paper original con 675M parámetros
  • PixArt-α: DiT rápido para generación de alta resolución

Resumen y cierre

Los Diffusion Transformers representan la nueva generación de modelos de generación de imágenes. Reemplazan la U-Net tradicional con un Vision Transformer que escala mejor, produce imágenes de mayor calidad, y se beneficia más del hardware moderno. Stable Diffusion 3 ya usa esta arquitectura, y es probable que los próximos modelos de generación de video (Sora, Kling) también usen transformers de difusión.

La lección principal: cuando una arquitectura demuestra mejor scaling que otra, eventualmente la reemplaza. Los transformers reemplazaron a CNNs en NLP, luego en visión, y ahora están reemplazando a U-Nets en difusión. Mantente atento a las tendencias arquitectónicas — suelen预示 lo que viene después.

En Bogotá decíamos: "del seguro al que madruga". Con DiT, el que madruga es el que usa la arquitectura que escala mejor. Y ahora ya sabes por qué.
