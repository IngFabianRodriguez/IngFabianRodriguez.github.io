ReAct - Razonamiento y Accion Combinados

16 de septiembre de 2026
reactreasoningactionagents

☕ Intro

Hagale pues, parcero. Día 259 y hoy vamos a hablar de algo que el 75% de los que construyen agentes NO usan correctamente: ReAct (Synergizing Reasoning and Acting). Si tu agente solo "piensa" o solo "actúa", estás dejando el 50% de la capacidad sobre la mesa. ReAct es precisamente la combinación de ambos.

En Bogotá, un equipo de ML construía un chatbot de soporte técnico. Tenían un Agente que razonaba perfectamente pero no podía ejecutar acciones. Y tenían herramientas disponibles pero el agente no sabía cuándo usarlas. El problema: no estaban combinando reasoning con action de forma estructurada.

🔎 ¿Qué es ReAct?

ReAct es un paradigma donde el LLM alterna entre razonamiento (thought) y acción (action) de forma interleaved. El agente:

  • Thought: Razona sobre la situación actual — "Veo que el usuario pregunta por X, necesito verificar Y"
  • Action: Ejecuta una acción — llama a una herramienta, busca en base de datos, consulta una API
  • Observation: Recibe el resultado de la acción

Este ciclo se repite hasta que el agente tiene suficiente información para responder.

📐 El Ciclo ReAct

La fórmula es simple:

Thought → Action → Observation → Thought → Action → Observation → ... → Response

Cada paso construye sobre el anterior. El reasoning hace que las acciones sean intencionales, no aleatorias.

💻 Implementación

Pipeline Básico

from typing import List, Dict, Any
from dataclasses import dataclass

@dataclass
class ReActStep:
    thought: str
    action: str
    observation: str = ""

class ReActAgent:
    """
    Agente ReAct: alterna entre razonamiento y accion.
    
    El loop:
    1. Think: razona sobre la situacion
    2. Act: ejecuta una accion (tool call)
    3. Observe: recibe el resultado
    4. Repite hasta tener respuesta final
    """
    
    def __init__(self, llm, tools: List[Any], max_iterations: int = 10):
        self.llm = llm
        self.tools = tools
        self.max_iterations = max_iterations
    
    def run(self, query: str) -> str:
        context = []
        query_lower = query.lower()
        
        for i in range(self.max_iterations):
            # 1. Generar siguiente paso (thought + action)
            prompt = self._build_prompt(query, context)
            step = self.llm.complete(prompt)
            
            # 2. Parsear thought y action
            thought = step.get("thought", "")
            action_name = step.get("action", "")
            action_input = step.get("action_input", {})
            
            # 3. Si no hay accion, terminamos
            if not action_name or action_name == "finish":
                return thought
            
            # 4. Ejecutar accion
            observation = self._execute_action(action_name, action_input)
            
            # 5. Anadir al contexto
            context.append({
                "thought": thought,
                "action": action_name,
                "observation": observation
            })
        
        return "Max iterations reached"
    
    def _build_prompt(self, query: str, context: List[Dict]) -> str:
        """Construye el prompt con el contexto del ciclo."""
        tools_desc = "\n".join([
            f"- {t.name}: {t.description}" 
            for t in self.tools
        ])
        
        context_str = ""
        for idx, c in enumerate(context):
            context_str += f"""
Paso {idx + 1}:
Thought: {c['thought']}
Action: {c['action']}
Observation: {c['observation']}
"""
        
        prompt = f"""Usa el formato:
Thought: [tu razonamiento sobre la situacion]
Action: [nombre de la herramienta a usar, o 'finish' si ya tienes respuesta]
Action Input: {{"input": [parametros]}}

Herramientas disponibles:
{tools_desc}

Query: {query}

Historial:
{context_str}

Determina el siguiente paso:"""
        
        return prompt
    
    def _execute_action(self, action_name: str, action_input: Dict) -> str:
        """Ejecuta una accion y devuelve el resultado."""
        for tool in self.tools:
            if tool.name == action_name:
                return tool.run(**action_input)
        return f"Error: herramienta '{action_name}' no encontrada"

# Ejemplo de herramienta
class SearchTool:
    name = "search"
    description = "Busca informacion en la base de conocimiento. Input: query (str)"
    
    def run(self, query: str) -> str:
        # Logica de busqueda
        return f"Resultados para '{query}': ..."

class CalculatorTool:
    name = "calculate"
    description = "Ejecuta un calculo matematico. Input: expression (str)"
    
    def run(self, expression: str) -> str:
        # Logica de calculo
        try:
            result = eval(expression)
            return str(result)
        except:
            return "Error en calculo"

Prompting para ReAct

REACT_PROMPT = """Eres un agente que resuelve problemas usando el paradigma ReAct.

Formato de salida (JSON):
{
    "thought": "Aqui describes tu razonamiento sobre que hacer ahora",
    "action": "Nombre de la herramienta a usar (o 'finish' si ya tienes respuesta)",
    "action_input": {{"param1": "valor1", "param2": "valor2"}}
}}

Herramientas disponibles:
{tools}

Historia de pasos previos:
{history}

Query actual: {query}

Responde SOLO con el JSON del siguiente paso:"""

def format_history(steps: List[Dict]) -> str:
    """Formatea el historial para el prompt."""
    if not steps:
        return "Sin pasos previos."
    
    formatted = []
    for i, step in enumerate(steps, 1):
        formatted.append(f"""
--- Paso {i} ---
Thought: {step['thought']}
Action: {step['action']}
Observation: {step['observation']}
""")
    return "\n".join(formatted)

def build_react_prompt(query: str, tools: List, history: List[Dict]) -> str:
    """Construye prompt completo para ReAct."""
    tools_str = "\n".join([f"- {t.name}: {t.description}" for t in tools])
    history_str = format_history(history)
    
    return REACT_PROMPT.format(
        tools=tools_str,
        history=history_str,
        query=query
    )

⚖️ ReAct vs Otros Paradigmas

ReAct vs Chain-of-Thought

CoT solo razona, no actúa. Genera una cadena de pensamientos pero no interactúa con el mundo. Bueno para problemas matemáticos puros, malo para tareas que requieren datos externos.

ReAct combina razonamiento con acciones. Puede buscar, calcular, consultar APIs. Más flexible, pero más complejo de implementar.

ReAct vs Act

Act (Agent Orchestrator) es similar pero optimiza para acciones secuenciales con menos reasoning explícito. ReAct hace el reasoning más visible y estructurado.

⚠️ Errores Comunes

Error 1: Sin Tools

El problema: ReAct sin herramientas es solo Chain-of-Thought. Si no le das acciones posibles, el agente no puede actuar.

La solución: Define herramientas claras con descriptions precisas. El LLM decide qué usar basándose en la descripción.

Error 2: Loop Infinito

El problema: Sin max_iterations, el agente puede entrar en loop de acciones que no progresan.

La solución: Siempre define un límite de iteraciones y maneja el caso de "max iterations reached".

Error 3: Contexto Crece Sin Límite

El problema: Cada paso añade al contexto. En 20 iteraciones, el contexto es enorme y el LLM se confunde.

La solución: Implementa resúmenes o limita el contexto a los últimos N pasos relevantes.

✅ Resumen

Hagale pues, lo esencial del día:

  • ReAct = Reasoning + Action interleaved. El agente razona, actúa, observa, y repite.
  • Cada ciclo: Thought → Action → Observation
  • El reasoning hace las acciones intencionadas, no aleatorias.
  • Necesita herramientas bien definidas para funcionar.
  • Sin loop infinito: siempre define max_iterations.
