🎯 Qué Es Agentic RAG?

Hagale pues, parcero. Día 262 y hoy toca un tema que está redefiniendo cómo construimos sistemas de recuperación de información: Agentic RAG. Esto no es tu RAG tradicional donde recuperas documentos y los pasas a un LLM. No sire. Aquí el agente decide qué buscar, cómo buscarlo, cuándo pedir más información, y cómo navegar bases de conocimiento complejas. El 80% todavía está haciendo RAG básico — esto es lo que viene.

📐 La Diferencia Entre RAG y Agentic RAG

La fórmula que lo resume:

$$\text{RAG Tradicional} \rightarrow \text{Query} \rightarrow \text{Retrieve} \rightarrow \text{Generate}$$

$$\text{Agentic RAG} \rightarrow \text{Query} \rightarrow \text{Agent} \rightarrow \text{Plan} \rightarrow \text{Retrieve} \rightarrow \text{Reflect} \rightarrow \text{Generate}$$

La diferencia clave: el agente puede hacer múltiples pasos de retrieval, re-planificar based on what it finds, y decidir si necesita más información antes de generar.

🔧 Arquitectura de un Agentic RAG System

La arquitectura tiene cuatro componentes principales que trabajan en loop:

from typing import List, Dict, Any, Optional
from enum import Enum

class AgentState(Enum):
    PLANNING = "planning"
    RETRIEVING = "retrieving"
    GENERATING = "generating"
    DONE = "done"

class AgenticRAG:
    """Sistema Agentic RAG con loop de retrieval-reflect."""

    def __init__(
        self,
        retriever: Any,
        generator: Any,
        max_retrieval_steps: int = 3,
        relevance_threshold: float = 0.7
    ):
        self.retriever = retriever
        self.generator = generator
        self.max_retrieval_steps = max_retrieval_steps
        self.relevance_threshold = relevance_threshold
        self.memory = []  # Historial de lo recuperado

    def query(self, question: str) -> Dict[str, Any]:
        """Procesa una query con agentic RAG."""
        self.memory = []
        state = AgentState.PLANNING
        step = 0

        # Plan inicial
        plan = self._create_plan(question)
        context = ""

        while state != AgentState.DONE and step < self.max_retrieval_steps:
            if state == AgentState.PLANNING:
                # Decidir siguientes acciones
                actions = self._decide_actions(plan, question, context)
                if not actions:
                    state = AgentState.GENERATING
                else:
                    state = AgentState.RETRIEVING

            elif state == AgentState.RETRIEVING:
                # Ejecutar retrieval
                for action in actions:
                    results = self.retriever.search(
                        query=action["query"],
                        top_k=action.get("top_k", 5)
                    )
                    self.memory.extend(results)

                    # Evaluar relevancia
                    if self._evaluate_relevance(results, question) < self.relevance_threshold:
                        # Necesitamos más información - volver a planning
                        state = AgentState.PLANNING
                        plan = self._update_plan(plan, results, question)
                        break
                else:
                    # Todos los resultados fueron relevantes
                    state = AgentState.GENERATING

            elif state == AgentState.GENERATING:
                # Generar respuesta con el contexto recuperado
                context = self._build_context(self.memory)
                answer = self.generator.generate(
                    question=question,
                    context=context
                )
                state = AgentState.DONE

            step += 1

        return {
            "answer": answer,
            "sources": self.memory,
            "steps_taken": step
        }

    def _create_plan(self, question: str) -> Dict[str, Any]:
        """Crea un plan inicial de retrieval."""
        return {
            "original_question": question,
            "sub_questions": self._decompose_question(question),
            "retrieval_history": []
        }

    def _decompose_question(self, question: str) -> List[str]:
        """Descompone pregunta en sub-preguntas más específicas."""
        # En producción, usar un LLM para esto
        # Por ahora, heurística simple
        return [question]  # Fallback: buscar la pregunta original

🔄 Multi-Step Retrieval con Reflection

El loop de retrieval-reflect es lo que hace agentic RAG especial. Después de cada retrieval, el agente reflexiona sobre si tiene suficiente información:

class RetrievalAgent:
    """Agente que decide qué y cómo recuperar en múltiples pasos."""

    def __init__(self, retriever, reflector):
        self.retriever = retriever
        self.reflector = reflector  # LLM que evalúa si el contexto es suficiente
        self.retrieval_history = []

    def retrieve_with_reflection(
        self,
        question: str,
        max_steps: int = 3
    ) -> str:
        """Retrieval en pasos con auto-evaluación."""
        context_parts = []
        current_question = question

        for step in range(max_steps):
            # Retrieval
            results = self.retriever.search(current_question, top_k=5)
            self.retrieval_history.append({
                "step": step,
                "query": current_question,
                "results": results
            })

            # Extraer contenido relevante
            new_context = "\n".join([r["content"] for r in results])
            context_parts.append(new_context)

            # Reflexión: ¿tenemos suficiente?
            full_context = "\n\n".join(context_parts)
            is_sufficient, gap = self.reflector.evaluate(
                question=question,
                context=full_context
            )

            if is_sufficient:
                break

            # No es suficiente - formular query para el gap
            current_question = gap

        return "\n\n".join(context_parts)

    def get_retrieval_stats(self) -> Dict[str, Any]:
        """Retorna estadísticas del proceso de retrieval."""
        return {
            "total_steps": len(self.retrieval_history),
            "queries": [r["query"] for r in self.retrieval_history],
            "total_docs_retrieved": sum(
                len(r["results"]) for r in self.retrieval_history
            )
        }

📊 Routing: Decidir Dónde Buscar

Agentic RAG puede路由 a diferentes fuentes o estrategias based on the query:

from typing import Literal

class Router:
    """Router inteligente que decide dónde y cómo buscar."""

    def __init__(self, vector_stores: Dict[str, Any], kg_client: Any = None):
        self.stores = vector_stores  # {"docs": store1, "qa": store2, "code": store3}
        self.kg = kg_client  # Knowledge graph opcional
        self.route_prompts = {
            "factual": "Busca información factual en la base de documentos.",
            "procedural": "Busca pasos o procedimientos en la base de código.",
            "conceptual": "Busca explicaciones conceptuales en la base de Q&A.",
            "hybrid": "Combina búsqueda factual y conceptual."
        }

    def route(self, question: str) -> Dict[str, Any]:
        """Decide la estrategia de routing basada en la query."""
        # Clasificar el tipo de query
        query_type = self._classify_query(question)

        # Decidir si usar knowledge graph
        use_kg = self._should_use_kg(question)

        routes = []
        if query_type == "factual":
            routes.append({"source": "docs", "strategy": "similarity"})
        elif query_type == "procedural":
            routes.append({"source": "code", "strategy": "bm25"})
        elif query_type == "conceptual":
            routes.append({"source": "qa", "strategy": "similarity"})
        else:  # hybrid
            routes = [
                {"source": "docs", "strategy": "similarity"},
                {"source": "qa", "strategy": "similarity"}
            ]

        return {
            "query_type": query_type,
            "routes": routes,
            "use_kg": use_kg,
            "prompt": self.route_prompts.get(query_type, "")
        }

    def _classify_query(self, question: str) -> Literal["factual", "procedural", "conceptual", "hybrid"]:
        """Clasifica el tipo de query (en producción usar LLM)."""
        question_lower = question.lower()

        # Palabras clave simples para clasificación
        if any(kw in question_lower for kw in ["cómo", "pasos", "procedimiento", "implementar"]):
            return "procedural"
        elif any(kw in question_lower for kw in ["por qué", "explicar", "qué es", "concepto"]):
            return "conceptual"
        elif any(kw in question_lower for kw in ["cuándo", "cuánto", "dónde", "quién", "número"]):
            return "factual"
        return "hybrid"

    def _should_use_kg(self, question: str) -> bool:
        """Decide si la query se beneficiaría de knowledge graph."""
        kg_keywords = ["relación", "conectar", "entre", "jerarquía", "padre", "hijo"]
        return any(kw in question.lower() for kw in kg_keywords)

⚠️ Errores Comunes (y Cómo Evitarlos)

Error 1: No poner límites al número de retrieval steps

El problema: El agente entra en loop infinito de retrieval, consume tokens y nunca termina.

La solución: Siempre establecer max_retrieval_steps y timeout:

class BoundedAgenticRAG(AgenticRAG):
    """Agentic RAG con límites estrictos."""

    def __init__(self, *args, max_retrieval_steps: int = 3, timeout_seconds: float = 30.0, **kwargs):
        super().__init__(*args, **kwargs)
        self.max_retrieval_steps = max_retrieval_steps
        self.timeout_seconds = timeout_seconds
        self.start_time = None

    def query(self, question: str) -> Dict[str, Any]:
        self.start_time = time.time()
        return super().query(question)

    def _check_limits(self) -> bool:
        """Verifica si se han excedido los límites."""
        elapsed = time.time() - self.start_time
        if elapsed > self.timeout_seconds:
            return False
        if self.step >= self.max_retrieval_steps:
            return False
        return True

Error 2: Mezclar recuperación de documentos sin evaluar relevancia primero

El problema: Se acumulan documentos irrelevantes y el contexto se diluye.

La solución: Filtrar por relevancia antes de añadir al contexto:

class RelevanceFilteredRetriever:
    """Filtra resultados por relevancia antes de añadir al contexto."""

    def __init__(self, base_retriever, relevance_threshold: float = 0.6):
        self.base = base_retriever
        self.threshold = relevance_threshold

    def search(self, query: str, top_k: int = 5) -> List[Dict]:
        results = self.base.search(query, top_k=top_k * 3)  # Traer más para filtrar

        # Filtrar por score
        filtered = [r for r in results if r["score"] >= self.threshold]

        # Deduplicar por contenido similar
        deduplicated = self._deduplicate(filtered)

        return deduplicated[:top_k]

    def _deduplicate(self, results: List[Dict]) -> List[Dict]:
        """Elimina resultados con contenido muy similar."""
        if not results:
            return []

        unique = [results[0]]
        for r in results[1:]:
            is_duplicate = any(
                self._similarity(r["content"], u["content"]) > 0.9
                for u in unique
            )
            if not is_duplicate:
                unique.append(r)
        return unique

    def _similarity(self, text1: str, text2: str) -> float:
        """Calcula similitud simple entre dos textos."""
        # En producción usar embeddings
        words1 = set(text1.lower().split())
        words2 = set(text2.lower().split())
        if not words1 or not words2:
            return 0.0
        intersection = words1 & words2
        union = words1 | words2
        return len(intersection) / len(union)

📊 Resumen

  • Agentic RAG añade un loop de plan-retrieve-reflect sobre RAG tradicional.
  • Multi-step retrieval: el agente puede hacer múltiples búsquedas guiadas por gaps detectados.
  • Routing inteligente: decide qué fuente y estrategia usar based on la query.
  • Límites estrictos: max steps y timeout para evitar loops infinitos.
  • Relevance filtering: filtra y deduce before adding to context.
