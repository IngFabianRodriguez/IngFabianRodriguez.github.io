🎯 ¿Qué Es Attention Mechanism?

Hágale pues, parcero. Llegamos al Día 107 y hoy toca uno de los conceptos que cambió completamente el deep learning: el Attention Mechanism. Si pensabas que las redes recurrentes eran el futuro, espera a ver cómo attention permitió que los Transformers dominaran todo — desde NLP hasta visión por computadora. Sin attention, ChatGPT, BERT, y probablemente medio mundo de la IA moderna no existiría. Así que prestá atención (valga la redundancia).

📐 La Matemática Detrás De Attention

Attention es fundamentalmente una idea sencilla pero profunda: dada una posición en una secuencia, ¿a qué partes de la misma (o de otra) secuencia debo prestar atención para entender mejor el contexto?

Scaled Dot-Product Attention

La fórmula original del paper "Attention Is All You Need" es:

Attention(Q, K, V) = softmax(QK^T / √d_k) × V

Donde:

  • Q (Query): El vector que representa "qué estoy buscando" — la posición actual
  • K (Key): El vector que representa "de qué trata" cada posición
  • V (Value): El contenido real de cada posición que queremos extraer
  • √d_k: El factor de escala — aquí está el primer error común que vamos a ver

La intuición: computamos la similitud entre Q y cada K usando el producto punto, escalamos para evitar que los valores crezcan demasiado cuando d_k es grande, aplicamos softmax para obtener pesos que sumen 1, y finalmente hacemos una suma ponderada de los valores V.

¿Por qué se escala por √d_k?

Cuando d_k es grande (ej: 512 o 768), el producto punto QK^T puede generar valores muy grandes en magnitud. Esto satura el softmax, haciendo que los gradientes sean cercanos a cero — vanilla vanishing gradients. Escalar por √d_k mantiene la varianza de los scores cerca de 1, asegurando un softmax "suave" con gradientes razonables.

Self-Attention vs Cross-Attention

  • Self-Attention: Q, K, V vienen de la misma secuencia. Cada posición attend a todas las demás posiciones de la misma secuencia. Ejemplo: en "El gato se sentó en la alfombra", "gato" attends a "sentó" y "alfombra" para capturar la relación.
  • Cross-Attention: Q viene de una secuencia (ej: el decoder) y K, V vienen de otra (ej: el encoder). Es cómo el decoder mira el input original en traducción. Q = "¿qué palabra traduzco ahora?", K, V = representaciones del sentence original.

🚀 Implementación En PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F
import matplotlib.pyplot as plt
import seaborn as sns
import math


# ============================================================
# 1. SCALED DOT-PRODUCT ATTENTION DESDE CERO
# ============================================================
def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Q: (batch, seq_q, d_k)
    K: (batch, seq_k, d_k)
    V: (batch, seq_k, d_v)
    mask: (batch, seq_q, seq_k) — opcional, para causal o padding
    """
    d_k = Q.size(-1)
    
    # Compute attention scores: Q @ K^T
    # shape: (batch, seq_q, seq_k)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # Apply mask if provided (for causal attention or padding)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    
    # Softmax para obtener pesos de atención
    attn_weights = F.softmax(scores, dim=-1)
    
    # Weighted sum de los values
    output = torch.matmul(attn_weights, V)
    
    return output, attn_weights

# 2. MULTI-HEAD ATTENTION CON nn.MultiheadAttention
# ============================================================
class MultiHeadAttentionDemo(nn.Module):
    def __init__(self, d_model=512, num_heads=8):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # Proyecciones lineales
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
        
        # Usar el módulo built-in de PyTorch
        self.multihead_attn = nn.MultiheadAttention(
            embed_dim=d_model, 
            num_heads=num_heads,
            batch_first=True
        )
    
    def forward(self, query, key, value, attn_mask=None):
        """
        query/key/value: (batch, seq_len, d_model)
        """
        # Proyecciones
        Q = self.W_q(query)
        K = self.W_k(key)
        V = self.W_v(value)
        
        # Multi-head attention con PyTorch
        # Devuelve: (output, attn_weights)
        attn_output, attn_weights = self.multihead_attn(
            query=Q, 
            key=K, 
            value=V,
            attn_mask=attn_mask
        )
        
        # Proyección de salida
        output = self.W_o(attn_output)
        
        return output, attn_weights

# 3. SELF-ATTENTION LAYER (solo-attention, sin RNN)
# ============================================================
class SelfAttentionLayer(nn.Module):
    """Una capa de self-attention con residuales y layernorm"""
    def __init__(self, d_model, num_heads=8, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(
            embed_dim=d_model,
            num_heads=num_heads,
            batch_first=True,
            dropout=dropout
        )
        self.norm = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        """
        x: (batch, seq_len, d_model)
        mask: mask para atención causal
        """
        # Multi-head attention con residuales
        attn_output, _ = self.self_attn(x, x, x, attn_mask=mask)
        x = self.norm(x + self.dropout(attn_output))
        return x

# ============================================================
# 4. CROSS-ATTENTION PARA ENCODER-DECODER
# ============================================================
class CrossAttentionLayer(nn.Module):
    """Cross-attention: queries del decoder, keys/values del encoder"""
    def __init__(self, d_model, num_heads=8, dropout=0.1):
        super().__init__()
        self.cross_attn = nn.MultiheadAttention(
            embed_dim=d_model,
            num_heads=num_heads,
            batch_first=True,
            dropout=dropout
        )
        self.norm = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, decoder_states, encoder_states, mask=None):
        """
        decoder_states: (batch, dec_seq, d_model) — queries
        encoder_states: (batch, enc_seq, d_model) — keys/values
        """
        attn_output, attn_weights = self.cross_attn(
            query=decoder_states,
            key=encoder_states,
            value=encoder_states,
            attn_mask=mask
        )
        output = self.norm(decoder_states + self.dropout(attn_output))
        return output, attn_weights

# 5. VISUALIZAR ATTENTION WEIGHTS
# ============================================================
def visualize_attention(attn_weights, sentence, head_idx=0):
    """
    Visualiza los pesos de atención como heatmap
    attn_weights: (num_heads, seq_len, seq_len) o (seq_len, seq_len)
    sentence: lista de tokens
    head_idx: cuál head visualizar si hay múltiples
    """
    if attn_weights.dim() == 4:
        # (batch, num_heads, seq, seq) -> tomar primer batch y head específico
        attn_weights = attn_weights[0, head_idx].detach().cpu().numpy()
    else:
        attn_weights = attn_weights[0].detach().cpu().numpy()
    
    plt.figure(figsize=(10, 8))
    sns.heatmap(
        attn_weights, 
        xticklabels=sentence,
        yticklabels=sentence,
        cmap='viridis',
        annot=False,
        fmt='.2f'
    )
    plt.title(f'Attention Weights - Head {head_idx}')
    plt.xlabel('Keys')
    plt.ylabel('Queries')
    plt.tight_layout()
    
    # Guardar como imagen
    plt.savefig('attention_heatmap.png', dpi=150)
    plt.close()
    print("Heatmap guardado en attention_heatmap.png")
    
    return 'attention_heatmap.png'

# EJEMPLO COMPLETO: MINI TRANSFORMER ENCODER
# ============================================================
class TransformerEncoderBlock(nn.Module):
    """Un bloque de encoder completo: MHAttention + FFN + residuales"""
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(
            embed_dim=d_model,
            num_heads=num_heads,
            batch_first=True,
            dropout=dropout
        )
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # Self-attention con residuales
        attn_output, attn_weights = self.self_attn(x, x, x, attn_mask=mask)
        x = self.norm1(x + self.dropout(attn_output))
        
        # Feed-forward con residuales
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_output))
        
        return x, attn_weights


class SimpleTransformerEncoder(nn.Module):
    def __init__(self, vocab_size, d_model, num_heads, d_ff, num_layers, max_seq_len):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_embedding = nn.Parameter(torch.randn(1, max_seq_len, d_model) * 0.02)
        self.layers = nn.ModuleList([
            TransformerEncoderBlock(d_model, num_heads, d_ff)
            for _ in range(num_layers)
        ])
    
    def forward(self, x, mask=None):
        # x: (batch, seq_len) — token IDs
        x = self.embedding(x) + self.pos_embedding[:, :x.size(1), :]
        
        attn_weights_all = []
        for layer in self.layers:
            x, attn_weights = layer(x, mask)
            attn_weights_all.append(attn_weights)
        
        return x, attn_weights_all

⚠️ Errores Comunes Y Cómo Evitarlos

❌ Error 1: No escalar el attention score — vanishing gradients en redes profundas

El problema: Si no escalamos QK^T por √d_k, los scores se vuelven muy grandes cuando d_k es grande. Esto satura el softmax, haciendo que los pesos de atención se concentren en un solo token (casi one-hot). Los gradientes del softmax son prácticamente cero, matando el aprendizaje en redes profundas con muchas capas de attention.

La solución: SIEMPRE escala por √d_k. Es una línea de código pero salva tu entrenamiento:

# ❌ WRONG — causa vanishing gradients
scores = torch.matmul(Q, K.transpose(-2, -1))

# ✅ CORRECTO — escala apropiada
d_k = Q.size(-1)
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

❌ Error 2: Demasiados attention heads — overfitting

El problema: Más heads = más parámetros = más capacidad de memorización. En datasets pequeños, el modelo aprende a "rotear" en lugar de generalizar. Además, cada head termina aprendiendo patrones redundantes o ruido.

La solución: El paper original de "Attention Is All You Need" usa 8 heads con d_model=512 (d_k=64). Una regla práctica: d_k debería ser al menos 32-64 para que cada head tenga suficiente representación. Usa menos heads en datasets pequeños y valida con attention analysis:

# ❌ WRONG — demasiados heads para dataset pequeño
num_heads = 32  # d_model 512 / 32 = 16 dims por head

# ✅ CORRECTO — número razonable de heads
num_heads = 8   # d_model 512 / 8 = 64 dims por head
# O prueba con heads más grandes: d_k = 64-128 mínimo

❌ Error 3: No usar causal mask en language modeling — data leakage

El problema: En generación autoregresiva, el modelo no debe "ver" los tokens futuros. Si no aplicas una causal mask, durante entrenamiento el modelo mira el token objetivo directamente, aprendiendo a copiar en lugar de predecir. En inferencia esto causa que el modelo genere texto repetitivo o sin sentido porque "chequeó" las respuestas.

La solución: Aplica una máscara causal (triangular inferior) antes del softmax:

def create_causal_mask(seq_len, device):
    """
    Crea máscara causal: 1 donde se permite atención, 0 donde no.
    Matriz triangular inferior — cada posición solo ve hacia atrás.
    """
    mask = torch.triu(torch.ones(seq_len, seq_len, device=device), diagonal=1)
    return mask == 0  # True donde podemos atender (triangular inferior)


def scaled_dot_product_attention_causal(Q, K, V):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    
    # Crear y aplicar máscara causal
    seq_len = Q.size(1)
    causal_mask = create_causal_mask(seq_len, Q.device)
    scores = scores.masked_fill(causal_mask.unsqueeze(0), float('-inf'))
    
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights

💡 Resumen

Attention Mechanism es el corazón de los modelos modernos. La idea central es simple: weighted sum de values, donde los pesos vienen de la similitud entre queries y keys. Lo que hace especial a attention es:

  • Paralelizable: A diferencia de RNN, toda la secuencia se procesa en paralelo
  • Direct connections: Cada posición puede attends a cualquier otra — sin pasos secuenciales de hidden state
  • Interpretable: Los attention weights muestran qué partes del input son relevantes

Los 3 errores que vimos son críticos en producción:

  1. No escalar → vanishing gradients → modelo no aprende
  2. Demasiados heads → overfitting → mala generalización
  3. No usar causal mask → data leakage → generación rota

Aplicar bien estos conceptos hace la diferencia entre un modelo que funciona en paper y uno que funciona en producción. Hágale, parcero, domínialo que mañana viene Transformers y ahí las cosas se ponen más interesantes todavía.
