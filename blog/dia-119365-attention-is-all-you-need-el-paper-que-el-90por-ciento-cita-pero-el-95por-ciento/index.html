Attention Is All You Need - El paper que el 90% cita pero el 95% no ha leído completo

30 de march de 2026
torch

Hola, parcero. Llegamos al Día 119 y hoy vamos con el paper que cambió NLP para siempre: Attention Is All You Need de Vaswani et al. (2017). Este paper es citado por el 90% de los papers de ML, pero el 95% no lo ha leído completo. Yo mismo, cuando lo leí por primera vez en 2018, me di cuenta de que había estado usando transformers incorrectamente por meses. Acompañame a desmenuzarlo completo, con la matemática y el código que realmente importa.

📜 Contexto Histórico y Por Qué Importa Este Paper

Antes de 2017, NLP dominaba con LSTM y GRU. Seq2Seq con attention existía, pero era engorroso. La dominating approach usaba recurrence — literalmente procesando token por token — lo cual hacía imposible paralelizar y limitaba los modelos a secuencias cortas. En 2017, Google Brain, Google Research y University of Toronto publicaron este paper y todo cambió.

La contribución central: reemplazar recurrencia con attention mechanism, logrando:

  • Paralelización completa: sin recurrencia, todo se procesa en paralelo
  • Long-range dependencies: attention directo capturando relaciones a distancia
  • Entrada y salida: el modelo completo encoder-decoder en una sola arquitectura
El equipo original incluía a Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Lukasz Kaiser y Illia Polosukhin. El último autor, Illia Polosukhin, dejó Google poco después — una historia interesante que pocos conocen.

🧠 La Arquitectura Completa: Matemáticas Detalladas

2.1 Scaled Dot-Product Attention

El corazón del transformer es Scaled Dot-Product Attention:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

Donde:

  • Q (Query): qué estoy buscando
  • K (Key): qué tengo para ofrecer
  • V (Value): el contenido real
  • d_k: dimensión de las keys (para scaling)

El scaling por √d_k es crítico — sin él, en dimensiones grandes, el dot product crece y el softmax va a saturación. Esto lo demostró empíricamente el equipo y es un detalle que muchos ignoran.

2.2 Multi-Head Attention

En lugar de hacer attention una sola vez, el paper propone multi-head attention:

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O$$

Donde cada head es:

$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

En el paper original: h = 8 heads, d_model = 512, d_k = d_v = 64. Cada head opera en un subspace de dimensión 64, y luego se concatena de vuelta a 512.

2.3 Positional Encoding

Sin recurrencia, el modelo no sabe el orden de los tokens. El paper resuelve esto con sinusoidal positional encoding:

$$PE_{(pos,2i)} = \sin\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$

$$PE_{(pos,2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)$$

La genialidad: permite al modelo aprender a attend relative positions porque cualquier offset es un patrón lineal en las sinusoidales.

2.4 Encoder y Decoder

El encoder tiene:

  • Multi-Head Self-Attention (cada posición attend a todas las anteriores)
  • Feed-Forward Network: dos linear transformations con ReLU

$$FFN(x) = W_2 \cdot \max(0, W_1 \cdot x + b_1) + b_2$$

  • LayerNorm y residual connections

El decoder añade:

  • Masked Multi-Head Self-Attention (previene ver futuro)
  • Encoder-Decoder Attention (keys y values del encoder, queries del decoder)

💻 Implementación Completa en PyTorch

Esta implementación replica la arquitectura exacta del paper, con comparaciones a implementaciones modernas.

import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class PositionalEncoding(nn.Module):
    """Positional Encoding original del paper - sinusoidal."""
    
    def __init__(self, d_model: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)
        
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(
            torch.arange(0, d_model, 2, dtype=torch.float) * 
            (-math.log(10000.0) / d_model)
        )
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        pe = pe.unsqueeze(0)  # (1, max_len, d_model)
        self.register_buffer('pe', pe)
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # x: (batch, seq_len, d_model)
        x = x + self.pe[:, :x.size(1)]
        return self.dropout(x)


class LearnedPositionalEncoding(nn.Module):
    """Alternative moderna: positional embeddings aprendidas.
    Muchos modelos modernos (BERT, GPT) usan esto en lugar de sinusoidal.
    """
    
    def __init__(self, d_model: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)
        self.pe = nn.Embedding(max_len, d_model)
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        batch, seq_len, _ = x.shape
        positions = torch.arange(seq_len, device=x.device).unsqueeze(0).expand(batch, -1)
        return self.dropout(x + self.pe(positions))


class MultiHeadAttention(nn.Module):
    """Multi-Head Attention del paper original.
    
    Paper: h=8 heads, d_model=512, d_k=d_v=64
    Moderno: puede variar estos hiperparámetros.
    """
    
    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % num_heads == 0
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # Proyecciones lineales
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
        
        self.dropout = nn.Dropout(p=dropout)
    
    def forward(self, query: torch.Tensor, key: torch.Tensor, value: torch.Tensor,
                mask: torch.Tensor = None) -> tuple[torch.Tensor, torch.Tensor]:
        batch_size = query.size(0)
        
        # Proyectar y separar en heads
        Q = self.W_q(query).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = self.W_k(key).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = self.W_v(value).view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # Scaled dot-product attention
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        
        attn_weights = F.softmax(scores, dim=-1)
        attn_weights = self.dropout(attn_weights)
        
        # Aplicar attention a values
        context = torch.matmul(attn_weights, V)
        
        # Concatenar heads y proyectar
        context = context.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        output = self.W_o(context)
        
        return output, attn_weights


class EncoderLayer(nn.Module):
    """Un Encoder layer del transformer."""
    
    def __init__(self, d_model: int, num_heads: int, d_ff: int = 2048, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(p=dropout)
    
    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        # Self-attention con residual
        attn_output, _ = self.self_attn(x, x, x, mask)
        x = self.norm1(x + self.dropout(attn_output))
        
        # Feed-forward con residual
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_output))
        
        return x


class DecoderLayer(nn.Module):
    """Un Decoder layer del transformer."""
    
    def __init__(self, d_model: int, num_heads: int, d_ff: int = 2048, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.cross_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(p=dropout)
    
    def forward(self, x: torch.Tensor, encoder_output: torch.Tensor,
                src_mask: torch.Tensor = None, tgt_mask: torch.Tensor = None) -> torch.Tensor:
        # Masked self-attention (causal)
        self_attn_output, _ = self.self_attn(x, x, x, tgt_mask)
        x = self.norm1(x + self.dropout(self_attn_output))
        
        # Cross-attention (encoder-decoder attention)
        cross_attn_output, _ = self.cross_attn(x, encoder_output, encoder_output, src_mask)
        x = self.norm2(x + self.dropout(cross_attn_output))
        
        # Feed-forward
        ffn_output = self.ffn(x)
        x = self.norm3(x + self.dropout(ffn_output))
        
        return x


class Transformer(nn.Module):
    """Transformer completo encoder-decoder.
    
    Esta es la arquitectura EXACTA del paper original.
    Para solo encoder (BERT): usa solo EncoderLayers.
    Para solo decoder (GPT): usa solo DecoderLayers con masking.
    """
    
    def __init__(self, d_model: int = 512, num_heads: int = 8, 
                 num_encoder_layers: int = 6, num_decoder_layers: int = 6,
                 d_ff: int = 2048, vocab_size: int = 37000, 
                 max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        
        self.d_model = d_model
        self.vocab_size = vocab_size
        
        # Embeddings
        self.src_embed = nn.Embedding(vocab_size, d_model)
        self.tgt_embed = nn.Embedding(vocab_size, d_model)
        
        # Positional encoding (sinusoidal original)
        self.pos_encoder = PositionalEncoding(d_model, max_len, dropout)
        
        # Encoder y Decoder
        self.encoder = nn.ModuleList([
            EncoderLayer(d_model, num_heads, d_ff, dropout) 
            for _ in range(num_encoder_layers)
        ])
        self.decoder = nn.ModuleList([
            DecoderLayer(d_model, num_heads, d_ff, dropout) 
            for _ in range(num_decoder_layers)
        ])
        
        # Output
        self.output = nn.Linear(d_model, vocab_size)
        
        self._init_weights()
    
    def _init_weights(self):
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)
    
    def forward(self, src: torch.Tensor, tgt: torch.Tensor,
                src_mask: torch.Tensor = None, tgt_mask: torch.Tensor = None) -> torch.Tensor:
        # Embed + positional encoding
        src = self.pos_encoder(self.src_embed(src) * math.sqrt(self.d_model))
        tgt = self.pos_encoder(self.tgt_embed(tgt) * math.sqrt(self.d_model))
        
        # Encoder
        for layer in self.encoder:
            src = layer(src, src_mask)
        
        # Decoder
        for layer in self.decoder:
            tgt = layer(tgt, src, src_mask, tgt_mask)
        
        return self.output(tgt)

    differences = """
    | Aspecto              | Paper Original (2017)      | Moderno (BERT/GPT)           |

    | Vocab size           | 37k (BPE)                   | 30k-50k (WordPiece)          |

🔍 Arquitectura Antes vs Después del Paper

  • Seq2Seq: Antes (2016): LSTM encoder-decoder + attention → Después (2017+): Transformer completo
  • Paralelización: Antes: Nulo (secuencial) → Después: Completa
  • Long dependencies: Antes: Problema con >100 tokens → Después: Sin límite teórico
  • Traducción: Antes: 8-12 LSTM layers, 384 dim → Después: 6 layers, 512 dim
  • Training time: Antes: Días → Después: Horas

🚨 Los 3 Errores Más Comunes

Error 1: Citar "Attention Is All You Need" sin haberlo leído

El error: Mucha gente dice "usa attention" o "es un transformer" sin entender que el paper propone una arquitectura específica encoder-decoder para traducción. No todo es transformer.

El fix: Lee el paper. Es corto (12 páginas). Entiende qué es encoder-decoder attention vs self-attention. Entiende por qué el decoder tiene masked attention.

Error 2: No entender que el paper propone encoder-decoder pero la mayoría usa solo una parte

El error: Asumir que BERT y GPT usan "el transformer". En realidad:

  • BERT: Solo el encoder del transformer. No tiene decoder.
  • GPT: Solo el decoder del transformer, con causal masking.
  • T5, BART: Encoder + Decoder completo como en el paper.

El fix: Recuerda: el paper original es seq2seq (traducción). BERT es solo encoder para classification/MLM. GPT es solo decoder para generación.

Error 3: Positional Encoding — Sinusoidal vs Learned

El error: Pensar que positional encoding sinusoidal es lo único posible o que learned es siempre mejor. El paper usa sinusoidal, pero muchos modelos modernos usan learned.

  • Sinusoidal: Generaliza a secuencias más largas que las vistas en training
  • Learned: Más flexible, pero no generaliza más allá del max_len visto

El fix: Para investigación, usa sinusoidal si necesitas extrapolación. Para producción con secuencias fijas, learned es más común y funciona igual de bien.

🏁 Resumen y Cierre

Hoy aprendimos que Attention Is All You Need no es solo "usar attention", es una arquitectura completa con:

  • Scaled Dot-Product Attention: el building block fundamental
  • Multi-Head Attention: múltiples subspaces de atención
  • Positional Encoding: sinusoidal en el paper, learned en modernos
  • Encoder-Decoder: el diseño original para seq2seq

Los errores comunes son: citar sin leer, no entender encoder-only vs decoder-only, y la elección de positional encoding. Con esto, ya sabes lo que el 95% no sabe.
