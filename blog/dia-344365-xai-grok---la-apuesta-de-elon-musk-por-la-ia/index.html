LLM Quality Assurance — Lo que el 90% No Hace y el 10% Hace para Calidad Consistente

Hagale pues, parcero. Llegamos al Día 344 y hoy el tema es uno de los más descuidados en producción con LLMs: el **Quality Assurance**. Porque de que te sirve tener un modelo potentísimo si sus outputs son una lotería? Aquí te enseño cómo montar un sistema de QA que funcione de verdad, con código y todo. Vamos.

🎯 ¿Por qué QA en LLMs es Diferente?

Con software tradicional, QA es relativamente straightforward: inputs + función → outputs esperados. Si hay bug, es determinístico. Pero con LLMs:

  • No determinismo: Mismo prompt → respuestas distintas
  • Subjetividad: ¿Qué es "calidad" exactamente?
  • Escala: Miles de requests por minuto imposibles de revisar manualmente
  • Contexto: La calidad depende del uso específico

La fórmula de calidad que yo uso en producción:

Quality Score = f(accuracy, relevance, coherence, safety, latency)

Cada componente tiene peso según el caso de uso. Para un sistema médico, safety y accuracy pesan 80%. Para un chatbot de entretenimiento, puede ser más importante la coherencia y el engagement.

📐 Framework de Quality Assurance

Este es el framework que uso para asegurar calidad consistente en pipelines de LLM:

"""
LLM Quality Assurance Framework
================================
Sistema completo para definir, medir y mantener calidad de outputs LLM
"""
from dataclasses import dataclass, field
from typing import Optional, List, Dict, Callable, Any
from enum import Enum
import time
import json


class QualityDimension(Enum):
    """Dimensiones de calidad para evaluar"""
    ACCURACY = "accuracy"          # Correctitud factual
    RELEVANCE = "relevance"        # Relevancia al prompt
    COHERENCE = "coherence"        # Cohesión y fluidez
    SAFETY = "safety"              # Sin contenido dañino
    COMPLETENESS = "completeness"  # Respuesta completa
    CONCISENESS = "conciseness"    # Conciso sin perder info


@dataclass
class QualityThreshold:
    """Umbral mínimo aceptable para una dimensión"""
    dimension: QualityDimension
    min_score: float  # 0.0 a 1.0
    weight: float = 1.0  # Peso en score final


@dataclass
class QualityScore:
    """Resultado de evaluación de calidad"""
    overall_score: float  # Score ponderado 0-1
    dimension_scores: Dict[QualityDimension, float]
    passed: bool
    failed_dimensions: List[QualityDimension]
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def to_dict(self) -> dict:
        return {
            "overall_score": self.overall_score,
            "passed": self.passed,
            "failed_dimensions": [d.value for d in self.failed_dimensions],
            "dimension_scores": {d.value: s for d, s in self.dimension_scores.items()},
            **self.metadata
        }


class QualityMetrics:
    """
    Métricas automatizadas para cada dimensión de calidad
    
    Implementa métricas estadísticas y basadas en modelos
    """
    
    @staticmethod
    def accuracy_score(output: str, expected_facts: List[str]) -> float:
        """
        Score de accuracy: verifica hechos contra lista conocida
        
        Args:
            output: Respuesta del LLM
            expected_facts: Lista de hechos que deben estar presentes
        """
        if not expected_facts:
            return 1.0  # Sin hechos que verificar = pasa
        
        output_lower = output.lower()
        matches = sum(1 for fact in expected_facts if fact.lower() in output_lower)
        return matches / len(expected_facts)
    
    @staticmethod
    def relevance_score(output: str, prompt: str, keywords: List[str]) -> float:
        """
        Score de relevancia: qué tan relacionado está el output al prompt
        
        Usa múltiples señales:
        1. Presencia de keywords importantes
        2. Longitud apropiada (ni muy corta ni muy larga)
        3. Inclusión del tema del prompt
        """
        output_lower = output.lower()
        prompt_lower = prompt.lower()
        
        # Keyword matching
        keyword_matches = sum(1 for kw in keywords if kw.lower() in output_lower)
        keyword_score = keyword_matches / len(keywords) if keywords else 1.0
        
        # Length appropriateness (斯乌斯! 经验法则)
        word_count = len(output.split())
        # Ideal: 50-500 palabras para la mayoría de casos
        if word_count < 10:
            length_score = 0.3
        elif word_count < 50:
            length_score = 0.7
        elif word_count <= 500:
            length_score = 1.0
        else:
            length_score = max(0.5, 1.0 - (word_count - 500) / 1000)
        
        # Topic overlap
        prompt_words = set(prompt_lower.split())
        output_words = set(output_lower.split())
        # Remover stopwords básicas
        stopwords = {'el', 'la', 'de', 'que', 'y', 'en', 'un', 'una', 'es', 'para'}
        prompt_words -= stopwords
        overlap = len(prompt_words & output_words)
        topic_score = min(1.0, overlap / max(1, len(prompt_words)))
        
        return (keyword_score * 0.4 + length_score * 0.3 + topic_score * 0.3)
    
    @staticmethod
    def coherence_score(output: str) -> float:
        """
        Score de coherencia: qué tan cohesiva es la respuesta
        
        Usa heurísticas:
        1. Consistencia léxica (palabras repetidas有意义)
        2. Estructura de oraciones (no fragments عشوائي)
        3. Orden lógico (primero, después, finalmente)
        """
        if not output or len(output.strip()) < 10:
            return 0.0
        
        sentences = [s.strip() for s in output.replace('!', '.').replace('?', '.').split('.') if s.strip()]
        
        if len(sentences) < 2:
            return 0.5  # Solo una oración, no se puede evaluar bien
        
        # Score de estructura: múltiples oraciones = mejor
        structure_score = min(1.0, len(sentences) / 5)
        
        # Score de repetición: palabras repetidas pueden indicar coherencia o redundancia
        words = output.lower().split()
        if len(words) < 5:
            return 0.5
        
        unique_ratio = len(set(words)) / len(words)
        # Unique ratio muy bajo = repetitivo, muy alto = incoherent
        repetition_score = 1.0 - abs(0.6 - unique_ratio) if unique_ratio < 0.6 else unique_ratio
        
        return (structure_score * 0.5 + repetition_score * 0.5)
    
    @staticmethod
    def safety_score(output: str, unsafe_patterns: List[str]) -> float:
        """
        Score de seguridad: detección de contenido dañino
        
        Args:
            output: Respuesta a verificar
            unsafe_patterns: Lista de patrones conocidos de contenido dañino
        """
        if not unsafe_patterns:
            return 1.0
        
        output_lower = output.lower()
        violations = sum(1 for pattern in unsafe_patterns if pattern.lower() in output_lower)
        
        if violations == 0:
            return 1.0
        elif violations == 1:
            return 0.5  # Una violación, podría ser falso positivo
        else:
            return max(0.0, 1.0 - (violations * 0.3))
    
    @staticmethod
    def completeness_score(output: str, required_elements: List[str]) -> float:
        """
        Score de completitud: verifica que todos los elementos requeridos estén presentes
        
        Args:
            output: Respuesta del LLM
            required_elements: Lista de elementos que deben estar presentes
                               (e.g., ["introducción", "conclusión", "ejemplo"])
        """
        if not required_elements:
            return 1.0
        
        output_lower = output.lower()
        found = sum(1 for elem in required_elements if elem.lower() in output_lower)
        return found / len(required_elements)

🚀 Quality Gates Implementation

Las quality gates son puntos de control que deciden si un output pasa o no a producción:

"""
Quality Gates — Puntos de control automatizados
"""
from typing import List, Optional, Callable, Any
from dataclasses import dataclass
from datetime import datetime
import json


@dataclass
class QualityGateResult:
    """Resultado de pasar por un gate"""
    gate_name: str
    passed: bool
    score: float
    threshold: float
    message: str
    timestamp: str = None
    
    def __post_init__(self):
        if self.timestamp is None:
            self.timestamp = datetime.utcnow().isoformat()


class QualityGate:
    """
    Quality Gate individual
    
    Un gate evalúa una condición específica y decide si el output procede.
    """
    
    def __init__(
        self,
        name: str,
        threshold: float,
        evaluator: Callable[[str, Any], float],
        fail_message: str = "Quality gate failed",
        metadata: dict = None
    ):
        self.name = name
        self.threshold = threshold
        self.evaluator = evaluator
        self.fail_message = fail_message
        self.metadata = metadata or {}
    
    def evaluate(self, output: str, context: Any = None) -> QualityGateResult:
        """Evalúa el output contra este gate"""
        try:
            score = self.evaluator(output, context)
            passed = score >= self.threshold
            
            message = f"{self.name}: {score:.2f} (threshold: {self.threshold})"
            if not passed:
                message = f"{message} - {self.fail_message}"
            
            return QualityGateResult(
                gate_name=self.name,
                passed=passed,
                score=score,
                threshold=self.threshold,
                message=message
            )
        except Exception as e:
            return QualityGateResult(
                gate_name=self.name,
                passed=False,
                score=0.0,
                threshold=self.threshold,
                message=f"{self.name}: Error evaluating - {str(e)}"
            )


class QualityPipeline:
    """
    Pipeline completo de Quality Gates
    
    Orchestrates múltiples gates y decide el destino final del output:
    - PRODUCTION: pasa todos los gates
    - REVIEW: pasa gates básicos pero falla en avanzados
    - REJECTED: falla gates críticos
    """
    
    class Decision(Enum):
        PRODUCTION = "production"
        REVIEW = "review"
        REJECTED = "rejected"
    
    def __init__(self):
        self.gates: List[QualityGate] = []
        self.stats = {
            "total_evaluated": 0,
            "production": 0,
            "review": 0,
            "rejected": 0
        }
    
    def add_gate(
        self,
        name: str,
        threshold: float,
        evaluator: Callable[[str, Any], float],
        fail_message: str = None,
        critical: bool = True
    ) -> "QualityPipeline":
        """Añade un gate al pipeline"""
        gate = QualityGate(
            name=name,
            threshold=threshold,
            evaluator=evaluator,
            fail_message=fail_message or f"{name} below threshold",
            metadata={"critical": critical}
        )
        self.gates.append(gate)
        return self
    
    def evaluate(self, output: str, context: Any = None) -> tuple[Decision, List[QualityGateResult]]:
        """
        Evalúa output contra todos los gates
        
        Returns:
            Tuple de (decisión, lista de resultados)
        """
        results = []
        critical_failed = False
        non_critical_failed = False
        
        for gate in self.gates:
            result = gate.evaluate(output, context)
            results.append(result)
            
            if not result.passed:
                if gate.metadata.get("critical", True):
                    critical_failed = True
                else:
                    non_critical_failed = True
        
        # Decidir basado en resultados
        if critical_failed:
            decision = self.Decision.REJECTED
        elif non_critical_failed:
            decision = self.Decision.REVIEW
        else:
            decision = self.Decision.PRODUCTION
        
        # Update stats
        self.stats["total_evaluated"] += 1
        self.stats[decision.value] += 1
        
        return decision, results
    
    def get_stats(self) -> dict:
        """Retorna estadísticas del pipeline"""
        total = self.stats["total_evaluated"]
        if total == 0:
            return self.stats.copy()
        
        return {
            **self.stats,
            "production_rate": self.stats["production"] / total,
            "review_rate": self.stats["review"] / total,
            "rejection_rate": self.stats["rejected"] / total
        }

📊 Sistema de Monitoreo de Calidad

QA no es solo evaluación puntual — necesitas trackear calidad en el tiempo:

"""
Quality Tracker — Monitoreo de calidad en el tiempo
"""
from dataclasses import dataclass, field
from typing import List, Dict, Optional
from datetime import datetime, timedelta
from collections import deque
import json


@dataclass
class QualityRecord:
    """Registro individual de evaluación"""
    timestamp: str
    quality_score: float
    decision: str
    failed_gates: List[str]
    metadata: Dict = field(default_factory=dict)


class QualityTracker:
    """
    Tracker de calidad con alertas y tendencias
    
    Funcionalidades:
    1. Almacena historial de evaluaciones
    2. Detecta tendencias (¿calidad subiendo o bajando?)
    3. Genera alertas cuando calidad cae bajo umbral
    4. Dashboard-ready: exporta métricas
    """
    
    def __init__(
        self,
        window_size: int = 1000,  # Últimas N evaluaciones para tendencias
        alert_threshold: float = 0.85,  # Alertar si avg cae bajo esto
        check_interval_minutes: int = 15
    ):
        self.window_size = window_size
        self.alert_threshold = alert_threshold
        self.check_interval = timedelta(minutes=check_interval_minutes)
        
        self.history: deque = deque(maxlen=window_size)
        self.alerts: List[Dict] = []
        self.last_check = datetime.utcnow()
        
        # Métricas acumuladas
        self.total_evaluated = 0
        self.total_passed = 0
    
    def record(
        self,
        quality_score: float,
        decision: str,
        failed_gates: List[str] = None,
        metadata: Dict = None
    ) -> Optional[Dict]:
        """
        Registra una nueva evaluación
        
        Returns alerta si se detectó anomalía, None si todo normal
        """
        failed_gates = failed_gates or []
        metadata = metadata or {}
        
        record = QualityRecord(
            timestamp=datetime.utcnow().isoformat(),
            quality_score=quality_score,
            decision=decision,
            failed_gates=failed_gates,
            metadata=metadata
        )
        
        self.history.append(record)
        self.total_evaluated += 1
        if decision == "production":
            self.total_passed += 1
        
        # Verificar si hay alerta
        alert = self._check_alert()
        if alert:
            self.alerts.append(alert)
        return alert
    
    def _check_alert(self) -> Optional[Dict]:
        """Verifica si las últimas evaluaciones justifican alerta"""
        now = datetime.utcnow()
        
        if now - self.last_check < self.check_interval:
            return None
        
        self.last_check = now
        
        if len(self.history) < 10:
            return None  # No enough data
        
        # Calcular promedio de últimas N
        recent_scores = [r.quality_score for r in list(self.history)[-50:]]
        avg_score = sum(recent_scores) / len(recent_scores)
        
        if avg_score < self.alert_threshold:
            return {
                "timestamp": now.isoformat(),
                "type": "quality_degradation",
                "avg_score": avg_score,
                "threshold": self.alert_threshold,
                "message": f"Quality avg ({avg_score:.2f}) below threshold ({self.alert_threshold})"
            }
        
        return None
    
    def get_trend(self) -> Dict:
        """
        Analiza tendencia de calidad
        
        Returns dict con:
        - direction: "improving", "stable", "degrading"
        - delta: cambio porcentual vs período anterior
        - prediction: score predicho para próximo período
        """
        if len(self.history) < 20:
            return {"direction": "unknown", "delta": 0.0, "prediction": 0.0}
        
        half = len(self.history) // 2
        first_half = [r.quality_score for r in list(self.history)[:half]]
        second_half = [r.quality_score for r in list(self.history)[half:]]
        
        first_avg = sum(first_half) / len(first_half)
        second_avg = sum(second_half) / len(second_half)
        
        delta = (second_avg - first_avg) / first_avg if first_avg > 0 else 0
        
        if delta > 0.05:
            direction = "improving"
        elif delta < -0.05:
            direction = "degrading"
        else:
            direction = "stable"
        
        # Simple linear prediction
        prediction = second_avg + delta * second_avg
        
        return {
            "direction": direction,
            "delta": delta,
            "prediction": max(0.0, min(1.0, prediction)),
            "current_avg": second_avg,
            "previous_avg": first_avg
        }
    
    def get_dashboard_metrics(self) -> Dict:
        """Métricas optimizadas para dashboard"""
        if not self.history:
            return {
                "total_evaluated": 0,
                "pass_rate": 0.0,
                "avg_quality": 0.0,
                "current_trend": "unknown"
            }
        
        recent = list(self.history)
        scores = [r.quality_score for r in recent]
        
        trend = self.get_trend()
        
        return {
            "total_evaluated": self.total_evaluated,
            "pass_rate": self.total_passed / self.total_evaluated if self.total_evaluated > 0 else 0.0,
            "avg_quality": sum(scores) / len(scores),
            "min_quality": min(scores),
            "max_quality": max(scores),
            "recent_count": len(recent),
            "current_trend": trend["direction"],
            "trend_delta_pct": trend["delta"] * 100,
            "active_alerts": len([a for a in self.alerts if datetime.fromisoformat(a["timestamp"]) > datetime.utcnow() - timedelta(hours=1)])
        }


# --- Demostración ---
if __name__ == "__main__":
    tracker = QualityTracker(alert_threshold=0.8)
    
    # Simular flujo de evaluaciones
    import random
    random.seed(42)
    
    print("=== Quality Tracker Demo ===\n")
    
    for i in range(100):
        # Simular scores que gradualmente mejoran
        base_score = 0.75 + (i / 100) * 0.2 + random.uniform(-0.1, 0.1)
        score = max(0.5, min(1.0, base_score))
        decision = "production" if score >= 0.8 else "review" if score >= 0.6 else "rejected"
        
        alert = tracker.record(
            quality_score=score,
            decision=decision,
            failed_gates=["safety"] if score < 0.7 else []
        )
        
        if alert:
            print(f"ALERT at {i}: {alert['message']}")
    
    print(f"\nFinal Metrics: {json.dumps(tracker.get_dashboard_metrics(), indent=2)}")
    print(f"\nTrend: {tracker.get_trend()}")

⚠️ Los 3 Errores Más Comunes

Error 1: No Tener Quality Gates

El problema: Dejar que todos los outputs lleguen a producción sin filtro.

Este es talvez el error más costoso. Equivale a desplegar código sin tests. Puede que funcione bien el 90% de las veces, pero ese 10% te va a dar problemas graves en producción, especialmente si estás en un dominio crítico como salud, finanzas o legal.

El fix: Implementa al menos 3 gates obligatorios desde el día uno:

# Gate mínimo viable para producción
pipeline = QualityPipeline()

# 1. Safety gate (crítico)
pipeline.add_gate(
    name="safety",
    threshold=0.95,
    evaluator=lambda o, c: QualityMetrics.safety_score(o, UNSAFE_PATTERNS),
    critical=True
)

# 2. Longitud gate (crítico)
pipeline.add_gate(
    name="min_length", 
    threshold=0.5,
    evaluator=lambda o, c: min(1.0, len(o.split()) / 30),
    critical=True
)

# 3. Coherence gate (crítico)
pipeline.add_gate(
    name="coherence",
    threshold=0.6,
    evaluator=lambda o, c: QualityMetrics.coherence_score(o),
    critical=True
)

# Si cualquier gate crítico falla → REJECTED
decision, results = pipeline.evaluate(output)
if decision == QualityPipeline.Decision.REJECTED:
    # Enviar a revisión humana o regenerar
    send_to_human_review(output, results)

Error 2: No Definir Métricas de Calidad

El problema: "Sabemos qué es calidad cuando la vemos" — pero eso no escala.

En producción con miles de requests, necesitas métricas objetivas y reproducibles. Si no las defines upfront, terminas dependiendo de feedback subjetivo que llega tarde y es inconsistente.

El fix: Define métricas antes de ir a producción:

# Definir métricas para tu caso de uso específico
CASE_METRICS = {
    "customer_support_chatbot": {
        "accuracy": QualityThreshold(QualityDimension.ACCURACY, min_score=0.85, weight=0.3),
        "safety": QualityThreshold(QualityDimension.SAFETY, min_score=0.98, weight=0.3),
        "relevance": QualityThreshold(QualityDimension.RELEVANCE, min_score=0.75, weight=0.25),
        "coherence": QualityThreshold(QualityDimension.COHERENCE, min_score=0.70, weight=0.15),
    },
    "code_generation": {
        "accuracy": QualityThreshold(QualityDimension.ACCURACY, min_score=0.90, weight=0.4),
        "completeness": QualityThreshold(QualityDimension.COMPLETENESS, min_score=0.85, weight=0.3),
        "conciseness": QualityThreshold(QualityDimension.CONCISENESS, min_score=0.60, weight=0.3),
    }
}

# Usar métricas específicas según el caso
def evaluate_for_use_case(output: str, use_case: str) -> QualityScore:
    thresholds = CASE_METRICS[use_case]
    
    scores = {}
    for dim, threshold in thresholds.items():
        if dim == QualityDimension.ACCURACY:
            score = QualityMetrics.accuracy_score(output, expected_facts)
        elif dim == QualityDimension.SAFETY:
            score = QualityMetrics.safety_score(output, unsafe_patterns)
        # ...
        scores[dim] = score
    
    overall = sum(s * t.weight for s, t in zip(scores.values(), thresholds.values()))
    passed = all(s >= t.min_score for s, t in zip(scores.values(), thresholds.values()))
    
    return QualityScore(overall, scores, passed, ...)

Error 3: No Trackear Tendencias de Calidad

El problema: Evaluar calidad en vacío sin contexto histórico.

Un score de 0.8 hoy puede ser bueno o malo dependiendo de la tendencia. Si la semana pasada promediabas 0.9, caer a 0.8 es una señal de alarma aunque 0.8 parezca "aceptable". Sin tracking histórico, pierdes la capacidad de detectar degradación antes de que se vuelva crítica.

El fix: Implementa tracking continuo desde el día uno:

# Tracker continuo en tu pipeline
tracker = QualityTracker(
    window_size=1000,
    alert_threshold=0.85,
    check_interval_minutes=5
)

def process_llm_request(prompt: str) -> str:
    output = llm.generate(prompt)
    
    # Evaluar y registrar
    decision, results = pipeline.evaluate(output)
    score = sum(r.score for r in results) / len(results)
    
    alert = tracker.record(
        quality_score=score,
        decision=decision.value,
        failed_gates=[r.gate_name for r in results if not r.passed]
    )
    
    if alert:
        # Alertar al equipo (PagerDuty, Slack, etc.)
        send_alert(alert)
        
        # Auto-remediación si es posible
        if decision == Decision.REJECTED:
            # Regenerar con parámetros más conservadores
            output = llm.generate(prompt, temperature=0.3, max_retries=2)
    
    return output

# Revisar dashboard diariamente
def daily_quality_review():
    metrics = tracker.get_dashboard_metrics()
    trend = tracker.get_trend()
    
    if trend["direction"] == "degrading":
        notify_engineering(
            f"Quality trending down: {trend['delta']*100:.1f}% change. "
            f"Current avg: {trend['current_avg']:.2f}"
        )
    
    return metrics

📊 Resumen y Recomendaciones

El framework de QA que te mostré tiene 4 componentes esenciales:

  • Métricas objetivas: Accuracy, relevance, coherence, safety, completeness
  • Quality Gates: Filtros automáticos que deciden destino (producción/revisión/rechazo)
  • Tracking histórico: Detectar tendencias antes de que sean problemas
  • Alertas automatizadas: Notificar cuando calidad cae bajo umbral

La regla de oro: No confíes en "se ve bien". Mide, trackea, y automatiza. El 10% que hace QA bien duerme tranquilo. El 90% que no lo hace está apagando incendios en producción.
