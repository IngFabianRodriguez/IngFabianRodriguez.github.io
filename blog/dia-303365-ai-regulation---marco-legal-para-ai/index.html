Intro - El Western Square de la IA

Imagina que estás en Bogotá en 1850. No hay leyes de tránsito, no hay patentes, no hay nada. Cualquiera puede robar tu caballo,没人管. Eso es internet en los años 90. Y eso es la IA en 2026. El EU AI Act acaba de entrar en vigencia, y la mayoría de las empresas están en modo pánico porque no tienen ni idea de qué hacer.

Hoy vamos a hablar de regulación de IA: qué existe, qué viene, y cómo el 10% de las empresas ya se están preparando mientras el 90% todavía piensa que "AI Regulation" es solo una palabra trending en Twitter.

El EU AI Act: La Primera Regulación Integral de IA

En agosto de 2024, la Unión Europeaimplementó el EU AI Act, el primer marco regulatorio comprehensivo para inteligencia artificial en el mundo. Es como el GDPR pero para IA — y es mucho más complejo.

El acto clasifica sistemas de IA en categorías de riesgo:

  • Riesgo Inaceptable (Prohibido): IA que manipula comportamiento, puntúa ciudadanos, o usa vigilancia subliminal.Nope.
  • Alto Riesgo: Contratación, crédito, educación, aplicación de ley, gestión de infraestructura crítica.Requiere evaluación de conformidad, documentación, y supervisión humana.
  • Riesgo Limitado: Chatbots, deepfakes, sistemas de recomendación.Obligaciones de transparencia.
  • Riesgo Mínimo: Filtros de spam, juegos, IA en background.No hay obligaciones especiales.

Las multas son brutales: hasta 35 millones de euros o 7% de revenue global por violaciones del artículo completo.

La Matemática del Compliance

Calcular el costo de compliance no es trivial. Necesitas entender:

$$\text{Costo Total} = C_{\text{documentación}} + C_{\text{auditoría}} + C_{\text{remediación}} + C_{\text{monitoreo}}$$

Donde cada componente tiene subcomponentes:

  • Documentación: $C_{doc} = h_{legal} \times r_{legal} \times t_{doc}$ — horas de legal × rate × tiempo
  • Auditoría: $C_{audit} = n_{sistemas} \times c_{audit\_por\_sistema}$
  • Remediación: $C_{rem} = \sum_{i=1}^{n_{hallazgos}} severidad_i \times esfuerzo_i \times costo\_por\_hora$
  • Monitoreo continuo: $C_{mon} = 12 \times r_{compliance\_officer}$

from dataclasses import dataclass, field
from typing import List, Dict, Optional, Tuple
from enum import Enum

class RiskLevel(Enum):
    """Niveles de riesgo según EU AI Act."""
    UNACCEPTABLE = "unacceptable"      # Prohibido
    HIGH = "high"                       # Alto riesgo
    LIMITED = "limited"                 # Riesgo limitado
    MINIMAL = "minimal"                 # Riesgo mínimo

class SystemCategory(Enum):
    """Categorías de sistemas de IA."""
    # Prohibidos
    MANIPULATION = "manipulation"
    SOCIAL_SCORING = "social_scoring"
    BIOMETRIC_SURVEILLANCE = "biometric_surveillance"
    
    # Alto riesgo
    HIRING = "hiring"                   # Empleo
    CREDIT = "credit"                   # Crédito
    EDUCATION = "education"             # Educación
    LAW_ENFORCEMENT = "law_enforcement" # Aplicación de ley
    INFRASTRUCTURE = "infrastructure"  # Infraestructura crítica
    
    # Riesgo limitado
    CHATBOT = "chatbot"
    DEEPFAKE = "deepfake"
    RECOMMENDER = "recommender"
    
    # Riesgo mínimo
    SPAM_FILTER = "spam_filter"
    GAME = "game"
    BACKGROUND_AI = "background_ai"

@dataclass
class AIProduct:
    """Producto de IA a evaluar."""
    name: str
    category: SystemCategory
    description: str
    uses_personal_data: bool = False
    has_human_oversight: bool = True
    is_transparent: bool = False
    registration_date: Optional[datetime] = None
    
    def classify_risk(self) -> RiskLevel:
        """Clasifica el riesgo del sistema según EU AI Act."""
        
        # Prohibidos
        if self.category in [
            SystemCategory.MANIPULATION,
            SystemCategory.SOCIAL_SCORING,
            SystemCategory.BIOMETRIC_SURVEILLANCE
        ]:
            return RiskLevel.UNACCEPTABLE
        
        # Alto riesgo
        elif self.category in [
            SystemCategory.HIRING,
            SystemCategory.CREDIT,
            SystemCategory.EDUCATION,
            SystemCategory.LAW_ENFORCEMENT,
            SystemCategory.INFRASTRUCTURE
        ]:
            return RiskLevel.HIGH
        
        # Riesgo limitado
        elif self.category in [
            SystemCategory.CHATBOT,
            SystemCategory.DEEPFAKE,
            SystemCategory.RECOMMENDER
        ]:
            return RiskLevel.LIMITED
        
        # Riesgo mínimo
        else:
            return RiskLevel.MINIMAL

    @classmethod
    def calculate_compliance_cost(
        cls,
        product: AIProduct,
        legal_rate: float = 200.0  # USD por hora de legal
    ) -> Dict:
        """Calcula costo total de compliance para un producto."""
        
        risk = product.classify_risk()
        requirements = cls.get_requirements(risk)
        
        # Costos base
        total_hours = sum(r.estimated_hours for r in requirements)
        total_cost = sum(r.estimated_cost for r in requirements)
        
        # Agregar costo de legal
        legal_cost = total_hours * legal_rate
        total_cost += legal_cost
        
        # Aplicar multiplicador de riesgo
        risk_multiplier = cls.RISK_COST_MULTIPLIERS[risk]
        adjusted_cost = total_cost * risk_multiplier if risk_multiplier > 0 else 0
        
        return {
            "product": product.name,
            "risk_level": risk.value,
            "category": product.category.value,
            "num_requirements": len(requirements),
            "estimated_hours": total_hours,
            "estimated_cost_usd": total_cost,
            "risk_adjusted_cost_usd": adjusted_cost,
            "max_fine_eur": cls.MAX_FINES[risk],
            "requirements": [
                {
                    "id": r.requirement_id,
                    "description": r.description,
                    "mandatory": r.mandatory,
                    "hours": r.estimated_hours,
                    "cost": r.estimated_cost
                }
                for r in requirements
            ]
        }

Los 3 Errores Que el 90% Comete

Error 1: Pensar Que "No Estoy en Europa, No Me Aplica"

Gran error. El EU AI Act tiene extraterritorialidad. Si tu producto o servicio afecta a ciudadanos europeos, aplica — aunque seas una startup en Bogotá.

¿Por qué está mal? El artículo 2 del EU AI Act establece que aplica a:

  • Proveedores que coloquen sistemas de IA en el mercado EU
  • Desplegadores de sistemas de IA ubicados en la EU
  • Proveedores y desplegadores fuera de la EU cuando el output se use dentro de la EU

La solución: Haz un análisis de extraterritorialidad. Si tienes хотя бы un usuario en EU, necesitas compliance.

Error 2: No Documentar Desde el Diseño

La documentación es la parte más ignorada. La gente piensa "ya documentaré después" — pero después es demasiado tarde y el costo se multiplica por 10.

¿Por qué está mal? Para sistemas de alto riesgo, necesitas documentar desde el inicio: datos de entrenamiento, arquitectura, validaciones, casos de uso, tutto. Sin esta documentación, no puedes certificar.

La solución: Implementa "compliance by design" desde el día 1. Usa templates predefinidos.

Error 3: No Hacer un Gap Analysis

Antes de empezar a cumplir, necesitas saber dónde estás hoy vs. dónde necesitas estar. Sin esto, es como navegar sin mapa.

¿Por qué está mal? Puedes gastar millones en compliance que no necesitas, o puedes descubrir tarde que te faltan requisitos críticos.

La solución: Realiza un gap analysis estructurado.

from typing import List, Tuple

class ComplianceGapAnalysis:
    """Análisis de brechas de compliance."""
    
    def __init__(self, product: AIProduct):
        self.product = product
        self.risk = product.classify_risk()
        self.requirements = EUAIActCompliance.get_requirements(self.risk)
        self.gaps: List[Tuple[str, str, str]] = []  # (req_id, requirement, gap_description)
        self.compliant: List[str] = []
    
    def assess_requirement(self, req_id: str, is_compliant: bool, gap_description: str = ""):
        """Evalúa un requisito individual."""
        if is_compliant:
            self.compliant.append(req_id)
        else:
            self.gaps.append((req_id, 
                            next(r.description for r in self.requirements if r.requirement_id == req_id),
                            gap_description))
    
    def generate_report(self) -> str:
        """Genera reporte de gap analysis."""
        
        compliance_rate = len(self.compliant) / len(self.requirements) * 100
        status = "COMPLIANT" if compliance_rate == 100 else "PARTIAL" if compliance_rate > 50 else "NON-COMPLIANT"
        
        report = f"""
# Gap Analysis Report - {self.product.name}

**Fecha:** {datetime.now().strftime('%Y-%m-%d')}
**Producto:** {self.product.name}
**Categoría:** {self.product.category.value}
**Nivel de Riesgo:** {self.risk.value.upper()}
**Estado:** {status}
**Tasa de Compliance:** {compliance_rate:.1f}%

---

## Resumen

- Total Requisitos: {len(self.requirements)}
- Requisitos Cumplidos: {len(self.compliant)}
- Brechas Identificadas: {len(self.gaps)}

---

## Requisitos Cumplidos ({len(self.compliant)})

"""
        for req_id in self.compliant:
            req = next(r for r in self.requirements if r.requirement_id == req_id)
            report += f"- [x] **{req.requirement_id}**: {req.description}\n"
        
        report += f"\n---\n\n## Brechas Identificadas ({len(self.gaps)})\n\n"
        for req_id, desc, gap in self.gaps:
            report += f"- [ ] **{req_id}**: {desc}\n"
            report += f"  - Brecha: {gap}\n"
            report += f"  - Acción requerida: Por definir\n\n"
        
        report += f"\n---\n\n## Estimación de Costo de Remediación\n\n"
        for req_id, desc, gap in self.gaps:
            req = next(r for r in self.requirements if r.requirement_id == req_id)
            report += f"- {req_id}: {req.estimated_hours}h / ${req.estimated_cost:,.0f}\n"
        
        total_hours = sum(r.estimated_hours for _, _, _ in self.gaps)
        total_cost = sum(r.estimated_cost for _, _, _ in self.gaps)
        report += f"\n**Total:** {total_hours}h / ${total_cost:,.0f}\n"
        
        return report

# Ejemplo de uso
def demo_gap_analysis():
    """Demuestra el análisis de brechas."""
    
    product = AIProduct(
        name="Hiring AI v2.0",
        category=SystemCategory.HIRING,
        description="Sistema de selección de candidatos"
    )
    
    analysis = ComplianceGapAnalysis(product)
    
    # Evaluar requisitos existentes
    analysis.assess_requirement("HIGH-001", is_compliant=True)
    analysis.assess_requirement("HIGH-002", is_compliant=False, 
                                  gap_description="No se ha realizado evaluación de conformidad")
    analysis.assess_requirement("HIGH-003", is_compliant=False,
                                  gap_description="Falta documentación técnica de datos de entrenamiento")
    analysis.assess_requirement("HIGH-004", is_compliant=True)
    analysis.assess_requirement("HIGH-005", is_compliant=True)
    analysis.assess_requirement("HIGH-006", is_compliant=False,
                                  gap_description="Usuarios no son notificados que interactúan con IA")
    analysis.assess_requirement("HIGH-007", is_compliant=False,
                                  gap_description="No hay informes de testing de robustness")
    analysis.assess_requirement("HIGH-008", is_compliant=False,
                                  gap_description="No existe plan de monitoreo post-market")
    
    print(analysis.generate_report())

Qué Viene en el Futuro

El EU AI Act es solo el comienzo. Otras jurisdicciones están siguiendo:

  • EE.UU.: Varias propuestas de ley a nivel federal y estatal (Colorado AI Act, California proposals)
  • Brasil: Projeto de Lei 2338/2023 — marco de IA en discusión
  • China: Regulations on Generative AI Services (2023)
  • UK: AI Safety Institute creado en 2024

La tendencia global es hacia más regulación, no menos. El 90% de las empresas están esperando a que sea obligatorio — el 10% está invirtiendo en compliance proactivo y va a tener ventaja competitiva.
