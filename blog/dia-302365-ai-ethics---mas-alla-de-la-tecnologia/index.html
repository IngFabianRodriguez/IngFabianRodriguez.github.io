Cuando el Algoritmo Decide, ¿Quién es Responsable?

En un tribunal de Rotterdam, un sistema de IA recomendaba sentencias. En un hospital de Boston, otro decidía qué pacientes recibían cuidados intensivos. En una ciudad de China, el sistema de crédito social determinaba quién podía viajar. En los tres casos, cuando las cosas salieron mal, nadie sabía exactamente quién era responsable: ¿el desarrollador del algoritmo, la empresa que lo compró, el gobierno que lo implementó?

La ética en IA no es un tema académico. Es el problema más práctico que tenemos. Y el 85% de las empresas que deployan IA lo ignoran hasta que algo sale mal públicamente.

Los 5 Dilemas Éticos Fundamentales

1. Bias y Discriminación Algorítmica

Los modelos aprenden de datos históricos. Y los datos históricos reflejan sesgos humanos. Si entrenas un hiring model con datos de los últimos 30 años, donde el 90% de gerentes fueron hombres, el modelo aprenderá que ser hombre = buen gerente.

"""
Detección de sesgos en modelos de ML
Framework para análisis de fairness.
"""

import numpy as np
import pandas as pd
from typing import Dict, List
from dataclasses import dataclass

@dataclass
class FairnessMetrics:
    """Métricas de equidad algorítmica."""
    demographic_parity: float  # Diferencia en tasa de aprobación entre grupos
    equalized_odds: float  # Diferencia en TPR y FPR entre grupos
    calibration: float  # Que predicciones sean calibradas por grupo
    individual_fairness: float  # Similar inputs → similar outputs

class BiasDetector:
    """
    Detecta y mide sesgos en modelos de ML.
    """
    
    def __init__(self, protected_attributes: List[str]):
        """
        Args:
            protected_attributes: Lista de atributos protegidos 
            (género, raza, edad, etc.)
        """
        self.protected_attrs = protected_attributes
    
    def compute_fairness_metrics(
        self, 
        y_true: np.ndarray, 
        y_pred: np.ndarray,
        sensitive_features: pd.DataFrame
    ) -> Dict[str, FairnessMetrics]:
        """
        Calcula métricas de fairness para cada grupo protegido.
        """
        results = {}
        
        for attr in self.protected_attrs:
            groups = sensitive_features[attr].unique()
            
            # Separar por grupo
            group_0_mask = sensitive_features[attr] == groups[0]
            group_1_mask = sensitive_features[attr] == groups[1]
            
            # Métricas por grupo
            tpr_g0 = self._true_positive_rate(y_true[group_0_mask], y_pred[group_0_mask])
            tpr_g1 = self._true_positive_rate(y_true[group_1_mask], y_pred[group_1_mask])
            
            fpr_g0 = self._false_positive_rate(y_true[group_0_mask], y_pred[group_0_mask])
            fpr_g1 = self._false_positive_rate(y_true[group_1_mask], y_pred[group_1_mask])
            
            # Demographic parity
            rate_g0 = y_pred[group_0_mask].mean()
            rate_g1 = y_pred[group_1_mask].mean()
            demographic_parity = abs(rate_g0 - rate_g1)
            
            # Equalized odds
            tpr_diff = abs(tpr_g0 - tpr_g1)
            fpr_diff = abs(fpr_g0 - fpr_g1)
            equalized_odds = (tpr_diff + fpr_diff) / 2
            
            results[attr] = FairnessMetrics(
                demographic_parity=demographic_parity,
                equalized_odds=equalized_odds,
                calibration=self._calibration_score(y_true, y_pred, sensitive_features[attr]),
                individual_fairness=0.0  # Requiere definir similaridad
            )
        
        return results
    
    def _true_positive_rate(self, y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """Tasa de verdaderos positivos (recall)."""
        if sum(y_true) == 0:
            return 0.0
        return sum((y_true == 1) & (y_pred == 1)) / sum(y_true)
    
    def _false_positive_rate(self, y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """Tasa de falsos positivos."""
        neg = sum(y_true == 0)
        if neg == 0:
            return 0.0
        return sum((y_true == 0) & (y_pred == 1)) / neg
    
    def _calibration_score(
        self, 
        y_true: np.ndarray, 
        y_pred: np.ndarray,
        sensitive_attr: pd.Series
    ) -> float:
        """Calibración por grupo: P(Y=1 | pred=1, grupo) ≈ P(Y=1 | grupo)."""
        scores = []
        for group in sensitive_attr.unique():
            mask = sensitive_attr == group
            if sum(mask) > 0:
                pred_pos_rate = y_pred[mask].mean()
                true_pos_rate = y_true[mask].mean()
                if pred_pos_rate > 0:
                    calibration = min(true_pos_rate / pred_pos_rate, 2.0)  # Cap at 2
                    scores.append(abs(1 - calibration))
        return 1 - np.mean(scores) if scores else 1.0

# Ejemplo de uso
detector = BiasDetector(protected_attributes=['gender', 'race', 'age'])

# Datos simulados
np.random.seed(42)
n = 1000
y_true = np.random.randint(0, 2, n)
y_pred = (y_true + np.random.randint(-1, 2, n)) > 0.5
y_pred = y_pred.astype(int)

sensitive = pd.DataFrame({
    'gender': np.random.choice(['M', 'F'], n),
    'race': np.random.choice(['A', 'B', 'W'], n),
    'age': np.random.choice(['<30', '30-50', '>50'], n)
})

metrics = detector.compute_fairness_metrics(y_true, y_pred, sensitive)

for attr, m in metrics.items():
    print(f"\n{attr.upper()}:")
    print(f"  Demographic Parity: {m.demographic_parity:.3f}")
    print(f"  Equalized Odds: {m.equalized_odds:.3f}")
    print(f"  Calibration: {m.calibration:.3f}")

2. Transparencia y Explicabilidad

El 70% de los modelos en producción son black boxes. Nadie sabe exactamente por qué el modelo rechazó tu préstamo, aprobó tu cirugía, o flagged tu transacción como fraudulenta. Y en muchos casos, ni siquiera el desarrollador puede explicarlo.

Regulation como el GDPR exigen "explicable AI" para decisiones automatizadas que afectan individuos. Pero hacer un modelo interpretable sin sacrificar performance es difícil.

"""
Explicabilidad de modelos con SHAP
Framework para entender predicciones.
"""

import shap
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

class ModelExplainer:
    """
    Explicador de modelos usando SHAP para entender decisiones.
    """
    
    def __init__(self, model, feature_names: List[str]):
        self.model = model
        self.feature_names = feature_names
        self.explainer = None
        self.shap_values = None
    
    def compute_shap_values(self, X: np.ndarray):
        """Calcula valores SHAP para explicar predicciones."""
        if hasattr(self.model, 'predict_proba'):
            self.explainer = shap.TreeExplainer(self.model)
        else:
            self.explainer = shap.LinearExplainer(self.model, X)
        
        self.shap_values = self.explainer.shap_values(X)
        return self.shap_values
    
    def explain_prediction(
        self, 
        X_instance: np.ndarray,
        top_n: int = 5
    ) -> List[Dict]:
        """
        Explica una predicción individual.
        Returns: Lista de features más importantes con dirección.
        """
        if self.shap_values is None:
            self.compute_shap_values(X_instance.reshape(1, -1))
            shap_vals = self.shap_values
        else:
            shap_vals = self.explainer.shap_values(X_instance.reshape(1, -1))
        
        # Para clasificación, usar clase positiva
        if isinstance(shap_vals, list):
            shap_vals = shap_vals[1]  # Clase positiva
        
        feature_importance = [
            {
                'feature': self.feature_names[i],
                'shap_value': shap_vals[0, i],
                'contribution': 'increases' if shap_vals[0, i] > 0 else 'decreases'
            }
            for i in range(len(shap_vals[0]))
        ]
        
        # Ordenar por valor absoluto
        feature_importance.sort(key=lambda x: abs(x['shap_value']), reverse=True)
        
        return feature_importance[:top_n]
    
    def plot_feature_importance(self, X: np.ndarray, save_path: str = None):
        """Grafica importancia de features."""
        if self.shap_values is None:
            self.compute_shap_values(X)
        
        shap.summary_plot(self.shap_values, X, feature_names=self.feature_names)

# Ejemplo
X = pd.DataFrame({
    'age': np.random.randint(18, 70, 1000),
    'income': np.random.randint(20000, 200000, 1000),
    'credit_score': np.random.randint(300, 850, 1000),
    'employment_years': np.random.randint(0, 40, 1000)
})
y = (X['credit_score'] > 600) & (X['income'] > 50000)

model = RandomForestClassifier(n_estimators=100)
model.fit(X, y)

explainer = ModelExplainer(model, X.columns.tolist())
explanation = explainer.explain_prediction(X.iloc[0].values)

print("Top 5 factores para esta decisión:")
for item in explanation:
    print(f"  {item['feature']}: {item['contribution']} probabilidad (SHAP: {item['shap_value']:.3f})")

3. Privacidad y Consentimiento

Los modelos de ML memorizan datos de entrenamiento. En algunos casos, pueden regurgitar datos específicos si les preguntas de la forma correcta. Esto viola expectativas razonable de privacidad.

Reglamentos como GDPR, CCPA, y Ley de Habeas Data en Colombia establecen que:

  • Los individuos tienen derecho a saber qué datos se usan sobre ellos
  • Tienen derecho a corregir datos inaccurate
  • Tienen derecho a borrar sus datos ("right to be forgotten")
  • El consentimiento debe ser informado y revocable
"""
Privacy-preserving ML techniques
Framework para entrenar modelos respetando privacidad.
"""

from typing import Dict, List, Tuple
import numpy as np
from dataclasses import dataclass

@dataclass
class PrivacyBudget:
    """Presupuesto de privacidad (epsilon-differential privacy)."""
    epsilon: float
    delta: float
    
    def __repr__(self):
        return f"(ε={self.epsilon:.2f}, δ={self.delta:.2e})"

class PrivacyPreservingML:
    """
    Técnicas de ML que preservan privacidad.
    """
    
    @staticmethod
    def add_laplace_noise(sensitivity: float, epsilon: float, size: int) -> np.ndarray:
        """
        Añade ruido Laplace para differential privacy.
        """
        scale = sensitivity / epsilon
        return np.random.laplace(0, scale, size)
    
    @staticmethod
    def train_with_dp_gradient_descent(
        X: np.ndarray,
        y: np.ndarray,
        epsilon: float,
        learning_rate: float = 0.01,
        epochs: int = 100
    ) -> np.ndarray:
        """
        Entrena modelo lineal con gradient descent differentially private.
        """
        n_features = X.shape[1]
        weights = np.zeros(n_features)
        sensitivity = 2 * learning_rate / len(X)  # Bound on gradient
        
        for epoch in range(epochs):
            # Gradient sin ruido
            predictions = X @ weights
            errors = predictions - y
            gradient = X.T @ errors / len(X)
            
            # Añadir ruido Laplace
            noise = PrivacyPreservingML.add_laplace_noise(sensitivity, epsilon, n_features)
            noisy_gradient = gradient + noise
            
            # Update
            weights -= learning_rate * noisy_gradient
        
        return weights
    
    @staticmethod
    def compute_privacy_budget(
        epochs: int,
        sample_rate: float,
        epsilon: float,
        delta: float
    ) -> PrivacyBudget:
        """
        Computa el presupuesto de privacidad usado.
        Usa composition theorem para DP.
        """
        # Subsampled Gaussian mechanism
        sigma = np.sqrt(2 * np.log(1.25 / delta)) / (epsilon * sample_rate)
        
        return PrivacyBudget(epsilon=epsilon, delta=delta)

# Ejemplo
np.random.seed(42)
X = np.random.randn(1000, 5)
true_weights = np.array([1.5, -0.5, 2.0, 0.0, -1.0])
y = X @ true_weights + np.random.randn(1000) * 0.1

# Entrenar con privacidad
private_weights = PrivacyPreservingML.train_with_dp_gradient_descent(X, y, epsilon=1.0)

print(f"Weights originales: {true_weights}")
print(f"Weights con DP:     {private_weights}")
print(f"Error:              {np.abs(private_weights - true_weights).mean():.3f}")

budget = PrivacyPreservingML.compute_privacy_budget(epochs=100, sample_rate=0.01, epsilon=1.0, delta=1e-5)
print(f"Presupuesto de privacidad: {budget}")

4. Responsabilidad y Rendición de Cuentas (Accountability)

Cuando un coche autónomo mata a alguien, ¿quién es responsable? ¿El fabricante del carro? ¿El desarrollador del software? ¿El dueño del carro? ¿El gobierno que aprobó el vehículo?

No existe todavía un marco legal claro en ningún país. Pero frameworks como la EU AI Act están intentando definir quién responde por qué.

  • High-risk AI systems: Requieren evaluación de conformidad, registro, documentación, y monitoreo continuo
  • Transparency obligations: Sistemas deben informar que son IA
  • Human oversight: Humanos deben poder revisar e interrumpir decisiones de IA

5. Impacto en el Empleo y Desigualdad

El 60% de las occupations actuales tendrán algún componente automatizado en los próximos 10 años. No significa que desaparecerán, pero cambiarán.

El riesgo: la automatización beneficia desproporcionadamente a quienes poseen capital (dueños de empresas, stockholders) sobre quienes viven de su trabajo. Sin intervención, la desigualdad aumenta.

Frameworks Éticos para IA Responsable

  • IEEE Ethically Aligned Design: Principios éticos para sistemas autônomos e inteligentes
  • OECD AI Principles: Principios intergovernmental para IA trustworthy
  • EU AI Act: Regulación comprehensiva de IA en Europa
  • NIST AI Risk Management Framework: Framework del gobierno de US para gestionar riesgos de IA

Cómo Implementar Ética en Tu Proyecto

No es opcional. regulatorias como GDPR y EU AI Act lo exigen. Y más importante, es lo correcto.

  1. Data audit: Revisa tus datos por sesgos antes de entrenar
  2. Fairness testing: Evalúa performance por grupo demográfico
  3. Explainability: Usa SHAP, LIME, o modelos intrínsecamente interpretables cuando sea possible
  4. Documentation: Mantén model cards con limitaciones y casos de uso intended
  5. Human oversight: Diseña flujos donde humanos pueden override decisiones
  6. Privacy by design: Usa differential privacy, federated learning, o data minimization

Resumen

  • Bias: Audita y mitiga sesgos en datos y modelos
  • Transparency: Haz que tus modelos sean explicables
  • Privacy: Respeta consentimiento y usa técnicas privacy-preserving
  • Accountability: Define quién es responsable de cada decisión
  • Impact: Considera efectos en empleo y desigualdad

La fórmula:
Responsible_AI = Fairness × Transparency × Privacy × Accountability × Human_Oversight

En Rotterdam, el tribunal ahora tiene un equipo de 5 personas dedicadas exclusivamente a auditar las decisiones algorítmicas. En Boston, cada recomendación del sistema de triaje pasa por un médico que puede override. En China, el debate sobre el crédito social escala al nivel más alto del gobierno.
