Hagale pues, parcero. Día 260 y hoy voy a hablarte de algo que el 85% IGNORA y que puede ahorrarte el 70% de tus costos de inference: Caching y Semantic Caching. Si estás pagando $0.01 por cada query a tu LLM y el 40% de tus usuarios preguntan lo mismo 3 veces... pues ahí tienes el problema.短局部变量 oKey takeaway: cada query que no cacheas es dinero quemado.

En Colombia, una fintech mediana procesa 50K conversaciones de soporte al mes con un LLM. Sin cache, eso son $500/mes en inference. Con semantic cache efectivo, bajan a $150/mes. La diferencia: $350/mes ahorrados, o $4,200/año. Eso paga un viaje a San Andrés, parcero.

🔎 ¿Por qué Caching?

El problema fundamental: las queries se repiten. No importa qué chatbot construyas:

  • Preguntas frecuentes (FAQ) — "¿cómo resetear mi contraseña?"
  • Explicaciones técnicas — "¿qué es RAG?"
  • Instrucciones de uso — "¿cómo hago el reporte?"
  • Respuestas comunes — confirmaciones, saludos, despedidas

La matemática:

Sin cache: cada query = 1 inference call = costo total

Con cache: cache hit = 0 inference calls = costo ~0

Cache hit rate = hits / (hits + misses)

Si tu cache hit rate es 0.4 y tienes 10K queries/mes a $0.01/query:

Costo sin cache = 10,000 × $0.01 = $100/mes

Costo con cache = 6,000 × $0.01 + 4,000 × $0 = $60/mes

¡50% de ahorro con solo cache básico!

📐 Exact Cache vs Semantic Cache

Exact Cache (Cache Exacto)

La forma más simple: guardar hash de query → respuesta.

import hashlib
from typing import Optional, Dict, Any

class ExactCache:
    """
    Exact cache: misma query exacta = cache hit.
    Funciona bien para queries literales repetidas.
    """
    
    def __init__(self, max_size: int = 10000):
        self.cache: Dict[str, Dict] = {}
        self.max_size = max_size
    
    def _hash_query(self, query: str) -> str:
        """Hash SHA256 de la query exacta."""
        return hashlib.sha256(query.encode()).hexdigest()
    
    def get(self, query: str) -> Optional[Dict]:
        """Devuelve respuesta cacheada si existe."""
        key = self._hash_query(query)
        return self.cache.get(key)
    
    def set(self, query: str, response: Dict, metadata: Dict = None) -> None:
        """Guarda query → respuesta."""
        if len(self.cache) >= self.max_size:
            # Evict oldest (FIFO)
            oldest_key = next(iter(self.cache))
            del self.cache[oldest_key]
        
        key = self._hash_query(query)
        self.cache[key] = {
            "response": response,
            "metadata": metadata or {},
            "query": query  # Guardar para debug
        }
    
    def invalidate(self, query: str) -> None:
        """Invalida una entrada específica."""
        key = self._hash_query(query)
        self.cache.pop(key, None)
    
    def clear(self) -> None:
        """Limpia todo el cache."""
        self.cache.clear()

# Demo
cache = ExactCache(max_size=1000)

query = "¿Cómo resetear mi contraseña?"
response = {"answer": "Ve a Configuración > Seguridad > Resetear contraseña"}

cache.set(query, response)
cached = cache.get(query)

print(f"Cache hit: {cached is not None}")
print(f"Respuesta: {cached['response']['answer']}")

Semantic Cache (Cache Semántico)

El problema del exact cache: "resetear clave" ≠ "¿cómo resetear mi contraseña?" (aunque significan lo mismo). Para eso existe semantic cache.

import numpy as np
from typing import Optional, List, Dict, Tuple
from sentence_transformers import SentenceTransformer

class SemanticCache:
    """
    Semantic cache: queries semánticamente similares = cache hit.
    
    Usa embeddings para medir similitud semántica.
    ERROR COMÚN #3: sin tune threshold → false positives.
    
    Si el threshold es muy bajo, "cómo matar gente" y "cómo cocinar arroz"
    se consideran similares. threshold correcto es domain-specific.
    """
    
    def __init__(
        self,
        max_size: int = 5000,
        embedding_model: str = "sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2",
        similarity_threshold: float = 0.85  # Ajustar según dominio!
    ):
        self.max_size = max_size
        self.similarity_threshold = similarity_threshold
        
        # Embedding model (multilingual para español)
        self.encoder = SentenceTransformer(embedding_model)
        
        # Almacenamiento
        self.queries: List[str] = []  # Queries originales
        self.embeddings: np.ndarray = None  # Embeddings pre-computados
        self.responses: List[Dict] = []  # Respuestas cacheadas
        self.hit_count = 0
        self.miss_count = 0
    
    def _get_embedding(self, query: str) -> np.ndarray:
        """Computa embedding para una query."""
        return self.encoder.encode(query, convert_to_numpy=True)
    
    def _compute_similarity(self, emb1: np.ndarray, emb2: np.ndarray) -> float:
        """Similitud coseno entre dos embeddings."""
        # Normalizar
        emb1_norm = emb1 / np.linalg.norm(emb1)
        emb2_norm = emb2 / np.linalg.norm(emb2)
        return float(np.dot(emb1_norm, emb2_norm))
    
    def get(self, query: str) -> Tuple[Optional[Dict], float]:
        """
        Busca query en cache.
        Devuelve (response, similarity_score).
        Si score < threshold, es cache miss.
        """
        if not self.queries:
            self.miss_count += 1
            return None, 0.0
        
        query_emb = self._get_embedding(query)
        
        # Buscar el más similar
        best_idx = -1
        best_similarity = 0.0
        
        for i, cached_emb in enumerate(self.embeddings):
            sim = self._compute_similarity(query_emb, cached_emb)
            if sim > best_similarity:
                best_similarity = sim
                best_idx = i
        
        if best_idx >= 0 and best_similarity >= self.similarity_threshold:
            self.hit_count += 1
            return self.responses[best_idx], best_similarity
        
        self.miss_count += 1
        return None, best_similarity
    
    def set(self, query: str, response: Dict) -> None:
        """Añade query + embedding al cache."""
        # Evict si está lleno (FIFO)
        if len(self.queries) >= self.max_size:
            self.queries.pop(0)
            self.embeddings = self.embeddings[1:]
            self.responses.pop(0)
        
        query_emb = self._get_embedding(query)
        
        if self.embeddings is None:
            self.embeddings = query_emb.reshape(1, -1)
        else:
            self.embeddings = np.vstack([self.embeddings, query_emb])
        
        self.queries.append(query)
        self.responses.append(response)
    
    def get_stats(self) -> Dict:
        """Estadísticas del cache."""
        total = self.hit_count + self.miss_count
        hit_rate = self.hit_count / total if total > 0 else 0.0
        
        return {
            "hits": self.hit_count,
            "misses": self.miss_count,
            "hit_rate": hit_rate,
            "size": len(self.queries),
            "max_size": self.max_size,
            "threshold": self.similarity_threshold
        }

# Demo
cache = SemanticCache(similarity_threshold=0.85)

# Queries de ejemplo
q1 = "¿Cómo resetear mi contraseña?"
r1 = {"answer": "Ve a Configuración > Seguridad > Resetear contraseña"}

q2 = "¿Cómo puedo cambiar mi clave?"

# Queries similares deberían hit

print(f"Query 1: hit={result1 is not None}, score={score1:.3f}")
print(f"Query 2: hit={result2 is not None}, score={score2:.3f}")
print(f"Stats: {cache.get_stats()}")

📊 Midiendo Cache Efficiency

def measure_cache_efficiency(cache: SemanticCache, test_queries: List[str]) -> Dict:
    """
    Mide efficiency del cache con un set de queries de prueba.
    
    Métricas clave:
    - Hit rate: % de queries servidas desde cache
    - Average similarity: similitud promedio de hits
    - Coverage: % de queries únicas que fueron cacheadas
    """
    results = {
        "total_queries": len(test_queries),
        "cache_hits": 0,
        "cache_misses": 0,
        "similarity_scores": [],
        "unique_queries_cached": set()
    }
    
    for query in test_queries:
        response, similarity = cache.get(query)
        
        if response is not None:
            results["cache_hits"] += 1
            results["similarity_scores"].append(similarity)
        else:
            results["cache_misses"] += 1
            # Simular que guardamos la respuesta
            cache.set(query, {"generated": True})
            results["unique_queries_cached"].add(query)
    
    total = results["cache_hits"] + results["cache_misses"]
    results["hit_rate"] = results["cache_hits"] / total if total > 0 else 0
    results["avg_similarity"] = np.mean(results["similarity_scores"]) if results["similarity_scores"] else 0
    results["coverage"] = len(results["unique_queries_cached"]) / len(test_queries) if test_queries else 0
    
    return results

# Ejemplo de uso
test_queries = [
    "¿Cómo resetear mi contraseña?",
    "¿Cómo puedo cambiar mi clave?",
    "¿Olvidé mi password",
    "¿Qué es un embedding vectorial?",
    "¿Cómo funcionan los embeddings?",
    "¿Cómo resetear mi contraseña?",  # Repetida
    "¿Cómo cambiar mi clave?",  # Similar a anterior
]

stats = measure_cache_efficiency(cache, test_queries)
print(f"Hit rate: {stats['hit_rate']:.1%}")
print(f"Avg similarity (hits): {stats['avg_similarity']:.3f}")
print(f"Coverage: {stats['coverage']:.1%}")
print(f"Cache size: {len(cache.queries)}")

🔄 Invalidation Strategies

ERROR COMÚN #2: Cache sin invalidation = stale responses

Si actualizas tu base de conocimiento y no invalidas el cache, los usuarios siguen obteniendo respuestas obsoletas. Hay que invalidar.

from datetime import datetime, timedelta
from enum import Enum

class InvalidationStrategy(Enum):
    TTL = "time_to_live"  # Invalidar por tiempo
    LRU = "least_recently_used"  # Evict menos usado
    TAG_BASED = "tag_based"  # Invalidar por tags/categorías
    VERSION_BASED = "version_based"  # Invalidar por versión de datos

class CacheWithInvalidation(SemanticCache):
    """
    Semantic cache con estrategias de invalidación.
    """
    
    def __init__(self, *args, invalidation: InvalidationStrategy = InvalidationStrategy.TTL, ttl_seconds: int = 3600, **kwargs):
        super().__init__(*args, **kwargs)
        self.invalidation = invalidation
        self.ttl_seconds = ttl_seconds
        self.timestamps: List[datetime] = []
        self.tags: List[set] = []  # Tags por entrada
        self.data_version = 1
    
    def set(self, query: str, response: Dict, tags: set = None) -> None:
        """Añade con timestamp y tags."""
        super().set(query, response)
        self.timestamps.append(datetime.now())
        self.tags.append(tags or set())
    
    def _is_valid(self, index: int) -> bool:
        """Check si una entrada sigue siendo válida."""
        if self.invalidation == InvalidationStrategy.TTL:
            age = datetime.now() - self.timestamps[index]
            return age.total_seconds() < self.ttl_seconds
        
        # LRU y otros requerirían tracking adicional
        return True
    
    def get(self, query: str) -> Tuple[Optional[Dict], float]:
        """Get con check de validity."""
        response, similarity = super().get(query)
        
        # Encontrar el índice del resultado
        if response is not None:
            # Buscar índice matching
            for i, (q, r) in enumerate(zip(self.queries, self.responses)):
                if r == response and i < len(self.timestamps):
                    if not self._is_valid(i):
                        # Invalidar y devolver miss
                        self._invalidate_index(i)
                        return None, 0.0
        
        return response, similarity
    
    def _invalidate_index(self, index: int) -> None:
        """Invalida entrada por índice."""
        self.queries.pop(index)
        self.embeddings = np.delete(self.embeddings, index, axis=0)
        self.responses.pop(index)
        self.timestamps.pop(index)
        self.tags.pop(index)
    
    def invalidate_by_tag(self, tag: str) -> int:
        """Invalida todas las entradas con un tag."""
        invalidated = 0
        i = 0
        while i < len(self.tags):
            if tag in self.tags[i]:
                self._invalidate_index(i)
                invalidated += 1
            else:
                i += 1
        return invalidated
    
    def invalidate_all(self) -> None:
        """Invalida todo el cache."""
        self.queries.clear()
        self.embeddings = None
        self.responses.clear()
        self.timestamps.clear()
        self.tags.clear()
    
    def bump_version(self) -> None:
        """Invalidar todo cuando cambia la versión de datos."""
        self.data_version += 1
        self.invalidate_all()

# Demo invalidation
cache = CacheWithInvalidation(
    invalidation=InvalidationStrategy.TTL,
    ttl_seconds=60  # 1 minuto para demo
)

cache.set("¿Qué es RAG?", {"answer": "RAG es..."}, tags={"tech", "llm"})
print(f"Cache size antes: {len(cache.queries)}")

# Simular paso del tiempo (en código real usar time.sleep)

# Query que debería invalidar por TTL si pasó el tiempo

print(f"Response after 1s (TTL=60s): {response is not None}")

⚠️ Los 3 Errores Fatales

Error 1: No cachear y recomputar las mismas responses

El problema: En producción, el 30-50% de las queries son duplicados o variaciones de queries anteriores. Sin cache, estás pagando inference cost por cada una. En una startup con 100K queries/mes a $0.002/query, eso son $200/mes desperdiciados.

La solución: Implementa semantic cache desde el día 1. Mide tu hit rate y optimiza el threshold.

Error 2: Cache sin invalidation causing stale responses

El problema: Si actualizas tu producto, FAQ, o base de conocimiento y no invalidas el cache semántico, sigues devolviendo información obsoleta. Los usuarios preguntan "¿cuál es el precio del plan premium?" y obtienen el precio de hace 6 meses.

La solución: Implementa TTL (time-to-live) + invalidation por tags cuando actualices contenido. Si cambias precios, invalida entradas con tag "pricing".

Error 3: Semantic cache sin tune threshold (false positives)

El problema: Si el threshold es muy bajo (ej: 0.6), queries muy distintas se consideran "similares". "¿Cómo cocinar arroz?" y "¿Cómo hacer paella?" podrían dar el mismo resultado si comparten embeddings cercanos, aunque sean cosas distintas.

La solución: Tunea el threshold con datos de producción. Empieza en 0.85-0.90 para texto en español. Mide false positive rate (queries que dio hit pero eran incorrectas) y ajusta.

# Cómo tunejar threshold
def tune_semantic_threshold(
    cache: SemanticCache,
    validation_queries: List[Tuple[str, bool]],  # (query, expected_hit)
    thresholds: List[float] = [0.7, 0.75, 0.8, 0.85, 0.9, 0.95]
) -> Dict:
    """
    Encuentra el threshold óptimo midiendo precision y recall.
    
    precision = true_hits / (true_hits + false_hits)
    recall = true_hits / total_expected_hits
    """
    results = {}
    
    for threshold in thresholds:
        cache.similarity_threshold = threshold
        
        true_positives = 0
        false_positives = 0
        false_negatives = 0
        
        for query, expected_hit in validation_queries:
            response, _ = cache.get(query)
            actual_hit = response is not None
            
            if expected_hit and actual_hit:
                true_positives += 1
            elif expected_hit and not actual_hit:
                false_negatives += 1
            elif not expected_hit and actual_hit:
                false_positives += 1
        
        precision = true_positives / (true_positives + false_positives) if (true_positives + false_positives) > 0 else 0
        recall = true_positives / (true_positives + false_negatives) if (true_positives + false_negatives) > 0 else 0
        f1 = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
        
        results[threshold] = {"precision": precision, "recall": recall, "f1": f1}
    
    # Mejor threshold por F1
    best_threshold = max(results, key=lambda t: results[t]["f1"])
    return {"results": results, "best_threshold": best_threshold}

✅ Resumen

Hagale pues, parcero. Lo esencial del día:

  • Exact cache = misma query exacta (case-sensitive). Rápido pero limitado.
  • Semantic cache = queries similares semanticamente. Más flexible, requiere embeddings.
  • Hit rate = hits / total. Mide qué % de queries se sirven desde cache.
  • Invalidation = TTL, tags, o version-based. Sin esto, cache = stale data.
  • Threshold tuning = domain-specific. Empieza en 0.85-0.90 para español.
  • El 85% ignora caching → 70% de costos de inference desperdiciados.

Short version: cada query que no cacheas es plata que echas al agua. 🇨🇴
