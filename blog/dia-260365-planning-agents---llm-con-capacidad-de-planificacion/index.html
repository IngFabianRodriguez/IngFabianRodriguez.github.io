Planning Agents - LLM Con Capacidad de Planificacion

17 de septiembre de 2026
planningagentsllmstrategy

☕ Intro

Hagale pues, parcero. Día 260 y hoy vamos a hablar de algo que el 80% de los practitioners de agentes IGNORAN: Planning Agents. Si tu agente hace las cosas sin un plan, sin pensar en la secuencia de pasos, sin anticipar obstáculos... pues eso no es un agente, es un script chamarrón.

En una empresa de logística en Medellín, tenían un chatbot que procesaba órdenes de envío. El bot hacía las cosas en orden aleatorio: a veces cobraba primero, a veces verificaba inventario después, a veces neither. El resultado: 30% de errores en órdenes. La solución: un agent con capacidad de planificación que define la secuencia óptima de acciones antes de ejecutar.

🔎 ¿Qué es un Planning Agent?

Un Planning Agent es un agente que, dado un objetivo, delibera y genera un plan (secuencia de acciones) antes de ejecutar. No actúa impulsivamente — razona primero.

La diferencia con ReAct:

  • ReAct: pensamiento y acción entrelazados, un paso a la vez
  • Planning Agent: piensa en TODOS los pasos primero, luego ejecuta el plan

📐 El Proceso de Planificación

El pipeline clásico:

Goal → Decompose → Plan → Execute → Monitor → Revise

Step 1: Goal Decomposition

Dividir el objetivo en sub-objetivos manejables:

def decompose_goal(goal: str, llm) -> List[str]:
    """
    Descompone un objetivo en sub-objetivos.
    
    Ejemplo:
    Input: "Organizar una fiesta de cumpleaños"
    Output: ["Definir presupuesto", "Invitar amigos", "Comprar comida", 
             "Decorar lugar", "Preparar juegos"]
    """
    prompt = f"""Descompón el siguiente objetivo en 5-8 pasos concretos
    y ordenados cronologicamente.
    
    Objetivo: {goal}
    
    Devuelve una lista de pasos, uno por linea."""
    
    response = llm.complete(prompt)
    steps = [s.strip() for s in response.split("\n") if s.strip()]
    return steps

# Ejemplo
goal = "Desplegar una aplicacion web en produccion"
steps = decompose_goal(goal, llm)
for i, step in enumerate(steps, 1):
    print(f"{i}. {step}")

Step 2: Plan Generation

from dataclasses import dataclass
from typing import List, Optional

@dataclass
class Action:
    name: str
    description: str
    preconditions: List[str]  # Que debe ser verdad antes de esta accion
    effects: List[str]        # Que cambia despues de esta accion
    tool: Optional[str] = None

@dataclass
class PlanStep:
    step_number: int
    action: Action
    params: dict
    expected_state: dict

class PlanningAgent:
    """
    Agente con capacidad de planificacion.
    
    Usa un LLM para generar planes estructurados
    y luego los ejecuta paso a paso.
    """
    
    def __init__(self, llm, tools: List, max_replan: int = 3):
        self.llm = llm
        self.tools = tools
        self.max_replan = max_replan
    
    def plan(self, goal: str) -> List[PlanStep]:
        """
        Genera un plan para alcanzar el objetivo.
        """
        # 1. Descomponer objetivo
        sub_goals = self.decompose(goal)
        
        # 2. Crear plan estructurado
        plan = []
        for i, sub_goal in enumerate(sub_goals):
            action = self.select_action(sub_goal)
            plan.append(PlanStep(
                step_number=i + 1,
                action=action,
                params={"goal": sub_goal},
                expected_state=self.get_expected_state(action, sub_goal)
            ))
        
        return plan
    
    def execute_plan(self, plan: List[PlanStep]) -> dict:
        """
        Ejecuta el plan paso a paso.
        Si un paso falla, replanifica.
        """
        results = []
        state = {}
        
        for step in plan:
            # Verificar precondiciones
            if not self.check_preconditions(step.action, state):
                # Replanificar desde este punto
                remaining_goals = [s.params["goal"] for s in plan[step.step_number:]]
                new_plan = self.replan(remaining_goals, state)
                results.extend(self.execute_plan(new_plan))
                return results
            
            # Ejecutar accion
            result = self.execute_action(step.action, step.params)
            state.update(result)
            results.append({"step": step.step_number, "result": result})
        
        return results
    
    def decompose(self, goal: str) -> List[str]:
        """Descompone el objetivo en sub-objetivos."""
        prompt = f"""Para el objetivo: {goal}
        
        Lista 5-8 sub-objetivos ordenados.
        Formato: uno por linea, sin numeros."""
        
        response = self.llm.complete(prompt)
        return [s.strip() for s in response.split("\n") if s.strip()]
    
    def select_action(self, sub_goal: str) -> Action:
        """Selecciona la mejor accion para un sub-objetivo."""
        # Logica de seleccion de accion
        for tool in self.tools:
            if tool.can_handle(sub_goal):
                return Action(
                    name=tool.name,
                    description=tool.description,
                    preconditions=tool.preconditions,
                    effects=tool.effects,
                    tool=tool.name
                )
        
        return Action(
            name="general",
            description=f"Accion para: {sub_goal}",
            preconditions=[],
            effects=[sub_goal]
        )
    
    def execute_action(self, action: Action, params: dict) -> dict:
        """Ejecuta una accion."""
        for tool in self.tools:
            if tool.name == action.tool:
                return tool.run(**params)
        return {"status": "no_tool_found"}
    
    def check_preconditions(self, action: Action, state: dict) -> bool:
        """Verifica si las precondiciones de la accion se cumplen."""
        for pre in action.preconditions:
            if pre not in state:
                return False
        return True
    
    def get_expected_state(self, action: Action, goal: str) -> dict:
        """Predice el estado despues de ejecutar la accion."""
        return {**action.effects, "goal_achieved": goal}
    
    def replan(self, remaining_goals: List[str], current_state: dict) -> List[PlanStep]:
        """Genera un nuevo plan dado el estado actual."""
        # Logica de replanificacion
        full_goal = " AND ".join(remaining_goals)
        return self.plan(full_goal)

🔄 Replanificación

El planning agent debe manejar fallos y replanificar:

class RobustPlanningAgent(PlanningAgent):
    """
    Planning agent con capacidad de replanificacion.
    Si un paso falla, analiza el error y genera nuevo plan.
    """
    
    def execute_plan(self, plan: List[PlanStep]) -> dict:
        results = []
        state = {}
        execution_attempts = 0
        
        for step in plan:
            success = False
            attempts = 0
            
            while not success and attempts < 3:
                try:
                    # Verificar precondiciones
                    if not self.check_preconditions(step.action, state):
                        # Replanificar
                        remaining = [s.params["goal"] for s in plan[step.step_number:]]
                        new_plan = self.replan_with_state(remaining, state)
                        results.extend(self.execute_plan(new_plan))
                        return results
                    
                    # Ejecutar
                    result = self.execute_action(step.action, step.params)
                    state.update(result)
                    results.append({
                        "step": step.step_number,
                        "action": step.action.name,
                        "result": result,
                        "success": True
                    })
                    success = True
                    
                except Exception as e:
                    attempts += 1
                    results.append({
                        "step": step.step_number,
                        "action": step.action.name,
                        "error": str(e),
                        "attempt": attempts
                    })
                    
                    if attempts >= 3:
                        # Analizar error y replanificar
                        error_analysis = self.analyze_error(step, e, state)
                        recovery_plan = self.generate_recovery_plan(error_analysis, state)
                        results.extend(self.execute_plan(recovery_plan))
                        return results
        
        return results
    
    def analyze_error(self, step: PlanStep, error: Exception, state: dict) -> dict:
        """Analiza por que fallo el paso."""
        prompt = f"""Analiza el error en el paso '{step.action.name}'.
        
        Error: {str(error)}
        Estado actual: {state}
        Objetivo del paso: {step.params}
        
        Explica:
        1. Por que fallo
        2. Como afecta al plan general
        3. Que se necesita para recuperarse"""
        
        return self.llm.complete_json(prompt)
    
    def generate_recovery_plan(self, error_analysis: dict, state: dict) -> List[PlanStep]:
        """Genera un plan de recuperacion."""
        recovery_goals = error_analysis.get("recovery_actions", [])
        plan = []
        
        for i, goal in enumerate(recovery_goals):
            action = self.select_action(goal)
            plan.append(PlanStep(
                step_number=i + 1,
                action=action,
                params={"goal": goal},
                expected_state=self.get_expected_state(action, goal)
            ))
        
        return plan

⚖️ Planning vs Reactive

Planning Agent:

  • Piensa antes de actuar
  • Genera un plan completo
  • Mejor para tareas complejas con múltiples pasos
  • Puede anticipar obstáculos

Reactive Agent:

  • Actúa y observa en cada paso
  • No tiene vista global del plan
  • Mejor para entornos dinámicos
  • Mas simple de implementar

⚠️ Errores Comunes

Error 1: Sobreplanificación

El problema: Planear 50 pasos de ahead cuando solo necesitas 5. Overhead de planificación sin beneficio.

La solución: Limita la profundidad del plan inicial (5-8 pasos) y replanifica según necesidad.

Error 2: Plan Rígido

El problema: No hay replanificación cuando las cosas fallan. El agente sigue el plan aunque sea obvio que no va a funcionar.

La solución: Implementa checkpointing y replanificación con análisis de errores.

Error 3: Sin Monitoreo

El problema: Ejecutar el plan sin verificar que cada paso funciona. Errores se acumulan.

La solución: Añade verificación post-acción: "did this actually work?" antes de proceder.

✅ Resumen

Hagale pues, lo esencial del día:

  • Planning Agent = piensa antes de actuar. Genera un plan completo antes de ejecutar.
  • Pipeline: Goal → Decompose → Plan → Execute → Monitor → Revise
  • Replanificación es clave: cuando algo falla, analiza y genera nuevo plan.
  • Planning vs Reactive: Planning para tareas complejas, Reactive para entornos dinámicos.
  • No sobreplanifiques: limita profundidad inicial, replanifica según necesidad.
