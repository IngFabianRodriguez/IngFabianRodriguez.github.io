Whisper - El Modelo de OpenAI para Transcription

17 de julio de 2026

Que Es Whisper?

Hagale pues, parcero. Dia 198 y hoy vamos a hablar de Whisper - el modelo de OpenAI que revoluciono la transcripcion de audio a texto. A diferencia de otros modelos ASR que requieren fine-tuning especifico por idioma o dominio, Whisper fue entrenado con 680,000 horas de audio multilingual y puede transcribir casi cualquier cosa sin adaptation. Vamos a ver como funciona internamente, por que es tan bueno, y como usarlo en produccion. Sirvete otro tintico y vamos pa'lla.

Arquitectura de Whisper

Whisper es un modelo seq2seq basado en Transformers con una arquitectura encoder-decoder:

  • Encoder: Convierte Mel spectrograms a una representacion de alta dimensi\u00f3n
  • Decoder: Genera tokens de texto autoregresivamente usando cross-attention
  • 660M parametros en la version base (hay variantes de 39M a 1550M)

La diferencia clave con otros modelos ASR es que Whisper no usa CTC - usa cross-attention completa entre el audio y el texto generado.

Tokenizacion

Whisper usa GPT-2 byte pair encoding (BPE) tokenizer. Esto le permite manejar cualquier idioma y incluso caracteres especiales sin problemas.

Variantes de Whisper

OpenAI liberó varias versiones de Whisper:

  • tiny: 39M params, 4x realtime en CPU
  • base: 74M params, 6x realtime en CPU
  • small: 244M params, 16x realtime en CPU
  • medium: 769M params, 32x realtime en CPU
  • large: 1550M params, 60x realtime en CPU

La version large-v3 es la mas precisa pero requiere GPU para inference en tiempo real.

Usando Whisper en PyTorch

import torch
from transformers import WhisperProcessor, WhisperForConditionalGeneration

def load_whisper_model(model_size="base"):
    """
    Carga el modelo Whisper y el processor.
    """
    model_name = f"openai/whisper-{model_size}"
    
    processor = WhisperProcessor.from_pretrained(model_name)
    model = WhisperForConditionalGeneration.from_pretrained(model_name)
    
    return processor, model


def transcribe_audio(audio_array, sample_rate, processor, model, device="cuda"):
    """
    Transcribe audio array a texto.
    
    Args:
        audio_array: numpy array con samples de audio
        sample_rate: sample rate del audio (tipicamente 16000)
        processor: WhisperProcessor
        model: WhisperForConditionalGeneration
        device: 'cuda' o 'cpu'
    """
    model = model.to(device)
    
    # Preprocesar audio
    input_features = processor(
        audio_array, 
        sampling_rate=sample_rate, 
        return_tensors="pt"
    ).input_features.to(device)
    
    # Generar
    forced_decoder_ids = processor.get_decoder_prompt_ids(language="es", task="transcribe")
    
    generated_ids = model.generate(
        input_features,
        forced_decoder_ids=forced_decoder_ids,
        max_new_tokens=448,
    )
    
    # Decodificar
    transcription = processor.batch_decode(generated_ids, skip_special_tokens=True)[0]
    
    return transcription


# Ejemplo de uso completo
audio, sample_rate = torchaudio.load("audio.wav")

processor, model = load_whisper_model("base")
transcription = transcribe_audio(audio.squeeze().numpy(), sample_rate, processor, model)
print(f"Transcription: {transcription}")

from transformers import WhisperForConditionalGeneration

def load_quantized_model(model_size="base"):
    """
    Carga el modelo con quantizacion INT8 para reducir memoria.
    """
    model_name = f"openai/whisper-{model_size}"
    
    model = WhisperForConditionalGeneration.from_pretrained(
        model_name,
        torch_dtype=torch.float16,
        load_in_8bit=True,
        device_map="auto"
    )
    
    return model


def batch_transcribe(audio_arrays, sample_rate, processor, model, device="cuda"):
    """
    Transcribe multiples audios en batch para mayor throughput.
    """
    # Preprocesar todos los audios
    inputs = processor(
        [audio.squeeze().numpy() for audio in audio_arrays],
        sampling_rate=sample_rate,
        return_tensors="pt",
        padding=True
    ).input_features.to(device)
    
    # Generar con batch
    generated_ids = model.generate(
        inputs,
        max_new_tokens=448,
    )
    
    # Decodificar
    transcriptions = processor.batch_decode(generated_ids, skip_special_tokens=True)
    
    return transcriptions

Fine-Tuning Whisper para Dominio Especifico

Aunque Whisper funciona bien out-of-the-box, para casos de uso especificos puede beneficiarse de fine-tuning.

from transformers import WhisperForConditionalGeneration, WhisperProcessor
from datasets import load_dataset

def prepare_dataset(batch, processor):
    """
    Prepara un batch para entrenamiento.
    """
    # Compute mel spectrograms
    audio = batch["audio"]
    
    features = processor(
        audio["array"],
        sampling_rate=audio["sampling_rate"],
        return_tensors="pt"
    )
    
    return {
        "input_features": features.input_features[0],
        "labels": processor.tokenizer(batch["text"]).input_ids
    }


def fine_tune_whisper(model_name, train_dataset, eval_dataset, output_dir):
    """
    Fine-tune de Whisper en un dataset especifico.
    """
    processor = WhisperProcessor.from_pretrained(model_name)
    model = WhisperForConditionalGeneration.from_pretrained(model_name)
    
    # Configure model for Spanish
    model.config.forced_decoder_ids = None
    model.config.suppress_tokens = []
    
    # Training arguments
    from transformers import TrainingArguments, Trainer
    
    training_args = TrainingArguments(
        output_dir=output_dir,
        per_device_train_batch_size=8,
        gradient_accumulation_steps=2,
        learning_rate=1e-5,
        warmup_steps=500,
        max_steps=4000,
        gradient_checkpointing=True,
        fp16=True,
        evaluation_strategy="steps",
        save_strategy="steps",
    )
    
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=train_dataset,
        eval_dataset=eval_dataset,
        tokenizer=processor.feature_extractor,
    )
    
    trainer.train()

Errores Comunes con Whisper

Error 1: No Especificar el Idioma

El problema: Sin especificar el idioma, el modelo puede mezclar idiomas o elegir el incorrecto, especialmente en multilingual audio.

# MAL: Sin forzar idioma
generated_ids = model.generate(input_features)

# BIEN: Forzar idioma español
forced_decoder_ids = processor.get_decoder_prompt_ids(language="es", task="transcribe")
generated_ids = model.generate(input_features, forced_decoder_ids=forced_decoder_ids)

Error 2: Usar el Modelo Incorrecto para el Hardware

El problema: Usar large en CPU es practicamente unusable (60x realtime).

# MAL: Para inference en CPU
model = load_whisper_model("large")  # 1550M params, 60x realtime!

# BIEN: Para CPU, usar tiny o base
model = load_whisper_model("base")  # 74M params, 6x realtime

Resumen y Cierre

Hoy cubrimos Whisper - el modelo de transcripcion de OpenAI:

  • Arquitectura: Transformer encoder-decoder seq2seq
  • Entrenamiento: 680k horas de audio multilingual
  • Variantes: Desde 39M hasta 1550M parametros
  • Uso: No requiere fine-tuning para la mayoria de casos
  • Eficiencia: Cuantizacion INT8 para produccion

Whisper cambio el juego para ASR porque demuestra que mas datos y un modelo mas grande puede superar a modelos especificos por dominio. El future es modelos foundation para audio.
