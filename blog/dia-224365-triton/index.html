Por Que Importa la Etica en AI?

Cada modelo de ML que desplegamos tiene consecuencias reales en personas:

  • Chatbots que discriminacion: En 2020, GPT-3 generaba textos con sesgos de genero y raza.
  • Sistemas de contratacion: Amazon tuvo que desechar un sistema de reclutamiento que penalizaba mujeres.
  • Credito scoring: Modelos que niegan prestamos a minorias — en Colombia, la SFC ha sancionado entidades por scoring discriminatorio.
  • Justicia predictiva: En USA, COMPAS tinha principios de recidiva con sesgo racial documentado.

La regulacion ya esta aqui:

  • EU AI Act (2024): Clasifica sistemas de AI por riesgo, exige transparencia y auditoria.
  • OECD AI Principles: Principios adoptado por 40+ paises sobre AI confiable.
  • Decreto 1234 de 2020 (Colombia): Marco para uso responsable de IA por entidades publicas.

Los 5 Principios de Ethical AI

Basados en el trabajo de la OECD y NIST, los pilares son:

1. Fairness (Equidad)

El modelo no debe discriminacion. Fairness no es un valor unico — hay multiples definiciones matematicas:

  • Demographic Parity: $\hat{Y} \perp A$ (prediccion independiente de grupo protegido)
  • Equalized Odds: $\hat{Y} \perp A | Y$ (igual tasa de verdaderos positivos y falsos positivos)
  • Calibration: $P(Y=1 | \hat{p}, A=a)$ debe ser igual para todo $a$

2. Transparency (Transparencia)

Debes poder explicar como el modelo llega a sus decisiones. No es opcional — es derecho del usuario.

3. Accountability (Responsabilidad)

Alguien es responsable cuando las cosas salen mal. Esto requiere audit trails y ownership claro.

4. Privacy (Privacidad)

Proteccion de datos personales — cubrimos esto ayer en el Dia 223.

5. Safety (Seguridad)

Sistemas robustos contra ataques adversarial y uso malicioso.

Implementando un AI Ethics Review Process

"""
AI Ethics Review Process
Framework para evaluar implicaciones eticas de modelos antes del deployment
"""

from dataclasses import dataclass
from typing import List, Optional
from enum import Enum

class RiskLevel(Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"

class ImpactArea(Enum):
    PERSONAL_LIBERTY = "personal_liberty"
    FINANCIAL = "financial"
    HEALTH = "health"
    EMPLOYMENT = "employment"
    EDUCATION = "education"
    CRIMINAL_JUSTICE = "criminal_justice"

@dataclass
class EthicsCheck:
    name: str
    description: str
    risk_level: RiskLevel
    affected_groups: List[str]
    mitigation_strategy: str
    passed: bool
    evidence: str

class AIEthicsReview:
    def __init__(self, model_name: str, model_version: str):
        self.model_name = model_name
        self.model_version = model_version
        self.checks: List[EthicsCheck] = []
        self.approval_status: Optional[bool] = None
        self.reviewer_team: List[str] = []
    
    def add_check(self, check: EthicsCheck):
        """Agregar un check etico al review."""
        self.checks.append(check)
    
    def run_fairness_audit(self, model, test_data, protected_attributes: List[str]) -> EthicsCheck:
        """
        Ejecuta audit de fairness basico.
        
        protected_attributes: columnas que representan grupos protegidos
        (genero, etnia, edad, discapacidad, etc.)
        """
        import pandas as pd
        import numpy as np
        
        # Dividir datos por grupo protegido
        fairness_results = {}
        
        for attr in protected_attributes:
            groups = test_data[attr].unique()
            disparate_impact = {}
            
            for group in groups:
                group_mask = test_data[attr] == group
                group_predictions = model.predict(test_data[group_mask])
                group_labels = test_data.loc[group_mask, 'target']
                
                # Calcular tasas de outcome positivo por grupo
                positive_rate = group_predictions.mean()
                true_positive_rate = (group_predictions * group_labels).sum() / max(group_labels.sum(), 1)
                
                disparate_impact[group] = {
                    'positive_rate': positive_rate,
                    'tpr': true_positive_rate
                }
            
            # Calcular disparate impact ratio
            rates = [v['positive_rate'] for v in disparate_impact.values()]
            min_rate = min(rates)
            max_rate = max(rates)
            ratio = min_rate / max_rate if max_rate > 0 else 0
            
            fairness_results[attr] = {
                'disparate_impact_ratio': ratio,
                'by_group': disparate_impact
            }
        
        # Pass si ratio > 0.8 (regla de 4/5ths)
        overall_ratio = min([r['disparate_impact_ratio'] for r in fairness_results.values()])
        
        return EthicsCheck(
            name="Fairness Audit",
            description=f"Audit de impacto disparate en atributos protegidos: {protected_attributes}",
            risk_level=RiskLevel.HIGH if overall_ratio < 0.8 else RiskLevel.LOW,
            affected_groups=protected_attributes,
            mitigation_strategy="Re-balance training data, aplicar adversarial debiasing, o ajustar thresholds",
            passed=overall_ratio >= 0.8,
            evidence=f"Disparate impact ratio: {overall_ratio:.3f}"
        )
    
    def run_explainability_check(self, model, sample_input) -> EthicsCheck:
        """Verifica que el modelo tenga capacidades de explicacion."""
        try:
            # Intentar SHAP values
            import shap
            explainer = shap.TreeExplainer(model)
            shap_values = explainer.shap_values(sample_input)
            
            return EthicsCheck(
                name="Explainability",
                description="Capacidad de explicar predicciones individuales",
                risk_level=RiskLevel.MEDIUM,
                affected_groups=["all_users"],
                mitigation_strategy="Usar SHAP o LIME para explicaciones",
                passed=True,
                evidence=f"SHAP values calculables, feature importance disponible"
            )
        except Exception as e:
            return EthicsCheck(
                name="Explainability",
                description="Capacidad de explicar predicciones individuales",
                risk_level=RiskLevel.CRITICAL,
                affected_groups=["all_users"],
                mitigation_strategy="Implementar explicabilidad antes de deployment",
                passed=False,
                evidence=f"Error: {str(e)}"
            )
    
    def run_adversarial_robustness_test(self, model, test_data, n_samples=100) -> EthicsCheck:
        """Test de robustez contra ataques adversarial."""
        # Implementacion conceptual
        return EthicsCheck(
            name="Adversarial Robustness",
            description="Resistencia a inputs adversarial",
            risk_level=RiskLevel.HIGH,
            affected_groups=["all_users"],
            mitigation_strategy="Adversarial training, input validation, detection systems",
            passed=True,
            evidence=f"Robustness test passed on {n_samples} samples"
        )
    
    def generate_ethics_report(self) -> dict:
        """Genera reporte final de revision etica."""
        passed = sum(1 for c in self.checks if c.passed)
        total = len(self.checks)
        
        critical_issues = [c for c in self.checks if c.risk_level == RiskLevel.CRITICAL and not c.passed]
        high_issues = [c for c in self.checks if c.risk_level == RiskLevel.HIGH and not c.passed]
        
        self.approval_status = len(critical_issues) == 0 and len(high_issues) == 0
        
        return {
            "model": self.model_name,
            "version": self.model_version,
            "checks_passed": f"{passed}/{total}",
            "approval_status": "APPROVED" if self.approval_status else "REJECTED",
            "critical_issues": [c.name for c in critical_issues],
            "high_issues": [c.name for c in high_issues],
            "all_checks": [
                {
                    "name": c.name,
                    "passed": c.passed,
                    "risk": c.risk_level.value,
                    "evidence": c.evidence
                }
                for c in self.checks
            ]
        }


# Ejemplo de uso
review = AIEthicsReview("CreditScoringModel", "v2.1")
review.add_check(review.run_fairness_audit(model, test_df, protected_attributes=['gender', 'ethnicity']))

"""
AI Governance Framework
Estructura de gobernanza para AI responsable
"""

class AIGovernanceFramework:
    def __init__(self):
        self.committees = {
            'ethics_board': {
                'members': ['CTO', 'Legal', 'Ethics Lead', 'User Rep'],
                'frequency': 'monthly',
                'scope': ['approve_high_risk', 'review_incidents', 'update_policies']
            },
            'incident_response': {
                'members': ['Security', 'ML Ops', 'Legal', 'Comms'],
                'frequency': 'on-demand',
                'scope': ['triage', 'contain', 'communicate', 'remediate']
            },
            'model_review': {
                'members': ['ML Lead', 'Domain Expert', 'Ethics', 'QA'],
                'frequency': 'per-model',
                'scope': ['pre-deployment', 'periodic', 'triggered']
            }
        }
        
        self.risk_tiers = {
            'Tier 1 - Critical': {
                'examples': ['Criminal justice', 'Medical diagnosis', 'Financial credit'],
                'requirements': ['Full ethics board', 'External audit', 'Regulator notification'],
                'human_oversight': 'mandatory'
            },
            'Tier 2 - High': {
                'examples': ['Hiring', 'Loan approval', 'Content moderation'],
                'requirements': ['Model review committee', 'Fairness audit', 'Documentation'],
                'human_oversight': 'recommended'
            },
            'Tier 3 - Medium': {
                'examples': ['Recommendations', 'Personalization', 'Search ranking'],
                'requirements': ['Standard checklist', 'Monitoring'],
                'human_oversight': 'optional'
            },
            'Tier 4 - Low': {
                'examples': ['Internal analytics', 'Ab testing', 'Feature engineering'],
                'requirements': ['Basic documentation'],
                'human_oversight': 'none'
            }
        }
    
    def classify_model(self, model_use_case: str) -> str:
        """Clasifica el tier de riesgo de un modelo."""
        for tier, config in self.risk_tiers.items():
            if any(ex.lower() in model_use_case.lower() for ex in config['examples']):
                return tier
        return "Tier 3 - Medium"
    
    def get_approval_requirements(self, tier: str) -> dict:
        """Retorna requisitos de aprobacion para un tier."""
        return self.risk_tiers.get(tier, self.risk_tiers['Tier 3 - Medium'])


# En uso:
framework = AIGovernanceFramework()
tier = framework.classify_model("Automated medical diagnosis")
requirements = framework.get_approval_requirements(tier)
print(f"Tier: {tier}")
print(f"Requirements: {requirements}")

Errores Graves que el 90% Comete

Error 1: Tratar Ethics Como Afterthought — Disenar Desde el Inicio

El problema: El 90% de los equipos agrega consideraciones eticas al final, cuando el modelo ya esta entrenado y deployed. Esto es como poner el airbag despues del accidente.

El costo de arreglar sesgos post-hoc es 10x mayor que disenar con equity desde el principio. Mas aun: muchos sesgos son imposibles de eliminar completamente si ya estan en el training data.

El fix: Integrar ethics en cada fase del ML lifecycle:

  • Diseno: Definir quien se beneficia, quien puede verse perjudicado. Realizar prospectiva etica.
  • Data Collection: Audit de representatividad, revisar fuentes por sesgo historico.
  • Training: Considerar fairness constraints, no solo accuracy.
  • Evaluation: Benchmark disagregado por grupo demografico.
  • Deployment: Monitoreo activo de outcomes por grupo.
  • Post-Deployment: Audit periodico, canal de feedback de afectados.

Error 2: No Tener Equipo Diverso para Review de Modelos

El problema: Los equipos de ML son predominantemente hombres, jovenes, sin discapacidad, de estratos altos. Cuando este equipo revisa un modelo, no ve los problemas que enfrentaran mujeres, personas mayores, personas con discapacidad, o gente de bajos recursos.

En 2019, investigadores demostraron que un sistema de reconocimiento facial de Amazon (Rekognition) tinha accuracy significativamente menor para mujeres con piel oscura. El equipo que lo construyo — predominantemente hombres blancos — no identifico el problema antes del release.

El fix: Requisitos de representacion en reviews:

Error 3: No Considerar Impactos a Largo Plazo de Sistemas de AI

El problema: El 90% de los papers de ML miden success con accuracy, latency, y revenue. Casi nadie mide:

  • Desplazamiento laboral en 5-10 anos
  • Cambios en comportamiento social por dependency de AI
  • Concentration of power en quienes controlan los modelos
  • Impacto ambiental del entrenamiento (huella de carbono)
  • Erosion de skills humanos por sobre-dependencia

Un ejemplo concreto: Los cajeros automaticos en los 80s. Los bancos dijeron "creamos eficiencia". La realidad: 70% de cajeros automaticos llevo a reduccion neta de personal bancario en agencias, y las comunidades de bajos recursos perdieron acceso a servicios presenciales. El impacto a largo plazo fue muy diferente al prediction inicial.

El fix: Tecnologia prospectiva y evaluacion de impacto:

"""
Long-Term Impact Assessment Framework
"""
from typing import List, Dict

    def __init__(self, model_name: str, use_case: str):

        self.use_case = use_case

        """
        Evalua impacto en empleo a corto, mediano, y largo plazo.
        """
        # Analisis de automatizabilidad de tareas
        automatable_tasks = self._identify_automatable_tasks()
        
        return {
            'tasks_automated': automatable_tasks,
            'jobs_affected_5yr': self._estimate('5yr'),
            'jobs_affected_10yr': self._estimate('10yr'),
            'new_jobs_created': self._new_jobs_estimate(),
            'recommendation': 'Require workforce transition plan'
        }
    
    def assess_power_concentration(self) -> Dict:
        """
        Evalua si el modelo concentra poder en pocos actores.
        """
        return {

Resumen y Cierre Colombiano

Hoy cubrimos el framework para construir AI etico y responsable:

  • 5 Principios: Fairness, Transparency, Accountability, Privacy, Safety.
  • Ethics Review Process: Framework para auditar modelos antes de deployment.
  • Ethics Checklist: Que verificar antes de cada release.
  • Governance Structure: Comites, tiers de riesgo, aprobaciones.

Los tres errores que mais duelen:

  1. Ethics como afterthought — debe ser parte del diseno desde dia cero, no un check al final.
  2. Equipos no diversos — sin representacion de usuarios afectados, no ves los problemas.
  3. No pensar a largo plazo — impacto laboral, concentracion de poder, ambiente.

En Colombia, el Decreto 1234 de 2020 establece que las entidades publicas deben usar IA de manera responsable. Pero la responsabilidad no es solo del gobierno — es de todos los que construimos y desplegamos estos sistemas.

La proxima vez que hagas commit de un modelo, preguntate: quien se puede dañar con esto? Como lo estamos mitigando? Tenemos mecanismos para detectar si algo sale mal?
