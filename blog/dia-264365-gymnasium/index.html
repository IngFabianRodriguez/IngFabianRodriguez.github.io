🎯 Por Qué Safety en Agentes Es Crítico

Hagale pues, parcero. Un modelo de lenguaje que se equivoca en una respuesta es un problema. Pero un agente autónomo que puede ejecutar acciones — enviar emails, modificar datos, hacer transacciones — si se sale de control, las consecuencias son otra historia. El 70% implementa agentes sin safeguards y el 20% que los implementa, muchos lo hacen mal. Hoy aprendemos a construir agentes seguros desde el día uno.

📐 El Problema: Agentes Pueden Hacer Daño Real

Un LLM tradicional solo genera texto. Un agente autónomo:

  • Ejecuta herramientas: puede modificar sistemas reales
  • Tiene Agency: toma decisiones que afectan el mundo
  • Opera autonomously: puede actuar sin supervisión constante
  • Es unpredictable: puede tomar caminos inesperados

Sin constraints adecuados, un agente podría:

  • Enviar emails inapropiados a clientes
  • Modificar o eliminar datos importantes
  • Hacer transacciones financieras incorrectas
  • Reveal información confidencial
  • Entrar en loops infinitos de acciones

📐 Capas de Protección: Defense in Depth

La arquitectura correcta tiene múltiples capas de safety, ninguna perfecta pero juntas reducen drásticamente el riesgo.

  1. Input Validation: Sanitizar y validar todo input del usuario
  2. Permission Model: Qué acciones puede ejecutar cada agente
  3. Confirmation Gates: Confirmación humana para acciones sensibles
  4. Output Filtering: Validar outputs antes de ejecutarlos
  5. Rate Limiting: Prevenir abuso y loops
  6. Audit Logging: Registrar todo para debugging y compliance
from dataclasses import dataclass, field
from typing import List, Dict, Any, Optional, Set, Callable
from enum import Enum
import time
import json

class RiskLevel(Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"

@dataclass
class Permission:
    """Un permiso para una acción específica."""
    action: str  # Nombre de la herramienta/acción
    max_per_hour: int = 100
    requires_confirmation: bool = False
    allowed_targets: Optional[Set[str]] = None  # e.g., {"email_to_whitelist"}
    max_value: Optional[float] = None  # Para acciones con valor (transacciones)

@dataclass
class SafetyConfig:
    """Configuración de seguridad para un agente."""
    agent_id: str
    permissions: List[Permission] = field(default_factory=list)
    blocked_keywords: Set[str] = field(default_factory=set)
    allowed_domains: Set[str] = field(default_factory=set)
    max_execution_time: float = 300  # 5 minutos
    max_actions_per_run: int = 50
    enable_audit_log: bool = True
    confirmation_callback: Optional[Callable] = None

@dataclass
class ActionRequest:
    """Una solicitud de acción."""
    tool_name: str
    parameters: Dict[str, Any]
    risk_level: RiskLevel = RiskLevel.LOW
    reason: str = ""
    requested_at: float = field(default_factory=time.time)

@dataclass
class AuditEntry:
    """Entrada en el audit log."""
    timestamp: float
    agent_id: str
    action: str
    parameters: Dict[str, Any]
    risk_level: RiskLevel
    approved: bool
    execution_time: Optional[float] = None
    result: Optional[str] = None
    error: Optional[str] = None

class SafetyGuard:
    """Guarda de seguridad multicapa para agentes."""

    def __init__(self, config: SafetyConfig):
        self.config = config
        self.audit_log: List[AuditEntry] = []
        self.action_counts: Dict[str, List[float]] = {}  # action -> timestamps
        self.pending_confirmations: Dict[str, ActionRequest] = {}

    def check_permission(self, request: ActionRequest) -> tuple[bool, str]:
        """
        Verifica si una acción está permitida.
        Returns: (allowed, reason)
        """
        # 1. Check rate limits
        if not self._check_rate_limit(request.tool_name):
            return False, f"Rate limit exceeded for {request.tool_name}"

        # 2. Check if action is permitted at all
        permission = self._get_permission(request.tool_name)
        if not permission:
            return False, f"Action {request.tool_name} not permitted"

        # 3. Check blocked keywords in parameters
        if self._contains_blocked_content(request):
            return False, "Content contains blocked keywords"

        # 4. Check target restrictions
        if permission.allowed_targets:
            if not self._check_targets(request, permission):
                return False, f"Target not in allowed list"

        # 5. Check value limits
        if permission.max_value is not None:
            value = request.parameters.get("value", 0)
            if value > permission.max_value:
                return False, f"Value exceeds limit: {value} > {permission.max_value}"

        return True, "Approved"

    def _check_rate_limit(self, action: str) -> bool:
        """Verifica rate limits para una acción."""
        now = time.time()
        hour_ago = now - 3600

        if action not in self.action_counts:
            self.action_counts[action] = []

        # Filtrar solo timestamps de la última hora
        self.action_counts[action] = [
            t for t in self.action_counts[action] if t > hour_ago
        ]

        # Get permission limit
        permission = self._get_permission(action)
        max_per_hour = permission.max_per_hour if permission else 100

        if len(self.action_counts[action]) >= max_per_hour:
            return False

        self.action_counts[action].append(now)
        return True

    def _get_permission(self, action: str) -> Optional[Permission]:
        """Busca permiso para una acción."""
        for p in self.config.permissions:
            if p.action == action:
                return p
        return None

    def _contains_blocked_content(self, request: ActionRequest) -> bool:
        """Check si los parámetros contienen contenido bloqueado."""
        params_str = json.dumps(request.parameters).lower()
        for keyword in self.config.blocked_keywords:
            if keyword.lower() in params_str:
                return True
        return False

    def _check_targets(self, request: ActionRequest, permission: Permission) -> bool:
        """Verifica si el target está permitido."""
        # Common target fields
        target = (
            request.parameters.get("to") or
            request.parameters.get("target") or
            request.parameters.get("recipient") or
            request.parameters.get("destination")
        )

        if not target:
            return True  # No target specified, allow

        if permission.allowed_targets and target not in permission.allowed_targets:
            return False

        return True

    def requires_confirmation(self, request: ActionRequest) -> bool:
        """Determina si una acción requiere confirmación."""
        permission = self._get_permission(request.tool_name)
        if permission and permission.requires_confirmation:
            return True

        # High risk actions always require confirmation
        if request.risk_level in [RiskLevel.HIGH, RiskLevel.CRITICAL]:
            return True

        return False

    def evaluate_risk(self, tool_name: str, parameters: Dict[str, Any]) -> RiskLevel:
        """Evalúa el nivel de riesgo de una acción."""
        high_risk_tools = {
            "send_email", "send_message", "delete_data",
            "transfer_funds", "modify_permissions", "execute_code",
            "delete_file", "drop_table", "update_config"
        }

        critical_risk_tools = {
            "delete_database", "transfer_all_funds", "modify_security_config"
        }

        if tool_name in critical_risk_tools:
            return RiskLevel.CRITICAL
        elif tool_name in high_risk_tools:
            # Check parameters for severity
            if parameters.get("batch") or parameters.get("many"):
                return RiskLevel.CRITICAL
            return RiskLevel.HIGH
        elif tool_name in {"read_data", "search", "get_info"}:
            # Check for sensitive data access
            if parameters.get("sensitive"):
                return RiskLevel.MEDIUM
            return RiskLevel.LOW

        return RiskLevel.MEDIUM

    def log_action(self, entry: AuditEntry):
        """Registra una acción en el audit log."""
        if self.config.enable_audit_log:
            self.audit_log.append(entry)

    def get_audit_summary(self) -> Dict[str, Any]:
        """Genera resumen del audit log."""
        total = len(self.audit_log)
        approved = sum(1 for e in self.audit_log if e.approved)
        rejected = total - approved

        by_risk = {}
        for entry in self.audit_log:
            risk = entry.risk_level.value
            if risk not in by_risk:
                by_risk[risk] = {"total": 0, "approved": 0}
            by_risk[risk]["total"] += 1
            if entry.approved:
                by_risk[risk]["approved"] += 1

        return {
            "total_actions": total,
            "approved": approved,
            "rejected": rejected,
            "by_risk_level": by_risk,
            "approval_rate": approved / total if total > 0 else 0
        }

📐 Constrains Basados en Reglas

Além de permisos, precisamos de constrains operacionais que limiten el comportamiento del agente.

from typing import Any, Dict, List, Union

class Constraint:
    """Base class para constraints."""
    def check(self, action: Dict[str, Any]) -> tuple[bool, str]:
        raise NotImplementedError

class MaxLengthConstraint(Constraint):
    """Constraint en longitud de strings."""
    def __init__(self, field: str, max_length: int):
        self.field = field
        self.max_length = max_length

    def check(self, action: Dict[str, Any]) -> tuple[bool, str]:
        value = action.get("parameters", {}).get(self.field, "")
        if len(str(value)) > self.max_length:
            return False, f"{self.field} exceeds {self.max_length} chars"
        return True, "OK"

class AllowedValuesConstraint(Constraint):
    """Constraint en valores permitidos."""
    def __init__(self, field: str, allowed: List[Any]):
        self.field = field
        self.allowed = set(allowed)

    def check(self, action: Dict[str, Any]) -> tuple[bool, str]:
        value = action.get("parameters", {}).get(self.field)
        if value not in self.allowed:
            return False, f"{self.field} must be one of {self.allowed}"
        return True, "OK"

class BlocklistConstraint(Constraint):
    """Constraint que bloquea ciertos valores."""
    def __init__(self, field: str, blocklist: List[Any]):
        self.field = field
        self.blocklist = set(blocklist)

    def check(self, action: Dict[str, Any]) -> tuple[bool, str]:
        value = action.get("parameters", {}).get(self.field)
        if value in self.blocklist:
            return False, f"{self.field} '{value}' is blocked"
        return True, "OK"

class RegexConstraint(Constraint):
    """Constraint basado en regex."""
    def __init__(self, field: str, pattern: str, description: str = ""):
        import re
        self.field = field
        self.pattern = re.compile(pattern)
        self.description = description

    def check(self, action: Dict[str, Any]) -> tuple[bool, str]:
        value = str(action.get("parameters", {}).get(self.field, ""))
        if not self.pattern.match(value):
            return False, f"{self.field} doesn't match required pattern: {self.description}"
        return True, "OK"

class ConstraintEngine:
    """Motor de evaluación de constraints."""

    def __init__(self):
        self.constraints: List[Constraint] = []

    def add_constraint(self, constraint: Constraint):
        self.constraints.append(constraint)

    def validate_action(self, action: Dict[str, Any]) -> tuple[bool, List[str]]:
        """
        Valida una acción contra todos los constraints.
        Returns: (all_passed, list_of_violations)
        """
        violations = []

        for constraint in self.constraints:
            passed, reason = constraint.check(action)
            if not passed:
                violations.append(reason)

        return len(violations) == 0, violations

    def validate_batch(self, actions: List[Dict[str, Any]]) -> Dict[str, Any]:
        """Valida un batch de acciones."""
        results = []
        for i, action in enumerate(actions):
            passed, violations = self.validate_action(action)
            results.append({
                "index": i,
                "action": action.get("tool_name", "unknown"),
                "passed": passed,
                "violations": violations
            })

        passed = sum(1 for r in results if r["passed"])
        return {
            "total": len(actions),
            "passed": passed,
            "failed": len(actions) - passed,
            "results": results
        }

📐 Sandboxing: Aislamiento de Acciones Peligrosas

Para acciones verdaderamente peligrosas, el sandboxing asegura que即使 fallan, no causan daño collateral.

import subprocess
import tempfile
import os
from typing import Dict, Any, Optional

class SandboxExecutor:
    """Ejecutor aislado para comandos peligrosos."""

    def __init__(
        self,
        max_memory_mb: int = 512,
        max_cpu_seconds: float = 30,
        allowed_paths: List[str] = None
    ):
        self.max_memory_mb = max_memory_mb
        self.max_cpu_seconds = max_cpu_seconds
        self.allowed_paths = allowed_paths or ["/tmp/sandbox"]

    def execute_in_sandbox(
        self,
        command: str,
        input_data: Optional[Dict[str, Any]] = None
    ) -> Dict[str, Any]:
        """
        Ejecuta un comando en sandbox aislado.
        Returns: {"success": bool, "output": str, "error": str, "execution_time": float}
        """
        import time
        start = time.time()

        try:
            # Escribir input a archivo temporal
            input_file = None
            if input_data:
                with tempfile.NamedTemporaryFile(mode='w', delete=False) as f:
                    import json
                    json.dump(input_data, f)
                    input_file = f.name

            # Build command with resource limits
            safe_command = [
                "timeout", str(self.max_cpu_seconds),
                "python3", "-c", self._create_safe_wrapper(command, input_file)
            ]

            # Execute with resource limits
            result = subprocess.run(
                safe_command,
                capture_output=True,
                text=True,
                cwd=self.allowed_paths[0] if self.allowed_paths else "/tmp",
                env=self._create_safe_env()
            )

            execution_time = time.time() - start

            return {
                "success": result.returncode == 0,
                "output": result.stdout,
                "error": result.stderr,
                "execution_time": execution_time,
                "return_code": result.returncode
            }

        except subprocess.TimeoutExpired:
            return {
                "success": False,
                "output": "",
                "error": f"Command timed out after {self.max_cpu_seconds}s",
                "execution_time": time.time() - start
            }
        except Exception as e:
            return {
                "success": False,
                "output": "",
                "error": str(e),
                "execution_time": time.time() - start
            }

    def _create_safe_wrapper(self, command: str, input_file: Optional[str]) -> str:
        """Crea wrapper seguro para ejecutar comando."""
        input_handling = f"""
with open('{input_file}', 'r') as f:
    import json
    INPUT_DATA = json.load(f)
""" if input_file else "INPUT_DATA = {}"

        return f"""
import sys
import json
import os

{input_handling}

# Safe execution environment
os.chdir('/tmp/sandbox')
os.environ['PATH'] = '/usr/bin:/bin'
os.environ['HOME'] = '/tmp/sandbox'

try:
    exec('''{command}''')
except Exception as e:
    print(f'ERROR: {{e}}', file=sys.stderr)
    sys.exit(1)
"""

    def _create_safe_env(self) -> Dict[str, str]:
        """Crea ambiente seguro."""
        env = {
            "PATH": "/usr/bin:/bin",
            "HOME": "/tmp/sandbox",
            "LANG": "en_US.UTF-8",
        }
        # Remove any potentially dangerous variables
        for key in ["LD_PRELOAD", "LD_LIBRARY_PATH", "PYTHONPATH"]:
            env[key] = ""
        return env

⚠️ Error 1: Solo Confiar en el LLM para Safety

El problema: Confiar ciegamente en que el LLM "sabrá no hacer cosas malas" es como dejar la puerta de la bóveda abierta confiando en que los ladrones serán honestos. LLMs pueden ser manipulated via jailbreaks, prompt injection, y simplemente por inputs inesperados.

La solución: Safety layers independientes del LLM. Cada acción pasa por checks de seguridad antes de ejecutarse, sin importar qué diga el prompt.

⚠️ Error 2: No Tener Rollback para Acciones Destructivas

El problema: Cuando una acción destructiva se ejecuta por error, no hay forma de revertirla. Un agent que borra datos pensando que eran temporales no puede traerlos de vuelta.

La solución: Acciones destructivas deben ser soft deletes o tener backup automático antes de ejecutar.

class SoftDeleteProtector:
    """Wrapper que convierte deletes en soft deletes."""

    def __init__(self, backup_prefix: str = "/backups"):
        self.backup_prefix = backup_prefix
        os.makedirs(backup_prefix, exist_ok=True)

    async def protected_delete(self, original_delete_func, table: str, query: Dict) -> Dict:
        """
        Hace backup antes de delete y convierte en soft delete.
        """
        # 1. Hacer backup de los datos que se van a borrar
        backup_id = f"{table}_{int(time.time())}"
        backup_path = f"{self.backup_prefix}/{backup_id}.json"

        # 2. Leer datos antes de borrar
        data_to_delete = await original_delete_func.fetch_for_delete(table, query)

        if not data_to_delete:
            return {"deleted": 0, "message": "No matching records"}

        # 3. Guardar backup
        with open(backup_path, 'w') as f:
            json.dump({
                "table": table,
                "query": query,
                "deleted_at": time.time(),
                "data": data_to_delete
            }, f)

        # 4. Hacer soft delete (marcar como deleted, no borrar)
        result = await original_delete_func.soft_delete(table, query, backup_id=backup_id)

        return {
            "deleted": result["count"],
            "backup_id": backup_id,
            "message": f"Soft deleted with backup at {backup_path}"
        }

    async def restore(self, backup_id: str) -> Dict:
        """Restaura datos desde un backup."""
        backup_path = f"{self.backup_prefix}/{backup_id}.json"

        if not os.path.exists(backup_path):
            return {"error": f"Backup {backup_id} not found"}

        with open(backup_path, 'r') as f:
            backup = json.load(f)

        # Restore to original table
        result = await original_delete_func.restore(backup["table"], backup["data"])

        return {
            "restored": len(backup["data"]),
            "table": backup["table"],
            "message": f"Restored from {backup_id}"
        }

class ActionRegistry:
    """Registry de acciones para poder hacer rollback."""

    def __init__(self):
        self.actions: List[Dict[str, Any]] = []
        self.rollback_handlers: Dict[str, callable] = {}

    def register_rollback(self, action_type: str, handler: callable):
        """Registra un handler de rollback para un tipo de acción."""
        self.rollback_handlers[action_type] = handler

    async def execute_with_rollback(self, action: Dict[str, Any]) -> Dict[str, Any]:
        """Ejecuta acción y guarda para posible rollback."""
        action_type = action["type"]
        params = action["parameters"]

        # Execute
        result = await self._execute_action(action_type, params)

        # Register for rollback if successful
        if result.get("success"):
            self.actions.append({
                "type": action_type,
                "params": params,
                "result": result,
                "timestamp": time.time()
            })

        return result

    async def rollback_last(self) -> Dict[str, Any]:
        """Hace rollback de la última acción."""
        if not self.actions:
            return {"error": "No actions to rollback"}

        last = self.actions.pop()
        action_type = last["type"]

        if action_type not in self.rollback_handlers:
            return {"error": f"No rollback handler for {action_type}"}

        return await self.rollback_handlers[action_type](last["params"], last["result"])

⚠️ Error 3: No Monitorear Acciones en Tiempo Real

El problema: Sin monitoreo, no sabes qué está haciendo tu agente hasta que algo malo pasa. Para cuando descubres el problema, ya es tarde.

La solución: Dashboard de monitoreo en tiempo real con alertas para acciones sospechosas.

class AgentMonitor:
    """Monitor en tiempo real para agentes."""

    def __init__(self, alert_callback: Optional[callable] = None):
        self.alert_callback = alert_callback
        self.action_counts: Dict[str, int] = {}
        self.anomaly_scores: List[float] = []
        self.alert_thresholds = {
            "actions_per_minute": 30,
            "consecutive_errors": 5,
            "anomaly_score": 0.8
        }

    def record_action(self, agent_id: str, action: Dict[str, Any]):
        """Registra una acción del agente."""
        tool = action.get("tool_name", "unknown")
        self.action_counts[tool] = self.action_counts.get(tool, 0) + 1

        # Check for anomalies
        if self._is_anomaly(action):
            self._trigger_alert(agent_id, "anomaly", action)

        # Check rate limits
        if self.action_counts[tool] > self.alert_thresholds["actions_per_minute"]:
            self._trigger_alert(agent_id, "high_rate", {"tool": tool, "count": self.action_counts[tool]})

    def record_error(self, agent_id: str, error: str):
        """Registra un error del agente."""
        # Track consecutive errors
        self.anomaly_scores.append(1.0)

        if len(self.anomaly_scores) >= self.alert_thresholds["consecutive_errors"]:
            if all(s > 0.5 for s in self.anomaly_scores[-5:]):
                self._trigger_alert(agent_id, "consecutive_errors", {
                    "errors": self.anomaly_scores[-5:]
                })

    def _is_anomaly(self, action: Dict[str, Any]) -> bool:
        """Detecta si una acción es anómala."""
        # Implementar lógica de detección de anomalías
        # Por ejemplo: acciones nunca vistas antes, parámetros inusuales, etc.
        tool = action.get("tool_name", "")
        params = action.get("parameters", {})

        # Simple anomaly detection: very large parameters
        if len(json.dumps(params)) > 10000:
            return True

        return False

    def _trigger_alert(self, agent_id: str, alert_type: str, data: Dict):
        """Dispara una alerta."""
        alert = {
            "agent_id": agent_id,
            "type": alert_type,
            "data": data,
            "timestamp": time.time()
        }

        if self.alert_callback:
            self.alert_callback(alert)

        # Log to monitoring system (e.g., Prometheus, DataDog)
        print(f"🚨 ALERT [{alert_type}]: Agent {agent_id} - {data}")

    def get_status(self) -> Dict[str, Any]:
        """Obtiene estado actual del monitoreo."""
        return {
            "action_counts": self.action_counts,
            "avg_anomaly_score": sum(self.anomaly_scores) / len(self.anomaly_scores) if self.anomaly_scores else 0,
            "total_actions": sum(self.action_counts.values())
        }

📐 Best Practices para Production

Resumen de prácticas esenciales para correr agentes seguros en producción:

  • Principio de mínimo privilegio: Agentes solo tienen permisos para lo que necesitan
  • Defense in depth: Múltiples capas de seguridad, ninguna es suficiente sola
  • Audit everything: Logging completo de todas las acciones
  • Human in the loop: Acciones críticas requieren confirmación humana
  • Soft deletes: Nunca borrar datos irrevocablemente
  • Monitoreo real-time: Alertas inmediatas para comportamiento anómalo
  • Rollback capability: Siempre poder deshacer acciones
  • Regular reviews: Auditar periódicamente qué están haciendo los agentes

📝 Resumen y Cierre

Hagale pues, parcero. Safety en agentes no es optional — es lo que separa un agent útil de un liability legal. Lo que aprendimos hoy:

  • Defense in depth: Múltiples capas de protección independientes del LLM
  • Permission model: Qué puede hacer cada agente, con límites claros
  • Constraints operacionais: Reglas que ninguna acción puede violar
  • Sandboxing: Aislamiento para acciones peligrosas
  • Soft deletes y rollback: Nunca perder datos irrevocablemente
  • Monitoreo real-time: Saber qué pasa antes de que sea un problema

El 70% que implementa agentes sin safety termina con:

  • Agents que hacen cosas inexplicables
  • Datos eliminados por error
  • Emails inapropiados enviados
  • Exposición de información confidencial
  • Problemas legales por GDPR y otras regulaciones

El 30% que hace safety bien tiene agentes que generan valor sin generar problemas. No seas del 70%.
