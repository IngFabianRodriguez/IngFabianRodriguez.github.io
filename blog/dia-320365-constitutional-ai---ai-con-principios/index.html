☕ Intro

Qué más, parce. Día 320 y hoy vamos con algo que el 80% ignora completamente: usar LLMs para analizar grafos. En Colombia pocos trabajan con grafos y los que lo hacen usually se limitan a herramientas clásicas como NetworkX o Gephi. Pero resulta que los LLMs pueden meterse en ese mundo también y hacer cosas muy interesantes.

Hoy te muestro cómo usar LLMs para node classification, link prediction, knowledge graph extraction y cómo combinarlos con Graph Neural Networks (GNNs). Y lo más importante: cómo evitar los 3 errores que hacen que el 80% fracase cuando intenta aplicar esto a grafos.

📐 Qué es Graph Analysis con LLMs?

Un grafo es una estructura de datos que consiste de nodos (entidades) y edges (relaciones):

$$\mathcal{G} = (\mathcal{V}, \mathcal{E})$$

donde $\mathcal{V}$ es el conjunto de vértices y $\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V}$ es el conjunto de aristas.

Los LLMs pueden trabajar con grafos de varias formas:

  • Graph Reasoning: Razonar sobre conexiones y patrones en el grafo
  • Node/Edge Classification: Clasificar nodos o aristas usando el LLM como clasificador
  • Knowledge Graph Extraction: Extraer conocimiento de texto y construir grafos
  • Graph Generation: Generar nuevos grafos o completar grafos incompletos

Por qué combinar con GNNs?

Las Graph Neural Networks (GNNs) son excelentes capturando patrones estructurales locales, pero:

  • No capturan semántica profunda del contenido de los nodos
  • Requieren grandes cantidades de datos de entrenamiento
  • No razonan bien sobre relaciones de largo alcance

Los LLMs complementan estas limitaciones: capturan semántica y razonan sobre relaciones.

🔧 Graph Analysis Framework con LLMs

Vamos al código:

"""
LLM Graph Analysis Framework
Combina LLMs con GNNs para análisis de grafos
"""

import numpy as np
import torch
import json
from typing import List, Dict, Tuple, Optional, Set, Any
from dataclasses import dataclass, field
from collections import defaultdict
import re


@dataclass
class GraphConfig:
    """Configuración para análisis de grafos"""
    # LLM
    llm_temperature: float = 0.1
    max_tokens: int = 500
    
    # Graph
    edge_threshold: float = 0.5  # Threshold para crear aristas
    
    # Combinar con GNN?
    use_gnn: bool = True
    gnn_weight: float = 0.3
    llm_weight: float = 0.7
    
    # Scale
    batch_size: int = 100  # Para grafos grandes


@dataclass
class Node:
    """Nodo en el grafo"""
    id: str
    label: str
    features: Dict[str, Any] = field(default_factory=dict)
    embedding: Optional[np.ndarray] = None


@dataclass 
class Edge:
    """Arista en el grafo"""
    source: str
    target: str
    weight: float = 1.0
    label: str = ""


class Graph:
    """Grafo básico"""
    
    def __init__(self):
        self.nodes: Dict[str, Node] = {}
        self.edges: List[Edge] = []
        self.adjacency: Dict[str, Set[str]] = defaultdict(set)
    
    def add_node(self, node: Node):
        self.nodes[node.id] = node
    
    def add_edge(self, edge: Edge):
        self.edges.append(edge)
        self.adjacency[edge.source].add(edge.target)
        self.adjacency[edge.target].add(edge.source)  # No directed por ahora
    
    def get_neighbors(self, node_id: str) -> Set[str]:
        return self.adjacency.get(node_id, set())
    
    def get_node_context(self, node_id: str, depth: int = 2) -> str:
        """
        Generar contexto textual de un nodo y sus vecinos.
        Esto es lo que se le pasa al LLM.
        """
        if node_id not in self.nodes:
            return ""
        
        node = self.nodes[node_id]
        context = f"Nodo: {node.label}\n"
        context += f"Features: {node.features}\n\n"
        
        # Explorar vecinos recursivamente
        visited = {node_id}
        current_level = {node_id}
        
        for d in range(depth):
            next_level = set()
            for nid in current_level:
                neighbors = self.get_neighbors(nid)
                for neighbor_id in neighbors:
                    if neighbor_id not in visited:
                        neighbor = self.nodes.get(neighbor_id)
                        if neighbor:
                            context += f"  -> Vecino (distancia {d+1}): {neighbor.label}\n"
                            context += f"     Features: {neighbor.features}\n"
                            next_level.add(neighbor_id)
                            visited.add(neighbor_id)
            current_level = next_level
        
        return context


class LLMGraphReasoner:
    """
    Usa un LLM para razonar sobre la estructura del grafo.
    
    El LLM puede:
    - Clasificar nodos basándose en su vecindario
    - Predecir links entre nodos
    - Detectar comunidades y patrones
    - Explicar why dos nodos están o no conectados
    """
    
    def __init__(self, llm_client, config: GraphConfig):
        self.llm = llm_client
        self.config = config
    
    def classify_node(
        self, 
        graph: Graph, 
        node_id: str, 
        class_labels: List[str]
    ) -> Tuple[str, float]:
        """
        Clasificar un nodo usando el LLM.
        Retorna (predicted_class, confidence).
        """
        context = graph.get_node_context(node_id, depth=2)
        
        prompt = f"""Eres un clasificador de nodos en un grafo de conocimiento.
Dado el siguiente nodo y su vecindario, clasifícalo en UNA de estas categorías:

Categorías: {', '.join(class_labels)}

{context}

Responde en JSON:
{{"class": "categoría_predicha", "confidence": 0.0 a 1.0, "reasoning": "explicación_corta"}}"""
        
        response = self.llm.generate(prompt, max_tokens=self.config.max_tokens)
        
        try:
            result = json.loads(response)
            return result.get("class", class_labels[0]), result.get("confidence", 0.5)
        except:
            return class_labels[0], 0.5
    
    def predict_link(
        self, 
        graph: Graph, 
        node_a: str, 
        node_b: str
    ) -> Tuple[bool, float, str]:
        """
        Predecir si debería existir un link entre dos nodos.
        Retorna (exists, probability, reasoning).
        """
        context_a = graph.get_node_context(node_a, depth=1)
        context_b = graph.get_node_context(node_b, depth=1)
        
        # Vecinos comunes
        neighbors_a = graph.get_neighbors(node_a)
        neighbors_b = graph.get_neighbors(node_b)
        common = neighbors_a & neighbors_b
        
        prompt = f"""Eres un predictor de enlaces en grafos.
Dados dos nodos, predice si deberían estar conectados y por qué.

NODO A:
{context_a}

NODO B:
{context_b}

Vecinos comunes entre A y B: {[graph.nodes[n].label for n in common if n in graph.nodes]}

Responde en JSON:
{{"link_exists": true/false, "probability": 0.0 a 1.0, "reasoning": "explicación"}}"""
        
        response = self.llm.generate(prompt, max_tokens=self.config.max_tokens)
        
        try:
            result = json.loads(response)
            return (
                result.get("link_exists", False),
                result.get("probability", 0.5),
                result.get("reasoning", "")
            )
        except:
            return False, 0.5, "Error parseando respuesta"
    
    def extract_knowledge_from_text(
        self, 
        text: str, 
        entity_types: List[str]
    ) -> Tuple[List[Node], List[Edge]]:
        """
        Extraer entidades y relaciones de texto para construir un grafo.
        """
        prompt = f"""Eres un extractor de conocimiento. Del siguiente texto, extrae:

1. ENTIDADES: Cada entidad con su tipo y un ID único
2. RELACIONES: Pares de entidades que están relacionadas

Tipos de entidades permitidas: {', '.join(entity_types)}

Texto:
{text}

Responde en JSON:
{{
  "entities": [
    {{"id": "E1", "type": "PERSONA", "label": "Nombre", "features": {{}}}}
  ],
  "relations": [
    {{"source": "E1", "target": "E2", "label": "RELACION"}}
  ]
}}"""
        
        response = self.llm.generate(prompt, max_tokens=self.config.max_tokens * 2)
        
        try:
            result = json.loads(response)
            
            nodes = []
            for e in result.get("entities", []):
                nodes.append(Node(
                    id=e["id"],
                    label=e["label"],
                    features={"type": e.get("type", "")}
                ))
            
            edges = []
            for r in result.get("relations", []):
                edges.append(Edge(
                    source=r["source"],
                    target=r["target"],
                    label=r.get("label", "")
                ))
            
            return nodes, edges
        except:
            return [], []


class GNNEncoder:
    """
    Encoder simple tipo GNN (Graph Neural Network).
    En producción usarías PyTorch Geometric o similar.
    Este es un baseline simplificado.
    """
    
    def __init__(self, embedding_dim: int = 64):
        self.embedding_dim = embedding_dim
        self.node_embeddings: Dict[str, np.ndarray] = {}
    
    def fit(self, graph: Graph):
        """Aprender embeddings de nodos basados en estructura"""
        # Simple: usar PageRank o estructura de vecinos
        for node_id in graph.nodes:
            # Embedding basado en grado y vecinos
            neighbors = graph.get_neighbors(node_id)
            degree = len(neighbors)
            
            # Crear embedding simple
            embedding = np.random.randn(self.embedding_dim) * 0.1
            embedding[0] = np.log1p(degree)  # Log grado
            
            # Promedio de IDs de vecinos (hack simple)
            if neighbors:
                neighbor_ids = [hash(n) % 1000 for n in neighbors]
                embedding[1] = np.mean(neighbor_ids) / 1000
            
            self.node_embeddings[node_id] = embedding
    
    def encode(self, node_id: str) -> np.ndarray:
        return self.node_embeddings.get(node_id, np.zeros(self.embedding_dim))
    
    def compute_similarity(self, node_a: str, node_b: str) -> float:
        """Similitud coseno entre dos nodos"""
        emb_a = self.encode(node_a)
        emb_b = self.encode(node_b)
        
        norm_a = np.linalg.norm(emb_a)
        norm_b = np.linalg.norm(emb_b)
        
        if norm_a == 0 or norm_b == 0:
            return 0.0
        
        return np.dot(emb_a, emb_b) / (norm_a * norm_b)


class HybridGraphAnalyzer:
    """
    Analizador híbrido que combina:
    1. GNN para patrones estructurales
    2. LLM para razonamiento semántico
    
    El ensemble captura tanto estructura como significado.
    """
    
    def __init__(
        self, 
        llm_client, 
        config: GraphConfig = GraphConfig()
    ):
        self.config = config
        self.llm_reasoner = LLMGraphReasoner(llm_client, config)
        self.gnn_encoder = GNNEncoder()
        self.graph = Graph()
        self.is_fitted = False
    
    def build_graph(self, nodes: List[Node], edges: List[Edge]):
        """Construir el grafo"""
        print(f"🏗️ Construyendo grafo con {len(nodes)} nodos y {len(edges)} aristas...")
        
        for node in nodes:
            self.graph.add_node(node)
        
        for edge in edges:
            self.graph.add_edge(edge)
        
        # Entrenar encoder GNN
        if self.config.use_gnn:
            self.gnn_encoder.fit(self.graph)
        
        self.is_fitted = True
        print("   ✓ Grafo construido")
    
    def classify_nodes(
        self, 
        node_ids: List[str], 
        class_labels: List[str]
    ) -> Dict[str, Dict]:
        """
        Clasificar nodos combinando GNN + LLM.
        """
        results = {}
        
        for node_id in node_ids:
            # Embedding GNN
            gnn_emb = self.gnn_encoder.encode(node_id)
            
            # Clasificación LLM
            llm_class, llm_conf = self.llm_reasoner.classify_node(
                self.graph, node_id, class_labels
            )
            
            # Combinar (en producción sería un clasificador entrenado)
            if self.config.use_gnn:
                # Usar promedio ponderado
                final_class = llm_class  # Por ahora solo LLM
                final_conf = llm_conf
            else:
                final_class = llm_class
                final_conf = llm_conf
            
            results[node_id] = {
                "class": final_class,
                "confidence": final_conf,
                "gnn_embedding": gnn_emb.tolist() if self.config.use_gnn else None
            }
        
        return results
    
    def predict_missing_links(
        self, 
        top_k: int = 10
    ) -> List[Tuple[str, str, float]]:
        """
        Predecir links faltantes en el grafo.
        """
        print(f"🔗 Buscando {top_k} links probables...")
        
        candidates = []
        node_ids = list(self.graph.nodes.keys())
        
        # Para grafos grandes, muestrear
        if len(node_ids) > self.config.batch_size:
            node_ids = np.random.choice(node_ids, self.config.batch_size, replace=False)
        
        for i, node_a in enumerate(node_ids):
            for node_b in node_ids[i+1:]:
                # Ya existe edge?
                neighbors = self.graph.get_neighbors(node_a)
                if node_b in neighbors:
                    continue
                
                # Predecir con LLM
                link_exists, prob, reasoning = self.llm_reasoner.predict_link(
                    self.graph, node_a, node_b
                )
                
                if link_exists and prob > self.config.edge_threshold:
                    candidates.append((node_a, node_b, prob))
        
        # Ordenar por probabilidad y retornar top-k
        candidates.sort(key=lambda x: x[2], reverse=True)
        return candidates[:top_k]
    
    def find_communities(self) -> List[List[str]]:
        """
        Detectar comunidades en el grafo (simplificado).
        """
        # Usar LLM para detectar comunidades
        # En producción usar Louvain o similar
        
        node_ids = list(self.graph.nodes.keys())
        communities = []
        
        # Clustering simple basado en vecinos
        visited = set()
        
        for node_id in node_ids:
            if node_id in visited:
                continue
            
            # BFS para encontrar comunidad
            community = [node_id]
            queue = [node_id]
            visited.add(node_id)
            
            while queue:
                current = queue.pop(0)
                neighbors = self.graph.get_neighbors(current)
                
                for neighbor in neighbors:
                    if neighbor not in visited:
                        # Mismo tipo de entidad? Asumir misma comunidad
                        if self.graph.nodes[current].features.get("type") == \
                           self.graph.nodes[neighbor].features.get("type"):
                            visited.add(neighbor)
                            community.append(neighbor)
                            queue.append(neighbor)
            
            communities.append(community)
        
        return communities


def create_graph_from_text(
    llm_client,
    text: str,
    entity_types: List[str]
) -> Graph:
    """Helper para crear un grafo desde texto"""
    config = GraphConfig()
    analyzer = HybridGraphAnalyzer(llm_client, config)
    
    nodes, edges = analyzer.llm_reasoner.extract_knowledge_from_text(
        text, entity_types
    )
    
    analyzer.build_graph(nodes, edges)
    return analyzer.graph

🔢 Métricas de Graph Analysis

Métricas de Node Classification

  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$
  • F1-Score: $2 \cdot \frac{\text{precision} \cdot \text{recall}}{\text{precision} + \text{recall}}$

Métricas de Link Prediction

  • AUC-ROC: Área bajo la curva ROC
  • Precision@K: Precisión en los primeros K predictions

Métricas de Grafo

  • PageRank: Importancia de nodos basada en links
  • Centralidad: Grado de conexión de nodos

⚠️ Los 3 Errores Comunes (y sus fixes)

Error 1: No usar LLMs para tareas de grafo

El problema: La gente piensa que los LLMs solo sirven para texto y que para grafos necesitas arquitecturas especiales como GNNs. FALSO. Los LLMs pueden razonar sobre estructura de grafos si se les da el contexto correcto.

El fix: Convierte el subgrafo relevante en texto descriptivo (vecinos, features, relaciones) y deja que el LLM razone. Para node classification, el LLM puede entender el contexto del nodo mejor que un clasificador estadístico.

Error 2: No combinar con la estructura del grafo

El problema: Usar SOLO el LLM sin considerar la estructura. El LLM no tiene acceso directo a las conexiones.

El fix: Combina con GNN embeddings. El GNN captura estructura local, el LLM captura semántica. Usa ensemble: típicamente 70% LLM + 30% GNN para classification, pero el LLM es más importante para razonamiento.

Error 3: No manejar la escala

El problema: Intentar pasar grafos grandes completos al LLM. Un grafo de 1M de nodos no cabe en el context window.

El fix: Usa batching y sampling. Para grafos grandes:

  • Muestrea vecindarios (ego graphs)
  • Usa GNN embeddings como features condensados
  • Clasifica en batches, no todo junto
  • Pre-filtra candidatos con métodos tradicionales antes de preguntar al LLM

📊 Ejemplo de Uso

# Crear grafo de ejemplo: red social
nodes = [
    Node(id="1", label="Juan", features={"type": "PERSONA", "edad": 30}),
    Node(id="2", label="María", features={"type": "PERSONA", "edad": 25}),
    Node(id="3", label="Carlos", features={"type": "PERSONA", "edad": 35}),
    Node(id="4", label="TechCorp", features={"type": "EMPRESA", "sector": "tech"}),
    Node(id="5", label="Universidad", features={"type": "INSTITUCION", "tipo": "educativa"}),
]

edges = [
    Edge(source="1", target="2", label="AMIGOS"),
    Edge(source="1", target="3", label="AMIGOS"),
    Edge(source="2", target="3", label="AMIGOS"),
    Edge(source="1", target="4", label="TRABAJA_EN"),
    Edge(source="3", target="4", label="TRABAJA_EN"),
    Edge(source="2", target="5", label="ESTUDIA_EN"),
]

# Inicializar framework
config = GraphConfig(
    use_gnn=True,
    llm_weight=0.7,
    gnn_weight=0.3
)

analyzer.build_graph(nodes, edges)

# Clasificar nodos
classes = ["PERSONA", "EMPRESA", "INSTITUCION"]

missing_links = analyzer.predict_missing_links(top_k=5)
print("Links probables:", missing_links)

# Extraer conocimiento de texto

☕ Resumen y Cierre

Parce, hoy aprendiste que los LLMs pueden trabajar con grafos y que la combinación LLM + GNN es potente. Los puntos clave:

  1. Context es todo: Convierte el vecindario del nodo en texto para que el LLM pueda razonar
  2. Combina con GNN: El GNN captura estructura, el LLM captura semántica
  3. Maneja la escala: No pases grafos grandes al LLM, muestrea y usa embeddings

Los errores más comunes:

  • ❌ No usar LLMs para graph tasks (se pueden usar y son buenos)
  • ❌ Ignorar la estructura del grafo (usa GNN embeddings)
  • ❌ No manejar escala (muestrea, no pases todo)
