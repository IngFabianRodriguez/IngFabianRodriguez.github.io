GPT-4 - La Nueva Generacion De LLMs

Hagale pues, parcero. Hoy es el Dia 214 y hablamos de GPT-4, la nueva generacion de LLMs multimodal. Cafe.

🎯 Que Es GPT-4?

GPT-4 es el modelo mas capaz de OpenAI hasta la fecha. MultModal: acepta texto e imagenes. 82% menos errores en exams que GPT-3.5.

Capacidades:

  • Multimodal: Vision + Lenguaje
  • Long context: 128k tokens
  • Alignment: Mejor comportamiento
  • Steerability: Personalidades y roles

📐 Usando GPT-4 Vision

from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "image_url", "image_url": {"url": "data:image/..."}},
                {"type": "text", "text": "Que ves en esta imagen?"}
            ]
        }
    ]
)
print(response.choices[0].message.content)
