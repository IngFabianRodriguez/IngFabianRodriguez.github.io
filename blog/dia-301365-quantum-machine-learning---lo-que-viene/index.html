En un laboratorio de IBM en Yorktown Heights, un grupo de físicos y machine learning engineers trabajan juntos en algo que hace cinco años parecía ciencia ficción: sistemas cuánticos que aprenden. Un qubit no es un bit normal — es un objeto que puede ser 0, 1, o ambos al mismo tiempo, gracias a la superposición cuántica. Y cuando combinas esa propiedad con redes neuronales, obtienes algo que el 90% todavía no entiende pero que el 10% está construyendo silenciosamente.

Quantum Machine Learning (QML) no es solo una palabra de moda — es un campo donde investigadores de Google, IBM, IonQ, y startups como PsiQuantum están invirtiendo miles de millones. Hoy te explico qué es, qué puede hacer ya, y qué viene mañana.

Los Fundamentos: Qubits, Superposición, y Entrelazamiento

Antes de hablar de QML, necesitas entender tres conceptos básicos de computación cuántica:

  • Qubit: La unidad básica de información cuántica. A diferencia de un bit clásico (0 o 1), un qubit puede estar en superposición de ambos estados.
  • Superposición: Un qubit existe como 0 y 1 simultáneamente hasta que lo midamos. Esto permite procesamiento paralelo masivo.
  • Entrelazamiento (Entanglement): Dos qubits entrelazados comparten estado instantáneamente sin importar la distancia. Einstein lo llamó "spooky action at a distance".

La fórmula de un estado cuántico es:

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$$

Donde $\alpha$ y $\beta$ son amplitudes de probabilidad complejas y $|\alpha|^2 + |\beta|^2 = 1$.

Variational Quantum Eigensolver (VQE)

El algoritmo más práctico de QML hoy es VQE. Resuelve el problema de encontrar el eigenvalor mínimo de un Hamiltonian. ¿Por qué importa? Porque muchos problemas de química, materiales, y optimización se formulan así.

"""
VQE: Variational Quantum Eigensolver
Encuentra el estado fundamental de un sistema cuántico.
"""

import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit.library import TwoLocal
from qiskit_algorithms import VQE, NumPyMinimumEigensolver
from qiskit_algorithms.optimizers import COBYLA
from qiskit.primitives import Estimator

def create_hamiltonian(h_matrix):
    """Crea el Hamiltonian del sistema."""
    from qiskit.quantum_info import SparsePauliOp
    return SparsePauliOp.from_matrix(h_matrix)

def vqe_circuit(num_qubits, depth=3):
    """Crea circuito variacional (ansatz)."""
    ansatz = TwoLocal(
        num_qubits=num_qubits,
        rotation_blocks=['ry', 'rz'],
        entanglement_blocks='cx',
        entanglement='linear',
        reps=depth
    )
    return ansatz

def run_vqe(hamiltonian, num_qubits):
    """Ejecuta VQE para encontrar el eigenvalor mínimo."""
    ansatz = vqe_circuit(num_qubits)
    estimator = Estimator()
    optimizer = COBYLA(maxiter=100)
    
    vqe = VQE(estimator, ansatz, optimizer)
    result = vqe.compute_minimum_eigenvalue(hamiltonian)
    
    return result.eigenvalue, result.optimal_parameters

# Ejemplo: Hamiltonian de Heisenberg para 2 qubits
heisenberg_h = np.array([
    [1, 0, 0, 0],
    [0, -1, 2, 0],
    [0, 2, -1, 0],
    [0, 0, 0, 1]
])

eigenvalue, params = run_vqe(heisenberg_h, 2)
print(f"Eigenvalor mínimo: {eigenvalue}")

Quantum Neural Networks (QNN)

Un Quantum Neural Network es una red neuronal donde las capas de entrada, ocultas, o salida operan en estados cuánticos. Hay dos aproximaciones principales:

  • Quantum-enhanced classical: Capas cuánticas en una red predominantemente clásica.
  • Fully quantum: Datos cuánticos procesados por circuito completamente cuántico.
"""
Quantum Neural Network con Qiskit
Red neuronal híbrida clásica-cuántica.
"""

from qiskit import QuantumCircuit
from qiskit.circuit import ParameterVector
from qiskit_machine_learning.neural_networks import EstimatorQNN

def create_qnn(num_qubits):
    """
    Crea un QNN para clasificación.
    """
    # Circuito con parámetros entrenables
    qc = QuantumCircuit(num_qubits)
    params = ParameterVector('theta', num_qubits * 3)
    
    # Capa de entrada: rotación
    for i in range(num_qubits):
        qc.rx(params[i], i)
        qc.ry(params[num_qubits + i], i)
    
    # Capa de entrelazamiento
    for i in range(num_qubits - 1):
        qc.cx(i, i + 1)
    qc.cx(num_qubits - 1, 0)
    
    # Capa de medición
    qc.measure_all()
    
    # Crear QNN
    qnn = EstimatorQNN(circuit=qc)
    
    return qnn

# Usar con datos clásicos (encoding variacional)
def encodeClassicalData(data, num_qubits):
    """Codifica datos clásicos en estado cuántico."""
    qc = QuantumCircuit(num_qubits)
    for i, val in enumerate(data[:num_qubits]):
        qc.ry(val * np.pi, i)
    return qc

num_qubits = 4
qnn = create_qnn(num_qubits)
print(f"QNN tiene {qnn.num_input_qubits} qubits de entrada")
print(f"QNN tiene {qnn.num_parameters} parámetros entrenables")

Quantum Support Vector Machines (QSVM)

QSVM usa kernels cuánticos para calcular similitud entre puntos en espacio de Hilbert de alta dimensionalidad. El kernel cuántico es:

$$K(x_i, x_j) = |\langle\phi(x_i)|\phi(x_j)\rangle|^2$$

Donde $|\phi(x)\rangle$ es el estado cuántico representando el punto $x$.

"""
Quantum SVM con kernel cuántico
Usa un circuito cuántico para calcular el kernel.
"""

from qiskit.circuit.library import ZZFeatureMap
from qiskit_machine_learning.kernels import FidelityQuantumKernel

def create_quantum_kernel(num_features, reps=2):
    """Crea feature map cuántico para kernel."""
    feature_map = ZZFeatureMap(
        feature_dimension=num_features,
        reps=reps,
        entanglement='linear'
    )
    
    qkernel = FidelityQuantumKernel(feature_map=feature_map)
    return qkernel

def classify_with_qsvm(X_train, y_train, X_test, num_features):
    """Clasificación con QSVM."""
    from qiskit_machine_learning.algorithms import QSVC
    
    # Crear kernel
    kernel = create_quantum_kernel(num_features)
    
    # Entrenar QSVC
    qsvc = QSVC(quantum_kernel=kernel)
    qsvc.fit(X_train, y_train)
    
    # Predecir
    predictions = qsvc.predict(X_test)
    
    return predictions

# Ejemplo con datos sintéticos
np.random.seed(42)
X_train = np.random.rand(50, 4) * 2 * np.pi
y_train = (X_train[:, 0] > np.pi).astype(int)
X_test = np.random.rand(10, 4) * 2 * np.pi

predictions = classify_with_qsvm(X_train, y_train, X_test, 4)
print(f"Predicciones: {predictions}")

¿Qué Puede Hacer QML Hoy?

Honestamente, QML todavía está en etapa experimental. Pero hay casos donde ya supera a ML clásico:

  • Simulación de moléculas: Encontrar estados fundamentales de moléculas para drug discovery. Google demostró ventaja cuántica en 2023 con sistemas de 100+ qubits.
  • Optimización combinatoria: Problemas QAOA (Quantum Approximate Optimization Algorithm) para logística y routing.
  • Machine learning cuántico: speedups teóricos para clustering y clasificación cuando los datos pueden codificarse eficientemente en estados cuánticos.

El Hardware de Hoy

  • IBM: 1000+ qubits (Condor), pero de baja coherencia
  • Google: 70 qubits (Sycamore), alta fidelidad de compuertas
  • IonQ: 32 qubits iónicos, altísima fidelidad pero lentos
  • D-Wave: 5000 qubits superconductores, optimizados para annealing

El problema fundamental: los qubits actuales tienen coherencia de microsegundos a milisegundos. Los errores acumulan rápido. Por eso la mayoría de QML práctico hoy usa aproximaciones híbridas classical-quantum.

Resumen: Lo Que Viene

  • Corto plazo: Algoritmos híbridos quantum-classical para problemas específicos de química y optimización
  • Mediano plazo: Error correction pragmático con 1000+ qubits lógicos
  • Largo plazo: Ventaja cuántica real para ML en problemas intractable classically

La fórmula del QML de hoy:
QML_Success = Classical_Preprocessing × Quantum_Kernel × Hybrid_Training
