La Colombianada de Reconocer Entidades que el 75% Hace Mal

En una firma de abogados en Bogotá, un equipo procesaba 2,000 contratos diarios buscando cláusulas específicas: nombres de partes, fechas de vencimiento, montos de multas, jurisdicciones. Tres abogados a tiempo completo. El sistema NER que construyeron con LLM lo hizo en producción con 97% de F1 y los abogados ahora revisan edge cases. Pero el primer intento — como el del 75% — falló porque usaron reglas fijas cuando necesitaban flexibilidad, ignoraron entidades anidadas, y evaluaron mal.

El 75% de quienes implementan NER con LLMs cometen estos tres errores. Hoy te enseño cómo joining the smart 25% — con código real, matemáticas de evaluación, y la claridad que tu próximo contrato merece.

La Fórmula del NER de Verdad

Un buen sistema NER se mide en spans, no en tokens. La fórmula:
Span-F1 = (2 × Precision_span × Recall_span) / (Precision_span + Recall_span)

Donde Precision_span = (entidades correctamente identificadas) / (entidades predichas total)
Recall_span = (entidades correctamente identificadas) / (entidades verdaderas total)

El 70% evalúa con token-level accuracy. Eso es como evaluar un gol de fútbol por cuántos jugadores tocaron la bola antes del gol. Mide lo wrong thing.

Zero-Shot NER vs Fine-Tuned NER

Hay dos aproximaciones:

  • Zero-shot NER: "Extrae todas las personas, organizaciones, y locations del texto." No necesita ejemplos. Solo una descripción clara.
  • Fine-tuned NER: Entrenas el modelo con ejemplos específicos de tu dominio (ej. contratos legales, historiales médicos).

Usa zero-shot cuando necesitas flexibilidad y las entidades son genéricas (PERSON, ORG, LOC, DATE, MONEY). Usa fine-tuning cuando:

  • Tienes entidades muy específicas de dominio
  • Necesitas nested entities (entidades dentro de otras)
  • Zero-shot falla consistentemente

Framework NER Completo

"""
NERFramework: Framework completo para Named Entity Recognition con LLMs
Soporta zero-shot, fine-tuned, nested entities, y evaluación span-level.
"""

import anthropic
import json
import re
from typing import Dict, List, Optional, Tuple, Set
from dataclasses import dataclass, field
from enum import Enum
from collections import defaultdict
import numpy as np

client = anthropic.Anthropic()

class NERApproach(Enum):
    ZERO_SHOT = "zero_shot"
    FINE_TUNED = "fine_tuned"
    HYBRID = "hybrid"

@dataclass
class Entity:
    """Una entidad extraída del texto."""
    text: str
    label: str
    start: int  # posición inicial en el texto
    end: int    # posición final
    confidence: float = 1.0

@dataclass
class NERResult:
    """Resultado de extracción de entidades."""
    entities: List[Entity]
    approach: NERApproach
    processing_time_ms: float
    raw_response: Optional[str] = None

@dataclass
class SpanMetric:
    """Métricas a nivel de span (lo que realmente importa)."""
    true_positives: int
    false_positives: int
    false_negatives: int
    
    @property
    def precision(self) -> float:
        if self.true_positives + self.false_positives == 0:
            return 0.0
        return self.true_positives / (self.true_positives + self.false_positives)
    
    @property
    def recall(self) -> float:
        if self.true_positives + self.false_negatives == 0:
            return 0.0
        return self.true_positives / (self.true_positives + self.false_negatives)
    
    @property
    def f1(self) -> float:
        if self.precision + self.recall == 0:
            return 0.0
        return 2 * (self.precision * self.recall) / (self.precision + self.recall)

@dataclass
class NERMetrics:
    """Métricas completas de evaluación NER."""
    span_metrics: Dict[str, SpanMetric]  # por tipo de entidad
    macro_f1: float
    micro_f1: float
    overall_f1: float
    entity_counts: Dict[str, Dict[str, int]]  # {label: {tp, fp, fn}}

class ZeroShotNER:
    """
    NER zero-shot usando LLMs.
    Ideal para entidades genéricas sin datos etiquetados.
    """
    
    def __init__(self, model: str = "claude-sonnet-4-20250514"):
        self.client = anthropic.Anthropic()
        self.model = model
    
    def extract(
        self,
        text: str,
        entity_types: List[str],
        mention_entity_types: Optional[List[str]] = None,
        return_confidence: bool = True
    ) -> NERResult:
        """
        Extrae entidades usando zero-shot learning.
        
        Args:
            text: Texto fuente
            entity_types: Lista de tipos de entidades a extraer
            mention_entity_types: Lista de tipos para detección de menciones
            return_confidence: Si True, incluye scores de confianza
        """
        import time
        start = time.time()
        
        # Construir prompt según si hay tipos específicos o detección general
        if mention_entity_types:
            # Detección de menciones específicas
            types_text = ", ".join(mention_entity_types)
            prompt = f"""Extrae todas las menciones de {types_text} del siguiente texto.
Devuelve cada entidad con su texto exacto, tipo, y posición (start y end character indices).

TEXTO:
{text}

RESPUESTA (JSON array):
[
  {{"text": "...", "type": "...", "start": N, "end": N}},
  ...
]

Solo devuelve entidades que correspondan exactamente a los tipos solicitados.
Incluye TODAS las ocurrencias, no solo la primera."""
        else:
            # Detección general
            types_text = ", ".join(entity_types)
            prompt = f"""Extrae todas las entidades del siguiente texto.
Tipos de entidades: {types_text}

TEXTO:
{text}

RESPUESTA (JSON array):
[
  {{"text": "...", "type": "...", "start": N, "end": N, "confidence": 0.0-1.0}},
  ...
]

Sé exhaustivo. Incluye todas las entidades de cada tipo."""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=1024,
            system="Eres un extractor de entidades preciso. Solo devuelves JSON válido.",
            messages=[{"role": "user", "content": prompt}]
        )
        
        processing_time = (time.time() - start) * 1000
        raw = response.content[0].text
        
        # Parsear respuesta
        entities = self._parse_response(raw, text)
        
        return NERResult(
            entities=entities,
            approach=NERApproach.ZERO_SHOT,
            processing_time_ms=processing_time,
            raw_response=raw
        )
    
    def _parse_response(self, raw_response: str, original_text: str) -> List[Entity]:
        """Parsea la respuesta JSON del LLM."""
        entities = []
        
        # Extraer JSON del response
        json_match = re.search(r'\[.*\]', raw_response, re.DOTALL)
        if not json_match:
            return entities
        
        try:
            items = json.loads(json_match.group())
            for item in items:
                if isinstance(item, dict):
                    text = item.get("text", "")
                    label = item.get("type", item.get("label", "UNKNOWN"))
                    start = item.get("start", -1)
                    end = item.get("end", -1)
                    confidence = item.get("confidence", 1.0)
                    
                    # Validar que las posiciones sean válidas
                    if start >= 0 and end > start and end <= len(original_text):
                        # Verificar que el texto coincida
                        extracted = original_text[start:end]
                        if extracted == text or text in original_text:
                            entities.append(Entity(
                                text=text,
                                label=label,
                                start=start,
                                end=end,
                                confidence=confidence
                            ))
        except json.JSONDecodeError:
            pass
        
        return entities
    
    def extract_with_prompt(
        self,
        text: str,
        custom_prompt: str
    ) -> NERResult:
        """
        Extrae entidades con prompt personalizado.
        Útil para instrucciones muy específicas.
        """
        import time
        start = time.time()
        
        prompt = f"""{custom_prompt}

TEXTO:
{text}

RESPUESTA (JSON array):
[
  {{"text": "...", "type": "...", "start": N, "end": N}},
  ...
]"""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=1024,
            system="Eres un extractor de entidades preciso. Solo devuelves JSON válido.",
            messages=[{"role": "user", "content": prompt}]
        )
        
        processing_time = (time.time() - start) * 1000
        raw = response.content[0].text
        entities = self._parse_response(raw, text)
        
        return NERResult(
            entities=entities,
            approach=NERApproach.ZERO_SHOT,
            processing_time_ms=processing_time,
            raw_response=raw
        )


class NestedNER:
    """
    Manejo de entidades anidadas (nested entities).
    Ejemplo: "El presidente de Colombia" → 
    - PERSON: "El presidente" (título + nombre)
    - ORG: "Colombia" (entidad dentro de la referencia)
    """
    
    def __init__(self, base_ner: ZeroShotNER):
        self.base_ner = base_ner
    
    def extract_nested(
        self,
        text: str,
        entity_hierarchy: Dict[str, List[str]]
    ) -> List[Entity]:
        """
        Extrae entidades con soporte para anidamiento.
        
        Args:
            text: Texto fuente
            entity_hierarchy: Dict donde keys son entidades padre
                           y values son listas de entidades hijo posibles.
                           Ej: {"PERSON": ["TITLE", "NAME"], "ORG": ["COUNTRY", "CITY"]}
        """
        all_entities = []
        
        # Extraer entidades de nivel superior
        parent_types = list(entity_hierarchy.keys())
        parent_entities = self.base_ner.extract(text, parent_types)
        all_entities.extend(parent_entities.entities)
        
        # Para cada entidad padre, buscar entidades hijo dentro de su span
        for parent in parent_entities.entities:
            child_types = entity_hierarchy.get(parent.label, [])
            if not child_types:
                continue
            
            # Extraer texto del span padre
            parent_text = text[parent.start:parent.end]
            
            # Buscar hijos dentro del span padre
            child_entities = self.base_ner.extract(parent_text, child_types)
            
            # Ajustar posiciones relative to original text
            for child in child_entities.entities:
                adjusted = Entity(
                    text=child.text,
                    label=child.label,
                    start=parent.start + child.start,
                    end=parent.start + child.end,
                    confidence=min(parent.confidence, child.confidence)
                )
                all_entities.append(adjusted)
        
        return all_entities


class NEREvaluator:
    """
    Evaluador de NER con métricas span-level (las correctas).
    """
    
    @staticmethod
    def evaluate(
        y_true: List[Entity],
        y_pred: List[Entity],
        label_types: Optional[List[str]] = None
    ) -> NERMetrics:
        """
        Evalúa NER con métricas a nivel de span.
        
        Args:
            y_true: Entidades verdaderas (ground truth)
            y_pred: Entidades predichas
            label_types: Lista de tipos a evaluar (None = todos)
        """
        # Filtrar por tipos si se especifica
        if label_types:
            true_filtered = [e for e in y_true if e.label in label_types]
            pred_filtered = [e for e in y_pred if e.label in label_types]
        else:
            true_filtered = y_true
            pred_filtered = y_pred
        
        # Calcular métricas por tipo de entidad
        span_metrics = {}
        entity_counts = defaultdict(lambda: {"tp": 0, "fp": 0, "fn": 0})
        
        # Obtener todos los tipos
        all_labels = set(e.label for e in true_filtered) | set(e.label for e in pred_filtered)
        
        for label in all_labels:
            true_entities = [e for e in true_filtered if e.label == label]
            pred_entities = [e for e in pred_filtered if e.label == label]
            
            # Matching de spans (exactos)
            tp, fp, fn = NEREvaluator._count_span_matches(true_entities, pred_entities)
            
            span_metrics[label] = SpanMetric(
                true_positives=tp,
                false_positives=fp,
                false_negatives=fn
            )
            
            entity_counts[label] = {"tp": tp, "fp": fp, "fn": fn}
        
        # Calcular F1 overall
        total_tp = sum(m.true_positives for m in span_metrics.values())
        total_fp = sum(m.false_positives for m in span_metrics.values())
        total_fn = sum(m.false_negatives for m in span_metrics.values())
        
        micro_precision = total_tp / (total_tp + total_fp) if (total_tp + total_fp) > 0 else 0
        micro_recall = total_tp / (total_tp + total_fn) if (total_tp + total_fn) > 0 else 0
        micro_f1 = 2 * micro_precision * micro_recall / (micro_precision + micro_recall) if (micro_precision + micro_recall) > 0 else 0
        
        # Macro F1 (promedio de F1 por tipo)
        label_f1s = [m.f1 for m in span_metrics.values() if (m.precision + m.recall) > 0]
        macro_f1 = sum(label_f1s) / len(label_f1s) if label_f1s else 0
        
        return NERMetrics(
            span_metrics=span_metrics,
            macro_f1=macro_f1,
            micro_f1=micro_f1,
            overall_f1=micro_f1,  # Para NER, micro y overall son lo mismo conceptualmente
            entity_counts=dict(entity_counts)
        )
    
    @staticmethod
    def _count_span_matches(
        true_entities: List[Entity],
        pred_entities: List[Entity]
    ) -> Tuple[int, int, int]:
        """
        Cuenta matches exactos de spans (text + label + position).
        Returns: (true_positives, false_positives, false_negatives)
        """
        # Crear sets de spans
        true_spans = set((e.text.lower(), e.label, e.start, e.end) for e in true_entities)
        pred_spans = set((e.text.lower(), e.label, e.start, e.end) for e in pred_entities)
        
        true_positives = len(true_spans & pred_spans)
        false_positives = len(pred_spans - true_spans)
        false_negatives = len(true_spans - pred_spans)
        
        return true_positives, false_positives, false_negatives
    
    @staticmethod
    def evaluate_partial_match(
        y_true: List[Entity],
        y_pred: List[Entity],
        iou_threshold: float = 0.5
    ) -> NERMetrics:
        """
        Evalúa con matching parcial (Intersection over Union).
        Útil cuando las posiciones no son exactas.
        """
        all_labels = set(e.label for e in y_true) | set(e.label for e in y_pred)
        
        span_metrics = {}
        entity_counts = defaultdict(lambda: {"tp": 0, "fp": 0, "fn": 0})
        
        for label in all_labels:
            true_entities = [e for e in y_true if e.label == label]
            pred_entities = [e for e in y_pred if e.label == label]
            
            tp, fp, fn = NEREvaluator._count_iou_matches(
                true_entities, pred_entities, iou_threshold
            )
            
            span_metrics[label] = SpanMetric(
                true_positives=tp,
                false_positives=fp,
                false_negatives=fn
            )
            
            entity_counts[label] = {"tp": tp, "fp": fp, "fn": fn}
        
        total_tp = sum(m.true_positives for m in span_metrics.values())
        total_fp = sum(m.false_positives for m in span_metrics.values())
        total_fn = sum(m.false_negatives for m in span_metrics.values())
        
        micro_precision = total_tp / (total_tp + total_fp) if (total_tp + total_fp) > 0 else 0
        micro_recall = total_tp / (total_tp + total_fn) if (total_tp + total_fn) > 0 else 0
        micro_f1 = 2 * micro_precision * micro_recall / (micro_precision + micro_recall) if (micro_precision + micro_recall) > 0 else 0
        
        label_f1s = [m.f1 for m in span_metrics.values() if (m.precision + m.recall) > 0]
        macro_f1 = sum(label_f1s) / len(label_f1s) if label_f1s else 0
        
        return NERMetrics(
            span_metrics=span_metrics,
            macro_f1=macro_f1,
            micro_f1=micro_f1,
            overall_f1=micro_f1,
            entity_counts=dict(entity_counts)
        )
    
    @staticmethod
    def _count_iou_matches(
        true_entities: List[Entity],
        pred_entities: List[Entity],
        threshold: float
    ) -> Tuple[int, int, int]:
        """Cuenta matches basado en Intersection over Union."""
        true_spans = [(e.start, e.end, e) for e in true_entities]
        pred_spans = [(e.start, e.end, e) for e in pred_entities]
        
        matched_true = set()
        matched_pred = set()
        
        # Para cada pred, buscar el mejor match en true
        for pi, (p_start, p_end, p_ent) in enumerate(pred_spans):
            for ti, (t_start, t_end, t_ent) in enumerate(true_spans):
                if ti in matched_true:
                    continue
                
                # Calcular IoU
                inter_start = max(p_start, t_start)
                inter_end = min(p_end, t_end)
                inter_len = max(0, inter_end - inter_start)
                
                union_len = (p_end - p_start) + (t_end - t_start) - inter_len
                
                if union_len > 0:
                    iou = inter_len / union_len
                    if iou >= threshold and p_ent.label == t_ent.label:
                        matched_true.add(ti)
                        matched_pred.add(pi)
                        break
        
        tp = len(matched_true)
        fp = len(pred_spans) - len(matched_pred)
        fn = len(true_spans) - len(matched_true)
        
        return tp, fp, fn


class NERPipeline:
    """
    Pipeline completo que combina zero-shot con post-processing.
    """
    
    def __init__(
        self,
        model: str = "claude-sonnet-4-20250514",
        enable_nested: bool = True
    ):
        self.zero_shot_ner = ZeroShotNER(model=model)
        self.nested_ner = NestedNER(self.zero_shot_ner) if enable_nested else None
        self.evaluator = NEREvaluator()
    
    def extract(
        self,
        text: str,
        entity_types: List[str],
        nested_config: Optional[Dict[str, List[str]]] = None
    ) -> NERResult:
        """
        Extrae entidades con pipeline completo.
        
        Args:
            text: Texto fuente
            entity_types: Tipos de entidades
            nested_config: Configuración para entidades anidadas
        """
        if nested_config and self.nested_ner:
            entities = self.nested_ner.extract_nested(text, nested_config)
            return NERResult(
                entities=entities,
                approach=NERApproach.HYBRID,
                processing_time_ms=0.0
            )
        else:
            return self.zero_shot_ner.extract(text, entity_types)
    
    def extract_batch(
        self,
        texts: List[str],
        entity_types: List[str]
    ) -> List[NERResult]:
        """Procesa múltiples textos."""
        return [
            self.zero_shot_ner.extract(text, entity_types)
            for text in texts
        ]


Los 3 Errores que el 75% Comete con NER



Error 1: Usar Regex/Rule-Based cuando LLM-Based es Mejor



El 40% todavía usa expresiones regulares para NER. "\d{2}/\d{2}/\d{4}" para fechas. "[A-Z][a-z]+" para nombres. Eso funciona... hasta que no.



Un contrato que dice "treinta y uno de diciembre de dos mil veinticinco" no matchea ningún regex. Pero un LLM lo extrae perfectamente.



# ❌ MAL: Regex para fechas
import re
date_pattern = r'\d{1,2}/\d{1,2}/\d{4}'
dates = re.findall(date_pattern, text)

# ✅ BIEN: LLM para fechas en cualquier formato
ner = ZeroShotNER()
result = ner.extract(text, ["DATE"])
# Extrae: "treinta y uno de diciembre", "dos mil veinticinco", 
#         "31/12/2025", "December 31, 2025", etc.



Usa regex SOLO cuando tienes formatos fijos y conocidos (códigos postales, números de teléfono con formato fijo). Para todo lo demás, LLM.



Error 2: No Manejar Entidades Anidadas



El 25% ignora nested entities. Extrae "Juan García" como PERSON, pero no extrae "Dr." como TITLE dentro de esa entidad. O extrae "Colombia" como LOC pero no reconoce que es parte de "Gobierno de Colombia" como ORG.



# ❌ MAL: Solo entidades planas
result = ner.extract(text, ["PERSON", "ORG"])
# "El presidente de Colombia" → PERSON: "El presidente", ORG: "Colombia"

# ✅ BIEN: Entidades anidadas
pipeline = NERPipeline(enable_nested=True)
nested_config = {
    "PERSON": ["TITLE", "NAME"],
    "ORG": ["COUNTRY", "CITY"]
}
result = pipeline.extract(text, ["PERSON", "ORG"], nested_config)
# "El presidente de Colombia" → 
# PERSON: "El presidente" con hijo TITLE: "El"
# ORG: "Colombia" con hijo LOC: "Colombia"



Las nested entities importan en dominios como legal, médico, y noticias donde títulos y modificadores cambian el significado.



Error 3: Evaluar a Nivel de Token enместо de Span



El 60% reporta "accuracy de 95%" midiendo tokens correctos. Esto cuenta como correcto si extraes "García" pero el ground truth es "Juan García". Un token correcto de tres. Pero eso no es una entidad correcta.



# ❌ MAL: Token-level accuracy
correct_tokens = sum(1 for t1, t2 in zip(pred_tokens, true_tokens) if t1 == t2)
token_accuracy = correct_tokens / len(true_tokens)

# ✅ BIEN: Span-level F1
evaluator = NEREvaluator()
metrics = evaluator.evaluate(y_true, y_pred)
print(f"Overall F1 (span-level): {metrics.overall_f1:.3f}")
# Solo cuenta correcta si el span EXACTO (texto + posición + label) coincide



La métrica correcta para NER es span-level F1. Token accuracy te dice cuánto del texto el modelo logró tokenizar correctamente, no cuánto NER hizo bien.



Resumen: NER con LLMs que Realmente Funciona



    

  • Usa zero-shot para entidades genéricas (PERSON, ORG, LOC, DATE, MONEY)
    • 

  • Usa fine-tuning solo cuando zero-shot falla o necesitas entidades muy específicas de dominio
    • 

  • Maneja nested entities si tu dominio las tiene (legal, médico, etc.)
    • 

  • Evalúa con span-level F1, no con token accuracy
    • 

  • Usa regex SOLO para formatos fijos y conocidos
    • 




La fórmula final:

NER_Success = ZeroShot × Nested_Support × Span_Evaluation



Cualquiera de estos siendo cero = sistema falla en producción.
