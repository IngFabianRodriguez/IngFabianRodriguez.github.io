Intro - Cuando Google Translate No Es Suficiente

Mi tía Clara vive en Cali y siempre me pide que le traduzca los correos que le llegan en inglés. Hace unos meses le pasó uno de su nieto que vive en Texas: "Dear grandma, I'm doing great in my new job, it's pretty chill". Mi tía lo tradujo como "Estoy haciendo grande en mi trabajo nuevo, es bastante frío". Vamos, tía Clara, "chill" no significa que la oficina tenga aire acondicionado.

El problema de la traducción no es solo lingüístico, es cultural. Y ahí es donde los LLMs están revolucionando el juego. Hoy vamos a ver cómo usar LLMs para traducción: zero-shot, fine-tuning, cómo manejar idiomas con pocos recursos, y las métricas para saber si tu traducción es buena o si es un世贸.

¿Por Qué LLMs Para Traducción?

Los modelos tradicionales de traducción como los basados en seq2seq fueron diseñados específicamente para traducir. Los LLMs como GPT-4, Claude, o LLaMA fueron entrenados con billions de texto multilingüe y han absorbido conocimiento de traducción incidentalmente.

La ventaja: los LLMs pueden manejar contexto largo, tono, jerga técnica, e incluso aspectos culturales. La desventaja: pueden ser overkill para traducciones simples y son más lentos que modelos especializados.

La decisión clave: ¿zero-shot (sin entrenamiento adicional) o fine-tuned (adaptado)?

Zero-Shot Translation

Zero-shot significa usar el LLM directamente sin ningún entrenamiento específico para traducción. Solo le dices: "Translate to Spanish".

from openai import OpenAI
from typing import List, Dict, Optional

client = OpenAI()

def translate_zero_shot(
    text: str,
    source_lang: str,
    target_lang: str,
    model: str = "gpt-4",
    tone: str = "formal"
) -> str:
    """Traducción zero-shot con LLM."""

    system_prompt = f"""You are a professional translator.
Translate the following text from {source_lang} to {target_lang}.
Maintain the original tone and style.
If you encounter ambiguous terms, provide the most contextually appropriate translation."""

    user_prompt = f"""Translate this text:

{text}

Requirements:
- Tone: {tone}
- Preserve formatting (paragraphs, line breaks)
- Keep technical terms in original language if no standard translation exists"""

    response = client.chat.completions.create(
        model=model,
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_prompt}
        ],
        temperature=0.3  # Baja temperature para consistencia
    )

    return response.choices[0].message.content

def batch_translate(
    texts: List[str],
    source_lang: str,
    target_lang: str,
    model: str = "gpt-4"
) -> List[str]:
    """Traduce múltiples textos en batch."""

    combined_text = "\n---\n".join([
        f"[Text {i+1}]:\n{t}" for i, t in enumerate(texts)
    ])

    system_prompt = f"""You are a professional translator.
Translate each section from {source_lang} to {target_lang}.
Preserve the [Text N] markers.
Maintain original tone and formatting."""

    response = client.chat.completions.create(
        model=model,
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": f"Translate the following texts:\n\n{combined_text}"}
        ],
        temperature=0.3
    )

    # Extraer cada traducción
    result = response.choices[0].message.content
    translations = []
    for segment in result.split("[Text"):
        if "]:\n" in segment:
            translations.append(segment.split("]:\n", 1)[1].strip())
    return translations

# Ejemplo de uso
if __name__ == "__main__":
    # Traducción simple
    english_text = "The software is pretty chill, but the code is getting messy."
    spanish = translate_zero_shot(english_text, "English", "Spanish")
    print(f"EN: {english_text}")
    print(f"ES: {spanish}")
    # Output esperado: "El software es bastante relajado, pero el código se está volviendo un desastre."
    # Note: "chill" se traduce correctamente como "relajado" en contexto informal

La Matemática: BLEU y Otras Métricas

¿Cómo sabemos si una traducción es buena? La métrica clásica es BLEU (Bilingual Language Evaluation), que mide overlap entre n-grams de la traducción y referencias humanas:

$$BLEU = BP \cdot \exp\left(\sum_{n=1}^{N} w_n \log p_n\right)$$

Donde:

  • BP = Brevity Penalty (penaliza traducciones muy cortas)
  • p_n = precisión de n-grams
  • w_n = peso para cada n-gram (típicamente 1/N)

BLEU va de 0 a 100. Pero tiene limitaciones: no captura bien el significado semántico ni la fluidez natural.

Métricas más modernas incluyen METEOR, chrF, y COMET (que usa un modelo neural para evaluar).

Código: Translation Framework Completo

from dataclasses import dataclass
from typing import List, Dict, Optional, Tuple
import torch
from collections import Counter
import math

@dataclass
class TranslationConfig:
    """Configuración para traducción con LLM."""
    model: str = "gpt-4"
    temperature: float = 0.3
    source_lang: str = "English"
    target_lang: str = "Spanish"
    domain: str = "general"  # general, medical, legal, technical
    preserve_formatting: bool = True
    glossary: Optional[Dict[str, str]] = None  # Términos fijos

class BLEUScore:
    """Implementación de BLEU score."""

    @staticmethod
    def ngrams(sequence: List[str], n: int) -> Counter:
        """Genera n-grams de una secuencia."""
        return Counter(tuple(sequence[i:i+n]) for i in range(len(sequence) - n + 1))

    @staticmethod
    def brevity_penalty(candidate: List[str], references: List[List[str]]) -> float:
        """Calcula brevidad penalizada."""
        c = len(candidate)
        r = min(abs(len(r) - c) for r in references)  # Closest reference length

        if c > r:
            return 1.0
        return math.exp(1 - r / c) if r > 0 else 0.0

    @staticmethod
    def precision(candidate: List[str], references: List[List[str]], n: int) -> float:
        """Calcula precisión de n-grams."""
        if len(candidate) < n:
            return 0.0

        cand_ngrams = BLEUScore.ngrams(candidate, n)
        ref_ngrams = Counter()
        for ref in references:
            ref_ngrams |= BLEUScore.ngrams(ref, n)

        overlap = sum((cand_ngrams & ref_ngrams).values())
        total = sum(cand_ngrams.values())

        return overlap / total if total > 0 else 0.0

    @classmethod
    def compute(cls, candidate: str, references: List[str], max_n: int = 4) -> float:
        """Calcula BLEU score."""
        cand_tokens = candidate.split()
        ref_tokens = [ref.split() for ref in references]

        bp = cls.brevity_penalty(cand_tokens, ref_tokens)

        # Promedio ponderado de precisiones
        precisions = []
        for n in range(1, max_n + 1):
            p = cls.precision(cand_tokens, ref_tokens, n)
            if p > 0:
                precisions.append(p)

        if not precisions:
            return 0.0

        # Media geométrica de precisiones
        score = math.exp(sum(math.log(p) for p in precisions) / len(precisions))
        return bp * score * 100  # Escalar a 0-100

class TranslationFramework:
    """Framework completo para traducción con LLMs."""

    def __init__(self, llm_client=None):
        self.client = llm_client
        self.bleu = BLEUScore()
        self.translation_cache = {}

    def translate(
        self,
        text: str,
        config: TranslationConfig
    ) -> str:
        """Traduce texto con configuración dada."""

        # Preparar prompt según dominio
        domain_context = self._get_domain_context(config.domain)

        # Aplicar glossary si existe
        if config.glossary:
            text = self._apply_glossary(text, config.glossary)

        # Construir prompt
        prompt = self._build_prompt(text, config, domain_context)

        # Llamar al LLM
        response = self._call_llm(prompt, config)

        # Post-procesamiento
        if config.preserve_formatting:
            response = self._preserve_formatting(text, response)

        return response

    def _get_domain_context(self, domain: str) -> str:
        """Obtiene contexto especializado por dominio."""
        contexts = {
            "medical": "Use precise medical terminology. Ensure accuracy of anatomical and pharmacological terms.",
            "legal": "Use formal legal language. Preserve legal structure and terminology.",
            "technical": "Maintain technical accuracy. Keep established technical terms in original language when standard translation doesn't exist.",
            "general": "Prioritize natural, fluent translation that sounds native."
        }
        return contexts.get(domain, contexts["general"])

    def _apply_glossary(self, text: str, glossary: Dict[str, str]) -> str:
        """Aplica glossary de términos antes de traducir."""
        for term, translation in glossary.items():
            # Marcar términos para no traducir
            text = text.replace(term, f"||{term}||")
        return text

    def _build_prompt(self, text: str, config: TranslationConfig, domain_context: str) -> str:
        """Construye prompt para traducción."""
        return f"""Translate from {config.source_lang} to {config.target_lang}.

Domain: {config.domain}
Context: {domain_context}

Text to translate:
{text}

Requirements:
- Maintain original tone and style
- Preserve paragraph structure
- Use natural target language that sounds native
- For marked terms ||term||, use the provided translation exactly"""

    def _call_llm(self, prompt: str, config: TranslationConfig) -> str:
        """Llama al LLM para traducción."""
        if self.client:
            # Usar cliente real
            response = self.client.chat.completions.create(
                model=config.model,
                messages=[
                    {"role": "user", "content": prompt}
                ],
                temperature=config.temperature
            )
            return response.choices[0].message.content
        else:
            # Mock para testing
            return f"[Translated: {prompt[:50]}...]"

    def _preserve_formatting(self, original: str, translation: str) -> str:
        """Preserva estructura de párrafos."""
        original_paras = original.split("\n\n")
        trans_paras = translation.split("\n\n")

        # Simple: asegurar mismo número de párrafos
        if len(original_paras) == len(trans_paras):
            return "\n\n".join(trans_paras)
        return translation

    def evaluate_translation(
        self,
        candidate: str,
        references: List[str]
    ) -> Dict[str, float]:
        """Evalúa traducción contra referencias."""
        bleu = self.bleu.compute(candidate, references)

        # Métricas adicionales
        metrics = {
            "bleu": bleu,
            "length_ratio": len(candidate) / max(len(r) for r in references),
            "word_overlap": len(set(candidate.split()) & set(" ".join(references).split()))
                           / len(set(candidate.split()))
        }

        return metrics

class CodeSwitchingHandler:
    """Maneja code-switching (mezcla de idiomas) en traducción."""

    def __init__(self, framework: TranslationFramework):
        self.framework = framework

    def detect_code_switching(self, text: str) -> List[Dict]:
        """Detecta segmentos con code-switching."""
        # Patrones comunes de code-switching
        import re
        patterns = [
            r'\b(pero|and|porque|that|si|if)\b',  # Conjuncciones
            r'\b(el|la|the|un|a)\s+\w+\s+\w+\b',   # Artículos mezclados
        ]

        segments = []
        last_end = 0

        for pattern in patterns:
            for match in re.finditer(pattern, text, re.IGNORECASE):
                segments.append({
                    "start": match.start(),
                    "end": match.end(),
                    "text": match.group(),
                    "pattern": pattern
                })

        return sorted(segments, key=lambda x: x["start"])

    def translate_with_code_switching(
        self,
        text: str,
        config: TranslationConfig
    ) -> str:
        """Traduce manejando code-switching apropiadamente."""

        # Detectar code-switching
        switches = self.detect_code_switching(text)

        if not switches:
            # Sin code-switching, traducción normal
            return self.framework.translate(text, config)

        # Traducir segmentos alternadamente
        result = []
        last_pos = 0

        for switch in switches:
            # Traducir segmento antes del switch
            if switch["start"] > last_pos:
                segment = text[last_pos:switch["start"]]
                translated = self.framework.translate(segment, config)
                result.append(translated)

            # Mantener el código mezclado como está
            result.append(switch["text"])
            last_pos = switch["end"]

        # Traducir resto
        if last_pos < len(text):
            segment = text[last_pos:]
            translated = self.framework.translate(segment, config)
            result.append(translated)

        return " ".join(result)

# Ejemplo de evaluación
def demo_evaluation():
    """Demuestra evaluación de traducciones."""
    framework = TranslationFramework()

    candidate = "El software es bastante relajado pero el código se está volviendo un desastre"
    references = [
        "El software es bastante relajado pero el código se está volviendo un desastre",
        "El software es bastante tranquilo aunque el código se está volviendo un desorden"
    ]

    metrics = framework.evaluate_translation(candidate, references)
    print(f"BLEU Score: {metrics['bleu']:.2f}")
    print(f"Length Ratio: {metrics['length_ratio']:.2f}")
    print(f"Word Overlap: {metrics['word_overlap']:.2f}")

Fine-Tuning Para Dominios Específicos

Para traducción de alta calidad en dominios específicos (médico, legal, técnico), el zero-shot puede no ser suficiente. Ahí entra el fine-tuning.

from transformers import AutoModelForSeq2SeqLM, AutoTokenizer, Trainer, TrainingArguments
from datasets import Dataset
import json

def prepare_translation_data(
    data_path: str,
    source_lang: str,
    target_lang: str
) -> Dataset:
    """Prepara dataset para fine-tuning de traducción."""

    # Cargar datos
    with open(data_path, 'r') as f:
        data = json.load(f)

    # Formatear para seq2seq
    formatted_data = []
    for item in data:
        formatted_data.append({
            "input_text": f"Translate from {source_lang} to {target_lang}: {item['source']}",
            "target_text": item['target']
        })

    return Dataset.from_list(formatted_data)

def fine_tune_translation_model(
    model_name: str,
    train_data: Dataset,
    eval_data: Dataset,
    output_dir: str
):
    """Fine-tunea un modelo para traducción."""

    # Cargar modelo y tokenizer
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSeq2SeqLM.from_pretrained(model_name)

    # Tokenizar datos
    def tokenize(batch):
        inputs = tokenizer(
            batch["input_text"],
            padding="max_length",
            truncation=True,
            max_length=128
        )
        targets = tokenizer(
            batch["target_text"],
            padding="max_length",
            truncation=True,
            max_length=128
        )

        inputs["labels"] = targets["input_ids"]
        return inputs

    train_data = train_data.map(tokenize, batched=True)
    eval_data = eval_data.map(tokenize, batched=True)

    # Configuración de entrenamiento
    training_args = TrainingArguments(
        output_dir=output_dir,
        num_train_epochs=3,
        per_device_train_batch_size=16,
        per_device_eval_batch_size=16,
        warmup_steps=500,
        weight_decay=0.1,
        logging_dir=f"{output_dir}/logs",
        logging_steps=100,
        eval_strategy="epoch",
        save_strategy="epoch",
        load_best_model_at_end=True,
    )

    # Entrenar
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=train_data,
        eval_dataset=eval_data,
    )

    trainer.train()
    return model, tokenizer

def translate_with_fine_tuned(
    text: str,
    model,
    tokenizer,
    source_lang: str,
    target_lang: str
) -> str:
    """Traduce usando modelo fine-tuned."""
    input_text = f"Translate from {source_lang} to {target_lang}: {text}"

    inputs = tokenizer(input_text, return_tensors="pt", truncation=True)
    outputs = model.generate(
        **inputs,
        max_length=128,
        num_beams=4,
        early_stopping=True
    )

    return tokenizer.decode(outputs[0], skip_special_tokens=True)

Los 3 Errores Que el 80% Comete

Error 1: No Considerar LLMs Para Traducción

Mucha gente todavía asume que Google Translate o DeepL son siempre la mejor opción. No es cierto.

¿Por qué está mal? Para traducciones que requieren contexto cultural, tono específico, o manejo de jerga técnica, los LLMs superan a los sistemas tradicionales porque pueden razonar sobre el significado, no solo hacer mapping palabra por palabra.

La solución: Evalúa ambas opciones para tu caso de uso. Para textos complejos, creativos, o culturalmente densos, usa LLMs. Para textos simples y repetitivos, los sistemas tradicionales pueden ser más rápidos y baratos.

Error 2: No Hacer Fine-Tuning Para Dominios Específicos

Usar un LLM general para traducción médica, legal, o técnica sin adaptación es como pedirle a un médico general que haga cirugía de cerebro. Puede intentarlo, pero no es su especialidad.

¿Por qué está mal? Sin fine-tuning, el modelo puede usar terminología incorrecta o inapropiada para el dominio. "Drug" puede traducirse como "droga" en contexto general pero debe ser "medicamento" en contexto médico.

La solución: Crea un dataset especializado (aunque sea pequeño, 100-500 ejemplos de alta calidad) y hace fine-tuning. Los resultados son dramáticamente mejores.

Error 3: No Manejar Code-Switching

En comunidades latinas en EE.UU., el code-switching es la norma: "I'm gonna go get some tacos, está bien?" No manejar esto produce traducciones que suenan robóticas.

¿Por qué está mal? El code-switching tiene reglas gramaticales propias. "I'm gonna" no se traduce como "Estoy yendo a", sino que se mantiene la estructura del inglés mezclada con español. Sin manejo adecuado, la traducción pierde naturalidad y a veces significado.

La solución: Implementa detección de code-switching y preserva los segmentos en el idioma original cuando sea apropiado, o traduce considerando el contexto lingüístico mixto.

Low-Resource Languages

Para idiomas con pocos datos de entrenamiento, hay estrategias específicas:

  • Multilingual models: Usa modelos entrenados con muchos idiomas (mBERT, XLM-R)
  • Back-translation: Traduce a inglés y de vuelta para augmentar datos
  • Pivot translation: Traduce a través de un idioma puente (ej: Nahuatl → Español → Inglés)
  • Few-shot learning: Usa ejemplos en el prompt aunque el idioma no sea el objetivo
class LowResourceTranslator:
    """Traductor para idiomas con pocos recursos."""

    def __init__(self, client):
        self.client = client

    def translate_with_pivot(
        self,
        text: str,
        source_lang: str,
        target_lang: str,
        pivot_lang: str = "Spanish"
    ) -> str:
        """Traduce usando un idioma pivot."""

        # Primera traducción: source → pivot
        step1 = self._translate_direct(text, source_lang, pivot_lang)

        # Segunda traducción: pivot → target
        final = self._translate_direct(step1, pivot_lang, target_lang)

        return final

    def translate_few_shot(
        self,
        text: str,
        source_lang: str,
        target_lang: str,
        examples: List[Tuple[str, str]]
    ) -> str:
        """Traduce con few-shot examples."""

        examples_text = "\n".join([
            f"Example: {src} → {tgt}"
            for src, tgt in examples
        ])

        prompt = f"""You are a translator for {target_lang}.

Translate the following text from {source_lang} to {target_lang}.

{examples_text}

Now translate:

{text}"""

        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3
        )

        return response.choices[0].message.content

    def _translate_direct(self, text, source, target):
        """Traducción directa simple."""
        prompt = f"Translate from {source} to {target}: {text}"
        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3
        )
        return response.choices[0].message.content

# Ejemplo: traducir del náhuatl al inglés usando español como pivot
def demo_low_resource():
    translator = LowResourceTranslator(client)

    nahuatl_text = "Cualli tetl in amoxtli"  # Ejemplo simplificado

    # Con pivot
    translation = translator.translate_with_pivot(
        nahuatl_text,
        source_lang="Nahuatl",
        target_lang="English",
        pivot_lang="Spanish"
    )
    print(f"Nahuatl: {nahuatl_text}")
    print(f"English: {translation}")

TRANSLATION_STRATEGY_GUIDE = {
    # Textos simples, alta volumen, baja-latencia
    "quick_generic": {
        "method": "google_deepl",
        "when": "Documentos simples, no hay contexto cultural, necesitas velocidad"
    },

    # Textos complejos con contexto
    "complex_contextual": {
        "method": "llm_zero_shot",
        "model": "gpt-4",
        "when": "Textos creativos, literaria, marketing, contexto cultural importante"
    },

    # Dominios especializados con dataset
    "specialized_with_data": {
        "method": "llm_fine_tuned",
        "when": "Dominio médico/legal/técnico con 100+ ejemplos de entrenamiento"
    },

    # Code-switching
    "codeswitching": {
        "method": "llm_with_handler",
        "when": "Textos de comunidades bilingües, redes sociales, chat"
    },

    # Low-resource
    "low_resource": {
        "method": "pivot_or_multilingual",
        "when": "Idiomas con pocos recursos, dialectos, lenguas indígenas"
    }
}

def recommend_strategy(
    text_type: str,
    has_domain_data: bool,
    is_low_resource: bool,
    has_code_switching: bool
) -> str:
    """Recomienda estrategia de traducción."""
    if has_code_switching:
        return "codeswitching"
    elif is_low_resource:
        return "low_resource"
    elif has_domain_data and text_type in ["medical", "legal", "technical"]:
        return "specialized_with_data"
    elif text_type in ["creative", "literary", "marketing"]:
        return "complex_contextual"
    else:
        return "quick_generic"

Cierre - Colombianito

Entonces, ¿qué aprendimos hoy? Que traducir con IA no es solo apretar el botón de Google Translate. Hay toda una ciencia (y arte) detrás: zero-shot vs fine-tuning, BLEU scores, manejo de code-switching, idiomas con pocos recursos...

La próxima vez que tu tía Clara te pida que le traduzcas algo, ya sabes qué hacer: pregúntale primero qué tipo de texto es, si tiene contexto cultural, si hay términos técnicos. Y si te dice "es que el nieto me dijo que el trabajo está pretty chill", tú ya sabes que chill no significa frío, significa relajado. Aunque en el fondo, lo que quiere decir es que el muchacho está bien, y eso no necesita traducción.

En resumen: para traducciones simples, las herramientas tradicionales están bien. Pero cuando el texto se pone interesante —contexto cultural, jerga, code-switching, dominios técnicos— ahí los LLMs brillan. Y si tienes datos específicos para tu dominio, el fine-tuning es el move.
