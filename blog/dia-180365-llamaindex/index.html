Activation Functions - ReLU vs GELU vs Swish

29 de junio de 2026
activationsrelugeluswish

🎯 Activation Functions: Conceptos Fundamentales

Las activation functions introducen no-linearidad en las redes. Sin ellas, una red neuronal de 100 capas sería equivalente a una sola capa lineal. El 85% de practitioners usa ReLU en todo sin entender cuándo y por qué otras funciones son mejores.

Las tres más importantes:

  • ReLU: max(0, x) — simple, eficiente, default en la mayoría de casos
  • GELU: x · Φ(x) — la preferida de Transformers y LLMs
  • Swish: x · sigmoid(x) — research muestra mejor performance en deep networks

📐 La Matemática Detrás

ReLU:

$$f(x) = \\max(0, x)$$

GELU (Gaussian Error Linear Unit):

$$f(x) = x \\cdot \\Phi(x) = x \\cdot \\frac{1}{2}\\left[1 + \\text{erf}\\left(\\frac{x}{\\sqrt{2}}\\right)\\right]$$

Swish:

$$f(x) = x \\cdot \\sigma(x) = \\frac{x}{1 + e^{-x}}$$

¿Por qué importa?

  • ReLU: muerte de neuronas si muchos inputs son negativos
  • GELU: más suave, mejor para Transformers
  • Swish: gated, permite información fluida incluso cuando x < 0

💻 Implementación en PyTorch

import torch
import torch.nn as nn

# Las tres activation functions más comunes
class ActivationsDemo(nn.Module):
    def __init__(self, activation_type='relu'):
        super().__init__()
        self.fc1 = nn.Linear(768, 512)
        
        # Selecciona activation
        if activation_type == 'relu':
            self.activation = nn.ReLU()
        elif activation_type == 'gelu':
            self.activation = nn.GELU()
        elif activation_type == 'swish':
            self.activation = nn.SiLU()  # Swish = SiLU en PyTorch
        elif activation_type == 'leaky_relu':
            self.activation = nn.LeakyReLU(0.1)
        else:
            raise ValueError(f"Unknown activation: {activation_type}")
        
        self.fc2 = nn.Linear(512, 256)
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.activation(x)  # Aquí aplica la activation
        x = self.fc2(x)
        return x

# Uso
model = ActivationsDemo('gelu')
x = torch.randn(32, 768)
output = model(x)
print(f"Output shape: {output.shape}")

⚠️ Errores Comunes

Error 1: Usar ReLU en Transformers

El problema: GELU es significativamente mejor para Transformers porque su forma suave permite mejor flow de gradientes en arquitecturas profundas. BERT, GPT, y LLMs usan GELU.

# Incorrecto para Transformers
model = nn.Sequential(
    nn.Linear(768, 512),
    nn.ReLU(),  # ❌ Funciona pero no es óptimo
    nn.Linear(512, 256),
)

# Correcto para Transformers
model = nn.Sequential(
    nn.Linear(768, 512),
    nn.GELU(),  # ✓ Mejor para self-attention
    nn.Linear(512, 256),
)

Error 2: No Usar BatchNorm Después de Conv

El problema: Sin normalization, la varianza deactivations puede explotar especialmente con ReLU. Conv + BatchNorm + Activation es el pattern correcto.

# Pattern correcto para CNNs
class ConvBlock(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.bn = nn.BatchNorm2d(out_channels)  # ✓ Antes de activation
        self.activation = nn.ReLU()  # ✓ Después de BN
    
    def forward(self, x):
        x = self.conv(x)
        x = self.bn(x)
        x = self.activation(x)
        return x

Error 3: Dying ReLU Problem

El problema: Con ReLU, si muchos inputs son negativos, las neuronas "mueren" y siempre output 0. Esto reduce la capacidad del modelo.

# Solución: usar LeakyReLU o PReLU
leaky_relu = nn.LeakyReLU(0.1)  # Permite gradiente pequeño para x < 0
prelu = nn.PReLU()  # Learnable slope para negativos

# Test
x = torch.tensor([-5.0, -1.0, 0.0, 1.0, 5.0])
print(f"LeakyReLU: {leaky_relu(x)}")
# tensor([-0.5, -0.1,  0. ,  1. ,  5. ])
print(f"PReLU: {prelu(x)}")

✅ Resumen y Recomendaciones

  • CNN/Vision: ReLU o LeakyReLU son suficientes
  • Transformers/LLMs: GELU es el standard
  • Deep Networks: Swish/SiLU puede outperform ReLU
  • Siempre usa Conv → BatchNorm → Activation
  • Cuidado con dying ReLU en redes profundas

Hágale que activation functions importan. GELU para Transformers, ReLU para CNNs, y si ves "dead neurons", cambia a LeakyReLU o PReLU. El 15% que usa la activación correcta tiene modelos que entrenan 20% más rápido, parcero.
