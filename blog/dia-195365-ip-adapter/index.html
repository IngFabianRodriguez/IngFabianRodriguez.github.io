Optimización de Prompts: La Guía Definitiva Que el 80% Ignora

Hagale pues, parcero. Día 195 y hoy llegamos al tema que nadie te explica bien: cómo optimizar prompts de verdad. No es solo "escribir mejor", es usar técnicas como prompt tuning, soft prompts y prefix tuning para que tu LLM aprenda a responder sin reentrenar todo el modelo. Esto lo ignoran el 80% de los developers. Vamos con café.

🎯 Por Qué tus Prompts No Generalizan

El problema fundamental: hard-coded prompts (escribir instrucciones fijas en el input) no generalizan a situaciones nuevas. Si tu prompt dice "cuando el usuario pregunte por clima, responde con datos meteorológicos", fallará cuando pregunte "cómo está el tiempo en Bogotá?".

La solución: aprender representations de los prompts que se adaptan automáticamente. Eso es el prompt tuning.

Conceptos clave:

  • Hard prompts: Texto fijo escrito por humanos — no generaliza
  • Soft prompts: Embeddings aprendibles que se concatenan con el input
  • Prefix tuning: Prepende un vector aprendible antes de cada capa transformer
  • P-tuning: Usa embeddings de tokens persistentes (prompt tokens)

📐 La Matemática del Prompt Tuning

En lugar de modificar los pesos del modelo base, aprendemos un conjunto de k embeddings de prompt:

$$\mathcal{L}(\theta_p) = \sum_{(x,y) \in \mathcal{D}} -\log p_\theta(y | p_\theta(x))$$

Donde $p_\theta$ son los pesos del modelo frozen y $p_\theta$ son los embeddings del prompt que optimizamos via gradient descent.

Comparación de métodos:

Fine-tuning completo: $\theta_{nuevo} = \theta_{pre} - \alpha \nabla_\theta \mathcal{L}$ — actualiza TODOS los parámetros.

Prompt tuning: Solo actualiza $P = [p_1, p_2, ..., p_k]$ donde $k \ll |\theta|$ — el modelo base queda frozen.

Prefix tuning: Para cada capa $l$, prepending $P_l \in \mathbb{R}^{k \times d_{model}}$ antes de $h_l$.

🚀 Implementación en PyTorch

import torch
import torch.nn as nn
from transformers import AutoModel, AutoTokenizer

class PromptTuner(nn.Module):
    """Prompt Tuning: embeddings aprendibles concatenados al input."""
    def __init__(self, model_name, num_prompts=20, embed_dim=768):
        super().__init__()
        self.model = AutoModel.from_pretrained(model_name)
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        
        # Soft prompts aprendibles (num_prompts x embed_dim)
        self.prompt_embeddings = nn.Parameter(
            torch.randn(num_prompts, embed_dim) * 0.01
        )
        # Freeze el modelo base
        for param in self.model.parameters():
            param.requires_grad = False
    
    def forward(self, input_ids, attention_mask):
        # Obtener embeddings del input
        inputs_embeds = self.model.get_input_embeddings()(input_ids)
        
        # Concatenar soft prompts antes del input
        batch_size = input_ids.shape[0]
        prompt_embeds = self.prompt_embeddings.unsqueeze(0).expand(batch_size, -1, -1)
        inputs_embeds = torch.cat([prompt_embeds, inputs_embeds], dim=1)
        
        # Adjust attention mask para incluir los prompts
        prompt_mask = torch.ones(batch_size, self.prompt_embeddings.shape[0], 
                                  device=attention_mask.device)
        attention_mask = torch.cat([prompt_mask, attention_mask], dim=1)
        
        outputs = self.model(inputs_embeds=inputs_embeds, 
                            attention_mask=attention_mask)
        return outputs.last_hidden_state


class PrefixTuner(nn.Module):
    """Prefix Tuning: prepending a CADA capa del transformer."""
    def __init__(self, model_name, num_prefix=20, prefix_dim=768):
        super().__init__()
        self.model = AutoModel.from_pretrained(model_name)
        
        # Para cada capa: prefix keys + values como embeddings aprendibles
        num_layers = self.model.config.num_hidden_layers
        self.prefix_keys = nn.ParameterDict()
        self.prefix_values = nn.ParameterDict()
        
        for layer in range(num_layers):
            self.prefix_keys[str(layer)] = nn.Parameter(
                torch.randn(num_prefix, prefix_dim) * 0.01
            )
            self.prefix_values[str(layer)] = nn.Parameter(
                torch.randn(num_prefix, prefix_dim) * 0.01
            )
    
    def forward(self, input_ids, attention_mask):
        # Prefix tuning intercepta los attention heads
        # (versión simplificada - ver implementación completa con hooks)
        outputs = self.model(input_ids, attention_mask=attention_mask)
        return outputs.last_hidden_state

🔧 P-Tuning y Prompt Tokens Persistentes

class PTuning(nn.Module):
    """P-Tuning: usa tokens virtuales como prompts (no son tokens reales)."""
    def __init__(self, vocab_size, embed_dim=768, num_prompt_tokens=100):
        super().__init__()
        # Tokens virtuales (no corresponden a ninguna palabra real)
        self.prompt_tokens = nn.Parameter(
            torch.randn(num_prompt_tokens, embed_dim) * 0.01
        )
        # MLP pequeño para transformar los prompt tokens
        self.prompt_mlp = nn.Sequential(
            nn.Linear(embed_dim, embed_dim),
            nn.ReLU(),
            nn.Linear(embed_dim, embed_dim)
        )
        self.vocab_size = vocab_size
        self.embed_dim = embed_dim
    
    def get_prompt_embeddings(self):
        """Aplica MLP a los prompt tokens (mejora estabilidad)."""
        return self.prompt_mlp(self.prompt_tokens)


class HybridPromptTuner(nn.Module):
    """Combina hard prompts (texto real) + soft prompts (aprendibles)."""
    def __init__(self, model_name, num_soft_prompts=10):
        super().__init__()
        self.model = AutoModel.from_pretrained(model_name)
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        
        # Soft prompts aprendibles
        self.soft_prompt = nn.Parameter(
            torch.randn(num_soft_prompts, self.model.config.hidden_size) * 0.01
        )
        
        # Hard-coded prompt template
        self.hard_prompt_template = "Responde de forma {estilo} sobre {tema}: "
    
    def build_prompt(self, estilo, tema):
        """Combina hard + soft prompts."""
        hard_prompt = self.hard_prompt_template.format(estilo=estilo, tema=tema)
        hard_ids = self.tokenizer(hard_prompt, return_tensors="pt")["input_ids"]
        hard_embeds = self.model.get_input_embeddings()(hard_ids)
        
        # Concatenar: hard_prompt + soft_prompt + input
        return hard_embeds, hard_ids.shape[1]
    
    def forward(self, input_ids, estilo="formal", tema="general"):
        hard_embeds, hard_len = self.build_prompt(estilo, tema)
        soft_prompt = self.soft_prompt.unsqueeze(0).expand(input_ids.shape[0], -1, -1)
        
        inputs_embeds = self.model.get_input_embeddings()(input_ids)
        inputs_embeds = torch.cat([hard_embeds, soft_prompt, inputs_embeds], dim=1)
        
        return self.model(inputs_embeds=inputs_embeds)

⚠️ Errores Comunes (y Sus Fixes)

Error 1: No Usar Soft Prompts Cuando Hard-Coded Prompts No Generalizan

El problema: Escribes prompts fijos en texto. Si tu aplicación recibe variaciones no vistas, el prompt falla. Ejemplo:

# ❌ Hard-coded - no generaliza
PROMPT = "Clasifica como: positivo, negativo o neutral"

# El usuario escribe: "esto es una basura horrible"
# → funciona

# El usuario escribe: "no puedo creer que sea tan malo"
# → puede fallar porque "malo" no está explícitamente en el prompt

# ✅ Soft prompt - aprende la representación semántica
prompt_tuner = PromptTuner("bert-base-uncased", num_prompts=50)
# El modelo aprende qué patrones son positivos/negativos/neutrales

El fix: Implementa prompt tuning cuando necesites que el modelo se adapte a distribuciones de inputs no vistas en entrenamiento.

Error 2: Prompt Tuning Sin Suficiente Data

El problema: Prompt tuning necesita suficientes ejemplos para aprender buenos embeddings. Con <1000 ejemplos puede sobreajustar o no aprender nada útil.

# ❌ Prompts learn慢慢地 con poca data (underfitting)
num_prompts = 20
num_examples = 100  # Muy pocos!

# ✅ Regla práctica: mínimo 5-10 ejemplos por prompt token
num_prompts = 10
num_examples = 5000  # Suficiente para que los prompts aprendan

# ⚠️ Si tienes poca data, usa few-shot prompting en vez de prompt tuning
EXAMPLES = [
    ("Me encanta", "positivo"),
    ("Esto es terrible", "negativo"),
    ("No está mal", "neutral"),
]

El fix: Asegura al menos 1K-5K ejemplos para prompt tuning efectivo. Si tienes menos, usa few-shot con ejemplos en el prompt.

Error 3: No Separar Optimización de Prompts de Fine-Tuning

El problema: Mezclar ambos causa que los prompts aprendidos interfieran con los pesos del modelo. No sabes qué está aprendiendo qué.

class MixedModel(nn.Module):

        self.model = AutoModel.from_pretrained("bert-base")
        self.prompt_embeds = nn.Parameter(torch.randn(20, 768))
        # ¡ERROR! No separas qué optimiza qué
    
    def forward(self, input_ids):
        # Ambos se entrenan juntos → confusión
        ...

# ✅ Dos fases separadas
# Fase 1: Solo prompt tuning (modelo frozen)
prompt_tuner = PromptTuner("bert-base")
optimizer = torch.optim.Adam(prompt_tuner.prompt_embeddings, lr=1e-3)
# Entrenar solo los prompts...

# Fase 2: Fine-tuning ligero si necesitas más rendimiento
for param in prompt_tuner.model.parameters():
    param.requires_grad = True
optimizer2 = torch.optim.Adam(prompt_tuner.model.parameters(), lr=1e-5)
# Entrenar modelo + prompts juntos...

El fix: Entrena en fases separadas. Primero optimiza prompts con modelo frozen. Depois, si necesitas más rendimiento, hace fine-tuning del modelo completo con learning rate muy bajo.

🚀 Integración en Production

import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

class ProductionPromptTuner:
    """Sistema de producción para prompt tuning."""
    def __init__(self, model_name, num_prompts=20):
        self.model = AutoModelForSequenceClassification.from_pretrained(model_name)
        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.prompt_embeddings = nn.Parameter(
            torch.randn(num_prompts, self.model.config.hidden_size)
        )
        # Cargar prompts entrenados
        self.load_prompts("prompts_trained.pt")
    
    @torch.no_grad()
    def predict(self, text, style="formal"):
        """Inference con prompts aprendidos."""
        inputs = self.tokenizer(text, return_tensors="pt")
        inputs_embeds = self.model.get_input_embeddings()(inputs["input_ids"])
        
        # Concatenar prompts
        prompt = self.prompt_embeddings.unsqueeze(0)
        inputs_embeds = torch.cat([prompt.expand(inputs_embeds.shape[0], -1, -1), 
                                   inputs_embeds], dim=1)
        
        # Adjust attention mask
        mask = torch.ones_like(inputs_embeds[:, :, 0])
        outputs = self.model(inputs_embeds=inputs_embeds, 
                            attention_mask=mask)
        return outputs.logits.argmax(dim=-1)
    
    def save_prompts(self, path):
        torch.save(self.prompt_embeddings.state_dict(), path)
    
    def load_prompts(self, path):
        self.prompt_embeddings.load_state_dict(torch.load(path))


# En producción:
# 1. Entrena prompts offline con datos etiquetados
# 2. Guarda solo los embeddings de prompts (~MB)
# 3. Carga prompts + modelo frozen en producción
# 4. Inference rápido sin gradient tracking

📊 Resumen

  • Prompt tuning: Aprender embeddings de prompts con modelo frozen — 0.1-1% de parámetros.
  • Prefix tuning: Prepend a cada capa transformer — 0.5-2% de parámetros.
  • P-tuning: Tokens virtuales + MLP transformador — mejora estabilidad.
  • Hybrid: Combina hard prompts (texto real) + soft prompts (aprendibles).

Usa soft prompts cuando necesites generalizar a inputs no vistos. Usa prefix tuning cuando tengas restricciones de memoria muy estrictas. Usa P-tuning cuando necesites más estabilidad en el entrenamiento.
