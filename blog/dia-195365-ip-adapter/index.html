🎯 Qué Es IP-Adapter y Por Qué Necesitas Conocerlo

Hagale pues, parcero. Día 195 y hoy llegamos a IP-Adapter — una arquitectura de cross-attention que permite usar imágenes como prompts para modelos de difusión. Esto lo ignoran el 80% de los desarrolladores que trabajan con Stable Diffusion y modelos similares. Vamos con café.

El problema: quieres generar imágenes con un estilo visual específico pero no tienes palabras para describirlo.Tienes una imagen de referencia y quieres que el modelo la use como guía. Eso es exactamente lo que resuelve IP-Adapter.

Conceptos clave:

  • IP-Adapter: Image Prompt Adapter — permite condicionar generación con imágenes
  • Cross-attention: Mecanismo que conecta el prompt de imagen con el modelo de difusión
  • Decoupled cross-attention: Separa el condicionamiento de texto e imagen
  • Feature extraction: Usar un encoder de imágenes pre-entrenado (CLIP) para extraer features

📐 La Arquitectura Detrás de IP-Adapter

IP-Adapter usa un enfoque de dual cross-attention:

$$\mathcal{F}_{ca} = \text{Attention}(Q, K_{text}, V_{text}) + \alpha \cdot \text{Attention}(Q, K_{img}, V_{img})$$

Donde $\alpha$ es un factor de escala que controla la influencia de la imagen vs el texto.

Componentes principales:

  • Image Encoder: Extrae features de la imagen de prompt (típicamente CLIP ViT)
  • IP-Adapter Module: Pequeña red que transforma features de imagen a keys/values de cross-attention
  • Fusion: Combina el conditioning de texto e imagen

🚀 Implementación en PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F
from transformers import CLIPVisionModel, CLIPProcessor

class ImagePromptAdapter(nn.Module):
    """IP-Adapter: condiciona generación con imágenes."""
    def __init__(self, cross_attention_dim=768, num_tokens=4, clip_model_name="openai/clip-vit-base-patch32"):
        super().__init__()
        
        # Encoder de imagen (CLIP)
        self.image_encoder = CLIPVisionModel.from_pretrained(clip_model_name)
        self.processor = CLIPProcessor.from_pretrained(clip_model_name)
        
        # Proyección de imagen a cross-attention space
        self.image_proj = nn.Sequential(
            nn.Linear(cross_attention_dim, cross_attention_dim),
            nn.GELU(),
            nn.Linear(cross_attention_dim, cross_attention_dim)
        )
        
        # Tokens de imagen aprendibles
        self.num_tokens = num_tokens
        self.image_tokens = nn.Parameter(torch.randn(1, num_tokens, cross_attention_dim))
    
    def encode_image(self, image):
        """Extrae features de la imagen usando CLIP."""
        with torch.no_grad():
            image_features = self.image_encoder(image).last_hidden_state
        # Proyectar al espacio de cross-attention
        image_embeds = self.image_proj(image_features)
        return image_embeds
    
    def forward(self, latents, image, text_embeddings, alpha=1.0):
        """
        Aplica condicionamiento de imagen al proceso de difusión.
        latents: representación latente actual
        image: imagen de prompt (B, 3, H, W)
        text_embeddings: embeddings de texto del prompt
        alpha: peso del condicionamiento de imagen
        """
        batch_size = latents.shape[0]
        
        # Extraer features de imagen
        img_embeds = self.encode_image(image)
        
        # Concatenar image tokens al texto
        # text_embeddings shape: (B, seq_len, cross_attention_dim)
        img_tokens = self.image_tokens.expand(batch_size, -1, -1)
        
        # Fusionar: texto + imagen
        combined_embeds = torch.cat([text_embeddings, img_tokens], dim=1)
        
        # El resto del proceso de difusión usa combined_embeds
        return combined_embeds


class CrossAttentionLayer(nn.Module):
    """Capa de cross-attention para IP-Adapter."""
    def __init__(self, query_dim=768, context_dim=768, num_heads=8):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = query_dim // num_heads
        
        self.q_linear = nn.Linear(query_dim, query_dim)
        self.k_linear = nn.Linear(context_dim, query_dim)
        self.v_linear = nn.Linear(context_dim, query_dim)
        self.out_linear = nn.Linear(query_dim, query_dim)
    
    def forward(self, query, context, image_context, alpha=1.0):
        """
        query: features del modelo de difusión
        context: embeddings de texto
        image_context: embeddings de imagen del IP-Adapter
        """
        batch_size = query.shape[0]
        
        # Q from query (latents)
        q = self.q_linear(query)
        q = q.view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        
        # K, V del contexto combinado (texto + imagen)
        combined_context = torch.cat([context, image_context], dim=1)
        k = self.k_linear(combined_context)
        v = self.v_linear(combined_context)
        k = k.view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        v = v.view(batch_size, -1, self.num_heads, self.head_dim).transpose(1, 2)
        
        # Attention
        attn = F.scaled_dot_product_attention(q, k, v)
        attn = attn.transpose(1, 2).contiguous().view(batch_size, -1, self.num_heads * self.head_dim)
        
        # Escalar por alpha
        out = self.out_linear(attn) * alpha
        return out

🔧 Implementación Completa con Stable Diffusion

import torch
from diffusers import StableDiffusionPipeline, AutoencoderKL
from PIL import Image

class IPAdapterPipeline:
    """Pipeline de Stable Diffusion con IP-Adapter."""
    def __init__(self, model_id="runwayml/stable-diffusion-v1-5"):
        super().__init__()
        self.pipe = StableDiffusionPipeline.from_pretrained(model_id)
        self.pipe.to("cuda")
        
        # IP-Adapter modules
        self.ip_adapter = ImagePromptAdapter(
            cross_attention_dim=768,
            num_tokens=4
        ).to("cuda")
        
        # Imagen de referencia
        self.reference_image = None
    
    def set_image_prompt(self, image_path):
        """Carga una imagen como prompt de referencia."""
        self.reference_image = Image.open(image_path).convert("RGB")
        self.reference_image = self.reference_image.resize((512, 512))
    
    @torch.no_grad()
    def generate(self, prompt, num_inference_steps=50, guidance_scale=7.5, image_strength=0.8):
        """
        Genera imagen condicionada por texto + imagen.
        """
        if self.reference_image is None:
            raise ValueError("Primero establece una imagen de prompt con set_image_prompt()")
        
        # Procesar imagen de referencia
        image_input = self.pipe.feature_extractor(
            images=self.reference_image,
            return_tensors="pt"
        ).pixel_values.to("cuda")
        
        # Extraer features de imagen
        img_embeds = self.ip_adapter.encode_image(image_input)
        
        # Generar con el pipeline
        result = self.pipe(
            prompt=prompt,
            num_inference_steps=num_inference_steps,
            guidance_scale=guidance_scale,
            ip_adapter_image_embeds=img_embeds,
            strength=image_strength
        )
        
        return result.images[0]

⚠️ Errores Comunes (y Sus Fixes)

Error 1: Mezclar Texto e Imagen Sin Separar Cross-Attention

El problema: Usar la misma cross-attention para texto e imagen causa interferencia. El modelo no puede separar qué viene de dónde.

# ❌ Cross-attention unificada (incorrecta)
class UnifiedCrossAttention(nn.Module):
    def forward(self, query, context):
        # Contexto mezclado = no sabes qué atendió a qué
        combined = torch.cat([text_features, image_features], dim=1)
        return self.attention(query, combined)

# ✅ IP-Adapter: cross-attention desacoplada
class DecoupledCrossAttention(nn.Module):
    def __init__(self):
        super().__init__()
        # Una cross-attention para texto
        self.text_attention = CrossAttentionLayer()
        # Otra para imagen
        self.image_attention = CrossAttentionLayer()
    
    def forward(self, query, text_features, image_features, alpha=1.0):
        # Primero текст
        text_out = self.text_attention(query, text_features)
        # Depois imagen con peso alpha
        image_out = self.image_attention(query, image_features)
        # Combinar
        return text_out + alpha * image_out

El fix: Usa IP-Adapter con cross-attention separada para texto e imagen. Esto permite controlar independientemente el peso de cada condicionamiento.

Error 2: No Usar Encoder de Imagen Adequado

El problema: Usar un encoder de imagen débil (ej: un autoencoder básico) pierde información semántica importante.

# ❌ Encoder débil para features de imagen
class WeakImageEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(3, 32, 3),
            nn.ReLU(),
            nn.Conv2d(32, 64, 3),
            nn.AdaptiveAvgPool2d((1, 1))
        )
        self.proj = nn.Linear(64, 768)
    
    def forward(self, x):
        x = self.conv(x)
        return self.proj(x.flatten(1))

# ✅ Usar CLIP como encoder (robusto y semántico)
class CLIPImageEncoder(nn.Module):
    def __init__(self, model_name="openai/clip-vit-base-patch32"):
        super().__init__()
        self.clip = CLIPVisionModel.from_pretrained(model_name)
        # No es necesario proyectar - CLIP ya está en el espacio correcto
    
    def forward(self, x):
        return self.clip(x).last_hidden_state

El fix: Usa CLIP o un encoder multimodal pre-entrenado. CLIP captura información semántica rica que vale la pena preservar.

Error 3: Alpha Mal Tunneado

El problema: El factor de escala $\alpha$ controla cuánto influye la imagen. Si es muy alto, domina sobre el texto. Si es muy bajo, no tiene efecto.

📊 Resumen

  • IP-Adapter: Permite usar imágenes como prompts adicionales para modelos de difusión.
  • Arquitectura: Encoder de imagen (CLIP) + proyección + cross-attention desacoplada.
  • Beneficio clave: Separa el condicionamiento de texto e imagen para control independiente.
  • Aplicaciones: Transferencia de estilo, generación basada en referencia, control de composición.

Usa IP-Adapter cuando quieras condicionar la generación con una imagen de referencia. Usa alpha tuning para balancear texto vs imagen. Usa CLIP como encoder para mejores features semánticas.
