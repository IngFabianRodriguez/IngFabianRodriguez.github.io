Word Embeddings - Representando Palabras Como Vectores

Hagale pues, parcero. Llegamos al Dia 195 y hoy hablamos de word embeddings, la base de todo en NLP moderno. Si pensabas que las palabras eran solo texto, espera a ver como las convertimos en vectores. Cafe.

🎯 Que Son Los Word Embeddings?

Los word embeddings son representaciones vectoriales densas de palabras. Cada palabra se mapea a un vector de cientos de dimensiones donde palabras semanticamente similares estan cerca en el espacio vectorial.

Conceptos clave:

  • Dimensionalidad: Tipicamente 100-300 dimensiones
  • dense vs sparse: Vectores densos vs one-hot sparsos
  • Semantic similarity: Palabras similares tienen vectores similares

📐 La logica De Los Embeddings

import torch
import torch.nn as nn

# Embedding layer basico
embedding = nn.Embedding(vocab_size=10000, embedding_dim=300)

# Convertir indices a embeddings
word_indices = torch.tensor([0, 45, 123, 890])
word_vectors = embedding(word_indices)  # Shape: (4, 300)

🚀 Usando Pre-trained Embeddings

import gensim.downloader as api

# Cargar embeddings pre-entrenados
word2vec = api.load("glove-wiki-gigaword-100")

# Buscar palabras similares
similar = word2vec.most_similar("machine_learning", topn=5)
print(similar)

⚠️ Errores Comunes

Error 1: No Normalizar Los Vectores

El problema: Similitud coseno da valores inconsistentes.

La solucion: Normaliza los vectores antes de calcular similitud.
