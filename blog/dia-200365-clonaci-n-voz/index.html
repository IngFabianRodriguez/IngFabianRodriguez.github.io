Attention Is All You Need - El Paper Historico

Hagale pues, parcero. Hoy es el Dia 200 y hablamos del paper que cambio todo: Attention Is All You Need. Un dia historico para AI. Cafe.

🎯 El Paper Historico

"Attention Is All You Need" (Vaswani et al., 2017) introdujo los Transformers, reemplazando RNNs y CNNs para tareas de sequence-to-sequence.

Aportaciones clave:

  • Self-Attention: Relacionar posiciones dentro de una secuencia
  • Positional Encoding: Información de posicion sin recurrence
  • Parallelization: Entrenamiento paralelo completo

📐 Arquitectura Transformer

# Arquitectura basica del Transformer
class Transformer(nn.Module):
    def __init__(self, d_model, nhead, num_layers):
        super().__init__()
        self.encoder = EncoderLayer(d_model, nhead)
        self.decoder = DecoderLayer(d_model, nhead)
        
    def forward(self, src, tgt):
        enc_out = self.encoder(src)
        dec_out = self.decoder(tgt, enc_out)
        return dec_out

🚀 Componentes Principales

# Multi-Head Attention
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, nhead):
        super().__init__()
        self.h = nhead
        self.d_k = d_model // nhead
        self.q_linear = nn.Linear(d_model, d_model)
        self.k_linear = nn.Linear(d_model, d_model)
        self.v_linear = nn.Linear(d_model, d_model)
        self.out = nn.Linear(d_model, d_model)
