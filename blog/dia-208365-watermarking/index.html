🎯 Qué Es Whisper y Cómo Funciona?

Whisper es un modelo seq2seq basado en Transformer encoder-decoder entrenado con 680,000 horas de audio multilingual diverso. A diferencia de modelos anteriores que usaban phoneme vocabularies, Whisper predice texto directamente del espectrograma mel.

La arquitectura es un Transformer clásico:

# Encoder: toma espectrograma mel (80 bins, 30ms window)
# Decoder: GPT-style attention, genera texto token por token

# La innovación NO es la arquitectura — es la ESCALA de training
# 680K horas de audio en múltiples idiomas y dominios

Usa un enfoque multitask: además de transcripción, también predice idioma, y puede hacer traducción (English-to-Other). El objetivo es:

$$\mathcal{L} = -\log P(y | x)$$

Donde $y$ es la secuencia de texto target y $x$ es el audio input. Es un language modeling condicionado en audio.

📐 CTC (Connectionist Temporal Classification)

Whisper no usa CTC directamente — es un modelo seq2seq con cross-attention. Pero entender CTC es clave porque la mayoría de modelos ASR (Automatic Speech Recognition) anteriores lo usaban.

CTC resuelve un problema: no sabemos alineamiento entre frames de audio y caracteres/phonemes de salida. El audio tiene ~100 frames/segundo pero el texto tiene ~5 caracteres/segundo.

La Idea de CTC

CTC introduce un token especial blank (ε) que representa "no output aquí". La red produce una secuencia larga, y CTC collapsea repeticiones y blanks:

# Ejemplo: audio de "cat"
# Network output: [c, c, ε, ε, a, a, t, t, ε]
# CTC collapse:   [c, a, t]  ← elimina reps y blanks

# La función de pérdida CTC:
# L = -log P(y | x) donde y se calcula sobre todos los paths
# que colapsan a la transcription correcta

# Implementación simplificada:
def ctc_loss(log_probs, targets, input_lengths, target_lengths):
    """
    log_probs: (T, B, V) - T timesteps, B batch, V vocab
    targets: (B, T_trg) - sequences target
    """
    from torch.nn import CTCLoss
    criterion = CTCLoss(blank=0, zero_infinity=True)
    return criterion(log_probs, targets, input_lengths, target_lengths)

La forward algorithm computa la probabilidad de todos los paths que producen el target en tiempo $O(T \cdot T)$:

$$\alpha_t(s) = \text{probabilidad de estar en estado } s \text{ después de timestep } t$$

Se usa dynamic programming para no enumerar todos los $T^N$ paths posibles.

📊 Usando Whisper Para Transcripción

# Instalación
# pip install openai-whisper

import whisper
import torch

# Cargar modelo (hay tiny, base, small, medium, large)
model = whisper.load_model("base")

# Transcribir archivo de audio
result = model.transcribe("audio.mp3")
print(result["text"])

# Con opciones avanzadas
result = model.transcribe(
    "audio.mp3",
    language="es",           # Especificar idioma!
    task="transcribe",       # o "translate" para English
    beam_size=5,              # Beam search, mejor accuracy
    temperature=0,            # 0 = determinístico
    condition_on_previous_text=True,  # Usa contexto previo
)
print(result["segments"])  # Cada segmento con timestamps

Usando HuggingFace Transformers

from transformers import WhisperProcessor, WhisperForConditionalGeneration
from datasets import load_dataset

processor = WhisperProcessor.from_pretrained("openai/whisper-base")
model = WhisperForConditionalGeneration.from_pretrained("openai/whisper-base")

# Cargar audio de ejemplo
dataset = load_dataset("hf-internal-testing/librispeech_as4_dummy", "clean", split="validation")
sample = dataset[0]["audio"]
input_features = processor(sample["array"], sampling_rate=sample["sampling_rate"],
                            return_tensors="pt").input_features

# Generar
forced_decoder_ids = processor.get_decoder_prompt_ids(language="english", task="transcribe")
generated_ids = model.generate(input_features, forced_decoder_ids=forced_decoder_ids)

transcription = processor.batch_decode(generated_ids, skip_special_tokens=True)
print(transcription)

🚀 Fine-Tuning Whisper Para Dominio Específico

Whisper general funciona bien, pero para jerga técnica, acentos fuertes o vocabularios especializados (médico, legal, tecnología), el fine-tuning es casi obligatorio.

from datasets import load_dataset, Audio
from transformers import WhisperForConditionalGeneration, WhisperProcessor, Trainer, TrainingArguments

# Cargar dataset de tu dominio
dataset = load_dataset("path/a/tu/dataset_audio")
dataset = dataset.cast_column("audio", Audio(sampling_rate=16000))

processor = WhisperProcessor.from_pretrained("openai/whisper-base")
model = WhisperForConditionalGeneration.from_pretrained("openai/whisper-base")

def prepare_dataset(examples):
    audio = examples["audio"]
    examples["input_features"] = processor(audio["array"], sampling_rate=16000).input_features[0]
    examples["labels"] = processor(text=examples["text"]).input_ids
    return examples

dataset = dataset.map(prepare_dataset, remove_columns=dataset.column_names["train"])

# Fine-tuning con Trainer
training_args = TrainingArguments(
    output_dir="./whisper-finetuned",
    per_device_train_batch_size=8,
    learning_rate=1e-5,
    warmup_steps=500,
    max_steps=5000,
    gradient_accumulation_steps=2,
    fp16=True,
    evaluation_strategy="steps",
    save_steps=1000,
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=dataset["train"],
    eval_dataset=dataset.get("test"),
)
trainer.train()

⚠️ Errores Comunes y Cómo Evitarlos

Error 1: Whisper Sin Especificar Language — Mezcla de Idiomas

El problema: Sin especificar language, Whisper intenta detectar el idioma y puede mezclar idiomas en transcripciones de bilingual speakers (como muchos colombianos que mezclamos español e inglés).

La solución: SIEMPRE especifica el idioma:

# MAL: deja que detecte
result = model.transcribe("audio.mp3")  # Puede mezclaryo

# BIEN: especificar idioma
result = model.transcribe(
    "audio.mp3",
    language="es",  # Siempre especifica
    task="transcribe"
)

# Para bilingües: transcribe en dos pasos
result_es = model.transcribe("audio.mp3", language="es")
result_en = model.transcribe("audio.mp3", language="en")
# Luego selecciona el mejor o combina

Error 2: No Usar Beam Size > 1 — Baja Accuracy

El problema: Por default Whisper usa greedy decoding (temperature=0 con argmax). Esto es rápido pero pierde accuracy porque no considera múltiples hipótesis.

La solución: Usa beam search con beam_size > 1:

# Decoding: Greedy vs Beam Search
# Greedy: toma el token con mayor probabilidad en cada paso
# → rápido pero puede elegir mala palabra que afecta el resto

# Beam Search: mantiene N hipótesis y elige la mejor
result = model.transcribe(
    "audio.mp3",
    language="es",
    beam_size=5,        # Mantiene 5 hipótesis
    best_of=5,          # samplea N candidatos y elige el mejor
    temperature=0,       # 0 = no sampling, solo beam
)

El beam search mejora Word Error Rate (WER) significativamente, especialmente en audios largos donde errores tempranos se propagan.

Error 3: Whisper Para Dominio Técnico Sin Fine-Tuning Específico

El problema: Whisper general no conoce terminología técnica, jerga médica, legal, nombres propios, o acentos específicos. Transcribe "radiografía" como "radiografías" mal, o confunde "LSTM" con algo inventado.

La solución: Fine-tunea con data de tu dominio:

# 1. Recopila 1-10 horas de audio con transcription del dominio
# 2. Usa whispered-base o whisper-small para fine-tuning rápido
# 3. Si es poco data: usa LoRA para fine-tuning eficiente

from peft import LoraConfig, get_peft_model
from transformers import WhisperForConditionalGeneration

model = WhisperForConditionalGeneration.from_pretrained("openai/whisper-base")

# LoRA config - entrena solo 0.5% de parámetros
lora_config = LoraConfig(
    r=32,
    lora_alpha=64,
    target_modules=["q_proj", "v_proj", "k_proj", "out_proj"],
    lora_dropout=0.05,
)
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# trainable params: 1,534,464 || all params: 149,737,344 || trainable%: 1.025

Con solo 1-2 horas de data domain-specific y LoRA, puedes mejorar dramáticamente la transcription de tu jargon.

📝 Resumen y Cierre

Whisper revolucionó speech-to-text con escala masiva de training (680K horas) y arquitectura Transformer seq2seq. La CTC loss fue pioneers en resolver el alineamiento audio-texto, pero Whisper usa attention directo. Los 3 errores más graves: no especificar idioma (mezcla idiomas), no usar beam search (pierde accuracy), y usar Whisper vanilla para dominios técnicos sin fine-tuning.
