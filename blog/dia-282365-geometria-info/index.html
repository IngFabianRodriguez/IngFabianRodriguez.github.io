Intro: La Historia de Dos Desarrolladores

Son las 9 de la mañana en Medellin. Andres llega a su puesto de trabajo, se hace un cafecito y abre su laptop. Va a trabajar en el prompt del chatbot. Hace unos cambios, prueba, funciona bien. Hace otros cambios, prueba de nuevo.

2 semanas despues, el prompt en production es un desastre. Nadie sabe cual version esta desplegada, nadie sabe cual cambio hizo que el modelo empezara a dar respuestas raras, nadie tiene registro de los 47 intentos que se hicieron.

Ahora, Pedro. Llega a su puesto en la misma ciudad. Se hace el mismo cafecito. Abre su laptop y tiene esto:


$ git log --oneline prompts/
a3f2b1d Prompt v2.3 - Respuesta más concisa
8c4d9e2 Prompt v2.2 - Agregué contexto de usuario
1b7a3f5 Prompt v2.1 - Fix: límite de tokens
4e8c1d9 Prompt v2.0 - Refactor completo
...

Pedro sabe exactamente qué esta en production, qué cambio causo el problema de la semana pasada, y tiene tests automatizados que le dicen si el nuevo prompt pasa las pruebas antes de deployar.

Andres y Pedro tienen acceso a los mismos LLMs, la misma capacidad tecnica. La diferencia? Pedro tiene un workflow de desarrollo. Andres esta improvisando.

Hoy vamos a construir el workflow de Pedro.

La Matematica del Development Workflow

Antes de escribir codigo, formalicemos qué significa "iterar rapido" en desarrollo LLM.

1. El Ciclo de Iteracion

Cada iteracion de prompt sigue este ciclo:

I = {P_i, E_i, F_i, D_i}

Donde:

  • P_i: El prompt en la iteracion i
  • E_i: Evaluacion/resultado de la iteracion
  • F_i: Feedback/metricas de E_i
  • D_i: Decision (aceptar, rechazar, modificar P_i)

La velocidad de iteracion se define como:

v = 1 / T(I)

Donde T(I) es el tiempo total del ciclo. Un buen workflow minimiza T(I).

2. Experiment Tracking

Cada experimento debe registrar:

Experiment {
  id: UUID,
  timestamp: t,
  prompt_version: v,
  input: {...},
  output: {...},
  metrics: {
    latency_ms: Δt,
    token_count: n,
    quality_score: q,
    custom: {...}
  },
  parent_experiment: UUID | null,
  tags: [string]
}

Sin tracking, no hay aprendizaje. Sin aprendizaje, cada iteracion empieza de cero.

3. Versioning Semántico para Prompts

Usamos versionado semantico:

MAJOR.MINOR.PATCH

  • MAJOR: Cambios que alteran fundamentalmente el comportamiento
  • MINOR: Nuevas features sin romper backward compatibility
  • PATCH: Bug fixes menores

Ejemplo:

  • prompts/v1.0.0/ — Prompt inicial
  • prompts/v1.1.0/ — Agregué few-shot examples
  • prompts/v1.1.1/ — Fix en formatting del output
  • prompts/v2.0.0/ — Refactor completo del sistema prompt

1. Sistema de Versioning de Prompts con Git

"""
LLM Development Workflow - Prompt Versioning System
====================================================
Sistema completo para versionar, testear y deployar prompts
como codigo de verdad.
"""

from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional, Dict, Any, List
from enum import Enum
import json
import hashlib
import subprocess
from pathlib import Path


class PromptType(Enum):
    SYSTEM = "system"
    USER = "user"
    ASSISTANT = "assistant"


@dataclass
class PromptVersion:
    """Representa una version de un prompt"""
    version: str  # MAJOR.MINOR.PATCH
    content: str
    created_at: datetime
    author: str
    description: str
    type: PromptType
    tags: List[str] = field(default_factory=list)
    parent_version: Optional[str] = None

    def content_hash(self) -> str:
        """Hash unico del contenido para verificar cambios"""
        return hashlib.sha256(self.content.encode()).hexdigest()[:8]


@dataclass
class Experiment:
    """Un experimento individual"""
    id: str
    timestamp: datetime
    prompt_version: str
    input_data: Dict[str, Any]
    output: str
    metrics: Dict[str, float]
    quality_score: float
    tags: List[str]
    parent_id: Optional[str] = None

    def to_dict(self) -> Dict[str, Any]:
        return {
            "id": self.id,
            "timestamp": self.timestamp.isoformat(),
            "prompt_version": self.prompt_version,
            "input": self.input_data,
            "output": self.output,
            "metrics": self.metrics,
            "quality_score": self.quality_score,
            "tags": self.tags
        }


class PromptVersionControl:
    """
    Sistema de control de versiones para prompts.
    Usa Git internamente para tracking de cambios.
    """

    def __init__(self, repo_path: str, prompts_dir: str = "prompts"):
        self.repo_path = Path(repo_path)
        self.prompts_dir = self.repo_path / prompts_dir
        self.experiments_file = self.repo_path / "experiments.jsonl"

        self.prompts_dir.mkdir(parents=True, exist_ok=True)

    def _run_git(self, args: List[str]) -> str:
        """Ejecuta un comando git"""
        result = subprocess.run(
            ["git"] + args,
            cwd=self.repo_path,
            capture_output=True,
            text=True
        )
        if result.returncode != 0:
            raise RuntimeError(f"Git error: {result.stderr}")
        return result.stdout.strip()

    def create_version(
        self,
        content: str,
        version: str,
        author: str,
        description: str,
        prompt_type: PromptType = PromptType.SYSTEM,
        tags: List[str] = None
    ) -> PromptVersion:
        """Crea una nueva version del prompt"""

        # Determinar parent version
        parent = self._get_latest_version(prompt_type)
        parent_version = parent.version if parent else None

        pv = PromptVersion(
            version=version,
            content=content,
            created_at=datetime.now(),
            author=author,
            description=description,
            type=prompt_type,
            tags=tags or [],
            parent_version=parent_version
        )

        # Guardar archivo
        version_path = self._get_version_path(prompt_type, version)
        version_path.parent.mkdir(parents=True, exist_ok=True)
        version_path.write_text(content)

        # Metadata JSON
        meta_path = version_path.with_suffix('.meta.json')
        with open(meta_path, 'w') as f:
            json.dump({
                "version": version,
                "created_at": pv.created_at.isoformat(),
                "author": author,
                "description": description,
                "content_hash": pv.content_hash(),
                "parent_version": parent_version,
                "tags": tags or []
            }, f, indent=2)

        # Git commit
        self._run_git(["add", str(version_path), str(meta_path)])
        self._run_git([
            "commit", "-m",
            f"prompt({prompt_type.value}): v{version} - {description}"
        ])

        return pv

    def _get_version_path(self, prompt_type: PromptType, version: str) -> Path:
        """Obtiene el path a una version especifica"""
        return self.prompts_dir / prompt_type.value / f"v{version}.txt"

    def _get_latest_version(self, prompt_type: PromptType) -> Optional[PromptVersion]:
        """Obtiene la ultima version de un tipo de prompt"""
        type_dir = self.prompts_dir / prompt_type.value

        if not type_dir.exists():
            return None

        versions = []
        for f in type_dir.glob("v*.txt"):
            version_str = f.stem[1:]  # Remove 'v' prefix
            versions.append(version_str)

        if not versions:
            return None

        # Parse and sort
        def parse_version(v):
            parts = v.split('.')
            return tuple(int(x) for x in parts)

        latest = sorted(versions, key=parse_version)[-1]

        content = (type_dir / f"v{latest}.txt").read_text()
        meta = json.loads((type_dir / f"v{latest}.meta.json").read_text())

        return PromptVersion(
            version=latest,
            content=content,
            created_at=datetime.fromisoformat(meta["created_at"]),
            author=meta["author"],
            description=meta["description"],
            type=prompt_type,
            tags=meta["tags"],
            parent_version=meta.get("parent_version")
        )

    def get_version(self, prompt_type: PromptType, version: str) -> PromptVersion:
        """Obtiene una version especifica"""
        path = self._get_version_path(prompt_type, version)
        meta_path = path.with_suffix('.meta.json')

        content = path.read_text()
        meta = json.loads(meta_path.read_text())

        return PromptVersion(
            version=version,
            content=content,
            created_at=datetime.fromisoformat(meta["created_at"]),
            author=meta["author"],
            description=meta["description"],
            type=prompt_type,
            tags=meta["tags"],
            parent_version=meta.get("parent_version")
        )

    def list_versions(self, prompt_type: PromptType) -> List[PromptVersion]:
        """Lista todas las versiones de un tipo de prompt"""
        type_dir = self.prompts_dir / prompt_type.value

        if not type_dir.exists():
            return []

        versions = []
        for f in type_dir.glob("v*.txt"):
            version_str = f.stem[1:]
            versions.append(self.get_version(prompt_type, version_str))

        def parse_version(v):
            parts = v.version.split('.')
            return tuple(int(x) for x in parts)

        return sorted(versions, key=parse_version)

    def diff_versions(
        self,
        prompt_type: PromptType,
        version_a: str,
        version_b: str
    ) -> str:
        """Muestra el diff entre dos versiones"""
        path_a = self._get_version_path(prompt_type, version_a)
        path_b = self._get_version_path(prompt_type, version_b)

        result = subprocess.run(
            ["git", "diff", str(path_a), str(path_b)],
            cwd=self.repo_path,
            capture_output=True,
            text=True
        )

        return result.stdout or "No differences found"

    def rollback(self, prompt_type: PromptType, version: str) -> PromptVersion:
        """Hace rollback a una version anterior"""
        self._run_git(["checkout", f"--", str(self._get_version_path(prompt_type, version))])
        self._run_git([
            "commit", "-m",
            f"prompt({prompt_type.value}): rollback to v{version}"
        ])

        return self.get_version(prompt_type, version)


# Uso
pvc = PromptVersionControl(
    repo_path="/path/to/my-llm-project",
    prompts_dir="prompts"
)

# Crear version inicial
pvc.create_version(
    content="Eres un asistente de IA helpful y conciso.",
    version="1.0.0",
    author="fabian",
    description="Prompt inicial",
    prompt_type=PromptType.SYSTEM,
    tags=["initial", "v1"]
)

# Hacer cambios y crear nueva version
pvc.create_version(
    content="""Eres un asistente de IA helpful y conciso.
Siempre responde en español latino.
Si no sabes algo, admitelo claramente.""",
    version="1.1.0",
    author="fabian",
    description="Agregué instrucciones de idioma",
    prompt_type=PromptType.SYSTEM,
    tags=["localization"]
)

# Ver historial
versions = pvc.list_versions(PromptType.SYSTEM)
for v in versions:
    print(f"v{v.version} - {v.description} ({v.author})")

# Ver diff entre versiones

print(diff)

2. Sistema de Experiment Tracking

"""
Experiment Tracker - Seguimiento de Experimentos LLM
======================================================
Sistema para registrar, buscar y comparar experimentos.
"""

from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional, Dict, Any, List, Callable
from enum import Enum
import json
import uuid
from pathlib import Path
from dataclasses import asdict


class ExperimentStatus(Enum):
    RUNNING = "running"
    COMPLETED = "completed"
    FAILED = "failed"
    CANCELLED = "cancelled"


@dataclass
class Experiment:
    id: str
    name: str
    prompt_version: str
    created_at: datetime
    updated_at: datetime
    status: ExperimentStatus
    input_data: Dict[str, Any]
    output: Optional[str]
    expected_output: Optional[str]
    metrics: Dict[str, float]
    quality_score: Optional[float]
    tags: List[str]
    notes: str
    parent_id: Optional[str]
    metadata: Dict[str, Any]

    def to_dict(self) -> Dict[str, Any]:
        return {
            "id": self.id,
            "name": self.name,
            "prompt_version": self.prompt_version,
            "created_at": self.created_at.isoformat(),
            "updated_at": self.updated_at.isoformat(),
            "status": self.status.value,
            "input_data": self.input_data,
            "output": self.output,
            "expected_output": self.expected_output,
            "metrics": self.metrics,
            "quality_score": self.quality_score,
            "tags": self.tags,
            "notes": self.notes,
            "parent_id": self.parent_id,
            "metadata": self.metadata
        }


class ExperimentTracker:
    """
    Tracker de experimentos con persistencia en JSONL.
    Cada experimento se guarda en una linea para easy appending.
    """

    def __init__(self, experiments_dir: str = "./experiments"):
        self.experiments_dir = Path(experiments_dir)
        self.experiments_dir.mkdir(parents=True, exist_ok=True)
        self.index_file = self.experiments_dir / "index.json"

        # Load or create index
        if self.index_file.exists():
            with open(self.index_file) as f:
                self.experiments: Dict[str, Experiment] = {}
                data = json.load(f)
                for exp_data in data.values():
                    exp_data["created_at"] = datetime.fromisoformat(exp_data["created_at"])
                    exp_data["updated_at"] = datetime.fromisoformat(exp_data["updated_at"])
                    exp_data["status"] = ExperimentStatus(exp_data["status"])
                    self.experiments[exp_data["id"]] = Experiment(**exp_data)
        else:
            self.experiments = {}

    def _save_index(self):
        """Guarda el indice de experimentos"""
        data = {
            k: {
                **asdict(v),
                "created_at": v.created_at.isoformat(),
                "updated_at": v.updated_at.isoformat(),
                "status": v.status.value
            }
            for k, v in self.experiments.items()
        }

        with open(self.index_file, 'w') as f:
            json.dump(data, f, indent=2)

    def create_experiment(
        self,
        name: str,
        prompt_version: str,
        input_data: Dict[str, Any],
        expected_output: Optional[str] = None,
        tags: List[str] = None,
        parent_id: Optional[str] = None,
        metadata: Dict[str, Any] = None
    ) -> Experiment:
        """Crea un nuevo experimento"""
        exp_id = str(uuid.uuid4())[:8]

        exp = Experiment(
            id=exp_id,
            name=name,
            prompt_version=prompt_version,
            created_at=datetime.now(),
            updated_at=datetime.now(),
            status=ExperimentStatus.RUNNING,
            input_data=input_data,
            output=None,
            expected_output=expected_output,
            metrics={},
            quality_score=None,
            tags=tags or [],
            notes="",
            parent_id=parent_id,
            metadata=metadata or {}
        )

        self.experiments[exp_id] = exp
        self._save_index()

        return exp

    def complete_experiment(
        self,
        exp_id: str,
        output: str,
        metrics: Dict[str, float],
        quality_score: Optional[float] = None
    ):
        """Marca experimento como completado con resultados"""
        exp = self.experiments.get(exp_id)
        if not exp:
            raise ValueError(f"Experiment {exp_id} not found")

        exp.output = output
        exp.metrics = metrics
        exp.quality_score = quality_score
        exp.status = ExperimentStatus.COMPLETED
        exp.updated_at = datetime.now()

        self._save_index()

    def fail_experiment(self, exp_id: str, error: str):
        """Marca experimento como fallido"""
        exp = self.experiments.get(exp_id)
        if not exp:
            raise ValueError(f"Experiment {exp_id} not found")

        exp.status = ExperimentStatus.FAILED
        exp.metadata["error"] = error
        exp.updated_at = datetime.now()

        self._save_index()

    def get_experiment(self, exp_id: str) -> Optional[Experiment]:
        return self.experiments.get(exp_id)

    def search_experiments(
        self,
        prompt_version: Optional[str] = None,
        tags: Optional[List[str]] = None,
        min_quality_score: Optional[float] = None,
        status: Optional[ExperimentStatus] = None,
        limit: int = 100
    ) -> List[Experiment]:
        """Busca experimentos con filtros"""
        results = []

        for exp in self.experiments.values():
            # Filter by version
            if prompt_version and exp.prompt_version != prompt_version:
                continue

            # Filter by tags
            if tags and not any(t in exp.tags for t in tags):
                continue

            # Filter by quality
            if min_quality_score and \
               (exp.quality_score is None or exp.quality_score < min_quality_score):
                continue

            # Filter by status
            if status and exp.status != status:
                continue

            results.append(exp)

        # Sort by created_at desc
        results.sort(key=lambda x: x.created_at, reverse=True)

        return results[:limit]

    def compare_experiments(
        self,
        exp_ids: List[str]
    ) -> Dict[str, Any]:
        """Compara multiples experimentos lado a lado"""
        exps = [self.experiments[eid] for eid in exp_ids if eid in self.experiments]

        if len(exps) < 2:
            raise ValueError("Need at least 2 experiments to compare")

        # Build comparison table
        comparison = {
            "experiments": [e.id for e in exps],
            "versions": [e.prompt_version for e in exps],
            "metrics": {},
            "quality_scores": {}
        }

        # Aggregate metrics
        all_metric_keys = set()
        for exp in exps:
            all_metric_keys.update(exp.metrics.keys())

        for key in all_metric_keys:
            comparison["metrics"][key] = [exp.metrics.get(key) for exp in exps]

        comparison["quality_scores"] = {
            exp.id: exp.quality_score for exp in exps
        }

        return comparison

    def get_best_experiment(
        self,
        prompt_version: Optional[str] = None,
        tags: Optional[List[str]] = None
    ) -> Optional[Experiment]:
        """Obtiene el mejor experimento segun quality score"""
        exps = self.search_experiments(
            prompt_version=prompt_version,
            tags=tags,
            status=ExperimentStatus.COMPLETED
        )

        if not exps:
            return None

        return max(exps, key=lambda x: x.quality_score or 0)

    def generate_report(self, prompt_version: str) -> Dict[str, Any]:
        """Genera un reporte de experimentos para una version"""
        exps = self.search_experiments(
            prompt_version=prompt_version,
            status=ExperimentStatus.COMPLETED
        )

        if not exps:
            return {"error": "No experiments found"}

        quality_scores = [e.quality_score for e in exps if e.quality_score]

        return {
            "prompt_version": prompt_version,
            "total_experiments": len(exps),
            "avg_quality_score": sum(quality_scores) / len(quality_scores) if quality_scores else None,
            "best_experiment": self.get_best_experiment(prompt_version=prompt_version).id,
            "metric_summary": self._summarize_metrics(exps)
        }

    def _summarize_metrics(self, exps: List[Experiment]) -> Dict[str, Dict[str, float]]:
        """Calcula summary de metricas"""
        all_metrics = {}

        for exp in exps:
            for key, value in exp.metrics.items():
                if key not in all_metrics:
                    all_metrics[key] = []
                all_metrics[key].append(value)

        summary = {}
        for key, values in all_metrics.items():
            summary[key] = {
                "avg": sum(values) / len(values),
                "min": min(values),
                "max": max(values)
            }

        return summary


# Uso

# Crear experimento

    prompt_version="1.1.0",
    input_data={"query": "Explícame qué es la fotosíntesis"},
    expected_output="La fotosíntesis es el proceso por el cual...",
    tags=["concise", "v1.1.0"],
    parent_id=None
)

# ... ejecutar experimento con LLM ...

# Completar con resultados

    exp_id=exp.id,
    output="La fotosíntesis es el proceso...",
    metrics={
        "latency_ms": 1234.5,
        "token_count": 256,
        "relevance_score": 0.92
    },
    quality_score=0.85
)

# Buscar mejores experimentos

print(f"Best experiment: {best.id} with score {best.quality_score}")

# Comparar versiones

report_v2 = tracker.generate_report("1.1.0")

3. CI/CD para Prompts - Automated Testing Pipeline

"""
CI/CD Pipeline para Prompts
============================
Sistema de testing automatizado para prompts en CI/CD.
"""

from dataclasses import dataclass
from typing import List, Dict, Any, Optional, Callable
from datetime import datetime
import json
from enum import Enum


class TestStatus(Enum):
    PASSED = "passed"
    FAILED = "failed"
    SKIPPED = "skipped"


@dataclass
class TestCase:
    name: str
    input_data: Dict[str, Any]
    expected_output: Optional[str] = None
    expected_contains: Optional[List[str]] = None
    expected_not_contains: Optional[List[str]] = None
    max_latency_ms: Optional[float] = None
    min_quality_score: Optional[float] = None
    tags: List[str] = None

    def __post_init__(self):
        self.tags = self.tags or []


@dataclass
class TestResult:
    test_name: str
    status: TestStatus
    execution_time_ms: float
    output: Optional[str]
    error: Optional[str]
    metrics: Dict[str, float]
    timestamp: datetime

    def passed(self) -> bool:
        return self.status == TestStatus.PASSED


class PromptTestRunner:
    """
    Runner de tests para prompts.
    Diseñado para correr en CI/CD o localmente.
    """

    def __init__(self, llm_caller: Callable):
        """
        llm_caller: funcion que recibe (prompt, input_data) y retorna
                   (output, metrics_dict)
        """
        self.llm_caller = llm_caller
        self.results: List[TestResult] = []

    def run_test(self, test_case: TestCase) -> TestResult:
        """Ejecuta un test case individual"""
        start = datetime.now()

        try:
            # Llamar al LLM
            output, metrics = self.llm_caller(
                prompt=test_case.input_data.get("prompt", ""),
                context=test_case.input_data
            )

            execution_time = (datetime.now() - start).total_seconds() * 1000

            # Validar resultado
            error = None

            if test_case.expected_output and output != test_case.expected_output:
                error = f"Output mismatch: expected '{test_case.expected_output}', got '{output}'"

            if test_case.expected_contains:
                for expected in test_case.expected_contains:
                    if expected.lower() not in output.lower():
                        error = f"Missing expected content: '{expected}'"
                        break

            if test_case.expected_not_contains:
                for forbidden in test_case.expected_not_contains:
                    if forbidden.lower() in output.lower():
                        error = f"Forbidden content found: '{forbidden}'"
                        break

            if test_case.max_latency_ms and execution_time > test_case.max_latency_ms:
                error = f"Latency too high: {execution_time:.2f}ms > {test_case.max_latency_ms}ms"

            if error:
                status = TestStatus.FAILED
            else:
                status = TestStatus.PASSED

            return TestResult(
                test_name=test_case.name,
                status=status,
                execution_time_ms=execution_time,
                output=output,
                error=error,
                metrics=metrics,
                timestamp=datetime.now()
            )

        except Exception as e:
            execution_time = (datetime.now() - start).total_seconds() * 1000
            return TestResult(
                test_name=test_case.name,
                status=TestStatus.FAILED,
                execution_time_ms=execution_time,
                output=None,
                error=str(e),
                metrics={},
                timestamp=datetime.now()
            )

    def run_suite(self, test_cases: List[TestCase]) -> Dict[str, Any]:
        """Ejecuta una suite completa de tests"""
        self.results = []

        for tc in test_cases:
            result = self.run_test(tc)
            self.results.append(result)

        # Generar summary
        passed = sum(1 for r in self.results if r.passed())
        failed = len(self.results) - passed

        return {
            "summary": {
                "total": len(self.results),
                "passed": passed,
                "failed": failed,
                "pass_rate": passed / len(self.results) if self.results else 0,
                "total_time_ms": sum(r.execution_time_ms for r in self.results)
            },
            "results": [
                {
                    "name": r.test_name,
                    "status": r.status.value,
                    "execution_time_ms": r.execution_time_ms,
                    "error": r.error
                }
                for r in self.results
            ]
        }

    def assert_all_passed(self, results: Dict[str, Any]):
        """Assertion helper para CI/CD"""
        if results["summary"]["failed"] > 0:
            failed_tests = [r["name"] for r in results["results"] if r["status"] == "failed"]
            raise AssertionError(
                f"Tests failed: {failed_tests}. "
                f"Pass rate: {results['summary']['pass_rate']:.1%}"
            )

El deploy se hace copiando y pegando entre archivos. No hay historial. No hay rollback. Si algo sale mal, a reescribir desde cero.
