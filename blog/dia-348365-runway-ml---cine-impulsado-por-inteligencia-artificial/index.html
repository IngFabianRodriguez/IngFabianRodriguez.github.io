📐 Matematica de Agentic Systems

Los LLMs como agentes son fundamentalmente un problema de decision secuencial. Podemos modelarlo como un proceso de Markov parcialmente observable (POMDP):

$$P(a_t | s_{t-1}, o_t) = \text{LLM}(a_t | \text{state}, \text{observation}, \text{action history})$$

Donde:

  • s_{t-1}: Estado anterior del sistema
  • o_t: Observacion actual (feedback del ambiente)
  • a_t: Accion tomada por el agente

La recompensa acumulada sigue la formulacion de RL:

$$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$$

Donde γ ∈ (0,1) es el factor de descuento y r es la recompensa inmediata. En agentes de LLM, la "recompensa" es implícita y modelada a traves del feedback del ambiente o evaluaciones del propio LLM.

🤖 Frameworks para Patrones Emergentes

El campo esta evolucionando hacia sistemas donde los LLMs no solo responden, sino que actuan, planifican, y usan herramientas. Aqui va un framework completo para implementar agentes LLM:

"""
Emerging LLM Patterns Framework
Frameworks para implementar patrones emergentes: Agents, Tool Use, Multi-Modal
"""

from dataclasses import dataclass, field
from typing import List, Dict, Callable, Optional, Any
from enum import Enum
import time
import json


class AgentState(Enum):
    """Estados de un agente LLM"""
    IDLE = "idle"
    THINKING = "thinking"
    ACTING = "acting"
    WAITING = "waiting"  # Esperando respuesta de tool
    DONE = "done"
    ERROR = "error"


class ToolResult:
    """Resultado de una llamada a herramienta"""
    def __init__(self, success: bool, data: Any, error: Optional[str] = None):
        self.success = success
        self.data = data
        self.error = error
        self.timestamp = time.time()


@dataclass
class Tool:
    """
    Definicion de una herramienta que el agente puede usar.
    
    Las herramientas son funciones con:
    - name: identificador unico
    - description: que hace (el LLM usa esto para decidir)
    - parameters: schema de entrada
    - function: implementacion real
    """
    name: str
    description: str
    parameters: Dict[str, Any]
    function: Callable
    
    def __post_init__(self):
        # Validar que la funcion tenga el docstring
        if not self.function.__doc__:
            print(f"Warning: Tool {self.name} lacks documentation")
    
    def execute(self, **kwargs) -> ToolResult:
        """Ejecuta la herramienta con los parametros dados"""
        try:
            result = self.function(**kwargs)
            return ToolResult(success=True, data=result)
        except Exception as e:
            return ToolResult(success=False, data=None, error=str(e))
    
    def get_schema(self) -> Dict[str, Any]:
        """Retorna el schema de la herramienta para el LLM"""
        return {
            "name": self.name,
            "description": self.description,
            "parameters": self.parameters
        }


@dataclass
class AgentMessage:
    """Mensaje en el historial del agente"""
    role: str  # 'user', 'assistant', 'system', 'tool'
    content: str
    tool_call: Optional[Dict] = None
    tool_result: Optional[Any] = None
    timestamp: float = field(default_factory=time.time)


class LLMAgent:
    """
    Framework base para agentes LLM con tool use y planning.
    
    Patron de operacion:
    1. Recieve task
    2. Planificar pasos (usando LLM como planner)
    3. Seleccionar tool apropiado
    4. Ejecutar tool
    5. Feed result back al LLM
    6. Repetir hasta completar tarea
    
    La clave esta en el loop:
        while not done:
            action = select_action(state)
            result = execute(action)
            state = update(state, result)
    """
    
    def __init__(
        self,
        name: str,
        system_prompt: str,
        llm_call: Callable[[str], str],
        tools: Optional[List[Tool]] = None,
        max_iterations: int = 10,
        verbose: bool = True
    ):
        self.name = name
        self.system_prompt = system_prompt
        self.llm_call = llm_call
        self.tools = tools or []
        self.max_iterations = max_iterations
        self.verbose = verbose
        
        # Estado del agente
        self.state = AgentState.IDLE
        self.history: List[AgentMessage] = []
        self.context: Dict[str, Any] = {}  # Memoria de corto plazo
        self.iteration = 0
        
        # Registro de tools para el LLM
        self.tool_registry = {t.name: t for t in self.tools}
    
    def _build_system_prompt(self) -> str:
        """Construye el prompt de sistema con contexto de tools"""
        prompt = self.system_prompt + "\n\n"
        
        if self.tools:
            prompt += "You have access to the following tools:\n\n"
            for tool in self.tools:
                prompt += f"## {tool.name}\n"
                prompt += f"{tool.description}\n"
                prompt += f"Parameters: {json.dumps(tool.parameters, indent=2)}\n\n"
        
        prompt += "When you decide to use a tool, respond with:\n"
        prompt += '{"tool": "tool_name", "parameters": {"param1": "value1"}}\n'
        prompt += "When you have completed the task, respond with:\n"
        prompt += '{"done": true, "summary": "what you accomplished"}'
        
        return prompt
    
    def _get_tool_schema_for_llm(self) -> str:
        """Genera el schema de tools para pasar al LLM"""
        if not self.tools:
            return "No tools available."
        
        schema_lines = ["Available tools:"]
        for tool in self.tools:
            schema_lines.append(f"- {tool.name}: {tool.description}")
            if tool.parameters.get("properties"):
                props = tool.parameters["properties"]
                schema_lines.append(f"  Parameters: {', '.join(props.keys())}")
        
        return "\n".join(schema_lines)
    
    def add_tool(self, tool: Tool) -> None:
        """Agrega una nueva herramienta al agente"""
        self.tools.append(tool)
        self.tool_registry[tool.name] = tool
    
    def think(self, user_message: str) -> Dict[str, Any]:
        """
        Ejecuta un ciclo de pensamiento del agente.
        
        Returns:
            Dict con 'response', 'tool_used', 'tool_result', 'done'
        """
        self.iteration += 1
        self.state = AgentState.THINKING
        
        if self.verbose:
            print(f"\n[Iteration {self.iteration}] Agent thinking...")
        
        # Construir contexto completo para el LLM
        messages = [AgentMessage(
            role="system",
            content=self._build_system_prompt()
        )]
        
        # Agregar historial previo
        for msg in self.history[-10:]:  # Ultimos 10 mensajes
            messages.append(msg)
        
        # Agregar mensaje actual
        messages.append(AgentMessage(role="user", content=user_message))
        
        # Llamar al LLM
        llm_input = "\n".join([
            f"{m.role}: {m.content}" for m in messages
        ])
        
        llm_response = self.llm_call(llm_input)
        
        # Parsear respuesta del LLM
        try:
            # Intentar parsear como JSON
            parsed = json.loads(llm_response)
            
            if "done" in parsed:
                self.state = AgentState.DONE
                return {
                    "response": parsed.get("summary", "Task completed"),
                    "tool_used": None,
                    "tool_result": None,
                    "done": True
                }
            
            if "tool" in parsed:
                tool_name = parsed["tool"]
                parameters = parsed.get("parameters", {})
                
                return self._execute_tool(tool_name, parameters)
            
        except json.JSONDecodeError:
            # El LLM devolvio texto plano
            pass
        
        # Respuesta directa del LLM
        self.state = AgentState.DONE
        return {
            "response": llm_response,
            "tool_used": None,
            "tool_result": None,
            "done": True
        }
    
    def _execute_tool(self, tool_name: str, parameters: Dict) -> Dict[str, Any]:
        """Ejecuta una herramienta y retorna el resultado"""
        self.state = AgentState.ACTING
        
        if tool_name not in self.tool_registry:
            return {
                "response": f"Error: Unknown tool '{tool_name}'",
                "tool_used": tool_name,
                "tool_result": None,
                "done": False
            }
        
        tool = self.tool_registry[tool_name]
        
        if self.verbose:
            print(f"[{self.name}] Executing tool: {tool_name}")
            print(f"Parameters: {parameters}")
        
        # Ejecutar la herramienta
        result = tool.execute(**parameters)
        
        # Registrar en historial
        self.history.append(AgentMessage(
            role="assistant",
            content=f"Tool call: {tool_name}",
            tool_call={"name": tool_name, "parameters": parameters}
        ))
        
        self.history.append(AgentMessage(
            role="tool",
            content=str(result.data) if result.success else result.error,
            tool_result=result
        ))
        
        if result.success:
            self.state = AgentState.IDLE
            return {
                "response": f"Tool {tool_name} executed successfully: {result.data}",
                "tool_used": tool_name,
                "tool_result": result.data,
                "done": False
            }
        else:
            self.state = AgentState.ERROR
            return {
                "response": f"Tool {tool_name} failed: {result.error}",
                "tool_used": tool_name,
                "tool_result": None,
                "done": False
            }
    
    def run(self, task: str) -> str:
        """
        Ejecuta una tarea completa con el agente.
        
        Loop principal:
        while not done and iteration < max_iterations:
            result = think(task)
            if result["done"]:
                return result["response"]
            task = f"Previous result: {result['response']}\nContinue with: {task}"
        """
        self.iteration = 0
        self.history.clear()
        
        current_task = task
        max_loops = self.max_iterations
        
        while self.iteration < max_loops:
            result = self.think(current_task)
            
            if result["done"]:
                if self.verbose:
                    print(f"\n[{self.name}] Task completed in {self.iteration} iterations")
                return result["response"]
            
            # Preparar siguiente iteracion con contexto del resultado previo
            current_task = f"Previous result: {result['response']}\n\nContinue with the original task: {task}"
        
        return f"Max iterations ({max_loops}) reached. Last result: {result['response']}"
    
    def reset(self) -> None:
        """Resetea el estado del agente"""
        self.state = AgentState.IDLE
        self.history.clear()
        self.context.clear()
        self.iteration = 0


class MultiAgentOrchestrator:
    """
    Orchestrator para sistemas multi-agente.
    
    Patron de arquitectura:
    - Un orchestrator coordina multiples agentes especializados
    - Cada agente tiene un rol y herramientas especificas
    - El orchestrator decide que agente maneja cada subtarea
    
    Matematica de asignacion:
        agent_score = Σ(w_i * capability_i) para cada subtask
        Seleccionar agent = argmax(agent_score)
    
    Donde w_i son los pesos de importancia de cada capability.
    """
    
    def __init__(self, orchestrator_llm: Callable[[str], str]):
        self.agents: Dict[str, LLMAgent] = {}
        self.orchestrator_llm = orchestrator_llm
        self.execution_trace: List[Dict] = []
    
    def register_agent(self, agent: LLMAgent, role: str) -> None:
        """Registra un agente con un rol especifico"""
        self.agents[role] = agent
        print(f"Registered agent '{agent.name}' with role '{role}'")
    
    def decompose_task(self, task: str) -> List[Dict[str, str]]:
        """
        Descompone una tarea en subtareas usando el LLM como planner.
        
        Returns:
            List of {"subtask": str, "assigned_role": str, "reasoning": str}
        """
        agent_roles = "\n".join([
            f"- {role}: {agent.name} ({len(agent.tools)} tools)"
            for role, agent in self.agents.items()
        ])
        
        planning_prompt = f"""Task: {task}

Available agents and their roles:
{agent_roles}

Decompose this task into subtasks and assign each to the most appropriate agent.
Consider:
- Which agent has the right tools for each subtask?
- What is the logical order of execution?
- Are there dependencies between subtasks?

Respond with a JSON array of subtasks:
[
  {{"subtask": "...", "assigned_role": "...", "reasoning": "..."}},
  ...
]"""
        
        response = self.orchestrator_llm(planning_prompt)
        
        try:
            subtasks = json.loads(response)
            return subtasks
        except json.JSONDecodeError:
            print(f"Failed to parse task decomposition: {response}")
            return [{"subtask": task, "assigned_role": list(self.agents.keys())[0], "reasoning": "Default"}]
    
    def execute_plan(self, subtasks: List[Dict]) -> List[Dict[str, Any]]:
        """
        Ejecuta un plan de subtareas con los agentes apropiados.
        
        Returns:
            List of {"subtask": str, "result": str, "agent": str, "success": bool}
        """
        results = []
        
        for i, subtask_info in enumerate(subtasks):
            subtask = subtask_info["subtask"]
            role = subtask_info["assigned_role"]
            
            print(f"\n[Step {i+1}] Executing: {subtask[:50]}... (role: {role})")
            
            if role not in self.agents:
                print(f"Warning: No agent with role '{role}', skipping")
                results.append({
                    "subtask": subtask,
                    "result": f"No agent available for role: {role}",
                    "agent": None,
                    "success": False
                })
                continue
            
            agent = self.agents[role]
            result = agent.run(subtask)
            
            results.append({
                "subtask": subtask,
                "result": result,
                "agent": role,
                "success": agent.state != AgentState.ERROR
            })
            
            self.execution_trace.append({
                "step": i,
                "subtask": subtask,
                "role": role,
                "agent_name": agent.name,
                "success": agent.state != AgentState.ERROR
            })
        
        return results
    
    def run(self, task: str) -> Dict[str, Any]:
        """
        Ejecuta una tarea completa: decompose -> assign -> execute.
        
        Returns:
            Dict con 'plan', 'results', 'final_output', 'success'
        """
        print(f"\n{'='*60}")
        print(f"Multi-Agent Orchestrator starting task")
        print(f"Task: {task[:100]}...")
        print(f"{'='*60}")
        
        # Step 1: Decompose
        subtasks = self.decompose_task(task)
        print(f"\nDecomposed into {len(subtasks)} subtasks")
        
        # Step 2: Execute
        results = self.execute_plan(subtasks)
        
        # Step 3: Synthesize
        success = all(r["success"] for r in results)
        synthesis_prompt = f"""Task: {task}

Results from subtasks:
{json.dumps(results, indent=2)}

Synthesize these results into a coherent final output."""
        
        final_output = self.orchestrator_llm(synthesis_prompt)
        
        return {
            "task": task,
            "plan": subtasks,
            "results": results,
            "final_output": final_output,
            "success": success
        }


# Ejemplo de uso con herramientas reales
def create_research_agent(llm_call: Callable) -> LLMAgent:
    """Crea un agente especializado en busqueda y investigacion"""
    
    # Definir herramientas
    search_tool = Tool(
        name="web_search",
        description="Search the web for information about a topic",
        parameters={
            "type": "object",
            "properties": {
                "query": {"type": "string", "description": "Search query"},
                "max_results": {"type": "integer", "description": "Max results to return", "default": 5}
            },
            "required": ["query"]
        },
        function=lambda query, max_results=5: f"Search results for '{query}': Found {max_results} articles"
    )
    
    read_tool = Tool(
        name="read_url",
        description="Read content from a specific URL",
        parameters={
            "type": "object",
            "properties": {
                "url": {"type": "string", "description": "URL to read"},
                "max_words": {"type": "integer", "description": "Max words to extract", "default": 500}
            },
            "required": ["url"]
        },
        function=lambda url, max_words=500: f"Content from {url}: [First {max_words} words extracted]"
    )
    
    write_tool = Tool(
        name="write_note",
        description="Write a note or summary to memory",
        parameters={
            "type": "object",
            "properties": {
                "content": {"type": "string", "description": "Content to save"},
                "title": {"type": "string", "description": "Title for the note"}
            },
            "required": ["content"]
        },
        function=lambda content, title="Untitled": f"Saved note: {title}"
    )
    
    system_prompt = """You are a Research Agent. Your job is to:
1. Search for relevant information
2. Read and analyze sources
3. Synthesize findings into coherent summaries

Be thorough but focused. Use tools when needed."""
    
    return LLMAgent(
        name="ResearchAgent",
        system_prompt=system_prompt,
        llm_call=llm_call,
        tools=[search_tool, read_tool, write_tool],
        verbose=True
    )


def create_coder_agent(llm_call: Callable) -> LLMAgent:
    """Crea un agente especializado en programacion"""
    
    execute_tool = Tool(
        name="execute_code",
        description="Execute Python code and return the result",
        parameters={
            "type": "object",
            "properties": {
                "code": {"type": "string", "description": "Python code to execute"},
                "language": {"type": "string", "description": "Programming language", "default": "python"}
            },
            "required": ["code"]
        },
        function=lambda code, language="python": f"Executed {language} code. Output: [simulated]"
    )
    
    review_tool = Tool(
        name="review_code",
        description="Review code for bugs, security issues, and improvements",
        parameters={
            "type": "object",
            "properties": {
                "code": {"type": "string", "description": "Code to review"},
                "focus": {"type": "string", "description": "Focus area", "default": "general"}
            },
            "required": ["code"]
        },
        function=lambda code, focus="general": f"Code review ({focus}): Found 0 critical issues"
    )
    
    system_prompt = """You are a Coding Agent. Your job is to:
1. Write clean, efficient code
2. Execute and test code
3. Review and improve code quality

Always explain your reasoning. Use tools appropriately."""
    
    return LLMAgent(
        name="CoderAgent",
        system_prompt=system_prompt,
        llm_call=llm_call,
        tools=[execute_tool, review_tool],
        verbose=True
    )

🔮 Direcciones Futuras

El campo esta evolucionando hacia varias direcciones emocionantes:

1. Multimodal Foundation Models

Los proximos modelos procesan texto, imagen, audio, video, y mas — todo en un solo modelo unificado. La matematica de esto es atencion crozada:

$$Attention(Q, K, V) = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

Donde Q, K, V pueden venir de diferentes modalidades pero se proyectan a un espacio latente comun.

2. Retrieval-Augmented Generation (RAG) Evolved

RAG esta evolucionando de simple retrieval a retrieval con memoria persistente y aprendizaje en tiempo real:

$$\text{Answer} = \text{LLM}( \text{Query}, \text{TopK}(\text{Embed}(\text{Query}), \text{VDB})))$$

3. Constitutional AI y RLHF 2.0

Los metodos de alignment estan mejorando con mejores senales de recompensa y menores sesgos:

$$R_{\text{CAI}}(x, y) = R_{\text{HH}}(x, y) + \lambda \cdot \mathbb{1}[\text{principle\_violated}(y)]$$

"""
Practical Application Framework
Ejemplos de como aplicar patrones emergentes en produccion

from typing import Dict, List, Optional
from dataclasses import dataclass


@dataclass
class UseCasePattern:
    """Patron para un caso de uso especifico"""
    name: str
    description: str
    complexity: str  # 'low', 'medium', 'high'
    recommended_patterns: List[str]
    example_code_snippet: str


USE_CASE_PATTERNS = {
    "chatbot_simple": UseCasePattern(
        name="Chatbot Simple",
        description="FAQ bot con contexto limitado",
        complexity="low",
        recommended_patterns=["basic_prompting", "few_shot"],
        example_code_snippet="""
prompt = f\"\"\"User: {question}
Assistant: Let me answer that\"\"\"
"""
    ),
    
    "research_assistant": UseCasePattern(
        name="Research Assistant",
        description="Agente que busca, lee, sintetiza",
        complexity="high",
        recommended_patterns=["agentic", "tool_use", "multi_step"],
        example_code_snippet="""
agent = LLMAgent(tools=[search_tool, read_tool])
result = agent.run(research_query)
"""
    ),
    
    "code_generation": UseCasePattern(
        name="Code Generation System",
        description="Generador de codigo con testing automatico",
        complexity="high",
        recommended_patterns=["cot", "self_reflection", "execution_loop"],
        example_code_snippet="""
for attempt in range(max_attempts):
    code = llm(plan_prompt)
    result = execute(code)
    if result.success:
        break
    feedback = review(result)
    plan_prompt = f\"Fix: {feedback}\"
"""
    ),
    
    "document_processor": UseCasePattern(
        name="Document Processor",
        description="Extrae, resume, responde sobre documentos",
        complexity="medium",
        recommended_patterns=["rag", "chunking", "summarization"],
        example_code_snippet="""
chunks = chunk_document(doc)
embeddings = embed(chunks)
relevant = retrieve(query, embeddings)
answer = llm(f\"Context: {relevant}\\nQuestion: {query}\")
"""
    )
}


def select_pattern(use_case: str) -> UseCasePattern:
    """Selecciona el patron apropiado basado en el caso de uso"""
    return USE_CASE_PATTERNS.get(use_case, USE_CASE_PATTERNS["chatbot_simple"])


# Framework para evaluar readiness de un proyecto LLM
class LLMProjectReadiness:
    """
    Evalua si un proyecto esta listo para produccion con LLMs.
    
    Criterios:
    - Quality: Que tan buena es la respuesta requerida?
    - Latency: Cual es el budget de tiempo?
    - Cost: Cuanto podemos gastar por query?
    - Safety: Hay riesgos de contenido harmful?
    - Reliability: Que tan critica es la exactitud?
    """
    
    DIMENSIONS = {
        "quality": {"weight": 0.3, "questions": [
            "Requiere razonamiento complejo?",
            "Necesita hechos verificables?",
            "Que tan tolerable es la ambiguedad?"
        ]},
        "latency": {"weight": 0.2, "questions": [
            "Es para usuario final o batch?",
            "Cual es el timeout aceptable?"
        ]},
        "cost": {"weight": 0.15, "questions": [
            "Volumen de requests esperado?",
            "Costo por 1K tokens aceptable?"
        ]},
        "safety": {"weight": 0.2, "questions": [
            "Contenido potencialmente harmful?",
            "Requiere moderation?"
        ]},
        "reliability": {"weight": 0.15, "questions": [
            "Error puede causar dano?",
            "Requiere audit trail?"
        ]}
    }
    
    @classmethod
    def evaluate(cls, answers: Dict[str, int]) -> Dict[str, any]:
        """
        Evalua readiness basado en respuestas (1-5 para cada dimension).
        
        Returns:
            Dict con scores, recommendation, y nivel de madurez
        """
        weighted_score = 0
        for dimension, data in cls.DIMENSIONS.items():
            if dimension in answers:
                score = answers[dimension] / 5.0  # Normalize to 0-1
                weighted_score += score * data["weight"]
        
        if weighted_score >= 0.7:
            maturity = "Production Ready"
            recommendation = "Safe to deploy with proper monitoring"
        elif weighted_score >= 0.5:
            maturity = "Needs Improvement"
            recommendation = "Address weak points before production"
        else:
            maturity = "Experimental"
            recommendation = "Use with caution, strong guardrails needed"
        
        return {
            "overall_score": weighted_score,
            "maturity_level": maturity,
            "recommendation": recommendation,
            "dimension_scores": {
                d: answers.get(d, 0) / 5.0 
                for d in cls.DIMENSIONS.keys()
            }
        }

📊 Metrics y Evaluacion

Para sistemas de produccion, necesitamos metricas rigurosas:

Metrics de Calidad:

  • BLEU/ROUGE: Comparacion con referencias humanas
  • BERTScore: Similitud semantica
  • Human Preference Rating: Evaluacion directa

Metrics de Sistema:

  • Latencia p50, p95, p99
  • Tokens por request (input + output)
  • Cache hit ratio
  • Error rate por tipo

Formula para Cost-Benefit:

$$\text{Cost Efficiency} = \frac{\text{Quality Score} \times \text{Successful Requests}}{\text{Total Cost}}$$

⚠️ Errores Comunes

Error 1: No Estar al Dia

El problema: Usar tecnicas del 2023 cuando en 2026 hay metodos significativamente mejores.

La solucion: Dedicar tiempo semanal a research. Follow arXiv, papers-with-code, y los blogs de Anthropic/OpenAI. Suscribete a newsletters como The Batch o Last Week in AI. El campo avanza rapido — lo que era best practice hace 6 meses puede estar obsoleto.

Error 2: No Experimentar

El problema: Quedarse con la primera solucion que funciona sin probar alternativas.

La solucion: Implementar un framework de experimentacion. A/B test prompts, modelos, temperaturas. Small changes pueden tener big impact. Usa herramientas como LangSmith, Weights & Biases, o PromptLayer para trackear experimentos sistematicamente.

Error 3: No Aprender de los Fallos

El problema: Deployment falla, nadie hace post-mortem, el mismo error se repite.

La solucion: Post-mortems rigurosos para cada fallo significativo. Loguea inputs, outputs, y contextos para poder hacer forensics. Crea un "failure modes catalog" de tu sistema y actualizalo continuamente. Los mejores sistemas LLM son los que aprenden de sus errores iterativamente.
