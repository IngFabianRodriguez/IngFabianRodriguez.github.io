Hágale pues, parcero. Llegamos al Día 112 y hoy vamos a romperla con la Transformer Architecture. Esta es la arquitectura que cambió todo en NLP desde 2017: BERT, GPT, T5, Llama, Claude — todos son Transformers. Y no solo en texto: Vision Transformers (ViT), protein folding (AlphaFold), speech recognition, hasta generación de imágenes con DALL-E y Stable Diffusion. Si no entiendes Transformers, no entiendes el state-of-the-art actual. Dejá el tinto, esto es pa' quedarse.

Attention Is All You Need — El Paper Que Cambió Todo

En Junio 2017, Vaswani et al. de Google publicaron un paper que decía algo controversial: "Attention is all you need" — no necesitas recurrent networks (RNNs, LSTMs) para secuencias. Puedes resolver todo con attention. La comunidad pensó que estaban locos. Tres años después, BERT y GPT-2 dominaban todo.

La innovación central era simple pero profunda: en vez de procesar secuencias token por token secuencialmente (como RNN), el Transformer procesa toda la secuencia en paralelo usando self-attention. Esto permitía training mucho más paralelo, y por ende, training mucho más rápido en GPUs.

La Magia Del Self-Attention

Self-attention permite que cada posición en una secuencia "mire" a todas las otras posiciones y aprenda qué tan relevantes son entre sí. Para la palabra "banco" en "Voy al banco a depositar dinero", self-attention puede aprender que "banco" se relaciona fuertemente con "depositar" y "dinero", pero no con otras palabras lejanas.

La operación es elegantemente simple:

Para cada input $\mathbf{x}_i$, calculamos query ($q_i$), key ($k_i$), y value ($v_i$):

$$ q_i = W_Q \mathbf{x}_i, \quad k_i = W_K \mathbf{x}_i, \quad v_i = W_V \mathbf{x}_i $$

La atención de una posición hacia todas las otras:

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

El factor $\sqrt{d_k}$ previene que los dot products sean muy grandes, lo que haría el softmaxpeakear a una distribución degenerada (todas las probabilidades en un solo valor).

Multi-Head Attention

En vez de hacer una sola attention, el Transformer usa multi-head attention: múltiples "cabezas" de atención en paralelo, cada una aprendiendo diferentes tipos de relaciones.

$$ \text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W_O $$

donde cada $\text{head}_i = \text{Attention}(QW_{Q_i}, KW_{K_i}, VW_{V_i})$.

Si tienes 8 heads y $d_{model} = 512$, cada head trabaja con $d_k = d_v = 64$. Esto permite que diferentes heads aprendan diferentes patterns: algunos pueden enfocarse en sintaxis, otros en coreferencia, otros en relaciones semánticas.

Positional Encoding — El Detalle Crítico

Aquí viene algo que muchos devs olvidan: self-attention es permutation invariant. Esto significa que si barres la oración "el gato persigue al perro", self-attention ve lo mismo que "perro追逐 al gato el persigue". No distingue orden.

Para solucionar esto, el Transformer añade positional encoding a cada input antes de la primera capa. El paper original usa sinusoidal encoding:

$$ PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$

$$ PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$

Para $i = 0, 1, \ldots, d_{model}/2-1$. Esto produce un vector único para cada posición. ¿Por qué sinusoidales? Porque permiten que el modelo aprenda relaciones relativas entre posiciones fácilmente (el pattern sinusoidal se puede expresar como funciones lineales de la posición relativa).

Arquitectura Completa: Encoder-Decoder

El Transformer original tiene dos partes: Encoder (izquierda) y Decoder (derecha). El encoder procesa el input completo en paralelo. El decoder genera el output autoregresivamente (un token a la vez, usando los tokens generados anteriormente).

Encoder

Cada encoder layer tiene:

  1. Multi-Head Self-Attention: Cada posición mira todas las posiciones del input
  2. Add & Norm: Residual connection + Layer Normalization
  3. Feed-Forward Network: Dos capas lineales con ReLU: $FFN(x) = W_2 \max(0, W_1 x + b_1) + b_2$
  4. Add & Norm: Otra vez residual + LayerNorm

Decoder

El decoder tiene tres partes por layer:

  1. Masked Multi-Head Self-Attention: Solo mira posiciones anteriores (no puede ver el futuro durante training)
  2. Cross-Attention: El query viene del decoder, pero keys y values vienen del encoder output — esto conecta input con output
  3. Feed-Forward Network: Igual que en el encoder

Implementación Completa En PyTorch

Acá va el código real, 100+ líneas, pa' que veas cómo implementar un Transformer completo desde cero usando las primitivas de PyTorch.

import torch
import torch.nn as nn
import torch.nn.functional as F
import math

# ============================================================
# PARTE 1: Positional Encoding (Sinusoidal)
# ============================================================
class PositionalEncoding(nn.Module):
    """Positional encoding sinusoidal. Permite al modelo conocer
    la posición de cada token sin aprender embeddings de posición."""
    
    def __init__(self, d_model: int, max_len: int = 5000, dropout: float = 0.1):
        super().__init__()
        self.dropout = nn.Dropout(p=dropout)
        
        # Crear la matriz de positional encoding
        pe = torch.zeros(max_len, d_model)  # (max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)  # (max_len, 1)
        
        # Divisor para las frecuencias
        div_term = torch.exp(
            torch.arange(0, d_model, 2, dtype=torch.float) * 
            (-math.log(10000.0) / d_model)
        )  # (d_model/2,)
        
        # Sin para posiciones pares, cos para posiciones impares
        pe[:, 0::2] = torch.sin(position * div_term)  # pares
        pe[:, 1::2] = torch.cos(position * div_term)  # impares
        
        pe = pe.unsqueeze(0)  # (1, max_len, d_model) para broadcast
        self.register_buffer('pe', pe)
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """x: (batch, seq_len, d_model)"""
        x = x + self.pe[:, :x.size(1), :]
        return self.dropout(x)

# ============================================================
# PARTE 2: Multi-Head Attention
# ============================================================
class MultiHeadAttention(nn.Module):
    """Multi-Head Attention mechanism.
    
    Args:
        d_model: dimensión del modelo ( embedding size)
        num_heads: número de heads de atención
        dropout: dropout rate
    """
    
    def __init__(self, d_model: int, num_heads: int, dropout: float = 0.1):
        super().__init__()
        assert d_model % num_heads == 0, "d_model must be divisible by num_heads"
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads  # dimensión por head
        
        # W_q, W_k, W_v: (d_model, d_model)
        self.W_q = nn.Linear(d_model, d_model, bias=False)
        self.W_k = nn.Linear(d_model, d_model, bias=False)
        self.W_v = nn.Linear(d_model, d_model, bias=False)
        self.W_o = nn.Linear(d_model, d_model, bias=False)  # output projection
        
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, query: torch.Tensor, key: torch.Tensor, value: torch.Tensor,
                mask: torch.Tensor = None) -> tuple:
        """
        Args:
            query: (batch, seq_len, d_model)
            key: (batch, seq_len, d_model)
            value: (batch, seq_len, d_model)
            mask: (batch, 1, seq_len, seq_len) - mask para evitar mirar ahead
        Returns:
            output: (batch, seq_len, d_model)
            attention_weights: (batch, num_heads, seq_len, seq_len)
        """
        batch_size = query.size(0)
        seq_len = query.size(1)
        
        # Proyectar Q, K, V
        Q = self.W_q(query)  # (B, L, d_model)
        K = self.W_k(key)
        V = self.W_v(value)
        
        # Split en multiple heads: (B, L, num_heads, d_k) -> (B, num_heads, L, d_k)
        Q = Q.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, seq_len, self.num_heads, self.d_k).transpose(1, 2)
        
        # Attention scores: (B, num_heads, L, L)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        # Aplicar mask (para decoder: prevent lookahead)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        
        # Softmax
        attention_weights = F.softmax(scores, dim=-1)
        attention_weights = self.dropout(attention_weights)
        
        # Aplicar attention a values: (B, num_heads, L, d_k)
        attended = torch.matmul(attention_weights, V)
        
        # Concatenar heads: (B, num_heads, L, d_k) -> (B, L, num_heads, d_k) -> (B, L, d_model)
        attended = attended.transpose(1, 2).contiguous().view(batch_size, seq_len, self.d_model)
        
        # Output projection
        output = self.W_o(attended)
        
        return output, attention_weights

# ============================================================
# PARTE 3: Feed-Forward Network
# ============================================================
class FeedForward(nn.Module):
    """Position-wise Feed-Forward Network.
    
    FFN(x) = W_2 * ReLU(W_1 * x + b_1) + b_2
    usual: d_model=512, d_ff=2048
    """
    
    def __init__(self, d_model: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.w1 = nn.Linear(d_model, d_ff)
        self.w2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.w2(self.dropout(F.relu(self.w1(x))))

# ============================================================
# PARTE 4: Transformer Encoder Layer
# ============================================================
class TransformerEncoderLayer(nn.Module):
    """Un solo layer del encoder."""
    
    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn = FeedForward(d_model, d_ff, dropout)
        
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        # Self-attention con residual
        attn_output, _ = self.self_attn(x, x, x, mask)
        x = self.norm1(x + self.dropout1(attn_output))
        
        # Feed-forward con residual
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout2(ffn_output))
        
        return x

# ============================================================
# PARTE 5: Transformer Decoder Layer
# ============================================================
class TransformerDecoderLayer(nn.Module):
    """Un solo layer del decoder."""
    
    def __init__(self, d_model: int, num_heads: int, d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.cross_attn = MultiHeadAttention(d_model, num_heads, dropout)
        self.ffn = FeedForward(d_model, d_ff, dropout)
        
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)
        self.dropout3 = nn.Dropout(dropout)
        
    def forward(self, x: torch.Tensor, encoder_output: torch.Tensor,
                tgt_mask: torch.Tensor = None, memory_mask: torch.Tensor = None) -> torch.Tensor:
        # Masked self-attention (solo ve posiciones anteriores)
        attn_output, _ = self.self_attn(x, x, x, tgt_mask)
        x = self.norm1(x + self.dropout1(attn_output))
        
        # Cross-attention (del encoder)
        attn_output, _ = self.cross_attn(x, encoder_output, encoder_output, memory_mask)
        x = self.norm2(x + self.dropout2(attn_output))
        
        # Feed-forward
        ffn_output = self.ffn(x)
        x = self.norm3(x + self.dropout3(ffn_output))
        
        return x

# ============================================================
# PARTE 6: Transformer Encoder y Decoder Completo
# ============================================================
class TransformerEncoder(nn.Module):
    """Encoder completo con N layers."""
    
    def __init__(self, num_layers: int, d_model: int, num_heads: int, 
                 d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.layers = nn.ModuleList([
            TransformerEncoderLayer(d_model, num_heads, d_ff, dropout)
            for _ in range(num_layers)
        ])
        self.num_layers = num_layers
        
    def forward(self, x: torch.Tensor, mask: torch.Tensor = None) -> torch.Tensor:
        for layer in self.layers:
            x = layer(x, mask)
        return x

class TransformerDecoder(nn.Module):
    """Decoder completo con N layers."""
    
    def __init__(self, num_layers: int, d_model: int, num_heads: int,
                 d_ff: int, dropout: float = 0.1):
        super().__init__()
        self.layers = nn.ModuleList([
            TransformerDecoderLayer(d_model, num_heads, d_ff, dropout)
            for _ in range(num_layers)
        ])
        self.num_layers = num_layers
        
    def forward(self, x: torch.Tensor, encoder_output: torch.Tensor,
                tgt_mask: torch.Tensor = None, memory_mask: torch.Tensor = None) -> torch.Tensor:
        for layer in self.layers:
            x = layer(x, encoder_output, tgt_mask, memory_mask)
        return x

# ============================================================
# PARTE 7: Transformer Completo (Ejemplo Completo)
# ============================================================
class SimpleTransformer(nn.Module):
    """Transformer completo para secuencia a secuencia."""
    
    def __init__(self, src_vocab_size: int, tgt_vocab_size: int,
                 d_model: int = 512, num_heads: int = 8,
                 num_encoder_layers: int = 6, num_decoder_layers: int = 6,
                 d_ff: int = 2048, dropout: float = 0.1, max_len: int = 5000):
        super().__init__()
        
        self.d_model = d_model
        
        # Embeddings
        self.src_embedding = nn.Embedding(src_vocab_size, d_model)
        self.tgt_embedding = nn.Embedding(tgt_vocab_size, d_model)
        
        # Positional encoding
        self.pos_encoder = PositionalEncoding(d_model, max_len, dropout)
        self.pos_decoder = PositionalEncoding(d_model, max_len, dropout)
        
        # Encoder y Decoder
        self.encoder = TransformerEncoder(num_encoder_layers, d_model, 
                                          num_heads, d_ff, dropout)
        self.decoder = TransformerDecoder(num_decoder_layers, d_model,
                                          num_heads, d_ff, dropout)
        
        # Output projection
        self.output_proj = nn.Linear(d_model, tgt_vocab_size)
        
        # Init params
        self._init_params()
        
    def _init_params(self):
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)
    
    def forward(self, src: torch.Tensor, tgt: torch.Tensor,
                src_mask: torch.Tensor = None, tgt_mask: torch.Tensor = None) -> torch.Tensor:
        # Encode
        src_emb = self.pos_encoder(self.src_embedding(src) * math.sqrt(self.d_model))
        encoder_output = self.encoder(src_emb, src_mask)
        
        # Decode
        tgt_emb = self.pos_decoder(self.tgt_embedding(tgt) * math.sqrt(self.d_model))
        decoder_output = self.decoder(tgt_emb, encoder_output, tgt_mask, src_mask)
        
        # Project to vocabulary
        logits = self.output_proj(decoder_output)
        
        return logits

⚠️ Errores Comunes Y Sus Soluciones

Error 1: No Usar Positional Encoding — El Transformer No Distingue Orden

El problema: Muchos devs implementan Transformers y se preguntan por qué el modelo no aprende patrones secuenciales básicos. O peor, usan embeddings de posición aprendibles pero los inicializan mal. Sin positional encoding, o con positional encoding incorrecta, el Transformer es permutation invariant: "el perro muerde al gato" y "el gato muerde al perro" son idénticos para el modelo.

La solución: Usa positional encoding sinusoidal (como en el paper original) o embeddings de posición aprendidos. Para la mayoría de casos, la sinusoidal es mejor porqueGeneraliza a secuencias más largas que las vistas en training:

# MAL: Olvidar positional encoding
class BadTransformer(nn.Module):
    def __init__(self, vocab_size, d_model):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        # ERROR: No hay positional information!
        
    def forward(self, x):
        return self.embedding(x)  # x es permutation invariant!

# BIEN: Positional encoding sinusoidal
class GoodTransformer(nn.Module):
    def __init__(self, vocab_size, d_model, max_len=5000):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.pos_encoding = PositionalEncoding(d_model, max_len)
        
    def forward(self, x):
        emb = self.embedding(x) * math.sqrt(d_model)
        return self.pos_encoding(emb)  # Ahora tiene posición!

Error 2: Deep Transformers Sin Warmup — Training Instability

El problema: Transformers profundos (12+ capas) con learning rates altos son extremadamente inestables en early training. Puedes ver NaN losses después de unas pocas batches. Esto pasa porque los attention scores pueden explotar si el gradient es muy grande, y sin warmup, el modelo recibe updates muy agressivos antes de estabilizar.

La solución: Usa learning rate warmup. El schedule linearly aumenta el LR de 0 a su valor pico durante los primeros N steps (ej: 4000-10000), y luego lo decrementa usando cosine decay o step decay:

# Learning rate warmup schedule
def get_lr_scheduler(optimizer, warmup_steps, total_steps, strategy='cosine'):
    def lr_lambda(step):
        if step < warmup_steps:
            # Linear warmup
            return float(step) / float(max(1, warmup_steps))
        elif strategy == 'cosine':
            # Cosine decay
            progress = float(step - warmup_steps) / float(max(1, total_steps - warmup_steps))
            return max(0.1, 0.5 * (1.0 + math.cos(math.pi * progress)))
        else:
            # Step decay
            return 0.1
        
    return torch.optim.lr_scheduler.LambdaLR(optimizer, lr_lambda)

# En training:
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
scheduler = get_lr_scheduler(optimizer, warmup_steps=4000, total_steps=100000)

for step, batch in enumerate(dataloader):
    loss = model(batch)
    loss.backward()
    
    # Gradient clipping previene explosiones
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    
    optimizer.step()
    scheduler.step()
    optimizer.zero_grad()

Error 3: Transformers Gigantes Sin Gradient Checkpointing — Out of Memory

El problema: Un GPT-3 (175B params) o incluso un LLaMA-7B tiene un memory footprint enorme durante training. Cada layer guarda lasactivaciones completas para backprop — esto es proporcional a batch_size × seq_len × num_layers × hidden_dim. Para un modelo de 7B con seq_len=2048 y batch_size=1, lasactivaciones pueden ocupar 20GB+ de GPU memory. Te quedas sin VRAM rapidísimo.

La solución: Usa gradient checkpointing (also called "recompute activations"). En vez de guardar todas lasactivaciones, las recomputas durante backprop. Esto intercambia compute por memory:

# PyTorch tiene gradient checkpointing integrado
from torch.utils.checkpoint import checkpoint, checkpoint_sequential

# Para un modelo con múltiples capas:
class MemoryEfficientTransformer(nn.Module):
    def __init__(self, num_layers, d_model, num_heads, d_ff):
        super().__init__()
        self.layers = nn.ModuleList([
            TransformerEncoderLayer(d_model, num_heads, d_ff)
            for _ in range(num_layers)
        ])
        
    def forward(self, x):
        # checkpoint_sequential ahorra memory recomputando layers en groups
        # segmentos de 2-4 capas es un buen balance
        return checkpoint_sequential(
            self.layers,  # ModuleList
            2,            # number of segments
            x
        )

# Para un solo layer con operaciones custom, usa checkpoint():
class EfficientAttention(nn.Module):
    def __init__(self, d_model, num_heads):

El tradeoff: gradient checkpointing aumenta el tiempo de training en ~20-30% pero puede reducir el memory footprint en ~50-60%. Para transformers grandes, es esencial.

Resumen Del Día — De Colombia Pa' El Mundo

Hoy aprendimos que el Transformer no es magia — es una combinación elegante de piezas que ya existían: attention, residual connections, positional encoding, feed-forward networks. La innovación de Vaswani et al. fue arquitectónica: how you combine these pieces matters more than the pieces themselves.

Lo clave pa' llevar: Si implementas un Transformer, no olvides positional encoding (es el error #1 más común). Si entrenas uno profundo, usa warmup y gradient clipping. Si es muy grande, usa gradient checkpointing. Y si puedes usar uno pretrained... úsalo. La cantidad de compute que se ha invertido en GPT-4, Claude, Gemini es absurdamente grande — no hay razón para entrenar desde cero a menos que tengas una razón muy específica.

El Transformer es el modelo fundamental de la era actual de AI. Entiende uno y entiendes BERT, GPT, T5, ViT, SAM, DALL-E, Stable Diffusion... todos son variantes del mismo architecture. Eso es todo por hoy, parcero. Mañana seguimos con más.
