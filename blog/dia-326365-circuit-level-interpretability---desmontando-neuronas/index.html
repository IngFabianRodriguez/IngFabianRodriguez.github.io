Circuit-level Interpretability - Desmontando Neuronas

Hagale pues, parcero. Hoy es el Dia 326 y hablamos de Circuit-level Interpretability. Dejala el cafe.

🎯 Circuits En LLMs

Circuit-level interpretability busca identificar que subgrafico de la red implementa cada capability del modelo.

Conceptos clave:

  • Attention heads: Componentes que implementan operaciones especificas
  • Residual streams: informacion que fluye a traves del modelo
  • MLP neurons: Neuronas individuais con roles

📐 Finding Induction Heads

from transformer_lens import HookedTransformer
import torch

model = HookedTransformer.from_pretrained("gpt2")

# Buscar attention heads que implementan "induction"
# Induccion: dado [A, B, ..., A] predecir B

# Get attention patterns
_, cache = model.run_with_cache(tokens)
attn = cache["blocks.0.attn.hook_attn"]

# Buscar heads con patrones de induction
# Head 5 y 6 frecuentemente implementan esto
induction_head_0 = attn[:, 5, :, :]
induction_head_1 = attn[:, 6, :, :]
