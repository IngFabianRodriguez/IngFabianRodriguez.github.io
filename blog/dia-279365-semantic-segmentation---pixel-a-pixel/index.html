Semantic Segmentation - Pixel A Pixel

06 de octubre de 2026
segmentationdeeplabmask-rcnncomputer-vision

El 80% clasifica imágenes por completo y el 20% entiende cada píxel

Clasificar una imagen es útil: "esto es un gato" o "esto es un carro". Pero a veces necesitas más. Necesitas saber exactamente dónde está cada objeto, no solo qué es. ¿Dónde están los carriles en esta foto de carretera? ¿Qué píxeles pertenecen a la acera versus la carretera? ¿Dónde están los obstáculos?

La segmentación semántica responde esta pregunta a nivel de píxel: cada píxel de la imagen se clasifica con una etiqueta de clase. No es "hay un carro en la imagen" — es "estos 50,000 píxeles son carro, estos 30,000 son peatón, estos 100,000 son carretera".

De clasificación a pixel-level

Una CNN estándar para clasificación toma una imagen y produce una predicción global. La magia de la segmentación está en cómo convertimos esa arquitectura en algo que produce un mask del tamaño de la imagen original.

El problema: downsampling

Las CNNs típicamente reducen el spatial resolution mientras aumenta los canales: una imagen de 224x224 pasa por varias capas de pooling/strides hasta convertirse en features de 7x7 con muchos canales. Perfecto para clasificación, inútil para segmentación donde necesitamos output del mismo tamaño que el input.

La solución: arquitectura encoder-decoder

La solución más elegante usa dos partes:

  • Encoder: la red normal que extrae features de alto nivel (resnet, vgg, etc.)
  • Decoder: red que gradualmente恢复 (recupera) la resolución espacial mientras refina las predicciones

El decoder toma los features de baja resolución del encoder y los va upsampling paso a paso, combinando información de diferentes niveles del encoder (skip connections).

Arquitecturas clave

FCN (Fully Convolutional Network)

El paper seminal de Long et al. (2014) mostró que cualquier CNN de clasificación puede convertirse en una red fully convolutional para segmentación. La idea: reemplazar las capas fully connected por convoluciones 1x1.

El FCN usa skip connections para combinar información de diferentes capas del encoder. Pero el upsampling bilinear inicial produce resultados borrosos.

U-Net

U-Net, creada para imágenes médicas en 2015, fue revolucionaria. Su arquitectura en forma de "U" tiene:

  • Contracting path (lado izquierdo): CNN estándar que reduce resolución
  • Expansive path (lado derecho): upsampling con skip connections al contracting
  • Skip connections: concatenación de features del encoder con los del decoder en el mismo nivel de resolución

Las skip connections permiten que la red combine información de bajo nivel (bordes, texturas) con información de alto nivel (objetos, regiones).

import torch
import torch.nn as nn
import torch.nn.functional as F

class UNet(nn.Module):
    def __init__(self, in_channels=3, out_channels=1, features=[64, 128, 256, 512]):
        super(UNet, self).__init__()
        self.downs = nn.ModuleList()
        self.ups = nn.ModuleList()
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # Contracting path (encoder)
        for feature in features:
            self.downs.append(DoubleConv(in_channels, feature))
            in_channels = feature
        
        # Bottom (bottleneck)
        self.bottleneck = DoubleConv(features[-1], features[-1] * 2)
        
        # Expansive path (decoder)
        for feature in reversed(features):
            self.ups.append(
                nn.ConvTranspose2d(feature * 2, feature, kernel_size=2, stride=2)
            )
            self.ups.append(DoubleConv(feature * 2, feature))
        
        # Output layer
        self.final_conv = nn.Conv2d(features[0], out_channels, kernel_size=1)
    
    def forward(self, x):
        skip_connections = []
        
        # Encoder
        for down in self.downs:
            x = down(x)
            skip_connections.append(x)
            x = self.pool(x)
        
        x = self.bottleneck(x)
        skip_connections = skip_connections[::-1]
        
        # Decoder
        for idx in range(0, len(self.ups), 2):
            x = self.ups[idx](x)
            skip = skip_connections[idx // 2]
            x = torch.cat([skip, x], dim=1)
            x = self.ups[idx + 1](x)
        
        return self.final_conv(x)

class DoubleConv(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(DoubleConv, self).__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True)
        )
    
    def forward(self, x):
        return self.conv(x)

DeepLab y Atrous Convolutions

DeepLab (Google) introdujo las atrous convolutions (también llamadas dilated convolutions). La idea es simple: en lugar de hacer pooling para aumentar el receptive field, podemos usar convoluciones con "huecos" que capturan contexto a mayor escala sin reducir la resolución.

Mathemáticamente, una atrous convolution con rate r aplica el kernel sobre posiciones separadas por r-1 píxeles:

$$y[i] = \sum_{k} x[i + r \cdot k] \cdot w[k]$$

DeepLabv3+ usa atrous convolutions multi-scale con ASPP (Atrous Spatial Pyramid Pooling) para capturar contexto a diferentes escalas.

Métricas para segmentación

IoU (Intersection over Union)

La métrica estándar para segmentación es IoU, también conocida como Jaccard index. Para cada clase:

$$\text{IoU} = \frac{\text{TP}}{\text{TP} + \text{FP} + \text{FN}} = \frac{\text{Intersection}}{\text{Union}}$$

  • Intersection: píxeles predichos como clase X que realmente son clase X
  • Union: todos los píxeles predichos como X más todos los que son X en el ground truth

El mean IoU (mIoU) es el promedio de IoU sobre todas las clases. Es la métrica más usada en benchmarks como Cityscapes y Pascal VOC.

Pixel Accuracy

Menos informativa pero intuitiva: qué porcentaje de píxeles están correctamente clasificados?

$$\text{Accuracy} = \frac{\text{píxeles correctos}}{\text{total píxeles}}$$

El problema: si tienes 95% de fondo y 5% de objetos, predecir todo como fondo te da 95% accuracy aunque no detectas nada.

Datasets principales

  • Pascal VOC 2012: 20 clases, ~1,500 imágenes de entrenamiento, benchmark clásico
  • MSCOCO: 80 cosas + material, el más grande y desafiante
  • Cityscapes: escenas urbanas, 19 clases, enfocado en autonomous driving
  • ADE20K: 150 clases de scene parsing, muy diverso

Aplicaciones del mundo real

  • Autonomous driving: segmentar carretera, carriles, peatones, vehículos para navegación
  • Medical imaging: tumor segmentation en CT/MRI, órganos en ultrasound
  • Satellite imagery: clasificar terreno, construir mapas, detectar cambios
  • Portrait segmentation: separar personas del fondo para foto edición
  • Video conferencing: background blur/virtual backgrounds basados en segmentación

Resumen

  • Segmentación semántica clasifica cada píxel de la imagen
  • U-Net es la arquitectura más popular para datos limitados (especialmente médica)
  • DeepLab con atrous convolutions excels en captura de contexto multi-escala
  • IoU es la métrica estándar, más robusta que accuracy para datos desbalanceados
  • Los avances en segmentación enable aplicaciones desde autos autónomos hasta diagnóstico médico

La segmentación semántica es el foundation para tareas más avanzadas como instance segmentation (donde separas instancias individuales del misma clase) y panoptic segmentation (que combina ambas).
