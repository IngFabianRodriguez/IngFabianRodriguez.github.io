📐 La Matemática de la Creatividad Generativa

Antes de código, la teoría. La creatividad en LLMs es fundamentalmente un problema de distribución de probabilidad condicional.

El Proceso de Generación Creativa

Un LLM genera texto token por token. En cada paso t, calcula:

P(x_t | x_1, x_2, ..., x_{t-1}, θ)

donde θ son los parámetros del modelo. La temperatura T modifica esta distribución:

P_T(x_t) = softmax(logits / T) = exp(logits_i / T) / Σexp(logits_j / T)

Cuando T → 0: el modelo se vuelve completamente determinístico — siempre elige el token más probable.

Cuando T → 1: la distribución original se preserva.

Cuando T → 2 o más: el modelo empieza a muestrear tokens muy improbables, aumentando la "creatividad" pero también el caos.

La Ecuación del Control Creativo

Para controlar creatividad, necesitamos una función que balancee diversidad y coherencia:

Quality(generation) = α × Coherence - β × Repetition - γ × Incoherence

donde:

  • Coherence: Qué tan relacionadas están las secciones del texto (medida por embedding similarity)
  • Repetition: Penalización por tokens o frases repetidas
  • Incoherence: Qué tan abruptas son las transiciones (medida por log-probabilidad de transiciones)

Top-K y Top-P Sampling

Además de temperatura, usamos top_k y top_p para controlar la exploración:

Top-K: En cada paso, solo considera los K tokens más probables.

Top-P (nucleus): En cada paso, considera tokens hasta que su probabilidad acumulada alcance P.

La combinación óptima para escritura creativa estructurada es típicamente top_p=0.9 con temperature=0.7-0.9.

class CreativeGenre(Enum):
    """Géneros creativos disponibles"""
    NARRATIVE = "narrative"           # Prosa narrativa
    POETRY = "poetry"                # Poesía

    TECHNICAL_NARRATIVE = "technical_narrative"  # Narrativa técnica


class Tone(Enum):
    """Tonos disponibles"""
    FORMAL = "formal"
    INFORMAL = "informal"
    SERIOUS = "serious"
    HUMOROUS = "humorous"
    ROMANTIC = "romantic"
    DARK = "dark"

class WritingStyle(Enum):

@dataclass
class CreativityConfig:
    """Configuración de creatividad para generación"""
    temperature: float = 0.7          # Creatividad (0.0 = none, 1.0+ = chaos)
    top_p: float = 0.9                # Nucleus sampling
    top_k: int = 50                   # Top-k sampling
    max_tokens: int = 500            # Máximo de tokens a generar
    repetition_penalty: float = 1.1   # Penalización de repetición
    presence_penalty: float = 0.0     # Penalización de presencia
    stop_sequences: list[str] = field(default_factory=list)
    
    # Controles de estructura
    paragraph_count: Optional[int] = None  # Número de párrafos (None = auto)
    sentence_count: Optional[int] = None    # Número de oraciones (None = auto)
    line_count: Optional[int] = None        # Para poesía/guiones

class GenrePromptBuilder:
    """
    Construye prompts estructurados por género.
    Cada género tiene templates específicos que maximizan calidad.
    """
    
    GENRE_TEMPLATES = {
        CreativeGenre.NARRATIVE: {
            "system": """Eres un escritor de prosa narrativa con décadas de experiencia.
Tu especialidad es crear historias que capturan la condición humana con precisión cirúrgica.
Escribe con propósito — cada palabra debe servir a la narrativa.""",

            "elements": ["protagonista", "conflicto", "escenario", "punto de vista"]
        },
        CreativeGenre.POETRY: {
            "system": """Eres un poeta que domina múltiples formas poéticas.
Puedes escribir sonetos, haikus, verso libre, o cualquier forma que mejor sirva al poema.
Cada poema debe tener una imagen central poderosa y ritmo natural.""",
            "forms": ["soneto", "haiku", "verso libre", "oda", "elegía"],
            "devices": ["metáfora", "simile", "personificación", "aliteración", "asonancia"]
        },
        CreativeGenre.DIALOGUE: {
            "system": """Eres un escritor de diálogos para theater y cine.
Los diálogos deben ser naturales, con pausas dramáticas y subtexto.
Cada línea debe revelar carácter o avanzar la trama.""",
            "format": "Nombre: Línea\n[ dirección ]",
            "subtext": True
        },
        CreativeGenre.SCREENPLAY: {
            "system": """Eres un guionista profesional familiarizado con formato de Hollywood.
Escribes escenas visuales con acción concisa y diálogos高效的.""",
            "format": "INT./EXT. LOCATION - TIME\n\nACTION\n\nCHARACTER: Dialogue",
            "visual_emphasis": True
        },
        CreativeGenre.BLOG_POST: {
            "system": """Eres un blogger técnico que escribe contenido accesible y atractivo.
Combinas profundidad técnica con ejemplos prácticos y narrativa clara.""",
            "structure": ["hook", "problema", "solución", "ejemplos", "conclusión"],
            "tone": "conversational but informed"
        }
    }
    
    @classmethod
    def build_system_prompt(cls, genre_config: GenreConfig) -> str:
        """Construye el prompt de sistema basado en género y tono"""
        template = cls.GENRE_TEMPLATES.get(genre_config.genre)
        if not template:
            raise ValueError(f"Género no soportado: {genre_config.genre}")
        
        system = template["system"]
        
        # Agregar tono
        tone_instructions = {
            Tone.FORMAL: "Usa lenguaje formal y preciso.",
            Tone.INFORMAL: "Usa lenguaje casual y accesible, como hablando con un amigo.",
            Tone.SERIOUS: "Mantén tono serio y reflexivo.",
            Tone.HUMOROUS: "Incorpora humor natural, no forzado.",
            Tone.ROMANTIC: "Captura emoción y tensión romántica.",
            Tone.DARK: "Explora temas oscuros con profundidad psicológica.",
            Tone.OPTIMISTIC: "Mantén visión esperanzadora y positivas.",
            Tone.NOSTALGIC: "Evoca recuerdos con melancolía cálida.",
            Tone.SARCASTIC: "Usa sarcasmo inteligente y wit.",
        }
        
        system += f"\n\nTono: {tone_instructions.get(genre_config.tone, '')}"
        
        # Agregar estilo
        style_instructions = {
            WritingStyle.MINIMALIST: "Escribe con el estilo de Hemingway: corto, directo, concreto. Evita adjetivos innecesarios.",
            WritingStyle.BAROQUE: "Usa descripción rica en detalles sensoriales. Desarrolla escenas completamente.",
            WritingStyle.JOURNALISTIC: "Sigue estilo AP: clara, concisa, en pirámide invertida.",
            WritingStyle.ACADEMIC: "Usa precisión académica, citas cuando apropiado, estructura lógica.",
            WritingStyle.CREATIVE: "Emplea recursos literarios: metáforas, símil, personificación.",
            WritingStyle.TECHNICAL: "Prioriza claridad y precisión sobre ornamento.",
        }
        
        system += f"\n\nEstilo: {style_instructions.get(genre_config.style, '')}"
        
        return system
    
    @classmethod
    def build_user_prompt(cls, request: CreativeWritingRequest) -> str:
        """Construye el prompt de usuario con estructura"""
        template = cls.GENRE_TEMPLATES.get(request.genre_config.genre)
        
        prompt_parts = []
        
        # Agregar constraints del género
        constraints = []
        if request.genre_config.max_adjectives_per_noun:
            constraints.append(f"Máximo {request.genre_config.max_adjectives_per_noun} adjetivos por sustantivo.")
        if request.genre_config.max_adverbs_per_verb:
            constraints.append(f"Máximo {request.genre_config.max_adverbs_per_verb} adverbios por verbo.")
        if request.genre_config.sentence_length_range:
            min_w, max_w = request.genre_config.sentence_length_range
            constraints.append(f"Oraciones de {min_w}-{max_w} palabras.")
        
        # Agregar world building si existe
        if request.world_building:
            wb_section = "\n\n## Contexto del Mundo\n"
            for key, value in request.world_building.items():
                wb_section += f"- {key}: {value}\n"
            prompt_parts.append(wb_section)
        
        # Agregar character profiles si existen
        if request.character_profiles:
            char_section = "\n\n## Personajes\n"
            for i, char in enumerate(request.character_profiles):
                char_section += f"\n{i+1}. {char.get('name', 'Personaje')}: {char.get('description', '')}\n"
                if 'motivation' in char:
                    char_section += f"   Motivación: {char['motivation']}\n"
                if 'flaw' in char:
                    char_section += f"   Debilidad: {char['flaw']}\n"
            prompt_parts.append(char_section)
        
        # Agregar constraints explícitos
        if request.constraints:
            prompt_parts.append(f"\n\n## Restricciones Adicionales\n" + "\n".join(f"- {c}" for c in request.constraints))
        
        # Combinar
        full_prompt = f"{request.prompt}\n" + "\n".join(prompt_parts)
        
        return full_prompt


class CreativityController:
    """
    Controla los parámetros de generación creativa.
    Ajusta dinámicamente según el contenido deseado.
    """
    
    # Parámetros óptimos por tipo de tarea
    TASK_CONFIGS = {
        # Tareas que requieren precisión
        "factual": CreativityConfig(temperature=0.3, top_p=0.85, top_k=20),
        "instruction": CreativityConfig(temperature=0.5, top_p=0.9, top_k=40),
        
        # Tareas creativas
        "brainstorm": CreativityConfig(temperature=0.9, top_p=0.95, top_k=100),
        "story": CreativityConfig(temperature=0.75, top_p=0.92, top_k=60),
        "poetry": CreativityConfig(temperature=0.85, top_p=0.9, top_k=50),
        "dialogue": CreativityConfig(temperature=0.7, top_p=0.88, top_k=45),
        
        # Tareas de revisión
        "rewrite_formal": CreativityConfig(temperature=0.4, top_p=0.85, top_k=30),
        "rewrite_creative": CreativityConfig(temperature=0.8, top_p=0.92, top_k=70),
    }
    
    @classmethod
    def get_config_for_task(cls, task_type: str, custom_overrides: dict = None) -> CreativityConfig:
        """Obtiene configuración para un tipo de tarea"""
        base_config = cls.TASK_CONFIGS.get(task_type, cls.TASK_CONFIGS["story"])
        
        if custom_overrides:
            # Aplicar overrides
            for key, value in custom_overrides.items():
                if hasattr(base_config, key):
                    setattr(base_config, key, value)
        
        return base_config
    
    @classmethod
    def adjust_for_creativity_level(cls, config: CreativityConfig, level: float) -> CreativityConfig:
        """
        Ajusta configuración según nivel de creatividad deseado.
        level: 0.0 (muy conservador) a 1.0 (muy creativo)
        """
        import copy
        config = copy.deepcopy(config)
        
        # Mapear nivel a temperatura
        # nivel 0.0 → temp 0.3
        # nivel 0.5 → temp 0.7
        # nivel 1.0 → temp 1.0
        config.temperature = 0.3 + (level * 0.7)
        
        # Ajustar top_p inversamente (más creatividad = más exploración)
        config.top_p = 0.85 + (level * 0.12)
        
        return config


class CreativeWritingFramework:
    """

    """
    
    def __init__(self, llm_client=None):

⚠️ Los 3 Errores Más Comunes en Writing Creativo con LLMs

Error 1: Usar Highest Temperature Para Todo

El error más común. La gente pone temperature=1.0 o incluso temperature=1.5 pensando que así получится "más creatividad".

Problema: Con temperatura alta, el modelo empieza a muestrear tokens casi aleatorios. El resultado es texto incoherente, frases que no van a ningún lado, y repeticiones extrañas.

Matemática: Con T=1.5, la distribución se aplana drásticamente:

softmax(logits / 1.5) ≈ distribución casi uniforme

Esto significa que tokens muy improbables tienen casi la misma probabilidad que los probables.

Solución: Usar temperature entre 0.6-0.9 para narrativa, 0.7-1.0 para poesía. Ajustar según el efecto deseado:

  • Diálogos intensos: 0.65-0.75 (claro, directo, natural)
  • Descripción literaria: 0.75-0.85 (rica pero controlada)
  • Poesía: 0.8-0.95 (más inesperado, más риск)
  • Brainstorming: 0.9-1.0 (máxima exploración)
# ❌ MAL: Todo con temperature altísima
response = llm.generate(prompt, temperature=1.2)

# ✅ BIEN: Ajustar por tipo de contenido
def get_temperature_for_content(content_type: str) -> float:
    temperatures = {
        "technical_documentation": 0.3,
        "business_email": 0.4,
        "narrative_prose": 0.75,
        "poetry": 0.85,
        "brainstorming": 0.95
    }
    return temperatures.get(content_type, 0.7)

Error 2: No Controlar Tone y Style

El segundo error más común. Pides "escribe una historia" sin especificar tone, style, vocabulary level, o genre constraints. El LLM hace lo que quiere — y tú no kontrolas el resultado.

Problema: Sin constraints de tono, obtienes texto genérico que podría ser cualquier cosa. No hay voz distintiva, no hay personalidad.

Solución: Usar GenrePromptBuilder y Tone/Style enums para estructurar exactamente lo que quieres:

# ❌ MAL: Prompt vago
prompt = "Escribe una historia sobre un detective"

# ✅ BIEN: Prompt estructurado con tono y estilo
genre = GenreConfig(
    genre=CreativeGenre.NARRATIVE,
    tone=Tone.DARK,
    style=WritingStyle.MINIMALIST,
    vocabulary_level="complex"
)

request = CreativeWritingRequest(
    prompt="Escribe una historia sobre un detective que investiga su propio pasado",
    genre_config=genre,
    creativity=CreativityConfig(temperature=0.75)
)

Error 3: No Evaluar la Creatividad de Forma Apropiada

El tercer error: generar texto y no tener forma de medir si es "bueno" o "creativo". La gente lo califica subjetivamente — esto no escala.

Problema: Sin métricas objetivas, no puedes hacer A/B testing, no puedes comparar prompts, no puedes mejorar iterativamente.

Solución: Implementar métricas de evaluación creativas:

from collections import Counter
import math

class CreativityEvaluator:
    """Evalúa objetivamente la calidad creativa del texto generado"""
    
    @staticmethod
    def evaluate_diversity(text: str) -> float:
        """
        Mide diversidad léxica.
        Returns: 0.0 (todo repetido) a 1.0 (muy diverso)
        """
        words = text.lower().split()
        if not words:
            return 0.0
        unique_words = len(set(words))
        total_words = len(words)
        return unique_words / total_words
    
    @staticmethod
    def evaluate_repetition(text: str, n: int = 3) -> float:
        """
        Detecta repeticiones de n-grams.
        Returns: 0.0 (sin repeticiones) a 1.0 (muchas repeticiones)
        """
        words = text.lower().split()
        if len(words) < n:
            return 0.0
        
        ngrams = [tuple(words[i:i+n]) for i in range(len(words) - n + 1)]
        ngram_counts = Counter(ngrams)
        
        # Calcular ratio de repetición
        total_ngrams = len(ngrams)
        repeated = sum(1 for count in ngram_counts.values() if count > 1)
        
        return repeated / total_ngrams if total_ngrams > 0 else 0.0
    
    @staticmethod
    def evaluate_sentence_variation(text: str) -> float:
        """
        Mide variación en longitud de oraciones.
        Returns: 0.0 (todas iguales) a 1.0 (mucha variación)
        """
        sentences = text.split('.')
        sentences = [s.strip() for s in sentences if s.strip()]
        
        if len(sentences) < 2:
            return 0.0
        
        lengths = [len(s.split()) for s in sentences]
        mean_length = sum(lengths) / len(lengths)
        
        # Calcular coeficiente de variación
        variance = sum((l - mean_length) ** 2 for l in lengths) / len(lengths)
        std_dev = math.sqrt(variance)
        
        coefficient_of_variation = std_dev / mean_length if mean_length > 0 else 0
        
        # Normalizar a 0-1 (CV típicamente entre 0.3 y 1.0)
        return min(coefficient_of_variation / 0.7, 1.0)
    
    @classmethod
    def evaluate_creativity(cls, text: str) -> dict:
        """Evaluación completa de creatividad"""
        return {
            "diversity_score": cls.evaluate_diversity(text),
            "repetition_score": cls.evaluate_repetition(text),
            "sentence_variation": cls.evaluate_sentence_variation(text),
            "overall_quality": cls._calculate_overall(text)
        }
    
    @staticmethod
    def _calculate_overall(text: str) -> float:
        """Calcula score overall de creatividad"""
        div = CreativityEvaluator.evaluate_diversity(text)
        rep = 1 - CreativityEvaluator.evaluate_repetition(text)  # Invertir: menos repetición = mejor
        var = CreativityEvaluator.evaluate_sentence_variation(text)
        
        # Ponderación: diversidad 40%, no-repetición 35%, variación 25%
        return (div * 0.4) + (rep * 0.35) + (var * 0.25)


# Uso
text = """El silencio era denso, como terciopelo negro que envuelve la ciudad. 
Los neonatos parpadeaban en la oscuridad, pintando las paredes con luz líquida.

📊 Resumen y Estrategia Final

Para hacer writing creativo con LLMs bien, la fórmula es:

  1. Entender la matemática: Temperatura, top-p, top-k son herramientas — no magic bullets. Usa cada una con propósito.
  2. Estructurar por género: Cada género tiene conventions. Respétalas o violarlas con intención.
  3. Controlar tono y estilo: No dejes que el LLM decida — tú decides.
  4. Evaluar objetivamente: Métricas sobre intuición.
