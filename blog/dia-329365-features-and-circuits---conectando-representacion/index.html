LLM Multi-Agent Systems — Lo que el 85% No Conoce y el 15% Usa para Coordinación Real

PuesResulta que en Colombia tenemos un dicho: "Uno para todos y todos para uno". Y resulta que eso mismo es exactamente lo que hacen los LLM Multi-Agent Systems cuando funcionan bien. Yo me acuerdo cuando empece a experimentar con esto y la diferencia era brutal — cuando tienes un solo agente, hace lo que puede; cuando tienes múltiples agentes coordinados, hacen lo que ninguno podría hacer solo. Eso sí, la cosa no es simplemente poner tres agentes a trabajar y ya. Hay que coordinarlos, asignarles roles, manejar la comunicación entre ellos y evitar que se pisen el trabajo. Hoy le cuento cómo funciona todo eso.

🎯 Qué Son los LLM Multi-Agent Systems

Un sistema multi-agente con LLMs es básicamente un grupo de modelos de lenguaje que trabajan juntos, cada uno con un rol específico, comunicándose entre sí para resolver problemas que son demasiado complejos para un solo agente. Piense en ello como un equipo de trabajo donde cada persona tiene su especialidad y se necesitan mutuamente para completar el proyecto.

La diferencia fundamental con un solo agente es que aquí no hay una sola toma de decisiones centralizada. En cambio, hay distribución de tareas, negociación entre agentes y comportamiento emergente que surge de las interacciones entre ellos. Eso es lo que los hace tan poderosos — y también lo que los hace tricky de diseñar correctamente.

Arquitectura Básica de un Sistema Multi-Agente

La estructura más común tiene tres componentes esenciales: los agentes propiamente dichos, un protocolo de comunicación entre ellos, y un mecanismo de coordinación que define cómo trabajan juntos. Cada agente tiene su propio prompt que define su rol, sus capacidades y sus limitaciones.

El protocolo de comunicación puede ser tan simple como mensajes directos o tan complejo como protocolos basados en estados. Lo importante es que cada agente sepa exactamente qué información puede enviar, a quién, y cómo interpretarla. Sin esto, terminamos con agentes que trabajan en direcciones opuestas sin siquiera saberlo.

from dataclasses import dataclass, field
from typing import List, Dict, Any, Optional
from enum import Enum
import asyncio

class AgentRole(Enum):
    COORDINATOR = "coordinator"
    RESEARCHER = "researcher"
    CRITIC = "critic"
    EXECUTOR = "executor"

@dataclass
class AgentMessage:
    sender: str
    receiver: str
    content: Any
    message_type: str
    timestamp: float = 0
    reply_to: Optional[str] = None

@dataclass
class Agent:
    name: str
    role: AgentRole
    system_prompt: str
    model: Any
    inbox: List[AgentMessage] = field(default_factory=list)
    
    def send_message(self, receiver: str, content: Any, msg_type: str = "info"):
        msg = AgentMessage(
            sender=self.name,
            receiver=receiver,
            content=content,
            message_type=msg_type
        )
        return msg
    
    async def think(self, context: Dict[str, Any]) -> str:
        prompt = f"{self.system_prompt}\n\nContexto: {context}"
        response = await self.model.generate(prompt)
        return response

class MultiAgentFramework:
    def __init__(self, agents: List[Agent]):
        self.agents = {a.name: a for a in agents}
        self.message_queue: List[AgentMessage] = []
        self.shared_context: Dict[str, Any] = {}
    
    async def start(self, task: str) -> Dict[str, Any]:
        coordinator = self._get_agent_by_role(AgentRole.COORDINATOR)
        
        # Coordinator descompone la tarea
        decomposition = await coordinator.think({
            "task": task,
            "action": "decompose",
            **self.shared_context
        })
        
        # Distribuir subtareas
        subtasks = self._parse_subtasks(decomposition)
        
        # Ejecutar en paralelo
        results = await asyncio.gather(*[
            self._execute_subtask(subtask) for subtask in subtasks
        ])
        
        # Coordinator agrega resultados
        final_result = await coordinator.think({
            "task": task,
            "action": "synthesize",
            "results": results,
            **self.shared_context
        })
        
        return {"result": final_result, "subtasks": results}
    
    def _get_agent_by_role(self, role: AgentRole) -> Agent:
        for agent in self.agents.values():
            if agent.role == role:
                return agent
        raise ValueError(f"No agent found with role {role}")
    
    async def _execute_subtask(self, subtask: Dict) -> Dict[str, Any]:
        agent_name = subtask["agent"]
        agent = self.agents.get(agent_name)
        if not agent:
            return {"error": f"Agent {agent_name} not found"}
        
        result = await agent.think({
            "subtask": subtask["description"],
            **self.shared_context
        })
        
        return {"agent": agent_name, "result": result}
    
    def _parse_subtasks(self, decomposition: str) -> List[Dict]:
        # Parser simple - en producción usar JSON o estructura más robusta
        lines = decomposition.strip().split("\n")
        subtasks = []
        for line in lines:
            if line.strip().startswith("-"):
                desc = line.strip()[1:].strip()
                # Asignar a agente basado en contexto o round-robin
                subtasks.append({"agent": "researcher", "description": desc})
        return subtasks

📐 Cómo Implementar Comunicación Entre Agentes

El protocolo de comunicación es el sistema nervioso del multi-agent framework. Sin comunicación clara, los agentes trabajan en silos y el sistema se degrada a un conjunto de actores independientes sin coordinación real.

Hay varios patrones de comunicación que funcionan bien. El más simple es broadcast: un agente envía un mensaje a todos los demás. Esto es útil para compartir información general pero no escala bien porque genera demasiado ruido. El segundo es direct messaging: un agente envía específicamente a otro. Esto es más privado y eficiente para conversaciones punto a punto.

El patrón más interesante es el de blackboard o pizarra compartida: hay un espacio común donde todos los agentes pueden escribir y leer información. Cada agente lee lo que necesita, contribuye con lo suyo, y el sistema evoluciona orgánicamente. Este patrón funciona especialmente bien cuando los agentes tienen Expertise complementario y no necesitan constantemente sincronizarse.

Protocolos de Interacción

Además de cómo se envían los mensajes, necesitamos definir cómo responden los agentes. Un patrón efectivo es el request-response: Agent A envía una solicitud a Agent B y espera una respuesta antes de proceder. Esto funciona bien para tareas secuenciales donde B depende de A.

Otro patrón es publish-subscribe: los agentes se suscriben a ciertos tipos de eventos y son notificados automáticamente cuando ocurren. Esto reduce acoplamiento porque los agentes no necesitan conocerse directamente — solo necesitan conocer el canal de eventos.

from typing import Callable, Dict, List, Any
from collections import defaultdict
import time

class MessageBus:
    """Sistema de comunicación entre agentes"""
    
    def __init__(self):
        self.subscribers: Dict[str, List[Callable]] = defaultdict(list)
        self.message_history: List[AgentMessage] = []
    
    def publish(self, topic: str, message: AgentMessage):
        """Publica un mensaje a un topic"""
        self.message_history.append(message)
        for callback in self.subscribers[topic]:
            callback(message)
    
    def subscribe(self, topic: str, callback: Callable[[AgentMessage], None]):
        """Suscribe un agente a un topic"""
        self.subscribers[topic].append(callback)
    
    def send_direct(self, from_agent: str, to_agent: str, 
                   content: Any, msg_type: str = "info"):
        """Envía mensaje directo a un agente específico"""
        msg = AgentMessage(
            sender=from_agent,
            receiver=to_agent,
            content=content,
            message_type=msg_type,
            timestamp=time.time()
        )
        self.publish(f"agent:{to_agent}", msg)
        return msg
    
    def broadcast(self, from_agent: str, content: Any, 
                  msg_type: str = "broadcast"):
        """Broadcast a todos los agentes"""
        msg = AgentMessage(
            sender=from_agent,
            receiver="*",
            content=content,
            message_type=msg_type,
            timestamp=time.time()
        )
        self.publish("broadcast", msg)
        return msg

class AgentProtocol:
    """Define protocolos de interacción entre agentes"""
    
    def __init__(self, agent: Agent, message_bus: MessageBus):
        self.agent = agent
        self.bus = message_bus
        self.pending_requests: Dict[str, asyncio.Future] = {}
        self._setup_subscriptions()
    
    def _setup_subscriptions(self):
        # Subscribe a mensajes directos
        self.bus.subscribe(f"agent:{self.agent.name}", self._handle_message)
        
        # Subscribe a broadcasts relevantes
        self.bus.subscribe("broadcast", self._handle_broadcast)
    
    async def _handle_message(self, msg: AgentMessage):
        if msg.message_type == "request":
            response = await self._process_request(msg)
            self.bus.send_direct(
                from_agent=self.agent.name,
                to_agent=msg.sender,
                content=response,
                msg_type="response"
            )
        elif msg.message_type == "response":
            future = self.pending_requests.get(msg.reply_to)
            if future:
                future.set_result(msg.content)
    
    async def _handle_broadcast(self, msg: AgentMessage):
        # Los agentes procesan broadcasts según su rol
        if msg.sender == self.agent.name:
            return  # No procesar propios broadcasts
        await self.agent.think({"broadcast": msg.content})
    
    async def request(self, to_agent: str, content: Any, 
                      timeout: float = 30) -> Any:
        """Hace un request y espera respuesta"""
        request_id = f"{self.agent.name}:{time.time()}"
        msg = AgentMessage(
            sender=self.agent.name,
            receiver=to_agent,
            content=content,
            message_type="request",
            timestamp=time.time(),
            reply_to=request_id
        )
        
        future = asyncio.Future()
        self.pending_requests[request_id] = future
        
        self.bus.publish(f"agent:{to_agent}", msg)
        
        try:
            return await asyncio.wait_for(future, timeout)
        except asyncio.TimeoutError:
            return {"error": "Request timeout"}
        finally:
            self.pending_requests.pop(request_id, None)

⚠️ Error 1: No Considerar la Arquitectura Multi-Agente

El primer error grueso que veo es pensar que multi-agente es simplemente poner varios agentes a trabajar sin estructura. Muchos asumen que si un agente puede hacer X, entonces tres agentes harán 3X. Eso no funciona así. Cada agente que agregamos aumenta la complejidad de coordinación exponencialmente porque hay más relaciones que gestionar.

Cuando no diseñas explícitamente la arquitectura, terminas con agentes que duplican trabajo, que se contradicen entre sí, o que simplemente no se comunican. El resultado es un sistema que es peor que tener un solo agente bien diseñado. He visto proyectos que intentan resolver esto añadiendo más agentes cuando el problema real es que no hay arquitectura.

Solución: Diseño Top-Down con Roles Explícitos

Antes de escribir código, define la arquitectura. Cuántos agentes necesitas realmente, qué roles van a cumplir, cómo se comunican entre sí, y qué pasa cuando hay conflictos. Un buen enfoque es empezar con un solo agente bien diseñado y solo escalar a multi-agente cuando demuestres que la tarea realmente requiere colaboración.

La decisión de ir a multi-agente debe ser motivada por la complejidad real de la tarea, no por la emoción de tener muchos agentes. Si puedes resolverlo con uno, usa uno. Multi-agente tiene costos de coordinación que solo valen la pena cuando hay beneficios claros de especialización o división del trabajo.

⚠️ Error 2: No Manejar Conflictos Entre Agentes

El segundo error es ignorar que los agentes van a disagree entre sí. Esto no es un bug — es una feature. Si dos agentes siempre están de acuerdo, probablemente uno no está agregando valor. El conflicto constructivo es lo que hace que un equipo sea mejor que la suma de sus partes.

Pero si no tienes mecanismos para manejar el conflicto, terminamos con agentes que discuten eternamente sin llegar a una conclusión, o con uno que domina sobre los demás sin evaluación real de mérito. También puede pasar que el sistema entre en ciclos de feedback donde cada agente refuerza las dudas del anterior, creando parálisis por análisis.

Solución: Protocolos de Resolución de Conflictos

Diseña explícitamente cómo se resuelven los desacuerdos. Un patrón efectivo es tener un agente crítico cuya función específica es evaluar las propuestas de los demás y señalar problemas. Otro patrón es usar votación o consenso con criterios definidos de antemano.

También ayuda tener mecanismos de timeout y fallback. Si dos agentes no pueden ponerse de acuerdo después de N intercambios, que intervenga un coordinador o que se aplique una regla de decisión por defecto. El objetivo no es eliminar el conflicto sino canalizarlo productivamente.

from enum import Enum
from typing import List, Tuple, Optional

class ConflictResolution(Enum):
    COORDINATOR_DECIDES = "coordinator"
    CRITIC_EVALUATES = "critic"
    VOTING = "voting"
    TIMEOUT_FALLBACK = "timeout"

class ConflictManager:
    """Maneja conflictos entre agentes"""
    
    def __init__(self, agents: Dict[str, Agent], 
                 resolution: ConflictResolution = ConflictResolution.COORDINATOR_DECIDES):
        self.agents = agents
        self.resolution = resolution
        self.max_iterations = 3
    
    async def resolve(self, proposals: List[Tuple[str, str]]) -> str:
        """
        Resuelve conflicto entre propuestas de múltiples agentes.
        Args:
            proposals: Lista de (agent_name, proposal) tuples
        Returns:
            Propuesta seleccionada
        """
        if len(proposals) == 1:
            return proposals[0][1]
        
        if self.resolution == ConflictResolution.COORDINATOR_DECIDES:
            return await self._coordinator_decides(proposals)
        elif self.resolution == ConflictResolution.CRITIC_EVALUATES:
            return await self._critic_evaluates(proposals)
        elif self.resolution == ConflictResolution.VOTING:
            return await self._voting(proposals)
        else:
            return proposals[0][1]
    
    async def _coordinator_decides(self, proposals: List[Tuple[str, str]]) -> str:
        coordinator = self.agents.get("coordinator")
        if not coordinator:
            return proposals[0][1]
        
        evaluation = await coordinator.think({
            "action": "resolve_conflict",
            "proposals": [{"agent": p[0], "proposal": p[1]} for p in proposals]
        })
        
        # Parsear evaluación y retornar propuestawinning
        for p in proposals:
            if p[1] in evaluation.lower():
                return p[1]
        return proposals[0][1]
    
    async def _critic_evaluates(self, proposals: List[Tuple[str, str]]) -> str:
        critic = self.agents.get("critic")
        if not critic:
            return proposals[0][1]
        
        scores = []
        for agent_name, proposal in proposals:
            score = await critic.think({
                "action": "evaluate",
                "proposal": proposal
            })
            scores.append((agent_name, proposal, score))
        
        # Seleccionar la de mayor score
        scores.sort(key=lambda x: x[2], reverse=True)
        return scores[0][1]
    
    async def _voting(self, proposals: List[Tuple[str, str]]) -> str:
        votes = defaultdict(int)
        for agent_name, _ in proposals:
            # Cada agente vota por la propuesta que no sea suya
            for other_agent, proposal in proposals:
                if other_agent != agent_name:
                    votes[proposal] += 1
                    break
        
        if not votes:
            return proposals[0][1]
        
        return max(votes.items(), key=lambda x: x[1])[0]

⚠️ Error 3: No Diseñar Protocolos de Comunicación

El tercer error es tratar la comunicación como algo que emerges naturalmente. No lo hace. Si no diseñas explícitamente los protocolos de comunicación, terminamos con agentes que se asumen cosas, que interpretan los mensajes de formas diferentes, o que simplemente no saben cuándo comunicar qué.

Esto causa problemas desde sutiles hasta catastróficos. En el mejor caso, hay ineficiencias porque los agentes repiten trabajo o esperan información. En el peor caso, el sistema toma decisiones incorrectas porque agentes diferentes tienen información diferente y no lo saben.

Solución: Especificar Contratos de Comunicación

Define qué información se comparte, cuándo, y en qué formato. Cada mensaje debe tener una estructura clara que el receptor pueda interpretar sin ambigüedad. Los protocolos deben ser explícitos sobre quién necesita saber qué y cuándo.

Un buen diseño de comunicación incluye: formatos de mensaje estándar, canales dedicados para diferentes tipos de información, mecanismos de confirmación de recepción, y logging para poder auditar qué se dijo y cuándo. Sí, es más trabajo de entrada, pero evita horas de debugging después.

from dataclasses import dataclass, field
from typing import Any, Dict, List, Optional
from datetime import datetime
import json

@dataclass
class CommunicationProtocol:
    """Define contratos de comunicación entre agentes"""
    
    name: str
    version: str
    message_types: Dict[str, Dict[str, Any]]
    channels: Dict[str, List[str]] = field(default_factory=dict)
    
    @classmethod
    def define_protocol(cls) -> "CommunicationProtocol":
        return cls(
            name="multi_agent_v1",
            version="1.0",
            message_types={
                "task_request": {
                    "required_fields": ["task_id", "description", "priority"],
                    "optional_fields": ["deadline", "constraints"],
                    "response_type": "task_response"
                },
                "task_response": {
                    "required_fields": ["task_id", "status", "result"],
                    "optional_fields": ["errors", "metadata"],
                    "expects_ack": True
                },
                "status_update": {
                    "required_fields": ["agent", "status", "timestamp"],
                    "optional_fields": ["progress", "blockers"],
                    "broadcast": True
                },
                "query": {
                    "required_fields": ["query_id", "question"],
                    "optional_fields": ["context"],
                    "response_type": "query_response"
                },
                "query_response": {
                    "required_fields": ["query_id", "answer", "confidence"],
                    "optional_fields": ["sources"],
                    "reply_to_required": True
                },
                "conflict_signal": {
                    "required_fields": ["agents_involved", "issue"],
                    "optional_fields": ["proposals"],
                    "escalates_to": "coordinator"
                }
            },
            channels={
                "tasks": ["coordinator", "executor", "researcher"],
                "status": ["*"],
                "conflicts": ["coordinator", "critic"],
                "queries": ["*"]
            }
        )
    
    def validate_message(self, msg: AgentMessage) -> Tuple[bool, Optional[str]]:
        """Valida que un mensaje cumpla con el protocolo"""
        msg_type = self.message_types.get(msg.message_type)
        if not msg_type:
            return False, f"Unknown message type: {msg.message_type}"
        
        # Validar campos requeridos
        if not isinstance(msg.content, dict):
            return False, "Message content must be a dictionary"
        
        required = msg_type.get("required_fields", [])
        for field_name in required:
            if field_name not in msg.content:
                return False, f"Missing required field: {field_name}"
        
        return True, None
    
    def format_message(self, msg_type: str, **kwargs) -> Dict[str, Any]:
        """Formatea un mensaje según el protocolo"""
        msg_def = self.message_types.get(msg_type)
        if not msg_def:
            raise ValueError(f"Unknown message type: {msg_type}")
        
        # Combinar requeridos con opcionales
        content = {k: v for k, v in kwargs.items() 
                   if k in msg_def.get("required_fields", []) 
                   or k in msg_def.get("optional_fields", [])}
        
        return {
            "type": msg_type,
            "protocol": self.name,
            "version": self.version,
            "timestamp": datetime.now().isoformat(),
            "content": content
        }
    
    def get_channel_for(self, message_type: str) -> List[str]:
        """Retorna los agentes que reciben este tipo de mensaje"""
        return self.channels.get(message_type, [])

# Implementación del sistema de comunicación
class AgentCommunicationSystem:
    """Sistema de comunicación que enforcing el protocolo"""
    
    def __init__(self, protocol: CommunicationProtocol):
        self.protocol = protocol
        self.message_log: List[Dict[str, Any]] = []
    
    def send(self, from_agent: str, to_agent: str, 
             msg_type: str, **content) -> Tuple[bool, Optional[str]]:
        msg_content = self.protocol.format_message(msg_type, **content)
        
        msg = AgentMessage(
            sender=from_agent,
            receiver=to_agent,
            content=msg_content,
            message_type=msg_type
        )
        
        valid, error = self.protocol.validate_message(msg)
        if not valid:
            return False, error
        
        self.message_log.append({
            "from": from_agent,
            "to": to_agent,
            "type": msg_type,
            "content": msg_content,
            "timestamp": datetime.now().isoformat()
        })
        
        return True, None
    
    def broadcast_status(self, agent: str, status: str, 
                         **kwargs) -> Tuple[bool, Optional[str]]:
        msg_content = self.protocol.format_message(
            "status_update",
            agent=agent,
            status=status,
            timestamp=datetime.now().isoformat(),
            **kwargs
        )
        
        msg = AgentMessage(
            sender=agent,
            receiver="*",
            content=msg_content,
            message_type="status_update"
        )
        
        valid, error = self.protocol.validate_message(msg)
        if valid:
            self.message_log.append({
                "from": agent,
                "to": "*",
                "type": "status_update",
                "content": msg_content,
                "timestamp": datetime.now().isoformat()
            })
        
        return valid, error

📊 Math: Complejidad de Coordinación en Multi-Agent Systems

Hay una forma de pensar formalmente sobre la complejidad de coordinar múltiples agentes. Si tenemos N agentes y cada par puede comunicarse, el número de posibles conexiones es O(N²). Esto crece rápido: con 5 agentes hay 10 conexiones potenciales, con 10 agentes hay 45, y así sucesivamente.

Pero el problema real no es solo el número de conexiones — es la complejidad de las interacciones. En un sistema bien diseñado, cada agente solo necesita comunicarse con un subconjunto de los demás. El ratio de comunicaciones reales a conexiones posibles es una medida de la eficiencia del diseño.

La complejidad temporal de ejecutar un sistema multi-agente también es interesante. Si las tareas pueden ejecutarse en paralelo, el tiempo total es determinado por el path crítico — la secuencia más larga de tareas dependientes. Si serializamos todo, el tiempo es la suma de todos los tiempos individuales. El speedup potencial es el tiempo serial dividido por el tiempo paralelo mínimo teórico.

La fórmula del speedup máximo teórico es: Speedup ≤ N / (1 + α(N-1)), donde α es el overhead de coordinación como fracción del tiempo de trabajo útil. Cuando α se acerca a 0, obtenemos speedup cercano a N. Cuando α se acerca a 1, el speedup se satura y agregar más agentes no ayuda.

import math

def coordination_overhead(n_agents: int, connectivity: float) -> float:
    """
    Calcula overhead de coordinación en sistema multi-agente.
    
    Args:
        n_agents: Número de agentes
        connectivity: Fracción de conexiones utilizadas (0 a 1)
    
    Returns:
        Overhead total de coordinación
    """
    # Conexiones potenciales: N*(N-1)/2
    potential_connections = n_agents * (n_agents - 1) / 2
    
    # Conexiones reales
    real_connections = potential_connections * connectivity
    
    # Overhead grows with log de conexiones (redes bien diseñadas)
    # y con conexiones reales (manutenção de estado)
    overhead = math.log(real_connections + 1) + real_connections * 0.1
    
    return overhead

def speedup_theoretical(n_agents: int, alpha: float) -> float:
    """
    Calcula speedup teórico dado overhead de coordinación.
    
    Args:
        n_agents: Número de agentes
        alpha: Overhead de coordinación como fracción (0 a 1)
    
    Returns:
        Speedup máximo teórico
    """
    if alpha >= 1:
        return 1.0  # Sin speedup si overhead es 100%
    
    # Amdahl's Law adaptada para multi-agente
    speedup = n_agents / (1 + alpha * (n_agents - 1))
    return speedup

def optimal_agents(task_complexity: float, agent_capability: float, 
                   coordination_overhead_per_agent: float) -> int:
    """
    Determina número óptimo de agentes para una tarea.
    
    Args:
        task_complexity: Complejidad de la tarea (tiempo serial)
        agent_capability: Capability por agente (throughput)
        coordination_overhead_per_agent: Overhead por agente agregado
    
    Returns:
        Número óptimo de agentes
    """
    # Tiempo por agente = task_complexity/n + coordination_overhead
    # Optimizar: min_n (task_complexity/n + n*overhead)
    
    # Derivando: optimal n = sqrt(task_complexity / overhead)
    optimal = math.sqrt(task_complexity * agent_capability / coordination_overhead_per_agent)
    return max(1, int(optimal))

# Ejemplo: 
# Tarea que toma 1000s serial, cada agente puede hacer 100 units/s,
# overhead de coordinación de 50s por agente
task_time = 1000.0
agent_throughput = 100.0

🔧 Asignación de Roles en la Práctica

Un sistema multi-agente efectivo tiene agentes con roles claros y complementarios. No se trata de tener muchos agentes haciendo variaciones del mismo trabajo — se trata de especialización genuina donde cada agente aporta algo que los demás no tienen.

El rol más importante es el coordinador. Este agente no necesariamente hace el trabajo más inteligente — pero es el que ve el panorama completo, descompone las tareas, y asegura que todo fluya hacia el objetivo final. Sin un buen coordinador, el sistema tiende a divergir o a concentrarse en detalles mientras pierde de vista lo importante.

El crítico es otro rol valioso. Su trabajo es evaluar las propuestas de los demás, señalar problemas potenciales, y proponer alternativas. Un buen crítico no bloquea — mejora. La diferencia es que el crítico ofrece soluciones, no solo problemas.

Los agentes ejecutores son los que hacen el trabajo pesado. Receptores, analizadores, generadores de código — todos los roles que transforman inputs en outputs útiles. Un sistema bien diseñado tiene un número limitado de ejecutores especializados, no un ejército de generalistas.

class RoleAssigner:
    """Asigna roles a agentes basado en capacidades y requisitos"""
    
    def __init__(self, agents: List[Agent]):
        self.agents = agents
        self.assignments: Dict[str, AgentRole] = {}
    
    def assign_roles(self, task_requirements: Dict[str, int]) -> Dict[Agent, AgentRole]:
        """
        Asigna roles óptimos basado en requisitos de la tarea.
        
        Args:
            task_requirements: Dict con role -> minimum_needed
        
        Returns:
            Dict de agente -> rol asignado
        """
        # Verificar que tenemos suficientes agentes
        total_needed = sum(task_requirements.values())
        if total_needed > len(self.agents):
            raise ValueError(f"Need {total_needed} agents, have {len(self.agents)}")
        
        # Para cada rol requerido, asignar el mejor agente disponible
        assignments = {}
        available_agents = list(self.agents)
        
        for role, count in sorted(task_requirements.items(), 
                                   key=lambda x: -x[1]):  # Priorizar roles con más demanda
            best_agents = self._select_best_for_role(available_agents, role)
            
            for i in range(count):
                if i < len(best_agents):
                    assignments[best_agents[i]] = role
                    available_agents.remove(best_agents[i])
        
        self.assignments = {a.name: r for a, r in assignments.items()}
        return assignments
    
    def _select_best_for_role(self, agents: List[Agent], 
                              role: AgentRole) -> List[Agent]:
        """Selecciona los mejores agentes para un rol específico"""
        # En implementación real, evaluar capabilities vs role requirements
        # Por ahora, selección round-robin ponderada por role match
        
        scored = []
        for agent in agents:
            score = self._role_match_score(agent, role)
            scored.append((score, agent))
        
        scored.sort(key=lambda x: -x[0])
        return [a for _, a in scored]
    
    def _role_match_score(self, agent: Agent, role: AgentRole) -> float:
        """Calcula qué tan bien un agente encaja en un rol"""
        # En producción, esto evaluaría capabilities del agente vs requisitos del rol
        if agent.role == role:
            return 1.0
        elif agent.role == AgentRole.COORDINATOR:
            return 0.5  # Coordinator puede hacer de muchas cosas
        else:
            return 0.1

🚀 Comportamiento Emergente en Multi-Agent Systems

Una de las cosas más fascinantes de los sistemas multi-agente es el comportamiento emergente. Esto es cuando el sistema en su conjunto exhibe capacidades o comportamientos que ningún agente individual tiene. No está diseñado explícitamente — surge de las interacciones entre componentes.

Ejemplos de comportamiento emergente incluyen: estrategias de resolución de problemas que ningún agente individual propuso, división espontánea del trabajo basada en eficiencia observada, y hastarudimentos de otros dominios como negoc handlesion o colaboración que los agentes desarrollan por su cuenta.

Lo importante es que el comportamiento emergente no se puede diseñar directamente — solo se puede crear el contexto donde pueda aparecer. Eso significa agentes con capacidades suficientes, protocolos de comunicación que permitan flexibilidad, y objetivos claros que den dirección sin imponer método.

Cómo Fomentar Comportamiento Emergente Positivo

Para que emerjan comportamientos útiles, necesitas tres cosas: diversidad de perspectivas entre los agentes, interacciones frecuentes que permitan que ideas se combinen, y presión selectiva que rewarded las mejores soluciones. Si los agentes son todos iguales, no hay nada nuevo que emerja. Si no interactúan, no hay combinación. Si no hay presión selectiva, no hay mejora.

También ayuda tener memoria compartida o acceso a información común. Los agentes que solo ven su propio trabajo no pueden construir sobre el trabajo de otros. Un blackboard o repositorio compartido permite que conocimientos parciales se combinen en soluciones completas.

class EmergentBehaviorFramework:
    """Framework para fomentar y detectar comportamiento emergente"""
    
    def __init__(self, agents: List[Agent], shared_context: Dict[str, Any]):
        self.agents = agents
        self.shared_context = shared_context
        self.interaction_log = []
        self.solution_history = []
    
    def run_iteration(self, task: str, max_interactions: int = 10) -> Dict[str, Any]:
        """Ejecuta una iteración del sistema con interacciones"""
        
        # Fase 1: Cada agente propone basado en su perspectiva
        proposals = {}
        for agent in self.agents:
            proposal = agent.think({
                "task": task,
                "context": self.shared_context,
                "phase": "propose"
            })
            proposals[agent.name] = proposal
        
        # Fase 2: Interacciones entre agentes
        for _ in range(max_interactions):
            # Seleccionar par de agentes para interactuar
            agent_a, agent_b = self._select_interaction_pair()
            
            # Intercambio de propuestas
            response = agent_b.think({
                "action": "respond_to_proposal",
                "from_agent": agent_a.name,
                "proposal": proposals[agent_a.name],
                "own_proposal": proposals[agent_b.name]
            })
            
            # Registrar interacción
            self.interaction_log.append({
                "from": agent_a.name,
                "to": agent_b.name,
                "proposal_a": proposals[agent_a.name],
                "response": response
            })
            
            # Actualizar propuesta si hay mejora
            if self._is_improvement(response, proposals[agent_a.name]):
                proposals[agent_a.name] = response
        
        # Fase 3: Síntesis final
        final_solutions = []
        for agent_name, proposal in proposals.items():
            quality = self._evaluate_solution(proposal, task)
            final_solutions.append({
                "agent": agent_name,
                "solution": proposal,
                "quality": quality
            })
        
        # Ordenar por calidad
        final_solutions.sort(key=lambda x: -x["quality"])
        self.solution_history.append(final_solutions)
        
        return {
            "best_solution": final_solutions[0] if final_solutions else None,
            "all_solutions": final_solutions,
            "n_interactions": len(self.interaction_log)
        }
    
    def _select_interaction_pair(self) -> Tuple[Agent, Agent]:
        """Selecciona par de agentes para interactuar"""
        # En producción, usar heurísticas basadas en
        # diversidad, expertise complementario, etc.
        import random
        return random.sample(self.agents, 2)
    
    def _is_improvement(self, new: str, old: str) -> bool:
        """Determina si new es mejora sobre old"""
        # Heurística simple: propuesta más larga suele tener más detalle
        # En producción, usar evaluación real
        return len(new) > len(old)
    
    def _evaluate_solution(self, solution: str, task: str) -> float:
        """Evalúa calidad de una solución"""
        # Placeholder - en producción usar métricas reales
        return len(solution) / 100.0
