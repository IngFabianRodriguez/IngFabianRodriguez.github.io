Video Understanding - Frames Y Temporalidad

11 de octubre de 2026
videotemporal3d-cnnlstm

El Problema Del Video

Una imagen vale mas que mil palabras, pero un video vale mas que mil imagenes. El problema es que analizar video es exponencialmente mas dificil que analizar imagenes estaticas.

Un video de 30 segundos a 30 FPS son 900 frames. Cada frame es una imagen de potentially millones de pixeles. Y no solo tienes que entender cada frame, sino que tienes que entender la relacion temporal entre ellos.

Como dice el dicho: "el video es la sucesion temporal de imagenes que cuenta una historia". Entender esa historia es el objetivo del Video Understanding.

El Desafio De La Temporalidad

Las CNNs standard funcionan bien para imagenes porque asumen que los pixeles tienen relaciones espaciales fijas. Para video, tienes que capturar:

  • Motion: como se mueven los objetos entre frames
  • Action: que accion esta ocurriendo en el video
  • Sequence: el orden de los eventos importa
  • Context: el significado depende del historial

La matematica basica para video es extension 3D de imagenes:

I(x, y, t) -> I(x, y, z, t)

Donde anadimos la dimension temporal z (o t, pero ya tenemos t para tiempo, entonces usualmente llamamos frames como z).

Arquitecturas 3D-CNN

La manera mas directa de procesar video es reemplazar convoluciones 2D con convoluciones 3D que operan sobre volumenes espaciotemporales.

import torch
import torch.nn as nn

class Conv3DBlock(nn.Module):
    """Bloque convolutional 3D para video."""
    
    def __init__(self, in_channels, out_channels, kernel_size, stride=1, padding=1):
        super().__init__()
        self.conv = nn.Conv3d(
            in_channels,
            out_channels,
            kernel_size=(kernel_size, kernel_size, kernel_size),
            stride=(stride, stride, stride),
            padding=(padding, padding, padding)
        )
        self.bn = nn.BatchNorm3d(out_channels)
        self.relu = nn.ReLU()
    
    def forward(self, x):
        return self.relu(self.bn(self.conv(x)))

class VideoCNN(nn.Module):
    """CNN 3D para clasificacion de video."""
    
    def __init__(self, num_classes):
        super().__init__()
        
        # Early layers
        self.conv1 = Conv3DBlock(3, 64, kernel_size=7, stride=2, padding=3)
        self.pool1 = nn.MaxPool3d(kernel_size=(1, 2, 2), stride=(1, 2, 2))
        
        # Residual blocks
        self.conv2 = self._make_layer(64, 128, 3)
        self.pool2 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))
        
        self.conv3 = self._make_layer(128, 256, 3)
        self.conv4 = self._make_layer(256, 512, 3)
        
        # Global pooling y clasificacion
        self.global_pool = nn.AdaptiveAvgPool3d((1, 1, 1))
        self.fc = nn.Linear(512, num_classes)
    
    def _make_layer(self, in_channels, out_channels, num_blocks):
        layers = []
        layers.append(Conv3DBlock(in_channels, out_channels, kernel_size=3))
        for _ in range(num_blocks - 1):
            layers.append(Conv3DBlock(out_channels, out_channels, kernel_size=3))
        return nn.Sequential(*layers)
    
    def forward(self, x):
        # x shape: (batch, channels, frames, height, width)
        x = self.pool1(self.conv1(x))
        x = self.pool2(self.conv2(x))
        x = self.conv3(x)
        x = self.conv4(x)
        x = self.global_pool(x)
        x = x.view(x.size(0), -1)
        return self.fc(x)

# Input: (batch, 3, 16, 224, 224) - 16 frames de 224x224
# Output: (batch, num_classes)

C3D: The Classic

El paper "Learning Spatiotemporal Features with 3D Convolutional Networks" (Tran et al., 2014) introdujo C3D, que uso 3D convoluciones para aprender features espaciotemporales.

La ventaja de C3D es que las convoluciones 3D capturan naturalmente la informacion de movimiento porque procesan volumenes de video directamente.

class C3D(nn.Module):
    """C3D Network - el clasico para video."""
    
    def __init__(self, num_classes):
        super().__init__()
        
        self.conv1 = nn.Conv3d(3, 64, kernel_size=3, padding=1)
        self.pool1 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))
        
        self.conv2 = nn.Conv3d(64, 128, kernel_size=3, padding=1)
        self.pool2 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))
        
        self.conv3a = nn.Conv3d(128, 256, kernel_size=3, padding=1)
        self.conv3b = nn.Conv3d(256, 256, kernel_size=3, padding=1)
        self.pool3 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))
        
        self.conv4a = nn.Conv3d(256, 512, kernel_size=3, padding=1)
        self.conv4b = nn.Conv3d(512, 512, kernel_size=3, padding=1)
        self.pool4 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))
        
        self.conv5a = nn.Conv3d(512, 512, kernel_size=3, padding=1)
        self.conv5b = nn.Conv3d(512, 512, kernel_size=3, padding=1)
        self.pool5 = nn.MaxPool3d(kernel_size=(2, 2, 2), stride=(2, 2, 2))
        
        self.fc6 = nn.Linear(8192, 4096)
        self.fc7 = nn.Linear(4096, num_classes)
        
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(0.5)
        
    def forward(self, x):
        x = self.relu(self.conv1(x))
        x = self.pool1(x)
        
        x = self.relu(self.conv2(x))
        x = self.pool2(x)
        
        x = self.relu(self.conv3a(x))
        x = self.relu(self.conv3b(x))
        x = self.pool3(x)
        
        x = self.relu(self.conv4a(x))
        x = self.relu(self.conv4b(x))
        x = self.pool4(x)
        
        x = self.relu(self.conv5a(x))
        x = self.relu(self.conv5b(x))
        x = self.pool5(x)
        
        x = x.view(x.size(0), -1)
        x = self.dropout(x)
        x = self.relu(self.fc6(x))
        x = self.dropout(x)
        x = self.fc7(x)
        
        return x

I3D: Inflating 2D to 3D

I3D (Inflated 3D) aprovecha modelos de imagen pre-entrenados "inflando" los pesos 2D a 3D:

W_3D = W_2D expanded along time dimension

def inflate_weights(weights_2d, kernel_size=7):
    """
    Infla pesos 2D a 3D repitiendo a lo largo del eje temporal.
    """
    # weights_2d shape: (out_channels, in_channels, H, W)
    # output shape: (out_channels, in_channels, T, H, W)
    weights_2d = weights_2d.unsqueeze(2)  # (out, in, 1, H, W)
    weights_3d = weights_2d.repeat(1, 1, kernel_size, 1, 1)  # (out, in, T, H, W)
    weights_3d = weights_3d / kernel_size  # Normalize
    return weights_3d

class I3D(nn.Module):
    """Inflated 3D ConvNet - usa pretrained 2D features."""
    
    def __init__(self, in_channels=3, num_classes=400):
        super().__init__()
        
        # Usamos InceptionV1 preentrenado en ImageNet
        self.features = nn.Sequential(
            Conv3DBlock(3, 64, kernel_size=7, stride=2, padding=3),
            nn.MaxPool3d(kernel_size=(2, 3, 3), stride=(2, 2, 2)),
            
            Conv3DBlock(64, 64, kernel_size=1),
            Conv3DBlock(64, 192, kernel_size=3, padding=1),
            nn.MaxPool3d(kernel_size=(2, 3, 3), stride=(2, 2, 2)),
            
            # Inception modules...
        )
        
        self.avg_pool = nn.AdaptiveAvgPool3d((None, 1, 1))
        self.dropout = nn.Dropout(0.5)
        self.fc = nn.Linear(1024, num_classes)
        
    def forward(self, x):
        x = self.features(x)
        x = self.avg_pool(x)
        x = x.squeeze(3)
        x = x.squeeze(3)
        x = self.dropout(x)
        x = self.fc(x)
        return x

Two-Stream Networks

Una arquitectura alternativa es usar dos flujos separados: uno para espacial (frame individual) y otro para temporal (optical flow):

class TwoStreamNetwork(nn.Module):
    """Two-Stream Network para video."""
    
    def __init__(self, num_classes):
        super().__init__()
        
        # Stream espacial (imagen RGB)
        self.spatial_stream = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=7, stride=2, padding=3),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=3, stride=2),
            # ... mas capas
        )
        
        # Stream temporal (optical flow)
        self.temporal_stream = nn.Sequential(
            nn.Conv2d(2, 64, kernel_size=7, stride=2, padding=3),  # 2 canales para flow
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=3, stride=2),
            # ... mas capas
        )
        
        # Fusion
        self.fc = nn.Linear(2048 * 2, num_classes)
        
    def forward(self, frames, optical_flow):
        # frames: (B, 3, H, W) - un solo frame o promedio
        # optical_flow: (B, 2, H, W) - optica flow apilado
        
        spatial_out = self.spatial_stream(frames)
        temporal_out = self.temporal_stream(optical_flow)
        
        # Concatenar y clasificar
        combined = torch.cat([spatial_out, temporal_out], dim=1)
        return self.fc(combined)

def compute_optical_flow(video_frames):
    """
    Calcula optical flow entre frames consecutivos.
    Usa Gunnar Farneback algorithm.
    """
    import cv2
    
    flows = []
    for i in range(len(video_frames) - 1):
        frame1 = cv2.cvtColor(video_frames[i], cv2.COLOR_RGB2GRAY)
        frame2 = cv2.cvtColor(video_frames[i+1], cv2.COLOR_RGB2GRAY)
        
        flow = cv2.calcOpticalFlowFarneback(
            frame1, frame2,
            None,
            0.5, 3, 15, 3, 5, 1.2, 0
        )
        flows.append(flow)
    
    return np.stack(flows)

LSTM para Secuencias de Video

Otra aproximacion es usar CNNs para extraer features por frame y luego usar LSTMs para modelar la dependencia temporal:

class CNN_LSTM(nn.Module):
    """CNN + LSTM para video classification."""
    
    def __init__(self, cnn_backbone, hidden_size=512, num_layers=2, num_classes=400):
        super().__init__()
        
        # CNN pre-entrenada para extraer features
        self.cnn = cnn_backbone
        self.feature_dim = self.cnn.output_dim
        
        # LSTM para dependencia temporal
        self.lstm = nn.LSTM(
            input_size=self.feature_dim,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=0.5,
            bidirectional=True
        )
        
        # Clasificador
        self.fc = nn.Linear(hidden_size * 2, num_classes)  # *2 por bidirectional
        
    def forward(self, x):
        # x: (batch, frames, channels, height, width)
        batch_size, num_frames, C, H, W = x.size()
        
        # Procesar cada frame con CNN
        x = x.view(batch_size * num_frames, C, H, W)
        features = self.cnn(x)  # (batch*frames, feature_dim)
        features = features.view(batch_size, num_frames, -1)  # (batch, frames, feature_dim)
        
        # LSTM sobre la secuencia
        lstm_out, (h_n, c_n) = self.lstm(features)
        
        # Usar el ultimo hidden state
        final_hidden = h_n[-1]  # (batch, hidden_size)
        
        # Clasificar
        return self.fc(final_hidden)

class AttentionLSTM(nn.Module):
    """LSTM con attention para video."""
    
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        
        self.lstm = nn.LSTM(input_size, hidden_size, batch_first=True, bidirectional=True)
        
        # Attention mechanism
        self.attention = nn.Sequential(
            nn.Linear(hidden_size * 2, hidden_size),
            nn.Tanh(),
            nn.Linear(hidden_size, 1)
        )
        
        self.fc = nn.Linear(hidden_size * 2, num_classes)
    
    def forward(self, x):
        # x: (batch, frames, features)
        
        lstm_out, _ = self.lstm(x)  # (batch, frames, hidden*2)
        
        # Calculate attention weights
        attn_weights = self.attention(lstm_out)  # (batch, frames, 1)
        attn_weights = torch.softmax(attn_weights, dim=1)
        
        # Weighted sum
        context = torch.sum(attn_weights * lstm_out, dim=1)  # (batch, hidden*2)
        
        return self.fc(context)

Video Transformers

Similar a como los transformers revolucionaron NLP, ahora estan revolucionando video:

class VideoTransformer(nn.Module):
    """Transformer para video sin CNN backbone."""
    
    def __init__(self, num_frames, patch_size=16, hidden_size=768, num_heads=12, num_layers=12, num_classes=400):
        super().__init__()
        
        self.num_frames = num_frames
        self.patch_size = patch_size
        self.hidden_size = hidden_size
        
        # Patch embedding (divide video en patches y aplana)
        # Asume video de forma (C, T, H, W)
        self.patch_embed = nn.Conv3d(
            3, hidden_size,
            kernel_size=(patch_size, patch_size, patch_size),
            stride=(patch_size, patch_size, patch_size)
        )
        
        # CLS token
        self.cls_token = nn.Parameter(torch.randn(1, 1, hidden_size))
        
        # Positional embedding
        self.pos_embed = nn.Parameter(torch.randn(1, num_frames + 1, hidden_size))
        
        # Transformer encoder
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=hidden_size,
            nhead=num_heads,
            dim_feedforward=hidden_size * 4,
            dropout=0.1,
            batch_first=True
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers)
        
        # Classification head
        self.fc = nn.Linear(hidden_size, num_classes)
        
    def forward(self, x):
        # x: (batch, channels, frames, height, width)
        B = x.size(0)
        
        # Patch embedding
        x = self.patch_embed(x)  # (B, hidden, T', H', W')
        x = x.flatten(2).transpose(1, 2)  # (B, T'*H'*W', hidden)
        
        # Add CLS token
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)
        
        # Add positional embedding
        x = x + self.pos_embed
        
        # Transformer
        x = self.transformer(x)
        
        # Use CLS token for classification
        cls_output = x[:, 0]
        
        return self.fc(cls_output)

class Timesformer(nn.Module):
    """TimeSformer: Transformer espacio-temporal para video."""
    
    def __init__(self, img_size=224, num_classes=400, num_frames=8):
        super().__init__()
        
        self.num_frames = num_frames
        self.patch_size = 16
        hidden_size = 768
        
        # Space-time attention分开
        self.space_attention = nn.MultiheadAttention(hidden_size, 12, batch_first=True)
        self.time_attention = nn.MultiheadAttention(hidden_size, 12, batch_first=True)
        
        # Patch embedding
        self.patch_embed = nn.Conv2d(3, hidden_size, kernel_size=patch_size, stride=patch_size)
        
        # Positional embeddings
        self.space_pos_embed = nn.Parameter(torch.randn(1, (img_size // 16) ** 2, hidden_size))
        self.time_pos_embed = nn.Parameter(torch.randn(1, num_frames, hidden_size))
        
        # ... transformer layers ...
        
    def forward(self, x):
        # x: (B, T, C, H, W)
        B, T = x.size(0), x.size(1)
        
        # Procesar frames independientemente primero
        x = x.view(B * T, C, H, W)
        x = self.patch_embed(x)  # (B*T, num_patches, hidden)
        
        # D-T (Divided Space-Time) attention
        # Primero attention espacial
        x = x + self.space_pos_embed
        x = self.space_attention(x, x, x)[0]
        
        # Luego attention temporal
        x = x.view(B, T, -1) + self.time_pos_embed
        x = x.view(B * T, -1, self.hidden_size)
        x = self.time_attention(x, x, x)[0]
        
        # Pooling y classification
        x = x.mean(dim=0)
        return self.fc(x)

Optical Flow: Capturando Movimiento

El optical flow es fundamental para entender video. Representa el movimiento aparente entre frames:

I(x, y, t) = I(x + dx, y + dy, t + dt)

El algoritmo de Horn-Schunck resuelve:

E = (I_x u + I_y v + I_t)^2 + alpha * (||nabla u||^2 + ||nabla v||^2)

def horn_schunck_flow(image1, image2, alpha=1.0, iterations=100):
    """
    Calcula optical flow usando el metodo de Horn-Schunck.
    """
    # Calcular gradientes
    Ix = (image1[:, :, 1:] + image2[:, :, 1:]) / 2
    Iy = (image1[:, 1:, :] + image2[:, 1:, :]) / 2
    It = image2 - image1
    
    # Inicializar u, v con ceros
    u = np.zeros_like(image1)
    v = np.zeros_like(image1)
    
    # Iterar
    for _ in range(iterations):
        # Promedio local de u y v
        u_avg = filter2d(u)  # Convolucion con kernel 3x3
        v_avg = filter2d(v)
        
        # Actualizar
        denominator = Ix**2 + Iy**2 + alpha**2
        u = u_avg - Ix * (Ix * u_avg + Iy * v_avg + It) / denominator
        v = v_avg - Iy * (Ix * u_avg + Iy * v_avg + It) / denominator
    
    return u, v

def filter2d(image):
    """Filtro de promedio 3x3."""
    kernel = np.array([[1, 2, 1], [2, 4, 2], [1, 2, 1]]) / 16.0
    return convolve2d(image, kernel, mode='same')

Resumen

El Video Understanding es uno de los problemas mas desafiantes en computer vision porque requiere:

  • Capturar movimiento: optical flow, 3D convolutions
  • Modelar temporalidad: LSTMs, Transformers
  • Combinar espacial y temporal: two-stream networks, I3D
  • Escala computacional: videos son enormes comparados con imagenes

Las arquitecturas modernas como TimeSformer y Video Transformers estan pushing the boundaries, pero el field sigue siendo muy activo.
