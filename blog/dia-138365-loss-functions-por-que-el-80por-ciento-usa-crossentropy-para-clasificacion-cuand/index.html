Fundamentos Teóricos

Vamos paso a paso. Entender las Loss Functions es entender qué está optimizando tu red realmente. Cada loss tiene supuestos sobre la distribución de tus datos y la tarea.

CrossEntropy vs Categorical Cross-Entropy

Primero lo primero: CrossEntropy y Categorical Cross-Entropy son la MISMA función. El nombre "Categorical" solo clarifica que estamos ante problemas de clasificación con múltiples clases mutuamente excluyentes.

$$\mathcal{L}_{CE} = -\sum_{c=1}^{C} y_c \log(\hat{y}_c)$$

Donde:

  • C = número de clases
  • y_c = label verdadero (1 para la clase correcta, 0 para las demás)
  • hat{y}_c = probabilidad predicha para la clase c

La implementación en PyTorch

PyTorch implementa CrossEntropyLoss como:

$$\text{CrossEntropyLoss}(x, y) = \text{LogSoftmax}(x) + \text{NLLLoss}(y)$$

Es decir: primero aplicas log-softmax a las logits, luego Negative Log Likelihood. Esto es NUMÉRICAMENTE ESTABLE porque log-softmax evita overflow/underflow que pasaría si hicieras softmax + log por separado.

Binary Cross-Entropy (BCE)

BCE es para multi-label classification o regresión logística binaria:

$$\mathcal{L}_{BCE} = -\frac{1}{N}\sum_{i=1}^{N} [y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]$$

Diferencia crítica: BCE trata cada label como INDEPENDIENTE. En CrossEntropy, los labels son MUTUAMENTE EXCLUYENTES (solo una clase es correcta). Si tienes 3 classes y una imagen es "gato", BCE te puede dar alta probabilidad para "perro" Y "gato" al mismo tiempo. CrossEntropy no — solo una clase puede ganar.

Focal Loss — Para Class Imbalance Severo

Lin et al. propuso Focal Loss en 2017 para detectar objetos donde hay extreme class imbalance (ej: 99% background, 1% objects):

$$\mathcal{L}_{FL} = -\alpha_t (1 - \hat{y}_t)^\gamma \log(\hat{y}_t)$$

Donde gamma (gamma) es el focusing parameter:

  • gamma = 0: Focal Loss = CrossEntropy normal
  • gamma > 0: Reduce el weight de ejemplos "fáciles" (alta confianza), enfoca en los difíciles
  • gamma = 2: Valor típico en detección de objetos

Label Smoothing

Label Smoothing reemplaza los labels "duros" (0 y 1) con valores "blandos":

$$y_{smooth} = y \cdot (1 - \epsilon) + \frac{\epsilon}{C}$$

Donde epsilon es el smoothing factor (típico: 0.1). Esto previene overconfidence y mejora generalization en datasets grandes.

import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from typing import Optional


# ─────────────────────────────────────────────
# 1. CROSS-ENTROPY DESDE CERO (LOG-SOFTMAX + NLL)
# ─────────────────────────────────────────────

class CrossEntropyLossFromScratch(nn.Module):
    """
    Implementación manual de CrossEntropyLoss de PyTorch.
    
    math: CrossEntropyLoss(logits, target) = LogSoftmax(logits) + NLLLoss(target)
    
    PyTorch hace esto internamente por estabilidad numérica.
    """
    def __init__(self, reduction: str = 'mean'):
        super().__init__()
        self.reduction = reduction
    
    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        """
        Args:
            logits: (batch_size, num_classes) — raw outputs sin activar
            targets: (batch_size,) — class indices (no one-hot!)
        
        Returns:
            Scalar loss
        """
        # Paso 1: Log-Softmax (numéricamente estable)
        # log_softmax(x)_c = x_c - log(sum(exp(x_j)))
        # Restamos el max para evitar overflow
        log_probs = F.log_softmax(logits, dim=-1)  # (batch, classes)
        
        # Paso 2: NLL = -log(p_true)
        # Necesitamos solo el log_prob de la clase verdadera
        batch_size = logits.shape[0]
        
        # targets es un tensor de índices, no one-hot
        # gather toma el valor en el índice especificado
        loss_per_sample = -log_probs.gather(dim=1, index=targets.unsqueeze(1))
        loss_per_sample = loss_per_sample.squeeze(1)  # (batch,)
        
        # Paso 3: Reduction
        if self.reduction == 'mean':
            return loss_per_sample.mean()
        elif self.reduction == 'sum':
            return loss_per_sample.sum()
        else:  # 'none'
            return loss_per_sample


# Verificación rápida
def verify_cross_entropy():
    """Compara nuestra implementación con PyTorch."""
    torch.manual_seed(42)
    
    logits = torch.randn(8, 5)  # batch=8, classes=5
    targets = torch.randint(0, 5, (8,))
    
    # Nuestra implementación
    our_loss = CrossEntropyLossFromScratch(reduction='mean')(logits, targets)
    
    # PyTorch implementation
    pytorch_loss = F.cross_entropy(logits, targets)
    
    print(f"Nuestra impl: {our_loss.item():.6f}")
    print(f"PyTorch impl: {pytorch_loss.item():.6f}")
    print(f"Diferencia: {abs(our_loss.item() - pytorch_loss.item()):.8f}")
    
    return torch.allclose(our_loss, pytorch_loss, atol=1e-5)


# ─────────────────────────────────────────────
# 2. FOCAL LOSS DESDE CERO
# ─────────────────────────────────────────────

class FocalLoss(nn.Module):
    """
    Focal Loss para class imbalance.
    
    Paper: Lin et al. "Focal Loss for Dense Object Detection" (ICCV 2017)
    
    math: FL(p_t) = -alpha_t * (1 - p_t)^gamma * log(p_t)
    
    Args:
        alpha: Class weight (default: None, puede ser tensor de weights)
        gamma: Focusing parameter (default: 2.0)
            gamma=0 → CrossEntropy normal
            gamma>0 → reduce peso de ejemplos fáciles
        reduction: 'mean', 'sum', 'none'
    """
    def __init__(self, alpha: Optional[torch.Tensor] = None, gamma: float = 2.0, 
                 reduction: str = 'mean'):
        super().__init__()
        self.alpha = alpha  # Puede ser tensor de class weights
        self.gamma = gamma
        self.reduction = reduction
    
    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        # Calcular probabilidades con softmax
        probs = F.softmax(logits, dim=-1)  # (batch, classes)
        
        # Obtener la probabilidad de la clase correcta (pt)
        # targets es (batch,) con índices de clase
        pt = probs.gather(dim=1, index=targets.unsqueeze(1)).squeeze(1)  # (batch,)
        
        # Focal weight: (1 - pt)^gamma
        focal_weight = (1 - pt).pow(self.gamma)  # (batch,)
        
        # Cross entropy per sample: -log(pt)
        ce_loss = F.cross_entropy(logits, targets, reduction='none')  # (batch,)
        
        # Focal loss = focal_weight * ce_loss
        focal_loss = focal_weight * ce_loss  # (batch,)
        
        # Aplicar alpha si existe
        if self.alpha is not None:
            # alpha es un tensor con weight por clase
            alpha_t = self.alpha.gather(dim=0, index=targets)  # (batch,)
            focal_loss = alpha_t * focal_loss
        
        # Reduction
        if self.reduction == 'mean':
            return focal_loss.mean()
        elif self.reduction == 'sum':
            return focal_loss.sum()
        return focal_loss


# ─────────────────────────────────────────────
# 3. LABEL SMOOTHING CROSS ENTROPY
# ─────────────────────────────────────────────

class LabelSmoothingCrossEntropy(nn.Module):
    """
    CrossEntropy con Label Smoothing.
    
    math: y_smooth = y * (1 - eps) + eps / C
           loss = -sum(y_smooth * log(probs))
    
    Args:
        epsilon: Smoothing factor (0.1 es típico, NUNCA > 0.3)
            epsilon=0 → vanilla cross entropy
            epsilon=1 → distribución uniforme (destruye learning)
    
    WARNING: epsilon > 0.3 esencialmente destruye el aprendizaje.
    """
    def __init__(self, epsilon: float = 0.1, reduction: str = 'mean'):
        super().__init__()
        self.epsilon = epsilon
        self.reduction = reduction
    
    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        num_classes = logits.shape[-1]
        
        # Convertir targets a one-hot
        # targets: (batch,) → targets_onehot: (batch, classes)
        targets_onehot = F.one_hot(targets, num_classes).float()
        
        # Label smoothing
        # y_smooth = y * (1 - eps) + eps / C
        with torch.no_grad():
            smooth_targets = targets_onehot * (1 - self.epsilon) + self.epsilon / num_classes
        
        # Log-softmax de las logits
        log_probs = F.log_softmax(logits, dim=-1)  # (batch, classes)
        
        # Cross entropy con targets suaves
        loss = -smooth_targets * log_probs  # (batch, classes)
        loss = loss.sum(dim=-1)  # (batch,) — sum sobre clases
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        return loss


# ─────────────────────────────────────────────
# 4. WEIGHTED CROSS-ENTROPY
# ─────────────────────────────────────────────

class WeightedCrossEntropyLoss(nn.Module):
    """
    CrossEntropy con class weights para imbalance.
    
    Útil cuando tienes desbalance severo de clases
    y no quieres usar oversampling.
    
    math: loss = -weight_c * y_c * log(p_c)
    
    Args:
        weights: Tensor de shape (C,) con peso por clase
            weight_c > 1: la clase c es más importante
            weight_c < 1: la clase c es menos importante
    """
    def __init__(self, weights: Optional[torch.Tensor] = None, reduction: str = 'mean'):
        super().__init__()
        self.weights = weights  # (num_classes,)
        self.reduction = reduction
    
    def forward(self, logits: torch.Tensor, targets: torch.Tensor) -> torch.Tensor:
        # Cross entropy con weight por clase
        loss = F.cross_entropy(logits, targets, weight=self.weights, reduction='none')
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        return loss

# 5. CONTRASTIVE LOSS PARA METRIC LEARNING
# ─────────────────────────────────────────────

class ContrastiveLoss(nn.Module):
    """
    Contrastive Loss para metric learning (FaceNet, etc).
    
    Mantiene embeddings de la misma clase cercanos,
    embeddings de clases diferentes separados.
    
    math: L = (1-y) * d² + y * max(0, margin - d)²
    
    donde d = ||f1 - f2||₂ (distancia euclidiana)
    
    Args:
        margin: Margin mínimo entre clases diferentes (típico: 1.0 o 2.0)
    """
    def __init__(self, margin: float = 1.0):
        super().__init__()
        self.margin = margin
    
    def forward(self, embeddings1: torch.Tensor, embeddings2: torch.Tensor, 
                labels: torch.Tensor) -> torch.Tensor:
        """
        Args:
            embeddings1: (batch, embedding_dim)
            embeddings2: (batch, embedding_dim)
            labels: (batch,) — 1 si son misma clase, 0 si diferente
        """
        # Distancia euclidiana
        distances = F.pairwise_distance(embeddings1, embeddings2)  # (batch,)
        
        # Same class (label=1): want small distance
        # Different class (label=0): want distance > margin
        same_class_loss = labels * distances.pow(2)
        diff_class_loss = (1 - labels) * F.relu(self.margin - distances).pow(2)
        
        loss = same_class_loss + diff_class_loss
        return loss.mean()

def compare_losses():
    """

    Muestra cómo cada uno responde a imbalance.
    """
    print("=" * 60)
    print("LOSS FUNCTIONS COMPARISON")
    print("=" * 60)
    
    # Simular scenario con imbalance (clase 0 mucho más frecuente)
    torch.manual_seed(42)
    
    # 100 samples, 3 classes, imbalance: clase 0 = 70%, clase 1 = 20%, clase 2 = 10%
    batch_size = 100
    num_classes = 3
    logits = torch.randn(batch_size, num_classes)
    
    # Targets con imbalance
    targets = torch.zeros(batch_size, dtype=torch.long)
    targets[:70] = 0  # 70 samples clase 0
    targets[70:90] = 1  # 20 samples clase 1
    targets[90:] = 2  # 10 samples clase 2
    
    # Class weights para este imbalance específico
    class_weights = torch.tensor([1.0, 3.5, 10.0])  # inverso a frecuencia
    
    # Losses
    ce = F.cross_entropy(logits, targets)
    ce_weighted = F.cross_entropy(logits, targets, weight=class_weights)
    focal = FocalLoss(gamma=2.0)(logits, targets)
    label_smooth = LabelSmoothingCrossEntropy(epsilon=0.1)(logits, targets)
    
    print(f"Standard CE:          {ce.item():.4f}")
    print(f"Weighted CE:          {ce_weighted.item():.4f}")
    print(f"Focal Loss (γ=2):     {focal.item():.4f}")
    print(f"Label Smoothing (ε=0.1): {label_smooth.item():.4f}")
    
    # Qué pasa con epsilon > 0.3?
    print("\n--- Label Smoothing con epsilon alto (PELIGRO) ---")
    for eps in [0.3, 0.5, 0.7, 0.9]:
        ls_loss = LabelSmoothingCrossEntropy(epsilon=eps)(logits, targets)
        print(f"epsilon={eps}: {ls_loss.item():.4f} {'⚠️ DESTRUYE LEARNING' if eps > 0.3 else ''}")
    
    return True

El problema: CrossEntropy asume que solo UNA clase es correcta por muestra. En multi-label, múltiples labels pueden ser correctos simultáneamente (ej: una imagen puede ser "perro" Y "mamífero" Y "animal").

Error 2: No Usar Class Weights con Imbalance Severo — Tu Modelo Ignora las Clases Raras

El problema: Sin class weights, CrossEntropy treats all classes equally. Si tienes 99% clase 0 y 1% clase 1, el modelo aprende a predecir siempre 0 y obtiene 99% accuracy sin aprender nada útil.

# ✅ FIX 1: Calcular class weights desde el dataset
def compute_class_weights(dataset_targets, num_classes):
    """
    Computa pesos inversos a la frecuencia.
    Clase con 1000 samples → weight = 1/1000
    Clase con 10 samples → weight = 1/10 (10x más peso)
    """
    from collections import Counter
    counts = Counter(dataset_targets.numpy())
    total = len(dataset_targets)
    
    weights = []
    for c in range(num_classes):
        count = counts.get(c, 0)
        # Peso = total / (num_classes * count)
        # Suavizado con +1 para evitar división por cero
        weight = total / (num_classes * (count + 1))
        weights.append(weight)
    
    return torch.tensor(weights, dtype=torch.float32)

# ✅ FIX 2: Usar WeightedRandomSampler durante training
from torch.utils.data import WeightedRandomSampler

def create_balanced_sampler(dataset_targets):
    """Crea un sampler que balancea las clases automáticamente."""
    class_counts = torch.bincount(dataset_targets)
    class_weights = 1.0 / class_counts  # peso inverso
    
    # Weight para cada sample = peso de su clase
    sample_weights = class_weights[dataset_targets]
    
    sampler = WeightedRandomSampler(
        weights=sample_weights,
        num_samples=len(dataset_targets),
        replacement=True  # Oversample las clases minoritarias
    )
    return sampler

# epsilon=0.15 → moderado, bueno para datasets grandes
# epsilon=0.2 → máximo recomendado, solo para casos con mucho ruido

# Verificación: epsilon=0.1 significa:
# - Para clase correcta: weight = (1 - 0.1) + 0.1/10 = 0.91
# - Para clase incorrecta: weight = 0.1/10 = 0.01
# El modelo aún puede ser muyconfident en la clase correcta


# ✅ FIX 2: NO usar label smoothing cuando:
# - Tienes dataset pequeño (el smoothing no ayuda a generalizar)
# - Necesitas máxima precisión en una clase específica
# - Estás haciendo metric learning (contrastive losses ya regularizan)

def should_use_label_smoothing(dataset_size, num_classes, noise_level='low'):
    """
    Guía simple para decidir si usar label smoothing.
    """
    if dataset_size < 10000:
        return False, "Dataset muy pequeño"
    if noise_level == 'high':
        return True, epsilon=0.15, "Ayuda con labels ruidosos"
    if noise_level == 'medium':
        return True, epsilon=0.1, "Mejora generalización"
    else:  # low noise
        return True, epsilon=0.05, "Mínimo smoothing, solo para regularización"

Resumen y Cierre

Bueno parcero, vamos con el resumen del día:

  • CrossEntropy: Para multi-class classification (UNA clase correcta por muestra). NO para multi-label.
  • BCE/BCEWithLogitsLoss: Para multi-label classification o binary classification. Múltiples labels pueden ser True simultáneamente.
  • Focal Loss: Para class imbalance severo (detección de objetos). Gamma=2 es buen punto de partida.
  • Label Smoothing: epsilon ≤ 0.15 mejora generalización. epsilon > 0.3 DESTRUYE learning.
  • Class Weights: Siempre calcula e inyecta cuando tienes desbalance de clases.
