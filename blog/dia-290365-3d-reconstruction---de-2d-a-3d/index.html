LLM Prompt Optimization — Qué el 85% Hace Mal y Qué el 15% Hace Bien Para Mejorar Respuestas

17 de octubre de 2026
prompt-optimizationa-b-testingllmopsmetrics

Intro

El equipo reporta que el prompt "no funciona bien". Pides ejemplos. Te muestran 3 inputs donde la respuesta no fue buena. Cambias el prompt basado en esos 3 ejemplos. ¿Resultado? Funciona mejor para esos 3 casos, pero en producción empieza a fallar para 15 casos que antes funcionaban. Eso le pasa al 85% de los equipos que optimizan prompts.

El 15% que no tiene este problema hace algo diferente: optimiza sistemáticamente con datos, no con intuición. Mide antes de cambiar. Testea A/B en producción. Guarda métricas. Hoy te muestro cómo implementar un prompt optimization framework real, no el "voy a cambiar cosas y a ver qué pasa" que la mayoría hace.

Por qué la mayoria optimiza mal

El problema fundamental: no hay ground truth con prompts. No hay una respuesta "correcta". Así que la gente optimiza con:

  • Intuición: "Creo que agregando más contexto funcionará mejor"
  • Cherry-picking: 2-3 ejemplos que alguien seleccionó a mano
  • Anécdotas: "El cliente dijo que funcionaba mejor"

Esto es como ajustar un modelo de machine learning con un solo ejemplo. La matemática no cierra. Si cambiaste el prompt y no mediste el impacto en 1000+ запросов antes y después, no sabes si mejoraste o empeoraste. Solo sabes que seleccionaste algunos ejemplos que ahora funcionan mejor y no te importa los demás.

La optimización real de prompts sigue el mismo proceso que cualquier otra optimización de producto: hypotheses, experiments, data, iteration. Nada de "se siente bien". Todo de "tenemos un 12% de mejora en la métrica X con significance estadística".

"""
Prompt Optimization Framework
Sistema de A/B testing y optimización sistemática de prompts
"""

import os
import json
import hashlib
import time
from dataclasses import dataclass, field
from typing import Optional, Callable, Generator
from datetime import datetime
from collections import defaultdict
import random


@dataclass
class PromptVariant:
    """Una variante del prompt con metadata."""
    id: str
    name: str
    system_prompt: str
    user_template: str
    weight: float = 1.0  # Para weighted routing
    enabled: bool = True
    created_at: str = field(default_factory=lambda: datetime.utcnow().isoformat())
    metadata: dict = field(default_factory=dict)


@dataclass
class PromptMetrics:
    """Métricas acumuladas para una variante."""
    variant_id: str
    total_requests: int = 0
    successful_requests: int = 0
    failed_requests: int = 0
    total_latency_ms: float = 0.0
    token_usage: dict = field(default_factory=lambda: {"input": 0, "output": 0})
    
    # Métricas de calidad (labels humanos o LLM judge)
    quality_scores: list = field(default_factory=list)
    compliance_scores: list = field(default_factory=list)
    
    # Feedback directo
    thumbs_up: int = 0
    thumbs_down: int = 0
    
    # Categorías específicas del dominio
    category_results: dict = field(default_factory=lambda: defaultdict(lambda: {"correct": 0, "total": 0}))

    def accuracy(self) -> float:
        if not self.quality_scores:
            return 0.0
        return sum(self.quality_scores) / len(self.quality_scores)

    def avg_latency(self) -> float:
        if self.total_requests == 0:
            return 0.0
        return self.total_latency_ms / self.total_requests


class PromptOptimizer:
    """
    Framework para optimización sistemática de prompts.
    
    El flujo:
    1. Registrar variantes del prompt
    2. Routing A/B entre variantes
    3. Recolectar métricas automáticamente
    4. Statistical significance testing
    5. Promote mejor variante a production
    """

    def __init__(self, experiment_name: str, primary_metric: str = "accuracy"):
        self.experiment_name = experiment_name
        self.primary_metric = primary_metric
        self.variants: dict[str, PromptVariant] = {}
        self.metrics: dict[str, PromptMetrics] = {}
        self.active_variant: Optional[str] = None
        self.control_variant: Optional[str] = None

    def register_variant(self, variant: PromptVariant) -> str:
        """Registrar una nueva variante del prompt."""
        self.variants[variant.id] = variant
        self.metrics[variant.id] = PromptMetrics(variant_id=variant.id)
        return variant.id

    def set_control(self, variant_id: str):
        """Definir cuál variante es el control (baseline)."""
        if variant_id not in self.variants:
            raise ValueError(f"Variant {variant_id} not found")
        self.control_variant = variant_id

    def set_active(self, variant_id: str):
        """Definir cuál variante está activa para producción."""
        if variant_id not in self.variants:
            raise ValueError(f"Variant {variant_id} not found")
        self.active_variant = variant_id

    def select_variant(self, user_id: Optional[str] = None, deterministic: bool = True) -> PromptVariant:
        """
        Seleccionar qué variante usar para un request.
        
        Si deterministic=True, usa user_id para consistency
        (mismo usuario siempre ve la misma variante).
        """
        enabled_variants = [v for v in self.variants.values() if v.enabled]
        if not enabled_variants:
            raise ValueError("No enabled variants")
        
        if deterministic and user_id:
            # Hash para consistency
            h = int(hashlib.md5(f"{self.experiment_name}:{user_id}".encode()).hexdigest(), 16)
            idx = h % sum(v.weight for v in enabled_variants)
            cumulative = 0
            for variant in enabled_variants:
                cumulative += variant.weight
                if idx < cumulative:
                    return variant
        else:
            # Random weighted
            total_weight = sum(v.weight for v in enabled_variants)
            r = random.uniform(0, total_weight)
            cumulative = 0
            for variant in enabled_variants:
                cumulative += variant.weight
                if r < cumulative:
                    return variant
        
        return enabled_variants[0]

    def record_request(
        self,
        variant_id: str,
        latency_ms: float,
        success: bool,
        quality_score: Optional[float] = None,
        compliance_score: Optional[float] = None,
        tokens_used: dict = None,
        thumbs: Optional[int] = None,
        category: Optional[str] = None,
        correct: Optional[bool] = None
    ):
        """Registrar el resultado de un request."""
        m = self.metrics[variant_id]
        m.total_requests += 1
        
        if success:
            m.successful_requests += 1
        else:
            m.failed_requests += 1
        
        m.total_latency_ms += latency_ms
        
        if tokens_used:
            m.token_usage["input"] += tokens_used.get("input", 0)
            m.token_usage["output"] += tokens_used.get("output", 0)
        
        if quality_score is not None:
            m.quality_scores.append(quality_score)
        
        if compliance_score is not None:
            m.compliance_scores.append(compliance_score)
        
        if thumbs is not None:
            if thumbs > 0:
                m.thumbs_up += 1
            else:
                m.thumbs_down += 1
        
        if category and correct is not None:
            m.category_results[category]["total"] += 1
            if correct:
                m.category_results[category]["correct"] += 1

    def get_leaderboard(self) -> list[dict]:
        """Obtener ranking de variantes por métrica principal."""
        results = []
        for vid, m in self.metrics.items():
            variant = self.variants[vid]
            results.append({
                "id": vid,
                "name": variant.name,
                "requests": m.total_requests,
                self.primary_metric: getattr(m, self.primary_metric)(),
                "accuracy": m.accuracy(),
                "avg_latency_ms": m.avg_latency(),
                "success_rate": m.successful_requests / max(m.total_requests, 1),
                "thumbs_ratio": m.thumbs_up / max(m.thumbs_up + m.thumbs_down, 1),
                "enabled": variant.enabled
            })
        
        return sorted(results, key=lambda x: x[self.primary_metric], reverse=True)

    def statistical_significance(self, variant_a: str, variant_b: str) -> dict:
        """
        Calcular statistical significance entre dos variantes.
        Usa chi-squared para rates, t-test para scores continuos.
        """
        import math
        
        m_a = self.metrics[variant_a]
        m_b = self.metrics[variant_b]
        
        n_a = len(m_a.quality_scores)
        n_b = len(m_b.quality_scores)
        
        if n_a < 30 or n_b < 30:
            return {"significant": False, "reason": "Insufficient samples"}
        
        mean_a = sum(m_a.quality_scores) / n_a
        mean_b = sum(m_b.quality_scores) / n_b
        
        # Pooled variance
        var_a = sum((x - mean_a) ** 2 for x in m_a.quality_scores) / (n_a - 1)
        var_b = sum((x - mean_b) ** 2 for x in m_b.quality_scores) / (n_b - 1)
        
        pooled_se = math.sqrt(var_a / n_a + var_b / n_b)
        if pooled_se == 0:
            return {"significant": False, "reason": "No variance"}
        
        t_stat = (mean_a - mean_b) / pooled_se
        df = min(n_a - 1, n_b - 1)
        
        # Simplified significance check
        # (en producción usar scipy.stats.t.sf)
        effect_size = (mean_a - mean_b) / math.sqrt((var_a + var_b) / 2)
        
        return {
            "variant_a": variant_a,
            "variant_b": variant_b,
            "mean_a": mean_a,
            "mean_b": mean_b,
            "t_statistic": t_stat,
            "effect_size": effect_size,
            "significant": abs(effect_size) > 0.3 and min(n_a, n_b) >= 100,
            "confidence": "high" if min(n_a, n_b) >= 200 else "medium" if min(n_a, n_b) >= 100 else "low",
            "samples_a": n_a,
            "samples_b": n_b
        }

    def should_promote(self, variant_id: str, min_improvement: float = 0.05) -> dict:
        """Determinar si una variante debe ser promoted a production."""
        if not self.control_variant:
            return {"should_promote": False, "reason": "No control defined"}
        
        ctrl = self.metrics[self.control_variant]
        cand = self.metrics[variant_id]
        
        ctrl_accuracy = ctrl.accuracy()
        cand_accuracy = cand.accuracy()
        
        improvement = (cand_accuracy - ctrl_accuracy) / max(ctrl_accuracy, 0.01)
        
        sig_result = self.statistical_significance(self.control_variant, variant_id)
        
        return {
            "should_promote": (
                improvement >= min_improvement and
                sig_result.get("significant", False) and
                cand.total_requests >= 100
            ),
            "improvement_pct": improvement * 100,
            "variant_requests": cand.total_requests,
            "control_requests": ctrl.total_requests,
            "statistical_significance": sig_result,
            "reason": "All conditions met" if (
                improvement >= min_improvement and
                sig_result.get("significant", False) and
                cand.total_requests >= 100
            ) else f"Condition not met: improvement={improvement:.1%}, significant={sig_result.get('significant')}, requests={cand.total_requests}"
        }

            name="B v2 (more structured)",

Responde siguiendo este formato:

2. Explicación clara
3. Próximos pasos si aplica

Si no sabes algo, dice que no sabes.""",
            user_template="{user_input}",
            weight=1.0
        ))
        
        # Variante C: tono más casual colombiano
        self.optimizer.register_variant(PromptVariant(
            id="c-v3-colombian",
            name="C v3 (Colombian casual tone)",
            system_prompt="""Eres un asistente de soporte al cliente de TechStore.
Hablas con un tono friendly y cercano, como un amigo que te ayuda.
Usa expresiones colombianas naturales cuando sea appropriate.
Si no sabes algo, di la verdad.""",
            user_template="{user_input}",
            weight=1.0
        ))
        
        # Configurar
        self.optimizer.set_control("ctrl-v1")
        self.optimizer.set_active("ctrl-v1")
    
    def generate_with_tracking(
        self,
        user_input: str,
        user_id: str,
        llm_call_fn: Callable
    ) -> tuple[str, PromptVariant]:
        """Hacer un LLM call con tracking automático de métricas."""
        
        # Seleccionar variante
        variant = self.optimizer.select_variant(user_id=user_id, deterministic=True)
        
        # Hacer el call
        start = time.time()
        try:
            response = llm_call_fn(
                prompt=variant.user_template.format(user_input=user_input),
                system_prompt=variant.system_prompt
            )
            success = True
            latency_ms = (time.time() - start) * 1000
            
            # Aquí iría tu lógica de evaluación automática o LLM-as-judge
            quality_score = self._auto_evaluate(response.content, user_input)
            
        except Exception as e:
            response = LLMResponse(content=str(e), latency_ms=0, tokens_used={})
            success = False
            latency_ms = 0
            quality_score = None
        
        # Registrar métricas
        self.optimizer.record_request(
            variant_id=variant.id,
            latency_ms=latency_ms,
            success=success,
            quality_score=quality_score,
            tokens_used=response.tokens_used if hasattr(response, 'tokens_used') else {}
        )
        
        return response.content, variant
    
    def _auto_evaluate(self, response: str, user_input: str) -> float:
        """
        Evaluación automática simple.
        En producción, usa LLM-as-judge o labels humanos.
        """
        score = 0.5  # Default
        
        # Checks básicos
        if len(response) > 50:
            score += 0.1
        if len(response) < 1000:
            score += 0.1
        if any(word in response.lower() for word in ["gracias", "cómo", "puedo"]):
            score += 0.1
        
        return min(score, 1.0)
    
    def run_experiment_report(self):
        """Generar reporte del experimento actual."""
        leaderboard = self.optimizer.get_leaderboard()
        
        print(f"\n=== Prompt Experiment: {self.optimizer.experiment_name} ===\n")
        
        for rank, result in enumerate(leaderboard, 1):
            marker = " ← ACTIVE" if result["id"] == self.optimizer.active_variant else ""
            print(f"{rank}. {result['name']}{marker}")
            print(f"   Requests: {result['requests']}")
            print(f"   Accuracy: {result['accuracy']:.1%}")
            print(f"   Avg Latency: {result['avg_latency_ms']:.0f}ms")
            print(f"   Success Rate: {result['success_rate']:.1%}")
            print()
        
        # Análisis entre control y mejor performer
        if len(leaderboard) >= 2:
            best = leaderboard[0]
            if best["id"] != self.optimizer.control_variant:
                sig = self.optimizer.should_promote(best["id"])
                print(f"Recommendation for {best['name']}:")
                print(f"  Should promote: {sig['should_promote']}")
                print(f"  Reason: {sig['reason']}")

Métricas: qué medir y por qué

Métricas de calidad

No puedes optimizar lo que no mides. Para prompts de LLM, las métricas relevantes son:

  • Task Accuracy: ¿La respuesta cumple correctly el task?
  • Latency: ¿Cuánto tiempo tarda en responder?
  • Token Usage: ¿Cuántos tokens consume?
  • Compliance: ¿Sigue las instrucciones del prompt?
  • User Feedback: Thumbs up/down, ratings

El flujo de optimización iterativa

"""
Pipeline de optimización iterativa
"""

class PromptOptimizationPipeline:
    """
    Ejecuta el ciclo completo de optimización:
    1. Hipótesis → 2. Crear variante → 3. A/B test → 4. Analizar → 5. Iterar
    """
    
    def __init__(self, optimizer: PromptOptimizer):
        self.optimizer = optimizer
        self.experiment_history = []
    
    def create_hypothesis_variant(
        self,
        hypothesis: str,
        base_variant_id: str,
        change_description: str
    ) -> str:
        """
        Crear una nueva variante basada en una hipótesis.
        
        Ejemplo:
          hypothesis="El prompt necesita más contexto"
          change="Agregar ejemplos de few-shot"
        """
        base = self.optimizer.variants[base_variant_id]
        
        new_system = base.system_prompt + "\n\n" + change_description
        
        new_variant = PromptVariant(
            id=self._generate_id(hypothesis),
            name=f"Hypothesis: {hypothesis[:50]}",
            system_prompt=new_system,
            user_template=base.user_template,
            weight=1.0,
            metadata={"hypothesis": hypothesis, "change": change_description}
        )
        
        return self.optimizer.register_variant(new_variant)
    
    def run_experiment(
        self,
        variant_ids: list[str],
        min_duration_hours: int = 24,
        min_requests_per_variant: int = 100
    ) -> dict:
        """Ejecutar un experimento y retornar resultados."""
        
        start_time = time.time()
        
        while True:
            # Check si tenemos suficientes datos
            all_have_min = all(
                self.optimizer.metrics[vid].total_requests >= min_requests_per_variant
                for vid in variant_ids
            )
            
            elapsed_hours = (time.time() - start_time) / 3600
            
            if all_have_min and elapsed_hours >= min_duration_hours:
                break
            
            # Log progreso
            print(f"Waiting... {elapsed_hours:.1f}h elapsed, min requests: {min_requests_per_variant}")
            time.sleep(300)  # Check cada 5 minutos
        
        # Análisis final
        results = self._analyze_experiment(variant_ids)
        self.experiment_history.append(results)
        
        return results
    
    def _analyze_experiment(self, variant_ids: list[str]) -> dict:
        """Analizar resultados del experimento."""
        
        control = self.optimizer.control_variant
        best_variant = None
        best_accuracy = 0
        
        for vid in variant_ids:
            m = self.optimizer.metrics[vid]
            acc = m.accuracy()
            
            if acc > best_accuracy:
                best_accuracy = acc
                best_variant = vid
            
            # Statistical significance vs control
            if vid != control and control in variant_ids:
                sig = self.optimizer.statistical_significance(control, vid)
                print(f"{vid} vs {control}: effect_size={sig['effect_size']:.3f}, significant={sig['significant']}")
        
        return {
            "variants_tested": variant_ids,
            "best_variant": best_variant,
            "best_accuracy": best_accuracy,
            "recommendation": self.optimizer.should_promote(best_variant) if best_variant else None
        }
    
    def _generate_id(self, hypothesis: str) -> str:
        import uuid
        return f"hyp-{hashlib.md5(hypothesis.encode()).hexdigest()[:8]}"

Los 3 errores que el 85% comete

Error 1: No testear prompts sistemáticamente

El más común. Alguien dice "el prompt no está funcionando bien" y inmediatamente empiezan a hacer cambios sin datos. No hay baseline, no hay control, no hay forma de saber si el cambio fue una mejora o no.

La conversación va más o menos así:

  • "¿Cómo sabemos si el nuevo prompt es mejor?"
  • "Pues... se siente mejor cuando lo pruebo"
  • "¿Pero medimos algo?"
  • "No, pero confiamos en elfeeling"

Fix: A/B testing riguroso. Divide tu tráfico, mide cada variante, no hagas cambios en producción sin datos.

# El fix: antes de cambiar cualquier prompt, define tu experimento
optimizer = PromptOptimizer("payment-prompt-test")

optimizer.register_variant(PromptVariant(
    id="control",
    name="Current prompt",
    system_prompt="Provide customer support responses.",
    user_template="{input}"
))

optimizer.register_variant(PromptVariant(
    id="treatment",
    name="New prompt with examples",
    system_prompt="Provide customer support responses. Example: Q: 'Where's my order?' A: 'I can help you track your order...'",
    user_template="{input}"
))

# Solo hacer el cambio si hay mejora estadísticamente significativa
result = optimizer.should_promote("treatment", min_improvement=0.05)
if result["should_promote"]:
    optimizer.set_active("treatment")

Error 2: Cambiar el prompt basado en un solo ejemplo

Muestra 3 ejemplos al equipo. En uno, la respuesta no fue buena. Inmediatamente deciden cambiar el prompt para resolver ese caso específico. El resultado: el prompt ahora sí funciona para esos 3 ejemplos, pero falla para 20 que antes funcionaban.

Esto esoverfitting alExampleset. Si optimizas para 3 casos, estás sacrificando los demás.

Fix: Evaluar en datos grandes antes de decidir. Si no tienes 100+ ejemplos de test, no tienes enough data paraoptimizar. Recolecta más primero.

# Evaluar en dataset grande antes de decidir
TEST_DATASET = load_json("test_cases.json")  # 100+ casos

def evaluate_variant(variant_id: str, test_cases: list) -> dict:
    """Evaluar variante en todo el dataset, no cherry-picked examples."""
    
    results = []
    for case in test_cases:
        response = call_llm(
            prompt=case["input"],
            system_prompt=variants[variant_id].system_prompt
        )
        
        # Evaluación automática (o LLM-as-judge)
        score = evaluate(response, case["expected"])
        results.append({"input": case["input"], "score": score})
    
    return {
        "variant_id": variant_id,
        "avg_score": mean([r["score"] for r in results]),
        "p10_score": percentile([r["score"] for r in results], 10),  # No sacrifiques los percentiles bajos
        "p50_score": percentile([r["score"] for r in results], 50),
        "p90_score": percentile([r["score"] for r in results], 90),
        "total_tested": len(results)
    }

# Si el promedio mejora pero el p10 empeora, NO haces el cambio
ctrl_results = evaluate_variant("control", TEST_DATASET)
treat_results = evaluate_variant("treatment", TEST_DATASET)

print(f"Control: avg={ctrl_results['avg_score']:.2f}, p10={ctrl_results['p10_score']:.2f}")
print(f"Treatment: avg={treat_results['avg_score']:.2f}, p10={treat_results['p10_score']:.2f}")

if treat_results['p10_score'] < ctrl_results['p10_score'] - 0.05:
    print("❌ NO PROMOVE: el tratamiento empeora los casos difíciles")

Error 3: No tener métricas de prompt quality

¿Cómo sabes que tu prompt mejoró? Si no tienes métricas concretas, no lo sabes. Solo tienes feelings.

El 85% no tiene respuesta a "¿cómo está performando el prompt hoy?" porque nunca estableció qué medir.

Fix: Define métricas antes de optimizar. Mínimo:

  • Token usage

# Dashboard de métricas en tiempo real
class PromptMetricsDashboard:
    """Simple dashboard para trackear métricas de prompts."""
    
    def __init__(self, optimizer: PromptOptimizer):
        self.optimizer = optimizer
    
    def render(self) -> str:
        leaderboard = self.optimizer.get_leaderboard()
        
        output = ["```"]
        output.append(f"Prompt Optimization Dashboard: {self.optimizer.experiment_name}")
        output.append("=" * 60)
        
        for entry in leaderboard:
            variant = self.optimizer.variants[entry["id"]]
            marker = "← ACTIVE" if entry["id"] == self.optimizer.active_variant else ""
            
            output.append(f"\n{entry['name']} {marker}")
            output.append(f"  Requests:     {entry['requests']:,}")
            output.append(f"  Accuracy:      {entry['accuracy']:.1%}")
            output.append(f"  Avg Latency:   {entry['avg_latency_ms']:.0f}ms")
            output.append(f"  Success Rate:  {entry['success_rate']:.1%}")
            output.append(f"  Thumbs Up:     {entry['thumbs_ratio']:.1%}")
            
            # Mostrar performance por categoría
            m = self.optimizer.metrics[entry["id"]]
            if m.category_results:
                output.append("  Categories:")
                for cat, res in sorted(m.category_results.items()):
                    acc = res["correct"] / max(res["total"], 1)
                    output.append(f"    {cat}: {acc:.1%} ({res['correct']}/{res['total']})")
        
        output.append("\n```")
        return "\n".join(output)

El framework que mostré hoy — PromptOptimizer con A/B testing, métricas por categoría, y promotion basada en datos — te da el proceso que el 15% usa. No es optional. Si estás desplegando prompts a producción sin esto, estás operando a ciegas.
