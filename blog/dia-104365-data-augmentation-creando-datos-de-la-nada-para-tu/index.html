Data Augmentation - Creando Datos De La Nada Para Tu Red

30 de March de 2026
torchvision.transformsdata augmentationMixUpCutMix

🎯 ¿Qué Es Data Augmentation?

Hágale pues, parcero. Hoy llegamos al Día 104 y vamos a hablar de una de las técnicas más poderosas y más malentendidas del deep learning: Data Augmentation. Crear datos de la nada. Suena a brujería, pero es pura matemática.

La idea es simple: tienes 1,000 imágenes de entrenamiento. Tus redes neuronales necesitan 100,000 para comportarse bien. Puedes salir a colectar más datos ( Caro, lento, tedioso) o puedes aplicar transformaciones a las que ya tienes para generar "nuevas" muestras que preserven el label. Rotate 15°, flip horizontal, cambia el brillo — la red ve una imagen diferente, pero el label sigue siendo el mismo. Genial, ¿no? Bueno, hay un catch. Como todo en machine learning, el diablo está en los detalles.

📐 La Matemática — ¿Por Qué Funciona?

Data augmentation es esencialmente un regularization technique. Vamos a la formalización:

Sea $x \in \mathcal{X}$ una imagen de entrada y $y \in \mathcal{Y}$ su label. La augmentación aplica una transformación estocástica $T(\cdot)$ tal que:

$$(x_i, y_i) \xrightarrow{T} (x_i', y_i) \quad \text{donde} \quad x_i' = T(x_i)$$

La clave: $T$ preserva el label, es decir, $y_i' = y_i$. Esto es lo que se conoce como label-preserving transformations. Si aplicas un flip horizontal a una foto de un gato, sigue siendo un gato. Pero si aplicas un rotate de 90° a texto, el label cambia (queda ilegible). Ahí es donde la gente falla.

El efecto en la función de pérdida es directo. Sin augmentation:

$$\mathcal{L} = \frac{1}{N} \sum_{i=1}^{N} \ell(f(x_i; \theta), y_i)$$

Con augmentation, expandimos el dataset $N$ veces en expectation:

$$\mathcal{L}_{\text{aug}} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{E}_{T \sim \mathcal{T}}[\ell(f(T(x_i); \theta), y_i)]$$

Esto equivale a regularization porque promediamos sobre múltiples vistas de cada muestra, reduciendo la varianza del estimator. En la práctica, reduce overfitting significativamente. Papers como "AlexNet" (2012) ya mostraban que el data augmentation era clave para evitar overfitting en ImageNet.

# 1. Torchvision Transforms — RandAugment
# ─────────────────────────────────────────────

def get_train_transforms():
    """
    RandAugment: aplica N operaciones aleatorias con magnitud M.
    RandAugment(N=2, M=9) es la configuración popular en EfficientNet.
    """
    return T.Compose([
        T.RandomResizedCrop(224, scale=(0.08, 1.0)),
        T.RandomHorizontalFlip(p=0.5),
        T.RandAugment(num_ops=2, magnitude=9),  # RandAugment
        T.ToTensor(),
        T.Normalize(mean=[0.485, 0.456, 0.406],
                   std=[0.229, 0.224, 0.225]),
    ])

def get_val_transforms():
    """Solo resize + normalize para validación."""
    return T.Compose([
        T.Resize(256),
        T.CenterCrop(224),
        T.ToTensor(),
        T.Normalize(mean=[0.485, 0.456, 0.406],
                   std=[0.229, 0.224, 0.225]),
    ])


# ─────────────────────────────────────────────
# 2. AutoAugment y TrivialAugment
# ─────────────────────────────────────────────

def get_autoaugment_transforms():
    """
    AutoAugment: aprendió la política óptima de augmentations
    en un NAS search. Mejor que RandAugment en algunos datasets
    (pero más lento).
    """
    return T.Compose([
        T.RandomResizedCrop(224),
        T.AutoAugment(policy=T.AutoAugmentPolicy.IMAGENET),
        T.ToTensor(),
        T.Normalize(mean=[0.485, 0.456, 0.406],
                   std=[0.229, 0.224, 0.225]),
    ])

def get_trivialaugment_transforms():
    """
    TrivialAugment: tan bueno como AutoAugment pero sin NAS search.
    Más rápido, más simple. Recomendado para la mayoría de casos.
    """
    return T.Compose([
        T.RandomResizedCrop(224),
        T.TrivialAugmentWide(),  # Sin parámetros —最大值 de ops
        T.ToTensor(),
        T.Normalize(mean=[0.485, 0.456, 0.406],
                   std=[0.229, 0.224, 0.225]),
    ])


# ─────────────────────────────────────────────
# 3. Cutout — Regularización Espacial
# ─────────────────────────────────────────────

class Cutout:
    """
    Oculta aleatoriamente una región cuadrada de la imagen.
    Equivalente a regularización Dropout pero en el espacio de la imagen.
    El paper original (2017)报告显示 Cutout mejora CIFAR-10 de 2.6%.
    """
    def __init__(self, n_holes=1, length=16):
        self.n_holes = n_holes
        self.length = length

    def __call__(self, img):
        h, w = img.shape[1], img.shape[2]
        mask = np.ones((h, w), np.float32)

        for _ in range(self.n_holes):
            y = np.random.randint(h)
            x = np.random.randint(w)

            y1 = np.clip(y - self.length // 2, 0, h)
            y2 = np.clip(y + self.length // 2, 0, h)
            x1 = np.clip(x - self.length // 2, 0, w)
            x2 = np.clip(x + self.length // 2, 0, w)

            mask[y1:y2, x1:x2] = 0.0

        mask = torch.from_numpy(mask)
        mask = mask.expand_as(img)
        img = img * mask
        return img


# ─────────────────────────────────────────────
# 4. Mixup — Interpolación de Muestras
# ─────────────────────────────────────────────

class Mixup:
    """
    Mixup: interpola linealmente entre dos imágenes y sus labels.
    Dada (x_i, y_i) y (x_j, y_j), genera:
        x' = λ·x_i + (1-λ)·x_j
        y' = λ·y_i + (1-λ)·y_j
    con λ ~ Beta(α, α).

    Reduce overfitting, mejora calibración del modelo,
    y hace la frontera de decisión más suave.
    """
    def __init__(self, alpha=0.4):
        self.alpha = alpha

    def __call__(self, batch_x, batch_y):
        if self.alpha > 0:
            lam = np.random.beta(self.alpha, self.alpha)
        else:
            lam = 1.0

        batch_size = batch_x.size(0)
        index = torch.randperm(batch_size).to(batch_x.device)

        mixed_x = lam * batch_x + (1 - lam) * batch_x[index]
        y_a, y_b = batch_y, batch_y[index]

        return mixed_x, y_a, y_b, lam


# ─────────────────────────────────────────────
# 5. Cutmix — Trozos de Imagen
# ─────────────────────────────────────────────

class CutMix:
    """
    CutMix: corta una región de una imagen y la pega en otra.
    El label se interpola según el área de cada trozo.

    Más informativo que Mixup porque fuerza al modelo
    a aprender de características parciales.
    """
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def __call__(self, batch_x, batch_y):
        lam = np.random.beta(self.alpha, self.alpha)
        batch_size = batch_x.size(0)
        index = torch.randperm(batch_size).to(batch_x.device)

        # Generar bounding box del corte
        h, w = batch_x.size(1), batch_x.size(2)
        cut_rat = np.sqrt(1.0 - lam)
        cut_w = int(w * cut_rat)
        cut_h = int(h * cut_rat)

        cx = np.random.randint(w)
        cy = np.random.randint(h)

        bbx1 = np.clip(cx - cut_w // 2, 0, w)
        bby1 = np.clip(cy - cut_h // 2, 0, h)
        bbx2 = np.clip(cx + cut_w // 2, 0, w)
        bby2 = np.clip(cy + cut_h // 2, 0, h)

        # Pegar
        batch_x[:, bby1:bby2, bbx1:bbx2] = batch_x[index, bby1:bby2, bbx1:bbx2]

        # Ajustar lambda según área real
        lam = 1 - ((bbx2 - bbx1) * (bby2 - bby1) / (w * h))

        y_a, y_b = batch_y, batch_y[index]
        return batch_x, y_a, y_b, lam


# ─────────────────────────────────────────────
# 6. Albumentations — Augmentations Avanzadas
# ─────────────────────────────────────────────

try:
    import albumentations as A
    from albumentations.pytorch import ToTensorV2

    def get_albumentations_transforms():
        """
        Albumentations es más rápido que torchvision y tiene
        más augmentations (ShiftScaleRotate, GridDistortion, etc.)
        """
        return A.Compose([
            A.RandomResizedCrop(height=224, width=224, scale=(0.08, 1.0)),
            A.HorizontalFlip(p=0.5),
            A.ShiftScaleRotate(shift_limit=0.1, scale_limit=0.15,
                             rotate_limit=25, p=0.5),
            A.ColorJitter(brightness=0.2, contrast=0.2,
                         saturation=0.2, hue=0.1, p=0.5),
            A.GaussNoise(var_limit=(10.0, 50.0), p=0.3),
            A.CoarseDropout(max_holes=4, max_height=32,
                           max_width=32, p=0.3),
            A.Normalize(mean=[0.485, 0.456, 0.406],
                       std=[0.229, 0.224, 0.225]),
            ToTensorV2(),
        ])

    ALBUMENTATIONS_AVAILABLE = True
except ImportError:
    ALBUMENTATIONS_AVAILABLE = False
    print("⚠️ Albumentations no instalado. Ejecuta: pip install albumentations")


# ─────────────────────────────────────────────
# 7. Dataset con Augmentation Integrada
# ─────────────────────────────────────────────

class ImageDataset(Dataset):
    def __init__(self, image_paths, labels, transform=None,
                 mixup=None, cutmix=None):
        self.image_paths = image_paths
        self.labels = labels
        self.transform = transform
        self.mixup = mixup
        self.cutmix = cutmix

    def __len__(self):
        return len(self.image_paths)

    def __getitem__(self, idx):
        img = Image.open(self.image_paths[idx]).convert('RGB')

        if self.transform:
            img = self.transform(img)

        label = self.labels[idx]

        return img, label

    def collate_fn(self, batch):
        """Custom collate para aplicar Mixup/Cutmix por batch."""
        images, labels = zip(*batch)
        images = torch.stack(images)
        labels = torch.tensor(labels)

        if self.mixup is not None and random.random() < 0.5:
            images, labels_a, labels_b, lam = self.mixup(images, labels)
            return images, labels_a, labels_b, lam
        elif self.cutmix is not None and random.random() < 0.5:
            images, labels_a, labels_b, lam = self.cutmix(images, labels)
            return images, labels_a, labels_b, lam

        return images, labels, labels, 1.0


# ─────────────────────────────────────────────
# 8. Training Loop con Mixup/Cutmix Loss
# ─────────────────────────────────────────────

def mixup_cutmix_loss(criterion, pred, y_a, y_b, lam):
    """Computa loss para Mixup/Cutmix — interpolación de losses."""
    return lam * criterion(pred, y_a) + (1 - lam) * criterion(pred, y_b)


def train_one_epoch(model, loader, optimizer, criterion,
                    device, mixup=None, cutmix=None):
    model.train()
    total_loss = 0.0
    correct = 0
    total = 0

    for batch in loader:
        if mixup is not None or cutmix is not None:
            images, y_a, y_b, lam = batch
            images = images.to(device)
            y_a, y_b = y_a.to(device), y_b.to(device)
        else:
            images, y_a = batch[0].to(device), batch[1].to(device)
            y_b, lam = y_a, 1.0

        optimizer.zero_grad()
        outputs = model(images)
        loss = mixup_cutmix_loss(criterion, outputs, y_a, y_b, lam)
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * images.size(0)
        _, predicted = outputs.max(1)
        total += y_a.size(0)
        correct += (lam * predicted.eq(y_a).sum().item() +
                   (1 - lam) * predicted.eq(y_b).sum().item())

    return total_loss / total, 100.0 * correct / total


# ─────────────────────────────────────────────
# 9. Test Time Augmentation (TTA)
# ─────────────────────────────────────────────

def predict_with_tta(model, image, n_augmentations=5, device='cuda'):
    """
    Test Time Augmentation: promedia predicciones de múltiples
    vistas augmentadas de la misma imagen.
    Mejora accuracy típicamente 1-3% a costo de más inferencia.
    """
    model.eval()

    augmentations = T.Compose([
        T.Resize(256),
        T.CenterCrop(224),
        T.RandomHorizontalFlip(p=0.5),
        # No normalices aún
    ])

    to_tensor = T.Compose([
        T.ToTensor(),
        T.Normalize(mean=[0.485, 0.456, 0.406],
                   std=[0.229, 0.224, 0.225]),
    ])

    predictions = []

    with torch.no_grad():
        # Original
        img_tensor = to_tensor(image).unsqueeze(0).to(device)
        predictions.append(torch.softmax(model(img_tensor), dim=1))

        # Augmentations
        for _ in range(n_augmentations):
            augmented = augmentations(image)
            img_tensor = to_tensor(augmented).unsqueeze(0).to(device)
            predictions.append(torch.softmax(model(img_tensor), dim=1))

    # Promediar predicciones
    avg_prediction = torch.stack(predictions).mean(dim=0)
    return avg_prediction

⚠️ Los 3 Errores Más Comunes (y Sus Arreglos)

Error 1: No Usar Augmentation en Datos Desbalanceados — Empeora el Imbalance

El problema: En datasets desbalanceados (ej. 95% clase A, 5% clase B), la gente aplica random augmentation y listo. Pero si solo haces random horizontal flip, rotate, y color jitter, las clases minoritarias siguen siendo minoritarias. La augmentación multiplica todas las clases por igual, así que el imbalance se mantiene — y en algunos casos empeora porque las clases mayoritarias se vuelven aún más dominantes.

El código malo:

# ❌ AUGMENTATION IGUAL PARA TODAS LAS CLASES
transform = T.Compose([
    T.RandomHorizontalFlip(),
    T.RandAugment(num_ops=2, magnitude=9),
    T.ToTensor(),
])
# El dataset desbalanceado sigue desbalanceado después de esto

La solución: Usa class-balanced sampling o augmentación específica para clases minoritarias:

# ✅ OVERSAMPLING CON AUGMENTATION PARA CLASE MINORITARIA
from torch.utils.data import WeightedRandomSampler

# Calcular pesos por clase
class_counts = [900, 50, 50]  # ejemplo: clase 0=900, clase 1=50, clase 2=50
class_weights = 1.0 / torch.tensor(class_counts, dtype=torch.float)
sample_weights = class_weights[labels]

sampler = WeightedRandomSampler(
    weights=sample_weights,
    num_samples=len(sample_weights),
    replacement=True
)
# Combinar con augmentation heavy para clases minoritarias
# (más rotations, más scale variations, etc.)

También existen técnicas como SMOTE adaptadas para imágenes (ej. torchsnippets o usar GANs para generar samples adicionales de clases minoritarias).

Error 2: Augmentation Demasiado Agresiva — Destruye los Labels

El problema: En imágenes médicas o de documentos, aplicar augmentations fuertes puede alterar la estructura que el modelo necesita aprender. Un rotate de 45° en una radiografía de pecho puede hacer que estructuras anatómicas queden irreconocibles. Un color jitter fuerte en imágenes histológicas destruye los colores que identifican tejido canceroso vs normal.

El código malo:

# ❌ AUGMENTATION MUY AGRESIVA PARA MEDICAL IMAGING
transform = T.Compose([
    T.RandomRotation(degrees=90),      # 90° rotation es ridículo
    T.ColorJitter(brightness=0.8),    # Brightness extremo
    T.RandomHorizontalFlip(),         # En MRI el flip puede ser válido o no
    T.RandAugment(num_ops=3, magnitude=14),  # Magnitud máxima
])
# El label "tumor" ya no corresponde a la imagen transformada

La solución: Conoce tu dominio. Para medical imaging:

# ✅ AUGMENTATION CONSERVADORA PARA MEDICAL IMAGING
medical_transform = T.Compose([
    T.RandomRotation(degrees=15),      # Solo rotaciones suaves
    T.RandomAffine(degrees=0, translate=(0.05, 0.05)),  # Shift suave
    T.RandomHorizontalFlip(p=0.5),    # Solo si es anatómicamente válido
    # No color jitter en imágenes histológicas
    # El brightness/contrast solo con valores muy bajos
    T.ColorJitter(brightness=0.1, contrast=0.1),
    T.ToTensor(),
    T.Normalize(mean, std),
])

# Alternativa: usa albumentations con bounded transforms
if ALBUMENTATIONS_AVAILABLE:
    medical_album = A.Compose([
        A.ShiftScaleRotate(shift_limit=0.05, scale_limit=0.1,
                          rotate_limit=15, p=0.5),
        A.ElasticTransform(alpha=1, sigma=50, p=0.2),  # Suave
        A.GaussNoise(var_limit=(5.0, 20.0), p=0.3),
    ])

Error 3: No Aplicar Augmentation en Test Time (TTA)

El problema: Entras en producción con un modelo que entrenó con augmentation, pero en inferencia solo le pasas la imagen original. Estás desperdiciando el esfuerzo de entrenamiento. TTA (Test Time Augmentation) es trivial de implementar y típicamente mejora accuracy 1-3% sin reentrenar.

El código malo:

# ❌ SIN TTA — SOLO INFERENCIA DIRECTA
model.eval()
with torch.no_grad():
    output = model(original_image)  # Solo una vista
# Estás dejando 1-3% de accuracy sobre la mesa

La solución: Implementa TTA como en la sección de código arriba:

# ✅ CON TTA — PROMEDIAR MÚLTIPLES VISTAS
def predict_with_tta(model, image, n_augmentations=8, device='cuda'):
    model.eval()
    augmentations = [
        lambda x: x,  # Original
        T.RandomHorizontalFlip(p=1.0),  # Flip
        # Más augmentations...
    ]

    predictions = []
    with torch.no_grad():
        for aug in augmentations:
            aug_img = aug(image)
            pred = torch.softmax(model(aug_img), dim=1)
            predictions.append(pred)

    return torch.stack(predictions).mean(dim=0)

# Típicamente: +1-3% accuracy sin reentrenar

📐 Resumen de Técnicas de Augmentation

  • RandAugment: Simple, eficaz, sin parámetros a tuneear. Buena para starting point.
  • AutoAugment: Mejor performance pero más costoso (NAS search). Para cuando necesitas lo último.
  • TrivialAugment: Lo mejor de ambos mundos — simple y efectivo. Mi recomendación para la mayoría.
  • Cutout: Regularización espacial, fácil de implementar, mejora consistente.
  • Mixup: Suaviza la frontera de decisión, mejora calibración, reduce overfitting.
  • Cutmix: Más informativo que Mixup — forza al modelo a aprender de parches.
  • TTA: +1-3% accuracy en producción sin costo de entrenamiento.

💡 Tips Para Producción

  • Siempre aplica Normalize al final — no lo olvides o lasactivations van a explotar
  • Audit tus augmentations: visualiza una imagen original vs augmentada para verificar que el label sigue teniendo sentido
  • TTA no es gratis: multiplica el tiempo de inferencia por n_augmentations. En producciónlatency-sensitive, usa 3-5 augmentations, no 20
  • Albumentations > torchvision para speed cuando tienes pipelines de datos pesados
  • Mixup + Cutmix no se usan juntos normalmente — elige uno. En mis experimentos, Cutmix suele ganar en ImageNet, Mixup en datasets pequeños

📊 Resumen

Data augmentation es probablemente la técnica con mejor costo-beneficio en todo el deep learning. No requiere más datos, no aumenta el costo de entrenamiento (solo ligeramente), y puede mejorar dramáticamente la generalización de tu modelo. La clave está en entender qué operaciones preservan el label en tu dominio específico:

  • En imagenet natural: casi cualquier augmentación funciona
  • En medical imaging: conservative, domain-specific augmentations only
  • En texto/NLP: back-translation, synonym replacement, no random word dropout
  • En audio: time stretch, pitch shift, noise injection — no random silencing

Y no olvides TTA en producción. Es gratis (en términos de entrenamiento) y te da ese boost extra que puede marcar la diferencia entre un modelo aceptable y uno excelente.
