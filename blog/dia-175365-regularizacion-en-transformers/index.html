Parcero, día 174 y hoy我们来聊聊 Cost Optimization en aplicaciones LLM. Si tu startup está quemando dinero en APIs de OpenAI y no tiene una estrategia de costos clara, esta vaina se va a poner fea. El 90% de las empresas que usan LLMs en producción están pagando más de lo necesario. De una.

Hagamos las cuentas:假设 una app con 100K usuarios activos mensuales, cada usuario hace 10 requests/día de ~500 tokens de output. Eso son 100K × 10 × 30 = 30M requests/mes. Si usas GPT-4 a $0.03/1K tokens output, eso son $450/mes solo en output tokens. Con caching agresivo y optimización de contexto, puedes reducir eso a $50-100/mes. Eso es 5-10x de ahorro.

🎯 La Anatomía del Costo LLM

Para optimizar costos, primero hay que entender de dónde vienen los costos. Cada API call tiene dos componentes:

  • Input tokens: Tu prompt + conversation history + system prompt. Se cobra por 1K tokens.
  • Output tokens: La respuesta del modelo. Típicamente 10-50x más caro que input en modelos recientes.

Los levers para reducir costos:

  • Reducir input tokens: Comprimir prompts, resumir history, usar context window más pequeño.
  • Reducir output tokens: lower max_tokens, usar modelos más baratos para tareas simples.
  • Cachear outputs: Semantic cache para queries repetidas (ver Día 173).
  • Routing inteligente: Enviar requests baratos a modelos baratos cuando sea posible.

📐 Estrategias de Optimización de Costos

1. Prompt Compression

No necesitas上下文 completo en cada request. Técnicas:

  • Truncate old messages: Cuando el conversation history crece, eliminar los mensajes más antiguos manteniendo los últimos N.
  • Summarize + retain: Resumir el history anterior y solo guardar el summary + últimos mensajes.
  • Semantic compression: Usar embeddings para identificar qué partes del contexto son realmente relevantes para la query actual.

2. Model Routing

No toda query necesita GPT-4. Clasifica la query y envía a modelo apropiado:

$$Cost_{router}(q) = \min_{m \in Models} \mathbb{1}[quality(m, q) \geq threshold] \cdot cost(m, q)$$

Un clasificador simple puede routing el 70-80% de queries a modelos más baratos (GPT-3.5, Llama-2, etc.) manteniendo 95%+ de calidad percibida.

"""
Cost Optimizer para LLM API que implementa:
1. Prompt compression
2. Smart routing  
3. Budget management y alerting
4. Token tracking por usuario/endpoint
"""
import logging
import time
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Any, Tuple
from enum import Enum
from collections import defaultdict
import hashlib

import tiktoken
from transformers import AutoTokenizer

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class ModelTier(Enum):
    """Tiers de modelos por costo/capacidad."""
    CHEAP = "cheap"      # gpt-3.5-turbo, llama-2-7b
    MEDIUM = "medium"    # claude-instant, gpt-4-32k
    EXPENSIVE = "expensive"  # gpt-4, claude-2


@dataclass
class ModelConfig:
    """Configuración de un modelo específico."""
    name: str
    provider: str  # openai, anthropic, local
    input_cost_per_1k: float  # USD
    output_cost_per_1k: float  # USD
    max_tokens: int
    tier: ModelTier
    capabilities: List[str] = field(default_factory=list)
    avg_latency_ms: float = 1000.0


# Catálogo de modelos

@dataclass
class TokenBudget:
    """Presupuesto de tokens para un usuario/endpoint."""
    user_id: str
    monthly_limit: int = 100_000
    current_usage: int = 0
    reset_day: int = 1  # Día del mes para reset
    
    def remaining(self) -> int:
        return max(0, self.monthly_limit - self.current_usage)
    
    def is_exhausted(self) -> bool:
        return self.current_usage >= self.monthly_limit


class PromptCompressor:
    """
    Comprime prompts para reducir tokens mientras preserva información clave.
    """
    
    def __init__(self, model_name: str = "gpt-3.5-turbo"):
        self.encoding = tiktoken.encoding_for_model(model_name)
    
    def count_tokens(self, text: str) -> int:
        """Cuenta tokens en un texto."""
        return len(self.encoding.encode(text))
    
    def compress_by_tokens(
        self, 
        messages: List[Dict], 
        max_tokens: int,
        preserve_recent: int = 6
    ) -> List[Dict]:
        """
        Comprime mensajes manteniendo solo los últimos N y resumiendo el resto.
        
        Args:
            messages: Lista de mensajes de conversación
            max_tokens: Máximo de tokens permitidos
            preserve_recent: Número de mensajes recientes a preservar intactos
        """
        if not messages:
            return []
        
        # Preservar últimos mensajes
        recent = messages[-preserve_recent:] if len(messages) > preserve_recent else messages
        
        # Calcular tokens de mensajes recientes
        recent_text = "\n".join([f"{m['role']}: {m['content']}" for m in recent])
        recent_tokens = self.count_tokens(recent_text)
        
        if recent_tokens <= max_tokens:
            #还有 espacio para algunos mensajes antiguos
            old_messages = messages[:-preserve_recent]
            if old_messages:
                # Mantener solo system y primeros mensajes del older
                system = [m for m in messages if m.get("role") == "system"]
                others = [m for m in messages if m.get("role") != "system"]
                
                available = max_tokens - recent_tokens
                kept_old = []
                kept_tokens = 0
                
                for m in others[:-preserve_recent]:
                    m_tokens = self.count_tokens(m['content'])
                    if kept_tokens + m_tokens <= available:
                        kept_old.append(m)
                        kept_tokens += m_tokens
                
                return system + kept_old + recent
        
        return recent


class CostOptimizer:
    """
    Optimizador de costos que routing inteligente + compression + budgets.
    """
    
    def __init__(
        self,
        monthly_budget_usd: float = 1000.0,
        enable_compression: bool = True,
        enable_routing: bool = True,
    ):
        self.monthly_budget = monthly_budget_usd
        self.current_spend = 0.0
        self.enable_compression = enable_compression
        self.enable_routing = enable_routing
        
        self.compressor = PromptCompressor()
        self.user_budgets: Dict[str, TokenBudget] = {}
        self.tokenizer = AutoTokenizer.from_pretrained("gpt2")  # Fallback
        
        # Métricas
        self.metrics = defaultdict(lambda: {
            "requests": 0,
            "tokens_in": 0,
            "tokens_out": 0,
            "cost": 0.0,
            "cache_hits": 0,
        })
        
        logger.info(f"CostOptimizer inicializado. Budget: ${monthly_budget_usd}/mes")
    
    def estimate_cost(
        self,
        model: str,
        input_tokens: int,
        output_tokens: int
    ) -> float:
        """Estima costo de un request."""
        if model not in MODEL_CATALOG:
            logger.warning(f"Modelo {model} no en catálogo, asumiendo gpt-3.5-turbo")
            model = "gpt-3.5-turbo"
        
        config = MODEL_CATALOG[model]
        input_cost = (input_tokens / 1000) * config.input_cost_per_1k
        output_cost = (output_tokens / 1000) * config.output_cost_per_1k
        return input_cost + output_cost
    
    def route_request(
        self,
        query: str,
        required_capabilities: List[str],
        quality_threshold: float = 0.9
    ) -> str:
        """
        Routing inteligente: selecciona el modelo más barato que satisface los requisitos.
        
        Args:
            query: Texto de la query
            required_capabilities: Capacidades requeridas
            quality_threshold: Threshold mínimo de calidad aceptable
            
        Returns:
            Nombre del modelo seleccionado
        """
        if not self.enable_routing:
            return "gpt-3.5-turbo"
        
        # Filtrar modelos que tienen las capabilities requeridas
        candidates = [
            (name, config) for name, config in MODEL_CATALOG.items()
            if all(cap in config.capabilities for cap in required_capabilities)
        ]
        
        if not candidates:
            logger.warning("No se encontró modelo con capabilities requeridas, usando gpt-4")
            return "gpt-4"
        
        # Ordenar por costo
        candidates.sort(key=lambda x: x[1].input_cost_per_1k + x[1].output_cost_per_1k)
        
        # Para queries simples (short, sin complexity), usar el más barato
        query_len = len(query.split())
        if query_len < 50 and "complex" not in required_capabilities:
            return candidates[0][0]  # Más barato
        
        # Para queries complejas, ir al menos dos tiers arriba del más barato
        if len(candidates) > 1:
            return candidates[min(1, len(candidates) - 1)][0]
        
        return candidates[0][0]
    
    def check_user_budget(self, user_id: str) -> Tuple[bool, int]:
        """
        Verifica si el usuario tiene presupuesto restante.
        
        Returns:
            (has_budget, remaining_tokens)
        """
        if user_id not in self.user_budgets:
            self.user_budgets[user_id] = TokenBudget(user_id=user_id)
        
        budget = self.user_budgets[user_id]
        return not budget.is_exhausted(), budget.remaining()
    
    def process_request(
        self,
        user_id: str,
        messages: List[Dict],
        model: Optional[str] = None,
        capabilities: Optional[List[str]] = None,
        max_response_tokens: int = 500,
    ) -> Dict[str, Any]:
        """
        Procesa un request con optimization de costos.
        
        Returns:
            Dict con request modificado y metadata de costos
        """
        start_time = time.time()
        
        # 1. Determinar modelo
        required_caps = capabilities or ["chat"]
        selected_model = model or self.route_request(
            messages[-1]["content"] if messages else "",
            required_caps
        )
        
        # 2. Comprimir si necesario
        model_config = MODEL_CATALOG.get(selected_model, MODEL_CATALOG["gpt-3.5-turbo"])
        compressed_messages = messages
        
        if self.enable_compression:
            compressed_messages = self.compressor.compress_by_tokens(
                messages,
                max_tokens=model_config.max_tokens - max_response_tokens
            )
        
        # 3. Estimar tokens
        messages_text = "\n".join([f"{m['role']}: {m['content']}" for m in compressed_messages])
        input_tokens = self.compressor.count_tokens(messages_text)
        estimated_output = min(max_response_tokens, model_config.max_tokens)
        
        # 4. Estimar costo
        estimated_cost = self.estimate_cost(selected_model, input_tokens, estimated_output)
        
        # 5. Check budget
        has_budget, remaining = self.check_user_budget(user_id)
        if not has_budget:
            return {
                "error": "Budget exhausted",
                "estimated_cost": estimated_cost,
                "user_budget_remaining": remaining,
            }
        
        # 6. Verificar budget del sistema
        if self.current_spend + estimated_cost > self.monthly_budget:
            return {
                "error": "Monthly budget exhausted",
                "current_spend": self.current_spend,
                "monthly_budget": self.monthly_budget,
            }
        
        return {
            "model": selected_model,
            "messages": compressed_messages,
            "estimated_cost": estimated_cost,
            "estimated_tokens_in": input_tokens,
            "estimated_tokens_out": estimated_output,
            "user_budget_remaining": remaining,
            "processing_time_ms": (time.time() - start_time) * 1000,
        }
    
    def record_usage(
        self,
        user_id: str,
        model: str,
        tokens_in: int,
        tokens_out: int,
        actual_cost: float,
    ) -> None:
        """Registra usage después de un request completado."""
        # Update user budget
        if user_id in self.user_budgets:
            self.user_budgets[user_id].current_usage += tokens_in + tokens_out
        
        # Update global spend
        self.current_spend += actual_cost
        
        # Update metrics
        self.metrics[model]["requests"] += 1
        self.metrics[model]["tokens_in"] += tokens_in
        self.metrics[model]["tokens_out"] += tokens_out
        self.metrics[model]["cost"] += actual_cost
    
    def get_cost_report(self) -> Dict[str, Any]:
        """Genera reporte de costos."""
        total_cost = sum(m["cost"] for m in self.metrics.values())
        total_tokens = sum(m["tokens_in"] + m["tokens_out"] for m in self.metrics.values())
        
        return {
            "total_spend_usd": self.current_spend,
            "monthly_budget_usd": self.monthly_budget,
            "budget_remaining_usd": self.monthly_budget - self.current_spend,
            "budget_utilization_pct": (self.current_spend / self.monthly_budget * 100) if self.monthly_budget > 0 else 0,
            "total_tokens": total_tokens,
            "by_model": dict(self.metrics),
            "cost_per_user": {
                uid: {
                    "tokens_used": budget.current_usage,
                    "budget_limit": budget.monthly_limit,
                    "utilization_pct": budget.current_usage / budget.monthly_limit * 100 if budget.monthly_limit > 0 else 0,
                }
                for uid, budget in self.user_budgets.items()
            },
        }


# Usage example
if __name__ == "__main__":
    optimizer = CostOptimizer(
        monthly_budget_usd=1000.0,
        enable_compression=True,
        enable_routing=True,
    )
    
    # Simular request
    result = optimizer.process_request(
        user_id="user_123",
        messages=[
            {"role": "system", "content": "Eres un asistente útil."},
            {"role": "user", "content": "Explica qué es blockchain en 2 oraciones."},
        ],
        capabilities=["chat"],
    )
    
    if "error" not in result:
        print(f"Model: {result['model']}")
        print(f"Estimated cost: ${result['estimated_cost']:.4f}")
        print(f"Input tokens: {result['estimated_tokens_in']}")
        
        # Simular completado
        optimizer.record_usage(
            user_id="user_123",
            model=result["model"],
            tokens_in=result["estimated_tokens_in"],
            tokens_out=result["estimated_tokens_out"],
            actual_cost=result["estimated_cost"],
        )
    
    # Reporte
    report = optimizer.get_cost_report()
    print(f"\nTotal spend: ${report['total_spend_usd']:.2f}")
    print(f"Budget remaining: ${report['budget_remaining_usd']:.2f}")

⚠️ Errores Comunes en Cost Optimization

Error 1: No trackear costos por usuario/endpoint

El problema: Sin visibility de quién está generando los costos, no puedes identificar who's burning money. Un solo usuario o endpoint puede representar 80% del costo. El 85% de companies no hacen este tracking.

Fix: Implementar token accounting por user_id y endpoint desde el día uno. Usar la estructura de CostOptimizer de arriba o servicios como Helicone, LangSmith para logging detallado.

Error 2: Usar siempre el modelo más capaz

El problema: GPT-4 para una tarea que pudo haber sido resuelta con GPT-3.5 es tirar dinero. La diferencia de costo es 10-20x por request. Queries simples (clasificaciones, extracciones, preguntas directas) típicamente no necesitan modelos frontier.

Fix: Implementar model routing basado en clasificación de query. Un classifier simple entrenado en-house puede routing el 70%+ de queries a modelos más baratos manteniendo calidad.

Error 3: No comprimir conversation history

El problema: Cada mensaje en el conversation history se cobra como input tokens. Después de 20 mensajes de ~100 tokens cada uno, ya son 2,000 tokens por request solo en history, antes del prompt real.

Fix: Implementar truncation strategies: mantener últimos N mensajes, o summarization del history antiguo. Con 10 conversaciones de 20 mensajes cada una, puedes ahorrar 50%+ en input tokens.

✅ Resumen y Cierre

  • Cost = input_tokens × price_in + output_tokens × price_out. Optimizar ambos lados.
  • Model routing puede ahorrar 70%+ sin sacrificar calidad.
  • Prompt compression (history truncation) reduce input tokens 30-50%.
  • Per-user budgeting previene que un solo usuario queme todo el budget.
  • Tracking y reportes son esenciales para identificar optimización opportunities.

Hágale que la diferencia entre una app LLM rentable y una que quema money está en estos detalles. No es glamour, pero es survival. Implementen cost optimization desde el principio, parcero.
