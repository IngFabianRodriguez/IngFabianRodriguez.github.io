🎯 Por Que La Regularizacion En Transformers Es Critica

Parcero, dia 175. Vamos a聊聊 Regularizacion en Transformers. Si pensabas que dropout era solo apagar neuronas al azar, esta vaina te va a expandir la mente. Los transformers tienen problemas de regularizacion unicos debido a su arquitectura, y el 80% de las implementaciones aplican dropout incorrectamente o no usan las tecnicas correctas. De una.

Los transformers son modelos enorme con millones o miles de millones de parametros. Con datasets relativamente pequenos comparado con el numero de parametros, el overfitting es el problema numero uno. La diferencia entre un transformer que generaliza bien y uno que memoriza el training data esta en como aplicas regularizacion.

📐 El Problema Unico De Los Transformers

Antes de hablar de tecnicas, entendamos por que los transformers son especiales:

  • Attention mechanisms: Crean conexiones entre TODOS los tokens, lo que puede llevar a que el modelo aprenda correlaciones espurias en el training data.
  • Embedding layers enormes: Especialmente problematicas cuando hay banyak tokens en el vocabulario.
  • Positional encodings: Si no se regularizan bien, el modelo puede depender excesivamente de posiciones en lugar de contenido.
  • Depth extrema: Modelos de 100+ capas son comunes, cada capa puede overfittear de manera diferente.

La receta de regularizacion para transformers incluye:

  • Dropout: Especialmente en attention y FFN layers.
  • Label Smoothing: Para分類 tasks.
  • Weight Decay: L2 regularization en los pesos.
  • Data Augmentation: Especialmente para NLP.
  • Stochastic Depth: Similar a dropout pero para capas.

💻 Implementacion De Regularizacion En PyTorch

"""
Regularizacion avanzada para Transformers.
Incluye: Dropout adaptativo, Label Smoothing, Stochastic Depth, Weight Decay.
"""
import torch
import torch.nn as nn
import torch.nn.functional as F
import math
from typing import Optional, Tuple


class AdaptiveDropout(nn.Module):
    """
    Dropout que se adapta based on the layer depth.
    Capas mas profundas reciben dropout mas agresivo.
    """
    def __init__(self, base_p: float = 0.1, max_p: float = 0.3, num_layers: int = 12):
        super().__init__()
        self.base_p = base_p
        self.max_p = max_p
        self.num_layers = num_layers
    
    def forward(self, x: torch.Tensor, layer_idx: int) -> torch.Tensor:
        # Interpolacion lineal de dropout rate segun profundidad
        alpha = layer_idx / max(1, self.num_layers - 1)
        p = self.base_p + alpha * (self.max_p - self.base_p)
        
        if self.training:
            return F.dropout(x, p=p)
        return x


class LabelSmoothingLoss(nn.Module):
    """
    Label Smoothing Loss - previene overconfidence.
    En lugar de hard labels [0, 0, 1, 0], usa [0.1, 0.1, 0.7, 0.1].
    """
    def __init__(self, num_classes: int, smoothing: float = 0.1):
        super().__init__()
        self.num_classes = num_classes
        self.smoothing = smoothing
        self.confidence = 1.0 - smoothing
    
    def forward(self, pred: torch.Tensor, target: torch.Tensor) -> torch.Tensor:
        """
        Args:
            pred: Logits de shape (batch, num_classes)
            target: Labels de shape (batch,)
        """
        # Crear distribution suave
        smooth_target = torch.zeros_like(pred)
        smooth_target.fill_(self.smoothing / (self.num_classes - 1))
        smooth_target.scatter_(1, target.unsqueeze(1), self.confidence)
        
        # Cross entropy con distribution suave
        log_prob = F.log_softmax(pred, dim=-1)
        loss = (-smooth_target * log_prob).sum(dim=-1).mean()
        
        return loss


class StochasticDepth(nn.Module):
    """
    Stochastic Depth - "dropout" para capas completas.
    En lugar de apagar neuronas, salta capas enteras durante training.
    Reduce sobreajuste en redes profundas.
    """
    def __init__(self, drop_prob: float = 0.2, mode: str = 'row'):
        super().__init__()
        self.drop_prob = drop_prob
        self.mode = mode
    
    def forward(self, x: torch.Tensor, layer_idx: Optional[int] = None) -> torch.Tensor:
        if not self.training:
            return x
        
        # Binary survival variable
        if layer_idx is not None:
            # Probabilidad de supervivencia decrece con profundidad
            survival_prob = 1.0 - (layer_idx / 12.0) * self.drop_prob
        else:
            survival_prob = 1.0 - self.drop_prob
        
        survival = torch.bernoulli(torch.tensor([survival_prob])).item()
        
        if survival:
            return x / survival_prob  # Escala para mantener expectation
        else:
            return torch.zeros_like(x)


class TransformerBlockWithRegularization(nn.Module):
    """
    Transformer Block con regularizacion completa.
    Incluye: Adaptive Dropout, Stochastic Depth, FFN dropout.
    """
    def __init__(
        self,
        d_model: int,
        num_heads: int,
        d_ff: int,
        dropout: float = 0.1,
        use_stochastic_depth: bool = True,
        layer_idx: int = 0,
        total_layers: int = 12,
    ):
        super().__init__()
        self.layer_idx = layer_idx
        self.use_stochastic_depth = use_stochastic_depth
        
        # Multi-head attention
        self.attention = nn.MultiheadAttention(d_model, num_heads, dropout=dropout, batch_first=True)
        self.attention_norm = nn.LayerNorm(d_model)
        
        # FFN con dropout
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout),
        )
        self.ffn_norm = nn.LayerNorm(d_model)
        
        # Regularizacion
        self.adaptive_dropout = AdaptiveDropout(
            base_p=dropout,
            max_p=dropout * 3,  # Capas profundas hasta 3x dropout
            num_layers=total_layers,
        )
        
        self.stochastic_depth = StochasticDepth(drop_prob=0.2) if use_stochastic_depth else None
    
    def forward(self, x: torch.Tensor, mask: Optional[torch.Tensor] = None) -> torch.Tensor:
        # Pre-norm attention (mejor que post-norm para regularizacion)
        attn_input = self.attention_norm(x)
        attn_output, _ = self.attention(attn_input, attn_input, attn_input, attn_mask=mask)
        
        # Adaptive dropout en attention
        attn_output = self.adaptive_dropout(attn_output, self.layer_idx)
        
        # Stochastic depth en skip connection
        if self.use_stochastic_depth and self.stochastic_depth:
            x = self.stochastic_depth(x + attn_output, self.layer_idx)
        else:
            x = x + attn_output
        
        # Pre-norm FFN
        ffn_input = self.ffn_norm(x)
        ffn_output = self.ffn(ffn_input)
        
        # Dropout en FFN
        ffn_output = self.adaptive_dropout(ffn_output, self.layer_idx)
        
        # Skip connection
        x = x + ffn_output
        
        return x


class TransformerEncoderRegularized(nn.Module):
    """
    Transformer Encoder completo con regularizacion multi-nivel.
    """
    def __init__(
        self,
        vocab_size: int,
        d_model: int = 512,
        num_heads: int = 8,
        num_layers: int = 6,
        d_ff: int = 2048,
        dropout: float = 0.1,
        label_smoothing: float = 0.1,
        max_seq_length: int = 512,
    ):
        super().__init__()
        
        # Embeddings
        self.token_embedding = nn.Embedding(vocab_size, d_model)
        self.position_embedding = nn.Embedding(max_seq_length, d_model)
        self.embedding_dropout = nn.Dropout(dropout)
        
        # Regularizacion de embeddings
        self.embed_norm = nn.LayerNorm(d_model)
        
        # Capas del transformer
        self.layers = nn.ModuleList([
            TransformerBlockWithRegularization(
                d_model=d_model,
                num_heads=num_heads,
                d_ff=d_ff,
                dropout=dropout,
                use_stochastic_depth=True,
                layer_idx=i,
                total_layers=num_layers,
            )
            for i in range(num_layers)
        ])
        
        # Output head
        self.output_norm = nn.LayerNorm(d_model)
        self.classifier = nn.Linear(d_model, vocab_size)
        
        # Loss con label smoothing
        self.criterion = LabelSmoothingLoss(vocab_size, label_smoothing)
        
        # Weight decay parameter
        self.weight_decay = 0.01
    
    def forward(
        self,
        input_ids: torch.Tensor,
        attention_mask: Optional[torch.Tensor] = None,
        labels: Optional[torch.Tensor] = None,
    ) -> dict:
        """
        Returns:
            dict con 'logits', 'loss' (si labels proporcionado), 'attentions'
        """
        batch_size, seq_len = input_ids.shape
        
        # Embeddings + positional
        positions = torch.arange(seq_len, device=input_ids.device).unsqueeze(0)
        x = self.token_embedding(input_ids) + self.position_embedding(positions)
        x = self.embed_norm(x)
        x = self.embedding_dropout(x)
        
        # Crear causal mask si es necesario
        if attention_mask is not None:
            # Convertir mask a format para attention
            mask = attention_mask.float()
            mask = mask.masked_fill(mask == 0, float('-inf')).masked_fill(mask == 1, 0.0)
        else:
            mask = None
        
        # Pass por capas
        attentions = []
        for layer in self.layers:
            x = layer(x, mask)
            if layer.layer_idx == len(self.layers) - 1:
                # Guardar attention del ultimo layer
                attentions.append(x)
        
        # Output
        x = self.output_norm(x)
        logits = self.classifier(x)
        
        result = {'logits': logits, 'attentions': attentions}
        
        # Calcular loss si hay labels
        if labels is not None:
            # Shift for language modeling
            shift_logits = logits[:, :-1, :].contiguous()
            shift_labels = labels[:, 1:].contiguous()
            
            # Flatten
            loss = self.criterion(
                shift_logits.view(-1, shift_logits.size(-1)),
                shift_labels.view(-1)
            )
            result['loss'] = loss
        
        return result
    
    def get_weight_decay_params(self) -> list:
        """
        Retorna parametros para weight decay selectivo.
        No aplica weight decay a biases y LayerNorms.
        """
        decay = []
        no_decay = ['bias', 'LayerNorm', 'layer_norm', 'norm']
        
        for name, param in self.named_parameters():
            if not any(nd in name for nd in no_decay):
                decay.append(param)
            else:
                pass  # No decay para biases y norms
        
        return decay


def create_optimizer_with_weight_decay(
    model: TransformerEncoderRegularized,
    learning_rate: float = 1e-4,
    weight_decay: float = 0.01,
) -> torch.optim.Optimizer:
    """
    Crea optimizer con weight decay selectivo.
    AdamW con different decay rates para diferentes parametros.
    """
    # Parametros con decay
    decay_params = model.get_weight_decay_params()
    
    # Parametros sin decay
    no_decay_params = []
    no_decay_names = ['bias', 'LayerNorm', 'layer_norm', 'norm']
    for name, param in model.named_parameters():
        if any(nd in name for nd in no_decay_names):
            no_decay_params.append(param)
    
    optimizer = torch.optim.AdamW([
        {'params': decay_params, 'weight_decay': weight_decay},
        {'params': no_decay_params, 'weight_decay': 0.0},
    ], lr=learning_rate)
    
    return optimizer

⚠️ Errores Comunes En Regularizacion De Transformers

Error 1: Usar dropout igual en todas las capas

El problema: Aplicar el mismo dropout rate en todas las capas ignora que capas profundas tienden a overfittear mas. El 70% de implementaciones usan dropout uniforme.

Fix: Implementar adaptive dropout que aumenta el dropout rate en capas mas profundas, o usar stochastic depth para saltarse capas enteras.

Error 2: No usar label smoothing

El problema: Con cross-entropy standard, el modelo puede volverse sobreconfident, asignando probabilidades cercanas a 0 o 1. Esto lleva a poor calibration y overfitting a labels especificos.

Fix: Usar label smoothing (0.1 es un buen default). En lugar de 100% certeza en la clase correcta, usar 90% para la clase correcta y 10% distribuido entre las demas.

Error 3: Aplicar weight decay a todo

El problema: Aplicar weight decay a biases y LayerNorms puede dañar el entrenamiento. Estos parametros necesitan ser pequenos para funcionar bien. El 60% de implementaciones aplican decay a todo.

Fix: Separar explicitamente los parametros en grupos con y sin decay. Solo aplicar weight decay a weights de matrices densas y embeddings.

✅ Resumen Y Cierre

  • Adaptive Dropout: Capas profundas necesitan mas regularizacion.
  • Stochastic Depth: Salta capas aleatoriamente - muy efectivo para transformers profundos.
  • Label Smoothing: Previene overconfidence y mejora generalizacion.
  • Weight Decay Selectivo: Solo decay en weights, no en biases ni norms.
  • Pre-norm vs Post-norm: Pre-norm es mas estable para training de transformers profundos.

Hagale que la regularizacion en transformers no es "apagar cosas al azar". Es una ciencia que requiere entender como la informacion fluye por el modelo. Implementen estas tecnicas desde el principio, parcero.
