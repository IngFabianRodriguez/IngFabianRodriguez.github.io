Weight Initialization - La Base De Una Buena Red

27 de junio de 2026
weight-initxavierhe-initializationneural-networks

Parcero, día 178 y hoy我们来聊聊 Weight Initialization — el foundation sobre el cual construyes redes que realmente aprenden. Si tus gradientes desaparecen o explotan desde el primer batch, el problema probablemente empezó con cómo inicializaste los pesos. De una.

Weight initialization no es glamour, pero es critical. La diferencia entre una red que converge en 10 epochs y una que nunca pasa del random guessing muchas veces está en cómo inicializaste los pesos. Es el foundation que el 80% ignora porque "ya viene por defecto".

🎯 Por Qué Importa la Inicialización

Imaginemos una red feedforward con 10 capas. Cada capa hace:

$$h^{(l)} = \sigma(W^{(l)} h^{(l-1)} + b^{(l)})$$

Durante backpropagation, el gradiente fluye hacia atrás multiplicando por los pesos:

$$\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial h^{(L)}} \cdot W^{(L)} \cdot W^{(L-1)} \cdot ... \cdot W^{(l+1)}$$

Si los pesos son > 1, los gradientes explotan (multiplicación en cadena). Si son < 1, desaparecen. Solo con pesos cerca de 1 la señal fluye bien.

📐 Inicialización Xavier/Glorot

Xavier initialization propone inicializar con varianza específica:

$$W \sim \mathcal{N}\left(0, \frac{2}{n_{in} + n_{out}}\right)$$

O uniforme:

$$W \sim U\left(-\frac{\sqrt{6}}{\sqrt{n_{in} + n_{out}}}, \frac{\sqrt{6}}{\sqrt{n_{in} + n_{out}}}\right)$$

Donde n_in y n_out son el número de entradas y salidas de la capa.

La intuición: mantener la varianza deactivaciones y gradientes constante a través de las capas.

import torch
import torch.nn as nn

def xavier_init(m):
    """Inicialización Xavier para capas lineales."""
    if isinstance(m, nn.Linear):
        nn.init.xavier_uniform_(m.weight)
        if m.bias is not None:
            nn.init.zeros_(m.bias)

# Usage
model = nn.Sequential(
    nn.Linear(768, 512),
    nn.ReLU(),
    nn.Linear(512, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)

model.apply(xavier_init)

💻 Inicialización He para ReLU

Para redes con ReLU, Xavier no es optimal porque ReLU mata la mitad de las activaciones (las negativas). He initialization ajusta la varianza:

$$W \sim \mathcal{N}\left(0, \frac{2}{n_{in}}\right)$$

def he_init(m):
    """Inicialización He para capas con ReLU."""
    if isinstance(m, nn.Linear):
        nn.init.kaiming_uniform_(m.weight, mode='fan_in', nonlinearity='relu')
        if m.bias is not None:
            nn.init.zeros_(m.bias)

# Usage
model = nn.Sequential(
    nn.Linear(768, 512),
    nn.ReLU(),
    nn.Linear(512, 256),
    nn.ReLU(),
    nn.Linear(256, 10)
)

model.apply(he_init)

# O directamente en PyTorch
linear = nn.Linear(768, 512)
nn.init.kaiming_normal_(linear.weight, mode='fan_in', nonlinearity='relu')

⚠️ Errores Comunes con Weight Initialization

Error 1: Usar inicialización por defecto siempre

El problema: PyTorch inicializa con W ~ N(0, 1/sqrt(fan_in) que funciona okay pero no es optimal para deep networks. Para redes profundas, esta inicialización causa vanishing o exploding después de varias capas.

Fix: Para redes con ReLU, usa He initialization. Para redes con sigmoid/tanh, usa Xavier. Para transformers, usa initialization específica (ver siguiente sección).

Error 2: Ignorar el bias initialization

El problema: Todos focusean en los pesos pero los bias también importan. Biases en 0 pueden causar que las primeras activaciones sean muy pequeñas. Biases mal inicializados enBatchNorm pueden causar problemas.

Fix:: Inicializa biases en 0 para la mayoría de casos. Para capas de salida, inicializa en valores razonables. Para bias en LayerNorm, usa 1 para gain y 0 para bias.

Error 3: No adaptar la inicialización al activation function

El problema: Usar Xavier con ReLU es suboptimal porque Xavier asume两边activations son simétricas alrededor de 0, pero ReLU mata las negativas. He initialization corrige esto.

Fix:: Match initialization con activation:

  • ReLU/LeakyReLU → He initialization
  • Sigmoid/Tanh → Xavier initialization
  • Softmax → Xavier o normal pequeña

✅ Resumen y Cierre

  • Weight initialization es el foundation de una red que converge.
  • Xavier: Para sigmoid/tanh. Varianza adaptadas a fan-in + fan-out.
  • He: Para ReLU. Considera que ReLU mata la mitad de las señales.
  • Siempre inicializa biases — no solo los pesos.
  • Match initialization con activation — cada activation tiene propiedades diferentes.

Hágale que weight initialization no es sexy pero salva tu training. Antes de blame el learning rate o la arquitectura, revise cómo inicializó los pesos. El 20% de los problemas de convergencia se resuelven con initialization correcta, parcero.
