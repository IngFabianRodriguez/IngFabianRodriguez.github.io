ImageNet — El dataset que cambió todo

03 de octubre de 2026

La Historia Del Dataset Que Hizo Posible Deep Learning

Antes de 2012, la comunidad de computer vision trabajaba con datasets pequeños: Caltech 101 (9,000 imágenes), PASCAL VOC (20,000 imágenes). Los modelos se overfitteaban fácilmente porque no había suficiente diversidad. Fei-Fei Li tuvo una visión: crear un dataset masivo que cubriera las 80,000+ categorías de nouns en inglés. Así nació ImageNet — 14 millones de imágenes etiquetadas a mano en 22,000 categorías. Pero lo más importante no fue el tamaño. Fue el ImageNet Large Scale Visual Recognition Challenge (ILSVRC) — la competencia anual que convirtió computer vision en un campo de investigación con benchmark claro.

ImageNet En Números

Para entender la escala de ImageNet:

  • 14 millones de imágenes total en ImageNet
  • 22,000 categorías de objetos (synsets de WordNet)
  • 1.2 millones de imágenes en ILSVRC training set
  • 150,000 imágenes en ILSVRC validation set
  • 1000 categorías en ILSVRC (el subset más famoso)

El ILSVRC: La Competencia Que Cambió Todo

Desde 2010, ILSVRC se convirtió en el campo de batalla donde se medían las arquitecturas. La métrica principal era Top-5 Error Rate: la fracción de imágenes donde el label correcto NO estaba en las 5 predicciones más probables del modelo.

Los Resultados Año Por Año:

  • 2010: Best non-deep learning method — 25% error
  • 2011: Best non-deep learning method — 25.3% error
  • 2012: AlexNet — 16.4% error (¡41% mejor que el segundo lugar!)
  • 2013: ZFNet — 11.7% error
  • 2014: VGG & GoogleNet — 7.3% y 6.7% error
  • 2015: ResNet — 3.6% error (¡mejor que humans!)
  • 2016+: Ensembles llegan a ~2.3% error

El momento crucial fue 2012. AlexNet de Krizhevsky et al. usó deep CNNs y ganó por un margen enorme. Eso convenció a toda la comunidad de que deep learning era el camino. Sin ImageNet, esta historia habría sido mucho más larga.

Construyendo Tu Propio Pipeline de ImageNet

Aunque descargar todo ImageNet requiere mucho storage, podemos construir un pipeline para trabajar con el dataset o subsets del mismo:

Pre-trained Models: El Poder De ImageNet

Lo más valioso de ImageNet no es solo el benchmark — son los modelos pre-entrenados. Un modelo entrenado en ImageNet aprende features genéricos que transfer learn a casi cualquier visión task. Esto es porque las primeras capas aprenden edges y textures (universales), mientras que las últimas capas aprenden features específicos del objeto.

import torchvision.models as models
import torch.nn as nn

# Cargar un modelo pre-entrenado en ImageNet
model = models.resnet50(weights='IMAGENET1K_V1')
print(f"ResNet50 parámetros: {sum(p.numel() for p in model.parameters()):,}")

# Freezar todas las capas excepto la última
for param in model.parameters():
    param.requires_grad = False

# Reemplazar la capa final para tu dataset (ej: 10 clases)
model.fc = nn.Linear(model.fc.in_features, 10)

# Solo los parámetros de fc se entrenan
trainable_params = sum(p.numel() for p in model.parameters() if p.requires_grad)
print(f"Parámetros entrenables: {trainable_params:,}")

# Fine-tuning: entrenar todo el modelo con learning rate bajo
def fine_tune_model(model, train_loader, num_epochs=10):
    optimizer = torch.optim.AdamW([
        {'params': model.fc.parameters(), 'lr': 1e-3},
        {'params': model.layer4.parameters(), 'lr': 1e-4},  # Últimas capas
        {'params': model.parameters(), 'lr': 1e-5},  # Primeras capas
    ], weight_decay=0.01)
    
    criterion = nn.CrossEntropyLoss()
    
    for epoch in range(num_epochs):
        model.train()
        total_loss = 0
        for images, labels in train_loader:
            optimizer.zero_grad()
            outputs = model(images)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()
            total_loss += loss.item()
        
        print(f"Epoch {epoch+1}: loss={total_loss/len(train_loader):.4f}")

# Transfer learning: usar features de ImageNet directamente
model.eval()
def extract_features(dataset, model):
    """Extrae features de la penúltima capa para transfer learning."""
    features = []
    labels = []
    
    with torch.no_grad():
        for images, lbls in DataLoader(dataset, batch_size=256):
            feat = model.avgpool(model.layer4(model.maxpool(model.relu(model.bn1(model.conv1(images))))))
            features.append(feat.view(feat.size(0), -1))
            labels.append(lbls)
    
    return torch.cat(features), torch.cat(labels)

# Features extraídos pueden usarse con cualquier classifier simple
X_features, y_labels = extract_features(cifar100, model)

La Fórmula De Transfer Learning Exitoso

No es solo usar un modelo pre-entrenado y ya. Hay una estrategia:

Step 1: Choose Your Architecture

Para datasets pequeños (< 10K imágenes): EfficientNet-B0 o MobileNetV3 — rápido y eficiente.

Para datasets grandes (> 100K imágenes): ResNet-50 o ViT-B/16 — más capacidad.

Step 2: Freeze vs Fine-tune

def get_transfer_learning_strategy(dataset_size, num_classes):
    """
    Estrategia de transfer learning basada en el tamaño del dataset.
    """
    if dataset_size < 1000:
        # Dataset muy pequeño: freeze todo, solo entrena classifier
        return {
            'freeze_backbone': True,
            'lr_head': 1e-3,
            'epochs': 50,
            'augmentation': 'strong'  # Más augmentation para compensar poco data
        }
    elif dataset_size < 50000:
        # Dataset mediano: freeze early layers, fine-tune late
        return {
            'freeze_backbone': False,
            'freeze_until': 'layer3',  # Freeze layer1 y layer2
            'lr_backbone': 1e-4,
            'lr_head': 1e-3,
            'epochs': 30,
            'augmentation': 'moderate'
        }
    else:
        # Dataset grande: fine-tune todo
        return {
            'freeze_backbone': False,
            'lr_backbone': 1e-5,
            'lr_head': 1e-4,
            'epochs': 20,
            'augmentation': 'light'
        }

strategy = get_transfer_learning_strategy(dataset_size=5000, num_classes=10)
print(f"Estrategia: {strategy}")

Step 3: Data Augmentation Es Crítico

Para datasets pequeños, augmentation puede ser la diferencia entre success y failure:

from torchvision import transforms

# Augmentation para training
train_aug = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.7, 1.0)),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomRotation(15),
    transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2, hue=0.1),
    transforms.RandomAffine(degrees=0, translate=(0.1, 0.1)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
    transforms.RandomErasing(p=0.3),  # Cutout aleatorio
])

# Para validación: solo resize y normalize
val_aug = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

Lecciones de ImageNet Que Aplicas Hoy

1. Dataset > Architecture

AlexNet no ganó por ser la mejor arquitectura — ganó porque tenía más datos y computación. Hoy sigue siendo verdad: datos buenos y diversos superan a arquitecturas sofisticadas con datos mediocre.

2. Benchmarks Impulsan Progreso

ImageNet ILSVRC dio a la comunidad un objetivo claro. Cada mejora se podía medir objetivamente. Eso aceleró la investigación 10x porque todos hablaban el mismo idioma.

3. Pre-training Es El Standard

Casi todo computer vision moderno empieza con ImageNet pre-training. Ya sea que uses ResNet, ViT, o CLIP, el conocimiento de ImageNet está ahí. No partes de cero.

El Error Que El 80% Commete Con Transfer Learning

Usar ImageNet normalization en datos que no son como ImageNet. Si tus imágenes son de microscopía o satellite imagery, los valores mean/std de ImageNet ([0.485, 0.456, 0.406]) no son óptimos. Calcula el mean/std de tu dataset y úsalos. Esto solo no es suficiente — también necesitas domain-specific pre-training si es posible.
