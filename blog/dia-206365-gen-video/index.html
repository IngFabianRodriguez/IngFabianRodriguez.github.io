La Evolución: De VAEs a Diffusion Models

Antes de entender cómo generan imágenes estos modelos, necesitamos el contexto histórico. La generación de imágenes pasó por varias etapas:

  • VAEs (Variational Autoencoders): Codifican una imagen a un espacio latente y decodifican. Rápidos pero borrosos. El Variational Autoencoder original de 2013.
  • GANs (Generative Adversarial Networks): Un generador compite contra un discriminador. Buenos detalles, pero difíciles de entrenar (mode collapse, equilibrio Nash frágil).
  • Diffusion Models (DDPM): La revolución actual. Agrega ruido Gaussian progressivement a una imagen y aprende a revertir el proceso. Resultados increíbles, entrenamiento estable.
  • Latent Diffusion Models (Stable Diffusion): Opera en espacio latente comprimido, no en píxeles directos. Mucho más eficiente computacionalmente.

La Matemática del Diffusion

El diffusion process tiene dos fases:

Forward Process (agregar ruido)

Dado una imagen x₀, agregamos ruido T veces hasta obtener x_T que es aproximadamente ruido Gaussiano puro:

q(x_t | x_{t-1}) = N(x_t; √(1-β_t) x_{t-1}, β_t I)

Donde β_t es una secuencia de varianzas que aumentan gradualmente. Gracias a la propiedad de Markov, podemos muestrear directamente x_t desde x₀:

q(x_t | x_0) = N(x_t; √ᾱ_t x_0, (1 - ᾱ_t) I)

Donde ᾱ_t = ∏ᵢ₌₁ᵗ α_i y α_i = 1 - β_i.

Reverse Process (quitar ruido)

El modelo aprende a revertir el proceso. Approximamos:

p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))

El modelo predice el ruido ε_θ(x_t, t) que se agregó, o equivalentemente, la media μ_θ.

La pérdida: L = E_{t, x_0, ε} [ ||ε - ε_θ(√ᾱ_t x_0 + √(1-ᾱ_t)ε, t)||² ]

Es simplemente MSE entre el ruido real y el ruido predicho.

Stable Diffusion con la Librería Diffusers

# Instalar: pip install diffusers transformers accelerate scipy safetensors

from diffusers import StableDiffusionPipeline, DPMSolverMultistepScheduler
import torch
from PIL import Image
import os

# Configuración: usar GPU si está disponible
device = "cuda" if torch.cuda.is_available() else "cpu"
print(f"Usando dispositivo: {device}")

# Cargar el pipeline de Stable Diffusion
model_id = "stabilityai/stable-diffusion-2-1"
pipe = StableDiffusionPipeline.from_pretrained(
    model_id,
    torch_dtype=torch.float16 if device == "cuda" else torch.float32,
    safety_checker=None,  # Desactivar para generación sin filtro
    requires_safety_checker=False
)

# Optimizaciones para GPU
if device == "cuda":
    pipe = pipe.to(device)
    # Usar DPM-Solver++ para convergencia más rápida
    pipe.scheduler = DPMSolverMultistepScheduler.from_config(
        pipe.scheduler.config,
        use_karras_sigmas=True
    )

print("Modelo cargado exitosamente!")

Text-to-Image: De Prompt a Imagen

def generate_image(
    pipe,
    prompt,
    negative_prompt="",
    num_inference_steps=25,
    guidance_scale=7.5,
    height=512,
    width=512,
    seed=None
):
    """
    Genera una imagen desde un prompt de texto
    
    Args:
        pipe: Pipeline de Stable Diffusion
        prompt: Descripción de la imagen deseada
        negative_prompt: Lo que NO queremos en la imagen
        num_inference_steps: Más steps = mejor calidad (típicamente 20-50)
        guidance_scale: Cuánto seguir el prompt (3-7 típico, >10 distorsiona)
        seed: Para reproducibilidad (-1 = aleatorio)
    """
    # Generador para reproducibilidad
    generator = torch.Generator(device=device)
    if seed is None or seed == -1:
        generator.seed()
    else:
        generator = generator.manual_seed(seed)

    # La magia del CFG (Classifier Free Guidance)
    # El modelo genera dos versiones: una condicionada y una no condicionada
    # y las interpola según guidance_scale
    result = pipe(
        prompt=prompt,
        negative_prompt=negative_prompt,
        num_inference_steps=num_inference_steps,
        guidance_scale=guidance_scale,
        height=height,
        width=width,
        generator=generator,
    )
    
    return result.images[0]

# Ejemplo básico: text-to-image
prompt = "A majestic Colombian coffee farm at sunrise, misty mountains, green coffee plants, golden light, photorealistic, 8K"
negative_prompt = "blurry, low quality, distorted, watermark, text"

image = generate_image(
    pipe,
    prompt=prompt,
    negative_prompt=negative_prompt,
    num_inference_steps=30,
    guidance_scale=7.5,
    seed=42
)

# Guardar la imagen
output_path = "/tmp/colombia_coffee.png"
image.save(output_path)
print(f"Imagen guardada en: {output_path}")

Image-to-Image (img2img): Transformando Imágenes Existentes

from diffusers import StableDiffusionImg2ImgPipeline
import requests
from io import BytesIO

# Cargar pipeline de img2img
pipe_img2img = StableDiffusionImg2ImgPipeline.from_pretrained(
    "stabilityai/stable-diffusion-2-1",
    torch_dtype=torch.float16 if device == "cuda" else torch.float32,
)
pipe_img2img = pipe_img2img.to(device)

# Cargar una imagen desde URL o archivo
def load_image(path_or_url):
    if path_or_url.startswith("http"):
        response = requests.get(path_or_url)
        return Image.open(BytesIO(response.content)).convert("RGB")
    return Image.open(path_or_url).convert("RGB")

# Especificar strength: qué tan lejos del original (0 = idéntico, 1 = irreconocible)
prompt_img2img = "A beautiful Colombian coffee farm transformed into a magical fantasy landscape, surreal art"
init_image = load_image("https://upload.wikimedia.org/wikipedia/commons/thumb/b/b5/Tinto_de_agua.jpg/800px-Tinto_de_agua.jpg")

processed_image = pipe_img2img(
    prompt=prompt_img2img,
    image=init_image,
    strength=0.75,  # 75% de transformación
    guidance_scale=7.5,
    num_inference_steps=30,
).images[0]

processed_image.save("/tmp/img2img_result.png")
print("img2img completado!")

Inpainting: Editar Partes Específicas de una Imagen

from diffusers import StableDiffusionInpaintPipeline
import numpy as np

pipe_inpaint = StableDiffusionInpaintPipeline.from_pretrained(
    "stabilityai/stable-diffusion-2-inpainting",
    torch_dtype=torch.float16 if device == "cuda" else torch.float32,
)
pipe_inpaint = pipe_inpaint.to(device)

# Crear una máscara para inpainting
# La máscara es blanca donde queremos generar, negra donde preservamos
def create_mask(image, region="center"):
    """Crea una máscara para inpainting"""
    width, height = image.size
    mask = Image.new("RGB", (width, height), "black")
    
    if region == "center":
        # Región central:box desde 1/4 a 3/4
        from PIL import ImageDraw
        draw = ImageDraw.Draw(mask)
        x1, y1 = width // 4, height // 4
        x2, y2 = 3 * width // 4, 3 * height // 4
        draw.rectangle([x1, y1, x2, y2], fill="white")
    
    return mask

# Imagen original (puede ser un sketch o boceto)
init_image = load_image("/tmp/sketch.png")
mask_image = create_mask(init_image, region="center")

prompt_inpaint = "A hyperrealistic Colombian gold museum artifact, intricate details, museum lighting"

inpainted = pipe_inpaint(
    prompt=prompt_inpaint,
    image=init_image,
    mask_image=mask_image,
    num_inference_steps=30,
    guidance_scale=7.5,
).images[0]

inpainted.save("/tmp/inpainted_result.png")
print("Inpainting completado!")

Parámetros Clave Explicados

CFG Scale (Classifier-Free Guidance)

El CFG controla cuánto sigue el modelo su prompt versus generando cosas aleatorias:

  • CFG 2-4: Creativo pero puede no seguir bien el prompt
  • CFG 7-9: Balance ideal, seguir prompt + calidad
  • CFG 11-15: Muy adherente al prompt pero saturación y distorsión
  • CFG > 15: Generalmente oversaturation, artefactos, inutilizable

Number of Inference Steps

Diffusion es un proceso iterativo. Cada step es una denoising iteration:

  • 10-15 steps: Rápido, calidad aceptable para previews
  • 25-35 steps: El punto óptimo actual
  • 50+ steps: Retornos marginales, solo para casos donde se necesita máxima calidad
Math: El proceso de denoising discretiza la ODE q(x_t|x_{t+1}). Más steps = mejor aproximación de la solución verdadera, pero después de ~30 steps el improvement es casi imperceptible.

Los 3 Errores Más Comunes

Error 1: No Usar Negative Prompts

El problema: Los modelos de difusión generan de todo por default, incluyendo cosas que no queremos. Sin negative prompts, obtienes watermark, texto, dedos多余的, deformidades, etc.

La solución: SIEMPRE incluir negative prompts, especialmente los clásicos:

negative_prompt = (
    "blurry, low quality, distorted, watermark, text, "
    "cropped, out of frame, poorly drawn face, deformed, "
    "extra limbs, malformed hands, missing fingers, "
    "signature, username, artist name, disfigured, "
    "mutation, mutated, ugly, disgusting"
)

image = generate_image(
    pipe,
    prompt="A Colombian street market, vibrant colors",
    negative_prompt=negative_prompt,
    # ... rest of params
)

Error 2: CFG Scale Demasiado Alto — Oversaturation

El problema: Con CFG > 12, la imagen se satura de colores, los detalles se distorsionan, los rostros se vuelven irreconocibles. El modelo "overcompensates" siguiendo ciegamente el prompt.

La solución: Mantener CFG entre 7-9 para la mayoría de prompts. Si necesita mayor adherencia al prompt:

# En lugar de CFG=15, pruebe:
# 1. Mejorar el prompt (más específico, menos ambiguo)
# 2. Usar weighted negative prompts para ajustar cosas específicas
# 3. Usar LoRA adapters para estilizar sin CFG extremo

# Si absolutamente necesita CFG alto (ej: para prompts muy específicos)
# combine con lower strength en img2img
result = pipe_img2img(
    prompt="Highly detailed architectural render",
    image=init_image,
    strength=0.4,  # Menos transformación
    guidance_scale=11,  # CFG más alto pero con menos transformación total
    num_inference_steps=30,
).images[0]
Regla empírica: CFG × Strength debería estar entre 5-10 para resultados estables. CFG alto + Strength alto = caos.

Error 3: No Entender que Diffusion es Iterativo y Necesita Steps Suficientes

El problema: Muchos usuarios ponen solo 5-10 steps y se preguntan por qué la imagen está borrosa o tiene artefactos. El denoising necesita tiempo para converger — con pocos steps, el proceso está a medio camino.

La solución: Entender la mecánica — la imagen se forma gradualmente:

# Visualicemos cómo se forma la imagen step by step
def generate_with_intermediates(
    pipe, prompt, negative_prompt, num_steps=30, guidance_scale=7.5
):
    """Genera imagen guardando todos los pasos intermedios"""
    from diffusers import DiffusionPipeline
    
    # Callback para guardar cada step
    intermediates = []
    
    def callback_on_step(pipe, step, timestep, callback_kwargs):
        latents = callback_kwargs.get("latents", None)
        if latents is not None and step % 5 == 0:
            # Decodificar latentes para ver progreso
            with torch.no_grad():
                img = pipe.vae.decode(
                    latents / pipe.vae.config.scaling_factor,
                    return_dict=False
                )[0]
            intermediates.append(img)
        return callback_kwargs
    
    result = pipe(
        prompt=prompt,
        negative_prompt=negative_prompt,
        num_inference_steps=num_steps,
        guidance_scale=guidance_scale,
        callback_on_step_end=callback_on_step,
    )
    
    return result.images[0], intermediates

# Con 5 steps vs 30 steps - la diferencia es drástica
# Step 1-5: casi puro ruido
# Step 10: formas vagamente reconocibles
# Step 20: estructura clara pero detalles borrosos
# Step 30: imagen completa y nítida

# Recomendación: NUNCA usar menos de 20 steps para producción
# Para testing/iteración rápida: 10-15 steps
# Para producto final: 25-35 steps
La matemática: Con T steps de denoising, cada step invierte una pequeña porción del proceso de difusión. El teorema de Wong tiene que ver con la convergencia de discretizaciones de ODE — necesitas suficientes steps para que el error de discretización sea pequeño. En la práctica: ≥25 steps para Stable Diffusion.

Resumen y Cierre

Hoy cubrimos la generación de imágenes con IA desde el ángulo práctico:

  • DALL-E vs Stable Diffusion: DALL-E es API cerrada de OpenAI; SD es open source y puedes correrlo localmente
  • La matemática del diffusion: Forward process (agregar ruido) y reverse process (quitar ruido, lo que se aprende)
  • Latent Diffusion: Opera en espacio latente comprimido, por eso SD es eficiente
  • Text-to-Image: Del prompt de texto a la imagen con CFG y steps
  • img2img: Transformar imágenes existentes con strength control
  • Inpainting: Editar regiones específicas con máscaras
  • Negative prompts: Imprescindibles para calidad
  • CFG scale: Mantener entre 7-9, no más de 12
  • Inference steps: Mínimo 25 para calidad producción

La generación de imágenes con IA pasó de ser curiosidad de investigación a herramienta de producción en menos de 3 años. Y lo mejor: con Stable Diffusion puedes correrlo en tu propia máquina, sin dependencias de APIs externas.
