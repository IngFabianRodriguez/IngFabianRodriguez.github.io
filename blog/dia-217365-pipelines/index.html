LoRA - Low-Rank Adaptation Para Fine-tuning Eficiente

Hagale pues, parcero. Dia 217 y hoy hablamos de LoRA, Low-Rank Adaptation, la revolucion en fine-tuning eficiente. Dejala el cafe.

🎯 Que Es LoRA?

LoRA (Low-Rank Adaptation) es una tecnica de fine-tuning que agrega pequenas matrices descomponuestas en lugar de entrenar todos los parametros. Esto reduce drásticamente el costo computacional.

Conceptos clave:

  • Low-Rank Decomposition: Descomponer actualizaciones en matrices pequenas
  • rank r: Tamano de las matrices decomponidas
  • congelar Pesos: Los pesos originales no se entrenan
  • Delta Weights: Solo se entrenan las matrices A y B

📐 La Matematica De LoRA

En lugar de actualizar W directamente, aprendemos una descomposicion:

import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, rank=4, alpha=1.0):
        super().__init__()
        self.rank = rank
        self.alpha = alpha
        
        # Frozen original weights
        self.weight = nn.Parameter(torch.randn(out_features, in_features))
        self.weight.requires_grad = False
        
        # Trainable LoRA parameters
        self.lora_A = nn.Parameter(torch.randn(rank, in_features))
        self.lora_B = nn.Parameter(torch.zeros(out_features, rank))
    
    def forward(self, x):
        # W + (alpha/rank) * BA
        return (self.weight + (self.alpha / self.rank) * self.lora_B @ self.lora_A) @ x

🚀 LoRA En Hugging Face

from peft import LoraConfig, get_peft_model

config = LoraConfig(
    r=8,  # rank
    lora_alpha=16,
    target_modules=["q_proj", "v_proj"],  # cuales capas modificar
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

model = get_peft_model(base_model, config)
model.print_trainable_parameters()
# Trainable: 0.19% of parameters!

⚠️ Errores Comunes

Error 1: Rank Muy Bajo

El problema: Capacidad insuficiente para aprender tareas complejas.

La solucion: Empieza con r=8 o 16 para modelos pequenos, hasta 64 para grandes.
