Contrastive Learning: El Aprendizaje Que el 75% No Sabe Que Existe

Hagale pues, parcero. Día 196 y hoy hablamos de contrastive learning — la técnica que usan SimCLR, CLIP, DALL-E y prácticamente todos los modelos de representación modernos. El 75% de los developers no sabe cómo funciona internamente ni cómo implementarla. Vamos con café.

🎯 Por Qué Necesitas Aprender Sin Labels

El problema: etiquetar datos es caro y lento. Tienes 10 millones de imágenes de productos y necesitas clasificarlas. ¿Contratas 100 personas para etiquetar todo? No, usas contrastive learning.

Contrastive learning aprende representations densas sin necesidad de labels. La idea: items similares (misma clase) deben tener representaciones cercanas, items distintos (clases diferentes) deben estar lejos.

Conceptos clave:

  • Positive pairs: Dos vistas del mismo item — deben acercerse
  • Negative pairs: Vistas de items distintos — deben alejarse
  • InfoNCE loss: Normalized Cross-Entropy loss que separa positivos de negativos
  • Temperature: Controla cuán tajamutril es la distribución de similitud

📐 La Matemática Del Contrastive Loss

InfoNCE (Noise Contrastive Estimation) es la función de pérdida fundamental:

$$\mathcal{L} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k)/\tau)}$$

Donde:

  • $z_i, z_j$ son embeddings de un positive pair
  • $\tau$ es la temperature (típicamente 0.01-0.1)
  • El denominador suma sobre todos los negative pairs
  • $\text{sim}(u,v) = \frac{u^T v}{|u||v|}$ (similitud coseno)

Intuitivamente: maximizar la probabilidad del positivo vs. todos los negativos.

🚀 Implementación en PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F
from torchvision import transforms
import torchvision.models as models

class SimCLR(nn.Module):
    """SimCLR: Simple Contrastive Learning of Visual Representations."""
    def __init__(self, feature_dim=128, temperature=0.07):
        super().__init__()
        # Encoder base (ResNet-18 sin la capa final)
        self.encoder = models.resnet18(pretrained=False)
        self.encoder.fc = nn.Identity()  # Quitar clasificación
        
        # Projection head: h -> z
        self.projection_head = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, feature_dim)
        )
        self.temperature = temperature
    
    def encode(self, x):
        """Encode image a features (h)."""
        return self.encoder(x)
    
    def project(self, h):
        """Project features a embeddings (z)."""
        return self.projection_head(h)
    
    def forward(self, x1, x2):
        # Dos augmentations del mismo batch
        h1 = self.encode(x1)
        h2 = self.encode(x2)
        
        z1 = self.project(h1)
        z2 = self.project(h2)
        
        return z1, z2


def contrastive_loss(z1, z2, temperature=0.07):
    """
    InfoNCE loss para SimCLR.
    z1, z2: embeddings de los dos augmented views, shape (batch_size, feature_dim)
    """
    batch_size = z1.shape[0]
    
    # Normalizar embeddings
    z1 = F.normalize(z1, dim=1)
    z2 = F.normalize(z2, dim=1)
    
    # Concatenar: [z1, z2] es el batch completo
    # Los primeros batch_size son z1, los segundos son z2
    z = torch.cat([z1, z2], dim=0)  # (2*batch_size, feature_dim)
    
    # Matriz de similitud: (2N, 2N)
    sim_matrix = torch.matmul(z, z.T) / temperature
    
    # Crear mask para positivos
    # Positive pairs: (i, i+N) y (i+N, i) para i in [0, N)
    labels = torch.cat([
        torch.arange(batch_size, device=z.device),
        torch.arange(batch_size, device=z.device)
    ]).long()
    
    # Mask diagonal: no comparar con sí mismo
    mask = torch.eye(2 * batch_size, device=z.device).bool()
    sim_matrix.masked_fill_(mask, float('-inf'))
    
    # Loss: cross-entropy entre similitud y labels
    loss = F.cross_entropy(sim_matrix, labels)
    return loss


def nt_xent_loss(z1, z2, temperature=0.07, batch_size=None):
    """
    NT-Xent (Normalized Temperature-scaled Cross Entropy) loss.
    Versión optimizada.
    """
    if batch_size is None:
        batch_size = z1.shape[0]
    
    # Normalizar
    z1 = F.normalize(z1, dim=1)
    z2 = F.normalize(z2, dim=1)
    
    # Concatenar representaciones
    z = torch.cat([z1, z2], dim=0)
    
    # Similitud coseno
    sim = torch.matmul(z, z.T) / temperature
    
    # Mask diagonal
    sim.fill_diagonal_(float('-inf'))
    
    # Positive similarity: [0, N) con [N, 2N) y vice versa
    pos_sim = torch.cat([
        torch.diag(sim, batch_size),
        torch.diag(sim, -batch_size)
    ]).reshape(2 * batch_size, 1)
    
    # Loss
    loss = -torch.log(torch.exp(pos_sim) / torch.exp(sim).sum(dim=1)).mean()
    return loss

🎯 CLIP-Style Learning

class CLIP(nn.Module):
    """CLIP: Contrastive Language-Image Pretraining."""
    def __init__(self, embed_dim=512):
        super().__init__()
        from transformers import CLIPTextModel, CLIPVisionModel
        
        # Text encoder
        self.text_encoder = CLIPTextModel.from_pretrained("openai/clip-vit-base-patch32")
        # Image encoder
        self.image_encoder = CLIPVisionModel.from_pretrained("openai/clip-vit-base-patch32")
        
        # Projection heads
        self.text_projection = nn.Linear(768, embed_dim)
        self.image_projection = nn.Linear(768, embed_dim)
        
        self.embed_dim = embed_dim
        self.temperature = nn.Parameter(torch.log(torch.tensor(1.0)))
    
    def encode_image(self, image):
        img_emb = self.image_encoder(image).last_hidden_state
        img_emb = self.image_projection(img_emb[:, 0, :])  # CLS token
        return F.normalize(img_emb, dim=-1)
    
    def encode_text(self, text):
        txt_emb = self.text_encoder(text).last_hidden_state
        txt_emb = self.text_projection(txt_emb[:, 0, :])
        return F.normalize(txt_emb, dim=-1)
    
    def forward(self, images, input_ids, attention_mask):
        # Encode both modalities
        img_emb = self.encode_image(images)
        txt_emb = self.encode_text(input_ids, attention_mask=attention_mask)
        
        # Temperature as learnable parameter
        temperature = torch.exp(self.temperature)
        
        # Contrastive loss
        logits = torch.matmul(img_emb, txt_emb.T) * temperature
        
        # Labels: diagonal es el positivo
        batch_size = images.shape[0]
        labels = torch.arange(batch_size, device=images.device)
        
        # Image-to-text loss + Text-to-image loss
        loss_i2t = F.cross_entropy(logits, labels)
        loss_t2i = F.cross_entropy(logits.T, labels)
        loss = (loss_i2t + loss_t2i) / 2
        
        return loss, img_emb, txt_emb


def zero_shot_classification(model, image, class_names):
    """Clasificación sin training usando CLIP."""
    model.eval()
    
    # Encode image
    img_emb = model.encode_image(image)
    
    # Encode class names como prompts
    prompts = [f"a photo of a {c}" for c in class_names]
    text_inputs = tokenizer(prompts, padding=True, return_tensors="pt")
    
    txt_emb = model.encode_text(
        text_inputs.input_ids, 
        attention_mask=text_inputs.attention_mask
    )
    
    # Similitud
    similarity = torch.matmul(img_emb, txt_emb.T)
    return class_names[similarity.argmax()]

⚠️ Errores Comunes (y Sus Fixes)

Error 1: Contrastive Learning Sin Suficiente Data Augmentation

El problema: Si las augmentations son muy débiles, el modelo no aprende representations útiles. Si solo haces random crop suave, los positivos son casi idénticos.

# ❌ Augmentations muy débiles - no aprende bien

    transforms.ToTensor(),

# → El modelo ve casi la misma imagen = no aprende nada

# ✅ Augmentations fuertes (como SimCLR original)
strong_aug = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.08, 1.0)),
    transforms.RandomHorizontalFlip(),
    transforms.RandomApply([
        transforms.ColorJitter(0.8, 0.8, 0.8, 0.2),
    ], p=0.8),
    transforms.RandomGrayscale(p=0.2),
    transforms.GaussianBlur(kernel_size=23),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], 
                        std=[0.229, 0.224, 0.225])
])
# → El modelo aprende invariance a color, rotate, scale, etc.

# ✅ Regla: augmentation debe ser suficientemente fuerte para que 
# la red NO reconozca el mismo objeto sin aprender features útiles

El fix: Usa augmentations agresivas. La强弱 debe ser tal que un humano no pueda saber qué objeto es sin analizar detalles.

Error 2: Negative Samples De Baja Calidad

El problema: Si tus negative samples son muy similares a los positivos (ej: misma categoría), el modelo se confunde y aprende representations ruidosas.

# ✅ Hard negatives: similares pero no iguales
# "Hard negative mining" - elige los más difíciles
def hard_negative_mining(anchor, positives, candidates, topk=5):
    """Selecciona los negatives más cercanos (más difíciles)."""
    anchor_norm = F.normalize(anchor, dim=1)
    candidates_norm = F.normalize(candidates, dim=1)
    
    # Similitud con todos los candidatos
    sim = torch.matmul(anchor_norm, candidates_norm.T)
    
    # Los más similares PERO no son positivos → hard negatives
    _, indices = torch.topk(sim, topk, largest=True)
    hard_negatives = candidates[indices]
    return hard_negatives

# ✅ Batch construction: mezcla categorías
def construct_batch(images, labels, batch_size=32):
    """Construir batch con categorías mezcladas."""
    unique_labels = torch.unique(labels)
    selected_labels = torch.randperm(len(unique_labels))[:batch_size]
    
    batch_images = []
    batch_labels = []
    for lbl in selected_labels:
        mask = labels == lbl
        imgs = images[mask]
        idx = torch.randperm(len(imgs))[:1]
        batch_images.append(imgs[idx])
        batch_labels.append(lbl)
    
    return torch.cat(batch_images), torch.cat(batch_labels)

El fix: Asegura que tus negatives sean de categorías diferentes. Usa hard negative mining para encontrar los más difíciles si tienes muchas categorías.

Error 3: Temperature No Tunneada

El problema: Temperature controla la "forma" de la distribución de similitud. Si es muy alta, todos los pares se ven igualmente similares. Si es muy baja, un solo negative domina el loss.

# ❌ Temperature fijo arbitrario

class SimCLRWithLearnableTemp(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder = SimCLREncoder()
        # Temperature learnable (inicializada alta)
        self.log_temperature = nn.Parameter(torch.tensor(0.0))
    
    def forward(self, x1, x2):
        z1, z2 = self.encoder(x1), self.encoder(x2)
        temperature = torch.exp(self.log_temperature)  # > 0, inicio ~1.0
        loss = contrastive_loss(z1, z2, temperature)
        return loss

📊 Resumen

  • SimCLR: Dos augmented views del mismo input → contrastive loss entre ellas.
  • InfoNCE: Maximiza similitud de positivos, minimiza similitud de negativos.
  • CLIP: Contrastive learning entre imágenes y texto — permite zero-shot classification.
  • Temperature: Controla qué tan difícil es la tarea. Más bajo = más focus en hard negatives.

Usa SimCLR cuando tengas muchas imágenes sin labels. Usa CLIP cuando tengas pares imagen-texto. Usa temperature learnable cuando no quieras tunear manualmente.
