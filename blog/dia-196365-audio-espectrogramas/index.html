Audio y Espectrogramas: Lo Que el 85% Ignora

15 de julio de 2026

🎯 Por Qué El Audio No Es Solo Ondas

Hagale pues, parcero. Día 196 y hoy hablamos de audio y espectrogramas — el puente entre las ondas de sonido y los modelos que procesan audio. El 85% de los desarrolladores de ML ignora cómo funciona la conversión audio-espectrograma y por qué es importante. Vamos con café.

El problema: un archivo de audio es solo una serie de números (amplitud en el tiempo). Pero las redes neuronales necesitan representarlo de forma que capture la información relevante — frecuencia, tono, timbre. Eso es exactamente lo que hacen los espectrogramas.

Conceptos clave:

  • Waveform: Representación cruda del audio como señal 1D (amplitud vs tiempo)
  • Spectrogram: Representación 2D de frecuencia vs tiempo
  • Mel Spectrogram: Espectrograma usando la escala Mel (más cercana a percepción humana)
  • MFCCs: Mel Frequency Cepstral Coefficients — features compactas para speech recognition

📐 La Matemática de la Transformada de Fourier

La base de todo es la Short-Time Fourier Transform (STFT):

$$X(m, \omega) = \sum_{n=-\infty}^{\infty} x[n] w[n-m] e^{-j\omega n}$$

Donde $w[n]$ es una ventana (típicamente Hann o Hamming) y $m$ indica la posición temporal.

El espectrograma se define como:

$$S(m, k) = |X(m, \omega_k)|^2$$

Donde $k$ indexa las frecuencias.

Escala Mel:

La escala Mel transforma la frecuencia lineal a una escala perceptual:

$$f_{mel} = 2595 \log_{10}\left(1 + \frac{f}{700}\right)$$

Esto hace que las frecuencias bajas estén más separadas (más resolución) y las altas estén más juntas — similar a cómo percibimos el sonido los humanos.

🚀 Implementación en Python

import numpy as np
import librosa
import librosa.display
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

class AudioProcessor:
    """Procesador de audio para ML: waveform -> spectrogram -> mel."""
    def __init__(self, sample_rate=22050, n_fft=2048, hop_length=512, 
                 n_mels=128, n_mfcc=20):
        self.sample_rate = sample_rate
        self.n_fft = n_fft
        self.hop_length = hop_length
        self.n_mels = n_mels
        self.n_mfcc = n_mfcc
    
    def load_audio(self, file_path):
        """Carga un archivo de audio."""
        waveform, sr = librosa.load(file_path, sr=self.sample_rate)
        return waveform, sr
    
    def waveform_to_spectrogram(self, waveform):
        """STFT: onda -> espectrograma de magnitud."""
        # Short-Time Fourier Transform
        stft = librosa.stft(
            waveform,
            n_fft=self.n_fft,
            hop_length=self.hop_length,
            window='hann'
        )
        # Magnitud (nos deshacemos de la fase)
        spectrogram = np.abs(stft)
        return spectrogram
    
    def spectrogram_to_mel(self, spectrogram):
        """Espectrograma lineal -> Mel spectrogram."""
        mel_basis = librosa.filters.mel(
            sr=self.sample_rate,
            n_fft=self.n_fft,
            n_mels=self.n_mels
        )
        # Proyectar a escala Mel
        mel_spectrogram = np.dot(mel_basis, spectrogram)
        # Log-scale (más cercano a percepción humana)
        mel_spectrogram_db = librosa.power_to_db(mel_spectrogram, ref=np.max)
        return mel_spectrogram_db
    
    def extract_mfcc(self, waveform):
        """Extrae MFCCs del waveform."""
        mfccs = librosa.feature.mfcc(
            y=waveform,
            sr=self.sample_rate,
            n_mfcc=self.n_mfcc,
            n_fft=self.n_fft,
            hop_length=self.hop_length
        )
        # Normalizar
        mfccs = (mfccs - mfccs.mean(axis=1, keepdims=True)) / mfccs.std(axis=1, keepdims=True)
        return mfccs
    
    def process(self, waveform):
        """Pipeline completo: waveform -> spectrogram -> mel."""
        spectrogram = self.waveform_to_spectrogram(waveform)
        mel = self.spectrogram_to_mel(spectrogram)
        mfcc = self.extract_mfcc(waveform)
        return {
            'waveform': waveform,
            'spectrogram': spectrogram,
            'mel_spectrogram': mel,
            'mfcc': mfcc
        }
    
    def visualize(self, waveform, mel_spectrogram, title="Audio Analysis"):
        """Visualiza waveform y mel spectrogram."""
        fig, axes = plt.subplots(2, 1, figsize=(12, 8))
        
        # Waveform
        axes[0].plot(waveform)
        axes[0].set_title('Waveform')
        axes[0].set_xlabel('Tiempo (samples)')
        axes[0].set_ylabel('Amplitud')
        
        # Mel Spectrogram
        img = librosa.display.specshow(
            mel_spectrogram, 
            x_axis='time', 
            y_axis='mel',
            sr=self.sample_rate,
            ax=axes[1]
        )
        axes[1].set_title('Mel Spectrogram')
        fig.colorbar(img, ax=axes[1], format='%+2.0f dB')
        
        plt.tight_layout()
        plt.savefig(f'{title}.png')
        plt.show()


def audio_to_tensor(waveform, target_length=22050 * 5):
    """Convierte waveform a tensor para PyTorch."""
    # Pad o truncate a longitud fija
    if len(waveform) < target_length:
        waveform = np.pad(waveform, (0, target_length - len(waveform)))
    else:
        waveform = waveform[:target_length]
    
    # Convertir a tensor (1, T)
    return torch.from_numpy(waveform).float().unsqueeze(0)

import torch

class AudioCNN(nn.Module):
    """CNN para clasificación de audio usando mel spectrograms."""
    def __init__(self, num_classes=10, in_channels=1):
        super().__init__()
        
        # Conv layers para extraer features del spectrograma
        self.conv1 = nn.Conv2d(in_channels, 32, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(32)
        
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(64)
        
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)
        
        self.conv4 = nn.Conv2d(128, 256, kernel_size=3, padding=1)
        self.bn4 = nn.BatchNorm2d(256)
        
        # Global average pooling
        self.gap = nn.AdaptiveAvgPool2d((1, 1))
        
        # Classifier
        self.fc = nn.Linear(256, num_classes)
    
    def forward(self, x):
        # x shape: (B, 1, n_mels, time_steps)
        
        x = F.relu(self.bn1(self.conv1(x)))
        x = F.max_pool2d(x, 2)
        
        x = F.relu(self.bn2(self.conv2(x)))
        x = F.max_pool2d(x, 2)
        
        x = F.relu(self.bn3(self.conv3(x)))
        x = F.max_pool2d(x, 2)
        
        x = F.relu(self.bn4(self.conv4(x)))
        x = F.max_pool2d(x, 2)
        
        # Global average pooling
        x = self.gap(x)
        x = x.view(x.size(0), -1)
        
        x = self.fc(x)
        return x


class ResidualAudioCNN(nn.Module):
    """CNN con residual connections para audio."""
    def __init__(self, num_classes=10):
        super().__init__()
        
        self.stem = nn.Sequential(
            nn.Conv2d(1, 64, kernel_size=5, stride=2, padding=2),
            nn.BatchNorm2d(64),
            nn.ReLU()
        )
        
        self.res1 = self._make_res_layer(64, 64)
        self.res2 = self._make_res_layer(64, 128, stride=2)
        self.res3 = self._make_res_layer(128, 256, stride=2)
        self.res4 = self._make_res_layer(256, 512, stride=2)
        
        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d((1, 1)),
            nn.Flatten(),
            nn.Dropout(0.5),
            nn.Linear(512, num_classes)
        )
    
    def _make_res_layer(self, in_channels, out_channels, stride=1):
        downsample = None
        if stride != 1 or in_channels != out_channels:
            downsample = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride=stride),
                nn.BatchNorm2d(out_channels)
            )
        
        return nn.ModuleDict({
            'main': nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1),
                nn.BatchNorm2d(out_channels),
                nn.ReLU(),
                nn.Conv2d(out_channels, out_channels, 3, padding=1),
                nn.BatchNorm2d(out_channels)
            ),
            'downsample': downsample if downsample is not None else nn.Identity()
        })
    
    def forward(self, x):
        x = self.stem(x)
        
        for res_layer in [self.res1, self.res2, self.res3, self.res4]:
            identity = x
            out = res_layer['main'](x)
            out = out + res_layer['downsample'](identity)
            x = F.relu(out)
        
        return self.classifier(x)

🎵 WaveNet y Autoregressive Audio Generation

class WaveNet(nn.Module):
    """WaveNet: generación autoregressive de audio."""
    def __init__(self, num_layers=30, num_channels=512, kernel_size=3, num_classes=256):
        super().__init__()
        
        self.num_layers = num_layers
        self.num_channels = num_channels
        self.kernel_size = kernel_size
        self.num_classes = num_classes
        
        # Embedding de entrada (µ-law encoded samples)
        self.embedding = nn.Embedding(num_classes, num_channels)
        
        # Dilated causal conv layers
        self.dilated_convs = nn.ModuleList()
        self.residual_convs = nn.ModuleList()
        self.skip_convs = nn.ModuleList()
        
        for i in range(num_layers):
            dilation = 2 ** (i % 10)  # Dilation grows exponentially, wraps after 10
            padding = (kernel_size - 1) * dilation
            
            self.dilated_convs.append(
                nn.Conv1d(
                    num_channels, 
                    num_channels * 2,  # Gated convolution
                    kernel_size,
                    padding=padding,
                    dilation=dilation
                )
            )
            
            self.residual_convs.append(
                nn.Conv1d(num_channels, num_channels, 1)
            )
            
            self.skip_convs.append(
                nn.Conv1d(num_channels, num_channels, 1)
            )
        
        # Output layers
        self.output_conv1 = nn.Conv1d(num_channels, num_channels, 1)
        self.output_conv2 = nn.Conv1d(num_channels, num_classes, 1)
    
    def forward(self, x):
        """
        x: (B, T) - audio codificado en µ-law
        """
        # Embedding
        x = self.embedding(x)  # (B, T, C)
        x = x.transpose(1, 2)  # (B, C, T)
        
        skip_connections = []
        
        for i in range(self.num_layers):
            # Dilated convolution
            out = self.dilated_convs[i](x)
            
            # Gated activation
            # Split along channel dimension
            in_channels = out.size(1) // 2
            gate = torch.sigmoid(out[:, :in_channels, :])
            data = torch.tanh(out[:, in_channels:, :])
            out = gate * data
            
            # Residual connection
            residual = self.residual_convs[i](out)
            x = x + residual
            
            # Skip connection
            skip = self.skip_convs[i](out)
            skip_connections.append(skip)
        
        # Sum skip connections
        x = sum(skip_connections)
        
        # Output
        x = F.relu(x)
        x = self.output_conv1(x)
        x = F.relu(x)
        x = self.output_conv2(x)
        
        return x
    
    @torch.no_grad()
    def generate(self, start_sample, num_samples, temperature=1.0):
        """Generación autoregressive de audio."""
        self.eval()
        
        generated = start_sample.tolist()
        
        for _ in range(num_samples):
            # Últimos samples del contexto
            context = torch.tensor([generated[-self.kernel_size * 2 ** 10:]], dtype=torch.long).to(next(self.parameters()).device)
            
            # Forward pass
            logits = self.forward(context)
            
            #采样 con temperature
            probs = F.softmax(logits[:, -1, :] / temperature, dim=-1)
            sample = torch.multinomial(probs, 1).item()
            
            generated.append(sample)
        
        return generated


def mu_law_encode(audio, quantization_channels=256):
    """Codificación µ-law para audio."""
    mu = quantization_channels - 1
    
    # Normalizar audio a [-1, 1]
    audio = audio / (np.abs(audio).max() + 1e-8)
    
    # µ-law encoding
    audio = np.sign(audio) * np.log1p(mu * np.abs(audio)) / np.log1p(mu)
    
    # Cuantizar
    audio = ((audio + 1) / 2 * mu + 0.5).astype(np.int32)
    
    return audio


def mu_law_decode(audio, quantization_channels=256):
    """Decodificación µ-law."""
    mu = quantization_channels - 1
    
    # Normalizar a [0, mu]
    audio = audio.astype(np.float32) / mu
    
    # Invertir µ-law
    audio = 2 * audio - 1
    audio = np.sign(audio) * (np.exp(np.abs(audio) * np.log1p(mu)) - 1) / mu
    
    return audio

⚠️ Errores Comunes (y Sus Fixes)

Error 1: Usar Raw Waveform Cuando Un Spectrogram Es Mejor

El problema: Procesar raw waveform es computacionalmente caro y no captura bien las features relevantes para la mayoría de tareas.

# ❌ Raw waveform para clasificación
class RawWaveformCNN(nn.Module):
    def __init__(self):
        super().__init__()
        # Necesita capturar patrones en 22k samples por segundo
        self.conv = nn.Conv1d(1, 64, 100)  # 100 samples ~ 4.5ms
        # No captura bien frecuencias
    
# ✅ Mel spectrogram para clasificación
class SpectrogramCNN(nn.Module):
    def __init__(self):
        super().__init__()
        # (B, 1, n_mels=128, time_steps)
        # Cada time step = ~23ms de audio
        # Cada bin mel = una banda de frecuencia
        self.conv = nn.Conv2d(1, 64, (3, 3))
        # Captura frecuencias y patrones temporales
    
# ✅ Regla: usa spectrogramas para classification/recognition
# Usa raw waveform para generación de audio (WaveNet, TTS)

El fix: Convierte audio a mel spectrogram para la mayoría de tareas de ML. Solo usa raw waveform para generación autoregressive.

Error 2: No Normalizar el Audio

El problema: Audios de diferentes fuentes tienen diferentes amplitudes. Sin normalización, el modelo puede sobreestimar o subestimar ciertos ejemplos.

# ❌ Sin normalización
waveform, sr = librosa.load("audio.wav", sr=22050)
# Amplitud varía según la fuente

# ✅ Normalización por peak
waveform = waveform / np.abs(waveform).max()

# ✅ Normalización por RMS
rms = np.sqrt(np.mean(waveform**2))
waveform = waveform / (rms + 1e-8)

# ✅ VAD (Voice Activity Detection) + normalización
def normalize_with_vad(waveform, sr):
    """Normaliza solo las regiones con voz."""
    # Detectar regiones de voz
    intervals = librosa.effects.split(
        waveform, 
        top_db=20,
        frame_length=2048,
        hop_length=512
    )
    
    # Crear mask
    mask = np.zeros_like(waveform, dtype=bool)
    for start, end in intervals:
        mask[start:end] = True
    
    # Normalizar solo regiones con voz
    voiced_waveform = waveform[mask]
    if len(voiced_waveform) > 0:
        waveform = waveform / (np.abs(voiced_waveform).max() + 1e-8)
    
    return waveform

El fix: Normaliza el waveform antes de convertir a spectrogram. Usa peak normalization o RMS normalization.

Error 3: Elegir Mal Los Parámetros Del Spectrograma

El problema: Los hiperparámetros del espectrograma (n_fft, hop_length, n_mels) afectan la resolución tiempo-frecuencia.

# ❌ Parámetros por defecto sin pensar
n_fft = 2048  # ~93ms por frame
hop_length = 512  # ~23ms de stride
n_mels = 128  # Muchas bandas mel

# ✅ Elegir según la tarea
# Para speech recognition: alta resolución temporal
TASK_CONFIGS = {
    'speech_recognition': {
        'n_fft': 512,      # ~23ms - buena resolución temporal
        'hop_length': 160, # ~7ms - captura fonemas
        'n_mels': 80,      # suficiente para speech
    },
    'music_classification': {
        'n_fft': 2048,     # ~93ms - buena resolución frecuencial
        'hop_length': 512, # ~23ms
        'n_mels': 128,     # más detalle mel
    },
    'speaker_identification': {
        'n_fft': 1024,     # ~46ms
        'hop_length': 256,  # ~12ms
        'n_mels': 64,      # menos bandas - más general
    },
    'sound_event_detection': {
        'n_fft': 2048,
        'hop_length': 512,
        'n_mels': 256,     # máxima resolución mel
    }
}

# ✅ Regla:权衡tiempo vs frecuencia
# n_fft grande = mejor frecuencia, peor tiempo
# n_fft pequeño = mejor tiempo, peor frecuencia
# hop_length pequeño = más frames, más detalle temporal

El fix: Elige n_fft, hop_length y n_mels según tu tarea. Speech recognition necesita alta resolución temporal. Music necesita alta resolución frecuencial.

📊 Resumen

  • STFT: Convierte waveform 1D a spectrograma 2D (frecuencia vs tiempo).
  • Mel Spectrogram: STFT proyectado a escala Mel — más cercano a percepción humana.
  • MFCCs: Features compactas derivadas del mel spectrogram — útiles para speech.
  • WaveNet: CNN autoregresiva para generación de audio raw.

Usa mel spectrogram como input para clasificación de audio. Usa raw waveform para generación autoregresiva. Elige los parámetros del spectrograma según tu tarea — alta resolución temporal para speech, alta resolución frecuencial para música.
