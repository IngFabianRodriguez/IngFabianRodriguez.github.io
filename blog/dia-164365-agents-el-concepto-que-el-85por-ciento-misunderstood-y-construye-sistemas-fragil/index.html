Agents — El concepto que el 85% misunderstood y construye sistemas frágiles

14 de may de 2026
langchainagentsautonomous

Hola, parcero. Llegamos al Día 164 y hoy vamos con Agents. Si pensabas que un "AI agent" es solo un chatbot con accesso a tools, esta vaina te va a volar la cabeza. El 85% construye agentes frágiles porque no entiende el concepto real — y hoy te explico por qué, con código real.

📐 Fundamentos Teóricos

Un Agent (en el contexto de LLMs) es un sistema que puede razonar, planificar, y ejecutar acciones de forma autónoma para lograr un objetivo. No es solo "un modelo que llama functions" — es un sistema completo con memoria, razonamiento, y capacidad de self-correction.

Componentes de un Agent

Un agent tiene cuatro componentes esenciales:

  • Model: El LLM que proporciona la capacidad de razonamiento
  • Tools: Funciones que el agent puede invocar (function calling)
  • Memory: Historial de interacciones y contexto
  • Planning: Capacidad de crear y ejecutar planes de acción

El ciclo ReAct

La mayoría de los agents modernos usan el patrón ReAct (Reasoning + Acting):

# El ciclo ReAct
# 1. Thought: Razonar sobre el estado actual y qué hacer
# 2. Action: Ejecutar una acción (llamar función, buscar, etc.)
# 3. Observation: Observar el resultado
# 4. Repeat

# Ejemplo de ciclo
cycle = [
    {"thought": "El usuario quiere预订 un vuelo. Necesito conocer su destino y fecha.",
     "action": "ask_for_details",
     "observation": "Usuario dijo: Bogotá a Medellín, 20 de mayo"},
    
    {"thought": "Tengo los datos básicos. Ahora busco vuelos disponibles.",
     "action": "search_flights(origin='Bogotá', dest='Medellín', date='2026-05-20')",
     "observation": "3 vuelos encontrados: AV123, AV456, LATAM789"},
    
    {"thought": "Tengo opciones. Le presento las opciones al usuario.",
     "action": "present_options",
     "observation": "Usuario seleccionó AV123"},
    
    {"thought": "El usuario eligió AV123. Procedo a reservation.",
     "action": "book_flight(flight_id='AV123')",
     "observation": "Reserva confirmada: código ABC123"}
]

Tipos de Agents

Hay varios niveles de complejidad:

  • Simple Reflex Agent: Solo reacciona al input actual, sin memoria
  • Model-Based Reflex Agent: Mantiene un estado interno del mundo
  • Goal-Based Agent: Planifica acciones para lograr un objetivo específico
  • Utility-Based Agent: Optimiza una función de utilidad para elegir entre acciones

💻 Implementación Práctica

Vamos con código real. Implementaremos un agent simple con LangChain y luego uno desde cero.

1. Agent básico con LangChain

from langchain.agents import AgentExecutor, create_openai_functions_agent
from langchain.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain.tools import Tool
from langchain_openai import ChatOpenAI
from langchain import hub

# 1. Definir las tools
def search_flights(origin: str, destination: str, date: str) -> dict:
    """Busca vuelos disponibles"""
    # Simulación
    return {
        "flights": [
            {"id": "AV123", "airline": "Avianca", "price": 250000, "time": "06:00"},
            {"id": "AV456", "airline": "Avianca", "price": 280000, "time": "14:30"},
            {"id": "LATAM789", "airline": "LATAM", "price": 265000, "time": "09:15"},
        ]
    }

def book_flight(flight_id: str, passenger_name: str, passenger_id: str) -> dict:
    """Reserva un vuelo"""
    # Simulación
    return {
        "status": "confirmed",
        "booking_code": "ABC123XYZ",
        "flight_id": flight_id,
        "passenger": passenger_name
    }

# Crear tools
tools = [
    Tool(
        name="search_flights",
        func=search_flights,
        description="Busca vuelos disponibles. Input: origin, destination, date"
    ),
    Tool(
        name="book_flight",
        func=book_flight,
        description="Reserva un vuelo. Input: flight_id, passenger_name, passenger_id"
    )
]

# 2. Crear el prompt del agent
prompt = ChatPromptTemplate.from_messages([
    ("system", """Eres un agente de viajes helpful. Ayudas a los usuarios a buscar y reservar vuelos.
    Usa las herramientas disponibles para buscar opciones y hacer reservas.
    Cuando tengas toda la información necesaria (origen, destino, fecha, nombre, ID), haz la reserva."""),
    ("user", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad"),
])

# 3. Crear el agent
llm = ChatOpenAI(model="gpt-4o", temperature=0)
agent = create_openai_functions_agent(llm, tools, prompt)

# 4. Crear el executor
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 5. Ejecutar
result = agent_executor.invoke({
    "input": "Quiero volar de Bogotá a Medellín el 20 de mayo. Mi nombre es Juan Pérez y mi cédula es 12345678."
})
print(result["output"])

2. Agent desde cero (sin LangChain)

import openai
import json
from datetime import datetime

class SimpleAgent:
    """Agent simple sin dependencias externas"""
    
    def __init__(self, tools, system_prompt):
        self.tools = tools
        self.system_prompt = system_prompt
        self.messages = [{"role": "system", "content": system_prompt}]
        self.max_iterations = 10
        self.iteration = 0
    
    def add_message(self, role, content):
        self.messages.append({"role": role, "content": content})
    
    def call_tool(self, tool_name, arguments):
        """Ejecuta una tool"""
        if tool_name not in self.tools:
            return {"error": f"Tool '{tool_name}' no encontrada"}
        return self.tools[tool_name](**arguments)
    
    def run(self, user_input):
        self.add_message("user", user_input)
        
        while self.iteration < self.max_iterations:
            self.iteration += 1
            
            # Obtener respuesta del modelo
            response = openai.ChatCompletion.create(
                model="gpt-4o",
                messages=self.messages,
                functions=self._get_functions_spec(),
                function_call="auto"
            )
            
            message = response["choices"][0]["message"]
            self.messages.append(message)
            
            # Si no hay function call, terminamos
            if not message.get("function_call"):
                return message["content"]
            
            # Ejecutar function call
            function_name = message["function_call"]["name"]
            arguments = json.loads(message["function_call"]["arguments"])
            
            result = self.call_tool(function_name, arguments)
            
            # Agregar resultado al conversation
            self.messages.append({
                "role": "function",
                "name": function_name,
                "content": json.dumps(result)
            })
        
        return "Error: Máximo de iteraciones alcanzado"
    
    def _get_functions_spec(self):
        """Convierte tools a formato OpenAI"""
        specs = []
        for name, func in self.tools.items():
            if hasattr(func, '_schema'):
                specs.append(func._schema)
            else:
                # Generar schema básico
                specs.append({
                    "name": name,
                    "description": func.__doc__ or "Sin descripción",
                    "parameters": {"type": "object", "properties": {}, "required": []}
                })
        return specs

# Ejemplo de uso
def search_weather(location: str) -> str:
    """Busca el clima de una ubicación"""
    return f"El clima en {location} es de 22°C con sol"

def calculate(expr: str) -> str:
    """Calcula una expresión matemática"""
    try:
        result = eval(expr)
        return str(result)
    except:
        return "Expresión inválida"

agent = SimpleAgent(
    tools={
        "search_weather": search_weather,
        "calculate": calculate
    },
    system_prompt="Eres un agente helpful. Usa las herramientas cuando sea necesario."
)

result = agent.run("¿Cuánto es 15 * 23 + 100?")
print(result)

🚨 Errores Comunes y Fixes

Error 1: No tener exit conditions claras

Síntoma: El agent sigue ejecutando acciones indefinidamente sin completar la tarea.

Causa: No hay límite de iteraciones ni forma de detectar cuándo el objetivo está logrado.

Fix: Implementa max_iterations, evalúa explícitamente si el goal está logrado después de cada acción, y usa un stop criterion claro en el prompt.

Error 2: Confundir "agente" con "chatbot con tools"

Síntoma: El sistema parece un agent pero solo hace una llamada a función y termina.

Causa: Falta el ciclo de reasoning y la capacidad de encadenar múltiples acciones basadas en resultados previos.

Fix: Un verdadero agent tiene memoria de estado, puede re-planificar basado en resultados, y hace múltiples iteraciones. Si solo llamas una función, no es un agent — es function calling básico.

Error 3: No manejar tool failures

Síntoma: El agent crashea o se comporta erráticamente cuando una tool falla.

Causa: No hay error handling, timeouts, ni fallback cuando una tool no responde.

Fix: Cada tool debe estar envuelta en try/catch, tener timeouts, y regresar errores estructurados que el agent pueda entender y manejar.

✅ Mejores Prácticas

  • Herramientas específicas sobre generales: Mejor 10 tools especializadas que 1 catch-all.
  • Memoria estructurada: Usa un sistema de memoria que permita contexto relevante, no solo chat history.
  • Self-correction: El agent debe poder evaluar sus propias acciones y corregir errores.
  • Logging detallado: Para debugging, necesitas saber exactamente qué pensó el agent, qué acción tomó, y qué observó.
  • Timeout y fallbacks: Siempre tener plan B cuando algo falla.
