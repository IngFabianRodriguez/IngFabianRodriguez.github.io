La Colombianada de Construir Cerebros Sintéticos

Tu cerebro consume 20 watts. ChatGPT consume 10,000 watts por запрос. Literalmente. Una estimación reciente sugiere que servir un solo query de GPT-4 requiere más energía que cargar tu teléfono para un día.，而我们的大脑却能在20瓦特内完成这一切。 La diferencia: sparsity, event-driven computation, y analog processing.

Neuromorphic computing busca cerrar esta brecha diseñando hardware que procesa información como el cerebro: usando spikes (pulsos), no cálculos continuos. No es deep learning en hardware diferente — es un paradigma completamente distinto de computación.

La fórmula de la eficiencia neuromórfica:
Efficiency = Sparse_Events × Analog_In_Memory × Event_Driven_Updates

Spiking Neural Networks: La Diferencia Fundamental

Las redes neuronales tradicionales son discretas: cada layer procesa todo simultáneamente. Las spiking neural networks (SNNs) son como cerebros reales:

  • Spikes en lugar de valores continuos: Neuronas se disparan (spike) solo cuando llega suficiente input. Silence = no computation.
  • Temporal coding: El timing de los spikes lleva información, no solo su presencia.
  • Plasticidad sináptica: STDP (Spike-Timing-Dependent Plasticity) aprende basado en correlaciones temporales entre spikes.

Esta diferencia es fundamental. En una CNN, siunchanged input, sigues computando cada forward pass. En una SNN, si no hay spikes, no hay trabajo. La sparsity es built-in, no forzada.

Framework de Spiking Neural Networks

"""
SpikingNeuralNetwork: Framework completo para SNNs
Implementa Leaky Integrate-and-Fire neurons y STDP learning.
"""

import numpy as np
from typing import List, Tuple, Optional, Dict, Any
from dataclasses import dataclass
from enum import Enum
import matplotlib.pyplot as plt

class NeuronModel(Enum):
    LIF = "leaky_integrate_and_fire"
    IF = "integrate_and_fire"
    IZHIKEEVICH = "izhikeevich"

@dataclass
class Spike:
    """Representa un spike neuronal."""
    neuron_id: int
    time: float
    layer: int

@dataclass
class SpikeTrace:
    """Trace de追踪 para STDP."""
    pre_trace: float
    post_trace: float

class LeakyIntegrateAndFire:
    """
    Modelo Leaky Integrate-and-Fire (LIF).
    
    La neurona acumula voltaje, pero también 'leaks' constantemente.
    Cuando el voltaje cruza threshold, dispara un spike y se resetea.
    """
    
    def __init__(
        self,
        neuron_id: int,
        tau_mem: float = 20.0,  # Time constant membran (ms)
        v_thresh: float = -50.0,  # Threshold de voltaje (mV)
        v_reset: float = -70.0,  # Voltaje de reset después de spike (mV)
        v_rest: float = -70.0,  # Voltaje de reposo (mV)
        r_mem: float = 10.0,  # Resistencia de membrana (MOhm)
        dt: float = 1.0  # Time step de simulación (ms)
    ):
        self.neuron_id = neuron_id
        self.tau_mem = tau_mem
        self.v_thresh = v_thresh
        self.v_reset = v_reset
        self.v_rest = v_rest
        self.r_mem = r_mem
        self.dt = dt
        
        # Estado
        self.v_mem = v_rest  # Voltaje actual de membrana
        self.last_spike_time = -np.inf
        self.spike_history: List[Spike] = []
        
        # Tracking para STDP
        self.trace = SpikeTrace(pre_trace=0.0, post_trace=0.0)
        
    def update(self, i_input: float, current_time: float) -> Optional[Spike]:
        """
        Actualiza el estado de la neurona.
        
        Args:
            i_input: Corriente de input en este timestep (nA)
            current_time: Tiempo actual de simulación (ms)
            
        Returns:
            Spike si la neurona dispara, None otherwise.
        """
        # Ecuación diferencial: tau * dv/dt = -(v - v_rest) + r * i
        # Discretized: v_new = v_old + dt/tau * (-(v_old - v_rest) + r * i)
        
        dv = self.dt / self.tau_mem * (
            -(self.v_mem - self.v_rest) + 
            self.r_mem * i_input
        )
        
        self.v_mem += dv
        
        # Check for spike
        if self.v_mem >= self.v_thresh:
            spike = Spike(
                neuron_id=self.neuron_id,
                time=current_time,
                layer=0  # Se actualiza después
            )
            
            # Reset
            self.v_mem = self.v_reset
            self.last_spike_time = current_time
            self.spike_history.append(spike)
            
            # Update post-synaptic trace
            self.trace.post_trace = 1.0
            
            return spike
        
        # Decay traces
        self.trace.pre_trace *= np.exp(-self.dt / self.tau_mem)
        self.trace.post_trace *= np.exp(-self.dt / self.tau_mem)
        
        return None
    
    def get_state(self) -> Dict[str, float]:
        return {
            "v_mem": self.v_mem,
            "last_spike": self.last_spike_time,
            "num_spikes": len(self.spike_history),
            "pre_trace": self.trace.pre_trace,
            "post_trace": self.trace.post_trace
        }


class Synapse:
    """
    Sinapsis con STDP (Spike-Timing-Dependent Plasticity).
    
    La fuerza sináptica cambia basada en el timing relativo
    de spikes pre- y post-sinápticos.
    """
    
    def __init__(
        self,
        pre_neuron_id: int,
        post_neuron_id: int,
        initial_weight: float = 0.5,
        tau_plus: float = 20.0,  # Time constant for potentiation (ms)
        tau_minus: float = 20.0,  # Time constant for depression (ms)
        a_plus: float = 0.01,  # Learning rate for potentiation
        a_minus: float = 0.012,  # Learning rate for depression
        w_max: float = 1.0,
        w_min: float = 0.0
    ):
        self.pre_neuron_id = pre_neuron_id
        self.post_neuron_id = post_neuron_id
        
        self.weight = initial_weight
        self.tau_plus = tau_plus
        self.tau_minus = tau_minus
        self.a_plus = a_plus
        self.a_minus = a_minus
        self.w_max = w_max
        self.w_min = w_min
        
    def compute_STDP(
        self, 
        pre_spike_time: float, 
        post_spike_time: float, 
        delta_t: float
    ) -> float:
        """
        Calcula el cambio de peso basado en STDP.
        
        Si pre spike ANTES de post spike (delta_t > 0): potentiation
        Si post spike ANTES de pre spike (delta_t < 0): depression
        """
        if delta_t > 0:
            # Pre before post → potentiation
            dw = self.a_plus * np.exp(-delta_t / self.tau_plus)
        else:
            # Post before pre → depression
            dw = -self.a_minus * np.exp(delta_t / self.tau_minus)
        
        return dw
    
    def update_weight(self, dw: float):
        """Actualiza peso con clamping a [w_min, w_max]."""
        self.weight = np.clip(self.weight + dw, self.w_min, self.w_max)


class SpikingLayer:
    """Capa de neuronas LIF conectadas por sinapsis."""
    
    def __init__(
        self,
        layer_id: int,
        num_neurons: int,
        neuron_params: Optional[Dict[str, float]] = None,
        connect_to: Optional['SpikingLayer'] = None,
        connectivity_prob: float = 0.3
    ):
        self.layer_id = layer_id
        self.num_neurons = num_neurons
        
        # Default LIF params
        default_params = {
            "tau_mem": 20.0,
            "v_thresh": -50.0,
            "v_reset": -70.0,
            "v_rest": -70.0,
            "r_mem": 10.0,
            "dt": 1.0
        }
        if neuron_params:
            default_params.update(neuron_params)
        
        # Crear neuronas
        self.neurons = [
            LeakyIntegrateAndFire(i, **default_params)
            for i in range(num_neurons)
        ]
        
        # Sinapsis a capa siguiente
        self.synapses_out: List[Dict[int, Synapse]] = []
        self.synapses_in: List[Dict[int, Synapse]] = []
        
        if connect_to:
            self._create_synapses(connect_to, connectivity_prob)
    
    def _create_synapses(
        self, 
        target_layer: 'SpikingLayer',
        prob: float
    ):
        """Crea sinapsis probabilísticamente."""
        self.synapses_out = [{} for _ in range(self.num_neurons)]
        target_layer.synapses_in = [{} for _ in range(target_layer.num_neurons)]
        
        for i in range(self.num_neurons):
            for j in range(target_layer.num_neurons):
                if np.random.random() < prob:
                    synapse = Synapse(i, j)
                    self.synapses_out[i][j] = synapse
                    target_layer.synapses_in[j][i] = synapse


class SpikingNeuralNetwork:
    """Red de capas spiking con simulación temporal."""
    
    def __init__(self, layers: List[SpikingLayer], dt: float = 1.0):
        self.layers = layers
        self.dt = dt
        self.current_time = 0.0
        self.all_spikes: List[Spike] = []
        
        # Assign layer info to spikes
        for layer in layers:
            for neuron in layer.neurons:
                neuron.layer = layer.layer_id
    
    def step(self, inputs: Dict[int, float]) -> List[Spike]:
        """
        Un timestep de simulación.
        
        Args:
            inputs: Dict mapping neuron_id -> input current
            
        Returns:
            Lista de spikes en este timestep
        """
        timestep_spikes = []
        
        # Process each layer
        for layer in self.layers:
            layer_spikes = []
            
            for neuron in layer.neurons:
                i_input = inputs.get(neuron.neuron_id, 0.0)
                
                # Input from synaptic currents (populated in previous step)
                syn_input = getattr(neuron, '_syn_input', 0.0)
                total_input = i_input + syn_input
                
                spike = neuron.update(total_input, self.current_time)
                
                if spike:
                    spike.layer = layer.layer_id
                    layer_spikes.append(spike)
                    timestep_spikes.append(spike)
            
            # Propagate spikes to next layer
            if layer.synapses_out:
                for spike in layer_spikes:
                    for post_neuron_id, synapse in layer.synapses_out[spike.neuron_id].items():
                        if post_neuron_id < len(self.layers[layer.layer_id + 1].neurons):
                            post_neuron = self.layers[layer.layer_id + 1].neurons[post_neuron_id]
                            post_neuron._syn_input = synapse.weight * 1.0  # Current from spike
                            
                            # Apply STDP
                            delta_t = self.current_time - spike.time
                            dw = synapse.compute_STDP(spike.time, post_neuron.last_spike_time, delta_t)
                            synapse.update_weight(dw)
            
            # Decay synaptic inputs
            for neuron in layer.neurons:
                if hasattr(neuron, '_syn_input'):
                    neuron._syn_input *= 0.9  # Decay
        
        self.all_spikes.extend(timestep_spikes)
        self.current_time += self.dt
        
        return timestep_spikes
    
    def run_simulation(
        self, 
        input_patterns: List[Dict[int, float]],
        simulation_time: float,
        return_spikes: bool = True
    ) -> Dict[str, Any]:
        """
        Corre simulación completa con múltiples input patterns.
        
        Args:
            input_patterns: Lista de dicts {neuron_id: current} para cada timestep
            simulation_time: Tiempo total de simulación (ms)
            return_spikes: Si True, devuelve todos los spikes
            
        Returns:
            Dict con spikes, firing rates, y estadísticas
        """
        num_steps = int(simulation_time / self.dt)
        output_spikes = []
        
        for step in range(num_steps):
            # Get input for this step
            if step < len(input_patterns):
                inputs = input_patterns[step]
            else:
                inputs = {}
            
            spikes = self.step(inputs)
            output_spikes.extend(spikes)
        
        # Compute firing rates
        firing_rates = {}
        for layer in self.layers:
            layer_neurons = len(layer.neurons)
            layer_spikes = [s for s in output_spikes if s.layer == layer.layer_id]
            if layer_neurons > 0:
                rate = len(layer_spikes) / (layer_neurons * simulation_time * 1000)  # Hz
                firing_rates[layer.layer_id] = rate
        
        return {
            "spikes": output_spikes if return_spikes else [],
            "total_spikes": len(output_spikes),
            "firing_rates": firing_rates,
            "simulation_time": simulation_time,
            "num_steps": num_steps
        }


class NeuromorphicHardware:
    """
    Simulación de hardware neuromórfico.
    Representa chips como Intel Loihi, IBM TrueNorth, Tianjic.
    """
    
    def __init__(self, name: str, cores: int, neurons_per_core: int):
        self.name = name
        self.cores = cores
        self.neurons_per_core = neurons_per_core
        self.total_neurons = cores * neurons_per_core
        
        # Power consumption model
        self.active_core_power = 0.1  # Watts per core cuando activo
        self.idle_power = 0.001  # Watts por core en idle
        self.leakage_power = 0.0001  # Watts por core
        
        self.active_cores = 0
        self.total_energy = 0.0
        
    def simulate_inference(
        self, 
        network: SpikingNeuralNetwork,
        input_data: List[Dict[int, float]],
        simulation_time: float
    ) -> Dict[str, float]:
        """
        Simula inferencia en el hardware.
        
        Returns:
            Dict con latency (ms), energy (J), y throughput (inferences/sec)
        """
        import time
        
        start = time.time()
        result = network.run_simulation(input_data, simulation_time)
        latency_ms = (time.time() - start) * 1000
        
        # Estimate active cores based on spike activity
        active_cores_estimate = min(
            self.cores,
            int(result["total_spikes"] / 100) + 1
        )
        
        # Energy = active_power * time + leakage * time
        energy_j = (
            self.active_core_power * active_cores_estimate * (simulation_time / 1000) +
            self.leakage_power * self.cores * (simulation_time / 1000)
        )
        
        throughput = 1000.0 / latency_ms  # inferences per second
        
        return {
            "latency_ms": latency_ms,
            "energy_j": energy_j,
            "throughput_inps": throughput,
            "spikes_per_inference": result["total_spikes"],
            "avg_firing_rate_hz": np.mean(list(result["firing_rates"].values()))
        }

Hardware Neuromórfico Real

El código above simula SNNs en hardware convencional. Pero hay chips reales diseñados específicamente para esto:

  • Intel Loihi 2: 128 cores, 1M neuronas, 120M sinapsis. On-chip learning con STDP. Consume ~2.5W.
  • IBM TrueNorth: 4096 cores, 1M neuronas, 256M sinapsis. 400mW typical. Diseñado para siempre-on edge AI.
  • BrainScaleS-2: 352 neuronas por chip, 1000x más rápido que tiempo real. Analog compute-in-memory.
  • Tianjic (China): 156 cucore processors, 40K neuronas. Soporta both SNN y ANN en mismo chip.

La ventaja: 100-1000x mejor eficiencia energética que GPUs para ciertas workloads, especialmente sensory processing y robotics.

Los 3 Errores que el 85% Comete con Neuromorphic

Error 1: Pensar que Es Reemplazo para Deep Learning

El 70% ve "neuromorphic" y assume "mejor que transformers". No es cierto. SNNs son excelentes para temporal/spatial patterns, robotics, sensory processing. Son terribles para language modeling, complex reasoning, o cualquier task que requiera precise floating point. Son paradigmas complementarios, no competencia.

Fix: Evalúa neuromorphic para tu use case específico. Si procesas eventos de cameras, audio temporal, o sensores de robotics → sí. Si entrenas LLMs → no. Hybrid approaches (SNN前端 + ANN backend) son el sweet spot.

Error 2: Subestimar la Complejidad de STDP

El 60% intenta implementar STDP básico y se frustra. STDP sounds simple (potentiation si pre antes de post, depression si vice versa) pero los parámetros interactúan de formas complejas. Tau constants, learning rates, y weight initialization afectan drasticamente la convergencia.

Fix: Empieza con implementaciones probadas (como el framework above). Usa surrogate gradient methods si tienes gradient-based training background. Considera convert redes pre-entrenadas a SNNs usando threshold-dependent normalization.

Error 3: No Considerar las Limitaciones de Hardware

El 80% diseña networks teóricamente y luego descubre que no caben en hardware real. DNNs modernas tienen millions de parámetros — chips neuromórficos tienen millions de neuronas pero con conectividad limitada y precisión baja (4-8 bits típicamente).

Fix: Diseña para sparsity desde el inicio. El 90% de sinapsis debería estar cerca de zero. Usa pruning agresivo. Simula en el target hardware antes de comprometerse con una architecture. Herramientas como Nengo, Brian2, o PySnn tienen backends para hardware real.

La Fórmula del Neuromorphic Computing Exitoso

Neuro_Success = Right_Use_Case × STDP_Tuning × Hardware_Aware_Design

Si eliges neuromorphic para el problema correcto (temporal, sparse, low-power), ajustas STDP con understanding de plasticidad biological, y diseñas considerando las limitaciones de hardware real, tienes un sistema que el 85% no puede replicar. Esto es el futuro de always-on AI en edge devices, robotics, y prosthetics.
