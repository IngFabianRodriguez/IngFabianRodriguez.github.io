La Colombianada de Clasificar que el 80% Hace Mal

En un call center en Medellín, un equipo de 15 personas clasificaba correos de clientes en 8 categorías: quejas, solicitudes, felicitaciones, devoluciones, garantías, facturación, soporte técnico, y "otros". 15 personas. Tiempo completo. Clasificando correos. El algoritmo que desarrollaron con LLM lo hizo en 3 semanas de desarrollo y ahora lo hace en tiempo real con 94% de accuracy. Pero el primer intento — como el de la mayoría — falló miserablemente.

El 80% de quienes usan LLMs para clasificación cometen errores evitables. Fine-tunean cuando no necesitan, no evalúan con métricas reales, ignoran el desbalance de clases. El 20% restante construye classifiers que realmente funcionan en producción. Hoy te enseño cómo joining that 20% — con código real, métricas reales, y la honestidad que el problema merece.

La fórmula de un buen classifier es:
Classifier_Quality = P(Correct) × Class_Balance × Metric_Appropriateness

P(Correct) es la accuracy general (0-1). Class_Balance es qué tan bien manejas clases desbalanceadas (0-1). Metric_Appropriateness es si usas la métrica correcta para tu caso (0-1). Multiplicados, si cualquiera es cero, el classifier falla.

Zero-Shot vs Fine-Tuned: La Decisión que el 70% Toma Mal

Hay dos formas de clasificar con LLMs:

  1. Zero-shot classification: Le das al LLM las categorías y el texto. No necesita ejemplos. Solo le describes qué es cada categoría.
  2. Fine-tuned classification: Entrenas el modelo con ejemplos etiquetados. El modelo aprende los patrones específicos de tu dominio.

El 70% hace fine-tuning cuando zero-shot bastaría. O peor: usa zero-shot cuando fine-tuning es necesario.

La regla es simple:

  • Usa zero-shot cuando: tienes categorías genéricas (sentiment, topic, intent), no tienes datos etiquetados, o necesitas flexibilidad para cambiar categorías rápido.
  • Usa fine-tuning cuando: las categorías son muy específicas de tu dominio, necesitas accuracy > 90%, o el zero-shot falla consistentemente.

Si puedes describir las categorías en una frase, usa zero-shot. Si necesitas 20 ejemplos para explicar la diferencia entre dos categorías, necesitas fine-tuning.

"""
ClassificationFramework: Framework completo para clasificar texto con LLMs
Soporta zero-shot, fine-tuned, y evaluación con métricas apropiadas.
"""

import anthropic
import json
import re
from typing import Dict, List, Optional, Tuple, Any, Literal
from dataclasses import dataclass, field
from enum import Enum
from collections import Counter, defaultdict
import numpy as np
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    confusion_matrix, classification_report
)

client = anthropic.Anthropic()

class ClassificationApproach(Enum):
    ZERO_SHOT = "zero_shot"
    FEW_SHOT = "few_shot"
    FINE_TUNED = "fine_tuned"

@dataclass
class ClassificationResult:
    predicted_class: str
    confidence: float  # 0-1
    all_scores: Dict[str, float]  # scores para todas las clases
    approach: ClassificationApproach
    processing_time_ms: float

@dataclass
class EvaluationMetrics:
    accuracy: float
    precision_macro: float
    recall_macro: float
    f1_macro: float
    precision_weighted: float
    recall_weighted: float
    f1_weighted: float
    per_class_metrics: Dict[str, Dict[str, float]]
    confusion_matrix: List[List[int]]
    class_distribution: Dict[str, int]
    recommended_metric: str

@dataclass
class LabeledExample:
    text: str
    label: str

class ZeroShotClassifier:
    """
    Clasificador zero-shot usando LLMs.
    Ideal para categorías genéricas sin datos etiquetados.
    """

    def __init__(self, model: str = "claude-sonnet-4-20250514"):
        self.client = anthropic.Anthropic()
        self.model = model

    def classify(
        self,
        text: str,
        categories: List[str],
        category_descriptions: Optional[Dict[str, str]] = None,
        return_scores: bool = True
    ) -> ClassificationResult:
        """
        Clasifica texto en una de las categorías dadas.

        Args:
            text: Texto a clasificar
            categories: Lista de nombres de categorías
            category_descriptions: Descripción detallada de cada categoría
            return_scores: Si True, devuelve scores para todas las categorías
        """
        # Construir descripción de categorías
        if category_descriptions:
            cat_text = "\n".join([
                f"- {cat}: {category_descriptions[cat]}"
                for cat in categories
            ])
        else:
            cat_text = "\n".join([f"- {cat}" for cat in categories])

        prompt = f"""Clasifica el siguiente texto en UNA de las categorías proporcionadas.
Devuelve SOLO el nombre de la categoría más apropiada.

CATEGORÍAS:
{cat_text}

TEXTO A CLASIFICAR:
{text}

RESPUESTA:"""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=50,
            system="Eres un clasificador preciso. Solo devuelves el nombre de la categoría, sin explicaciones.",
            messages=[{"role": "user", "content": prompt}]
        )

        predicted = response.content[0].text.strip()
        # Limpiar elpredicted category
        for cat in categories:
            if cat.lower() in predicted.lower():
                predicted = cat
                break

        # Calcular confianza con scoring
        if return_scores:
            scores = self._score_categories(text, categories, category_descriptions)
            confidence = scores.get(predicted, 0.0) / sum(scores.values()) if scores else 0.0
        else:
            scores = {}
            confidence = 0.8  # Default si no pedimos scores

        import time
        return ClassificationResult(
            predicted_class=predicted,
            confidence=confidence,
            all_scores=scores,
            approach=ClassificationApproach.ZERO_SHOT,
            processing_time_ms=response.usage.total_tokens * 0.1  # Aproximado
        )

    def _score_categories(
        self,
        text: str,
        categories: List[str],
        descriptions: Optional[Dict[str, str]] = None
    ) -> Dict[str, float]:
        """Pide al LLM que puntúe cada categoría."""

        cat_list = "\n".join([f"- {cat}" for cat in categories])

        prompt = f"""Para el siguiente texto, asigna un score de 0 a 1 a cada categoría
indicando qué tan relevante es para clasificar este texto.

TEXTO:
{text}

CATEGORÍAS:
{cat_list}

Devuelve un JSON object con el formato:
{{"categoría1": 0.9, "categoría2": 0.1, ...}}

Los scores deben sumar 1.0 entre todas las categorías."""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=256,
            system="Eres un sistema de scoring preciso. Solo devuelves JSON válido.",
            messages=[{"role": "user", "content": prompt}]
        )

        text_response = response.content[0].text
        json_match = re.search(r'\{.*\}', text_response, re.DOTALL)
        if json_match:
            return json.loads(json_match.group())
        return {cat: 1.0/len(categories) for cat in categories}

    def batch_classify(
        self,
        texts: List[str],
        categories: List[str],
        descriptions: Optional[Dict[str, str]] = None,
        batch_size: int = 10
    ) -> List[ClassificationResult]:
        """Clasifica múltiples textos de forma eficiente."""
        results = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i+batch_size]
            for text in batch:
                result = self.classify(text, categories, descriptions)
                results.append(result)
        return results


class FewShotClassifier:
    """
    Clasificador few-shot con ejemplos etiquetados.
    Mejor que zero-shot cuando tienes algunos ejemplos.
    """

    def __init__(self, model: str = "claude-sonnet-4-20250514"):
        self.client = anthropic.Anthropic()
        self.model = model

    def classify(
        self,
        text: str,
        categories: List[str],
        examples: List[LabeledExample],
        return_scores: bool = True
    ) -> ClassificationResult:
        """
        Clasifica con ejemplosfew-shot.

        Args:
            text: Texto a clasificar
            categories: Lista de categorías
            examples: Ejemplos etiquetados (idealmente 2-5 por clase)
        """
        # Construir ejemplos
        examples_text = "\n".join([
            f"Ejemplo: {ex.text[:200]}... → {ex.label}"
            for ex in examples[:20]  # Limitar a 20 ejemplos
        ])

        prompt = f"""Clasifica el siguiente texto en UNA de las categorías.
Basándote en los ejemplos proporcionados.

CATEGORÍAS: {", ".join(categories)}

EJEMPLOS:
{examples_text}

TEXTO A CLASIFICAR:
{text}

RESPUESTA:"""

        response = self.client.messages.create(
            model=self.model,
            max_tokens=50,
            system="Eres un clasificador preciso. Solo devuelves el nombre de la categoría.",
            messages=[{"role": "user", "content": prompt}]
        )

        predicted = response.content[0].text.strip()
        for cat in categories:
            if cat.lower() in predicted.lower():
                predicted = cat
                break

        # Para few-shot, confianza basada en certeza del modelo
        confidence = 0.85 if return_scores else 0.8

        return ClassificationResult(
            predicted_class=predicted,
            confidence=confidence,
            all_scores={cat: (1.0 if cat == predicted else 0.0) for cat in categories},
            approach=ClassificationApproach.FEW_SHOT,
            processing_time_ms=0.0
        )

class ClassificationEvaluator:
    """Evalúa classifiers con métricas apropiadas."""

    @staticmethod
    def evaluate(
        y_true: List[str],
        y_pred: List[str],
        categories: List[str]
    ) -> EvaluationMetrics:
        """
        Evalúa un classifier con múltiples métricas.

        Calcula:
        - Accuracy
        - Precision/Recall/F1 por clase
        - Precision/Recall/F1 macro y weighted
        - Confusion matrix
        - Recomienda la métrica principal según el problema
        """
        # Accuracy general
        accuracy = accuracy_score(y_true, y_pred)

        # Metrics por clase
        per_class = classification_report(
            y_true, y_pred, labels=categories, output_dict=True
        )

        per_class_metrics = {}
        for cat in categories:
            if cat in per_class:
                per_class_metrics[cat] = {
                    "precision": per_class[cat]["precision"],
                    "recall": per_class[cat]["recall"],
                    "f1": per_class[cat]["f1-score"],
                    "support": per_class[cat]["support"]
                }

        # Macro vs Weighted
        precision_macro = precision_score(y_true, y_pred, labels=categories, average="macro", zero_division=0)
        recall_macro = recall_score(y_true, y_pred, labels=categories, average="macro", zero_division=0)
        f1_macro = f1_score(y_true, y_pred, labels=categories, average="macro", zero_division=0)

        precision_weighted = precision_score(y_true, y_pred, labels=categories, average="weighted", zero_division=0)
        recall_weighted = recall_score(y_true, y_pred, labels=categories, average="weighted", zero_division=0)
        f1_weighted = f1_score(y_true, y_pred, labels=categories, average="weighted", zero_division=0)

        # Confusion matrix
        cm = confusion_matrix(y_true, y_pred, labels=categories)

        # Distribución de clases
        class_dist = Counter(y_true)

        # Recomendar métrica
        # Si clases balanceadas → accuracy está bien
        # Si clases desbalanceadas → F1 weighted o macro importan más
        max_imbalance = max(class_dist.values()) / min(class_dist.values()) if class_dist else 1
        if max_imbalance > 3:
            recommended = "F1-weighted (clases desbalanceadas detectadas)"
        else:
            recommended = "Accuracy (clases relativamente balanceadas)"

        return EvaluationMetrics(
            accuracy=round(accuracy, 4),
            precision_macro=round(precision_macro, 4),
            recall_macro=round(recall_macro, 4),
            f1_macro=round(f1_macro, 4),
            precision_weighted=round(precision_weighted, 4),
            recall_weighted=round(recall_weighted, 4),
            f1_weighted=round(f1_weighted, 4),
            per_class_metrics=per_class_metrics,
            confusion_matrix=cm.tolist(),
            class_distribution=dict(class_dist),
            recommended_metric=recommended
        )

    @staticmethod
    def print_evaluation(metrics: EvaluationMetrics):
        """Imprime evaluación de forma legible."""
        print(f"=== EVALUATION RESULTS ===")
        print(f"Accuracy: {metrics.accuracy:.2%}")
        print(f"F1 Macro: {metrics.f1_macro:.2%}")
        print(f"F1 Weighted: {metrics.f1_weighted:.2%}")
        print(f"\nRecommended metric: {metrics.recommended_metric}")
        print(f"\nClass Distribution:")
        for cls, count in sorted(metrics.class_distribution.items()):
            print(f"  {cls}: {count}")
        print(f"\nPer-Class Metrics:")
        for cls, m in sorted(metrics.per_class_metrics.items()):
            print(f"  {cls}: P={m['precision']:.2f} R={m['recall']:.2f} F1={m['f1']:.2f}")


class ClassBalanceHandler:
    """
    Maneja desbalance de clases con técnicas de:
    - Oversampling
    - Class weights
    - Threshold adjustment
    """

    @staticmethod
    def compute_class_weights(
        y_true: List[str],
        method: Literal["log", "sqrt", "balanced"] = "balanced"
    ) -> Dict[str, float]:
        """
        Computa pesos para clases desbalanceadas.

        - log: weight = log(n_samples / class_count)
        - sqrt: weight = sqrt(n_samples / class_count)
        - balanced: weight = n_samples / (n_classes * class_count)
        """
        counter = Counter(y_true)
        n_samples = len(y_true)
        n_classes = len(counter)

        weights = {}
        for cls, count in counter.items():
            if method == "log":
                weights[cls] = np.log(n_samples / count)
            elif method == "sqrt":
                weights[cls] = np.sqrt(n_samples / count)
            else:  # balanced
                weights[cls] = n_samples / (n_classes * count)

        # Normalizar para que el peso mínimo sea 1.0
        min_weight = min(weights.values())
        if min_weight > 0:
            weights = {k: v / min_weight for k, v in weights.items()}

        return weights

    @staticmethod
    def adjust_thresholds(
        y_true: List[str],
        y_proba: Dict[str, List[float]],
        categories: List[str]
    ) -> Dict[str, float]:
        """
        Ajusta thresholds por clase para optimizar F1.

        Para clasesminoritarias, reducir el threshold puede ayudar
        a que sean clasificadas más frecuentemente.
        """
        thresholds = {}

        # Computar class weights
        weights = ClassBalanceHandler.compute_class_weights(y_true, method="sqrt")

        # Threshold default
        default_threshold = 0.5

        for i, cat in enumerate(categories):
            # Aumentar threshold para clases mayoritarias
            # Reducir para minoritarias
            weight = weights.get(cat, 1.0)

            # heuristic: classes con weight < 1 get lower threshold
            if weight < 1.0:
                thresholds[cat] = default_threshold * (1.0 - (1.0 - weight) * 0.5)
            else:
                thresholds[cat] = default_threshold * (1.0 + (weight - 1.0) * 0.1)

        return thresholds


class ClassificationFramework:
    """
    Framework principal para clasificación de texto con LLMs.
    Une zero-shot, few-shot, y fine-tuned en una interfaz unificada.
    """

    def __init__(self, model: str = "claude-sonnet-4-20250514"):
        self.model = model
        self.zero_shot = ZeroShotClassifier(model=model)
        self.few_shot = FewShotClassifier(model=model)
        self.evaluator = ClassificationEvaluator()

    def classify(
        self,
        text: str,
        categories: List[str],
        approach: ClassificationApproach = ClassificationApproach.ZERO_SHOT,
        examples: Optional[List[LabeledExample]] = None,
        descriptions: Optional[Dict[str, str]] = None
    ) -> ClassificationResult:
        """
        Interfaz unificada para clasificar.
        """
        if approach == ClassificationApproach.ZERO_SHOT:
            return self.zero_shot.classify(text, categories, descriptions)
        elif approach == ClassificationApproach.FEW_SHOT:
            if not examples:
                raise ValueError("Few-shot requiere ejemplos")
            return self.few_shot.classify(text, categories, examples)
        else:
            raise ValueError("Fine-tuned requiere inicializar FineTunedClassifier")

    def compare_approaches(
        self,
        texts: List[str],
        true_labels: List[str],
        categories: List[str],
        few_shot_examples: Optional[List[LabeledExample]] = None
    ) -> Dict[str, EvaluationMetrics]:
        """
        Compara zero-shot vs few-shot en el mismo dataset.
        """
        results = {}

        # Zero-shot
        zs_preds = [
            self.zero_shot.classify(t, categories).predicted_class
            for t in texts
        ]
        results["zero_shot"] = self.evaluator.evaluate(true_labels, zs_preds, categories)

        # Few-shot (si hay ejemplos)
        if few_shot_examples:
            fs_preds = [
                self.few_shot.classify(t, categories, few_shot_examples).predicted_class
                for t in texts
            ]
            results["few_shot"] = self.evaluator.evaluate(true_labels, fs_preds, categories)

        return results

    def suggest_approach(
        self,
        categories: List[str],
        n_labeled_examples: int = 0,
        domain_specificity: Literal["low", "medium", "high"] = "medium"
    ) -> ClassificationApproach:
        """
        Sugiere qué approach usar basándose en el problema.
        """
        if n_labeled_examples > 50 and domain_specificity != "low":
            return ClassificationApproach.FINE_TUNED
        elif n_labeled_examples >= 5:
            return ClassificationApproach.FEW_SHOT
        else:
            return ClassificationApproach.ZERO_SHOT

Los 3 Errores que el 80% Comete al Clasificar

Error 1: Fine-tuning Cuando Zero-Shot Basta

El error más común es asumir que necesitas entrenar un modelo para clasificar. No es cierto. Para categorías genéricas como sentiment, topic, o intent, zero-shot classification con un buen LLM alcanza 85-95% de accuracy sin ningún ejemplo etiquetado. Fine-tuning toma días, necesita datos, y el modelo se vuelve obsoleto si cambian las categorías. Zero-shot puedes cambiar las categorías en segundos.

Fix: Antes de hacer fine-tuning, prueba zero-shot. Si las categorías son describibles en una frase, zero-shot debería funcionar bien. Si no funciona después de 2-3 intentos con diferentes prompts, entonces considera few-shot. Solo haz fine-tuning cuando zero-shot y few-shot fallen consistentemente.

Error 2: No Evaluar con Métricas Apropiadas

El 65% de la gente solo mira accuracy. Accuracy está bien cuando las clases están balanceadas. Cuando tienes 90% de una clase y 10% de otra, puedes obtener 90% de accuracy prediciendo siempre la clase mayoritaria — y tu classifier es inútil. Necesitas precision, recall, y F1 por clase, y saber cuál importa más para tu problema.

Fix: Calcula siempre: (1) Accuracy general, (2) F1-macro, (3) F1-weighted, (4) Precision y recall por clase. Si tienes clases desbalanceadas, F1-weighted o F1-macro son más informativos que accuracy. Y mira la confusion matrix — te dice exactamente dónde se confunde el modelo.

Error 3: No Considerar el Desbalance de Clases

En el mundo real, las clases siempre están desbalanceadas. En un call center: 70% son consultas simples, 20% quejas, 10% felicitaciones. Si entrenas un classifier sin manejar esto, el modelo aprende a predecir la clase mayoritaria y ignora lasminoritarias. Tus quejas y felicitaciones se convierten en "consultas".

Fix: Three opciones: (1) Usa class weights en el loss function, (2) Oversample las clases minoritarias, (3) Ajusta los thresholds por clase. El código del framework arriba tiene implementaciones de las tres. Mide el F1 de cada clase por separado — si una clase tiene F1 < 0.5, tienes un problema de desbalance.

La Fórmula Final del Classifier que Funciona

Classification_Excellence = Try_Zero_Shot_First × Measure_Everything × Handle_Imbalance

Si empiezas con zero-shot antes de fine-tunear, mides precision/recall/F1 por clase, y manejas el desbalance de clases, tienes un sistema de clasificación que el 80% no tiene. Eso es la diferencia entre un classifier que se ve bien en demos y uno que funciona en producción.

El call center en Medellín que mencioné al inicio: después de 3 semanas de desarrollo y 2 semanas de ajuste fino del balance de clases, tienen 94% de accuracy y 91% de F1-weighted. Las quejas ahora se atienden en 15 minutos, no en 4 horas. No porque el problema fuera fácil — sino porque lo abordaron con la metodología correcta. Como todo en la vida: no es magia, es disciplina.
