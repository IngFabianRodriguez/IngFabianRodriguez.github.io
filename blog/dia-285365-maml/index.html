OCR - Reconocimiento Optico De Caracteres

¿Qué es OCR y por qué importa en 2026?

OCR (Optical Character Recognition) o Reconocimiento Óptico de Caracteres es la tecnología que permite convertir imágenes de texto escrito o impreso en texto digital editable. Desde receipts escaneados hasta documentos legales históricos, OCR es el puente entre el mundo físico y el digital.

En Colombia, donde todavía gran parte de la documentación empresarial vive en papel, OCR se vuelve crítico para digitalizar procesos. Imagina tener que transcribir manualmente 10,000 facturas mensuales — en términos de tiempo y dinero, es inviable. Un buen sistema de OCR puede procesar esos documentos en minutos.

Para 2026, se estima que el mercado global de OCR alcanzará los $13.4 mil millones de dólares, impulsado por la automatización de procesos documentales en sectores como financiero, salud y gobierno.

Arquitectura de un sistema OCR moderno

Un pipeline de OCR moderno se compone de varias etapas:

  • Preprocesamiento de imagen: Mejora la calidad de la imagen input (denoising, binarización, deskew)
  • Detección de texto: Localiza regiones de texto en la imagen
  • Reconocimiento de texto: Convierte las regiones de imagen en texto
  • Post-procesamiento: Corrección de errores y formateo

Modelos de Deep Learning para OCR

Los enfoques modernos usan arquitecturas de red neuronal entrenadas end-to-end:

"""
OCR Pipeline con Deep Learning
Usa CNN para feature extraction + RNN para secuencia de caracteres
"""
import torch
import torch.nn as nn
from dataclasses import dataclass
from typing import List, Tuple, Optional

@dataclass
class OCRResult:
    text: str
    confidence: float
    bounding_boxes: List[Tuple[int, int, int, int]]

class CRNN(nn.Module):
    """
    Convolutional Recurrent Neural Network para OCR
    Combina CNN (spatial features) + RNN (sequence modeling) + CTC (decoding)
    """
    
    def __init__(self, num_classes: int, hidden_size: int = 256):
        super().__init__()
        
        # Feature extractor CNN
        self.cnn = nn.Sequential(
            nn.Conv2d(1, 64, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),  # 32x downsampling
            
            nn.Conv2d(64, 128, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
            
            nn.Conv2d(128, 256, kernel_size=3, padding=1),
            nn.BatchNorm2d(256),
            nn.ReLU(),
            nn.Conv2d(256, 256, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d((2, 1)),  # Reduce height, keep width
            
            nn.Conv2d(256, 512, kernel_size=3, padding=1),
            nn.BatchNorm2d(512),
            nn.ReLU(),
            nn.Conv2d(512, 512, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d((1, None))  # Global pooling temporal
        )
        
        # RNN para secuencias
        self.rnn = nn.LSTM(
            input_size=512,
            hidden_size=hidden_size,
            num_layers=2,
            batch_first=True,
            bidirectional=True
        )
        
        # Classification head
        self.classifier = nn.Linear(hidden_size * 2, num_classes)
        
    def forward(self, x):
        # CNN feature extraction
        conv_features = self.cnn(x)  # [B, C, 1, W]
        conv_features = conv_features.squeeze(2)  # [B, C, W]
        conv_features = conv_features.permute(0, 2, 1)  # [B, W, C]
        
        # RNN sequence modeling
        rnn_out, _ = self.rnn(conv_features)  # [B, W, hidden*2]
        
        # Per-timestep classification
        logits = self.classifier(rnn_out)  # [B, W, num_classes]
        
        return logits

class OCREngine:
    """Motor de OCR end-to-end"""
    
    def __init__(self, model_path: str = "ocr_model.pth"):
        self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        self.model = CRNN(num_classes=38)  # 26 letters + 10 digits + blank + unk
        self.model.load_state_dict(torch.load(model_path, map_location=self.device))
        self.model.eval()
        
        self.transform = self._build_transform()
        
    def _build_transform(self):
        """Preprocesamiento de imagen"""
        from torchvision import transforms
        return transforms.Compose([
            transforms.Resize((32, 128)),  # Altura fija, ancho variable
            transforms.Grayscale(),
            transforms.ToTensor(),
            transforms.Normalize(mean=[0.5], std=[0.5])
        ])
    
    def read(self, image_path: str) -> OCRResult:
        """Lee texto de una imagen"""
        from PIL import Image
        import torch.nn.functional as F
        
        # Cargar y preprocessar imagen
        img = Image.open(image_path).convert("RGB")
        img_tensor = self.transform(img).unsqueeze(0).to(self.device)
        
        # Inferencia
        with torch.no_grad():
            logits = self.model(img_tensor)  # [1, W, num_classes]
            logits = logits.log_softmax(dim=-1)
            
        # CTC decoding
        text = self._ctc_decode(logits)
        
        return OCRResult(
            text=text,
            confidence=logits.exp().max().item(),
            bounding_boxes=[]  # Simplified
        )
    
    def _ctc_decode(self, logits):
        """Decodifica usando CTC greedy decoding"""
        import numpy as np
        
        # Get best path
        log_probs = logits.squeeze(0)  # [W, num_classes]
        predictions = log_probs.argmax(dim=-1).cpu().numpy()
        
        # CTC collapse (remove duplicates and blanks)
        text = []
        prev_token = -1
        blank_idx = 37  # Blank token index
        
        for p in predictions:
            if p != blank_idx and p != prev_token:
                text.append(self._idx_to_char(p))
            prev_token = p
        
        return "".join(text)
    
    def _idx_to_char(self, idx):
        """Mapea índice a carácter"""
        if idx < 26:
            return chr(ord('a') + idx)
        elif idx < 36:
            return str(idx - 26)
        return ""

OCR con Tesseract y Pytesseract

Para casos de uso más simples, Tesseract es una opción robusta y bien mantenida:

"""
OCR con Tesseract
Alternativa rápida para documentos limpios
"""
import pytesseract
from PIL import Image, ImageFilter, ImageEnhance
import cv2
import numpy as np
from typing import Dict, Optional

class TesseractOCR:
    """Wrapper para Tesseract OCR con preprocesamiento"""
    
    def __init__(self, lang: str = "spa+eng"):
        self.lang = lang
        
    def preprocess_for_ocr(self, image_path: str) -> np.ndarray:
        """
        Preprocesa imagen para mejorar accuracy de OCR
        """
        # Cargar con OpenCV
        img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
        
        # Resize para mejorar detección
        img = cv2.resize(img, None, fx=2, fy=2, interpolation=cv2.INTER_CUBIC)
        
        # Denoising
        img = cv2.fastNlMeansDenoising(img, h=10)
        
        # Binarización adaptativa
        img = cv2.adaptiveThreshold(
            img, 255,
            cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
            cv2.THRESH_BINARY,
            blockSize=11,
            C=2
        )
        
        # Deskew (corregir rotación)
        coords = np.column_stack(np.where(img > 0))
        if len(coords) > 0:
            angle = cv2.minAreaRect(coords)[-1]
            if angle < -45:
                angle = 90 + angle
            elif angle > 45:
                angle = angle - 90
            if abs(angle) > 1:
                (h, w) = img.shape[:2]
                center = (w // 2, h // 2)
                M = cv2.getRotationMatrix2D(center, angle, 1.0)
                img = cv2.warpAffine(
                    img, M, (w, h),
                    flags=cv2.INTER_CUBIC,
                    borderMode=cv2.BORDER_REPLICATE
                )
        
        return img
    
    def extract_text(
        self,
        image_path: str,
        config: Optional[str] = None,
        enhance: bool = True
    ) -> Dict[str, str]:
        """
        Extrae texto de imagen con OCR
        
        Args:
            image_path: Ruta a la imagen
            config: Configuración adicional de Tesseract
            enhance: Si aplicar preprocesamiento
        
        Returns:
            Diccionario con texto extraído y metadata
        """
        if enhance:
            img = self.preprocess_for_ocr(image_path)
        else:
            img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
        
        # Configuración de Tesseract
        default_config = r"--oem 3 --psm 6"
        config = config or default_config
        
        # OCR
        text = pytesseract.image_to_string(
            img,
            lang=self.lang,
            config=config
        )
        
        # Extraer datos estructurados
        data = pytesseract.image_to_data(
            img,
            lang=self.lang,
            config=config,
            output_type=pytesseract.Output.DICT
        )
        
        return {
            "text": text.strip(),
            "confidence": np.mean([d for d in data["conf"] if d > 0]),
            "words": [
                {"word": w, "conf": c, "bbox": b}
                for w, c, b in zip(
                    data["text"],
                    data["conf"],
                    zip(data["left"], data["top"], data["width"], data["height"])
                )
                if w.strip()
            ]
        }
    
    def extract_from_pdf(self, pdf_path: str, dpi: int = 300) -> list:
        """
        Extrae texto de PDF escaneado
        Convierte cada página a imagen primero
        """
        import fitz  # PyMuPDF
        
        doc = fitz.open(pdf_path)
        pages_text = []
        
        for page_num in range(len(doc)):
            page = doc[page_num]
            
            # Renderizar página a imagen
            pix = page.get_pixmap(dpi=dpi)
            img_bytes = pix.tobytes("png")
            
            # Guardar temporalmente
            import tempfile
            with tempfile.NamedTemporaryFile(suffix=".png", delete=False) as tmp:
                tmp.write(img_bytes)
                tmp_path = tmp.name
            
            # OCR
            result = self.extract_text(tmp_path, enhance=True)
            pages_text.append({
                "page": page_num + 1,
                "text": result["text"]
            })
            
            # Limpiar
            import os
            os.unlink(tmp_path)
        
        return pages_text

Fine-tuning de modelo OCR para documentos específicos

Para documentos con layouts complejos o vocabularios especializados, el fine-tuning de modelos pre-entrenados es efectivo:

"""
Fine-tuning de modelo OCR para documentos colombianos
Ejemplo: reconocimiento de facturas y recibos de pago
"""
import torch
from torch.utils.data import Dataset, DataLoader
from PIL import Image
import json
from pathlib import Path

class InvoiceDataset(Dataset):
    """Dataset para facturas y documentos financieros"""
    
    def __init__(self, annotations_path: str, images_dir: str, vocab_path: str):
        with open(annotations_path) as f:
            self.annotations = json.load(f)
        
        self.images_dir = Path(images_dir)
        
        with open(vocab_path) as f:
            self.char_to_idx = json.load(f)
        
    def __len__(self):
        return len(self.annotations)
    
    def __getitem__(self, idx):
        ann = self.annotations[idx]
        
        # Cargar imagen
        img_path = self.images_dir / ann["image_path"]
        img = Image.open(img_path).convert("RGB")
        
        # Preprocesar
        img = self._preprocess(img)
        
        # Codificar labels
        label = self._encode_text(ann["text"])
        
        return {
            "image": img,
            "label": label,
            "text": ann["text"],
            "image_id": ann["image_id"]
        }
    
    def _preprocess(self, img: Image.Image):
        # Resize, normalize, etc.
        from torchvision import transforms
        transform = transforms.Compose([
            transforms.Resize((64, 256)),
            transforms.ToTensor(),
            transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
        ])
        return transform(img)
    
    def _encode_text(self, text: str):
        return [self.char_to_idx.get(c, 0) for c in text]

def train_model(model, train_loader, num_epochs=10, lr=1e-4):
    """Entrena el modelo OCR"""
    
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, num_epochs)
    criterion = torch.nn.CTCLoss(blank=0, reduction="mean", zero_infinity=True)
    
    for epoch in range(num_epochs):
        model.train()
        total_loss = 0
        
        for batch in train_loader:
            images = batch["image"]
            labels = batch["label"]
            
            optimizer.zero_grad()
            
            # Forward
            logits = model(images)
            
            # CTC loss (log_probs, targets, input_lengths, target_lengths)
            log_probs = logits.log_softmax(dim=-1).permute(1, 0, 2)
            input_lengths = torch.full((len(images),), log_probs.size(0))
            target_lengths = torch.tensor([len(l) for l in labels])
            targets = torch.cat(labels)
            
            loss = criterion(log_probs, targets, input_lengths, target_lengths)
            
            # Backward
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 5.0)
            optimizer.step()
            
            total_loss += loss.item()
        
        scheduler.step()
        print(f"Epoch {epoch+1}: Loss = {total_loss/len(train_loader):.4f}")

Errores comunes en implementación de OCR

  • No preprocesar imágenes: Imágenes de baja calidad dan resultados malos — invierte en preprocessing
  • Ignorar el idioma: Configura Tesseract con el lang correcto (spa+eng para documentos bilingües)
  • No manejar rotación/deskew: Documentos escaneados frecuentemente están torcidos
  • Usar PSM wrong: El Page Segmentation Mode debe coincidir con tu tipo de documento
  • No validar resultados: Siempre verifica confidence scores del OCR

Resumen

OCR es una tecnología madura pero que requiere atención al detalle para implementaciones exitosas. Las claves son:

  1. Preprocesamiento adecuado — La calidad de input determina la calidad de output
  2. Elegir el modelo correcto — Tesseract para casos simples, deep learning para complejidad alta
  3. Fine-tuning cuando sea necesario — Para vocabularios especializados
  4. Validación de resultados — Siempre verificar confidence scores
