ML Ethics in Practice — Casos Reales y Lessons Learned

Hagale pues, parcero. Aquí en Bogotá cuando algo sale mal, todos tienen la culpa menos el que hizo el disparate. En ML pasa lo mismo: los casos de sesgo son tan graves que hasta ProPublica hizo su propia investigación. Café en mano, hoy aprendemos de los errores ajenos para no repetir los mismos.

🎯 Por Qué Importan las Éticas en ML

Un modelo de ML no es neutral. Aprende de datos creados por humanos, con decisiones humanas, en contextos humanos. Si esas decisiones tienen sesgos, el modelo los amplifica. El problema no es la tecnología — es que automatizamos preferencias sin preguntarnos Whose voice is being amplified?

La matemática detrás del sesgo es sutil pero profunda. Si $\hat{Y}$ es nuestra predicción, el sesgo puede expresarse como:

$$\mathbb{E}[\hat{Y} | G=1] - \mathbb{E}[\hat{Y} | G=0] \neq 0$$

donde $G$ representa el grupo protegido. Un modelo "fair" busca que esta diferencia sea cercana a cero — pero hay muchas formas de definir "fairness", y matemáticamente son incompatibles entre sí (el Teorema de Impossibilidad de Kleinberg).

📐 Casos Reales de Sesgo

1. COMPAS — La Justica No Es Neutral

COMPAS (Correctional Offender Management Profiling for Alternative Sanctions) era usado en cortes de EE.UU. para predecir riesgo de reincidencia. ProPublica descubrió que el modelo tenía tasas distintas de falsos positivos para personas afrodescendientes vs blancas:

  • Afrodescendientes: 45% de falsos positivos
  • Blancos: 23% de falsos positivos

Matemáticamente, el score de COMPAS satisface "predictive parity" pero NO "equalized odds". La compañía (Northpoint) no publicó el algoritmo ni允许 auditing independiente.

2. Amazon Hiring — El Sexismo Codificado

Amazon desarrolló un sistema de CV screening automatizado. El modelo fue entrenado con 10 años de historiales de contratación — donde la mayoría de candidatos exitosos eran hombres. El resultado: penalizaba automáticamente palabras como "women's" y filtraba perfiles de universidades exclusivamente femeninas.

El sesgo estaba en los datos de entrenamiento, no en las etiquetas explícitas. El modelo aprendió que hombre = éxito sin que nadie le dijera eso.

3. Cambridge Analytica — La民主acia en Riesgo

No fue exactamente ML convencional, pero el impacto fue masivo: 87 millones de perfiles de Facebook usados para psicosmapping político. Microtargeting de mensajes personalizados basados en personalidad, sin consentimiento, para manipular decisiones electorales.

El problema: feedback loop entre datos collected y modelo de perfilado. Mientras más datos, más preciso el perfil — y más poder de manipulación.

🚀 Cómo Hacer un AI Ethics Audit

# Framework para AI Ethics Audit
class EthicsAudit:
    def __init__(self, model, sensitive_features):
        self.model = model
        self.sensitive = sensitive_features
        self.results = {}
    
    def demographic_parity(self, X, y_true, y_pred, privileged_group):
        """Check: ¿Predictions independientes de group membership?"""
        mask = X[self.sensitive] == privileged_group
        rate_priv = y_pred[mask].mean()
        rate_unpriv = y_pred[~mask].mean()
        return abs(rate_priv - rate_unpriv)
    
    def equalized_odds(self, X, y_true, y_pred, privileged_group):
        """Check: ¿Same TPR y FPR across groups?"""
        mask = X[self.sensitive] == privileged_group
        # True Positive Rate
        tpr_priv = ((y_pred == 1) & (y_true == 1) & mask).sum() / (y_true == 1).sum()
        tpr_unpriv = ((y_pred == 1) & (y_true == 1) & ~mask).sum() / (y_true == 1).sum()
        # False Positive Rate  
        fpr_priv = ((y_pred == 1) & (y_true == 0) & mask).sum() / (y_true == 0).sum()
        fpr_unpriv = ((y_pred == 1) & (y_true == 0) & ~mask).sum() / (y_true == 0).sum()
        return {'tpr_gap': abs(tpr_priv - tpr_unpriv), 'fpr_gap': abs(fpr_priv - fpr_unpriv)}
    
    def generate_report(self):
        return {
            'demographic_parity_difference': self.demographic_parity(...),
            'equalized_odds_gaps': self.equalized_odds(...),
            'calibration_by_group': self.calibration_check(...)
        }

⚠️ Los 3 Errores Más Comunes

Error 1: No Aprender de Casos Reales de Bias

El problema: Creer que "nosotros somos diferentes" y que los casos de COMPAS, Amazon, y Cambridge son anomalías que no aplican. Muchos equipos de ML siguen cometiendo los mismos errores porque no estudian la historia.

La solución: Implementar "bias case studies" como parte del on-boarding. Antes de deployar cualquier modelo, hacer el ejercicio: ¿qué pasaría si este modelo estuviese en las noticias de Caracol por las razones equivocadas?

Error 2: Pensar "Nuestro Producto No Tiene Implicaciones Éticas"

El problema: "Es solo un recomendador de películas" o "solo optimizamos engagement". Todo modelo que afecta decisiones sobre personas tiene implicaciones éticas — desde quién ve qué contenido hasta quién accede a qué servicios.

La solución: Hacer la pregunta correcta: ¿Quién se beneficia y quién resulta herido por las predictions de este modelo? Si no puedes responder fácilmente, tienes un problema de visibility.

Error 3: No Tener Proceso de Ethical Review

El problema: Ethics como afterthough — se revisa al final, cuando ya todo está construido y "no hay tiempo para cambios". El review se hace por compliance, no por convicción.

La solución: Integrar ethics review en el pipeline de desarrollo, no al final. Como en testing: si lo encuentras tarde, es 10x más caro arreglarlo.

📊 Resumen y Cierre

La ética en ML no es un teorema — es una práctica. Requiere:

  • Conciencia: Saber que el sesgo existe y puede estar en tus datos
  • Método: Frameworks como los de arriba para detectar y medir
  • Proceso: Reviews integrados, no como afterthough
  • Humildad: Aceptar que modelos "buenos" pueden hacer daño

En Colombia tenemos nuestros propios desafíos: sesgos en modelos de scoring crediticio para poblaciones rurales, detección de fraude que penaliza regiones específicas, sistemas de salud que priorizan based on datos de zonas urbanas. El llamado es a construir ML que servido para todos — no solo para los que ya tienen privilegios.
