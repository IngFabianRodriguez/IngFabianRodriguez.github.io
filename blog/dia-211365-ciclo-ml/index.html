🎯 Tipos de Sesgo en Machine Learning

Selection Bias (Sesgo de Selección)

Ocurre cuando los datos de entrenamiento no representan la realidad. Imagínate que entrenas un modelo para aprobar créditos en Colombia y solo usas datos de personas en estrato 5 y 6 — el modelo nunca va a entender la realidad financiera del común.

$$P_{\text{training}}(y|x) \neq P_{\text{real}}(y|x)$$

La distribución de entrenamiento diverge de la distribución real porque el muestreo no fue aleatorio o fue sesgado por acceso.

Confirmation Bias (Sesgo de Confirmación)

Cuando los ingenieros, intencional o inconscientemente, diseñan features o labels que confirman lo que ellos creen que el modelo debería predecir. Le metes tu worldview al modelo y luego el modelo te devuelve tu worldview como si fuera verdad.

También pasa cuando durante el desarrollo ignoras evidencia de que el modelo está fallando para ciertos grupos porque "no debería estar fallando".

Proxy Bias (Sesgo de Proxy)

Usas variables sustitutas (proxies) que correlacionan con características protegidas. El código postal en Colombia correlaciona con ingreso económico — si tu modelo usa zip code como feature, está usando ingreso como proxy.

# Ejemplo de proxy bias sutil
# "distancia al centro comercial" es proxy de ingreso socioeconómico
# "tipo de smartphone" es proxy de capacidad de pago
# "horario de llamadas" puede ser proxy de tipo de empleo

# Un modelo que denied credit basándose en estas features
# está discriminando indirectamente por ingreso, no por mérito crediticio
features = ['distancia_centro_comercial', 'tipo_smartphone', 'horario_llamadas']

📐 Fairness Metrics — Cómo Medir Si Tu Modelo Es Justo

Demographic Parity (Paridad Demográfica)

La probabilidad de obtener un resultado positivo debe ser igual para todos los grupos.

$$\mathbb{P}(\hat{Y}=1|A=0) = \mathbb{P}(\hat{Y}=1|A=1)$$

Donde $A$ es el grupo protegido (raza, género, etc.).

def demographic_parity_difference(model, X, sensitive_attr):
    """
    Calcula la diferencia en tasas de predicción positiva entre grupos.
    Valor = 0 significa paridad demográfica perfecta.
    """
    predictions = model.predict(X)
    
    # Grupo 0
    mask_0 = X[sensitive_attr] == 0
    rate_0 = predictions[mask_0].mean()
    
    # Grupo 1
    mask_1 = X[sensitive_attr] == 1
    rate_1 = predictions[mask_1].mean()
    
    return rate_1 - rate_0  # Esperado: cercano a 0

# En contexto colombiano: comparar aprobación crediticia
# entre personas de diferente estrato socioeconómico
dp_diff = demographic_parity_difference(
    credit_model, 
    X_test, 
    sensitive_attr='estrato'
)
print(f"Demographic Parity Difference: {dp_diff:.3f}")

Equalized Odds (Probabilidades Iguales)

Requiere que las tasas de verdaderos positivos y falsos positivos sean iguales entre grupos.

$$\mathbb{P}(\hat{Y}=1|Y=1,A=0) = \mathbb{P}(\hat{Y}=1|Y=1,A=1) \quad \text{(TPR相等)}$$

$$\mathbb{P}(\hat{Y}=1|Y=0,A=0) = \mathbb{P}(\hat{Y}=1|Y=0,A=1) \quad \text{(FPR相等)}$$

from sklearn.metrics import confusion_matrix

def equalized_odds_difference(model, X, y_true, sensitive_attr):
    """
    Calcula diferencia en TPR y FPR entre grupos.
    Valor = 0 significa equalized odds perfecto.
    """
    predictions = model.predict(X)
    
    results = {}
    for group in [0, 1]:
        mask = X[sensitive_attr] == group
        cm = confusion_matrix(y_true[mask], predictions[mask])
        
        tn, fp, fn, tp = cm.ravel()
        tpr = tp / (tp + fn) if (tp + fn) > 0 else 0  # True Positive Rate
        fpr = fp / (fp + tn) if (fp + tn) > 0 else 0  # False Positive Rate
        
        results[group] = {'tpr': tpr, 'fpr': fpr}
    
    tpr_diff = abs(results[1]['tpr'] - results[0]['tpr'])
    fpr_diff = abs(results[1]['fpr'] - results[0]['fpr'])
    
    return {'tpr_diff': tpr_diff, 'fpr_diff': fpr_diff}

# Verificar si el modelo trata igual a ambos estratos
eo_diff = equalized_odds_difference(credit_model, X_test, y_test, 'estrato')
print(f"TPR Difference: {eo_diff['tpr_diff']:.3f}")
print(f"FPR Difference: {eo_diff['fpr_diff']:.3f}")

🔍 Cómo Hacer Un Bias Audit Antes Del Deployment

import pandas as pd
import numpy as np
from sklearn.model_selection import StratifiedKFold

class BiasAuditor:
    def __init__(self, model, sensitive_column):
        self.model = model
        self.sensitive_column = sensitive_column
        
    def full_audit(self, X, y_true, protected_groups):
        """
        Ejecuta auditoría completa de bias.
        """
        print("=" * 60)
        print("BIAS AUDIT REPORT")
        print("=" * 60)
        
        # 1. Análisis exploratorio de datos
        print("\n📊 Data Distribution by Group:")
        print(X[protected_groups].value_counts(normalize=True))
        
        # 2. Fairness metrics
        print("\n📏 Fairness Metrics:")
        
        # Demographic parity
        dp = demographic_parity_difference(self.model, X, protected_groups)
        print(f"  Demographic Parity: {dp:.4f} (goal: 0)")
        
        # Equalized odds
        eo = equalized_odds_difference(self.model, X, y_true, protected_groups)
        print(f"  Equalized Odds TPR: {eo['tpr_diff']:.4f} (goal: 0)")
        print(f"  Equalized Odds FPR: {eo['fpr_diff']:.4f} (goal: 0)")
        
        # 3. Disparate impact (ratio of approval rates)
        print("\n⚖️ Disparate Impact:")
        predictions = self.model.predict(X)
        rates = [predictions[X[protected_groups] == g].mean() 
                 for g in X[protected_groups].unique()]
        ratio = min(rates) / max(rates) if max(rates) > 0 else 0
        print(f"  Impact Ratio: {ratio:.4f} (threshold: 0.8)")
        
        # 4. Recomendaciones
        print("\n💡 Recommendations:")
        if abs(dp) > 0.05:
            print("  - Demographic parity violated. Consider reweighting.")
        if eo['fpr_diff'] > 0.05:
            print("  - High FPR disparity. Check false positive rates by group.")
        if ratio < 0.8:
            print("  - Disparate impact below 80%. Legal risk.")
            
        return {
            'dp': dp, 
            'eo_tpr': eo['tpr_diff'],
            'eo_fpr': eo['fpr_diff'],
            'impact_ratio': ratio
        }

# Ejecutar auditoría antes de deployment
auditor = BiasAuditor(credit_model, 'estrato')
report = auditor.full_audit(X_test, y_test, 'estrato')

🛠️ Bias Mitigation Techniques

1. Reweighting (Reponderación)

Asigna pesos a las instancias de entrenamiento para compensar el desbalance entre grupos.

def compute_reweighting_factors(X, sensitive_attr, y):
    """
    Calcula factores de ponderación para equalizar impacto.
    Basado en: Kamiran & Calders (2009)
    """
    groups = X[sensitive_attr].unique()
    n = len(y)
    
    weights = pd.Series(np.ones(n), index=X.index)
    
    for group in groups:
        mask = X[sensitive_attr] == group
        group_size = mask.sum()
        
        # Calcular tasas por clase dentro del grupo
        for label in [0, 1]:
            label_mask = (mask) & (y == label)
            if label_mask.sum() > 0:
                # Weight = (prior global * count group) / (prior group * count global)
                p_label_global = (y == label).sum() / n
                p_label_group = label_mask.sum() / group_size
                
                if p_label_group > 0:
                    factor = (p_label_global * group_size) / (p_label_group * n)
                    # Ajustar solo muestras del grupo-clase
                    weights[label_mask] *= factor
    
    # Normalizar
    weights = weights * n / weights.sum()
    return weights

# Aplicar reweighting al entrenar
weights = compute_reweighting_factors(X_train, 'estrato', y_train)

# Entrenar con pesos
model_balanced = GradientBoostingClassifier()
model_balanced.fit(X_train, y_train, sample_weight=weights)

2. Resampling (Remuestreo)

Reequilibra el dataset mediante oversampling de grupos minoritarios o undersampling de mayoritarios.

from sklearn.utils import resample

def fair_resample(X, y, sensitive_attr, target_col='estrato'):
    """
    Resampling para balancear representación de grupos.
    """
    df = pd.concat([X, y], axis=1)
    df[sensitive_attr] = X[sensitive_attr]
    
    # Combinar grupos minoritarios
    majority = df[df[sensitive_attr] == 0]
    minority = df[df[sensitive_attr] == 1]
    
    # Undersample majority al tamaño de minority
    majority_downsampled = resample(
        majority,
        replace=False,
        n_samples=len(minority),
        random_state=42
    )
    
    # Combinar
    df_balanced = pd.concat([majority_downsampled, minority])
    df_balanced = df_balanced.sample(frac=1, random_state=42)  # Shuffle
    
    X_balanced = df_balanced.drop(columns=[y.name])
    y_balanced = df_balanced[y.name]
    
    return X_balanced, y_balanced

# Uso
X_train_fair, y_train_fair = fair_resample(X_train, y_train, 'estrato')
model_fair = GradientBoostingClassifier().fit(X_train_fair, y_train_fair)

⚠️ Los 3 Errores Más Costosos

Error 1: No Hacer Bias Audit Antes Del Deployment

El problema: Lanzar el modelo a producción sin verificar fairness. Si el modelo discrimina por género, etnia o estrato, las consecuencias legales y reputacionales pueden ser catastróficas.

La solución: Integrar bias audit en tu pipeline de CI/CD. No es opcional, es obligatorio.

# En tu CI/CD pipeline
def test_fairness_in_ci(model, X, y, sensitive_attr):
    """
    Test que falla si el modelo no pasa umbrales de fairness.
    """
    report = BiasAuditor(model, sensitive_attr).full_audit(X, y, sensitive_attr)
    
    assert abs(report['dp']) < 0.05, "Demographic parity violated"
    assert report['impact_ratio'] > 0.8, "Disparate impact below legal threshold"
    
    return True

Error 2: Asumir Que Datos "Naturales" Son Unbiased

El problema: "Los datos los收集 de la internet, entonces son naturales y no tienen sesgo". Falso. Los datos de internet reflejan los sesgos de la sociedad que los produjo.

La solución: Auditar la fuente de datos. ¿Quién generó estos datos? ¿Bajo qué condiciones? ¿Qué sesgos históricos pueden estar presentes?

Error 3: Optimizar Solo Accuracy Sin Considerar Fairness

El problema: "El modelo tiene 95% de accuracy, está excelente". Pero si ese 95% viene de discriminar contra un grupo específico, no es excelente — es problemático.

La solución: Incluir fairness metrics en tus métricas de evaluación. Accuracy + Fairness metrics，才是完整的。

# Accuracy + Fairness composite metric
def fairness_adjusted_accuracy(y_true, y_pred, sensitive_attr, X, alpha=0.5):
    """
    Combina accuracy con fairness penalty.
    alpha=1: solo accuracy
    alpha=0: solo fairness
    """
    from sklearn.metrics import accuracy_score
    
    acc = accuracy_score(y_true, y_pred)
    
    # Penalty por violation de paridad demográfica
    dp = demographic_parity_difference(
        type('Model', (), {'predict': lambda x: y_pred})(),
        X, sensitive_attr
    )
    
    fairness_score = 1 - abs(dp)
    
    return alpha * acc + (1 - alpha) * fairness_score

# Optimizar para ambas cosas
score = fairness_adjusted_accuracy(y_test, y_pred, 'estrato', X_test)
print(f"Fairness-Adjusted Score: {score:.4f}")

📝 Resumen

  • Selection bias: datos no representan la realidad — audita tu muestreo
  • Confirmation bias: le metes tu worldview al modelo — sé consciente de tus supuestos
  • Proxy bias: variables sustitutas discriminan indirectamente — identifica proxies
  • Demographic parity: igual probabilidad de resultado positivo por grupo
  • Equalized odds: igual TPR y FPR por grupo — más exigente
  • Reweighting y resampling: técnicas prácticas para mitigar bias

En Colombia, donde la desigualdad social es struktural, un modelo con bias no es solo un problema técnico — es un problema ético y político. Antes de deployar, pregúntate: ¿a quién estoy perjudcando con este modelo?
