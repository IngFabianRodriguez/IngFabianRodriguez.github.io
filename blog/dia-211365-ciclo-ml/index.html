LoRA - Low-Rank Adaptation De Modelos

Hagale pues, parcero. Dia 211 y hoy hablamos de LoRA, Low-Rank Adaptation, la forma eficiente de fine-tunar. Dejala el cafe.

🎯 Que Es LoRA?

LoRA reduce parametros entrenables agregando matrices de bajo rango junto a las capas de atencion. Solo entrena 0.1-10% de parametros.

Ventajas:

  • Eficiente: 10-100x menos parametros
  • Modular: Multiples adaptadores para diferentes tareas
  • Fast switching: Cambia entre tareas rapidamente

📐 LoRA En PyTorch

from loralib import LoRALayer, Linear

# Reemplazar capa lineal con LoRA
class LoRALinear(nn.Module):
    def __init__(self, in_features, out_features, rank=4):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.lora = LoRALayer(in_features, out_features, rank)
    
    def forward(self, x):
        return self.linear(x) + self.lora(x)
