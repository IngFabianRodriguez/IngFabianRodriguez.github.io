🔐 El Panorama de Amenazas en LLM Systems

Antes de hablar de soluciones, necesitamos entender los riesgos. Los sistemas LLM tienen superficies de ataque únicas que no existían en software tradicional:

La matemática del riesgo:

Para un sistema tradicional, la probabilidad de compromiso $P_{compromise}$ se modela como:

$$P_{compromise} = 1 - \prod_{i=1}^{n}(1 - p_i)$$

Donde $p_i$ es la probabilidad de explotación del vector de ataque $i$. En un sistema LLM con $n$ vectores de ataque potenciales — desde prompt injection hasta data poisoning — el riesgo compuesto crece de forma no lineal si no hay controles adecuados.

🛡️ Framework de Seguridad para LLMs

"""
Security Framework para LLM Production Systems.
"""

from dataclasses import dataclass, field
from typing import List, Dict, Optional, Set, Any, Callable
from datetime import datetime
from enum import Enum
import hashlib
import hmac
import json


class ThreatCategory(Enum):
    """Categorías de amenazas para LLMs."""
    PROMPT_INJECTION = "prompt_injection"       # Inyección de instrucciones
    DATA_EXTRACTION = "data_extraction"         # Extracción de datos sensibles
    MODEL_DOS = "model_dos"                     # Denial of service al modelo
    HALLUCINATION_ABUSE = "hallucination_abuse" # Generar contenido dañino
    PRIVACY_BREACH = "privacy_breach"           # Fuga de información privada
    ADVERSARIAL = "adversarial"                 # Inputs adversarios


@dataclass
class SecurityIncident:
    """Registro de un incidente de seguridad."""
    incident_id: str
    timestamp: datetime
    category: ThreatCategory
    severity: str  # "low", "medium", "high", "critical"
    input_data: str
    blocked_output: Optional[str]
    action_taken: str
    resolved: bool = False


@dataclass
class DataClassification:
    """Clasificación de datos."""
    level: str  # "public", "internal", "confidential", "restricted"
    category: str  # "pii", "financial", "health", "general"
    retention_days: int
    encryption_required: bool


class LLMSecurityFramework:
    """
    Framework completo de seguridad para sistemas LLM.
    
    Capas de protección:
    1. Input Validation: Sanitizar y validar inputs
    2. Output Filtering: Filtrar outputs peligrosos
    3. Access Control: Control de acceso granular
    4. Audit Logging: Logging inmutable de todo
    5. Encryption: Cifrado end-to-end
    6. Data Governance: Clasificación y retención de datos
    """
    
    def __init__(self, config: Dict[str, Any]):
        self.config = config
        self.incident_log: List[SecurityIncident] = []
        
        # Reglas de validación de input
        self.input_rules: List[Callable] = []
        self._register_default_rules()
        
        # Clasificación de datos por defecto
        self.data_classifications: Dict[str, DataClassification] = {}
        self._register_default_classifications()
        
        # Keys para encryption
        self._encryption_key = config.get("encryption_key")
        
    def _register_default_rules(self):
        """Registra reglas de seguridad por defecto."""
        # Regla 1: Detectar prompt injection
        def detect_injection(input_text: str) -> Optional[str]:
            injection_patterns = [
                "ignore previous instructions",
                "disregard all previous",
                "you are now",
                "pretend you are",
                "new system prompt",
                "override security",
            ]
            lower_input = input_text.lower()
            for pattern in injection_patterns:
                if pattern in lower_input:
                    return f"Prompt injection detected: '{pattern}'"
            return None
        
        # Regla 2: Detectar intentos de extracción de datos
        def detect_data_extraction(input_text: str) -> Optional[str]:
            extraction_patterns = [
                "reveal your system prompt",
                "show me your instructions",
                "ignore your guidelines",
                "what are your rules",
                "tell me about yourself",
            ]
            lower_input = input_text.lower()
            for pattern in extraction_patterns:
                if pattern in lower_input:
                    return f"Data extraction attempt: '{pattern}'"
            return None
        
        # Regla 3: Longitud excesiva (posible DoS)
        def detect_length_anomaly(input_text: str) -> Optional[str]:
            max_length = self.config.get("max_input_length", 10000)
            if len(input_text) > max_length:
                return f"Input length {len(input_text)} exceeds max {max_length}"
            return None
        
        self.input_rules = [
            detect_injection,
            detect_data_extraction,
            detect_length_anomaly,
        ]
    
    def _register_default_classifications(self):
        """Registra clasificaciones de datos por defecto."""
        self.data_classifications = {
            "email": DataClassification(
                level="confidential",
                category="pii",
                retention_days=365,
                encryption_required=True
            ),
            "phone": DataClassification(
                level="confidential",
                category="pii",
                retention_days=365,
                encryption_required=True
            ),
            "id_number": DataClassification(
                level="restricted",
                category="pii",
                retention_days=2555,  # 7 años paracompliance
                encryption_required=True
            ),
            "financial": DataClassification(
                level="restricted",
                category="financial",
                retention_days=2555,
                encryption_required=True
            ),
            "health": DataClassification(
                level="restricted",
                category="health",
                retention_days=2555,  # Regulación local aplicable
                encryption_required=True
            ),
        }
    
    def validate_input(self, input_text: str, user_id: str) -> Dict[str, Any]:
        """
        Valida input antes de enviarlo al LLM.
        
        Returns:
            {
                "allowed": bool,
                "violations": List[str],
                "sanitized_input": str,
                "risk_score": float
            }
        """
        violations = []
        sanitized = input_text
        risk_score = 0.0
        
        for rule in self.input_rules:
            violation = rule(input_text)
            if violation:
                violations.append(violation)
                risk_score += 0.3  # Incrementar riesgo por cada violación
        
        # Sanitización básica
        # Remover caracteres de control
        sanitized = ''.join(char for char in sanitized if ord(char) >= 32 or char in '\n\r\t')
        
        # Truncar si es muy largo
        max_length = self.config.get("max_input_length", 10000)
        if len(sanitized) > max_length:
            sanitized = sanitized[:max_length]
        
        allowed = len(violations) == 0 or risk_score < self.config.get("risk_threshold", 0.7)
        
        return {
            "allowed": allowed,
            "violations": violations,
            "sanitized_input": sanitized,
            "risk_score": min(risk_score, 1.0),
            "action": "block" if not allowed else ("review" if risk_score > 0.5 else "allow")
        }
    
    def filter_output(self, output_text: str, context: Dict) -> Dict[str, Any]:
        """
        Filtra output del LLM antes de enviarlo al usuario.
        """
        violations = []
        filtered_output = output_text
        
        # Reglas de contenido sensible
        sensitive_patterns = [
            (r'\b\d{3}-\d{2}-\d{4}\b', "SSN pattern detected"),  # SSN-like
            (r'\b\d{16}\b', "Credit card pattern detected"),
            (r'\b[A-Z]{1,2}\d{6,10}\b', "ID number detected"),
        ]
        
        import re
        for pattern, description in sensitive_patterns:
            if re.search(pattern, output_text):
                violations.append(description)
                # Mask sensitive data
                filtered_output = re.sub(pattern, "***REDACTED***", filtered_output)
        
        # Detectar información personal en outputs del modelo
        pii_patterns = [
            (r'\b[\w.+-]+@[\w-]+\.[\w.-]+\b', "Email detected"),
            (r'\b\d{3}[-.]?\d{3}[-.]?\d{4}\b', "Phone detected"),
        ]
        
        for pattern, description in pii_patterns:
            matches = re.findall(pattern, output_text)
            if matches:
                # Verificar si es información real o ficticia
                # En producción, hacer verificación contra base de datos
                violations.append(f"{description}: {len(matches)} potential(s)")
        
        return {
            "filtered": len(violations) > 0,
            "violations": violations,
            "output": filtered_output,
            "requires_review": len(violations) > 0
        }
    
    def classify_data(self, data_type: str) -> DataClassification:
        """Retorna la clasificación para un tipo de dato."""
        return self.data_classifications.get(
            data_type,
            DataClassification(
                level="internal",
                category="general",
                retention_days=90,
                encryption_required=False
            )
        )
    
    def log_security_event(
        self,
        category: ThreatCategory,
        severity: str,
        input_data: str,
        output_data: Optional[str],
        action_taken: str
    ) -> SecurityIncident:
        """Registra un evento de seguridad."""
        incident = SecurityIncident(
            incident_id=hashlib.sha256(
                f"{datetime.now().isoformat()}{input_data}".encode()
            ).hexdigest()[:16],
            timestamp=datetime.now(),
            category=category,
            severity=severity,
            input_data=input_data[:500],  # Truncar para guardar
            blocked_output=output_data[:500] if output_data else None,
            action_taken=action_taken
        )
        self.incident_log.append(incident)
        return incident

📋 Framework de Compliance para Datos Sensibles

Más allá de la seguridad técnica, necesitamos un framework de compliance que maneje los datos de acuerdo a las regulaciones aplicables. En Colombia, eso incluye la Ley 1581 de 2012 (protección de datos personales) y el Decreto 1377 de 2013.

"""
Compliance Framework para LLM Production Systems.
Implementa controles para GDPR, CCPA, y regulaciones locales.
"""

from dataclasses import dataclass, field
from typing import List, Dict, Optional, Any, Set
from datetime import datetime, timedelta
from enum import Enum


class Regulation(Enum):
    """Regulaciones soportadas."""
    GDPR = "gdpr"                    # EU General Data Protection
    CCPA = "ccpa"                   # California Consumer Privacy
    LGPD = "lgpd"                   # Brazil Lei Geral de Proteção
    LEY_1581 = "ley_1581"           # Colombia: Protección de datos
    HIPAA = "hipaa"                 # US Health Insurance Portability


class DataSubjectRight(Enum):
    """Derechos del titular de datos."""
    ACCESS = "access"               # Conocer qué datos tenemos
    RECTIFICATION = "rectification" # Corregir datos inexactos
    ERASURE = "erasure"             # Solicitar eliminación
    PORTABILITY = "portability"    # Recibir sus datos en formato portable
    OBJECT = "object"               # Objetar al tratamiento
    RESTRICT = "restrict"           # Restringir procesamiento


@dataclass
class ConsentRecord:
    """Registro de consentimiento del usuario."""
    consent_id: str
    user_id: str
    purpose: str
    granted: bool
    timestamp: datetime
    method: str  # "explicit", "implicit", "withdrawn"
    expires_at: Optional[datetime] = None


@dataclass
class DataProcessingActivity:
    """Actividad de procesamiento de datos."""
    activity_id: str
    purpose: str
    legal_basis: str  # "consent", "legitimate_interest", "contract", "legal_obligations"
    data_categories: List[str]
    retention_days: int
    safeguards: List[str]

class ComplianceFramework:
    """
    Framework de compliance para manejo de datos en LLMs.
    
    Principios fundamentales:
    1. Lawfulness: Todo procesamiento debe tener base legal
    2. Purpose Limitation: Datos solo para propósitos declarados
    3. Data Minimization: Solo recopilar lo necesario
    4. Accuracy: Mantener datos precisos y actualizados
    5. Storage Limitation: No guardar más de lo necesario
    6. Integrity & Confidentiality: Seguridad adecuada
    7. Accountability: Demonstrar compliance
    """
    
    def __init__(self, config: Dict[str, Any]):
        self.config = config
        self.applicable_regulations: Set[Regulation] = set()
        
        # Consent records
        self.consent_records: Dict[str, List[ConsentRecord]] = {}
        
        # Processing activities registradas
        self.processing_activities: Dict[str, DataProcessingActivity] = {}
        
        # Data inventory
        self.data_inventory: Dict[str, Dict] = {}
        
        # DSAR (Data Subject Access Requests) queue
        self.dsar_queue: List[Dict] = []
    
    def register_activity(
        self,
        purpose: str,
        legal_basis: str,
        data_categories: List[str],
        retention_days: int,
        regulation: Regulation
    ) -> DataProcessingActivity:
        """Registra una nueva actividad de procesamiento."""
        activity = DataProcessingActivity(
            activity_id=f"act_{purpose[:20]}_{datetime.now().strftime('%Y%m%d')}",
            purpose=purpose,
            legal_basis=legal_basis,
            data_categories=data_categories,
            retention_days=retention_days,
            safeguards=["encryption_at_rest", "encryption_in_transit", "access_logging"],
            regulation=regulation
        )
        self.processing_activities[activity.activity_id] = activity
        return activity
    
    def request_consent(
        self,
        user_id: str,
        purpose: str,
        data_categories: List[str]
    ) -> ConsentRecord:
        """Solicita consentimiento para procesamiento."""
        consent = ConsentRecord(
            consent_id=f"consent_{user_id}_{purpose}_{datetime.now().timestamp()}",
            user_id=user_id,
            purpose=purpose,
            granted=False,
            timestamp=datetime.now(),
            method="explicit",
            expires_at=datetime.now() + timedelta(days=365)
        )
        
        if user_id not in self.consent_records:
            self.consent_records[user_id] = []
        self.consent_records[user_id].append(consent)
        
        return consent
    
    def grant_consent(self, consent_id: str) -> bool:
        """Confirma que el usuario granting consent."""
        for user_id, records in self.consent_records.items():
            for record in records:
                if record.consent_id == consent_id:
                    record.granted = True
                    return True
        return False
    
    def check_consent(self, user_id: str, purpose: str) -> bool:
        """Verifica si existe consentimiento válido."""
        if user_id not in self.consent_records:
            return False
        
        for record in self.consent_records[user_id]:
            if record.purpose == purpose:
                if record.granted and not self._is_expired(record):
                    return True
        return False
    
    def _is_expired(self, record: ConsentRecord) -> bool:
        """Verifica si el consentimiento ha expirado."""
        if record.expires_at is None:
            return False
        return datetime.now() > record.expires_at

        Plazo de respuesta: 10 días hábiles (ampliable a 5 días más).
        """
        dsar_id = f"dsar_{requester_id}_{datetime.now().timestamp()}"
        
        # Verificar identidad del solicitante (en producción, proceso riguroso)
        # En producción: verificar documento de identidad
        
        if request_type == DataSubjectRight.ERASURE:
            # Right to be forgotten — implementar con cuidado
            # No aplica para datos que tenemos obligación legal de retener
            return {
                "dsar_id": dsar_id,
                "status": "processing",
                "estimated_completion": (datetime.now() + timedelta(days=10)).isoformat(),
                "notes": "Verificando excepciones legales antes de proceder"
            }
        
        elif request_type == DataSubjectRight.ACCESS:
            # Acceso a datos: recopilarlos y entregarlos
            user_data = self._collect_user_data(requester_id, data_categories)

🔒 Data Handling Pipeline

Ahora, cómo encajan todas estas piezas en un pipeline de datos que respete seguridad, compliance y privacy:

"""
Secure Data Pipeline para LLM Systems.
Maneja el flujo completo de datos con controles de seguridad.
"""

from dataclasses import dataclass
from typing import List, Dict, Any, Optional
from datetime import datetime
from enum import Enum
import hashlib


class ProcessingStage(Enum):
    """Etapas del procesamiento de datos."""
    INPUT_RECEIVED = "input_received"
    CLASSIFICATION = "classification"
    CONSENT_CHECK = "consent_check"
    SANITIZATION = "sanitization"
    LLM_PROCESSING = "llm_processing"
    OUTPUT_FILTER = "output_filter"
    STORAGE = "storage"
    ARCHIVAL = "archival"
    DELETION = "deletion"


class DataState(Enum):
    """Estado del dato en el pipeline."""
    PLAINTEXT = "plaintext"
    MASKED = "masked"
    ENCRYPTED = "encrypted"
    ANONYMIZED = "anonymized"
    DELETED = "deleted"


@dataclass
class DataPacket:
    """Un paquete de datos en el pipeline."""
    packet_id: str
    user_id: str
    content: str
    sensitive_elements: List[Dict[str, Any]]
    classification: str
    state: DataState
    consent_verified: bool
    processing_log: List[Dict]
    created_at: datetime


class SecureDataPipeline:
    """
    Pipeline seguro de datos para LLMs.
    
    Características:
    - Clasificación automática de datos
    - Verificación de consentimiento
    - Tokenización/masking de PII
    - Encriptación end-to-end
    - Audit trail completo
    - Manejo de retención automática
    """
    
    def __init__(self, security_framework, compliance_framework):
        self.security = security_framework
        self.compliance = compliance_framework
        
        # Pipeline stages
        self.stages = [
            ProcessingStage.INPUT_RECEIVED,
            ProcessingStage.CLASSIFICATION,
            ProcessingStage.CONSENT_CHECK,
            ProcessingStage.SANITIZATION,
            ProcessingStage.LLM_PROCESSING,
            ProcessingStage.OUTPUT_FILTER,
            ProcessingStage.STORAGE,
        ]
    
    def process(
        self,
        user_id: str,
        content: str,
        purpose: str,
        context: Optional[Dict] = None
    ) -> Dict[str, Any]:
        """
        Procesa datos a través del pipeline seguro.
        """
        # 1. Crear paquete inicial
        packet = DataPacket(
            packet_id=hashlib.sha256(f"{user_id}{content}{datetime.now().isoformat()}".encode()).hexdigest()[:16],
            user_id=user_id,
            content=content,
            sensitive_elements=[],
            classification="internal",
            state=DataState.PLAINTEXT,
            consent_verified=False,
            processing_log=[],
            created_at=datetime.now()
        )
        
        # 2. Classification
        packet = self._classify(packet)
        
        # 3. Consent check
        packet = self._check_consent(packet, purpose)
        
        # 4. Sanitization / Masking
        packet = self._sanitize(packet)
        
        # 5. LLM Processing (el modelo ve solo datos sanitizados)
        llm_response = self._process_llm(packet, context or {})
        
        # 6. Output filter
        filtered_response = self._filter_output(llm_response, packet)
        
        # 7. Storage (solo si aplica retención)
        self._handle_storage(packet, filtered_response)
        
        return {
            "packet_id": packet.packet_id,
            "response": filtered_response["output"],
            "was_sanitized": packet.state == DataState.MASKED,
            "sensitive_elements_found": len(packet.sensitive_elements),
            "consent_verified": packet.consent_verified,
            "processing_time_ms": 0  # Placeholder
        }
    
    def _classify(self, packet: DataPacket) -> DataPacket:
        """Clasifica el contenido del paquete."""
        # Detectar elementos sensibles
        sensitive = []
        
        import re
        patterns = [
            (r'\b[\w.+-]+@[\w-]+\.[\w.-]+\b', "email"),
            (r'\b\d{3}[-.]?\d{3}[-.]?\d{4}\b', "phone"),
            (r'\b\d{1,2}\s+\w+\s+\d{4,}\b', "date"),
        ]
        
        for pattern, type_ in patterns:
            matches = re.findall(pattern, packet.content)
            for match in matches:
                sensitive.append({
                    "type": type_,
                    "value": match,
                    "position": packet.content.find(match)
                })
        
        packet.sensitive_elements = sensitive
        packet.classification = "confidential" if sensitive else "internal"
        
        packet.processing_log.append({
            "stage": ProcessingStage.CLASSIFICATION.value,
            "timestamp": datetime.now().isoformat(),
            "result": "classified"
        })
        
        return packet
    
    def _check_consent(self, packet: DataPacket, purpose: str) -> DataPacket:
        """Verifica consentimiento del usuario."""
        has_consent = self.compliance.check_consent(packet.user_id, purpose)
        packet.consent_verified = has_consent
        
        packet.processing_log.append({
            "stage": ProcessingStage.CONSENT_CHECK.value,
            "timestamp": datetime.now().isoformat(),
            "result": "granted" if has_consent else "denied"
        })
        
        return packet
    
    def _sanitize(self, packet: DataPacket) -> DataPacket:
        """Sanitiza/masquea elementos sensibles."""
        if not packet.sensitive_elements:
            return packet
        
        sanitized = packet.content
        for element in packet.sensitive_elements:
            # Reemplazar con token
            token = f"[{element['type'].upper()}_{element['position']}]"
            sanitized = sanitized.replace(element['value'], token)
        
        packet.content = sanitized
        packet.state = DataState.MASKED
        
        packet.processing_log.append({
            "stage": ProcessingStage.SANITIZATION.value,
            "timestamp": datetime.now().isoformat(),
            "elements_masked": len(packet.sensitive_elements)
        })
        
        return packet
    
    def _process_llm(self, packet: DataPacket, context: Dict) -> str:
        """Procesa a través del LLM (placeholder)."""
        # En producción, aquí se llama al modelo
        # El modelo recibe SOLO el contenido sanitizado
        return f"Response based on sanitized input (packet {packet.packet_id[:8]}...)"
    
    def _filter_output(self, response: str, packet: DataPacket) -> Dict:

⚠️ Los 3 Errores Críticos

Error 1: No Considerar la Seguridad

El problema: Tratar la seguridad como un afterthought. Piensas "ya depois hacemos la seguridad" — pero cuando llega un ataque o una brecha, ya es demasiado tarde. El costo de remediar una brecha de datos es 3x el costo de prevenirla.

La solución: Security by design desde el día uno. Implementa validación de inputs, filtering de outputs, y logging de auditoría antes de poner cualquier cosa en producción.

# Checklist de seguridad mínimo para producción
SECURITY_CHECKLIST = {
    "input_validation": True,
    "output_filtering": True,
    "audit_logging": True,
    "encryption_at_rest": True,
    "encryption_in_transit": True,
    "rate_limiting": True,
    "prompt_injection_detection": True,
    "pii_masking": True,
}

Error 2: No Manejar Data Privacy

El problema: Enviar datos de usuarios directamente al LLM sin verificar consentimiento, sin clasificar qué datos son sensibles, y sin tener política de retención. Esto viola regulaciones como Ley 1581 en Colombia, GDPR en Europa, y CCPA en California.

La solución: Implementa consentimiento verificable, clasificación automática de datos, y políticas de retención. Los datos sensibles nunca deben llegar al LLM en texto plano.

# Pipeline de privacidad mínimo
PRIVACY_PIPELINE = {
    "classify_before_processing": True,
    "verify_consent": True,
    "mask_pii": True,
    "encrypt_stored_data": True,
    "enforce_retention": True,
    "allow_deletion": True,  # Derecho al olvido
}

Error 3: No Ser Compliant

El problema: No tener registro de qué datos procesas, para qué propósito, con qué base legal, y por cuánto tiempo. Cuando te auditorían o un usuario ejerce sus derechos (DSAR), no tienes cómo responder.

La solución: Mantén un registro de actividades de procesamiento (RoPA), implementa proceso para manejar DSARs, y haz audits regulares de compliance. La documentación no es opcional — es tu defensa.
