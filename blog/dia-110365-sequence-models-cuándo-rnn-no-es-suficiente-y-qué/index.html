🎯 Introducción

Hágale pues, parcero. Llegamos al Día 110 y hoy vamos a hablar de Sequence Models y por qué las RNNs simples a veces no son suficientes. Si ayer vimos GRU, hoy vamos un paso más allá: encoder-decoder, attention, y beam search. Esto es lo que se usa en traducción automática, chatbots, y resumen de texto. Después de años implementando esto en producción, te cuento los errores que el 80% de la gente comete.

📐 La Arquitectura Encoder-Decoder

El problema con las RNNs vanilla es que procesan una secuencia y producen una salida. ¿Pero qué pasa cuando entrada y salida tienen длины diferentes? Por ejemplo:

  • Traducción: "Hola mundo" (4 palabras) → "Hello world" (2 palabras)
  • Resumen: Un artículo de 500 palabras → 3 oraciones
  • Chat: Una pregunta → Una respuesta variable

La solución es la arquitectura Encoder-Decoder (o Seq2Seq):

# Diagrama conceptual de Seq2Seq:
#
# Encoder:  H_1 → H_2 → H_3 → ... → H_T (captura toda la info en un vector)
#             ↓    ↓    ↓         ↓
#           x_1  x_2  x_3       x_T
#
# Decoder:  s_0 → s_1 → s_2 → ... (genera salida token por token)
#              ↓    ↓    ↓
#            [c]  [c]  [c]  ...  (context vector del encoder)
#
# donde [c] = h_T (último estado del encoder = context vector)

El Context Vector: El Cuello de Botella

El mayor problema del encoder-decoder básico es el information bottleneck: toda la información de la secuencia de entrada se comprime en un único vector de tamaño fijo. Si la secuencia tiene 100 tokens y tu hidden size es 256, ¿cómo vas a representar toda esa información? Es como querer meter una biblioteca entera en una hoja de papel.

🚀 Implementación Completa En PyTorch

1. Seq2Seq Encoder-Decoder desde cero

import torch
import torch.nn as nn
import torch.nn.functional as F
import math


class Encoder(nn.Module):
    """
    Encoder RNN que procesa la secuencia de entrada.
    Retorna el último hidden state como context vector.
    """
    def __init__(self, input_size: int, embed_size: int, hidden_size: int):
        super().__init__()
        self.hidden_size = hidden_size
        self.embedding = nn.Embedding(input_size, embed_size, padding_idx=0)
        self.gru = nn.GRU(embed_size, hidden_size, batch_first=True)

    def forward(self, x: torch.Tensor, lengths: torch.Tensor) -> tuple:
        """
        Args:
            x: (batch, seq_len) — token IDs
            lengths: (batch,) — longitud real de cada secuencia
        Returns:
            hidden: (1, batch, hidden_size) — último estado oculto
        """
        # Embedding: (batch, seq_len) → (batch, seq_len, embed_size)
        embedded = self.embedding(x)

        # Pack padded sequence para ignorar padding
        packed = nn.utils.rnn.pack_padded_sequence(
            embedded, lengths.cpu(), batch_first=True, enforce_sorted=False
        )
        _, hidden = self.gru(packed)
        # hidden: (1, batch, hidden_size)

        return hidden

    def forward_all_states(self, x: torch.Tensor) -> torch.Tensor:
        """
        Retorna todos los estados ocultos, no solo el último.
        Necesario para attention.
        """
        embedded = self.embedding(x)
        outputs, hidden = self.gru(embedded)
        # outputs: (batch, seq_len, hidden_size)
        return outputs


class Decoder(nn.Module):
    """
    Decoder RNN que genera la secuencia de salida token por token.
    """
    def __init__(self, output_size: int, embed_size: int, hidden_size: int):
        super().__init__()
        self.hidden_size = hidden_size
        self.embedding = nn.Embedding(output_size, embed_size, padding_idx=0)
        self.gru = nn.GRU(embed_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(
        self,
        x: torch.Tensor,
        hidden: torch.Tensor,
        context: torch.Tensor = None
    ) -> tuple:
        """
        Args:
            x: (batch,) — token de entrada (teacher forcing o predicción anterior)
            hidden: (1, batch, hidden_size) — estado del decoder
            context: (batch, hidden_size) — context vector del encoder
        Returns:
            output: (batch, output_size) — logits
            hidden: (1, batch, hidden_size) — nuevo estado
        """
        # x: (batch,) → (batch, 1) → embedding → (batch, 1, embed_size)
        x = x.unsqueeze(1) if x.dim() == 1 else x
        embedded = self.embedding(x)

        # Concatenar embedding con context vector si existe
        if context is not None:
            # context: (batch, hidden_size) → (batch, 1, hidden_size)
            context = context.unsqueeze(1)
            # concatenated: (batch, 1, embed_size + hidden_size)
            concatenated = torch.cat([embedded, context], dim=-1)
            output, hidden = self.gru(concatenated, hidden)
        else:
            output, hidden = self.gru(embedded, hidden)

        # output: (batch, 1, hidden_size) → (batch, hidden_size) → (batch, output_size)
        output = self.fc(output.squeeze(1))
        return output, hidden


class Seq2Seq(nn.Module):
    """
    Modelo Seq2Seq completo con Encoder-Decoder.
    """
    def __init__(
        self,
        input_vocab_size: int,
        output_vocab_size: int,
        embed_size: int = 128,
        hidden_size: int = 256,
        pad_idx: int = 0,
    ):
        super().__init__()
        self.encoder = Encoder(input_vocab_size, embed_size, hidden_size)
        self.decoder = Decoder(output_vocab_size, embed_size, hidden_size)
        self.pad_idx = pad_idx

    def forward(
        self,
        src: torch.Tensor,
        tgt: torch.Tensor,
        src_lengths: torch.Tensor,
        teacher_forcing_ratio: float = 0.5,
    ) -> torch.Tensor:
        """
        Args:
            src: (batch, src_seq_len) — secuencia de entrada
            tgt: (batch, tgt_seq_len) — secuencia objetivo
            src_lengths: (batch,) — longitudes reales
            teacher_forcing_ratio: probabilidad de usar teacher forcing
        Returns:
            logits: (batch * tgt_seq_len, output_vocab_size)
        """
        batch_size = src.size(0)
        tgt_len = tgt.size(1)

        # Encoder: obtener context vector
        context = self.encoder(src, src_lengths)  # (1, batch, hidden_size)
        context = context.squeeze(0)  # (batch, hidden_size)

        # Decoder: generar secuencialmente
        outputs = []
        decoder_input = tgt[:, 0]  # <SOS> token
        decoder_hidden = context.unsqueeze(0)  # (1, batch, hidden_size)

        for t in range(1, tgt_len):
            output, decoder_hidden = self.decoder(decoder_input, decoder_hidden, context)
            outputs.append(output)

            # Teacher forcing: usar ground truth con cierta probabilidad
            if self.training and torch.rand(1).item() < teacher_forcing_ratio:
                decoder_input = tgt[:, t]
            else:
                decoder_input = output.argmax(dim=-1)

        return torch.stack(outputs, dim=1)  # (batch, tgt_len-1, vocab_size)

    def generate(
        self,
        src: torch.Tensor,
        src_lengths: torch.Tensor,
        max_len: int = 50,
        eos_idx: int = 2,
    ) -> torch.Tensor:
        """
        Generación greedy (sin teacher forcing) para inferencia.
        """
        batch_size = src.size(0)

        # Encoder
        context = self.encoder(src, src_lengths).squeeze(0)  # (batch, hidden_size)
        decoder_hidden = context.unsqueeze(0)

        # Iniciar con <SOS>
        decoder_input = torch.full((batch_size,), eos_idx + 1, device=src.device)

        generated = []
        for _ in range(max_len):
            output, decoder_hidden = self.decoder(decoder_input, decoder_hidden, context)
            predicted = output.argmax(dim=-1)
            generated.append(predicted)
            decoder_input = predicted

        return torch.stack(generated, dim=1)  # (batch, max_len)

2. Seq2Seq con Attention

class AttentionDecoder(nn.Module):
    """
    Decoder con attention mechanism.
    Permite al decoder "ver" todos los estados del encoder en cada paso.
    """
    def __init__(self, output_size: int, embed_size: int, hidden_size: int, enc_hidden_size: int):
        super().__init__()
        self.hidden_size = hidden_size
        self.enc_hidden_size = enc_hidden_size

        self.embedding = nn.Embedding(output_size, embed_size)
        # Atención: combina estado actual del decoder con estados del encoder
        self.attention = nn.Linear(hidden_size + enc_hidden_size, hidden_size)
        self.v = nn.Parameter(torch.randn(hidden_size))

        self.gru = nn.GRU(embed_size + enc_hidden_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size + enc_hidden_size, output_size)

    def forward(
        self,
        x: torch.Tensor,
        decoder_hidden: torch.Tensor,
        encoder_outputs: torch.Tensor,
        mask: torch.Tensor = None,
    ) -> tuple:
        """
        Args:
            x: (batch,) — token de entrada
            decoder_hidden: (1, batch, hidden_size) — estado actual del decoder
            encoder_outputs: (batch, src_seq_len, enc_hidden_size) — todos los estados del encoder
            mask: (batch, src_seq_len) — máscara para ignorar padding
        Returns:
            output: (batch, output_size) — logits
            decoder_hidden: (1, batch, hidden_size)
            attention_weights: (batch, src_seq_len) — pesos de atención
        """
        batch_size = encoder_outputs.size(0)
        src_seq_len = encoder_outputs.size(1)

        # x: (batch,) → (batch, 1, embed_size)
        embedded = self.embedding(x).unsqueeze(1)  # (batch, 1, embed_size)

        # Calcular attention scores
        # Repeat decoder_hidden para cada posición del encoder
        decoder_hidden_repeated = decoder_hidden.permute(1, 0, 2).repeat(1, src_seq_len, 1)
        # combined: (batch, src_seq_len, hidden_size + enc_hidden_size)
        combined = torch.cat([decoder_hidden_repeated, encoder_outputs], dim=-1)

        # energy: (batch, src_seq_len, hidden_size)
        energy = torch.tanh(self.attention(combined))
        # v: (hidden_size,) → (1, 1, hidden_size) → (batch, src_seq_len, hidden_size)
        energy = energy @ self.v.unsqueeze(0).unsqueeze(0).T  # (batch, src_seq_len, 1)

        # Aplicar máscara (si existe)
        if mask is not None:
            attention_weights = energy.squeeze(-1).masked_fill(mask == 0, float('-inf'))
        else:
            attention_weights = energy.squeeze(-1)

        # Softmax para obtener pesos de atención
        attention_weights = F.softmax(attention_weights, dim=-1)  # (batch, src_seq_len)

        # Context vector: suma ponderada de los estados del encoder
        context = attention_weights.unsqueeze(-1) * encoder_outputs  # (batch, src_seq_len, enc_hidden_size)
        context = context.sum(dim=1)  # (batch, enc_hidden_size)

        # GRU: concatenar embedding con context
        gru_input = torch.cat([embedded.squeeze(1), context], dim=-1)  # (batch, embed_size + enc_hidden_size)
        gru_input = gru_input.unsqueeze(1)  # (batch, 1, embed_size + enc_hidden_size)
        output, decoder_hidden = self.gru(gru_input, decoder_hidden)

        # Output: concatenar hidden state con context
        output = self.fc(torch.cat([output.squeeze(1), context], dim=-1))  # (batch, output_size)

        return output, decoder_hidden, attention_weights


class AttentionSeq2Seq(nn.Module):
    """
    Seq2Seq con Attention.
    """
    def __init__(
        self,
        input_vocab_size: int,
        output_vocab_size: int,
        embed_size: int = 128,
        hidden_size: int = 256,
    ):
        super().__init__()
        self.encoder = Encoder(input_vocab_size, embed_size, hidden_size)
        self.decoder = AttentionDecoder(output_vocab_size, embed_size, hidden_size, hidden_size)

    def forward(
        self,
        src: torch.Tensor,
        tgt: torch.Tensor,
        src_lengths: torch.Tensor,
        teacher_forcing_ratio: float = 0.5,
    ) -> torch.Tensor:
        batch_size = src.size(0)
        tgt_len = tgt.size(1)

        # Encoder: obtener TODOS los estados (no solo el último)
        encoder_outputs = self.encoder.forward_all_states(src)  # (batch, src_len, hidden_size)

        # Crear máscara para padding
        mask = (src != 0).float()  # (batch, src_len)

        # Iniciar decoder
        decoder_hidden = torch.zeros(1, batch_size, self.decoder.hidden_size, device=src.device)

        outputs = []
        attention_weights_all = []
        decoder_input = tgt[:, 0]  # <SOS>

        for t in range(1, tgt_len):
            output, decoder_hidden, attn_weights = self.decoder(
                decoder_input, decoder_hidden, encoder_outputs, mask
            )
            outputs.append(output)
            attention_weights_all.append(attn_weights)

            if self.training and torch.rand(1).item() < teacher_forcing_ratio:
                decoder_input = tgt[:, t]
            else:
                decoder_input = output.argmax(dim=-1)

        return torch.stack(outputs, dim=1)

    def generate(self, src, src_lengths, max_len=50, sos_idx=1, eos_idx=2):
        """Generación con atención para poder visualizar qué mira el modelo."""
        batch_size = src.size(0)
        encoder_outputs = self.encoder.forward_all_states(src)
        mask = (src != 0).float()

        decoder_hidden = torch.zeros(1, batch_size, self.decoder.hidden_size, device=src.device)
        decoder_input = torch.full((batch_size,), sos_idx, device=src.device)

        generated = []
        attention_history = []

        for _ in range(max_len):
            output, decoder_hidden, attn_weights = self.decoder(
                decoder_input, decoder_hidden, encoder_outputs, mask
            )
            predicted = output.argmax(dim=-1)
            generated.append(predicted)
            attention_history.append(attn_weights)
            decoder_input = predicted

        return torch.stack(generated, dim=1), torch.stack(attention_history, dim=1)

3. Beam Search

def beam_search(
    model: nn.Module,
    src: torch.Tensor,
    src_lengths: torch.Tensor,
    beam_width: int = 5,
    max_len: int = 50,
    sos_idx: int = 1,
    eos_idx: int = 2,
) -> torch.Tensor:
    """
    Beam Search para Decoding.

    Args:
        model: Seq2Seq con método generate()
        src: (batch, src_len) — secuencia de entrada
        src_lengths: (batch,) — longitudes reales
        beam_width: número de candidatos a mantener
        max_len: longitud máxima de generación
        sos_idx: índice del token start-of-sequence
        eos_idx: índice del token end-of-sequence

    Returns:
        best_sequence: (batch, max_len) — mejor secuencia encontrada
    """
    batch_size = src.size(0)
    device = src.device

    # Encoder
    encoder_outputs = model.encoder.forward_all_states(src)
    mask = (src != 0).float()
    decoder_hidden = torch.zeros(1, batch_size, model.decoder.hidden_size, device=device)

    # Inicializar beams: (log_prob, sequence, hidden_state)
    # Para beam_width=1 esto es equivalent a greedy
    beams = [(0.0, [sos_idx], decoder_hidden)]

    completed_sequences = []

    for step in range(max_len):
        all_candidates = []

        for log_prob, seq, hidden in beams:
            if seq[-1] == eos_idx:
                # Esta secuencia ya terminó, moverla a completed
                completed_sequences.append((log_prob, seq))
                continue

            # Decodificar un paso
            decoder_input = torch.tensor([seq[-1]], device=device)
            output, new_hidden, _ = model.decoder(
                decoder_input, hidden, encoder_outputs, mask
            )

            # Obtener top-k tokens
            log_probs = F.log_softmax(output, dim=-1)
            topk_log_probs, topk_ids = log_probs.topk(beam_width, dim=-1)

            # Crear candidatos
            for k in range(beam_width):
                token = topk_ids[0, k].item()
                new_log_prob = log_prob + topk_log_probs[0, k].item()
                new_seq = seq + [token]
                all_candidates.append((new_log_prob, new_seq, new_hidden))

        # Ordenar por log_prob y mantener top beam_width
        all_candidates.sort(key=lambda x: x[0], reverse=True)
        beams = all_candidates[:beam_width]

        # Si todas las secuencias terminaron, parar
        if not beams:
            break

    # Combinar secuencias completadas con las activas
    all_seqs = completed_sequences + [(log_prob, seq, None) for log_prob, seq, _ in beams]

    # Normalizar por longitud y tomar la mejor
    if all_seqs:
        all_seqs = [(log_prob / (len(seq) ** 0.7), seq) for log_prob, seq in all_seqs]
        all_seqs.sort(key=lambda x: x[0], reverse=True)
        best_seq = all_seqs[0][1]
    else:
        best_seq = [sos_idx]

    # Padding al max_len
    result = best_seq + [0] * (max_len - len(best_seq))
    return torch.tensor(result[:max_len], device=device).unsqueeze(0)

4. Scheduled Sampling (Teacher Forcing Progresivo)

class ScheduledSampler:
    """
    Scheduled Sampling: reduce gradualmente teacher forcing durante entrenamiento.
    Previene exposure bias.

    Al inicio usa 100% teacher forcing (fácil),
    gradualmente reduce hasta un mínimo,
    for the model to learn from its own mistakes.
    """
    def __init__(
        self,
        start_ratio: float = 1.0,  # Empezar con 100% teacher forcing
        end_ratio: float = 0.0,    # Terminar con 0% (autoregressive)
        num_steps: int = 10000,    # Pasos para hacer la transición
        strategy: str = "linear",   # "linear", "exponential", "inverse_sigmoid"
    ):
        self.start_ratio = start_ratio
        self.end_ratio = end_ratio
        self.num_steps = num_steps
        self.strategy = strategy
        self.step = 0

    def get_teacher_forcing_ratio(self) -> float:
        """Retorna el ratio actual de teacher forcing."""
        progress = min(self.step / self.num_steps, 1.0)

        if self.strategy == "linear":
            ratio = self.start_ratio + (self.end_ratio - self.start_ratio) * progress
        elif self.strategy == "exponential":
            ratio = self.start_ratio * ((self.end_ratio / self.start_ratio) ** progress)
        elif self.strategy == "inverse_sigmoid":
            # Empieza alto, baja rápido, termina cerca de 0
            ratio = self.end_ratio + (self.start_ratio - self.end_ratio) * (1 / (1 + math.exp(10 * progress - 5)))
        else:
            ratio = self.start_ratio

        self.step += 1
        return max(ratio, 0.0)

    def __repr__(self):
        return f"ScheduledSampler(step={self.step}/{self.num_steps}, strategy={self.strategy})"


class Trainer:
    def __init__(
        self,
        model: nn.Module,
        optimizer: torch.optim.Optimizer,
        scheduler: ScheduledSampler,
    ):
        self.model = model
        self.optimizer = optimizer
        self.scheduler = scheduler

    def train_step(self, src, tgt, src_lengths):
        tf_ratio = self.scheduler.get_teacher_forcing_ratio()

        self.model.train()
        logits = self.model(src, tgt, src_lengths, teacher_forcing_ratio=tf_ratio)

        # Loss
        loss = F.cross_entropy(
            logits.view(-1, logits.size(-1)),
            tgt[:, 1:].contiguous().view(-1),
            ignore_index=0,
        )

        loss.backward()
        torch.nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
        self.optimizer.step()
        self.optimizer.zero_grad()

        return loss.item(), tf_ratio

    def train_epoch(self, dataloader):
        total_loss = 0
        for i, (src, tgt, src_lengths) in enumerate(dataloader):
            loss, tf_ratio = self.train_step(src, tgt, src_lengths)
            total_loss += loss

            if i % 100 == 0:
                print(f"  Step {i}: loss={loss:.4f}, tf_ratio={tf_ratio:.3f}")

        return total_loss / len(dataloader)

⚠️ Errores Comunes Y Cómo Evitarlos

Error 1: Teacher forcing 100% del tiempo causa exposure bias

El problema: Si siempre usas teacher forcing durante entrenamiento, el modelo solo aprende a generar dado el ground truth anterior. En inferencia, el modelo genera dado su propia predicción anterior. Esta discrepancia causa que el modelo se acumulen errores durante generación larga — se llama exposure bias. El modelo nunca aprende a recuperarse de sus propios errores.

La solución: Usar scheduled sampling: empezar con teacher forcing alto e ir reduciéndolo gradualmente. También puedes usar free steering donde mezclas ambas estrategias.

# ❌ MAL: Teacher forcing constante al 100%
for epoch in range(num_epochs):
    for src, tgt in dataloader:
        output = model(src, tgt, teacher_forcing_ratio=1.0)  # ¡Siempre usa ground truth!

# ✅ BIEN: Scheduled sampling
sampler = ScheduledSampler(start_ratio=1.0, end_ratio=0.1, num_steps=10000)
for epoch in range(num_epochs):
    for src, tgt in dataloader:
        tf_ratio = sampler.get_teacher_forcing_ratio()
        output = model(src, tgt, teacher_forcing_ratio=tf_ratio)

# El modelo empieza aprendiendo de ground truth (fácil)
# y gradualmente aprende a recuperarse de sus propios errores

Error 2: No usar attention en secuencias largas causa information bottleneck

El problema: Sin attention, toda la información de la secuencia de entrada se comprime en un único context vector. Para secuencias largas, esto causa que información importante se pierda y el decoder no pueda "focus" en partes específicas de la entrada. El BLEU score cae drásticamente con la longitud.

La solución: Implementar attention mechanism. Esto permite al decoder en cada paso "mirar" todos los estados del encoder y weighting los más relevantes.

# ❌ MAL: Seq2Seq básico sin attention
class BadSeq2Seq(nn.Module):
    def __init__(self, ...):
        self.encoder = Encoder(...)
        self.decoder = Decoder(...)

    def forward(self, src, tgt):
        context = self.encoder(src)  # Solo el ÚLTIMO estado
        #                     ↑ BOTTLENECK
        output = self.decoder(tgt, context)
        return output

# ✅ BIEN: Seq2Seq con attention
class GoodSeq2Seq(nn.Module):
    def __init__(self, ...):
        self.encoder = Encoder(...)
        self.decoder = AttentionDecoder(...)  # ← Atención

    def forward(self, src, tgt):
        encoder_outputs = self.encoder(src)  # TODOS los estados
        #                    ↑
        # En cada paso, el decoder "mira" todos los estados del encoder
        output = self.decoder(tgt, encoder_outputs)
        return output

# Para secuencia de 50+ tokens, la diferencia es DRÁSTICA
# Sin attention: información se comprime, decoder no sabe qué vio
# Con attention: decoder puede enfocarse en tokens específicos

Error 3: Beam width=1 (greedy) cuando beam>1 mejora significativamente la calidad

El problema: Greedy decoding (beam_width=1) siempre elige el token más probable en cada paso. Pero el token más probable localmente no siempre lleva a la secuencia globalmente óptima. Por ejemplo: "voy a ir al [museo/banco]" — "banco" tiene alta probabilidad local pero arruina el significado global si el contexto era sobre cultura.

La solución: Usar beam search con beam_width >= 3. El tradeoff es que es más lento (lineal con beam_width), pero la calidad mejora significativamente, especialmente en tareas de generación larga como traducción o resumen.

# ❌ MAL: Greedy decoding
generated = model.generate(src, lengths, max_len=50)
# Solo considera el mejor token en cada paso
# Puede producir secuencias subóptimas

# ✅ BIEN: Beam search con beam_width=5
generated = beam_search(model, src, lengths, beam_width=5, max_len=50)
# Mantiene 5 candidatos y explora múltiples paths
# Considera la secuencia completa, no solo el siguiente token

# ✅ MEJOR: Beam search con beam_width=10 y length normalization
# La longitud afecta el score: normalizar por (len^alpha)
# Tip: alpha típicamente entre 0.6-0.7 funciona bien

# Comparación típica:
# Greedy:  Blue=0.28
# Beam-3:  Blue=0.33 (+18%)
# Beam-5:  Blue=0.35 (+25%)
# Beam-10: Blue=0.36 (+29%)
# Más allá de 10 el mejora marginal

💡 Resumen

  • Seq2Seq resuelve el problema de secuencias entrada/salida de longitud variable.
  • Encoder comprime la entrada en un context vector; Decoder genera la salida.
  • Attention resuelve el information bottleneck permitiendo al decoder ver todos los estados del encoder.
  • Beam search mejora sobre greedy considerando múltiples candidatos (beam > 1).
  • Scheduled sampling previene exposure bias mezclando teacher forcing con generación propia.
  • Errores comunes: teacher forcing 100%, no usar attention en secuencias largas, y greedy decoding.
