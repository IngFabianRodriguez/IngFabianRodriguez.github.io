Surveillance AI - Seguridad Y Privacidad

23 de octubre de 2026
surveillancecctvethicsprivacy

Intro

En Bogotá, una estación de metro con 200 cámaras CCTV genera 2TB de video por día. El operador de seguridad promedio puede monitorear efectivamente 6-8 cámaras simultáneamente, ignorando el 95% del footage. El resultado: incidentes que se detectan horas después cuando ya no se puede actuar. La Surveillance AI promete cambiar eso — detección en tiempo real, reconocimiento de anomalías, alertas automáticas. Pero el 80% de los implementadores no considera las implicaciones de privacidad y ética. El 20% que sí lo hace está constru-yendo sistemas que balances seguridad con derechos fundamentales. Hoy desglosamos cómo implementar surveillance AI de manera efectiva Y responsable.

Arquitectura de un Sistema de Surveillance AI

Un pipeline completo de surveillance intelligence incluye múltiples componentes:


from dataclasses import dataclass
from typing import List, Dict, Optional, Tuple
from enum import Enum
import numpy as np
import cv2
from datetime import datetime

class EventType(Enum):
    MOTION_DETECTED = "motion"
    INTRUSION = "intrusion"
    ABANDONED_OBJECT = "abandoned_object"
    CROWD_GATHERING = "crowd_gathering"
    FALL_DETECTION = "fall"
    FACIAL_MATCH = "facial_match"
    ANOMALY = "anomaly"

@dataclass
class BoundingBox:
    x: int
    y: int
    width: int
    height: int
    
    @property
    def area(self) -> int:
        return self.width * self.height
    
    def iou(self, other: 'BoundingBox') -> float:
        """Calcula Intersection over Union con otra caja."""
        x1 = max(self.x, other.x)
        y1 = max(self.y, other.y)
        x2 = min(self.x + self.width, other.x + other.width)
        y2 = min(self.y + self.height, other.y + other.height)
        
        intersection = max(0, x2 - x1) * max(0, y2 - y1)
        union = self.area + other.area - intersection
        
        return intersection / union if union > 0 else 0

@dataclass
class Detection:
    event_type: EventType
    confidence: float
    bbox: BoundingBox
    timestamp: datetime
    camera_id: str
    metadata: Dict = None

@dataclass
class Alert:
    alert_id: str
    detection: Detection
    priority: str  # low, medium, high, critical
    status: str  # new, acknowledged, resolved, false_positive
    assigned_to: Optional[str] = None

class SurveillancePipeline:
    """
    Pipeline completo de surveillance AI.
    
    Flujo: Video → Detection → Tracking → Analysis → Alert
    """
    
    def __init__(self, config: Dict):
        self.camera_ids = config["camera_ids"]
        
        # Modelos de detección
        self.object_detector = YOLOv8Detector(
            model_path=config["yolo_model"],
            conf_thresh=0.5
        )
        self.person_tracker = DeepSORTTracker()
        self.anomaly_detector = AnomalyDetectionModel()
        
        # Detección de rostros (para blacklist/whitelist)
        self.face_detector = FaceRecognitionSystem(
            model=config.get("face_model", "retinaface")
        )
        
        # Movimiento y flow analysis
        self.motion_detector = MOG2MotionDetector()
        self.flow_analyzer = OpticalFlowAnalyzer()
        
        # Gestión de alertas
        self.alert_manager = AlertManager(
            max_alerts_per_hour=config.get("max_alerts", 100)
        )
        
        # Privacy filters
        self.privacy_masker = PrivacyMasking(
            blur_faces=config.get("blur_faces", True),
            anonymize_metadata=config.get("anonymize", True)
        )
    
    def process_frame(self, camera_id: str, frame: np.ndarray, timestamp: datetime) -> List[Alert]:
        """
        Procesa un frame de video y genera alertas.
        """
        alerts = []
        
        # 1. Detección de objetos (personas, vehículos, objetos)
        detections = self.object_detector.detect(frame)
        people_detections = [d for d in detections if d.class_id == 0]  # Persona = clase 0 en COCO
        
        # 2. Tracking de personas
        if people_detections:
            tracks = self.person_tracker.update(people_detections, frame)
        else:
            tracks = []
        
        # 3. Análisis de anomalías en movimiento
        flow_features = self.flow_analyzer.extract_features(frame)
        anomaly_score = self.anomaly_detector.predict(flow_features)
        
        if anomaly_score > config["anomaly_threshold"]:
            alerts.append(self._create_alert(
                camera_id, EventType.ANOMALY, anomaly_score,
                self._get_frame_bbox(frame), timestamp
            ))
        
        # 4. Detección de eventos específicos
        for track in tracks:
            # Detectar intrusiones (persona en zona prohibida)
            if self._is_in_restricted_zone(track):
                alerts.append(self._create_alert(
                    camera_id, EventType.INTRUSION, 0.95,
                    track.bbox, timestamp
                ))
            
            # Detectar caídas
            if self._detect_fall(track):
                alerts.append(self._create_alert(
                    camera_id, EventType.FALL_DETECTION, 0.85,
                    track.bbox, timestamp
                ))
        
        # 5. Detección de rostros (solo si hay whitelist/blacklist activa)
        if self.face_detector.has_reference_faces():
            faces = self.face_detector.detect_faces(frame)
            for face in faces:
                match_result = self.face_detector.match(face)
                if match_result["match_type"] == "blacklist":
                    alerts.append(self._create_alert(
                        camera_id, EventType.FACIAL_MATCH,
                        match_result["confidence"],
                        BoundingBox(*face["bbox"]),
                        timestamp,
                        metadata={"match_type": "blacklist", "person_id": match_result["id"]}
                    ))
        
        # 6. Aplicar privacy masking para logging
        if self.privacy_masker.enabled:
            frame = self.privacy_masker.apply(frame, detections)
        
        return alerts
    
    def _create_alert(self, camera_id: str, event_type: EventType, 
                      confidence: float, bbox: BoundingBox, 
                      timestamp: datetime, metadata: Dict = None) -> Alert:
        """Crea y registra una alerta."""
        detection = Detection(
            event_type=event_type,
            confidence=confidence,
            bbox=bbox,
            timestamp=timestamp,
            camera_id=camera_id,
            metadata=metadata or {}
        )
        
        priority = self._calculate_priority(event_type, confidence)
        
        alert = self.alert_manager.create_alert(detection, priority)
        return alert
    
    def _calculate_priority(self, event_type: EventType, confidence: float) -> str:
        """Calcula prioridad de alerta basada en tipo de evento y confianza."""
        base_priority = {
            EventType.INTRUSION: "high",
            EventType.ABANDONED_OBJECT: "medium",
            EventType.CROWD_GATHERING: "medium",
            EventType.FALL_DETECTION: "critical",
            EventType.FACIAL_MATCH: "critical",
            EventType.ANOMALY: "medium",
        }
        
        priority = base_priority.get(event_type, "low")
        
        # Bajar prioridad si confianza es baja
        if confidence < 0.7:
            priority = "low"
        elif confidence < 0.85 and priority == "critical":
            priority = "high"
        
        return priority

Detección de Objetos con YOLOv8

YOLOv8 es el estándar actual para detección de objetos en tiempo real. Para surveillance, FPS y precisión son críticos:


# Detector YOLOv8 optimizado para surveillance
from ultralytics import YOLO
import torch
import numpy as np
from typing import List, Tuple

class YOLOv8Detector:
    """
    Detector de objetos usando YOLOv8 optimizado para inferencia en tiempo real.
    """
    
    def __init__(self, model_path: str = "yolov8m.pt", conf_thresh: float = 0.5):
        # Cargar modelo
        self.model = YOLO(model_path)
        
        # Optimizaciones
        if torch.cuda.is_available():
            self.model.to('cuda')
            # Half precision para GPUs NVIDIA
            self.model.model.half()
        
        self.conf_thresh = conf_thresh
        
        # Clases relevantes para surveillance (COCO)
        self.person_class = 0
        self.vehicle_classes = [2, 3, 5, 7]  # car, motorcycle, bus, truck
        self.baggage_class = 24  # suitcase
        
        # NMS threshold
        self.iou_thresh = 0.45
    
    def detect(self, frame: np.ndarray) -> List[Detection]:
        """
        Detecta objetos en un frame.
        
        Returns:
            Lista de Detection objects
        """
        # Inferencia
        results = self.model(
            frame,
            conf=self.conf_thresh,
            iou=self.iou_thresh,
            verbose=False,
            half=torch.cuda.is_available()
        )[0]
        
        detections = []
        boxes = results.boxes
        
        for i in range(len(boxes)):
            box = boxes[i]
            x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
            confidence = float(box.conf[0])
            class_id = int(box.cls[0])
            
            detection = Detection(
                bbox=BoundingBox(
                    x=int(x1), y=int(y1),
                    width=int(x2 - x1),
                    height=int(y2 - y1)
                ),
                confidence=confidence,
                class_id=class_id,
                class_name=results.names[class_id]
            )
            detections.append(detection)
        
        return detections
    
    def detect_people(self, frame: np.ndarray) -> List[Detection]:
        """Detecta solo personas."""
        all_detections = self.detect(frame)
        return [d for d in all_detections if d.class_id == self.person_class]
    
    def detect_vehicles(self, frame: np.ndarray) -> List[Detection]:
        """Detecta solo vehículos."""
        all_detections = self.detect(frame)
        return [d for d in all_detections if d.class_id in self.vehicle_classes]
    
    def detect_in_roi(self, frame: np.ndarray, roi_mask: np.ndarray) -> List[Detection]:
        """
        Detecta objetos solo dentro de una Region of Interest (ROI).
        Útil para filtrar detecciones en zonas de paso.
        """
        all_detections = self.detect(frame)
        
        filtered = []
        for det in all_detections:
            # Obtener centro del bounding box
            center_x = det.bbox.x + det.bbox.width // 2
            center_y = det.bbox.y + det.bbox.height // 2
            
            # Verificar si está dentro del ROI
            if roi_mask[center_y, center_x] > 0:
                filtered.append(det)
        
        return filtered
    
    def process_stream(self, video_path: str, callback=None, skip_frames: int = 0):
        """
        Procesa un video completo con detección.
        
        Args:
            video_path: ruta al video
            callback: función a llamar por cada frame detectado
            skip_frames: procesar cada N frames (0 = todos)
        """
        cap = cv2.VideoCapture(video_path)
        frame_count = 0
        
        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break
            
            frame_count += 1
            
            if skip_frames > 0 and frame_count % skip_frames != 0:
                continue
            
            # Detectar
            detections = self.detect(frame)
            
            # Callback
            if callback:
                callback(frame_count, frame, detections)
        
        cap.release()

Optical Flow para Análisis de Movimiento

El optical flow permite detectar movimiento sin depender de detección de objetos. Es útil para detectar anomalías comportamentales:


import cv2
import numpy as np
from typing import Tuple, List

class OpticalFlowAnalyzer:
    """
    Analiza flujo óptico para detectar anomalías de movimiento.
    """
    
    def __init__(self, roi_points: List[Tuple[int, int]] = None):
        # params para Lucas-Kanade optical flow
        self.lk_params = dict(
            winSize=(31, 31),
            maxLevel=3,
            criteria=(cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 30, 0.01)
        )
        
        # ROI para filtrar área de análisis
        self.roi_points = roi_points
        self.roi_mask = None
        if roi_points:
            self.roi_mask = self._create_roi_mask(roi_points)
        
        # Frame anterior para comparación
        self.prev_gray = None
    
    def extract_features(self, frame: np.ndarray) -> Dict:
        """
        Extrae features de flujo óptico del frame.
        
        Returns:
            Diccionario con magnitudes, ángulos, y estadísticas
        """
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        
        if self.prev_gray is None:
            self.prev_gray = gray
            return self._zero_features()
        
        # Calcular optical flow
        flow = cv2.calcOpticalFlowFarneback(
            self.prev_gray, gray,
            None,
            pyr_scale=0.5,
            levels=3,
            winsize=15,
            iterations=3,
            poly_n=5,
            poly_sigma=1.2,
            flags=0
        )
        
        # Separar componentes
        flow_x, flow_y = flow[..., 0], flow[..., 1]
        
        # Magnitud y ángulo
        magnitude, angle = cv2.cartToPolar(flow_x, flow_y)
        
        # Aplicar ROI mask si existe
        if self.roi_mask is not None:
            magnitude = magnitude * self.roi_mask
            flow_x = flow_x * self.roi_mask
            flow_y = flow_y * self.roi_mask
        
        # Features estadísticas
        features = {
            "mean_magnitude": float(np.mean(magnitude)),
            "max_magnitude": float(np.max(magnitude)),
            "std_magnitude": float(np.std(magnitude)),
            
            "mean_flow_x": float(np.mean(flow_x)),
            "mean_flow_y": float(np.mean(flow_y)),
            
            "dominant_angle": float(self._dominant_angle(angle)),
            "angle_variance": float(np.var(angle)),
            
            "flow_entropy": float(self._calculate_entropy(magnitude)),
            
            "motion_pixels": int(np.sum(magnitude > 2.0)),
            "motion_ratio": float(np.sum(magnitude > 2.0) / magnitude.size)
        }
        
        self.prev_gray = gray
        return features
    
    def detect_anomaly(self, current_features: Dict, baseline_features: Dict, threshold: float = 2.0) -> Tuple[bool, float]:
        """
        Detecta si el frame actual es una anomalía comparando con baseline.
        
        Returns:
            (is_anomaly, anomaly_score)
        """
        # Calcular distancia Mahalanobis simplificada
        score = 0.0
        
        # Comparar magnitudes
        mag_diff = abs(current_features["mean_magnitude"] - baseline_features["mean_magnitude"])
        mag_std = max(baseline_features["std_magnitude"], 0.1)
        score += (mag_diff / mag_std) ** 2
        
        # Comparar dirección de flujo
        angle_diff = abs(current_features["dominant_angle"] - baseline_features["dominant_angle"])
        angle_diff = min(angle_diff, 360 - angle_diff)  # Handle wrap-around
        score += (angle_diff / 45) ** 2  # 45 grados como referencia
        
        # Raíz del score
        anomaly_score = np.sqrt(score)
        
        return anomaly_score > threshold, anomaly_score
    
    def create_motion_heatmap(self, frame: np.ndarray) -> np.ndarray:
        """Crea un heatmap de movimiento para visualización."""
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        
        if self.prev_gray is None:
            self.prev_gray = gray
            return np.zeros_like(frame)
        
        flow = cv2.calcOpticalFlowFarneback(
            self.prev_gray, gray, None,
            pyr_scale=0.5, levels=3, winsize=15,
            iterations=3, poly_n=5, poly_sigma=1.2, flags=0
        )
        
        magnitude, _ = cv2.cartToPolar(flow[..., 0], flow[..., 1])
        
        # Normalizar
        magnitude_norm = cv2.normalize(magnitude, None, 0, 255, cv2.NORM_MINMAX)
        magnitude_uint8 = magnitude_norm.astype(np.uint8)
        
        # Aplicar colormap
        heatmap = cv2.applyColorMap(magnitude_uint8, cv2.COLORMAP_JET)
        
        self.prev_gray = gray
        return heatmap
    
    def _dominant_angle(self, angles: np.ndarray, mask: np.ndarray = None) -> float:
        """Calcula el ángulo dominante del flujo."""
        if mask is not None:
            angles = angles[mask > 0]
        
        if angles.size == 0:
            return 0.0
        
        # Convertir a vector promedio
        sin_sum = np.sum(np.sin(np.radians(angles)))
        cos_sum = np.sum(np.cos(np.radians(angles)))
        
        return float(np.degrees(np.arctan2(sin_sum, cos_sum)) % 360)
    
    def _calculate_entropy(self, magnitude: np.ndarray) -> float:
        """Calcula entropía de la distribución de magnitud."""
        hist, _ = np.histogram(magnitude.flatten(), bins=50, range=(0, 20))
        hist = hist / hist.sum()  # Normalizar
        hist = hist[hist > 0]  # Filtrar ceros
        return float(-np.sum(hist * np.log2(hist)))
    
    def _create_roi_mask(self, points: List[Tuple[int, int]]) -> np.ndarray:
        """Crea máscara binaria para ROI."""
        mask = np.zeros((480, 640), dtype=np.uint8)  # Default size
        pts = np.array(points, dtype=np.int32)
        cv2.fillPoly(mask, [pts], 255)
        return mask / 255.0
    
    def _zero_features(self) -> Dict:
        """Feature vector para frames sin movimiento previo."""
        return {
            "mean_magnitude": 0.0,
            "max_magnitude": 0.0,
            "std_magnitude": 0.0,
            "mean_flow_x": 0.0,
            "mean_flow_y": 0.0,
            "dominant_angle": 0.0,
            "angle_variance": 0.0,
            "flow_entropy": 0.0,
            "motion_pixels": 0,
            "motion_ratio": 0.0
        }

Reconocimiento Facial para Blacklist/Whitelist

El reconocimiento facial en surveillance debe usarse con extrema responsabilidad. Solo para casos específicos como blacklist de personas no autorizadas:


import face_recognition
import numpy as np
from typing import List, Dict, Optional
from dataclasses import dataclass
import pickle
import os

@dataclass
class FaceRecord:
    person_id: str
    name: str
    encoding: np.ndarray
    encoding_date: str
    tags: List[str]  # e.g., ["employee", "contractor", "blacklist"]

class FaceRecognitionSystem:
    """
    Sistema de reconocimiento facial para surveillance.
    Implementa blacklist/whitelist para alertas.
    """
    
    def __init__(self, encoding_model: str = "cnn", tolerance: float = 0.45):
        """
        Args:
            encoding_model: 'cnn' (más preciso) o 'hog' (más rápido)
            tolerance: threshold de similitud (menor = más estricto)
        """
        self.encoding_model = encoding_model
        self.tolerance = tolerance
        
        # Base de datos de rostros
        self.face_database: Dict[str, FaceRecord] = {}
        self.blacklist_ids: set = set()
        self.whitelist_ids: set = set()
    
    def load_database(self, db_path: str):
        """Carga base de datos de rostros desde disco."""
        if os.path.exists(db_path):
            with open(db_path, 'rb') as f:
                data = pickle.load(f)
                self.face_database = data.get("faces", {})
                self._rebuild_indices()
    
    def save_database(self, db_path: str):
        """Guarda base de datos a disco."""
        with open(db_path, 'wb') as f:
            pickle.dump({
                "faces": self.face_database
            }, f)
    
    def add_face(self, person_id: str, name: str, image_path: str, 
                 tags: List[str] = None) -> bool:
        """
        Añade un rostro a la base de datos.
        
        Returns:
            True si exitoso, False si no se detectó rostro
        """
        # Cargar y codificar imagen
        image = face_recognition.load_image_file(image_path)
        encodings = face_recognition.face_encodings(image, model=self.encoding_model)
        
        if len(encodings) == 0:
            return False  # No se detectó rostro
        
        # Usar la encoding más grande (más definido)
        encoding = max(encodings, key=lambda e: np.linalg.norm(e))
        
        # Guardar registro
        from datetime import datetime
        self.face_database[person_id] = FaceRecord(
            person_id=person_id,
            name=name,
            encoding=encoding,
            encoding_date=datetime.now().isoformat(),
            tags=tags or []
        )
        
        # Actualizar índices
        self._rebuild_indices()
        
        return True
    
    def match(self, face_encoding: np.ndarray) -> Dict:
        """
        Busca coincidencia de un rostro en la base de datos.
        
        Returns:
            Dict con match_type ('blacklist', 'whitelist', 'unknown'),
            confidence, y person_id si hay match
        """
        if not self.face_database:
            return {"match_type": "unknown", "confidence": 0.0, "person_id": None}
        
        # Calcular distancias con todos los rostros
        known_ids = list(self.face_database.keys())
        known_encodings = [self.face_database[pid].encoding for pid in known_ids]
        
        distances = face_recognition.face_distance(known_encodings, face_encoding)
        
        # Mejor coincidencia
        best_idx = np.argmin(distances)
        best_distance = distances[best_idx]
        best_id = known_ids[best_idx]
        
        # Convertir distancia a confianza (inversamente proporcional)
        # distancia 0 = confianza 100%, distancia 1 = confianza 0%
        confidence = max(0, 1.0 - (best_distance / self.tolerance))
        
        if best_distance > self.tolerance:
            return {"match_type": "unknown", "confidence": float(confidence), "person_id": None}
        
        record = self.face_database[best_id]
        
        # Determinar tipo de match
        if best_id in self.blacklist_ids:
            match_type = "blacklist"
        elif best_id in self.whitelist_ids:
            match_type = "whitelist"
        else:
            match_type = "registered"
        
        return {
            "match_type": match_type,
            "confidence": float(confidence),
            "person_id": best_id,
            "person_name": record.name
        }
    
    def detect_and_match(self, frame) -> List[Dict]:
        """
        Detecta rostros en un frame y busca coincidencias.
        
        Returns:
            Lista de resultados de match para cada rostro detectado
        """
        # Detectar ubicaciones de rostros
        face_locations = face_recognition.face_locations(frame, model=self.encoding_model)
        
        if not face_locations:
            return []
        
        # Codificar rostros detectados
        encodings = face_recognition.face_encodings(frame, face_locations, model=self.encoding_model)
        
        results = []
        for encoding, location in zip(encodings, face_locations):
            match_result = self.match(encoding)
            match_result["location"] = location  # (top, right, bottom, left)
            results.append(match_result)
        
        return results
    
    def add_to_blacklist(self, person_id: str):
        """Añade persona a blacklist."""
        self.blacklist_ids.add(person_id)
    
    def remove_from_blacklist(self, person_id: str):
        """Remueve persona de blacklist."""
        self.blacklist_ids.discard(person_id)
    
    def _rebuild_indices(self):
        """Reconstruye índices de blacklist/whitelist desde tags."""
        self.blacklist_ids = set()
        self.whitelist_ids = set()
        
        for pid, record in self.face_database.items():
            if "blacklist" in record.tags:
                self.blacklist_ids.add(pid)
            if "whitelist" in record.tags:
                self.whitelist_ids.add(pid)

Privacy y Compliance en Surveillance AI

El uso de surveillance AI sin consideraciones de privacidad viola regulaciones como GDPR y genera riesgos legales y éticos. La Privacy by Design no es opcional — es requisito:

Principios de Privacy by Design

  • Minimización de datos: solo recolectar lo necesario para el objetivo específico
  • Purpose limitation: los datos de surveillance solo para security, nunca para otros propósitos
  • Data anonymization: rostros yplate numbers deben ser anonimizados por defecto
  • Retention limits: definir tiempos máximos de almacenamiento
  • Access controls: solo personal autorizado accede a footage sin anonimizar

class PrivacyMasking:
    """
    Aplica técnicas de privacy masking sobre frames de video.
    """
    
    def __init__(self, blur_faces: bool = True, 
                 blur_license_plates: bool = True,
                 anonymize_timestamps: bool = True):
        self.blur_faces = blur_faces
        self.blur_license_plates = blur_plates
        self.anonymize_timestamps = anonymize_timestamps
        
        # Detector de rostros (lightweight para speed)
        self.face_cascade = cv2.CascadeClassifier(
            cv2.data.haarcascades + 'haarcascade_frontalface_default.xml'
        )
    
    def apply(self, frame: np.ndarray, detections: List[Detection]) -> np.ndarray:
        """
        Aplica masking de privacidad sobre un frame.
        
        Args:
            frame: frame original
            detections: detecciones del modelo (para saber dónde blur)
            
        Returns:
            Frame con privacy masking aplicado
        """
        result = frame.copy()
        
        # Blur rostros si está habilitado
        if self.blur_faces:
            result = self._blur_faces_detected(result, detections)
        
        # Blur license plates si está habilitado
        if self.blur_license_plates:
            result = self._blur_license_plates(result, detections)
        
        # Anonymize timestamps si está habilitado
        if self.anonymize_timestamps:
            result = self._remove_metadata(result)
        
        return result
    
    def _blur_faces_detected(self, frame: np.ndarray, detections: List[Detection]) -> np.ndarray:
        """Aplica blur a rostros detectados."""
        result = frame.copy()
        
        # Usar bounding boxes de detecciones de personas
        for det in detections:
            if det.class_name == "person":
                # Extraer región superior de la caja (donde estaría el rostro)
                x = det.bbox.x
                y = det.bbox.y
                w = det.bbox.width
                h = det.bbox.height
                
                # Rostro está en el 30% superior de la caja de persona
                face_y = y
                face_h = h // 3
                
                if face_h > 20:  # Mínimo tamaño para procesar
                    face_roi = result[face_y:face_y+face_h, x:x+w]
                    if face_roi.size > 0:
                        blurred_face = cv2.GaussianBlur(face_roi, (51, 51), 30)
                        result[face_y:face_y+face_h, x:x+w] = blurred_face
        
        return result
    
    def _blur_license_plates(self, frame: np.ndarray, detections: List[Detection]) -> np.ndarray:
        """Aplica blur a patentes de vehículos."""
        result = frame.copy()
        
        for det in detections:
            if det.class_name in ["car", "truck", "bus", "motorcycle"]:
                # Patentes están en la parte inferior del vehículo
                x = det.bbox.x
                y = det.bbox.y + int(det.bbox.height * 0.7)
                w = det.bbox.width
                h = det.bbox.height // 4
                
                if w > 40 and h > 10:
                    plate_roi = result[y:y+h, x:x+w]
                    if plate_roi.size > 0:
                        blurred_plate = cv2.GaussianBlur(plate_roi, (21, 21), 15)
                        result[y:y+h, x:x+w] = blurred_plate
        
        return result
    
    def _remove_metadata(self, frame: np.ndarray) -> np.ndarray:
        """
        Elimina metadata sensible del frame.
        En producción, también limpiar EXIF y metadatos del video.
        """
        # Para frames individuales, no hay timestamp visible
        # Esta función es más relevante para el contenedor de video
        return frame

            "camera_id": camera_id,
            "access_type": access_type,

        }
        
        self.access_log.append(entry)
        self._flush_to_disk()
    
    def generate_dsar_report(self, data_subject_id: str) -> Dict:

            log for log in self.access_log
            if log.get("user_id") == data_subject_id
        ]
        
        return {
            "subject_id": data_subject_id,
            "total_access_events": len(subject_accesses),
            "access_history": subject_accesses,
            "data_categories": ["access_logs"],
            "purpose": "security_operations",
            "retention_period_days": 90
        }

Error 2: No considerar sesgos en detección

Síntoma: El modelo detecta "anomalías" más frecuentemente en ciertas zonas donde hay más personas de ciertos grupos demográficos. Bias algorítmico.

Fix: Auditar regularly por sesgos y usar fairness metrics:


def audit_bias(model, test_dataset, demographic_groups: Dict) -> Dict:
    """
    Audita bias en modelo de detección.
    
    Returns:
        Reporte de fairness por grupo demográfico
    """
    results = {}
    
    for group_name, group_data in demographic_groups.items():
        # Calcular true/false positive rates para cada grupo
        predictions = model.predict(group_data["features"])
        
        results[group_name] = {
            "sample_size": len(group_data["labels"]),
            "true_positive_rate": np.mean(predictions == group_data["labels"]),
            "false_positive_rate": np.mean((predictions == 1) & (group_data["labels"] == 0)),
            "disparate_impact": calculate_disparate_impact(
                predictions, group_data["labels"]
            )
        }
    
    return results

def calculate_disparate_impact(predictions, labels) -> float:
    """
    Calcula disparate impact ratio.
    < 0.8 indica impacto dispar potencialmente problemático.
    """
    positive_rate_group = np.mean(predictions)
    positive_rate_baseline = np.mean(labels)
    
    if positive_rate_baseline == 0:
        return 1.0
    
    return positive_rate_group / positive_rate_baseline

Error 3: Ignorar retención y eliminación de datos

Síntoma: Video se almacena indefinidamente. Cuando llega una auditoría o request de un ciudadano, no hay forma de demostrar compliance. Riesgo legal enorme.

Fix: Implementar data lifecycle management automático:

Resumen

Surveillance AI es poderosa pero requiere implementación responsable:

  • Pipeline completo: detección + tracking + análisis + alertas
  • YOLOv8 + Optical Flow: combinación poderosa para detección en tiempo real
  • Reconocimiento facial: solo para blacklists/whitelists con governance claro
  • Privacy by Design: no es opcional, es requisito legal y ético
  • Compliance logging: auditorías, DSAR requests, data lifecycle
  • Bias auditing: verificar que el sistema no discrimina

El 80% de implementadores que ignora privacidad está creando problemas legales y éticos que eventualmente explotarán. El 20% que implementa privacy-first está constru-yendo sistemas sostenibles que protegen tanto la seguridad como los derechos fundamentales.
