🔬 Por Qué AI Governance Importa Ahora

En 2024, el EU AI Act entró en plena aplicación. En USA, múltiples estados tienen sus propias leyes. En China, las regulaciones de algoritmos llevan años activas. Si estás construyendo productos con IA y no conoces las regulaciones, estás jugando ruleta rusa con tu empresa.

El Panorama Global

  • Unión Europea: EU AI Act — la regulación más comprehensiva del mundo
  • Estados Unidos: Executive Order on AI + leyes estatales (California, Texas, etc.)
  • China: Algorithmic Recommendation Regulations, Generative AI Regulations
  • Latinoamérica: Brasil (PL 2338/2023), Colombia (proyectos de ley en discusión)
  • Internacional: UNESCO AI Ethics Recommendation, ISO/IEC standards

La Math de Risk Classification

El EU AI Act clasifica sistemas por nivel de riesgo:

$$R_{sistema} = \begin{cases} \text{Inaceptable} & \rightarrow \text{Bloqueado} \\ \text{Alto} & \rightarrow \text{Certification requerida} \\ \text{Limitado} & \rightarrow \text{Transparency requerida} \\ \text{Mínimo} & \rightarrow \text{Sin restricciones} \end{cases}$$

Fix — Compliance by Design:

# ✅ BIEN: Governance desde el día 1
from enum import Enum
from typing import Optional

class RiskLevel(Enum):
    MINIMAL = "minimal"
    LIMITED = "limited"
    HIGH = "high"
    UNACCEPTABLE = "unacceptable"

class AIGovernanceChecklist:
    def __init__(self):
        self.risk_level: Optional[RiskLevel] = None
        self.data_usage: list = []
        self.transparency_required = False
        self.certification_required = False
    
    def assess_risk(self, system_purpose: str, autonomy_level: str, 
                   uses_personal_data: bool) -> RiskLevel:
        """Evalúa el nivel de riesgo del sistema según EU AI Act"""
        
        # Unacceptable risk - automatically blocked
        if "social scoring" in system_purpose.lower():
            return RiskLevel.UNACCEPTABLE
        if "biometric_categorization" in system_purpose.lower() and \
           autonomy_level == "real_time":
            return RiskLevel.UNACCEPTABLE
        
        # High risk - requires certification
        high_risk_purposes = [
            "critical_infrastructure", "education", "employment",
            "essential_services", "law_enforcement", "democracy",
            "healthcare", "financial_services"
        ]
        if any(purpose in system_purpose.lower() for purpose in high_risk_purposes):
            self.certification_required = True
            return RiskLevel.HIGH
        
        # Limited risk - transparency required
        limited_risk_purposes = [
            "chatbot", "deepfake", "emotional_recognition"
        ]
        if any(purpose in system_purpose.lower() for purpose in limited_risk_purposes):
            self.transparency_required = True
            return RiskLevel.LIMITED
        
        return RiskLevel.MINIMAL
    
    def generate_documentation(self) -> dict:
        """Genera documentación de compliance"""
        return {
            "risk_assessment": self.risk_level.value if self.risk_level else "not_assessed",
            "certification_required": self.certification_required,
            "transparency_required": self.transparency_required,
            "data_usage": self.data_usage,
            "next_steps": self._get_next_steps()
        }
    
    def _get_next_steps(self) -> list:
        if self.risk_level == RiskLevel.HIGH:
            return [
                "Conduct conformity assessment",
                "Implement quality management system",
                "Register in EU database",
                "Apply CE marking",
            ]
        elif self.risk_level == RiskLevel.LIMITED:
            return [
                "Implement transparency measures",
                "Inform users about AI interaction",
                "Maintain technical documentation",
            ]
        return ["No specific requirements"]

Fix — AI Incident Response Plan:

# ✅ BIEN: Incident response para AI systems
from enum import Enum
from datetime import datetime, timedelta
from typing import Optional

class IncidentSeverity(Enum):
    MINOR = "minor"           # Sin impacto real, debug interno
    MODERATE = "moderate"     # Impacto limitado, remediar en 7 días
    SERIOUS = "serious"       # Impacto significativo, reportar en 72 horas
    CRITICAL = "critical"     # Daño a personas, reportar inmediatamente

class AIIncidentReport:
    def __init__(self, system_id: str, description: str, severity: IncidentSeverity):
        self.system_id = system_id
        self.description = description
        self.severity = severity
        self.timestamp = datetime.now()
        self.reported_to_authorities = False
    
    def should_report_to_authority(self) -> bool:
        """Determina si debe reportarse según EU AI Act Art 62"""
        # Criteria para "serious incident":
        # - Death or damage to health
        # - Serious harm to property
        # - Serious violation of fundamental rights
        serious_conditions = [
            "death", "health", "fundamental rights violation",
            "serious harm", "financial damage > threshold"
        ]
        return self.severity in [IncidentSeverity.SERIOUS, IncidentSeverity.CRITICAL] \
               or any(c in self.description.lower() for c in serious_conditions)
    
    def get_reporting_deadline(self) -> Optional[datetime]:
        """EU AI Act Art 62: 72 horas para incidents graves"""
        if not self.should_report_to_authority():
            return None
        return self.timestamp + timedelta(hours=72)

class AIIncidentResponse:
    def __init__(self):
        self.incidents: list[AIIncidentReport] = []
    
    def log_incident(self, system_id: str, description: str, 
                    severity: IncidentSeverity):
        incident = AIIncidentReport(system_id, description, severity)
        self.incidents.append(incident)
        
        # Auto-reporte si es grave
        if incident.should_report_to_authority():
            self._report_to_authorities(incident)
    
    def _report_to_authorities(self, incident: AIIncidentReport):
        # En producción, esto enviaría a la autoridad competente
        # en el EU sería: national competent authority o EU AI Office
        print(f"REPORTING INCIDENT: {incident.description}")
        print(f"Deadline: {incident.get_reporting_deadline()}")
        incident.reported_to_authorities = True

📜 El Marco Regulatorio Global

EU AI Act — Detalle del Sistema de Clasificación

La Unión Europea tiene el framework más comprehensivo:

  • Prohibited AI (Art 5): Social scoring por gobiernos, vigilancia masiva en espacios públicos, manipulación subliminal
  • High-Risk AI (Art 6-51): Requisitos estrictos de certificación, documentación, testing continuo
  • Limited Risk: Obligaciones de transparencia (chatbots deben identificarse como AI)
  • Minimal Risk: Sin obligaciones específicas

US AI Regulation — Sectorial y Fragmentada

Estados Unidos toma un approach diferente — sectorial:

  • Financial Services: CFPB, FTC regulan uso de AI en lending, credit
  • Healthcare: FDA regula AI/ML como medical devices
  • Employment: EEOC vigila sesgo algorítmico en hiring
  • State Laws: California CPRA, Texas AI Act, Illinois AI Video Interview Act

China AI Regulations

  • Generative AI Regulations (2023): Requisitos de copyright, etiquetado de synthetic content
  • Algorithmic Recommendation Rules: Transparency en recomendación de contenido
  • Deep Synthesis Rules: Regula deepfakes y contenido sintético

Step 1: Audit Técnico

def technical_audit() -> dict:
    """Realiza un audit técnico de tu sistema AI"""
    return {
        "system_purpose": input("¿Cuál es el propósito del sistema?"),
        "autonomy_level": input("¿Qué tan autónomo es? (low/medium/high)"),
        "personal_data_usage": input("¿Usa datos personales? (yes/no)"),
        "decision_impact": input("¿Impacta decisiones críticas? (yes/no)"),
        "sectors": input("¿En qué sectores opera? (healthcare/finance/etc)"),
    }

Step 2: Risk Classification

def classify_risk(audit: dict) -> str:
    """Clasifica el sistema según EU AI Act"""
    if audit["decision_impact"] == "yes" and audit["sectors"] in ["healthcare", "finance", "employment"]:
        return "HIGH_RISK"
    if audit["autonomy_level"] == "high":
        return "HIGH_RISK"
    if audit["personal_data_usage"] == "yes":
        return "LIMITED_RISK"
    return "MINIMAL_RISK"

Step 3: Documentar y Monitorear

  • Technical Documentation: Descripción del sistema, arquitectura, training data, performance metrics
  • Performance Monitoring: Métricas continuas de accuracy, fairness, safety
  • Incident Logging: Registro de todos los incidents y cómo se resolvieron
  • Human Oversight: Mechanisms para intervención humana cuando sea necesario

📊 Comparativa de Regulations

  • EU AI Act: Basado en risk tiers, certification required for high-risk, extraterritorial
  • US Approach: Sectorial, self-regulation encouraged, agency-specific rules
  • China: Content-focused, registration requirements, strict on synthetic media
  • ISO/IEC 42001: Certificación voluntaria de management systems para AI
  • NIST AI RMF: Voluntary framework, risk-based approach, widely adopted in US
