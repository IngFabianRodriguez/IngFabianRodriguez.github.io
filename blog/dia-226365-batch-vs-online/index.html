Zero-Shot Learning - Modelos Que Generalizan Sin Entrenamiento

Hagale pues, parcero. Hoy es el Dia 226 y hablamos de zero-shot learning, cuando los modelos generalizan sin ver ejemplos. Dejala el cafe.

🎯 Que Es Zero-Shot Learning?

Zero-shot learning es la capacidad de un modelo para clasificar o generar sobre categorias que nunca ha visto durante el entrenamiento. El modelo usa conocimiento previo para generalizar.

Como funciona:

  • Description-based: Usa descripciones semanticas de las clases
  • Attribute-based: Aprende atributos comunes primero
  • Embedding-based: Compara embeddings de clases conocidas vs desconocidas

📐 Zero-Shot Classification

from transformers import pipeline

# Zero-shot classifier
classifier = pipeline("zero-shot-classification")

result = classifier(
    "El nuevo telefono tiene una camara increible",
    candidate_labels=["tecnologia", "deportes", "politica", "entretenimiento"],
    hypothesis_template="Este texto es sobre {}."
)

print(result['labels'][0], result['scores'][0])

🚀 Zero-Shot En Vision

from transformers import CLIPProcessor, CLIPModel

model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

# Zero-shot image classification
image = Image.open("dog.jpg")
text = ["a photo of a dog", "a photo of a cat", "a landscape"]

inputs = processor(text=text, images=image, return_tensors="pt", padding=True)
outputs = model(**inputs)

# Clasificar
logits_per_image = outputs.logits_per_image
probs = logits_per_image.softmax(dim=1)
print(f"Predicted: {text[probs.argmax()]}")

⚠️ Errores Comunes

Error 1: Categorias Muy Similares

El problema: "Sofa" vs "sillon" confunde al modelo.

La solucion: Haz las descripciones mas discriminativas.
