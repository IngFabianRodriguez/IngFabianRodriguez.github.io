Gradient Clipping - Estabilizando El Entrenamiento

26 de junio de 2026
gradient-clippingexploding-gradientsrnnlstm

Parcero, día 177 y hoy我们来聊聊 Gradient Clipping — la técnica que evita que tus redes exploten durante el entrenamiento. Si alguna vez has visto loss变成NaN o los pesos crecer desproporcionadamente, esta vaina te va a salvar. De una.

Gradient clipping es simple en concepto: cuando los gradientes se vuelven demasiado grandes, los cortamos a un valor máximo. Esto previene que la red se vuelva inestable, especialmente en RNNs y LSTMs donde los gradientes pueden explotar exponencialmente.

🎯 El Problema: Exploding Gradients

En redes profundas, especialmente las recurrentes, los gradientes pueden crecer exponencialmente durante backpropagation. Esto pasa porque:

  • Multiplicación en cadena: Cada capa multiplica el gradiente por sus pesos. Si los pesos > 1, los gradientes explotan.
  • Secuencias largas: RNNs procesan secuencias paso a paso. El gradiente se multiplica en cada timestep.
  • Vanishing vs Exploding: Gradientes muy pequeños desaparecen (vanishing), muy grandes explotan.

Los síntomas son claros:

  • Loss se vuelve NaN o Infinity
  • Pesos se vuelven números enormes (10^9, 10^15)
  • Training diverge completamente

📐 Cómo Funciona Gradient Clipping

La formula es simple:

$$g_{clipped} = g \cdot \frac{clip\_norm}{||g||} \quad \text{si } ||g|| > clip\_norm$$

O en palabras: si la norma del gradiente excede un threshold, dividimos todos los elementos del gradiente por la norma y multiplicamos por el threshold.

En código:

def clip_gradients_(parameters, max_norm, eps=1e-8):
    """
    Gradient clipping by norm.
    
    Args:
        parameters: Model parameters
        max_norm: Maximum norm value
        eps: Small epsilon to avoid division by zero
        
    Returns:
        Total norm before clipping (for logging)
    """
    parameters = list(parameters)
    total_norm = 0.0
    
    # Calculate total norm across all parameters
    for p in parameters:
        if p.grad is None:
            continue
        param_norm = p.grad.data.norm(2)
        total_norm += param_norm.item() ** 2
    total_norm = total_norm ** 0.5
    
    # Compute clipping factor
    clip_coef = max_norm / (total_norm + eps)
    if clip_coef < 1:
        for p in parameters:
            if p.grad is None:
                continue
            p.grad.data.mul_(clip_coef)
    
    return total_norm

💻 PyTorch Native Gradient Clipping

PyTorch tiene gradient clipping built-in:

import torch.optim as optim
from torch.nn.utils import clip_grad_norm_

# Durante el training loop
for epoch in range(num_epochs):
    for batch in dataloader:
        optimizer.zero_grad()
        
        outputs = model(batch)
        loss = criterion(outputs, targets)
        loss.backward()
        
        # Clip gradientes antes de optimizer.step()
        # clip_grad_norm_(parameters, max_norm)
        total_norm = clip_grad_norm_(model.parameters(), max_norm=1.0)
        
        optimizer.step()
        
        # Log total_norm para monitorear
        writer.add_scalar('grad_norm', total_norm, global_step)

⚠️ Errores Comunes con Gradient Clipping

Error 1: Clippear después de optimizer.step()

El problema: Si clippeas después de actualizar los pesos, no tiene efecto. Los gradientes ya fueron aplicados a los pesos. Es como cerrar la puerta después de que el caballo escapó.

Fix:: SIEMPRE clippear entre loss.backward() y optimizer.step(). El orden correcto es: zero_grad → forward → loss → backward → clip_gradients → step.

Error 2: Max norm muy alto o muy bajo

El problema: Un max_norm de 100.0 para una red pequeña puede ser inútil. Un max_norm de 0.1 para una red profunda puede matar el aprendizaje. El 70% de developers usan valores por defecto sin entenderlos.

Fix:: Empieza con max_norm=1.0 y ajusta basado en la grad_norm que monitoreas. Si grad_norm está siempre cerca del max_norm, auméntalo. Si está muy por debajo, puedes bajar el threshold.

✅ Resumen y Cierre

  • Gradient clipping previene gradientes explosivos que causan divergencia.
  • Usa clip_grad_norm_ de PyTorch — es simple y efectivo.
  • El orden importa: backward() → clip() → step().
  • Monitorea total_norm para ajustar max_norm dinámicamente.
  • No es magia: si tus gradientes explotan, puede haber un problema más profundo (learning rate muy alto, mala inicialización).

Hágale que gradient clipping es una de esas técnicas que parece simple pero salva modelos de la divergencia. En RNNs y LSTMs es esencial. En transformers modernos también ayuda cuando usas learning rates altos. téngalo en su toolkit, parcero.
