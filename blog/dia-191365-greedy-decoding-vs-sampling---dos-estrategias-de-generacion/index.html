La mayoria de engineers ignoran Greedy Decoding vs Sampling hasta que les causa un bug dificil de debuggear en produccion. No seas ese engineer.

La Matematica Detras

La intuicion detras de Greedy Decoding vs Sampling se puede expresar matematicamente asi:

$$P(token_i | contexto) = \frac{e^{logitos_i / T}}{\sum_j e^{logitos_j / T}}$$

donde $T$ es la temperatura y $logitos$ son los valores sin normalizar del modelo. Esta formulacion captura la esencia: estamos balanceando dos objetivos competidores — explotar el token mas probable mientras mantenemos diversidad en la generacion.

La intuicion geometrica: imaginate que los parametros del modelo viven en un landscape de alta dimensionalidad. Greedy Decoding vs Sampling define como navegamos ese landscape — greedy siempre toma el paso mas empinado hacia abajo, mientras sampling toma pasos aleatorios que pueden llevar a optimos globales mejores.

Codigo Production-Grade

"""
Implementacion production-ready de Greedy Decoding vs Sampling.
Incluye: logging, error handling, tipado, tests basicos.
"""
import logging
from dataclasses import dataclass
from typing import Optional, List, Dict, Any, Tuple
from enum import Enum
import numpy as np

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class DecodingStrategy(Enum):
    """Estrategias de decodificacion disponibles."""
    GREEDY = "greedy"
    SAMPLING = "sampling"
    TOP_K = "top_k"
    TOP_P = "top_p"


@dataclass
class DecodingConfig:
    """Configuracion para decodificacion."""
    strategy: DecodingStrategy = DecodingStrategy.GREEDY
    temperature: float = 1.0
    top_k: int = 50
    top_p: float = 0.95
    seed: Optional[int] = None


class TextGenerator:
    """
    Implementacion de generacion de texto con multiples estrategias.
    
    Attributes:
        model: Modelo de lenguaje cargado
        config: Configuracion de decodificacion
    """
    
    def __init__(
        self,
        model: Any = None,
        config: Optional[DecodingConfig] = None,
    ):
        self.model = model
        self.config = config or DecodingConfig()
        self._rng = np.random.RandomState(self.config.seed)
        logger.info(f"TextGenerator inicializado con estrategia: {self.config.strategy}")
    
    def _apply_temperature(self, logits: np.ndarray, temperature: float) -> np.ndarray:
        """Aplica temperatura a los logits."""
        if temperature == 0:
            return logits
        return logits / temperature
    
    def _top_k_filter(self, logits: np.ndarray, k: int) -> np.ndarray:
        """Filtra logits manteniendo solo los top-k."""
        top_k_indices = np.argpartition(logits, -k)[-k:]
        masked_logits = np.full_like(logits, -float('inf'))
        masked_logits[top_k_indices] = logits[top_k_indices]
        return masked_logits
    
    def _top_p_filter(self, logits: np.ndarray, p: float) -> np.ndarray:
        """Filtra logits manteniendo probabilidad acumulada p."""
        sorted_indices = np.argsort(logits)[::-1]
        sorted_logits = logits[sorted_indices]
        probs = np.exp(sorted_logits) / np.sum(np.exp(sorted_logits))
        cumsum = np.cumsum(probs)
        
        cutoff_idx = np.searchsorted(cumsum, p)
        selected_indices = sorted_indices[:cutoff_idx + 1]
        
        masked_logits = np.full_like(logits, -float('inf'))
        masked_logits[selected_indices] = logits[selected_indices]
        return masked_logits
    
    def _sample_token(self, logits: np.ndarray) -> int:
        """Muestrea un token de los logits."""
        probs = np.exp(logits) / np.sum(np.exp(logits))
        return int(self._rng.choice(len(probs), p=probs))
    
    def _greedy_select(self, logits: np.ndarray) -> int:
        """Selecciona el token con mayor probabilidad."""
        return int(np.argmax(logits))
    
    def generate(
        self,
        prompt: str,
        max_tokens: int = 100,
    ) -> str:
        """
        Genera texto a partir de un prompt.
        
        Args:
            prompt: Texto de entrada
            max_tokens: Maximo numero de tokens a generar
            
        Returns:
            Texto generado
        """
        tokens = self._tokenize(prompt)
        
        for _ in range(max_tokens):
            logits = self._get_logits(tokens)
            
            if self.config.strategy == DecodingStrategy.GREEDY:
                next_token = self._greedy_select(logits)
            elif self.config.strategy == DecodingStrategy.SAMPLING:
                logits = self._apply_temperature(logits, self.config.temperature)
                next_token = self._sample_token(logits)
            elif self.config.strategy == DecodingStrategy.TOP_K:
                logits = self._apply_temperature(logits, self.config.temperature)
                logits = self._top_k_filter(logits, self.config.top_k)
                next_token = self._sample_token(logits)
            elif self.config.strategy == DecodingStrategy.TOP_P:
                logits = self._apply_temperature(logits, self.config.temperature)
                logits = self._top_p_filter(logits, self.config.top_p)
                next_token = self._sample_token(logits)
            
            tokens.append(next_token)
            
            if next_token == self._eos_token():
                break
        
        return self._detokenize(tokens)
    
    def _tokenize(self, text: str) -> List[int]:
        """Tokeniza el texto de entrada."""
        return [ord(c) for c in text]
    
    def _detokenize(self, tokens: List[int]) -> str:
        """Convierte tokens de vuelta a texto."""
        return ''.join(chr(t) for t in tokens)
    
    def _get_logits(self, tokens: List[int]) -> np.ndarray:
        """Obtiene logits del modelo para los tokens dados."""
        return np.random.randn(1000).astype(np.float32)
    
    def _eos_token(self) -> int:
        """Token de fin de secuencia."""
        return 0


def create_generator(
    strategy: str = "greedy",
    temperature: float = 1.0,
    seed: Optional[int] = None,
) -> TextGenerator:
    """
    Factory function para crear un generador configurado.
    
    Args:
        strategy: Estrategia de decodificacion
        temperature: Temperatura para sampling
        seed: Seed para reproducibilidad
        
    Returns:
        Instancia configurada del generador
    """
    strategy_map = {
        "greedy": DecodingStrategy.GREEDY,
        "sampling": DecodingStrategy.SAMPLING,
        "top_k": DecodingStrategy.TOP_K,
        "top_p": DecodingStrategy.TOP_P,
    }
    
    config = DecodingConfig(
        strategy=strategy_map.get(strategy, DecodingStrategy.GREEDY),
        temperature=temperature,
        seed=seed,
    )
    
    return TextGenerator(config=config)


if __name__ == "__main__":
    # Test con diferentes estrategias
    for strategy in ["greedy", "sampling", "top_k", "top_p"]:
        gen = create_generator(strategy=strategy, seed=42)
        print(f"Estrategia: {strategy}")
        print(f"Config: {gen.config}")

Errores Comunes

Error 1: No validar inputs antes de procesar

El problema: Confiar ciegamente en que los inputs seran validos. En produccion, valores NaN aparecen por corrupcion de datos, errores de API, o bugs en preprocessing. Si no validas, el modelo puede propagar NaNs silenciosamente y retornar garbage por horas antes de que alguien se de cuenta.

Solucion: Implementar validacion de inputs al inicio de cada paso de computacion. Verificar NaN, Inf, y tipos correctos. Fail fast es mejor que corrupcion silenciosa.

Error 2: Hardcodear hiperparametros en lugar de hacerlos configurables

El problema: Hiperparametros como temperature y top_k son criticos para el rendimiento pero muchos developers los hardcodean. Cuando necesitas ajustar para diferentes casos de uso, terminas cambiando codigo en multiples lugares.

Solucion: Usar configuracion centralizada (dataclasses, configs, variables de entorno). Esto permite ajustes sin cambiar codigo y facilita la reproducibilidad de experimentos.

Error 3: No guardar estado para reproducibilidad

El problema: Sin gestion de estado, no puedes reproducir resultados exactos. El mismo codigo con los mismos inputs puede dar resultados diferentes en diferentes ejecuciones debido a inicializacion aleatoria no controlada.

Solucion: Guardar random seed, estado de inicializacion, e hiperparametros junto con el modelo. Incluir version tracking.

Resumen y Cierre

  • Greedy Decoding vs Sampling es fundamental para sistemas ML robustos en produccion.
  • Validacion de inputs previene corrupcion silenciosa de datos.
  • Configuracion centralizada permite tuning sin cambiar codigo.
  • Gestion de estado es critica para reproducibilidad.
  • Logging detallado facilita debugging cuando las cosas fallan.
