Mechanistic Interpretability - Desmontando Redes Neuronales

Hagale pues, parcero. Dia 269 y hoy hablamos de Mechanistic Interpretability: desmontar redes neuronales capa por capa. Cafe.

🎯 Mechanistic Interpretability

Mecanistic interpretability busca entender exactamente como los circuitos neuronales implementan algoritmos:

  • Circuits: Patrones de conexion que implementan computo
  • Features: Representaciones internas de conceptos
  • Algorithms: Los pasos computacionales exactos

def analyze_circuit(model, behavior):

    # Patch cada capa y ver efecto

🚀 Superposition

# Superposition: representar mas features que neuronas
# Problema: necesitamos 1000 features pero solo 512 neuronas

# Solucion: features que nunca co-ocurren se representan juntos
# Polysemanticity: una neurona responde a multiples conceptos

# Esto causa "interference" y hace interpretability dificil
# y puede ser fuente de hallucinations

⚠️ Errores Comunes

Error 1: Circuit Hunting Sin Contexto

El problema: Encontrar circuitos pero no entender su rol.

La solucion: Estudiar el circuito completo, no solo partes.
