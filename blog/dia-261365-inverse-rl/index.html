🎯 Por Qué Los Agentes Olvidan Todo?

Hagale pues, parcero. Día 261 y hoy vamos a hablar de algo que el 90% de los equipos ignora cuando construyen agentes: Memory Systems. Un agente sin memoria es como un goldfish — hace cosas pero no recuerda nada. Cada conversación empieza de cero, cada tarea se repite, y el usuario termina frustrado porque "el bot no aprende". Esto separa un agente útil de uno inútil.

📐 Tipos de Memoria en Agentes

La arquitectura de memoria para agentes tiene tres capas, cada una con propósito diferente:

$$\text{Memory Architecture} = f(\text{Sensory}, \text{Short-Term}, \text{Long-Term})$$

  • Sensory Memory: Buffer de lo que está pasando ahora mismo. Representaciones raw del ambiente.
  • Short-Term Memory (STM): Contexto de la conversación actual. Limitado en tamaño — típicamente los últimos N mensajes o tokens.
  • Long-Term Memory (LTM): Todo lo que el agente ha aprendido across sessions. Puede persistir por días, semanas, o permanentemente.

🔧 Implementando Short-Term Memory

STM es lo que ves cuando miras el historial de chat. En agentes, esto se implementa típicamente como un sliding window sobre la conversación:

from collections import deque
from typing import List, Dict, Any

class ShortTermMemory:
    """Memory de conversación actual - sliding window approach."""

    def __init__(self, max_tokens: int = 4096):
        self.max_tokens = max_tokens
        self.messages: deque = deque()
        self.token_count = 0

    def add_message(self, role: str, content: str) -> None:
        """Agrega mensaje respetando el límite de tokens."""
        message = {"role": role, "content": content}
        msg_tokens = self._estimate_tokens(content)

        # Si un solo mensaje excede el límite, truncamos
        while self.token_count + msg_tokens > self.max_tokens and len(self.messages) > 1:
            removed = self.messages.popleft()
            self.token_count -= self._estimate_tokens(removed["content"])

        if msg_tokens > self.max_tokens:
            # Truncar el mensaje mismo
            content = self._truncate_to_tokens(content, self.max_tokens - 50)
            message["content"] = content
            msg_tokens = self.max_tokens

        self.messages.append(message)
        self.token_count += msg_tokens

    def get_context(self) -> List[Dict[str, str]]:
        """Retorna el contexto completo para el LLM."""
        return list(self.messages)

    def _estimate_tokens(self, text: str) -> int:
        """Estimación gruesa: ~4 caracteres por token para español."""
        return len(text) // 4

    def _truncate_to_tokens(self, text: str, max_tokens: int) -> str:
        """Trunca texto a un número estimado de tokens."""
        max_chars = max_tokens * 4
        return text[:max_chars]

    def clear(self) -> None:
        """Limpia toda la memoria de corto plazo."""
        self.messages.clear()
        self.token_count = 0

🧠 Implementando Long-Term Memory con Vector Store

LTM no puede ser solo un sliding window — necesitas persistencia y retrieval. La técnica más común es usar un vector database para almacenar experiencias pasadas y recuperarlas por similitud semántica:

from typing import List, Dict, Any, Optional
import numpy as np

class LongTermMemory:
    """Memoria persistente usando vector embeddings."""

    def __init__(self, vector_store, embedder, max_memories: int = 1000):
        self.store = vector_store  # Chroma, Pinecone, etc.
        self.embedder = embedder   # OpenAI, sentence-transformers, etc.
        self.max_memories = max_memories

    def add_memory(
        self,
        content: str,
        metadata: Optional[Dict[str, Any]] = None,
        importance: float = 1.0
    ) -> str:
        """Agrega un recuerdo a la memoria de largo plazo."""
        embedding = self.embedder.embed(content)

        memory_entry = {
            "content": content,
            "importance": importance,
            "metadata": metadata or {}
        }

        memory_id = self.store.add(
            embeddings=[embedding],
            documents=[content],
            metadatas=[memory_entry]
        )
        return memory_id

    def retrieve(
        self,
        query: str,
        top_k: int = 5,
        importance_weight: float = 0.3
    ) -> List[Dict[str, Any]]:
        """Recupera memorias relevantes a la query."""
        query_emb = self.embedder.embed(query)

        results = self.store.similarity_search(
            query_emb,
            k=top_k * 2  # Traer más para filtrar después
        )

        # Re-rank por relevancia e importancia
        scored = []
        for r in results:
            relevance = 1 - r.get("distance", 0)  # Convertir distancia a similitud
            importance = r.get("metadata", {}).get("importance", 1.0)
            score = (1 - importance_weight) * relevance + importance_weight * importance
            scored.append({**r, "score": score})

        # Retornar top_k ordenados por score
        return sorted(scored, key=lambda x: x["score"], reverse=True)[:top_k]

    def consolidate_from_stm(self, stm_messages: List[Dict]) -> None:
        """Consolida la memoria de corto plazo a largo plazo."""
        # Crear un resumen de la conversación
        conversation_text = "\n".join([
            f"{m['role']}: {m['content']}" for m in stm_messages
        ])

        # Extraer información importante (aquí podría usar un LLM para resumir)
        summary = self._summarize_conversation(conversation_text)

        # Guardar como memoria
        self.add_memory(
            content=summary,
            metadata={
                "type": "conversation_summary",
                "message_count": len(stm_messages),
                "first_role": stm_messages[0]["role"] if stm_messages else None
            }
        )

⚡ Memory Consolidation: De STM a LTM

El proceso de consolidar memoria es crítico. No quieres guardar cada mensaje — eso saturaría tu vector store. Quieres resumir y extraer lo importante:

class MemoryConsolidator:
    """Decide cuándo y qué consolidar de STM a LTM."""

    def __init__(
        self,
        stm: ShortTermMemory,
        ltm: LongTermMemory,
        consolidation_threshold: int = 20,
        min_importance_to_save: float = 0.6
    ):
        self.stm = stm
        self.ltm = ltm
        self.consolidation_threshold = consolidation_threshold
        self.min_importance_to_save = min_importance_to_save

    def should_consolidate(self) -> bool:
        """Determina si es momento de consolidar."""
        return len(self.stm.messages) >= self.consolidation_threshold

    def consolidate(self, session_id: str) -> Dict[str, Any]:
        """Ejecuta la consolidación STM -> LTM."""
        if not self.should_consolidate():
            return {"status": "skipped", "reason": "threshold_not_reached"}

        messages = self.stm.get_context()

        # Analizar importancia de cada mensaje (simplificado)
        important_memories = self._extract_important_memories(messages)

        consolidated = []
        for memory in important_memories:
            self.ltm.add_memory(
                content=memory["content"],
                metadata={
                    "session_id": session_id,
                    "importance": memory["importance"],
                    "type": memory["type"]
                }
            )
            consolidated.append(memory["content"])

        # Limpiar STM después de consolidar
        self.stm.clear()

        return {
            "status": "success",
            "memories_consolidated": len(consolidated),
            "sample": consolidated[:3]
        }

    def _extract_important_memories(self, messages: List[Dict]) -> List[Dict]:
        """Extrae memorias importantes de la conversación."""
        # En producción, esto usaría un LLM para clasificar
        # Por ahora, heurística simple:
        important = []
        for m in messages:
            content = m["content"]
            # Mensajes largos tienden a ser más importantes
            length_score = min(len(content) / 500, 1.0)
            # Mensajes del usuario suelen ser más importantes
            role_score = 0.8 if m["role"] == "user" else 0.4

            importance = (length_score + role_score) / 2

            if importance >= self.min_importance_to_save:
                important.append({
                    "content": content[:500],  # Limitar largo
                    "importance": importance,
                    "type": "conversation_fragment"
                })

        return important

⚠️ Errores Comunes (y Cómo Evitarlos)

Error 1: No Implementar memory eviction

El problema: La memoria crece infinitamente. Eventually consumes all storage and retrieval becomes slow.

La solución: Implementar políticas de eviction como LRU o importance-based pruning:

class EvictionPolicy:
    """Politicas de eviction para memoria de agente."""

    @staticmethod
    def lru_evict(memories: List[Dict], max_count: int) -> List[Dict]:
        """Mantiene solo los últimos max_count recuerdos."""
        return memories[-max_count:]

    @staticmethod
    def importance_evict(memories: List[Dict], max_count: int, min_importance: float) -> List[Dict]:
        """Evita recuerdos de baja importancia si hay muchos."""
        # Ordenar por importancia
        sorted_mem = sorted(memories, key=lambda x: x.get("importance", 0), reverse=True)

        # Si hay espacio, devolver todos los que superen el umbral
        if len(sorted_mem) <= max_count:
            return [m for m in sorted_mem if m.get("importance", 0) >= min_importance]

        # Tomar los más importantes hasta max_count
        return sorted_mem[:max_count]

Error 2: No separar contextos de diferentes usuarios o sesiones

El problema: Un usuario ve información de otro. Peor aún: tu agente mezcla contextos de sesiones diferentes.

La solución: Namespaces o filtros por session_id en el vector store:

classnamespacedMemory:
    """Memoria separada por sesión o usuario."""

    def __init__(self, base_memory: LongTermMemory, namespace: str):
        self.base = base_memory
        self.namespace = namespace  # e.g., "user_123" or "session_456"

    def add_memory(self, content: str, metadata: Dict = None) -> str:
        ns_metadata = {**metadata, "namespace": self.namespace}
        return self.base.add_memory(content, metadata=ns_metadata)

    def retrieve(self, query: str, top_k: int = 5) -> List[Dict]:
        # Filtrar por namespace
        results = self.base.store.similarity_search(
            query,
            k=top_k * 3,
            filter={"namespace": self.namespace}
        )
        return results[:top_k]

📊 Resumen

  • Short-Term Memory: Sliding window sobre conversación actual. Limitada en tokens.
  • Long-Term Memory: Vector store con embeddings. Persistente y searchable.
  • Consolidation: Proceso de mover información de STM a LTM cuando la sesión termina o el buffer se llena.
  • Eviction policies: LRU, importance-based, o híbridas para evitar crecimiento infinito.
  • Namespaces: Aislamiento de memoria entre usuarios y sesiones.
