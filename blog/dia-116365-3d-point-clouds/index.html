Dropout: La Técnica de Regularización que Todos Piensan Entender

Dropout, introducido por Srivastava et al. en 2014, funciona así: durante el entrenamiento, cada neurona tiene probabilidad p de ser "apagada" (set to zero) en cada forward pass. Durante inferencia, todas las neuronas están activas pero sus outputs se escalan por p.

La idea central es que la red no puede depender de neuronas específicas, así que aprende representaciones más robustas. En términos matemáticos:

$$\text{Durante entrenamiento: } y_i = x_i \cdot m_i, \quad m_i \sim \text{Bernoulli}(p)$$

$$\text{Durante inferencia: } E[y_i] = p \cdot x_i + (1-p) \cdot 0 = p \cdot x_i \quad \text{(por eso se escala)}$$

Pero hay variantes que la mayoría no conoce: Spatial Dropout, Variational Dropout, DropConnect, Alpha Dropout para redes SELU, y el powerful Monte Carlo Dropout para incertidumbre.

En Colombia decimos "zorro viejo no se deja atrapar". Dropout es viejo (2014) pero muchos developers siguen cayendo en los mismos errores una y otra vez. Vamos a cambiar eso.

"""
Dropout techniques en PyTorch — Spatial, Embeddings, MC, DropConnect, Alpha.
Código completo listo para producción y experiments.
"""
import torch
import torch.nn as nn
import torch.nn.functional as F
import matplotlib.pyplot as plt
import numpy as np
from torch.utils.data import DataLoader, TensorDataset


# ─────────────────────────────────────────────
# 1. Standard Dropout (baseline)
# ─────────────────────────────────────────────
class StandardDropout(nn.Module):
    """Dropout estándar: cada elemento individual tiene probabilidad p de ser zero."""

    def __init__(self, p=0.5):
        super().__init__()
        self.p = p

    def forward(self, x):
        if self.training:
            # Bernoulli sampling durante entrenamiento
            mask = torch.bernoulli(torch.full_like(x, 1 - self.p))
            return x * mask / (1 - self.p)  # escala para mantener expected value
        return x


# ─────────────────────────────────────────────
# 2. Spatial Dropout para CNNs (¡CRÍTICO!)
# ─────────────────────────────────────────────
class SpatialDropout(nn.Module):
    """
    Spatial Dropout: en lugar de zeroear elementos individuales,
    zeroea TODOS los elementos de un canal completo (feature map).

    Para CNNs, standard dropout es inefectivo porque los feature maps
    tienen correlación espacial fuerte. Si zeroeas un pixel, la información
    todavía fluye por pixels vecinos. Spatial dropout zeroea todo el canal.

    En PyTorch moderno: F.dropout2d / F.dropout3d hacen exactamente esto.
    """

    def __init__(self, p=0.5):
        super().__init__()
        self.p = p

    def forward(self, x):
        """
        x: [batch, channels, height, width]
        En training: apaga canales completos con prob p.
        """
        if self.training:
            # drop entire channels
            mask = torch.bernoulli(torch.full((x.size(0), x.size(1), 1, 1), 1 - self.p))
            # expand to match x shape
            mask = mask.expand_as(x)
            return x * mask / (1 - self.p)
        return x


# ─────────────────────────────────────────────
# 3. Dropout en Embeddings
# ─────────────────────────────────────────────
class EmbeddingDropout(nn.Module):
    """
    Dropout en embedding layers.
    Embbedings tienen alta dimensionalidad y sobre-ajustan fácilmente.
    Dropout en embeddings zeroea filas completas de la matrix de embeddings.

    Nota: PyTorch nn.Embedding no tiene dropout por defecto — hay que implementarlo.
    """

    def __init__(self, num_embeddings, embedding_dim, p=0.5):
        super().__init__()
        self.embed = nn.Embedding(num_embeddings, embedding_dim)
        self.p = p

    def forward(self, x):
        """
        x: LongTensor de índices [seq_len, batch] o [batch, seq_len]
        Embedding dropout zeroea filas enteras de la matriz de embeddings.
        """
        if self.training and self.p > 0:
            # Obtener embeddings
            embedded = self.embed(x)  # [batch, seq_len, embed_dim]

            # Crear mask para filas de embedding
            # mask shape: [num_embeddings, 1]
            mask = torch.bernoulli(torch.full(
                (self.embed.num_embeddings, 1),
                1 - self.p,
                device=x.device
            ))

            # Aplicar mask — indexing broadcast
            # self.embed.weight: [num_embeddings, embed_dim]
            dropped_weight = self.embed.weight * mask / (1 - self.p)

            # Forward con weight modificado
            return F.embedding(
                x,
                dropped_weight,
                padding_idx=self.embed.padding_idx,
                max_norm=self.embed.max_norm,
                norm_type=self.embed.norm_type,
                scale_grad_by_freq=self.embed.scale_grad_by_freq,
                sparse=self.embed.sparse
            )
        return self.embed(x)


# ─────────────────────────────────────────────
# 4. DropConnect (não Dropout)
# ─────────────────────────────────────────────
class DropConnect(nn.Module):
    """
    DropConnect: en lugar de zeroear outputs de neuronas,
    zeroea CONEXIONES (pesos) entre neuronas.

    Diferencia clave:
    - Dropout: apaga outputs (activaciones)
    - DropConnect: apaga weights (parámetros)

    Math: durante training, cada weight w_ij tiene prob p de ser zero.
    Durante inference, se usa E[w_ij] = (1-p) * w_ij (promedio del mask).
    """

    def __init__(self, module, p=0.5):
        super().__init__()
        self.module = module
        self.p = p
        # Para guardar el mask por layer
        self.mask = None

    def forward(self, x):
        if self.training:
            # Crear mask del mismo tamaño que los pesos
            for name, param in self.module.named_parameters():
                if 'weight' in name or 'bias' in name:
                    self.mask = torch.bernoulli(
                        torch.full_like(param, 1 - self.p)
                    )
                    param = param * self.mask / (1 - self.p)
        return self.module(x)


# ─────────────────────────────────────────────
# 5. Alpha Dropout (para redes SELU — Self-Normalizing ENN)
# ─────────────────────────────────────────────
class AlphaDropout(nn.Module):
    """
    Alpha Dropout: dropout especial para redes SELU (Self-Normalizing Neural Networks).

    Redes SELU mantienen media=0 y varianza=1 en cada capa si las inputs también lo son.
    Standard dropout rompe esto porque zeroear cambia la distribución.

    Alpha Dropout:
    1. Aplica el mask de dropout como estándar
    2. Shift y scale los valores para mantener media y varianza

    Math:
      Sea a = selu(x), luego a' = dropout(a, p)
      Se aplica: a'' = a' * λ + μ  donde μ, λ compensan el dropout

    PyTorch tiene F.alpha_dropout para esto.
    """

    def __init__(self, p=0.5):
        super().__init__()
        self.p = p

    def forward(self, x):
        if self.training:
            # F.alpha_dropout preserva mean y variance de la activación SELU
            return F.alpha_dropout(x, p=self.p, training=self.training)
        return x


# ─────────────────────────────────────────────
# 6. Monte Carlo Dropout — Uncertainty Estimation
# ─────────────────────────────────────────────
class MCDropoutModel(nn.Module):
    """
    Monte Carlo Dropout: usa dropout EN INFERENCIA para estimar incertidumbre.

    Idea: si haces T forward passes con dropout activo (training=True),
    obtienes T outputs diferentes. La varianza de esos outputs es una
    medida de incertidumbre del modelo.

    Esto es Bayesian approximation sin necesidad de inferencia variacional.
    """

    def __init__(self, base_model, n_classes=10, dropout_p=0.5):
        super().__init__()
        self.base_model = base_model
        self.n_classes = n_classes
        self.dropout_p = dropout_p

        # Reemplazar dropout layers con rate específico
        self._replace_dropout(self.base_model, dropout_p)

    def _replace_dropout(self, model, p):
        """Reemplaza todas las capas de Dropout con el rate dado."""
        for name, child in model.named_children():
            if isinstance(child, nn.Dropout) or isinstance(child, nn.Dropout2d):
                setattr(model, name, nn.Dropout(p=p))
            else:
                self._replace_dropout(child, p)

    def forward(self, x, training=None):
        """
        Forward normal. Si training=True, dropout está activo.
        """
        return self.base_model(x)

    def mc_forward(self, x, n_passes=30):
        """
        Hace n_passes forward passes con dropout activo.
        Retorna: media y desviación estándar de las predicciones.
        """
        if training is None:
            training_backup = self.base_model.training
            self.base_model.train()

        logits_list = []
        for _ in range(n_passes):
            with torch.no_grad():
                logits_list.append(self.base_model(x))

        logits = torch.stack(logits_list)  # [n_passes, batch, n_classes]
        mean_logits = logits.mean(dim=0)
        std_logits = logits.std(dim=0)

        if training is None:
            if not training_backup:
                self.base_model.eval()
        else:
            if not training:
                self.base_model.eval()

        return mean_logits, std_logits, logits


# ─────────────────────────────────────────────
# 7. CNN con Spatial Dropout — DEMO COMPLETA
# ─────────────────────────────────────────────
class CNNWithSpatialDropout(nn.Module):
    """CNN que usa Spatial Dropout entre capas convolucionales."""

    def __init__(self, in_channels=1, num_classes=10, dropout_p=0.25):
        super().__init__()
        # Conv block 1
        self.conv1 = nn.Conv2d(in_channels, 32, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(32)
        # Spatial dropout después de batch norm
        self.spatial_dropout1 = nn.Dropout2d(p=dropout_p)

        # Conv block 2
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(64)
        self.spatial_dropout2 = nn.Dropout2d(p=dropout_p)

        # Conv block 3
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)
        self.spatial_dropout3 = nn.Dropout2d(p=dropout_p)

        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(128 * 3 * 3, num_classes)

    def forward(self, x):
        # Block 1
        x = F.relu(self.bn1(self.conv1(x)))
        x = self.spatial_dropout1(x)  # Spatial dropout, no standard
        x = self.pool(x)

        # Block 2
        x = F.relu(self.bn2(self.conv2(x)))
        x = self.spatial_dropout2(x)
        x = self.pool(x)

        # Block 3
        x = F.relu(self.bn3(self.conv3(x)))
        x = self.spatial_dropout3(x)
        x = self.pool(x)

        x = x.view(x.size(0), -1)
        x = self.fc(x)
        return x


# ─────────────────────────────────────────────
# 8. SELU Network con Alpha Dropout
# ─────────────────────────────────────────────
class SELUNetworkWithAlphaDropout(nn.Module):
    """
    Red SELU (self-normalizing) con Alpha Dropout.
    Importante: LAS initialization es crítica para redes SELU.
    """

    def __init__(self, input_dim=784, hidden_dims=[256, 128], num_classes=10, dropout_p=0.2):
        super().__init__()
        self.scale = 1.0  # para SELU

        layers = []
        prev_dim = input_dim
        for hidden_dim in hidden_dims:
            layers.append(nn.Linear(prev_dim, hidden_dim))
            # SELU activation — mantiene auto-normalización
            layers.append(nn.SELU())
            # Alpha dropout — preserva la distribución
            layers.append(AlphaDropout(p=dropout_p))
            prev_dim = hidden_dim

        self.feature_layers = nn.Sequential(*layers)
        self.output_layer = nn.Linear(prev_dim, num_classes)

        # Inicialización crítica para SELU (lecun normal)
        self._initialize_weights()

    def _initialize_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Linear):
                nn.init.lecun_normal_(m.weight, nonlinearity='linear')
                if m.bias is not None:
                    nn.init.zeros_(m.bias)

    def forward(self, x):
        x = x.view(x.size(0), -1)
        x = self.feature_layers(x)
        return self.output_layer(x)

# 9. MC Dropout Comparison Demo
# ─────────────────────────────────────────────
def mc_dropout_comparison():
    """
    Compara predicción estándar vs MC dropout.
    """
    torch.manual_seed(42)

    # Modelo simple
    base_model = nn.Sequential(
        nn.Linear(10, 64),
        nn.ReLU(),
        nn.Dropout(0.5),
        nn.Linear(64, 32),
        nn.ReLU(),
        nn.Dropout(0.5),
        nn.Linear(32, 2)
    )

    mc_model = MCDropoutModel(base_model, n_classes=2, dropout_p=0.5)

    x_test = torch.randn(5, 10)

    # Standard inference
    base_model.eval()
    with torch.no_grad():
        standard_pred = base_model(x_test)

    # MC dropout inference
    mean_pred, std_pred, all_preds = mc_model.mc_forward(x_test, n_passes=50)

    print("Standard prediction (no dropout en inference):")
    print(f"  {standard_pred}")

    print("\nMC Dropout (50 passes, model.train()):")
    print(f"  Mean: {mean_pred}")
    print(f"  Std:  {std_pred}")

    # Confidence = 1 - uncertainty (std)
    confidence = 1 - std_pred.mean(dim=1)
    print(f"  Confidence: {confidence}")

    return mean_pred, std_pred, all_preds

Los 3 Errores Más Frecuentes con Dropout

Error 1: Usar Standard Dropout en CNNs (Spatial Dropout es necesario)

Este es quizás el error más común. En capas convolucionales, los feature maps tienen correlación espacial fuerte. Standard dropout (element-wise) es inefectivo porque si zeroeas un pixel, la información todavía fluye por pixels vecinos. Lo que necesitas es Spatial Dropout que zeroea canales completos:

# ❌ ERROR: Standard Dropout en CNN
class BadCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.drop1 = nn.Dropout(0.5)  # Inefectivo en convs

    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = self.drop1(x)  # Este dropout no hace casi nada en feature maps
        return x

# ✅ FIX: Usar Spatial Dropout (Dropout2d en PyTorch)
class GoodCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 32, 3, padding=1)
        self.drop1 = nn.Dropout2d(p=0.5)  # Zeroea canales completos

    def forward(self, x):
        x = F.relu(self.conv1(x))
        x = self.drop1(x)  # Este sí regulariza los feature maps
        return x

Error 2: MC Dropout sin saber que se necesita model.train() al final

Monte Carlo Dropout para incertidumbre requiere que el modelo esté en training=True durante los forward passes. Muchos olvidan volver a eval() después, lo que causa que las predicciones siguientes sean determinísticas (sin la estimación de incertidumbre):

# ❌ ERROR: MC Dropout sin restore training mode
mc_model = MCDropoutModel(my_model)
mc_model.train()  # Activar dropout

mean_pred, std_pred, _ = mc_model.mc_forward(x_test, n_passes=30)

# AQUÍ ESTÁ EL BUG: el modelo quedó en train mode
# Siguiente predicción estándar también tendrá dropout activo
standard_pred = my_model(x_new)  # ¡Dropout sigue activo!

# ✅ FIX: Restaurar eval mode después de MC
mc_model.eval()  # o mc_model.train(False)
mean_pred, std_pred, _ = mc_model.mc_forward(x_test, n_passes=30)
mc_model.eval()  # Asegurar que quedó en modo evaluación
standard_pred = my_model(x_new)  # Ahora sí determinístico

Error 3: Usar dropout=0.5 para toda la red sin considerar la profundidad

Un 0.5 para todas las capas es un one-size-fits-none. Redes profundas con dropout alto en las primeras capas pueden apagarse demasiado y la señal no llega a las capas finales. Capas cercanas al input necesitan menos dropout que las cercanas al output:

# ❌ ERROR: Dropout uniforme de 0.5 en toda la red
class UniformDropoutNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(784, 512)
        self.drop1 = nn.Dropout(0.5)  # Demasiado para la primera capa
        self.layer2 = nn.Linear(512, 256)
        self.drop2 = nn.Dropout(0.5)
        self.layer3 = nn.Linear(256, 128)
        self.drop3 = nn.Dropout(0.5)  # 0.5 aquí sí tiene sentido
        self.layer4 = nn.Linear(128, 10)
        self.drop4 = nn.Dropout(0.5)  # Puede ser muy agresivo

# ✅ FIX: Dropout gradually increasing hacia el final
class ProgressiveDropoutNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer1 = nn.Linear(784, 512)
        self.drop1 = nn.Dropout(0.1)   #Poco en early layers
        self.layer2 = nn.Linear(512, 256)
        self.drop2 = nn.Dropout(0.2)
        self.layer3 = nn.Linear(256, 128)
        self.drop3 = nn.Dropout(0.3)
        self.layer4 = nn.Linear(128, 10)
        self.drop4 = nn.Dropout(0.5)   # Más dropout cerca del output

Resumen y Cierre

Dropout es poderoso pero tiene variantes que la mayoría ignora. Aquí el resumen para que no te quemes:

  • Standard Dropout: para capas fully-connected (MLP).
  • Spatial Dropout (Dropout2d): para CNNs — zeroea canales completos.
  • Embedding Dropout: para NLP y embedding layers.
  • DropConnect: para regularizar weights directamente (más fuerte que Dropout).
  • Alpha Dropout: para redes SELU, preserva la auto-normalización.
  • MC Dropout: para incertidumbre sin inferencia bayesiana — usa model.train() antes y model.eval() después.

Y recuerden, parcero: dropout率为 0.5 no es magia. Cada arquitectura y dataset tiene su sweet spot. Experimenta con dropout schedules y diferentes rates por capa.
