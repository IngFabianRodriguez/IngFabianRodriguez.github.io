Segmentación Semántica con U-Net: Más Allá de Clasificar Píxeles

23 de julio de 2026
u-netsemantic-segmentationcomputer-visionmedical-imaging

Hagale pues, parcero. Hoy es el Día 205 y vamos a meternos de lleno en un tema que es pura matemática aplicada: la segmentación semántica. No那张 classifying an entire image — aquí el negocio es asignarle una clase a cada pixel. Imagínese eso en una tomografía axial computadorizada (TAC) buscando tumores: cada pixel importa, cada frontera cuenta. Dejó el café, esto se pone bueno.

Qué es la Segmentación Semántica?

Mientras que la clasificación de imágenes te dice "hay un gato en esta foto", la segmentación semántica te dice "estos píxeles son el gato, estos son el sofá, estos son la pared". Cada píxel recibe una etiqueta de clase.

Ahora, hay que ser preciso con la jerga porque es donde muchos se pierdan:

  • Semantic Segmentation: Asigna una clase a cada píxel. Si hay 3 gatos, todos los píxeles de los 3 gatos se marcan como "gato" — no los distinguimos entre sí.
  • Instance Segmentation: Va más allá — diferencia cada objeto individual. Cada gato recibe su propia instancia única.

La U-Net fue diseñada para semantic segmentation, no instance segmentation. Si necesita contar objetos individuales, mire Mask R-CNN o YOLO instance.

La matemática detrás

La segmentación semántica aprende una función f: ℝ^(H×W×C) → ℝ^(H×W×K) que mapea una imagen de entrada con altura H, ancho W y canales C a un mapa de segmentation de H×W donde cada posición tiene K valores (logits por clase). La clase predicha es:

ŷ_{h,w} = argmax_k ( logits_{h,w,k} )

La Arquitectura U-Net

U-Net, propuesta por Ronneberger et al. en 2015, tiene esa forma de "U" que le da el nombre. Dos caminos:

  • Encoder (camino de contracción): Captura contexto. Aplicamos conv → ReLU → conv → ReLU seguido de max pooling. La resolución baja, los canales suben (64 → 128 → 256 → 512).
  • Decoder (camino de expansión): Recupera ubicación espacial precisa. Upsampling + concatenación con skip connections del encoder + convolutions.

Las skip connections son la salsa secreta: permiten que la información espacial de alta resolución del encoder se combine con la información semántica del decoder.

La fórmula matemática

La skip connection se expresa como:

f_skip(x_encoder, x_decoder) = concat( upsample(x_decoder), x_encoder )

Donde upsample puede ser transposed convolution o bilinear interpolation seguida de convolution.

Implementando U-Net en PyTorch desde Cero

import torch
import torch.nn as nn
import torch.nn.functional as F

class DoubleConv(nn.Module):
    """Dos convoluciones seguidas de BatchNorm y ReLU"""
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.double_conv = nn.Sequential(
            nn.Conv2d(in_ch, out_ch, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_ch, out_ch, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_ch),
            nn.ReLU(inplace=True)
        )
    def forward(self, x):
        return self.double_conv(x)

class UNet(nn.Module):
    def __init__(self, in_channels=3, out_channels=1, features=[64, 128, 256, 512]):
        super().__init__()
        self.downs = nn.ModuleList()
        self.ups = nn.ModuleList()
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)

        # Encoder: camino de contracción
        for feature in features:
            self.downs.append(DoubleConv(in_channels, feature))
            in_channels = feature

        # Bottleneck
        self.bottleneck = DoubleConv(features[-1], features[-1] * 2)

        # Decoder: camino de expansión
        for feature in reversed(features):
            self.ups.append(
                nn.ConvTranspose2d(feature * 2, feature, kernel_size=2, stride=2)
            )
            self.ups.append(DoubleConv(feature * 2, feature))

        # Capa final: 1x1 conv para generar el mapa de segmentation
        self.final_conv = nn.Conv2d(features[0], out_channels, kernel_size=1)

    def forward(self, x):
        skip_connections = []

        # Encoder
        for down in self.downs:
            x = down(x)
            skip_connections.append(x)
            x = self.pool(x)

        x = self.bottleneck(x)
        skip_connections = skip_connections[::-1]  # Invertir para el decoder

        # Decoder con skip connections
        for idx in range(0, len(self.ups), 2):
            x = self.ups[idx](x)  # Upsample
            skip = skip_connections[idx // 2]
            # Manejar diferencia de tamaño si la imagen no es divisible por 2^n
            if x.shape != skip.shape:
                x = F.interpolate(x, size=skip.shape[2:])
            x = torch.cat([skip, x], dim=1)  # Concatenar
            x = self.ups[idx + 1](x)  # DoubleConv

        return self.final_conv(x)

# Instanciar el modelo
model = UNet(in_channels=3, out_channels=1)
print(f"Parámetros totales: {sum(p.numel() for p in model.parameters()):,}")
# Salida: ~31M parámetros

Dice Loss: lidiando con el Class Imbalance

En segmentación médica, típicamente tenemos un imbalance severo: los voxels del tumor pueden ser solo el 2% de la imagen. Usar cross-entropy aquí es un error grave — el modelo aprende a predecir el fondo siempre y listo.

El Dice Loss optimiza directamente el coeficiente de Dice:

Dice = (2 * |X ∩ Y|) / (|X| + |Y|)

Donde X es la predicción binaria e Y es el ground truth. Esto es equivalente al F1-score para segmentación.

class DiceLoss(nn.Module):
    def __init__(self, smooth=1e-6):
        super().__init__()
        self.smooth = smooth

    def forward(self, logits, targets):
        """
        logits: (B, C, H, W) - predicciones del modelo
        targets: (B, H, W) - etiquetas enteras 0 o 1
        """
        # Aplicar sigmoid para obtener probabilidades
        probs = torch.sigmoid(logits)
        
        # Aplanar
        probs = probs.view(-1)
        targets = targets.view(-1)

        # Calcular Dice coefficient
        intersection = (probs * targets).sum()
        dice = (2. * intersection + self.smooth) / (
            probs.sum() + targets.sum() + self.smooth
        )
        
        return 1 - dice  # Minimizar 1 - Dice = maximizar Dice

class CombinedLoss(nn.Module):
    """Combina BCE y Dice para mejor estabilidad"""
    def __init__(self, bce_weight=0.5, dice_weight=0.5):
        super().__init__()
        self.bce = nn.BCEWithLogitsLoss()
        self.dice = DiceLoss()
        self.bce_weight = bce_weight
        self.dice_weight = dice_weight

    def forward(self, logits, targets):
        bce_loss = self.bce(logits, targets.float())
        dice_loss = self.dice(logits, targets)
        return self.bce_weight * bce_loss + self.dice_weight * dice_loss

# Ejemplo de uso
criterion = CombinedLoss(bce_weight=0.3, dice_weight=0.7)
# En medical imaging, peso mayor al Dice porque hay poco foreground

IoU (Intersection over Union) y Dice Coefficient

Estas son las métricas estándar para evaluar segmentación:

IoU = |X ∩ Y| / |X ∪ Y|

Dice = 2|X ∩ Y| / (|X| + |Y|)

Relación: Dice = 2*IoU / (IoU + 1) — son monotonicamente equivalentes.

def iou_score(preds, targets, threshold=0.5, smooth=1e-6):
    """
    Calcula IoU a nivel de batch
    preds: (B, H, W) logits normalizados 0-1
    targets: (B, H, W) binario
    """
    preds = (preds > threshold).float()
    
    intersection = (preds * targets).sum(dim=(1, 2))
    union = preds.sum(dim=(1, 2)) + targets.sum(dim=(1, 2)) - intersection
    
    iou = (intersection + smooth) / (union + smooth)
    return iou.mean()

def dice_coefficient(preds, targets, threshold=0.5, smooth=1e-6):
    """Calcula Dice coefficient"""
    preds = (preds > threshold).float()
    
    intersection = (preds * targets).sum(dim=(1, 2))
    dice = (2. * intersection + smooth) / (
        preds.sum(dim=(1, 2)) + targets.sum(dim=(1, 2)) + smooth
    )
    return dice.mean()

Generando Segmentation Masks

def generate_mask(model, image_tensor, threshold=0.5):
    """
    Genera una segmentation mask desde una imagen
    image_tensor: (1, C, H, W) normalizada
    """
    model.eval()
    with torch.no_grad():
        logits = model(image_tensor)
        probs = torch.sigmoid(logits)
        mask = (probs > threshold).float()
    return mask.squeeze().cpu().numpy()

def visualize_segmentation(image, mask, alpha=0.5):
    """Superpone mask sobre imagen"""
    import numpy as np
    import matplotlib.pyplot as plt
    
    # image: (H, W, 3), mask: (H, W) binario
    color_mask = np.zeros_like(image)
    color_mask[mask == 1] = [0, 255, 0]  # Verde para foreground
    
    overlayed = (image * (1 - alpha) + color_mask * alpha).astype(np.uint8)
    return overlayed

Los 3 Errores Más Comunes

Error 1: Confundir Semantic Segmentation con Instance Segmentation

El problema: Muchos пытаются usar U-Net para contar objetos individuales o separar instancias superpuestas. U-Net le da a todos los pixeles de todos los objetos de la misma clase la misma etiqueta — no puede distinguir entre dos tumores vecinos.

La solución: Para instance segmentation necesita Mask R-CNN, YOLO instance, o SOMETHING else. U-Net es para semantic: una clase, todos los pixeles conectados.

Error 2: No Usar Dice Loss con Class Imbalance

El problema: En imágenes médicas, el foreground puede ser 1-5% de la imagen. BCE solo optimiza pixel-wise accuracy — el modelo aprende a predecir siempre fondo y obtiene 95%+ accuracy sin aprender nada útil.

La solución: Use DiceLoss o CombinedLoss. El Dice Loss optimiza directamente la métrica que le importa y es robusto al imbalance porque el gradiente es proporcional al overlap, no al número de píxeles:

# Si tiene severe imbalance (ej: 98% background)
# Pruebe Dice Loss puro con esta formulacion
class DiceLoss(nn.Module):
    def forward(self, logits, targets):
        probs = torch.sigmoid(logits)
        smooth = 1.0
        dice = (2. * (probs * targets).sum() + smooth) / \
               (probs.sum() + targets.sum() + smooth)
        return -torch.log(dice + 1e-6)  # Equivalent to 1 - dice

Error 3: Data Augmentation que Modifica las Masks

El problema: Aplicar random horizontal flip a la imagen PERO NO a la mask resulta en datos inconsistentes — el modelo aprende con etiquetas que no corresponden a la imagen. Lo mismo con random crop, rotation desalineado, o elastic transform si no se asegura que imagen y mask sufran la misma transformación.

La solución: Use albumentations con el argumento mask para transformar ambas de forma consistente:

import albumentations as A
from albumentations.pytorch import ToTensorV2

transform = A.Compose([
    A.RandomCrop(height=256, width=256, p=0.8),
    A.HorizontalFlip(p=0.5),
    A.Rotate(limit=15, p=0.3, mask_interpolation='nearest'),
    A.ElasticTransform(p=0.2, mask_interpolation='nearest'),
    A.GaussNoise(var_limit=(10.0, 50.0), p=0.2),
    A.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
], bbox=None, mask_interpolation='nearest')

# Para aplicar a un batch
transformed = transform(image=image, mask=mask)
# transformed['image'] e transformed['mask'] siempre estan alineados
Regla de oro: Si aplica una transformación a la imagen, DEBE aplicar la misma transformación exacta a la mask. No hay excepciones.

Resumen y Cierre

La segmentación semántica con U-Net es una herramienta poderosa para cuantificar regiones en imágenes. Hoy cubrimos:

  • La diferencia entre semantic segmentation (clasificar cada pixel) e instance segmentation (distinguir objetos individuales)
  • Arquitectura U-Net con encoder-decoder y skip connections
  • Implementación completa en PyTorch de la U-Net desde cero
  • Dice Loss para manejar class imbalance en datos médicos
  • Métricas IoU y Dice para evaluar la calidad de la segmentación
  • Cómo generar y visualizar segmentation masks

Recuerde: en producción, el data augmentation consistente entre imagen y mask es tan importante como la arquitectura del modelo. Y si necesita contar objetos específicos, no use U-Net — necesita instance segmentation.
